# 主要收获与接下来内容

数据科学确实能带来很多价值，但它并非魔法，尽管许多领导层人士相信这一点。数据科学已从数据分析中演变出更为复杂的形式，对于那些理解其能力边界的企业而言，它大有可为。若拥有优质数据，数据科学家能帮助企业理解数据、制定计划和决策，并自动化那些耗时或不准确的流程。数据科学包含若干核心价值。

## 数据科学的核心价值

数据科学的核心价值包括简洁性、可解释性、可重复性、可信度、可理解性和可共享性。

`简洁性`意味着数据科学解决方案应在保持有用性的前提下尽可能简单。`可解释性`要求解决方案产生的结果必须能被解释（倾向于白盒方案而非黑盒方案）。`可重复性`要求数据科学家遵循严谨的代码规范与流程，使得工作能够被复现（从而确保结果的可靠性）。`可信度`关乎让利益相关者及其他人员相信你的解决方案是有效、合乎伦理，且具备适当安全性和隐私保护的。`可理解性`虽与可解释性部分相关，但更侧重于整体工作的可理解性（而不仅仅是结果本身），这一点与可重复性有共同目标。最后，`可共享性`指的是你能多容易地将结果分享给利益相关者、同事（以及领导），这需要关注多个方面，且与可理解性相关联。

请注意，这些价值并非总是同等重要——如果可解释性并非必需且更高的准确性更为关键，那么它尤其可以被舍弃。
