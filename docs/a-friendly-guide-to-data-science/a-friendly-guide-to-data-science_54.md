# 关键要点与下章预告

本章深入探讨了数据科学中的伦理问题。我首先列举了几个令人不安的案例，说明当数据科学系统在缺乏伦理考量下创建时可能造成的危害。接着定义了伦理、偏见和公平性，并探讨了为什么尽管大多数数据科学项目很少考虑伦理，但它仍然至关重要。数据科学系统的有用性（即效用）常被视为与伦理数据科学相悖。确实，有时对伦理问题保持谨慎可能会导致系统不那么有用或性能稍逊，但通常那些看似性能更优的模型，不过是在更有效地延续现实世界中的偏见。我讨论了数据科学家基于希波克拉底誓言宣誓致力于伦理数据科学的概念，以及将其作为伦理数据科学主要手段的局限性。作为替代，我介绍了一个名为 RDS 框架的更全面的体系，旨在通过将其融入整个数据科学流程来确保数据科学更具伦理性。最后，我谈到了如何参与并培养一种伦理数据科学文化。

本书第一部分的这一章，为实践数据科学奠定了所有必要的基础。现在，你已经准备好深入探讨实践数据科学最重要的主题。我们将从了解领域知识的重要性开始。

## 实践者档案：哈维·辛克尔

**姓名：**哈维·辛克尔

**职位：**高级数据科学家

**行业：**跨行业咨询

**从业经验：**3 年数据科学家经验，此前从事技术工作

**教育背景：**

-   技术博士（在读）
-   领导力方向 MBA
-   医疗管理学士
-   全球健康副学士

*此处观点仅代表哈维个人，与其现任或历任雇主无关。*

### 背景

哈维·辛克尔从零售业起步，但他知道自己不想一直做这个。在一家家居建材店担任副经理期间，他了解了商业和报告，这促使他尝试新方向。他曾在几个不同的 IT 岗位工作，并意识到要实现进入大公司的目标，需要更正规的教育。他参军入伍，目的是服役结束后利用《退伍军人权利法案》的资助。退役后，他对医疗保健产生了兴趣。他获得了全球健康副学士学位和医疗管理学士学位，但后来因为《退伍军人权利法案》的资助即将用完而需要找工作，再次改变了方向。他最终回到了技术领域，并决心从事数据科学。他发现了普渡大学的技术博士项目。该项目要求先获得硕士学位，于是他先攻读了 MBA，然后开始攻读博士学位。他正专注于伦理与机器学习方向的研究。

## 工作

哈维在攻读博士学位期间，继续在多个行业从事数据科学咨询工作。如前所述，他的工作经验非常多样化，但大部分都以某种形式集中于 IT 领域。离开军队后，他得到了一份数据可视化咨询的工作，并了解到自他入伍以来相关工具已经发生了变化。他使用了 `Tableau` 和 `Power BI` 工作，并学到了很多可视化知识。在参与一些数据科学项目之前，他还担任过其他技术职位，这真正激发了他的兴趣。他阅读了几本关于人工智能和数据科学的书籍，包括佩德罗·多明戈斯的《终极算法》，这本书启发他在该领域深入探索，并引领他走到了今天。

### 语录

**工作中最喜欢的部分：** 哈维总体上喜欢与人共事，因为人让工作变得有趣且有价值，往往甚至超过技术工作本身。他尤其喜欢与能让他学到东西的人共事。他发现，能向其学习的人并不总是职位更高的。

**工作中最不喜欢的部分：** 收集需求以及与不懂技术的利益相关者合作可能很困难，因为有时人们对可能实现的目标抱有不可实际的期望。有时他们并不愿意倾听关于什么可行、什么不可行的现实情况。

**最喜欢的项目：** 一个令人难忘的项目是客户留存系统。当客户表示要离开公司时，客服代表使用哈维参与开发的系统来判定该客户是否可以被挽留，并帮助确定提供哪种奖励来阻止其离开。项目最后运行了二十多个模型，其中几个是他从零开始创建的，其他运行中的模型也得到了他的更新。这个系统因留住客户而创造了数千万美元的收益。

**最常使用的技能：** 数据库编程、通用编程和可视化是显而易见的。但良好的数据直觉也很重要。例如，你应该能识别模型是否过拟合，或者理解某些发现实际上并无太大帮助（比如更多女性购买女性卫生用品这类发现）。数据侦探技能也很关键，基本上归结于提出好的“为什么”问题。领域知识和理解数据收集方式同样重要。最后，沟通能力至关重要。

**目前主要使用的工具：** `SQL`、`R`、`Python`、`Tableau`、`Power BI`

**数据科学的未来：** 哈维认为，对数据科学家的需求仍在增长，但借助人工智能工具，需求程度已不像本来会那么高了。人工智能正在帮助我们将数据科学的生产力提高 10%到 15%，但它无法完全取代数据科学家或软件工程师。

**优秀数据科学家的特质：** 求知欲、强大的人际交往能力、技术天赋、学习新技术的意愿以及灵活性是最重要的具体技能，但总体上的软技能至关重要。即使不了解算法背后的精确数学原理，理解算法如何工作也很重要。最后这一点与许多公司向非技术人员推广自助分析工具的趋势相关，因为这些用户往往对这些工具的工作原理缺乏基本理解，数据科学家可能需要进行指导。

**他对未来数据科学家的建议：** 咨询公司和小公司是获得经验的好途径。咨询工作能让你接触不同行业，所以即使你不想一直做下去，它也是很有价值的。此外，实习可能在毕业前甚至毕业后都值得去做，只是为了获得一些实际工作经验。阅读更多关于人工智能和数据科学的非虚构类通识书籍也很有益。一些经典著作包括佩德罗·多明戈斯的《终极算法》、布莱恩·克里斯汀的《对齐问题》、纳特·西尔弗的《信号与噪声》以及纳西姆·塔勒布的《黑天鹅》。这些书能让你对更广阔的数据科学世界有所了解——谁在使用它、如何使用它以及它能做什么。

*哈维是一位在多种技术角色和行业拥有丰富经验的数据科学家。*
