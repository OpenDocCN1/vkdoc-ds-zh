## 关于作者
`阿什温·帕扬卡尔` 在 `IIIT` 海得拉巴获得了计算机科学与工程硕士学位，拥有超过 25 年的编程经验。他七岁时便用一台 `MS-DOS` 电脑和 `BASIC` 编程语言开启了编程与电子学的旅程。如今，他精通汇编语言、`C`、`C++`、`Java`、`Shell` 脚本、`JavaScript`、`Go` 语言、`HTML` 以及 `Python` 等编程语言。他的其他技术专长包括 `Raspberry Pi` 和 `Banana Pro` 等单板计算机、`Arduino` 等微控制器板，以及 `BBC Micro Bit` 等嵌入式板。他在软件/产品测试、软件自动化、数据库、数据分析与可视化、计算机视觉以及 Web 开发等领域拥有丰富的实践经验。
