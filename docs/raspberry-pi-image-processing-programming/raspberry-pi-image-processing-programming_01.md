## 前言

我想让这篇前言保持简短、简洁且精准。我从事图像处理领域已有相当长的时间。我在15多年前初次接触`Python`。当我第一次使用树莓派进行图像处理时，我发现翻阅现有的印刷书籍、视频教程和在线教程有些繁琐，因为其中大多数缺乏为初学者提供循序渐进且全面的入门指南。那时我便决心写一本书，随后出版了本书的第一版。自第一版出版以来已近五年，它亟需大量更新。

本书是我努力与累积经验的结晶——这包含了数千小时（不包括实际撰写本书的时间）投入在查阅技术文档、观看培训视频、借助不同工具编写代码、调试有缺陷的代码片段、在线上各类问答和技术论坛发帖提问与参与讨论，以及参考各种代码仓库寻找方向上的付出。我撰写本书这一版本的方式，旨在让初学者能轻松理解各个主题。本书包含数百个代码示例和图片（代码执行结果截图），以便读者理解每个概念。

# 引言

所有代码示例均附有充分说明。

本书首先对树莓派和 Python 编程进行了总体介绍，随后探讨了与图像处理领域相关的概念，接着深入讲解了 `Pillow` 和 `TKinter` 库。接下来的几章重点介绍科学计算的 Python 生态系统，以及使用 `NumPy`、`SciPy` 和 `Matplotlib` 等库进行图像处理。最后一章讨论了如何使用 `OpenCV` 对实时摄像头视频流进行图像处理操作。附录部分简要介绍了可用于生成示例图片的 `pgmagik` 库，同时还包含大量高效使用树莓派板的技巧与诀窍。

最后要说的是，我们启动并完成这个项目正值一个非常动荡的时期（2022 年初），当时世界大部分地区正面临由导致新冠疫情的新型病毒变种所引发的又一波感染浪潮。我们身边的每个人仍在从疫情的影响中恢复。这本书给我带来了使命感。希望所有读者在阅读本书时，都能像我享受写作过程一样乐在其中。
