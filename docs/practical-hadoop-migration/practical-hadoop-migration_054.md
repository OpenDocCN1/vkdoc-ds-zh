# 报告周期

以下为本项目报告相关详情：

-   **项目启动**: 项目将在 SRO 和项目委员会批准本启动文件后正式启动。
-   **报告周期**:
    -   项目团队向项目经理报告 — 每周
    -   项目经理向 SRO 报告 — 每月
    -   SRO 向项目委员会报告 — 每季度
-   **决策点**: 关键决策必须在每个里程碑完成后做出。
-   若超出商定的容许偏差范围，项目经理将执行例外报告。
-   项目问题将记录在附录 B 的问题日志中。
-   在所有里程碑完成后，或在（可行性研究）被认为不可行并出具可行性研究报告后，项目将由 SRO 正式关闭。
