# 绘图工具及其他

它们提供的模板、形状或功能可能略有不同，但从概念上讲非常相似。

因此，绘图工具在绘制各种模型方面提供了更高的灵活性和速度，但就数据建模而言，它们无法与 CASE 工具提供的功能相媲美。通常，绘图工具无法做到：

-   逆向工程
-   正向工程
-   链接模型
-   传播变更（从一个模型到另一个模型）
-   使用主题域进行分类

CASE 工具和绘图工具各有优势，您的具体需求将决定哪种工具最适合您的环境。两者都提供了多种您可以利用的建模功能。

### 管理与监控应用程序

这些工具旨在协助管理物理数据库结构。

管理数据库系统通常涉及以下任务：创建和管理数据库及对象、用户和角色、空间使用情况、备份计划，以及执行数据库维护（例如重建索引、重新创建统计信息以及执行其他任务）。

监控数据库涉及设置自动化任务，用于监控进程、数据库连接和单个用户的资源使用情况，并在达到特定阈值时设置警报。在某些情况下，监控只是捕获感兴趣的指标并将其存储一段时间（一个月、一年等），以便访问历史使用情况并进行审计。

## 第 4 章：关系数据库管理系统设计与实现工具

#### 数据库管理或管理应用程序

大多数关系数据库都具有相似的结构（原因显而易见），这使得为它们设计通用图形用户界面变得容易。有几家公司已成功设计出能与所有主流关系数据库管理系统配合使用的界面。

大多数数据库管理界面都具有以下功能：

-   修改数据库服务器以及数据库和模式相关的配置
-   添加/修改/删除数据库对象，如表、视图、触发器和存储过程
-   添加/修改/删除登录名/用户/角色，并管理用户/角色的权限
-   管理磁盘空间分配，并收缩数据库以释放已分配但未使用的空间
-   执行数据库维护（重建索引或创建索引），包括备份
-   安排和管理数据库相关的任务/作业，并记录其结果/状态
-   管理数据库服务器的锁定/阻塞/死锁，并记录所有操作（例如，终止或死锁的会话）
-   配置 SMTP 或任何其他协议，供数据库服务器用于向配置的电子邮件地址或电话号码发送警报
-   监控复制和镜像环境以确保数据完整性
-   设置和配置访问、安全和加密功能

所有主流的关系数据库管理系统都有自己的数据库管理界面，但当您需要使用通用界面管理不同的关系数据库管理系统时，问题就出现了。

这时，由第三方或中立供应商开发的界面就派上了用场。

像 Redgate 或 Embarcadero (DBArtisan) 这样的公司已经开发了流行的工具，而像 EMS 这样的公司也开发了免费的多种数据库工具。
