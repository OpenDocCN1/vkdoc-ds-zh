# 致谢

这是我在 Apress 出版的第二本书（第一本是《实践 Hadoop 安全》），继续了《实践 Hadoop》系列。我要感谢 Apress 给我这个机会来撰写本书。我还要感谢 Hadoop 社区和用户论坛，是他们为这项技术带来了创新，并让世界对它保持兴趣！我从 Hadoop 社区中那些无私奉献、信奉“乐善好施”精神的人们身上学到了很多。

就个人而言，我想感谢我的朋友萨提亚·孔达帕利，他通过我们的 Meetup 小组 Ambaricloud 为我们提供了一个 Hadoop 爱好者论坛。我还要感谢我们的赞助商 Hortonworks 对我们的支持。最后，我要感谢我的朋友米林德·班达卡，他在百忙之中抽出时间为本书撰写前言，并提供了关于他全新“蝴蝶架构”的整个章节。

我很感激我的编辑们——Apress 的丽塔·费尔南多、罗伯特·哈钦森和马修·穆迪——在本书汇编过程中给予的帮助。丽塔全程陪伴，回答我所有的问题，改进我的草稿，并确保我按时完成。

罗伯特·哈钦森在本书结构方面的帮助价值巨大。我也非常感谢罗伯特·盖革抽出时间从技术上审校我的第二本书。鲍勃总是对如何改进主题、推荐更多细节以及当然还有解决技术缺陷方面提出极好的建议。

最后，没有我的家人（我的妻子斯瓦蒂，以及我的孩子阿尼什和丽雅）在过去三年里第二次给予的持续支持，这本书的撰写是不可能的，我期待着能和他们有更多的时间在一起。
