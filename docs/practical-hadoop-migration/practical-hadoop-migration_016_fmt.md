# 关于技术审校

**罗伯特·L·盖革**目前是 Ampool Inc. 的首席架构师兼工程副总裁，该公司是一家专注于大数据和分析基础设施领域的初创公司。加入 Ampool 之前，他在一家基于 B2B 深度学习的初创公司负责解决方案/SaaS 领域的架构和开发工作；在此之前，他在 Pivotal Inc. 担任架构师和团队负责人，致力于 Hadoop 生态系统的安全与分析即服务领域。在加入 Pivotal 之前，罗伯特在一家小型分布式数据库初创公司 TransLattice 担任开发者和工程副总裁。他还曾在赛门铁克公司从事安全领域工作数年，负责并领导分布式入侵检测系统团队。他的职业生涯始于伊利诺伊州的摩托罗拉实验室，在伊利诺伊大学香槟分校毕业后，他从事了基于无线系统的分布式 IP、密码学/安全以及电子商务等工作。
