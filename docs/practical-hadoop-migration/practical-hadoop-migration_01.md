# 前言

我们正处于信息技术（IT）领域最大的一次变革之中。快速变化的业务需求要求 IT 在各个方面都具备敏捷性。


随着越来越多的纸质业务流程走向数字化，快速应用开发、分阶段部署和上线已成为常态。此外，这些数字应用产生的数据“废气”变得极其庞大，需要实时进行分析。不断增长的历史数据量被认为对提升业务效率、识别未来趋势与颠覆性变化具有重要价值。无处不在的最终用户连接性、高性价比的软硬件传感器以及内容生产的民主化，导致了企业中数据洪流的产生。因此，传统的数据基础设施亟需改造。当然，这不可能一蹴而就。为了让您的 IT 部门满足业务的新需求，必须精心规划数据基础设施的重构，以确保在此过渡期间现有业务流程仍然可用。

过去十年间，`Hadoop`和`NoSQL`平台应运而生，以满足大型网络规模公司的业务需求。这些平台的能力正在迅速演变，因此在行业内引起了巨大的热潮。然而，这些平台中没有一个是能满足现代企业所有需求的万灵药。您需要仔细考虑各种业务用例，并确定哪个平台最适合每个特定的用例。为不合适的用例引入不成熟的平台，是数据基础设施项目失败的主要原因。当今的数据架构师需要理解各种数据平台，包括它们的设计目标、当前与未来的数据保护能力、访问方法、性能最佳点，以及它们在功能上与传统数据平台的对比。因此，传统的数据库管理员和业务分析师往往被数量庞大的新技术和快速变化的数据格局所淹没。

本书正是为这些读者而写。它透过表象，提供了一种向现代数据架构过渡的实用方法。尽管感觉上新技术每天都在涌现，但评估这些技术的关键在于，将您当前及未来的业务用例和需求，与这些新技术的设计核心对齐。本书帮助读者理解现代数据平台的各个方面，并帮助您驾驭新兴的数据架构。我相信，它将帮助您避免实施现代数据架构的复杂性，并为您的业务实现无缝过渡。

——米林德·班达卡博士  

Ampool 公司创始人兼首席执行官


# 关于作者

## 米林德·班达卡
**米林德·班达卡**曾是雅虎团队的创始成员，该团队将 Apache `Hadoop` 从拥有 20 个节点的原型发展为数据中心级的生产系统，他自版本 `0.1.0` 起便一直为 `Hadoop` 做出贡献并使用它。他创立了雅虎网格解决方案团队，专注于培训、咨询以及支持数百名 `Hadoop` 新用户。并行编程语言和范式是他过去 20 多年来的研究重点。他曾任职于高级计算发展中心 (C-DAC)、国家超级计算应用中心 (NCSA)、先进火箭模拟中心、Siebel Systems、Pathscale Inc.（已被 QLogic 收购）、雅虎以及领英。截至 2013 年，米林德担任 EMC 旗下部门 Greenplum Labs 的首席架构师。

最近，他担任 Pivotal Software 的首席科学家。米林德在伊利诺伊大学厄巴纳-香槟分校获得计算机科学博士学位。

## 布尚·拉克
**布尚·拉克**是一位大数据专家、技术布道者、作家和狂热的博主，居住在风城芝加哥。他于 1988 年从印度顶尖学府之一（比拉理工学院与科学中心，皮拉尼校区）毕业后，在印度最大的软件公司塔塔咨询服务公司开始了职业生涯。之后，他加入了英国计算机公司 ICL，并与知名的英国客户合作。1995 年，他移居芝加哥，先后在利奥·伯内特、蓝十字、摩托罗拉、摩根大通和英国石油等《财富》50 强公司担任顾问，经常扮演关键和开创性的角色。

在为 IBM 客户成功执行了七年的大数据以及数据仓库项目（并于 2012 年获得公司著名的格斯特纳奖）之后，拉克先生花费了两年时间帮助优利系统公司的客户实施大数据方案，随后两年担任益普索（世界第三大市场研究公司）的高级副总裁（信息和数据架构），负责设计全球数据架构和大数据战略。

目前，拉克先生领导 HCL America 的大数据业务部门，这是一家业务遍及 31 个国家、营收达 70 亿美元的全球咨询公司。在 HCL，拉克先生负责为《财富》500 强企业设计大数据解决方案架构。拉克先生活跃于芝加哥 Hadoop 社区，并共同组织了一个 Meetup 小组（[www.meetup.com/ambariCloud-Big-Data-Meetup/](http://www.meetup.com/ambariCloud-Big-Data-Meetup/)），定期在此谈论新的 Hadoop 技术和工具。您可以在领英上找到拉克先生：[www.linkedin.com/in/bhushanlakhe](http://www.linkedin.com/in/bhushanlakhe)。
