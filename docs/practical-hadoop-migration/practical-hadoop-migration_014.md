**前言**

我们正处于信息技术（IT）领域最大的一次变革之中。快速变化的业务需求要求 IT 在各个方面都具备敏捷性。

随着越来越多的纸质业务流程走向数字化，快速应用开发、分阶段部署和上线已成为常态。此外，这些数字应用产生的数据“废气”变得极其庞大，需要实时进行分析。不断增长的历史数据量被认为对提升业务效率、识别未来趋势与颠覆性变化具有重要价值。无处不在的最终用户连接性、高性价比的软硬件传感器以及内容生产的民主化，导致了企业中数据洪流的产生。因此，传统的数据基础设施亟需改造。当然，这不可能一蹴而就。为了让您的 IT 部门满足业务的新需求，必须精心规划数据基础设施的重构，以确保在此过渡期间现有业务流程仍然可用。

过去十年间，`Hadoop`和`NoSQL`平台应运而生，以满足大型网络规模公司的业务需求。这些平台的能力正在迅速演变，因此在行业内引起了巨大的热潮。然而，这些平台中没有一个是能满足现代企业所有需求的万灵药。您需要仔细考虑各种业务用例，并确定哪个平台最适合每个特定的用例。为不合适的用例引入不成熟的平台，是数据基础设施项目失败的主要原因。当今的数据架构师需要理解各种数据平台，包括它们的设计目标、当前与未来的数据保护能力、访问方法、性能最佳点，以及它们在功能上与传统数据平台的对比。因此，传统的数据库管理员和业务分析师往往被数量庞大的新技术和快速变化的数据格局所淹没。

本书正是为这些读者而写。它透过表象，提供了一种向现代数据架构过渡的实用方法。尽管感觉上新技术每天都在涌现，但评估这些技术的关键在于，将您当前及未来的业务用例和需求，与这些新技术的设计核心对齐。本书帮助读者理解现代数据平台的各个方面，并帮助您驾驭新兴的数据架构。我相信，它将帮助您避免实施现代数据架构的复杂性，并为您的业务实现无缝过渡。

——米林德·班达卡博士  
Ampool 公司创始人兼首席执行官
