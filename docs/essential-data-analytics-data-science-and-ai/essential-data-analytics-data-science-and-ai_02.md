# 你会学到什么？

本书将涵盖多个主题，以加深你对这些技术如何独立运作及协同工作的理解。我们将从探讨如何获取数据开始。数据是你最重要的工具，无论你正在构建的内容仅用于练习还是应用于现实场景。有些人会花钱购买数据，但也有免费获取数据的途径。有时，你可能会遇到必须自行创建数据的情况，这被称为合成数据生成。我也会展示如何实现这一方法。所有这些方法都各有利弊。

获取数据后，你需要经历一个称为 ETL 的过程。这是处理数据时必不可少的环节。ETL 代表提取（Extract）、转换（Transform）和加载（Load）。虽然有商业工具可以为你完成这些操作，但你也可以使用我之前提到的`Python`或`R`等工具自行构建这个管道。一旦将数据加载到你希望的任何目的地，你就应该探索并理解你所拥有的数据。数据领域的人将这一过程称为 EDA，即探索性数据分析。有商业工具可以帮助你完成这项工作。例如，你可能听说过`Tableau`！这是一个流行的工具，但对某些人来说可能成本高昂，因此也有免费的方法来实现这一目标。

接下来，在数据加载并清洗完毕后，就进入了某些人认为最有趣的阶段！向模型输入干净的数据至关重要。算法的优劣完全取决于训练它们所使用的数据。根据你要完成的任务，你可以使用不同的算法来创建模型。训练模型后，你需要对其进行评估。未经测试就部署模型，以确保它能按你的预期运行，是不可取的。评估模型有多种技术，但并非所有评估技术都适用于同一模型，也并非都是必要的。

从我之前提到的例子中你可以想象，人工智能可以存在于许多不同的地方。一旦你确定准备好部署模型，就需要决定它的“栖身之所”。它可以放置在云端，也可以放在你的手机、冰箱甚至汽车等设备上！模型放置的位置将决定其做出预测或决策的速度快慢。

为模型找到安身之处后，这并非终点。这永远不是终点！你必须持续维护你的模型，并保护它免受恶意攻击者的侵害。我们将讨论一些需要警惕的不同对抗性攻击。我们还将讨论如何通过一种称为遥测的方法来保持模型的最新状态。

需要注意的是，并非所有任务都需要使用人工智能。根据任务的不同，使用人工智能可能有些大材小用。你应该考虑成本、规模以及其他我将在后续章节讨论的因素。

最后，对于人工智能的力量存在着一种可以理解的恐惧。不幸的是，我认为人工智能不会消失，所以你应该拥抱它，并找到与之合作而非对抗的方法。当然，应当制定相关法律来限制其发展边界，以免我们都变成屈从于人工智能神祇的僵尸。然而，许多事情已经并将继续改变。这并不像人们想象的那么可怕。不，书呆子们不会毁灭我们所有人。让我们更多地了解它，看看如何利用它帮助我们在日常生活中成长，让我们的时间和日程安排更高效。

同样重要的是，数据分析、数据科学和人工智能领域正在快速发展。虽然本书可能未涵盖所有新的发展，但所讨论的基础原理将始终保持其相关性。即使技术和方法不断演变，这些核心概念仍将继续作为有价值的指南。
