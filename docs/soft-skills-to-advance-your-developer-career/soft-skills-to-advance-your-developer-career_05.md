# 排版后内容

我理解，关于谈判技巧的两个章节是任何职业类书籍中最受欢迎的话题。这是人类与生俱来的运作方式。我能听到这样的争论：“是的，Zsolt，这种心态理论很酷，但我首先得赚钱，然后才会关注另外两个层面。”问题在于，了解和钻研策略很容易，但运用这些策略却需要你承担责任并打好基础。

大多数速效解决方案就像《黑客帝国》里的红色药丸。你只需吞下它，就会看到真相。但这种药丸在现实生活中并不存在，除非你称之为“为提高自身能力承担责任”。大多数人失败是因为将责任外包给了外部权威。当你阅读我的书时，我可能就是你的这个权威，我能让你相信，你只需要一套话术和一系列行动就能为自己谈判到更高的薪水。我的一些读者会成功。另一些人则会心跳加速地执行这些步骤，过程中充满羞耻感和内疚感。

另一方面，如果你落实了前五章的所有改变，甚至没有阅读关于如何获得加薪或找新工作的内容，你大幅提高赚钱能力的机会有多大？对于我的许多读者来说，答案是肯定的。

我仍然强烈建议你阅读关于争取加薪和面试新职位这两个章节。无论你多么专业，总有一些内幕信息能提高你的成功率。你会在正确的时间发出兴趣信号，使用正确的薪资范围，并以正确的方式展示你的技能。你还会了解到，成功不需要什么，以及哪些流行的职业建议反而会降低你在谈判桌上的机会。

在大多数小节末尾，一些练习将挑战你将本书中的想法付诸行动。这些问题不仅能鼓励你思考自己的职业生涯，还能帮助你提升技能。

我希望你现在已准备好开始你的旅程。谁知道呢，你买这本书也许是为了谈成 20%的加薪。而这只是你前方转变的开始。

要开始这段通往精通的旅程，最好的方法莫过于积累几个快速的胜利。如果你能在接下来的章节中实践一些想法，你将在几天内取得可衡量的进步。

## 如何通过速赢建立势头

**本节目标：**

-   腾出一些时间来处理对您重要的事情。
-   变得更有条理，并向你的主管展示这一点。
-   制定学习计划，建立你的在线形象。
-   了解如何研究薪资范围、公司和面试问题。
-   利用你的研究写出顶尖的、不会被拒的求职材料。

如果你发现自己陷入了一个深坑，你需要有意识的努力，并忍受随之而来的痛苦期，才能爬出来。本节将让这段痛苦期变得尽可能简单直接。

### 注意

有毒的自助读物会描绘出一个完美的榜样形象，他拥有完全的掌控力和所有的机会。这些榜样常常将自己的成功归因于一个决定：要在巅峰状态表现、奋斗、努力、变得心智坚强并取得成就。这些榜样的追随者往往沉浸于这个梦想，并开始模仿他们的行为，却没有建立适当的体系。这导致了短暂的兴奋，代价是持续消耗意志力。随着意志力耗尽，曾经热情的追随者放弃成为他们梦想中的人，并安于舒适的生活。

那些鼓吹会走上“成就者之路”行动的大师、榜样、网红和名人们只忘记了一件事：对普通人日常现实的同理心。你只有先爬出自己所在的那个深坑，才能征服山顶上的城堡。试图在你的生活中制造重大改变，就像用弹弓从你的坑里朝城堡发射泥巴。最终，你在取得任何成就之前就会筋疲力尽。

第一步往往是最难迈出的。我大学时的一个同行布莱恩想启动一个个人项目，他问我如何在全职工作之外还有精力运营两个博客。我让他告诉我他一天的生活。

他通常在早上 5:30 左右起床，通勤 45 分钟去上班。如果他睡过头，由于早高峰，通勤时间会变成 1.5 小时。他通常在下午 5:00 下班，除非有紧急情况。过去两周，他通常晚上 8:00 才到家，因为下班后经常有些杂事。不过，正常情况下，他会在下午 6:00 到 8:00 之间到家。

“你什么时候睡觉？”我问他，同时注意到他看起来疲惫不堪。

“大约午夜。但晚上 8:00 到午夜这段时间，我几乎没什么精力做任何有效率的事情，”他补充道。

“你至少需要 7 个小时的睡眠，除非你用一些科学方法优化过睡眠。有些人需要 8 小时。难怪你晚上无法集中精力。”

“我知道，但我妻子通常早上 9:00 上班，她在午夜前睡不着。我也很难入睡。”

“你定期冥想或锻炼吗？”

“我每周跑步两次，每次半小时。但除此之外没有了。”

“周末呢？”

“有时我睡到 11 点，还是觉得累。周六还能做点工作，但周日我们要和家人一起安排一些活动。”

诊断结果很明确。布莱恩做出的生活选择不适合他，并且耗尽了他大部分的能量储备。等他到家时，他甚至无法集中注意力。

### 塑造你的环境

几个月后，布莱恩选择搬到了城里。由于他可以在几个月内终止租房协议，所以搬家对他来说并不难。这一改变让他可以在上午 9:00 开始工作，睡到早上 7:00 或 8:00，不再牺牲自己的睡眠时间。

在搬家之前，布莱恩申请了每月几天在家办公，并获得了批准。节省长途通勤的时间带来了回报。

就你而言，可能还有其他环境限制因素让你无法发挥最佳状态。找出它们，并相应地塑造你的环境。

他还找了一家健身房，并在一天中、午餐前安排了雷打不动的锻炼时间。为了恢复更多精力，布莱恩找到了独处时间，每天冥想 15 分钟。当其他人去抽根烟假装放松时，他清理了思绪，并通过冥想真正放松了下来。

对你来说，做出这些重大改变可能不太可能；因此，你可以寻找其他节省时间、获得更多精力的方法：在下一个行动项中，你会找到一个每天节省 1 小时的资源。

### 每天多出一小时，节省时间

作为软件开发人员，我们常常为时间所困。一天中总没有足够的时间去做所有你想做的事情！如果有一种方法可以“创造”时间呢？你愿意至少将其中一部分时间更愉快地投入到你的职业生涯中吗？你当然愿意。你可以尝试一些技巧来提高效率，从而有时间去做其他事情。关于如何在你生活中找回时间的技巧，请访问我的网站（`www.devcareermastery.com/onehouraday`），下载我的指南，并将这个速赢方法应用到你的生活中。

### 通过更有条理来增强责任感

责任感是大五人格特质之一，与职场成功呈正相关。



### 说明

大五人格特质，也称为 OCEAN 模型，包含开放性、尽责性、外向性、宜人性和神经质。文章[`https://positivepsychologyprogram.com/big-five-personality-theory/`](https://positivepsychologyprogram.com/big-five-personality-theory/) 详细解释了这一模型。

大多数软件开发人员都需要完成各种差事：编写应用程序、修复 Bug、在周三前部署更新、参加会议、引入架构变更、指导同事、或向董事会展示你的解决方案。有些任务很紧急，有些很重要，还有些既紧急又重要。请使用软件来跟踪你的任务。

有些人用简单的文本文件来记录待办事项清单。作为一名开发者，很容易发现这种本地记录的弊端：如果电脑关机且你没有频繁保存，数据就会丢失。此外，由于清单是单向度的，你的用户体验也不会是最佳的。我们需要一个持久的多维数据存储方案。

我可以推荐的一款免费软件是 Trello。^(⁴) Trello 的看板和卡片能帮助你组织一周的工作。假设有五个列分别对应本周接下来的五天，还有一个“已完成”列来存放你本周已完成的任务。设置一张 Trello 卡片只需一分钟。你可以添加标签来指示紧急性和重要性。按优先级排列你每日的任务。挑选一项任务，着手处理。完成后，将其放入“已完成”列。如果有人因请求打断你，你可以简单地创建一张新卡片，并根据紧急性和重要性将其插入到正确的位置。这样你就可以说：“我周四再回复你，可以吗？”如果到了周四，其他任务改变了你的优先级，Trello 会提醒你应该联系同事，重新安排他请求的任务。

过完一天后，你可以将该列移动到看板的右侧。下一周你可以重复使用这个列。作为一个小改动，你还可以在“已完成”列旁边添加一个“今日”列。例如，如果今天是周三，把所有卡片从周三列移动到今日列，然后将周三列拖到右侧。如果今天积压了太多事情，可以根据你的工作量重新安排并分配卡片。

请随意定制看板，使其契合你在岗位中的实际需求。例如，如果你需要提前规划超过一周的任务，可以在看板右侧添加一个“稍后”列。

你的条理程度不仅能为你自己节省时间，还能帮助你保存意志力，因为关于要做什么的决定会变得容易得多。你将避免因未跟进事务而产生的挫败感，而且与不做规划相比，你会显得更加专业。

完成任务能帮助你建立前进的势头。快速完成最重要的职责，并专注于余下时间而无需担忧任何事情，这在情感上是非常有益处的。有时你下午两点就完成了所有义务，这意味着你余下的时间就处于“自由发挥”状态。其他时候你可能会卡在某项任务上。但嘿，你卡在你最重要的任务上，那个你本应专注的任务上。所以你没有理由为此感到内疚。你只需要回顾剩余的任务，并重新安排你的待办事项清单。

除了 Trello，另一款很棒的软件是 KanbanFlow。^(⁵) 只要你是个人使用，它就是免费的。该应用内置了一个番茄钟跟踪器，因此你可以将其与“每天找回一小时”指南中提到的番茄工作法（`www.devcareermastery.com/onehouraday`）结合使用。

如果你在跟踪进度和养成习惯方面需要更多指导，Habitica^(⁶) 应用可以为你提供游戏化的体验，提醒你希望自己的生活是什么样子。通过合理设置在角色扮演游戏虚拟世界中可获得的奖励，Habitica 会提醒你日常事务中的各个元素。我测试过 Habitica 几周，但对我来说管理开销太大了。不过，如果你痴迷于在角色扮演游戏中升级，你可以假装在玩《辐射 4》的同时推进你的职业生涯。

有可能 Habitica、KanbanFlow 或 Trello 并不适合你，因为你更喜欢开销更低的解决方案。在这种情况下，我更建议你寻求更多专注，而不是微观管理。清晰即力量。对我来说，决定能否更好专注的首要因素，是我将任何一周所追求的目标数量限制在三个以内。只有当我完成了为自己设定的全部三个目标后，我才能添加更多目标。这样一来，我既不会因为设定过高目标而沮丧，也不会分心。我清楚每天该专注什么，并且有内在动力去推动处理手头最重要的任务。

我所做的只是将三个目标以纯文本格式发布在一个智囊团小组中，例如：

```
1. [x] 完成我的 JavaScript 视频课程的第三课。
2. [ ] 为 Puppet、Terraform 和 Bamboo 的网络研讨会创建幻灯片。
3. [ ] 完成我的纳税申报，并为我的会计师准备好所有需提交的材料。
```

注意这些目标的简洁性。它们是二元的。即使第二个目标中我需要交付三场网络研讨会，我也只有在全部完成时才能勾选。保持简单能让你专注。审视你的目标会引导你的大脑去问自己：“我现在可以做些什么来取得进展？”将目标限制为每周三个会引导你的大脑去问自己：“对我来说，哪一件事最重要，能带来最大的改变？”

### 说明

启动效应是指利用大脑的网状激活系统（RAS）来注意和解读事件，从而采取正确行动的过程。例如，请查看`https://tinyurl.com/career-priming`。

纳税申报是必须完成的，毋庸置疑。即使有会计师帮助我，我也必须亲自提交所需材料。除非我把它列为生活中的优先事项，否则很可能第一周完成 80%，第二周完成 90%，第三周完成 95%；而我会因持续切换上下文感到负担。将其设为优先事项则能消除这些上下文切换。

这同样适用于工作。你可能有季度目标。规划你的一周并计划你要做什么。当别人为你制定了一个计划时，看看你的清单，思考那个计划是否比你为自己设定的目标更重要。在这方面你可能需要经理的帮助，所以你可以简单地将经理纳入你的计划中。这引出了下一点...



### 向你的主管发送周报

现在，你的卡片已经放在了“已完成”列，在归档它们之前，不妨将这些信息用于另一个目的：向你的主管发送一份简洁、精炼的简短周报。

收集你本周的成果，并将其总结在一封电子邮件中，用几个要点写下你本周的贡献。

如果你有悬而未决的问题，也请将其包含在报告中。这将确保你能得到答复，并且让你的主管了解哪些事情正在阻碍你。

临近周末时，你的下几周对应的列中可能已经有了一些卡片。在“下周计划”这一章节下，用几个要点来总结它们。

这样一来，你的主管不仅能知道你本周完成了哪些工作以及遇到了哪些问题，还能准确了解你下周的工作量。如果你的工作优先级与业务需求不符，你的主管将有机会重新安排它们。

你认为这样的报告能改善你与主管的关系吗？我猜会的。如果你的主管对此类信息不感兴趣，这很可能是一个强烈的信号，表明你待错了公司。

请注意，过去有一些自由职业者向我汇报过。其中一些人选择每天发送一份包含他们成就、阻碍和问题的报告。我发现这份报告是了解我在该自由职业者身上的投入是否获得正向回报的最佳工具。

### 研究你的薪资

这本书是关于职业发展的。如果你想取得进展，就必须知道你的贡献价值几何。研究你当前的职位以及你的目标职位。

有两个进行薪资研究的绝佳资源：Glassdoor ( [`www.glassdoor.com`](http://www.glassdoor.com) ) 和 PayScale ( [`www.payscale.com`](http://www.payscale.com) )。

你不仅可以查看薪资范围，还可以看到人们为换取特定薪资而工作公司的评价。请注意，评价有时会有偏差。一个对公司完全满意的人，发表评价的可能性通常低于一个刚刚决定离职的人。满意的人倾向于客观看待事物；不满意的人则往往非常主观地看待事物。最后，人们的意见也受限于他们的认知。就某些公司而言，我读到过许多不公平的评价，这些评价完全基于对不良行为缺乏支持，而另一些公司则鼓励正面评价以提高其在吸引力方面的排名。

另一个有用的资源是 [`http://stackoverflow.com/jobs`](http://stackoverflow.com/jobs) ，它可以让你在你专业领域内寻找工作机会。通常，在 Stack Overflow 上，你会收到与你自己相关的职位邀请。有些招聘广告会注明薪资范围。你不仅能了解在你期望的国家或城市应该瞄准的薪资范围，还能了解你正在申请的公司期望值。LinkedIn Jobs ( [`www.linkedin.com/jobs/`](http://www.linkedin.com/jobs/) ) 也可能是一个有趣的职位来源。

只需一次谷歌搜索，你就能找到其他求职网站。可能有些网站专门针对你的城市或你的特定领域。

如果你目前的收入没有达到应有水平，不要灰心。专注于重要的事情，请放心，只要采取正确的行动，你的薪水会增加。

### 制定学习计划

在进行职位研究后，你可能已经收集了一些需要打磨的技能。如果你的目标是加薪或在当前组织中获得新职位，你也可以向同事和主管请教，了解什么能让你的团队更进一步。或者，如果你的目标是不同的团队，你也很容易就能发现他们在工作中使用了哪些技能。

仅仅阅读这些技能是远远不够的，因为你会立刻忘记 90% 的内容。做笔记会有些帮助，但你仍然会忘记很多东西。我鼓励你采用基于项目的学习方式。

创建一个有意义的副项目，该项目需要用到你想学习的技能。确保你的副项目不仅仅是一个没有实用性的模拟应用，而是你正在解决一个有意义的问题。

通过从事有意义的副项目，你不仅能声称自己拥有某项工作所需的技能，而且还能展示它们。迟早会有人因为合作机会而联系你。GitHub 上的开源仓库也可能吸引其他合作者，前提是你知道如何让世界知道你在开发什么，并且找到了一个乐于接受的社区。

不过要小心。我见过很多人构建的副项目几乎没什么意义。不要重复造轮子；要做一些独特的东西。例如，在 React、Angular 和 Vue 成为框架战争的赢家之前，每个人都想发明自己的框架。过了一段时间，社区开始对新框架持怀疑态度。

如果你没有时间和精力去创建一个副项目，我鼓励你写博客文章。如果你不想，甚至不必托管自己的博客。像 GitHub Pages 和 Medium 这样的服务可以托管你的博客。

撰写你正在学习的主题是在大脑中建立持久联系的好方法。额外的好处是，当你申请新职位时，可以展示你的副项目或博客。

### 重新审视你的简历

如果你想申请一份新工作，请查看职位描述。然后看看你的简历。这份工作所要求的技能和经验在你的简历中是否清晰可见？让它们突出显示！

是否有与你所申请职位几乎无关的技能、描述和资历？把它们从简历中删掉，或者精简！

你是否链接了与这份工作相关的作品集网站、副项目、博客文章和其他活动？如果没有，请重新审视。

你是否写得太多了？没有多少人会阅读一份长达十页的简历；让内容更紧凑。如果你想详细描述你的成就，我建议创建一个附件，在其中进行更详细的阐述。那些对你职业生涯细节感兴趣的人会阅读你的附件；不感兴趣的人也可能将此附件视为一个加分项。

你是在写你自己（职能视角），还是在写公司如何从你的服务中获益（效用视角）？我建议采用后者；思考你的目标公司想读什么。

你的简历是否足够好地反映了你的专业领域？如果没有，让它突出显示。

如果你的简历中包含了照片，请到 Photofeeler ( [`www.photofeeler.com/`](http://www.photofeeler.com/) ) 上进行测试。如果你的评分很差，不放头像比保留要好。或者，你也可以去照相馆拍一张更好的头像。
