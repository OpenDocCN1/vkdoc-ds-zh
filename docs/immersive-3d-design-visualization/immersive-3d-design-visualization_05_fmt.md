# 7. 光照贴图分析与校正

本章分析光照贴图及其重要性。首先，让我们为您在 UE4 中创建的场景应用一些占位材质。然后，转到“内容”文件夹 ➤ “初学者内容” ➤ “材质”，将 `M_AssetPlatform` 材质拖放到场景中的所有网格上（见图 7-1）。

## 光照贴图分析

现在您已准备好烘焙光照并查看效果。单击“构建”旁边的下拉箭头，然后选择“仅构建光照”（见图 7-2）。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig2_HTML.jpg](img/502922_1_En_7_Fig2_HTML.jpg)
图 7-2：仅构建光照

给它一点时间。光照构建可能需要一段时间，具体取决于您的设置。您可以转到“光照质量”，查看当前激活的是哪个质量级别（见图 7-3）。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig3_HTML.jpg](img/502922_1_En_7_Fig3_HTML.jpg)
图 7-3：设置光照质量级别

“预览”质量烘焙速度最快，但质量最低。“产品”模式烘焙所需时间最长，但光照质量最高。在这种情况下，您可以将光照质量设置为“中”或“预览”质量。烘焙完成后，您应该会看到类似于图 7-4 的结果。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig4_HTML.jpg](img/502922_1_En_7_Fig4_HTML.jpg)
图 7-4：光照构建结果

图 7-4 中的结果可能看起来略微发黄。您可以通过在“详细信息”面板中启用“温度”并将光照强度增加到较高的数值（本例中为 15）来产生类似的结果。然后，将温度值降低到 4000（见图 7-5）。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig5_HTML.jpg](img/502922_1_En_7_Fig5_HTML.jpg)
图 7-5：光照设置

现在让我们回到光照烘焙的结果。正如您所见，我们的烘焙存在许多问题，包括阴影分辨率低和过渡生硬。要解决这个问题，您需要创建光照贴图 UV。

在内容浏览器中双击 `Wall_Tall` 资源，打开显示该资源详细信息的窗口（见图 7-6）。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig6_HTML.jpg](img/502922_1_En_7_Fig6_HTML.jpg)
图 7-6：资源详细信息窗口

您可以单击 UV 下拉菜单查看网格中存在的 UV。UV 通道 0 是在 Maya 中创建的 UV 贴图。UV 通道 1 是 UE4 自动生成的光照贴图 UV（见图 7-7）。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig7_HTML.jpg](img/502922_1_En_7_Fig7_HTML.jpg)
图 7-7：查看 UV 通道

如图 7-8 所示，显示了 UE4 自动生成的光照贴图 UV。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig8_HTML.jpg](img/502922_1_En_7_Fig8_HTML.jpg)
图 7-8：光照贴图 UV

要自己生成一些光照贴图 UV，请向下滚动到“构建设置”，并设置“目标光照贴图索引”通道编号。在我们的例子中是通道 1，不过您可以选择任何您想要的通道，然后单击“应用更改”（见图 7-9）。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig9_HTML.jpg](img/502922_1_En_7_Fig9_HTML.jpg)
图 7-9：生成光照贴图

这将根据您创建的 UV 贴图生成新的光照贴图 UV。它使用一种有缺陷的算法，并非总能产生良好的结果，但有时您可以用它来为小而简单的资源创建光照贴图 UV。

一旦您点击“应用更改”，如果您输入的数字大于网格中可用通道的数量，则会创建一个新通道。新的光照贴图将被重新生成。

接下来，让我们增加光照贴图的分辨率，以存储更高分辨率的阴影信息和其他各种光照信息。为此，请向下滚动并在“常规设置”下找到“光照贴图分辨率”（见图 7-10）。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig10_HTML.jpg](img/502922_1_En_7_Fig10_HTML.jpg)
**图 7-10** 光照贴图分辨率

让我们将其增加到一个更高的值。始终牢记，此值必须是 2 的幂，即该值必须为 2、4、8、16、32、64、128、256、512、1024 或 2048 等。由于这面墙很大，我们将其增加到 1024。请记住，光照贴图值越高，消耗的内存就越多。不要在所有物体上都使用高分辨率光照贴图。

完成后，点击**保存**（见图 7-11）。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig11_HTML.jpg](img/502922_1_En_7_Fig11_HTML.jpg)
**图 7-11** 保存更改

完成此操作后，让我们重新烘焙灯光并查看结果。如图 7-12 所示，你编辑过的墙面已经有了显著改善。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig12_HTML.jpg](img/502922_1_En_7_Fig12_HTML.jpg)
**图 7-12** 编辑后的墙面在灯光烘焙后显示出更好的效果。

## 使用 `Lightmass Importance Volume`

在进行最终烘焙之前，让我们引入一个非常重要的体积，它告诉 UE4 在场景中应将灯光计算集中在何处。UE4 不会自动知道你是如何布置关卡的，以及你想把光照重点放在哪里。`Lightmass Importance Volume` 就起到了这个作用。在**放置 Actor** 面板中，点击**体积**，你会在列表中看到它（见图 7-13）。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig13_HTML.jpg](img/502922_1_En_7_Fig13_HTML.jpg)
**图 7-13** `Lightmass Importance Volume`

将 `Lightmass Importance Volume` 拖放到你的场景中。它一开始很小。使用**缩放**工具（快捷键 `R`）将其缩放到足够大，以完全包围整个场景并将其包含在自身内部（见图 7-14）。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig14_HTML.jpg](img/502922_1_En_7_Fig14_HTML.jpg)
**图 7-14** `Lightmass Importance Volume` 的边界，呈浅黄色。

## 消除烘焙错误

现在是时候调整灯光中的一些设置来消除烘焙错误了。转到菜单栏中的**窗口**选项卡，点击**世界场景设置**（见图 7-15）。这会在你的**细节**面板旁边打开一个**世界场景设置**面板。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig15_HTML.jpg](img/502922_1_En_7_Fig15_HTML.jpg)
**图 7-15** 世界场景设置

在**世界场景设置**面板中的**Lightmass**选项卡下，你需要更改一些设置（见图 7-16）。首先，将 `Static Lighting Level Scale` 降低到 0.4。然后，将 `Indirect Lighting Quality` 提高到 3.0。最后，将 `Num Indirect Lighting Bounces` 增加到 7。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig16_HTML.jpg](img/502922_1_En_7_Fig16_HTML.jpg)
**图 7-16** `Lightmass` 设置

接下来，将 `Num Sky Lighting Bounces` 增加到 5，`Indirect Lighting Smoothness` 增加到 1.2（见图 7-17）。

![../images/502922_1_En_7_Chapter/502922_1_En_7_Fig17_HTML.jpg](img/502922_1_En_7_Fig17_HTML.jpg)
**图 7-17** 更改更多 `Lightmass` 设置。
