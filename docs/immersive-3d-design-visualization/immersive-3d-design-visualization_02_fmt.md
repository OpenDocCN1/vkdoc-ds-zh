# 3. 3D 建模基础：资源
让我们从 Maya 的基础知识开始。在开始制作高级内容之前，扎实掌握建模技巧非常重要。Maya 是一款非常复杂的软件应用程序，如果您希望在工作时达到最高效率，您需要记住许多热键和快捷键。之后，我将介绍如何在 Maya 中进行资源与场景的粗模制作。

## Maya 基本控制
让我们从基本导航控制开始。按下 `Alt+鼠标左键` 旋转视口。按下 `Alt+鼠标中键` 平移视图。按下 `Alt+鼠标右键` 并拖动以缩放视图。或者，您也可以使用滚轮进行缩放。您从`透视图`开始。您可以通过按下并按住空格键打开`热盒菜单`来更改视图模式（见图 3-1）。这是一个包含了所有 Maya 工具和选项卡的紧凑菜单。

![../images/502922_1_En_3_Chapter/502922_1_En_3_Fig1_HTML.jpg](img/502922_1_En_3_Fig1_HTML.jpg)
图 3-1 热盒菜单

您可以使用`热盒菜单`在不同视图之间切换。要切换视图，请按下并按住空格键。将鼠标悬停在 `Maya` 选项上时 `左键单击`。会弹出一个饼状菜单，显示所有可用的视图模式（见图 3-2）。

![../images/502922_1_En_3_Chapter/502922_1_En_3_Fig2_HTML.jpg](img/502922_1_En_3_Fig2_HTML.jpg)

从饼状菜单中，您可以选择要切换到的视图。默认情况下，您在`透视图`中工作，但您可以轻松切换到其他视图。

接下来，让我们看看如何处理对象。单击`多边形建模选项卡`（见图 3-3）查看所有可以添加到视口中的标准基本体。

在编辑模式下，有一些快捷键可以打开提供各种功能和工具的菜单。
- `右键单击` 显示模式菜单，允许您切换编辑模式。
- `Shift+右键单击` 打开一个工具菜单，可以访问诸如 `插入循环边`、`多切割`、`合并`、`倒角` 和 `桥接` 等工具。（这些工具将在本书后面讨论。）
- `Ctrl+Shift+右键单击` 打开所选变换工具的上下文菜单。（变换工具是移动、旋转和缩放）。
- 如果您选择了一个循环边，您可以向任何方向滑动它。按下 `Shift+Ctrl` 并使用操纵器来滑动选中的边/边。
- 选择一条边或一个顶点，然后按下 `Shift` 键，即可选择将选中的边/面向您选择的方向挤出。

我还可以讨论更多，但边工作边学习新的快捷键和技巧效果更好。不过在继续之前，请确保您已经练习了所讨论的所有快捷键和热键。

现在让我们开始创建一个简单的头戴设备。

## 构建基础模型
让我们开始构建基础模型。构建基础模型是确定资源外观的重要环节。通过基础模型，你可以自由灵活地试验想法，并决定哪些符合需求、哪些不符合。由于基础模型的几何形状非常简单，可以轻松修改，以验证不同方案的可行性。

首先，点击`多边形建模`选项卡下的圆柱体图标来创建一个圆柱体。你需要确保其拥有足够的边数。你可以在`通道`面板（快捷键`Ctrl+A`）中设置基础体的参数（见图 3-5）。

![../images/502922_1_En_3_Chapter/502922_1_En_3_Fig5_HTML.jpg](img/502922_1_En_3_Fig5_HTML.jpg)
图 3-5 修改参数

`通道`面板提供了 3D 模型的基本参数，你可以通过编辑这些参数进行常规修改。每个轴都有`平移`、`旋转`和`缩放`选项。

让我们为圆柱体添加`28`个细分。这能让它更平滑，并提供更多可操作的边。现在，按`R`键，使用操纵器将圆柱体在`Y`轴上缩放至约`0.2`，如图 3-6 所示。

![../images/502922_1_En_3_Chapter/502922_1_En_3_Fig7_HTML.jpg](img/502922_1_En_3_Fig7_HTML.jpg)

然后在面模式下选中顶盖和底盖并将其删除，如图 3-8 所示。

![../images/502922_1_En_3_Chapter/502922_1_En_3_Fig8_HTML.jpg](img/502922_1_En_3_Fig8_HTML.jpg)

![../images/502922_1_En_3_Chapter/502922_1_En_3_Fig9_HTML.jpg](img/502922_1_En_3_Fig9_HTML.jpg)

选中形状的最后两条边，并确保`移动`操纵器处于激活状态（按`W`键激活）。然后按住`Shift`键，将鼠标悬停在一个操纵器上。你应该会看到`挤出`字样出现，这意味着使用操纵器平移选中的边时，会将边挤出。使用`挤出`功能，将边向后挤出，如图 3-10 所示。

如果不小心，或者对单个基础体多次使用挤出，`挤出`可能会产生不需要的几何体。为了检查，选中任意一条边并移动它，观察是否出现多余的面。如果发现有多余的面与预期面重叠，应选中这些不需要的几何体并按`Backspace`键将其删除。

### 添加对称
现在让我们为对象启用`对称`功能。对称是一个强大的工具，因为当你编辑网格的一侧时，它会将操作复制到另一侧。你无需手动编辑网格的两侧。要启用`对称`功能，右键单击并从饼状菜单中选择`对象模式`。然后按`Ctrl+Shift+右键`打开`工具`菜单。`对称`是顶部的选项（见图 3-11）。

![../images/502922_1_En_3_Chapter/502922_1_En_3_Fig11_HTML.jpg](img/502922_1_En_3_Fig11_HTML.jpg)
图 3-11 对称选项

将鼠标悬停在`对称`上可以显示更多选项。

`对称`选项旁边有一个复选框。默认情况下，它是未选中的（见图 3-12）。将鼠标悬停在其上，选中它，然后右键单击以切换为开启状态。用同样的方法可以将其关闭。

![../images/502922_1_En_3_Chapter/502922_1_En_3_Fig12_HTML.jpg](img/502922_1_En_3_Fig12_HTML.jpg)
图 3-12 切换对称开启

启用后，你就可以开始编辑模型了。你会看到，你对网格一侧所做的任何编辑都会自动复制到另一侧。

## 使用 UE4 进行交互式可视化

### `Level Editor`

`Level Editor` 是 UE4 的核心编辑器。它允许用户管理和编辑关卡。关卡通过将 `Actor` 放置并编辑到场景中来创建和编辑。这些 `Actor` 定义了玩家在与该关卡及其 `Actor` 交互时将体验到的内容。若要打开 `Level Editor`，请导航至 `Window` ➤ `Levels`（见图 4-10）。

![../images/502922_1_En_4_Chapter/502922_1_En_4_Fig10_HTML.jpg](img/_HTML.jpg)

*图 4-10：打开 `Levels` 面板*

一旦打开`Levels`面板，你将看到如图 4-11 所示的窗口。

![../images/502922_1_En_4_Chapter/502922_1_En_4_Fig11_HTML.jpg](img/_HTML.jpg)

*图 4-11：`Levels` 窗口*

`Levels`面板显示场景中所有存在的关卡。目前，默认的示例关卡是打开的。你可以看到这个窗口被命名为`Persistent Level`。你可以通过点击其名称前的睁眼图标来禁用此关卡（见图 4-12）。

![../images/502922_1_En_4_Chapter/502922_1_En_4_Fig12_HTML.jpg](img/_HTML.jpg)

*图 4-12：关卡可见性切换*

一旦你禁用一个关卡，场景中的所有内容都会消失。这表明你场景中的每一个`Actor`都是一个关卡的一部分。通过编辑这些`Actor`，你可以修改该关卡。你可以通过点击窗口右下角的铅笔图标来保存更改（见图 4-13）。

![../images/502922_1_En_4_Chapter/502922_1_En_4_Fig13_HTML.jpg](img/_HTML.jpg)

*图 4-13：保存关卡更改*

### Output Log

`Output Log`面板是一个开发者工具，用于显示与后台发生情况相关的调试消息和错误消息。错误消息会被记录在此，这提供了有关错误原因的宝贵信息，以便你进行调查和修复问题。若要打开输出日志，请导航至 `Windows` ➤ `Developer Tools` ➤ `Output Log`（见图 4-14）。
