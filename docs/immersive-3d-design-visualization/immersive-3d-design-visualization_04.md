# 6. 创建 UV

在本章中，你将学习如何展开你的资源并为纹理贴图做好准备。展开是 3D 资源创建中至关重要的一步。在展开过程中，你将以 3D 格式布局 3D 模型的表面，以便在其上进行绘制、应用位图纹理或程序化纹理。如果不进行展开，通常无法正确地为资源贴图。

展开时，你需要尽可能保持 UV 岛平坦，以减少对应用纹理造成的扭曲。你还应尽可能保持 UV 岛均匀并接近其原始大小，以确保不会将过多的 UV 空间分配给微小的资源。同样，确保给较大的资源尽可能多的 UV 空间。
