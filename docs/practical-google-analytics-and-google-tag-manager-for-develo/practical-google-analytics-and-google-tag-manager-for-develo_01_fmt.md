
## 前言

很久很久以前，一些聪明人意识到，从集中地点分配水资源可以提供更好的控制并提高效率。这就是灌溉的开端，一种将水引向植物更有序、更有效的方式。

时间快进数千年，另一些聪明人发明了更先进的方法，灌溉全球数亿英亩的土地。假设你拥有一个种植多种作物的农场：咖啡（当然！）、玉米和大豆——每种作物需要不同的水量和不同的肥料量。没有灌溉，就不可能及时、有效地为你的作物创建并维持这两种（以及其他）必需资源的恒定、精确的输送。

你现在可能正在问自己：这家伙在说什么？嗯，就像灌溉用于向多种作物输送资源一样，`Google Tag Manager` (`GTM`) 用于快速有效地向不同页面输送不同的标签。因此，在我们的场景中，不是作物，而是页面；不是资源，而是标签；两者都有规则来定义每种情况下该做什么。

就像灌溉使农民能够以更具可扩展性的方式管理其资源一样，`Google Tag Manager` 也为开发者提供了同样的能力。`GTM` 是一个强大的工具，使来自不同部门和地点的多位专业人士能够协同工作，创建并部署针对数字挑战（如敏捷性和性能）的解决方案。

这并不是说所有问题都会消失，或者三步之内你就能称霸网络；不，`GTM` 不是 Asterix 的神奇药水。正如你将在这本书中学到的，创建一个强大的 `GTM` 实现需要纪律和努力，但你也会学到，这份努力将带来数倍的回

正如乔纳森和 LunaMetrics 团队在接下来的章节中准确而全面地描述的那样，你可以利用 `Google Tag Manager` 创造奇迹，无论是实现 `Google Analytics` 还是进行其他类型的数据收集。

现在，翻过这一页，开始动手吧！

丹尼尔·韦斯伯格

## 引言

### 本书的目标读者是谁？

> “一本书要是没有图画和对话，那还有什么意思呢？”——刘易斯·卡罗尔，《爱丽丝梦游仙境》

`Google Analytics` 被应用于数以百万计的网站，用于衡量和理解用户行为。但对许多网站而言，`Google Analytics` 的实施流程通常是这样的：注册一个帐户，按照简单说明将跟踪代码粘贴到网站模板中，然后在报表中查看网站数据。

这当然比完全没有数据要好！但如果你的规划仅止于此，就会错失 `Google Analytics` (`GA`) 许多最强大的功能：那些能根据你的组织、网站和受众来定制数据的功能。本书将向你展示如何衡量特殊交互、转化以及其他类型的数据，从而获得具有实际影响力的报告和分析。

进一步实施中的障碍之一，可能是在网站页面上部署和测试跟踪代码标签所需的 IT 资源，以便实现更多测量功能。`Google Tag Manager` (`GTM`) 通过一个基于网页的工具来管理和部署这些标签，帮助你克服这一障碍。

`GA` 和 `GTM` 就像花生酱和果酱一样相得益彰。当然，即使没有 `GTM`，你也可以完成本书中的所有内容，但 `GTM` 能让整个过程更加精简且易于测试，因此强烈建议在所有 `GA` 实施中使用它。在本书中，`GTM` 将随 `GA` 功能一同介绍，你将学习如何使用 `GTM` 来实施它们。

### 我需要是开发者吗？

书名写着“面向开发者”，但这到底意味着什么呢？

网络分析，就其本质而言，是衡量网页的。`GA` 和 `GTM` 使用 `JavaScript` 代码来进行这种衡量。因此，你应该熟悉让网页在浏览器中运行的基本技术：`HTML`、`CSS` 和 `JavaScript`。

但是，你是否需要能够面对空白屏幕从头开始编写一个功能完备的网站呢？当然不需要。你的大部分工作只是在现有功能正常的页面上，这里那里添加几行代码，以便测量该页面的某些元素。如果你的职位是“开发者”，那自然毫无问题；但如果你从事市场营销、内容创作或其他角色，只要具备一些基本的 `HTML` 技能，就应该能够跟上本书的节奏并实施其中的示例。

### 我应该如何阅读本书？

特别是如果你刚开始接触 `GA` 和 `GTM`，第一部分：使用 `Google Tag Manager` 实施 `Google Analytics` 涵盖了你在实施过程中需要了解的基础知识，以及如何建立网站测量的基础架构，还包括部署和测试的流程。即使你已有现成的实施，第一部分也可能提供良好的基础复习，特别是第 3 章和第 4 章，如果你刚接触 `GTM` 的话。

第二部分：使用 `Google Tag Manager` 增强网站数据 涵盖了你想从网站发送到 `GA` 的各种额外数据类型，而第三部分：从其他来源收集数据 则提供了从移动应用、后端系统等发送 `GA` 数据的信息。第二部分和第三部分的各章是对扩展和增强你的实施所涉及的主题的集合，你可以按任意顺序阅读。挑选出对你最有价值或最优先的主题，优先处理它们。第 5 章 是一个不错的起点，因为它涵盖了 `GA` 中最常见的一些额外跟踪类型，以及在 `GA` 和 `GTM` 中实施的一般方法。之后，你可以根据自己的兴趣或需求随意跳着读。

额外章节：将 `GA` 与 `BigQuery` 结合用于大数据分析 概述了获取 `GA` 数据的最新方式——通过谷歌的 `BigQuery` 服务，从而能够对你的网站数据进行深入的统计分析和数据挖掘技术。附录 则概述了用于设置和报告数据的 `GA` 和 `GTM` API。
