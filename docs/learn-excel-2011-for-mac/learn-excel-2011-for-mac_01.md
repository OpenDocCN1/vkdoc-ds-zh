使用 Excel 2011 for Mac 掌控数据管理、分析与自动化

上手 Microsoft Excel 2011 for Mac 并不难，但要想充分发挥 Excel 的潜力，你需要深入钻研。*学习 Excel 2011 for Mac* 提供了一种实践性、动手操作的方法，教你如何快速高效地完成工作。从使用公式和函数到创建数据库，从分析数据到自动化任务，你将学到充分利用这款强大的应用软件执行各类商务任务所需的一切知识。

你将发现如何掌握并利用 Excel:Mac 界面的秘诀，按自己的方式定制 Excel，并充分利用 Excel 数百个内置函数的强大功能。你将能够将原始数据转化为有力且富有说服力的图表，甚至还会探索如何与使用 Windows 的同事共享工作簿。

**你将学到如何：**

-   创建工作簿和模板，为你和同事节省时间和精力
-   快速一致地格式化工作表
-   使用 SmartArt、图片等让你的工作表脱颖而出
-   通过假设分析、单变量求解和规划求解快速解决业务问题
-   使用表格存储和筛选数据，并使用数据透视表分析数据
-   通过 VBA 自动化任务来简化工作流程
