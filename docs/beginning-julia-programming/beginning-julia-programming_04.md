# 2. 面向对象编程

## 2.1 引言

Julia 被设计成一种面向对象编程（OOP）语言。这一选择源于 OOP 语言在计算领域的巨大成功。在 OOP 中定义计算问题的便捷性使其成为一种著名的计算范式；因此，Julia 也采用了 OOP。要学习 Julia，了解 OOP 是前提条件。本章专门为此目的而设。

## 2.2 过程式编程 vs. 面向对象编程

定义计算任务时，你可以定义一套固定的程序，通过数据块并根据过程的要求将它们连接起来，以解决问题。这种强调设定过程，而不考虑数据类型及其不同使用模式的范式，被称为过程式编程。另一方面，OOP 则强调对象以及它们之间通过运算符建立的关系（运算符作用于对象，改变它们的值和其他属性以解决计算任务）。C++、Java 和 Python 都是 OOP 语言，Julia 也是如此。

## 2.3 OOP 的思想

对象的概念源于对我们日常生活的观察。对象被理解为具有一组属性和一组相关行为的事物。这正是人类婴儿最初认识环境的方式。例如，婴儿会学到球（对象）有颜色、形状和大小（属性），并且它会滚动、打滑和弹跳（行为）。

20 世纪 70 年代初，施乐帕克研究中心（PARC）的艾伦·凯致力于 OOP 概念的研究 [1]。在研究名为 Smalltalk [2] 的编程语言时，他运用了 OOP 的思想。关键思想是基于将计算机编程应用于物理模拟。现实世界可以被想象成各种对象（具有属性和行为）相互作用。因此，在构建模拟世界时采用相同的想法是很自然的。所有基于 GUI 的系统都继承了凯在这些想法上的努力成果，如今所有主流编程语言都严格遵循这些理念。

## 2.4 对象

在 Julia 的世界里，一切都是对象。但什么是对象呢？对象是一个抽象概念，用来表示可以执行计算的实体。就像一个物理对象一样，计算机中的对象也有一组属性和一组相关行为。数字、字符串、图片、视频、文件等都可以被视为对象。在数字中，你可以将对象进一步细分为整数、浮点数和布尔数等子类，或者它们的有序或无序集合。在字符串中，你可以有字符、单词、句子等等。在文件中，可以有文本文件、媒体文件、数据文件、脚本文件等。

## 2.5 对象的类型

每个对象都有一个关联的类型。类型决定了内存存储需求以及可以对对象进行何种计算操作。例如，`int` 和 `float` 是不同类型的对象，`int` 存储整数，而 `float` 存储浮点数。这些类型将在后续章节中详细讨论。`float` 需要存储关于小数点前和小数点后数字位数的信息，而 `int` 对象则无需关心这些信息。类似地，复数存储在另一种对象类型中，恰当地命名为 `complex`，因为它需要存储复数的两个部分（即实部和虚部）。因此，它们在计算机内存中的存储方式必然大相径庭，并在后续计算中以非常不同的方式被使用。创建对象时必须声明其类型。除非明确指定，Julia 会动态分配类型。对象的类型可以通过内置函数 `typeof()` 获取，该函数接受需要扫描类型的对象。

让我们通过一个例子来测试这个概念。尽管对象的值在数值上都是 1，但它们分别被存储为整数、浮点数和字符：

```
julia> a = 1

julia> b = 1.0
1.0
julia> c = '1'
'1': ASCII/Unicode U+0031
（类别 Nd: 数字，十进制数字）
julia> typeof(a) # 64 位整数对象
Int64
julia> typeof(b) # 64 位浮点数对象
Float64
julia> typeof(c) # 字符对象
Char
```

整数对象与浮点对象和字符串截然不同。某些函数会明确要求特定类型的对象。在这些情况下，需要将它们相互转换。有时转换会很麻烦，偶尔甚至无法完成。有关转换问题的详细信息将在第 3 章中借助数字对象进行概述。

## 2.6 对象引用

Julia 中的对象被表示为对计算机内存中某个对象的引用。“A”指向一个内存位置。这个内存位置可以通过内置函数 `pointer_from_objref(x)` 访问，其中 `x` 是对该对象的引用。类似地，可以通过函数 `sizeof(x)` 获取内存的字节大小。我们可以通过之前使用过的代码来理解这一点：

```
julia> a = 1 # a 引用一个 Int64 类型的整数对象

julia> b = 1.0 # b 引用一个 Float64 类型的浮点数对象
1.0
julia> c = '1' # c 引用一个 Char 类型的对象
'1': ASCII/Unicode U+0031
（类别 Nd: 数字，十进制数字）
julia> typeof(a)
Int64
julia> typeof(b)
Float64
julia> typeof(c)
Char
julia> pointer_from_objref(a) # a 的内存地址
Ptr{Void} @0x000000011b8240a0
julia> pointer_from_objref(b) # b 的内存地址
Ptr{Void} @0x0000000120804e30
julia> pointer_from_objref(c) # c 的内存地址
Ptr{Void} @0x0000000120a672e0
julia> sizeof(a) # a 占用 8 字节（Int64）

julia> sizeof(b) # b 占用 8 字节（Int64）

julia> sizeof(c) # c 占用 4 字节（Char）

```

命令 `whos()` 会显示机器内存消耗的详细状态。例如，在编写本文时，我机器的状态显示如下：

```
julia> whos()
Base  34434 KB     Module
Core  12485 KB     Module
Main  41112 KB     Module
a         8 bytes  Int64
ans       4 bytes  Char
b         8 bytes  Float64
c         4 bytes  Char
```

机器的状态清楚地表明，除了 `Base`、`Core` 和 `Main` 模块之外，当前命名空间（或者简单来说，工作环境）中创建了四个引用：

*   `a`（对象的 `Int64` 数据类型占用 8 字节）
*   `b`（对象的 `Float64` 数据类型占用 8 字节）
*   `c`（对象的 `Char` 数据类型占用 4 字节）
*   `ans`（对象的 `Char` 数据类型占用 4 字节）
    *   `ans` 是自动创建的，引用 Julia 提示符下最后使用的对象。



## 2.7 变量

变量是与一个值相关联（或绑定）的名称，即对存储在内存位置中的数据的引用。数据被视为对象；变量引用或指向该对象。当代码运行时，对象的值可以被改变——因此得名“变量”。（换句话说，该对象能够在不同时间点存储不同的值。）例如，在以下代码中，名为 `a` 的变量可以存储一个整数，然后是另一个整数，接着是一个浮点数，一个字符串，最后是一个有理数。因此，`a` 的值可以是可变的。

```
julia> a = 1 # 'a' 指向值为 1 的整数对象

julia> a = 2 # 现在 'a' 指向一个新的整数对象
### 值为 2

julia> a = 3.4 # 现在 'a' 指向一个新的浮点数
### 对象，值为 3.4
3.4

julia> a = "hi" # 现在 'a' 指向一个字符串
### 值为 "hi"
"hi"

julia> a = 1//2 # 现在 'a' 指向一个有理数
### 1/2
1//2
```

### 2.7.1 变量命名

变量名是区分大小写的，并且在 Julia 中没有任何语义含义。因此，关键字不能用作变量名。Julia 提供了一个极其灵活的变量命名系统。甚至允许使用 Unicode 字符作为变量名。在 Julia REPL 和其他几个 Julia 编辑环境中，可以通过输入对应的 LaTeX 命令然后按 Tab 键来调用 Unicode 字符。例如，要给变量命名为 `α`，你需要输入 `\alpha`，然后按 Tab 键就会看到 `α` 作为变量名。

关于变量名有一些规则：

-   变量名必须以字母（A–Z 或 a–z）、下划线或大于 `00A0` 的 Unicode 码点子集开头。
-   后续字符可以包括特殊字符（例如，`&`、`@`、`%`、`ˆ`、`#` 等）和数字（0–9）或其他 Unicode 字符。
-   关键字不允许用于变量命名。

### 2.7.2 命名风格约定

为了保持一致性，Julia 提出了一种命名风格约定（这是建议性的，并非强制性的）。风格约定的主要方面如下：

-   变量名使用小写字母书写。
-   单词分隔可以用下划线（`_`）表示，但不鼓励使用下划线，除非名称在不用下划线时难以阅读。
-   类型和模块的名称以大写字母开头，单词分隔使用大写字母而不是下划线表示。
-   函数和宏的名称是小写的，不带下划线。
-   对其参数进行写入的函数，其名称以 `!` 结尾。这些函数有时被称为“更改”或“原地”函数，因为它们旨在调用函数后更改其参数，而不仅仅是返回一个值。

## 2.8 总结

在本章中，我们讨论了面向对象编程的基本范式，以及 Julia 如何真正证明其作为面向对象编程候选者的作用。处理对象使得任务模块化，因为计算的灵活性赋予了开发者自由，能够以多种方式探索计算任务的维度。不同的物理系统可以轻松模拟，因为您只需定义一个合适的计算对象，并将其属性声明为相关的函数（称为方法）。对象可以通过变量名来引用，并且通过引用调用可以轻松地更改值。
