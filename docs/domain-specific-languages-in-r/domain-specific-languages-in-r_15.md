# 13. 结语

将领域特定语言嵌入到 R 中，通过提供灵活的方式来构建数据结构或处理数据，从而丰富了这门语言。在本书中，我们学习了如何使用运算符重载、元编程和非标准求值等技术来实现小型领域特定语言。通过示例，我们探讨了针对不同问题的几种语言设计。

R 语言的灵活性——无论是我们如何重写运算符和函数、特化泛型函数，还是在表达式求值方面的灵活性——使得领域特定语言成为设计包接口的一种自然方法。广受欢迎的 tidyverse 系列包在很大程度上利用了这一点。`ggplot2`包使用加号运算符在“图形语法”中组合图形命令。`magrittr`管道运算符`%>%`被用于在`dplyr`和`tidyr`等包中创建转换动词序列。tidyverse 包还利用非标准求值，用数据框列对表达式进行作用域外扩。从 tidyverse 的流行程度可以明显看出，使用精心设计的领域特定语言可以显著提高编程人员的工作效率。这是因为它相比更传统的分析框架接口，在可读性和灵活性方面都有所提升。

这里的关键词是“精心设计”。当我们实现一个领域特定语言时，我们要求用户能够比使用更传统的接口更高效地使用该语言，而不是依赖标准的 R 语法。只有当你设计的语言在组件组合方式以及它如何与外围 R 代码交互方面保持一致时，这种情况才会成立。

设计一门语言需要一些反复试验。当然，随着经验的积累，你会减少错误的数量，但通过尝试用不同方式表达相同想法，你总能从中获益。正是通过实验，你才能学会语言的不同组件如何组合起来表达思想。设计一个新的领域特定语言的一个好方法是考虑各种用例，并写下你理想中希望如何用新语言来表达你想要实现的计算。你此时还无需实现任何语言结构；只需尝试以不同方式写下表达式即可。

一旦你对语言理想的外观感到满意，就可以开始考虑如何实现它了。可能无法完全按照设计阶段提出的语法来实现该语言。由于你是将语言嵌入到 R 中，该语言的表达式也必须是有效的 R 代码。这在一定程度上限制了你能做什么。但从理想设计出发，你可以修改你的用例，直到这些示例在你的语言和 R 中都是有效的表达式，然后，你就可以运用本书中学到的技术来实现你的语言了。

祝你好运。
