## 总结

本章介绍了使用 `Python` 和 `SymPy` 库进行计算机辅助符号计算。虽然解析技术和数值技术通常被分开考虑，但事实上，解析方法支撑着一切计算，并且在算法和数值方法的开发中至关重要。无论是通过手工还是使用 `SymPy` 这样的计算机代数系统进行解析数学运算，它都是计算工作的重要工具。因此，我所鼓励的方法是：解析方法和数值方法紧密交织，值得在开始分析计算问题时先采用解析和符号方法。当这些方法变得不可行时，再转向数值方法。然而，如果在对问题进行解析分析之前就直接应用数值方法，很可能最终解决的问题会比实际需要的更为复杂。
