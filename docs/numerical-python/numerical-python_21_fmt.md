# 14. 统计建模

在上一章中，我们介绍了基本的统计概念和方法。在本章中，我们将以前一章奠定的基础为起点，探索统计建模，它涉及创建试图解释数据的模型。一个模型可以有一个或多个参数，我们可以使用拟合过程来找到最能解释观测数据的参数值。一旦模型拟合到数据上，就可以根据模型的自变量值来预测新观测值。我们还可以对数据和拟合的模型进行统计分析，并尝试回答一些问题，例如模型是否准确地解释了数据、模型中的哪些因素比其他因素更相关（更具预测性），以及是否存在对模型预测能力贡献不显著的参数。

在本章中，我们主要使用 `statsmodels` 库。它提供了用于定义统计模型并将其拟合到观测数据、计算描述性统计量以及执行统计检验的类和函数。`statsmodels` 库与我们在上一章中介绍的 SciPy `stats` 模块有一些重叠，但它主要是对 SciPy 功能的扩展^(⁵⁹)。特别是，`statsmodels` 库的主要重点是将模型拟合到数据上，而不是概率分布和随机变量，对于后者，它在许多情况下依赖于 SciPy `stats`。

### statsmodels

`statsmodels` 库提供了与统计检验和统计建模相关的丰富功能，包括线性回归、逻辑回归和时间序列分析。有关该项目及其文档的更多信息，请访问项目网页 [`http://statsmodels.sourceforge.net`](http://statsmodels.sourceforge.net) 。在撰写本文时，`statsmodels` 的最新版本是 0.9.0。

`statsmodels` 库与 `patsy` 库紧密集成，后者允许我们使用简单的公式来编写统计模型。`patsy` 库是 `statsmodels` 库的依赖项之一，但也可以与其他统计库一起使用，例如将在第 15 章讨论的 `scikit-learn`。不过，在此我们将介绍 `patsy` 库如何与 `statsmodels` 库一起使用。

### patsy

`patsy` 库提供了一种功能，可以使用受 R 等统计软件启发的简单公式语言来定义统计模型。`patsy` 库被设计为 `statsmodels` 等统计建模包的配套库。有关该项目及其文档的更多信息，请访问网页 [`http://patsy.readthedocs.org`](http://patsy.readthedocs.org) 。在撰写本文时，`patsy` 的最新版本是 0.5.0。

## 统计建模简介

在本章中，我们考虑以下类型的问题：对于一组响应（因）变量 *Y* 和解释（自）变量 *X*，我们希望找到 *Y* 与 *X* 之间的数学关系（模型）。一般来说，我们可以将数学模型写成函数 *Y* = *f*(*X*) 的形式。知道函数 *f*(*X*) 就能让我们计算出任意 *X* 值对应的 *Y* 值。如果我们不知道函数 *f*(*X*)，但拥有观测数据 {*y*[*i*], *x*[*i*]}，则可以对函数 *f*(*X*) 进行参数化，并将参数值拟合到数据上。*f*(*X*) 参数化的一个例子是线性模型 *f*(*X*) = *β*[0] + *β*[1]*X*，其中系数 *β*[0] 和 *β*[1] 是模型的参数。通常，我们的数据点数量远多于模型中自由参数的数量。在这种情况下，例如，我们可以使用最小二乘拟合，它最小化残差 *r* = *Y* − *f*(*X*) 的范数，尽管也可以使用其他最小化目标函数^(60)，例如取决于残差 *r* 的统计特性。

到目前为止，我们描述了一个*数学*模型。使模型成为*统计*模型的关键要素在于，数据 {*y*[*i*], *x*[*i*]} 包含不确定性因素，例如由测量噪声或其他不可控情况引起。这种数据不确定性可以在模型中用随机变量来描述：例如，*Y* = *f*(*X*) + *ε*，其中 *ε* 是一个随机变量。由于它包含随机变量，因此这是一个统计模型。根据随机变量在模型中的出现方式及其所遵循的分布，我们会得到不同类型的统计模型，每种模型可能需要不同的分析和求解方法。

统计模型的一个典型应用场景是描述实验中的观测值 *y*[*i*]，其中 *x*[*i*] 是一个向量，包含随每次观测一起记录的控制旋钮（即实验条件）。*x*[*i*] 中的某个元素可能与预测观测结果 *y*[*i*] 相关，也可能不相关，而确定哪些解释变量是相关的，是统计建模的一个重要方面。当然，也有可能存在一些相关因素未包含在解释变量集 *x*[*i*] 中，但它们却会影响观测结果 *y*[*i*]。在这种情况下，可能无法用该模型准确地解释数据。判断模型能否准确解释数据，是统计建模的另一个基本方面。

一种广泛使用的统计模型是 *Y* = *β*[0] + *β*[1] *X* + *ε*，其中 *β*[0] 和 *β*[1] 是模型参数，*ε* 服从均值为零、方差为 *σ*² 的正态分布：*ε* ~ *N*(0, *σ*²)。若 *X* 是标量，该模型称为*简单线性回归*；若 *X* 是向量，则称为*多元线性回归*；若 *Y* 是向量，则称为*多变量线性回归*。由于残差 *ε* 服从正态分布，对于所有这些情况，都可以使用*普通最小二乘法*（OLS）将模型拟合到数据。在多变量线性回归的情况下，放宽 *Y* 中各元素必须独立同分布且方差相等的条件，会产生模型的变体，这些变体可通过*广义最小二乘法*（GLS）和*加权最小二乘法*（WLS）等方法求解。所有求解统计模型的方法通常都有一组假设条件，在应用这些模型时需加以留意。对于标准线性回归，最重要的假设是残差独立且服从正态分布。

*广义线性模型*是线性回归模型的扩展，它允许响应变量中的误差具有正态分布以外的其他分布。具体来说，响应变量被假定为线性预测变量的函数，并且响应变量的方差可以是其值的函数。这为线性模型提供了广泛的推广，适用于许多情况。例如，这使得可以对响应变量取离散值这类重要问题进行建模，比如二值结果或计数结果。此类模型中响应变量的误差可能遵循不同的统计分布（例如，二项分布和/或泊松分布）。这类模型的示例包括用于二值结果的*逻辑回归*和用于正整数结果的*泊松回归*。

在接下来的章节中，我们将探讨如何使用 `Patsy` 和 `statsmodels` 库来定义和求解这些类型的统计模型。

## 使用 Patsy 定义统计模型

# 统计建模基础

所有统计建模的共同点是，我们需要对响应变量 `Y` 和解释变量 `X` 之间的数学关系做出假设。在绝大多数情况下，我们关注的是线性模型，例如 `Y` 可以写成响应变量 `X` 的线性组合、响应变量的函数，或者具有线性分量的模型。例如，`Y = α[1]X[1] + … + α[n]X[n]`，`Y = α[1]X + α[2]X² … + α[n]X^(n)`，以及 `Y = α[1] sin X[1] + α[2] cos X[2]` 都是这种线性模型的例子。请注意，对于模型为线性的要求，我们只需要该关系对于未知系数 `α` 是线性的，而不必对已知的解释变量 `X` 是线性的。相比之下，非线性模型的一个例子是 `Y = exp (β[0] + β[1]X)`，因为在这种情况下 `Y` 相对于 `β[0]` 和 `β[1]` 不是线性函数。然而，这个模型是*对数线性*的，因为对关系取对数可以得到一个线性模型：`~Y = β₀ + β₁X`，其中 `~Y = log Y`。能以此方式转化为线性模型的问题，就是可以用广义线性模型处理的那类问题。

## 设计矩阵

一旦模型的数学形式确定下来，下一步通常就是构建所谓的**设计矩阵** `y` 和 `X`，使得回归问题可以写成矩阵形式 `y = Xβ + ε`，其中 `y` 是观测值向量（或矩阵），`β` 是系数向量，而 `ε` 是残差（误差）。设计矩阵 `X` 中的元素 `X[ij]` 是对应于每个系数 `β[j]` 和观测值 `y[i]` 的解释变量（的函数）的值。`statsmodels` 和其他统计建模库中的许多统计模型求解器都可以将设计矩阵 `X` 和 `y` 作为输入。

例如，如果观测值为 `y = [1, 2, 3, 4, 5]`，有两个独立变量，其对应值分别为 `x[1] = [6, 7, 8, 9, 10]` 和 `x[2] = [11, 12, 13, 14, 15]`，并且所考虑的线性模型是 `Y = β[0] + β[1]X[1] + β[2]X[2] + β[3]X[1]X[2]`，那么右侧的设计矩阵就是 `X = [1, x[1], x[2], x[1]x[2]]`。我们可以使用 NumPy 的 `vstack` 函数构建这个设计矩阵：

```
In [9]: y = np.array([1, 2, 3, 4, 5])
In [10]: x1 = np.array([6, 7, 8, 9, 10])
In [11]: x2 = np.array([11, 12, 13, 14, 15])
In [12]: X = np.vstack([np.ones(5), x1, x2, x1*x2]).T
In [13]: X
Out[13]: array([[   1.,    6.,   11.,   66.],
               [   1.,    7.,   12.,   84.],
               [   1.,    8.,   13.,  104.],
               [   1.,    9.,   14.,  126.],
               [   1.,   10.,   15.,  150.]])
```

给定设计矩阵 `X` 和观测向量 `y`，我们可以求解未知的系数向量 `β`，例如使用最小二乘拟合（见第 5 和第 6 章）：

```
In [14]: beta, res, rank, sval = np.linalg.lstsq(X, y)
In [15]: beta
Out[15]: array([ -5.55555556e-01,  1.88888889e+00, -8.88888889e-01, -1.33226763e-15])
```

## 使用 Patsy 库构建设计矩阵

这些步骤是其最简单形式下统计建模的精髓。然而，对这个基本方法的变体与扩展使得统计建模自成一个领域，并且需要诸如 `statsmodels` 之类的计算框架来进行系统分析。例如，虽然在这个简单例子中构建设计矩阵 `X` 很直接，但对于更复杂的模型，以及如果我们希望能够轻松改变模型的定义方式，则可能会很繁琐。这正是 Patsy 库的用武之地。它提供了一种方便（尽管不一定直观）的公式语言来定义模型，并自动构建相关的设计矩阵。要为 Patsy 公式构建设计矩阵，我们可以使用 `patsy.dmatrices` 函数。它将公式字符串作为第一个参数，将一个包含响应变量和解释变量数据数组的类字典对象作为第二个参数。Patsy 公式的基本语法是 `"y ~ x1 + x2 + ..."`，这意味着 `y` 是解释变量 `x1` 和 `x2` 的线性组合（并显式地包含一个截距系数）。有关 Patsy 公式语法的概述，请参见表 14-1。

作为入门示例，请再次考虑我们之前使用的线性模型 `Y = β[0] + β[1]X[1] + β[2]X[2] + β[3]X[1]X[2]`。要使用 Patsy 定义这个模型，我们可以使用公式 `"y ~ 1 + x1 + x2 + x1*x2"`。注意，我们在模型公式中省略了系数，因为默认假设公式中的每一项都有一个模型参数作为其系数。除了指定公式外，我们还需要创建一个字典 `data`，将变量名映射到相应的数据数组：

```
In [16]: data = {"y": y, "x1": x1, "x2": x2}
In [17]: y, X = patsy.dmatrices("y ~ 1 + x1 + x2 + x1*x2", data)
```

结果是两个数组 `y` 和 `X`，它们是针对给定数据数组和指定模型公式的设计矩阵：

## Patsy 公式语法详解

现在我们已经了解了如何使用 `Patsy` 公式构建设计矩阵，或将其直接与 `statsmodels` 的众多统计模型类之一一起使用，我们简要回顾一下 `Patsy` 公式的语法和符号约定，然后再继续深入探讨 `statsmodels` 库中可用的不同统计模型。

如前所述并总结在表 14-1 中，模型公式的基本语法形式为 “`LHS ~ RHS`”。`~` 字符用于分隔模型等式的左侧（LHS）和右侧（RHS）。LHS 指定构成响应变量的项，RHS 指定构成解释变量的项。LHS 和 RHS 表达式中的项由 `+` 或 `-` 符号分隔，但这些不应解释为算术运算符，而应解释为集合并集和集合差集运算符。例如，`a+b` 表示模型包含 `a` 和 `b` 两者，而 `-a` 表示模型 *不* 包含项 `a`。`a*b` 类型的表达式会自动展开为 `a + b + a:b`，其中 `a:b` 是纯交互项 *a* ∙ *b*。

### 具体示例

作为一个具体示例，考虑以下公式及得到的右侧项（我们可以使用 `term_names` 属性从 `design_info` 属性中提取它们）：

```python
In [31]: from collections import defaultdict
In [32]: data = defaultdict(lambda: np.array([]))
In [33]: patsy.dmatrices("y ~ a", data=data)[1].design_info.term_names
Out[33]: ['Intercept', 'a']
```

这里的两个项是 `Intercept` 和 `a`，分别对应于常数项和对 `a` 的线性依赖。默认情况下，`Patsy` 始终包含截距常数，在 `Patsy` 公式中也可以使用 `y ~ 1 + a` 显式写出。在 `Patsy` 公式中包含 `1` 是可选的。

```python
In [34]: patsy.dmatrices("y ~ 1 + a + b", data=data)[1].design_info.term_names
Out[34]: ['Intercept', 'a', 'b']
```

在这种情况下，我们多了一个解释变量（`a` 和 `b`），这里截距被显式包含在公式中。如果我们不想在模型中包含截距，可以使用 `-1` 表示法来移除该项：

```python
In [35]: patsy.dmatrices("y ~ -1 + a + b", data=data)[1].design_info.term_names
Out[35]: ['a', 'b']
```

### 交互项的展开

`a * b` 类型的表达式会自动展开，以包含所有低阶交互项：

```python
In [36]: patsy.dmatrices("y ~ a * b", data=data)[1].design_info.term_names
Out[36]: ['Intercept', 'a', 'b', 'a:b']
```

高阶展开也同样有效：

```python
In [37]: patsy.dmatrices("y ~ a * b * c", data=data)[1].design_info.term_names
Out[37]: ['Intercept', 'a', 'b', 'a:b', 'c', 'a:c', 'b:c', 'a:b:c']
```

### 移除特定项

要从公式中移除特定项，我们可以写出该项并在前面加上减号运算符。例如，要从 `a*b*c` 的自动展开中移除纯三阶交互项 `a:b:c`，我们可以使用：

```python
In [38]: patsy.dmatrices("y ~ a * b * c - a:b:c", data=data)[1].design_info.term_names
Out[38]: ['Intercept', 'a', 'b', 'a:b', 'c', 'a:c', 'b:c']
```

### 使用恒等函数 `I()`

在 `Patsy` 中，`+` 和 `-` 运算符用于项集合的类集合操作；如果我们需要表示算术运算，则需要将表达式包裹在函数调用中。为方便起见，`Patsy` 提供了一个名为 `I` 的恒等函数，可用于此目的。为了说明这一点，请考虑以下两个示例，它们展示了 `y ~ a + b` 和 `y ~ I(a + b)` 的结果项：

```
In [39]: data = {k: np.array([]) for k in ["y", "a", "b", "c"]}
In [40]: patsy.dmatrices("y ~ a + b", data=data)[1].design_info.term_names
Out[40]: ['Intercept', 'a', 'b']
In [41]: patsy.dmatrices("y ~ I(a + b)", data=data)[1].design_info.term_names
Out[41]: ['Intercept', 'I(a + b)']
```
