# 引言

科学与数值计算是研究、工程和分析领域中一个蓬勃发展的领域。过去几十年计算机行业的革命为计算从业者提供了新的强大工具。这使得前所未有的规模和复杂性的计算事业得以实现。由此催生了整个领域和行业。这一发展仍在继续，并且随着硬件、软件和算法的不断改进，正在创造新的机遇。最终推动这一运动的赋能技术是近几十年来开发的强大计算硬件。然而，对于计算从业者来说，用于计算工作的软件环境与执行计算所依赖的硬件同等重要，甚至更为重要。本书介绍的是一种流行且快速发展的数值计算环境：`Python` 编程语言及其庞大的计算工作库和扩展生态系统。

计算是一项跨学科活动，需要在理论和实践主题方面具备经验和专业知识：扎实的数学和科学思维理解是有效计算工作的基本要求。同样重要的是计算机编程和计算机科学的扎实训练。本书的作用是通过介绍如何利用 `Python` 编程语言及其周围出现的计算环境进行科学计算，来架起这两门学科之间的桥梁。

在此书中，假设读者已具备一些数学和数值方法方面的先前训练，以及 `Python` 编程的基础知识。本书的重点是提供使用 `Python` 进行计算问题求解的实用介绍。每章都会对所涵盖主题的理论进行简要介绍，以引入符号并提醒读者基本方法和算法。然而，本书并非对数值方法的自洽论述。为帮助之前不熟悉本书某些主题的读者，每章末尾均提供了进一步阅读的参考资料。同样，没有 `Python` 编程经验的读者可能会发现，将本书与专注于 `Python` 编程语言本身的书籍一起阅读会很有帮助。

# 本书的组织方式

本书第一章介绍了科学计算的一般原理，以及可用于 Python 计算的主要开发环境：重点介绍`IPython`及其交互式 Python 提示符、出色的`Jupyter Notebook`应用，以及`Spyder IDE`。

第二章介绍了`NumPy`库，并在此基础上更广泛地讨论了基于数组的计算及其优点。第三章，我们转向符号计算——这在许多方面补充了基于数组的计算——使用`SymPy`库。第四章，我们讲解使用`Matplotlib`库进行绘图和可视化。总而言之，第二章至第四章提供了本书其余部分用于特定领域问题的基础计算工具：数值计算、符号计算和可视化。

第五章的主题是方程求解，我们将使用`SciPy`和`SymPy`库，通过数值和符号两种方法进行探索。第六章，我们探讨优化，这是方程求解的自然延伸。这里我们主要使用`SciPy`库，并简要涉及`cvxopt`库。第七章讨论插值，这是另一种基础数学方法，本身应用广泛，并且在更高级的算法和方法中扮演重要角色。第八章涵盖数值和符号积分。第五章至第八章涵盖了在所有类型的计算工作中普遍存在的核心计算技术。这些章节中的大多数方法都可在`SciPy`库中找到。

第九章，我们开始讲解常微分方程。第十章是一个关于稀疏矩阵和图方法的临时章节，这有助于为下一章打好基础。第十一章，我们讨论偏微分方程，它在概念上与常微分方程密切相关，但需要一套不同的技术，这必然引出稀疏矩阵（即第十章的主题）。

从第十二章开始，我们转变方向，开始探索数据分析和统计学。第十二章，我们介绍`Pandas`库及其出色的数据分析框架。第十三章，我们涵盖来自`SciPy stats`包的基本统计分析方法。第十四章，我们继续探讨统计建模，使用`statsmodels`库。第十五章，统计与数据分析的主题继续深入，讨论使用`scikit-learn`库的机器学习。第十六章，我们通过讨论贝叶斯统计学和`PyMC`库来结束与统计学相关的章节。总而言之，第十二章至第十六章提供了对广阔统计学和数据分析领域的介绍：这是近年来在科学 Python 社区内外都发展迅速的领域。

第十七章，我们短暂地回到科学计算的一个核心主题：信号处理。第十八章，我们讨论数据输入和输出，以及多种读写数值数据文件的方法，这是大多数类型计算工作所需的基础主题。第十九章，本书的最后一个常规章节，介绍了两种加速 Python 代码的方法，使用`Numba`和`Cython`库。

附录涵盖了本书所用软件的安装。为了安装所需的软件（主要是 Python 库），我们使用`conda`包管理器。`Conda`也可用于创建虚拟和隔离的 Python 环境，这是创建稳定且可重现计算环境的重要主题。附录还讨论了如何使用`conda`包管理器处理此类环境。
