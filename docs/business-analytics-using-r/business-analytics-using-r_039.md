# 分析趋势

分析领域正朝着整合特定行业（如医疗保健、银行和汽车）的垂直应用方向发展。另一方面，横向应用则跨越多个行业领域，包括消费者购买行为、交易监控（用于预防欺诈和洗钱），以及了解客户为何离开特定品牌或组织。

### 11.2.9 实时分析

各类组织都渴望了解自身面临的机遇。他们希望实时掌握正在发生的事情——例如，某个特定的人在购买什么，或者计划购买什么——并适时利用这一机会，提供最佳的解决方案、折扣，或交叉销售相关产品或服务。组织不再满足于延迟的数据分析，因为那样会因未能实时了解情况而错失商机。

### 11.2.10 让分析工具触达业务用户

人们一直观察到，数据分析师将分析结果提交给业务用户之前存在延迟。由于这种时间上的损失，即使分析结果很出色，也可能毫无用处，无法帮助组织制定有效的策略。相反，让工具对业务用户更有用、更可直接使用，使他们能够及时做出决策，这将使业务用户处于有利地位。整个世界正朝着在很大程度上实现这一目标的方向发展。

### 11.2.11 解决方案在不同工具间的迁移

工具多样化意味着为一种工具提供的解决方案不容易迁移到其他系统。这主要是因为使用了不同的编程语言和环境。业界正致力于使来自一种工具的解决方案能够轻松地在其他工具上实现或迁移。预测模型标记语言（PMML）方面的努力已经在朝这个方向发展。数据挖掘小组（DMG）也正在这方面开展工作。

### 11.2.12 云，云，无处不在的云

云中的数据和分析工具都为大数据分析提供了显著推动。越来越多的组织和机构正在使用云设施进行数据存储和分析。组织正从私有云转向公有云或混合云进行数据存储和分析。这为组织带来了成本效益、可扩展性和高可用性。当然，安全性可能是一个问题，目前正在大力提升云的安全性。

### 11.2.13 数据库内分析

数据库内分析通过在一定程度上解决治理问题，提高了安全性并减少了隐私担忧。组织在必要时可以省去数据分析的中间环节，例如数据仓库。对治理和安全问题更加关注的组织将为数据库内分析提供重要的推动力。许多供应商组织已经在这方面崭露头角。

### 11.2.14 内存分析

内存分析的价值在于能够同时、在内存中驱动事务处理和分析处理。这对于那些需要根据分析结果立即进行干预的领域可能非常有帮助。一些组织已经采用了具有混合事务/分析处理（HTAP）的系统。然而，仅仅为了使用 HTAP 而使用它可能用处不大，即使数据变化速率较慢，并且你仍然需要从各种不同系统中引入数据来进行有效分析。这反而可能造成过度设计，导致组织成本增加。

### 11.2.15 机器学习自主服务

越来越多的组织，如果找不到可靠且经验丰富、能有效提供帮助的数据科学家，可能会转向机器学习自主服务（例如微软 Azure 机器学习工作室、亚马逊机器学习或 Google Prediction API）。

### 11.2.16 保障安全与合规性

消费者和组织对信息安全与合规性要求的认识都在提高。这促使人们大力加强数据分析环境的安全性。这一趋势将持续下去，使工具和系统更加安全。不同国家的多样化要求可能会对数据的使用和保护方式施加某些限制。对于使用数据进行分析的组织来说，合规性很可能是一项挑战。

### 11.2.17 医疗保健

医疗保健领域的大数据可用于预测流行病、预防疾病，以及改善基于价值的医疗保健和生活质量。各种现代设备（如智能手机、Fitbit 产品和计步器）会产生大量数据，例如，它们可以测量你每天走了多远或消耗了多少卡路里。这些数据可用于制定饮食计划或开药。其他非结构化数据——例如医疗设备日志、医生笔记、化验结果、X 光报告以及临床和实验室数据——其规模可能足以进行分析，以改善患者护理，从而提高效率。可用于大数据分析生成和处理的其他数据还包括：索赔数据、电子健康/医疗记录数据（EHR 或 EMR）、制药研发数据、临床试验数据、基因组数据、患者行为和情感数据，以及医疗设备数据。
