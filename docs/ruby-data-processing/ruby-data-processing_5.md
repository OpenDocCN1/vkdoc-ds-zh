## 逆向工程复杂解决方案

在某些时候，你会遇到由其他人（或者是由很久以前的你自己所写，而你已经忘记了它是如何工作的）编写的代码，你需要理解这段代码做了什么，以及是否需要修复或改进它。
阅读一个使用`map`、`reduce`或`select`的数据处理工作流，与阅读典型的命令式编码风格的代码非常不同。此外，Ruby 传递块的方式可能会让许多不熟悉这种编码风格的人感到困惑。我曾遇到过一些人，他们阅读我的`map`/`reduce`/`select`数据处理级联代码时，表现出愤怒、困惑和轻蔑。而我自己看到其他人写的这类代码时，也曾有过同样的感受。我从命令式编程转向使用这种风格，是因为我可以用更少的代码行解决问题，并且能够有条理地解决问题，因为级联中的每一步都可以单独调试。
在本节中，我将给出一个示例，并引导你逆向工程这个解决方案，从而理解最初用来推导出该方案的技术。

# 帕斯卡三角形的解法

我在互联网上找到了以下代码（来自 [`http://kellegous.com/j/2006/06/28/post-9/`](http://kellegous.com/j/2006/06/28/post-9/)），用于生成帕斯卡三角形（我选取了 0..5 以便更易显示）。此处使用已获得代码作者 Kelly Norton 的许可。

```ruby
text =
(0..5).reduce([[1]]) { |a,x|
  a.unshift a.first.reduce([0,[]]) { |b,y|
    [y,b.last << (b.first + y)]
  }.last + [1]
}.reduce([]) { |c,z|
  next [z[z.length/2].to_s.length*2,z.length,""] if c.empty?
  [c[0],c[1], z.map { |j|
    j.to_s.center(c[0])
  }.join('').center(c[0]*c[1])+"\n#{c.last}"]
}.last
puts text
```

当我运行它时，得到了以下结果：

```
         1    
        1 1   
       1 2 1  
      1 3 3 1 
    1 4 6 4 1 
1 5 10 10 5 1 
=> nil
```

非常棒。它看起来像一个格式精美的帕斯卡三角形，而且比我之前写的示例简洁得多。

这个函数似乎使用了两个级联的 `reduce` 步骤来构建结果。让我们看看第一阶段做了什么：

```ruby
text =
(0..5).reduce([[1]]) { |a,x|
  a.unshift a.first.reduce([0,[]]) { |b,y|
    [y,b.last << (b.first + y)]
  }.last + [1]
}
# => [[1, 6, 15, 20, 15, 6, 1], [1, 5, 10, 10, 5, 1], [1, 4, 6, 4, 1], [1, 3, 3, 1], [1, 2, 1], [1, 1], [1]]
```

这很有趣。它看起来像帕斯卡三角形的数组，但顺序是反的。让我们添加一条调试语句。别忘了随后要返回 memo 对象。

```ruby
text =
(0..5).reduce([[1]]) { |a,x|
  memo =
    a.unshift a.first.reduce([0,[]]) { |b,y|
      [y,b.last << (b.first + y)]
    }.last + [1]
  # => [[1, 6, 15, 20, 15, 6, 1], [1, 5, 10, 10, 5, 1], [1, 4, 6, 4, 1], [1, 3, 3, 1], [1, 2, 1], [1, 1], [1]]
  memo
}
```

我们可以看到，每次 `reduce` 运行都会向三角形中添加一行，并将该三角形保存在 memo 中。让我们通过在每个主要步骤后打印关键数据，来看看每个内部 `reduce` 步骤中发生了什么：

```ruby
text =
(0..5).reduce([[1]]) { |a,x|
  puts "处理 a 之前：#{a}，x：#{x}"
  memo =
    a.unshift a.first.reduce([0,[]]) { |b,y|
      puts "  处理内层循环之前，b：#{b}，y：#{y}"
      inner_memo =
        [y,b.last << (b.first + y)]
      puts "    处理内层循环 y：#{y} 之后，内部 memo 为：#{inner_memo}"
      inner_memo
    }.last + [1]
  puts "处理 x：#{x} 之后，memo 为：#{memo}"
  puts ""
  memo
}
```

显而易见，内层循环的每一步都会遍历最后一行（`a[]`的第一个元素），并通过将元素右移将其插入到内部记忆数组 `memo` 的前面。接着，它会将该数字（`y`）与 `b[]` 的第一个元素（始终是整数或 `nil`）相加，然后将结果追加到 `b[]` 最后一个元素（始终是数组）的末尾。处理完成后得到的内部记忆数组 `inner_memo`，其第一个元素是一个数字，第二个元素是部分行。这个第一个元素在下一次迭代中需要与部分行的最后一个元素相加时使用。

内层循环最后一次运行后，记忆数组的第二个元素是`[1,6,15,20,16,5]`，这几乎是三角形的一整行。这就是为什么内层循环的结果会在数组末尾追加`[1]`，从而构成三角形的一个完整行。

从这里开始，只需反转结果即可得到三角形的原始数据，然后将其打印出来——正如我在本书前面所写的示例那样。我将其留作练习，让读者思考这个例子如何将三角形格式化为漂亮的对称形式并打印出来。
