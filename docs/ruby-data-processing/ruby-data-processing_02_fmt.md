# 引言

多年来，我主要编写响应式软件，但总会有涉及字符串操作、数据合成或数据格式化的用户界面或报表组件。由于我并非计算机科学专业出身，并未学习过像 Lisp 或 Smalltalk 这类语言中的高阶函数，如 `map()`、`reduce()` 和 `select()`。而且，在我上学时，Ruby、Python、C++ 和 JavaScript 也尚未出现。因此，我在某些任务中不得不使用繁琐且容易出错的命令式代码。

在学习 Ruby 几年后，尽管我仍在使用命令式编程风格进行数据处理，但我发现了 Ruby 的 `Enumerable` 库，并开始使用其高阶函数，例如 `map()`、`reduce()` 和 `select()`。我的数据处理代码发生了怎样的变化呢？

*   代码变得更加直观，因为数据处理任务可以通过由 `map`、`reduce` 和 `select` 阶段组成的级联管道来表达。管道中的每个阶段都易于开发和调试。

*   代码量减少了一半。

*   代码自然更加健壮，调试时间也大大缩短。

*   通过围绕 `map`、`reduce` 和 `select` 来构思解决方案，我能够设想并解决更复杂的问题。

然而，除了最基础的示例外，我找不到任何关于如何使用这些函数来解决数据处理问题的例子。为了解决这类问题，我花费了大量时间在 `map`、`reduce` 和 `select` 上进行反复试错。

我决定撰写本书，旨在：

*   系统化我的学习成果，并帮助你比我更快、更有效地理解它；

*   向你展示我的问题解决方法，以帮助你解决自己的数据处理问题。

我也承认，在编写示例的过程中，我被迫学习了这些函数在编程中的许多细微之处。

## 本书适用读者

本书适用于以下人群：

*   希望通过更熟练地使用 `map`、`reduce` 和 `select` 来提升编写数据处理代码的技能；

*   愿意亲手输入示例中的所有代码，并使用 `irb` Ruby 命令行和文本编辑器运行代码；

*   愿意仔细阅读并尝试本书中的示例，思考并反思输出结果，甚至独立调整程序以理解其运行机制；

*   愿意学习处理数据问题的不同方法；

*   愿意尝试失败的方法来学习这些函数的细微之处。

## 本书可能不适用读者

如果你希望：

*   通过菜谱式的指南获得解决标准问题的方案；或者

*   获得一个数据处理方案的参考手册。

那么本书可能对您帮助不大。

## 预备知识

你应该熟悉一些 Ruby 编程知识，或者至少熟悉其他某种语言的编程知识。如果你不了解 Ruby，可以搜索《笨办法学 Ruby》这本书，并按照作者 Zed Shaw 的建议通读一遍。

如果你精通 Python，那么在阅读本书时放慢速度，并在线查询 Ruby 相关信息，你可能会从中受益。

如果你想使用 Google、Bing 或其他搜索引擎在线查找帮助，那么互联网连接会很有用。

你应该拥有一台安装了 `Ruby 2.2.x` 的计算机。Windows、Linux 和 Mac OSX 系统均可。

你应该有一个好的语法高亮文本编辑器。我推荐 Windows 上的 `Notepad++` 或 Linux/Macintosh 上的 `gedit`，这两款都是免费的。`Sublime Text` 可在 Windows、Linux 或 Macintosh 上运行，性能略优，但在撰写本文时售价约为 70 美元。
