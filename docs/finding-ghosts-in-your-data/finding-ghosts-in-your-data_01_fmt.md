# 引言

欢迎阅读这本关于异常检测的书！在本书中，我们将用 Python 构建一个异常检测引擎。为此，我们必须首先回答一个问题：“什么是异常？”这个问题有一个简单的答案，但给出这个简单答案后，又会引出更多问题，而这些问题的答案又会打开更多未知之门。这正是学术界的乐趣与诅咒所在：我们总能沿着兔子洞再深入一点。

然而，在开始深入探索之前，让我们先设定好预期。本书中的所有代码都将使用 Python。这当然不是唯一可用的语言——我尊敬的审稿人、另一位同事和我曾使用 C# 和 R 的组合编写过一个异常检测引擎，因此并非必须使用 Python。我们会在书中讨论语言和其他设计选择，这里就不再赘述。关于你对 Python 的熟悉程度，本书的目的并非教你该语言，因此我假设你对它有一定了解。当然，我会为我们编写的代码提供上下文，并对那些不太直观的概念花费额外时间进行解释。此外，本书中使用的所有代码都可在配套的 GitHub 仓库中找到，地址为 [`https://github.com/Apress/finding-ghosts-in-your-data`](https://github.com/Apress/finding-ghosts-in-your-data)。

我写这本书的目标不仅仅是编写一个异常检测引擎，而是要在学术界和开发界之间架起一座桥梁。关于异常检测已有丰富的文献，但其中大部分内容晦涩难懂，充满了形式逻辑。我想向您介绍这些学术文献中的一些最佳见解，但以一种对大多数开发者有意义的方式呈现。因此，本书的每个部分至少会有一章专门讨论理论。此外，大多数编写代码的章节也会从理论开始，因为仅仅输入几个命令或查看项目自述文件中的示例方法调用是不够的；我想帮助您理解为什么某件事很重要，某种方法何时有效，以及何时可能失败。此外，如果您希望自行深入研究相关文献，书末的参考文献列表包含了各种学术资源。
