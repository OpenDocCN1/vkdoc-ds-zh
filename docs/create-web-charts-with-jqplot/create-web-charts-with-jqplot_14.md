# jqPlot 插件

本附录列出了`jqPlot`发行版中可用的完整插件列表（参见表B-1）。并非所有这些插件都在本书中进行了介绍；如需更多信息，请访问`jqPlot`网站 (`www.jqplot.com`)。

表 B-1. jqPlot 发行版中可用的插件（版本 1.0.8）

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| `$.jqplot.BarRenderer` | 渲染器 | 绘制条形图。 |
| `$.jqplot.BezierCurveRenderer` | 渲染器 | 将线条绘制为堆叠的贝塞尔曲线。 |
| `$.jqplot.BlockRenderer` | 渲染器 | 绘制xy块状图。块状图的数据点显示为带有内部文本标签的彩色方块。 |
| `$.jqplot.BubbleRenderer` | 渲染器 | 绘制气泡图。气泡图的数据点显示为带有可选内部文本标签的彩色圆圈。 |
| `$.jqplot.CanvasAxisLabelRenderer` | 渲染器 | 绘制轴标签，使用`canvas`元素支持高级功能，例如旋转文本。此渲染器使用单独的渲染引擎在画布上绘制文本。 |
| `$.jqplot.CanvasAxisTickRenderer` | 渲染器 | 绘制轴刻度，使用`canvas`元素支持高级功能，例如旋转文本。此渲染器使用单独的渲染引擎在画布上绘制文本。 |
| `$.jqplot.CanvasOverlay` | 插件 | 在图表上绘制叠加线条。 |
| `$.jqplot.CanvasTextRenderer` | 渲染器 | 由Jim Studt (`http://jim.studt.net/canvastext/`) 编写的`canvastext.js`插件的修改版本。 |
| `$.jqplot.CategoryAxisRenderer` | 渲染器 | 渲染类别样式轴，系列中y数据值之间的像素间距相等。 |
| `$.jqplot.ciParser` | 插件 | 一个将自定义JavaScript对象表示法 (JSON) 数据对象转换为`jqPlot`数据格式的函数。 |
| `$.jqplot.Cursor` | 插件 | 一个表示光标的类，如同在图表上显示的那样。 |
| `$.jqplot.DateAxisRenderer` | 渲染器 | 将轴渲染为一系列日期值。 |
| `$.jqplot.DonutRenderer` | 渲染器 | 绘制环形图；x值（如果存在）用作扇区标签，y值给出扇区大小。 |
| `$.jqplot.Dragable` | 插件 | 使绘制的点可被用户拖动。 |
| `$.jqplot.EnhancedLegendRenderer` | 渲染器 | 绘制具有高级功能的图例。 |
| `$.jqplot.FunnelRenderer` | 渲染器 | 绘制漏斗图；x值（如果存在）用作标签，y值给出区域大小。漏斗图仅绘制单个系列。 |
| `$.jqplot.Highlighter` | 插件 | 当鼠标悬停在数据点上时高亮显示它们。 |
| `$.jqplot.Json2` | 插件 | 创建一个包含两个方法：`stringify()`和`parse()`的JSON对象。 |
| `$.jqplot.LogAxisRenderer` | 渲染器 | 渲染对数轴。 |
| `$.jqplot.MekkoAxisRenderer` | 渲染器 | 与`MekkoRenderer`插件一起使用；将y轴显示为0到1（0到100%）的范围，x轴为每个系列显示一个刻度，并按所有y值的总和进行缩放。 |
| `$.jqplot.MekkoRenderer` | 渲染器 | 绘制一种在二维图形上显示三维数据的Mekko风格图表。 |
| `$.jqplot.MeterGaugeRenderer` | 渲染器 | 绘制仪表盘图表。 |
| `$.jqplot.Mobile` | 插件 | jQuery移动端虚拟事件支持。 |
| `$.jqplot.OHLCRenderer` | 渲染器 | 绘制开盘-最高-最低-收盘、蜡烛图和最高-最低-收盘图表。 |
| `$.jqplot.PieRenderer` | 渲染器 | 绘制饼图；x值（如果存在）用作扇区标签，y值给出扇区大小。 |
| `$.jqplot.PointLabels` | 插件 | 在数据点处放置标签。 |
| `$.jqplot.PyramidAxisRenderer` | 渲染器 | 与`PyramidRenderer`插件一起使用；在底部显示两个x轴，在中心显示y轴。 |
| `$.jqplot.PyramidGridRenderer` | 渲染器 | 与`PyramidRenderer`插件一起使用；在`canvas`元素上创建网格。 |
| `$.jqplot.PyramidRenderer` | 渲染器 | 绘制金字塔图。 |
| `$.jqplot.Trendline` | 插件 | 自动计算并绘制所绘数据的趋势线。 |
