## 引言

欢迎来到图表的世界。如果你正手捧这本书，你无疑对数据可视化感兴趣，或许希望开发充满交互式图表的网页。或者，你的目的是提升对 `jqPlot` 库的了解。无论你的目标是什么，我希望这本书能助你实现它。

除了使用 `jqPlot` 库实现的各种图表类型，本书还涵盖了一系列主题：`jQuery` 库与选择器、HTML5 与 `canvas`、小部件与控件，以及数学概念（比例尺与域、曲线拟合与趋势线等）。

我通过大量示例丰富了这些广泛的主题，每个示例都紧密聚焦于一个特定主题，并按顺序呈现，配有分步指导。

一旦你掌握了流程并备好合适的工具，图表开发就会变得简单。因此，在呈现这些材料时，我包含了有用的、可复用的代码片段以及对底层概念的解释。阅读本书后，你将能够自信地创建任何类型的数据可视化，无论是传统的还是新颖的。
