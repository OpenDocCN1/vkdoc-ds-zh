# 引言

本书从数据科学的角度审视 Python，并教授读者用于制定关键业务决策的成熟数据可视化技术。本书首先介绍使用 Python 进行数据科学，然后介绍 Python 环境，让您熟悉 Jupyter Notebooks 和 Spyder IDE 等编辑器。在学习了 Python 编程入门之后，您将掌握数据科学中使用的 Python 基本编程技术。接着，您将学习数据可视化，了解它如何满足现代业务需求并成为决策的关键。您还将了解 Python 中一些流行的数据可视化库。然后，重点转向数据收集，您将从数据科学的角度学习数据收集的各个方面，并了解 Python 的数据收集结构。之后，您将学习 Python 中的文件 I/O 处理和正则表达式，以及收集和清理数据的技术。接下来，您将探索和分析数据，了解 Python 中的各种数据结构。然后，您将深入探讨数据可视化技术，了解 Python 中的多种绘图系统。最后，您将学习两个详细的案例研究，有机会重温迄今为止掌握的概念。

本书适合希望学习 Python 以进入数据科学领域并成为数据科学家的人士。除具备基本编程知识外，无需特定的编程先决条件。

具体而言，以下列表概述了本书涵盖的内容：

*   第 1 章介绍了数据科学的主要概念及其生命周期。它还展示了 Python 编程及其主要库在数据科学处理中的重要性。您将学习如何在数据科学应用中使用不同的 Python 数据结构。您将学习如何将抽象序列和数据框作为主要的 Python 数据结构来实现。您将学习如何应用基本的 Python 编程技术进行数据清理和操作。您将学习如何进行基本的推断性统计分析。此外，还提供了带有参考答案的练习题，用于练习真实场景。

*   第 2 章演示了如何在现代业务中实现数据可视化。您将学习如何认识数据可视化在决策中的作用，以及如何加载和使用重要的 Python 数据可视化库。此外，还提供了带有参考答案的练习题，用于练习真实场景。

*   第 3 章阐述了 Python 中的数据收集结构及其实现。您将学习如何识别 Python 中不同的收集形式。您将学习如何创建列表以及如何操作列表内容。您将了解创建字典作为数据容器的目的及其操作方法。您将学习如何以元组形式维护数据，以及元组结构与字典结构之间的区别，以及基本的元组操作。您将学习如何从其他数据收集形式创建序列。您将学习如何从不同的数据收集结构以及从另一个数据框创建数据框。您将学习如何从序列或数据框创建面板作为 3D 数据收集。此外，还提供了带有参考答案的练习题，用于练习真实场景。

*   第 4 章展示了如何向用户读取和发送数据，读取和提取存储在历史文件中的数据，以及打开文件进行读取、写入或两者兼有。您将学习如何访问文件属性和操作会话。您将学习如何从用户读取数据并应用类型转换。您将学习如何应用正则表达式提取数据，使用正则表达式替代方案，以及使用锚点和重复表达式进行数据提取。此外，还提供了带有参考答案的练习题，用于练习真实场景。

*   第 5 章涵盖了数据收集和清理，以获得可靠的数据进行分析。您将学习如何应用数据清理技术来处理缺失值。您将学习如何离线读取 CSV 数据格式或直接从在线云中提取数据。您将学习如何合并和整合来自不同来源的数据。您将学习如何从 JSON、HTML 和 XML 格式读取和提取数据。此外，还提供了带有参考答案的练习题，用于练习真实场景。

*   第 6 章展示了如何使用 Python 脚本探索和分析不同收集结构中的数据。您将学习如何应用 Python 技术来探索和分析数据序列，创建序列，通过位置访问序列中的数据，并对序列应用统计方法。您将学习如何探索和分析数据框中的数据，创建数据框，以及更新和访问数据框结构中的数据。您将学习如何操作数据框中的数据，例如包含列、选择行、添加或删除数据，以及对数据框应用统计操作。您将学习如何对面板数据结构应用统计方法来探索和分析存储的数据。您将学习如何对分组数据进行统计分析，遍历组，并应用聚合、转换和过滤技术。此外，还提供了带有参考答案的练习题，用于练习真实场景。

*   第 7 章展示了如何可视化来自不同收集结构的数据。您将学习如何使用 Python 绘图工具（如折线图、条形图、饼图、箱线图、直方图和散点图）绘制来自序列、数据框或面板的数据。您将学习如何使用带状图、箱线图、蜂群图和联合图来实现 Seaborn 绘图系统。您将学习如何使用折线图、条形图、直方图、散点图、堆叠图和饼图来实现 Matplotlib 绘图。此外，还提供了带有参考答案的练习题，用于练习真实场景。

*   第 8 章研究了两个真实案例研究，从数据收集开始，依次进行数据清理、数据探索、数据分析和可视化。最后，您将学习如何讨论研究结果并为决策者提供建议。
