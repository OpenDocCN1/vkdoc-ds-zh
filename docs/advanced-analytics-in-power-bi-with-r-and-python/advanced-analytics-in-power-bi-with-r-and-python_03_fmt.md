# 章节摘要

- 第 1 章 – 图形语法：可以说，R 相对于 Python 的优势之一在于其数据可视化能力。R 中最顶尖的数据可视化包是 `ggplot2`，它基于一种被称为图形语法的概念。本章将向您介绍 `ggplot2` 包，并展示如何在 Power BI 中正确使用该包的框架。
- 第 2 章 – 在 Power BI 中使用 `ggplot2` 创建 R 自定义视觉对象：使用 `ggplot2` 的最大好处之一是，它在创建可视化时能让您极具表现力。本章提供了多种可视化的实现方案，让您了解可以在 Power BI 中使用 `ggplot2` 包创建的 R 视觉对象类型。
- 第 3 章 – 读取 CSV 文件：本章提供了 R 和 Python 两种语言的实现方案，让您能够动态合并 `csv` 文件，而使用 Power Query 完成同样任务则要困难得多。
- 第 4 章 – 读取 Excel 文件：本章提供了 R 和 Python 两种语言的实现方案，让您能够动态合并来自多个 Excel 工作簿的多个工作表，而使用 Power Query 完成同样任务则要困难得多。
- 第 5 章 – 读取 SQL Server 数据：本章提供了 R 和 Python 两种语言的实现方案，让您能够将 SQL Server 中的数据加载到 Power BI 数据模型中。此方案的优势在于，它向您展示了如何使用 R 和 Python 在 SQL Server 中记录有关数据加载的信息。
- 第 6 章 – 通过 API 将数据读取到 Power BI 数据模型中：本章提供了 R 和 Python 两种语言的实现方案，向读者展示如何使用 API 为 Power BI 获取数据，而使用 Power Query 完成同样任务要困难得多，并且在许多情况下是不可能的。
- 第 7 章 – 高级字符串操作与模式匹配：本章提供了 R 和 Python 两种语言的实现方案，向您展示如何利用正则表达式执行高级字符串操作任务。正则表达式是 R 和 Python 的原生功能，但在 Power Query 中不可用。
- 第 8 章 – 使用 R 和 Python 创建计算列：本章提供了 R 和 Python 两种语言的实现方案，向您展示如何基于高级数学公式创建表达式。您将学习重构数学公式的基础知识，还将学习如何使用预构建的函数，这些函数为您抽象了众多计算的复杂性。本章使用半正矢公式作为示例。
- 第 9 章 – 将机器学习和 AI 应用于您的 Power BI 数据模型：本章涵盖多个主题，涉及机器学习和人工智能。首先，它展示了如何将用 R 和 Python 构建的自定义机器学习模型应用于您的 Power BI 数据模型的示例。然后，它展示了如何在不使用 Power BI Premium 的情况下，通过 Microsoft 认知服务增强您的 Power BI 数据模型。本章并未将您局限于 Microsoft 提供的功能，最后还展示了如何利用 IBM Watson 自然语言理解，向您展示如何利用一些 Microsoft 认知服务中不具备的文本分析功能。
- 第 10 章 – 将数据科学模型和数据整理脚本投入生产：本章向您展示如何在 Power BI 的企业解决方案中利用 R 和 Python。所展示的方法侧重于免费解决方案，这些方案适用于已拥有本地版 SQL Server 2017 及更高版本的用户。

现在我们已经扫清了所有预备知识，可以进入本书的内容了。Power BI 最著名的顶级功能是其可视化能力。鉴于此，本书将首先向您介绍如何通过 `ggplot2` 包使用 R 编程语言来极大地增强 Power BI 的可视化能力。
