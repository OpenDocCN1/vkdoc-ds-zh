# 引言

许多人认为 Microsoft Power BI 是市场上首屈一指的自助式商业智能工具。近年来，它超越了 QlikView 和 Tableau 等强大的工具，占据了第一的位置。它被认为是一款如此出色的自助式商业智能工具的原因之一，在于它不仅仅是一个可视化工具。Microsoft Power BI 内置了以下功能：

*   `DAX` 表达式和查询语言，使您能够使用复杂的业务逻辑，以快速高效的方式查询您的 Power BI 数据模型
*   一个名为 `Power Query` 的数据整理工具，使您能够将数据塑形和转换为有利于数据分析的形式
*   `Vertipaq` 引擎，它以针对报表进行优化的方式高效存储数据，并快速高效地执行复杂计算
*   预打包的交互式可视化效果，使您能够以报表使用者易于理解的方式呈现数据

那么，您可能会问，既然有这么多功能，为什么还需要在 Power BI 中利用 R 和 Python 等编程语言呢？答案是为了填补原生工具不足的少数几个领域。几个例子如下：

*   以相对简单的方式创建自定义可视化效果
*   无需 `Power BI Premium` 即可将数据科学应用于您的 Power BI 数据模型
*   使用 `Power Query` 或 `DAX` 中不可用的高级技术执行高级字符串操作
*   无需 `Power BI Premium` 即可与 `Microsoft Cognitive Services` 交互
*   以高效的方式与第三方数据 API 通信，以丰富您的 Power BI 数据模型
*   以及更多其他功能

本书涵盖了如何利用 R 和 Python 将前面列出的附加功能引入您的 Power BI 解决方案。R 是 Power BI 的完美补充，因为它是一种专门为数据分析而编写的语言。几十年来，数据分析师一直在使用 R 来执行数据整理和数据可视化等任务。因此，Power BI 中可能不具备的功能，可能在 R 中早已存在。

在过去十年中，Python 已成为数据分析领域非常流行的编程语言。使 Python 如此吸引人的特点之一是，它不仅非常适合数据分析，也非常适合一般的编程任务。使用 Python 与 API 通信轻而易举，但同样的任务使用 Power Query 则非常笨拙。

R 和 Python 的这些特性使它们成为 Power BI 的完美伴侣。本书将涵盖一些示例，以说明上述特性。这些示例将包含详细的步骤和详尽的描述，以便您清楚地理解它们的工作原理。在开始使用这些示例之前，您需要配置您的环境。让我们来看看这些配置。
