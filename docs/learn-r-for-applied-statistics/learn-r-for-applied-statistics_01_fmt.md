# 引言

## 本书适合哪些读者？

本书主要面向希望学习使用 R 语言进行统计编程的程序员或学习者。本书将涵盖使用 R 语言进行描述性统计、推断性统计、回归分析和数据可视化。

## 本书的结构如何？

本书的结构由以下两个需求决定：

| 主题 | 章节 |
| --- | --- |
| R 语言及 R 编程基础介绍 | 第 1 至 3 章 |
| 描述性统计、数据可视化、推断性统计和回归分析 | 第 4 至 6 章 |

本书适合初学者学习使用 R 语言进行统计编程。

本书也适合希望将其作为参考书的专业人士。
