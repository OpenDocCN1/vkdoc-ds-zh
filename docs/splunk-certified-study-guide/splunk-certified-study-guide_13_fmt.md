# 12. Splunk 管理员考试题集

本章提供了对 Splunk Enterprise 管理员认证有用的多项选择题，让你了解考试内容。

## 问题

1. 以下哪种身份验证类型需要在 Splunk 中编写脚本？
   1. ADFS
   2. LDAP
   3. SAML
   4. RADIUS

2. 从 Windows 通用转发器发送日志时，支持哪种 Splunk 索引器操作系统平台？
   1. 任何操作系统平台
   2. 仅限 Linux 平台
   3. 仅限 Windows 平台
   4. 以上都不是

3. 在 Splunk 中创建网络输入时，所需的最低设置是什么？
   1. 协议，端口号
   2. 协议，端口，位置
   3. 协议，用户名，端口
   4. 协议，IP，端口号

4. 在 Splunk 中创建的本地用户帐户将密码存储在哪一个文件中？
   1. `$SPLUNK_HOME/etc/passwd`
   2. `$SPLUNK_HOME/etc/authentication`
   3. `$SPLUNK_HOME/etc/users/passwd.conf`
   4. `$SPLUNK_HOME/etc/users/authentication.conf`

5. 以下哪些是在 Splunk 中添加输入的方法？（选择所有适用的选项。）
   1. CLI
   2. Splunk Web
   3. 编辑 `inputs.conf`
   4. 编辑 `monitor.conf`

6. 您在 Splunk 运行时更新了 `props.conf` 文件。您没有重启 Splunk，并运行了以下命令。
   1. Splunk 包含的磁盘上所有配置的列表
   2. `splunkd` 启动时所有配置的详细列表
   3. 磁盘上的 `props.conf` 配置列表，以及配置所在的文件路径
   4. 当前正在运行的 `props.conf` 配置列表，以及生成该配置的文件路径

7. 哪个 Splunk 组件负责将应用程序和其他某些配置更新分发给搜索头集群成员？
   1. 部署器
   2. 集群主节点
   3. 部署服务器
   4. 搜索头集群主节点

8. 在哪种场景下，Splunk 管理员希望在创建索引时启用数据完整性检查？
   1. 确保热存储桶仍开放写入，并且未被强制滚动到冷状态
   2. 确保配置文件未被篡改，用于审计和/或法律目的
   3. 确保用户密码未被篡改，用于审计和/或法律目的
   4. 确保数据未被篡改，用于审计和/或法律目的

9. 监控控制台如何监控转发器？
   1. 通过从转发器拉取内部日志
   2. 通过使用转发器监控插件
   3. 通过转发器转发的内部日志
   4. 通过部署服务器转发的内部日志

10. Splunk 在输入阶段使用的默认字符编码是什么？
    1. UTF-8
    2. UTF-16
    3. EBCDIC
    4. ISO 8859

11. 哪种 Splunk 转发器类型允许在转发到索引器之前解析数据？
    1. 通用转发器
    2. 解析转发器
    3. 重型转发器
    4. 高级转发器

12. 配置可选网络输入时，支持以下哪些选项？
    1. 元数据覆盖，发送方过滤选项，网络输入队列（量子队列）
    2. 元数据覆盖，发送方过滤选项，网络输入队列（内存/持久队列）
    3. 文件名覆盖，发送方过滤选项，网络输出队列（内存/持久队列）
    4. 元数据覆盖，接收方过滤选项，网络输入队列（内存/持久队列）

13. 哪些有效的存储桶类型是可搜索的？（选择所有适用的选项。）
    1. 热存储桶
    2. 冷存储桶
    3. 温存储桶
    4. 冻结存储桶

14. 需要更改哪个硬件属性才能增加单个搜索头上同时进行的搜索（临时搜索和计划搜索）数量？
    1. 磁盘
    2. CPU
    3. 内存
    4. 网卡

15. 使用白名单或黑名单配置监控输入时，支持哪种过滤列表的方法？

    2. 正则表达式
    3. 不规则表达式
    4. 仅通配符

16. 通用转发器在发送数据时具有哪些功能？（选择所有适用的选项。）

    2. 压缩数据

17. 对于单行事件源，最有效的方式是将 `SHOULD_linemerge` 设置为何值？

    2. false
    3. `<正则表达式字符串>`
    4. 换行符

18. 以下哪些陈述描述了部署管理？（选择所有适用的选项。）

    2. 负责将应用程序发送到转发器
    3. 一旦使用，成为管理转发器的唯一方式
    4. 可以自动重启运行转发器的主机操作系统
