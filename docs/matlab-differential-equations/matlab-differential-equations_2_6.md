
# 9. 数学分析：函数、极限、连续性与级数

MATLAB 的符号数学模块让您能够轻松处理数学分析问题。它可以计算极限、求导数、求和级数、寻找函数的泰勒级数、计算积分以及处理方程。

在求解极限时，可使用相同函数来计算数列极限、函数极限、函数序列极限，当然也能用于分析函数的连续性以及数值级数和幂级数的收敛性。单变量和多变量分析的方法是类似的。以下是可用的函数。

| 函数描述 | 说明 |
| :--- | :--- |
| `limit(sequence, inf)` | 计算由通项表示的数列在 `n` 趋于无穷大时的极限。 |
| `limit(function, x, a)` | 计算由解析表达式表示的关于变量 `x` 的函数，当变量 `x` 趋于值 `a` 时的极限。 |
| `limit(function, a)` | 计算由解析表达式表示的关于变量 `x` 的函数，当变量 `x` 趋于值 `a` 时的极限。 |
| `limit(function, x, a, 'right')` | 计算由解析表达式表示的关于变量 `x` 的函数，当变量 `x` 从右侧趋于值 `a` 时的极限。 |
| `limit(function, x, a, 'left')` | 计算由解析表达式表示的关于变量 `x` 的函数，当变量 `x` 从左侧趋于值 `a` 时的极限。 |
| `symsum(S, v, a, b)` | 求通项为 `S`、变量 `v` 从 `a` 到 `b` 的级数之和。 |
| `symsum(S, v)` | 求通项为 `S`、变量 `v` 的值从 `0` 到 `v-1` 的级数之和。 |
| `r = symsum(S)` | 返回关于符号变量 `k`（由 `findsym` 确定）的通项为 `S` 的级数之和，其中 `k` 的值从 `0` 到 `k-1`。 |
| `symsum(S, a, b)` | 求关于符号变量 `k`（由 `findsym` 确定）的通项为 `S` 的级数之和，其中 `k` 的值从 `a` 到 `b`。 |

以下例子验证了函数 `f(x) = sin(x) / x` 在 `R-{0}` 上的连续性。下面的命令检查了极限关系是否成立。

```matlab
>> syms x a
>> limit(sin(x)/x, x, a)
ans =
sin(a)/a
```

接下来我们证明函数在点 `x = 0` 不连续，通过说明其左右极限不匹配（一个为 `0`，另一个为无穷大）。

```matlab
>> syms x
>> limit(exp(1/x), x, 0, 'right')
ans =
inf
>> limit(exp(1/x), x, 0, 'left')
ans =
0
```

在以下例子中，我们通过应用比值检验法来确定级数是否收敛，如果收敛，则计算其和。

```matlab
>> syms n
>> f = n/2^n
f =
n/(2^n)
>> limit(subs(f, n, n+1)/f, n, inf)
ans =
1/2
```

我们看到相邻项比值的极限小于 `1`，这意味着该级数收敛。我们使用以下方法计算其和：

```matlab
>> symsum(f, n, 1, inf)
ans =
2
```

## 导数、积分与微分方程

下文将介绍在数学分析中，处理导数、积分和微分方程时常用的 MATLAB 函数。我们首先从与微分相关的函数开始。

| 函数描述 | 说明 |
| :--- | :--- |
| `diff('f', 'x')` | 返回 `f` 对 `x` 的导数。 |
| `syms x, diff(f, x)` | 返回 `f` 对 `x` 的导数。 |
| `diff('f', 'x', n)` | 返回 `f` 对 `x` 的 `n` 阶导数。 |
| `syms x, diff(f, x, n)` | 返回 `f` 对 `x` 的 `n` 阶导数。 |
| `r = taylor(f, n, v)` | 返回函数 `f` 在变量 `v` 下的 `n-1` 阶麦克劳林级数。 |
| `r = taylor(f)` | 返回函数 `f` 在默认变量下的 `5` 阶麦克劳林级数。 |
| `r = taylor(f, n, v, a)` | 返回函数 `f` 在变量 `v` 下、点 `a` 邻域内的 `n-1` 阶泰勒级数。 |
| `R = jacobian(w, v)` | 返回 `w` 对 `v` 的雅可比矩阵。 |

下表总结了与微分方程相关的函数：

| `dsolve('e', 'v')` | 求解微分方程 `e`，其中 `v` 是自变量（如果不指定 `'v'`，则自变量默认为 `x`）。仅返回显式解。 |
| `dsolve('e', 'c', 'v')` | 求解微分方程 `e`，并满足 `c` 指定的初始条件，其中 `v` 是自变量。 |
| `dsolve('e', 'c1', 'c2', ..., 'cn', 'v')` | 求解微分方程 `e`，并满足 `c1`,...,`cn` 指定的初始条件，其中 `v` 是自变量。 |
| `dsolve('e', 'c1,c2,...,cn', 'v')` | 求解微分方程 `e`，并满足指定的初始条件 `c1`,...,`cn`，其中 `v` 是自变量。 |
| `dsolve('e1', 'e2', ..., 'en', 'c1', 'c2', ..., 'cn', 'v')` | 求解微分方程组 `e1`,...,`en`，并满足指定的初始条件 `c1`,...,`cn`，其中 `v` 是自变量。 |
| `dsolve('e1, e2,..., en', 'c1, c2,..., cn', 'v')` | 求解微分方程组 `e1`,...,`en`，并满足指定的初始条件 `c1`,...,`cn`，其中 `v` 是自变量。 |

# 线性代数：化简与求解方程

MATLAB 专门处理了用于简单、有理数和复数代数表达式的计算。符号数学工具箱中的函数能高效实现代数表达式的化简、因式分解、合并与展开等运算，并包含三角表达式和复变量表达式。这些函数的语法如下。

| `r = collect(S)` `r = collect(S, v)` | 根据变量 `v`（若未指定 `v`，则按 `x`）合并多项式数组 `S` 中的每个多项式。 |
| `r = expand(S)` | 展开 `S` 中包含的每个多项式、三角、指数或对数函数。 |
| `factor(x)` | 对 `x`（符号或数值）进行因式分解。 |
| `r = horner(p)` | 将多项式 `p` 转换为 Horner 形式（即嵌套形式）。 |
| `[n, d] = numden(A)` | 将符号或数值矩阵 `A` 的每个元素转换为简化后的有理形式。 |
| `r = simple(s)` `[r,how] = simple(s)` | 简化符号表达式 `s`，寻求最短的可能输出。第二种形式仅输出最终结果及描述特定简化过程的字符串。 |
| `r = simplify(S)` | 简化符号矩阵 `S` 的每个元素。 |
| `[y, sigma] = subexpr(x, sigma)` `[y, sigma] = subexpr(x, 'sigma')` | 将符号表达式 `x` 用公共子表达式重写，并用符号变量 `sigma` 替代该子表达式。 |

第一个示例，我们将表达式 `y(sin(x) + 1) + sin(x)` 按 `sin(x)` 进行合并。
```
>> syms x and
>> pretty (collect (y * (sin (x) + 1) + sin (x), sin (x)))
(y + 1) sin (x) + y
```

接下来，我们先按 `x` 合并，再按 `ln(x)` 合并函数 `f(x) = aln(x)-xln(x)-x`。
```
>> syms a x
>> f=a*log(x)-log(x)*x-x
f =
a*log(x)-log(x)*x-x
>> pretty(collect(f,x))
(- log (x) - 1) x + log (x)
>> pretty(collect(f,log(x)))
(a - x) log (x) - x
```

下面的示例中，我们展开各种代数表达式。
```
>> syms a b x y t
>> expand([sin(2*t), cos(2*t)])
ans =
[2 * sin (t) * cos (t), 2 * cos (t) ^ 2-1]
>> expand(exp((a+b)²))
ans =
exp(a²) * exp(a*b) ^ 2 * exp(b²)
>> expand (cos (x + y))
ans =
cos (x) * cos (y) - sin (x) * sin(y)
>> expand((x-2)*(x-4))
ans =
x²-6*x+8
```

接下来我们对各种表达式进行因式分解。
```
>> factor(x³-y³)
ans =
(x - y) *(x²+x*y+y²)
>> factor([a²-b², a³+b³])

[(a-b)*(a+b), (a+b)*(a²-a*b+b²)]

ans =
(2) * (3) ^ 2 * (5) * (101) * (3803) * (3607) * (27961) * (3541)
```

```

以下函数可用于求解符号方程和方程组：

| `solve('equation', 'x')` | 针对变量 `x` 求解方程。 |
| `syms x; solve(equation,x)` | 针对变量 `x` 求解方程。 |
| `solve('e1,e2,...,en', 'x1,x2,...,xn')` | 针对变量 `x1,...,xn` 求解方程组 `e1,...,en`。 |
| `syms x1 x2... xn; solve(e1,e2,...,en, x1,x2,...,xn)` | 针对变量 `x1,...,xn` 求解方程组 `e1,...,en`。 |

第一个示例，我们针对变量 `x` 求解方程 `3ax - 7x² + x³ = 0`，其中 `a` 是参数。
```
>> solve('3*a*x-7*x²+x³=0','x')
ans =
[                       0]
[7/2 + 1/2 *(49-12*a) ^(1/2)]
[7/2-1/2 *(49-12*a) ^(1/2)]
```

接下来，我们将上述方程中的 `a` 视为变量，`x` 视为参数进行求解。
```
>> pretty(solve('3*a*x-7*x²+x³=0','a'))
-1/3 x (- 7 + x)
```

在下面的示例中，我们计算 `-1` 和 `1` 的四次方根。
```
>> S=solve('x⁴+1=0')
