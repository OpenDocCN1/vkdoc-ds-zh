# Power Query 的演变

自 `Power Query` 最初作为 `Excel 2010` 的可下载插件问世以来，它经历了多年的显著演变。对于 `Excel 2013`，它仍然是可选的，直到 `2016` 版本才完全集成到 `Excel` 中。事实上，它在当时经历了名称变更，并归入“获取和转换”标题下。

大约从 `2017` 年起——以及自 `Excel 2019` 版本以来——它又恢复为 `Power Query` 的名称。*本书所探讨的就是这个版本。* 这并不意味着你不能将本书描述的技术用于该产品的早期版本。然而，这意味着你用来启动 `Power Query` 的某些 `Excel` 界面方面会与第 `1` 章至第 `5` 章中描述的略有不同。这些差异基本上很小，不会给有经验的 `Excel` 用户带来任何困难。

之所以能够实现这一点，是因为 `Power Query` 是通过一个独立的界面来访问的。它从 `Excel` 内部调用，但存在于其自己的平行宇宙中。这确保了无论你使用哪个版本的 `Excel`，它都具有一致的外观和体验。进入 `Power Query` 的入口点可能因 `Excel` 版本而异——但产品本身保持不变。只需记住，可用的数据源范围取决于你使用的 `Excel` 版本。一些“企业级”数据源仅在 `Excel` 的 `Pro`（专业版）和 `Enterprise`（企业版）订阅中可用。
