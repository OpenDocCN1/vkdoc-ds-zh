# 开始学习 Power Query

本书附带一小组样本数据，用于创建贯穿全书的示例。我意识到，对于一个可以处理数千万行数据的产品来说，使用这么小的数据集似乎有些矛盾，但我更愿意使用一套易于理解的源数据，以便读者能够专注于学习的内容，而不是数据本身。

不可避免地，并非所有问题都能在一本书中得到预见和解答。尽管如此，我希望我已经回答了你可能遇到的许多数据导入和转换问题，并且——更重要的是——给了你方法和信心，来解决在应用该产品解决实际问题时可能遇到的大部分 `Power Query` 挑战。

最后一点，第 `6`–`12` 章中关于“纯” `Power Query` 的信息是独立于 `Excel` 的。因此，如果你在 `Power BI`、`SQL Server Integration Services` 或 `Power BI Service` 中学习 `Power Query`，你可以找到大量相关信息来协助你的数据转换项目。

祝你在使用 `Power Query` 时好运，我真诚地希望你在使用它时能像我写这本书时一样开心。
