# 引言

数据分析已成为定义一个时代的流行语之一。管理者希望员工能在数秒内提供有意义的见解；用户只想快速且出色地完成工作。每个人都希望使用直观易用的工具，进行清晰、有说服力且准确的分析。

微软在短短几年前就认识到了这些趋势和需求，当时他们通过一个名为 `Power Query` 的加载项扩展了 Excel。`Power Query` 曾经只是世界领先电子表格的一个可选扩展，如今已成为 Excel 工具集的基本支柱。它允许用户从各种来源获取数据，并将其转换为基础数据，在此基础上添加指标、即时分析和 KPI，以展现他们的见解。

有了 `Power Query`，自助式数据访问和转换的时代终于到来了。

## 什么是 `Power Query`？

`Power Query` 是一种用于执行 `ETL` 的工具。这个缩写代表**提**取（`E`）、**转**换（`T`）、**加**载（`L`）。这是一个顺序流程，涵盖：

*   连接到当前 Excel 工作簿（或文件）外部的源数据，并访问需要导入 Excel 的全部或部分数据。这是 `ETL` 中的*提取*阶段。

*   重塑数据（即“数据混搭”过程），使结果数据成为 Excel 可以使用的形式。本质上，这意味着确保数据采用连贯、结构化且完整的表格格式。这是 `ETL` 中的*转换*阶段。

*   将数据以工作表表格的形式或导入到 Excel/`Power Pivot` 数据模型中的形式返回给 Excel。这是 `ETL` 中的*加载*阶段。

这三个阶段构成了数据摄取过程。因此，值得简要了解每个阶段包含的内容。

### 连接到源数据

过去需要手动将所有数据输入到电子表格中的日子已经一去不复返了。如今的数据存在于多种位置和格式中，而且数据量巨大，无法重新输入。

这正是 `Power Query` 能够即时连接到 40 多种标准数据源的能力显得无比宝贵的原因。你的会计数据在 `MS Dynamics` 中？直接连接。你的 `CRM` 数据在 `Salesforce` 中？直接连接。你的组织正在使用数据湖？……答案可想而知。

然而，这只是 `Power Query` 帮助简化分析的一小部分能力。它不仅能够连接到众多数据源（其中许多将在第 1 章到第 5 章中概述），而且是通过一个统一的界面来实现的，这使得连接数据源变得极其简单。除此之外，你还可以使用 `Power Query` 预览源数据，确保你加载的正是所需的数据。最后，最重要的是，几乎所有可用的源数据连接都使用相同的界面。这意味着，一旦你学会了设置*一个*连接，你就学会了如何*连接到几乎所有可用的数据源*。

从本质上讲，`Power Query` 的一部分只是另一种连接外部数据的方式。然而，其统一的数据访问接口、丰富的可用数据源以及其极致的简洁性，很可能会促使你迅速替换掉任何使用旧技术建立的数据连接。

### 数据转换

一旦建立到数据源的连接，你可能需要以某种方式调整数据。实际上，你甚至可能需要完全重塑数据。这就是数据混搭过程——也是 `Power Query` 的闪光之处。

`Power Query` 只需点击几下，就能完成从最简单的数据转换任务到最复杂的数据重构挑战。你可以：

*   筛选源数据，以便只精确加载你需要的行和列

*   通过计算或从现有数据列中提取的数据来扩展源数据

*   以多种方式轻松快速地清理和合理化数据

*   连接或拆分源表，为每个特定的分析需求准备逻辑上统一的数据集

*   对源数据进行分组和聚合，以减少加载到 Excel 中的数据量

*   准备源数据表，使其成为可用的数据模型

此清单仅仅触及了 `Power Query` 在数据混搭能力方面的皮毛。毫不夸张地说，它在转换源数据方面强大得令人难以置信。实际上，它可以执行过去那些需要复杂编程技能和强大服务器的高价产品才能处理的数据摄取和转换任务。

现在，所有这些都可以通过一个无需编码的界面完成，该界面帮助你处理最混乱的源数据，并将其作为清晰明了的可操作信息表格交付给 Excel。如果你想成为 `Power Query` 超级用户，你可以使用内置的 `M` 语言扩展其功能。

### 加载到工作表或数据模型

这最后一个阶段是目前为止最简单的。它只是告诉 `Power Query` 将数据放在哪里的问题。可以是以下之一，或两者：

*   *工作表*：`Power Query` 可以将每个源查询的数据放入单独的工作表中。一旦进入工作表，它就是完全“正常”的 Excel 数据。从此以后，你可以像多年来学到的所有 Excel 技巧一样，对 Excel 中的数据进行任何你想要的操作。

*   *数据模型*：通常也称为 *`Power Pivot` 数据模型*（这是我更喜欢的说法），这是一种内存数据存储。它可以处理比 Excel 多很多行的数据——在某些情况下可达数千万行——并且通常是 Excel 中数据透视表输出的基础。在处理大型源数据集时，它通常是你使用 `Power Query` 访问的数据的理想目的地，因为数据在内存中被压缩（因此保存到磁盘时占用空间更小），并且可以轻松超过 Excel 工作表的 `1,048,576` 行限制。

数据模型和 `Power Pivot` 本身都是内容广泛的主题，本书将不对它们进行详细讨论。

# 将 Power Query 集成到日常工作流程中

`Power Query` 已完全集成到最新版本的 `Excel` 中。这意味着在导入和分析数据时，你可以将其无缝地用作日常工作的一部分。简而言之：

- 数据源连接、转换例程以及数据加载到 `Excel` 的过程只需创建一次，便可在任何适合的时候重复使用。
- 你可以随时手动触发数据刷新——这些刷新可以是工作簿中所有数据源连接的完全刷新，也可以是你想要的单个数据源刷新。
- 数据源可以在不同 `Excel` 工作簿之间重复使用。
- `Power Query` 处理过程可以在不同 `Excel` 文件之间复制。
- `Power Query` 的处理过程（称为查询）可以通过交互式参数进行管理和扩展，从而创建功能强大的 `ETL` 过程。
- 基于 `Power Query` 的数据流可以使用内置的 `M` 语言进行定制和扩展。

因此，就像处理几乎所有基于 `Excel` 的工作一样，你很可能会一次性构建，然后频繁使用。

# Power Query 的演变

自 `Power Query` 最初作为 `Excel 2010` 的可下载插件问世以来，它经历了多年的显著演变。对于 `Excel 2013`，它仍然是可选的，直到 `2016` 版本才完全集成到 `Excel` 中。事实上，它在当时经历了名称变更，并归入“获取和转换”标题下。

大约从 `2017` 年起——以及自 `Excel 2019` 版本以来——它又恢复为 `Power Query` 的名称。`本书所探讨的就是这个版本。` 这并不意味着你不能将本书描述的技术用于该产品的早期版本。然而，这意味着你用来启动 `Power Query` 的某些 `Excel` 界面方面会与第 `1` 章至第 `5` 章中描述的略有不同。这些差异基本上很小，不会给有经验的 `Excel` 用户带来任何困难。

之所以能够实现这一点，是因为 `Power Query` 是通过一个独立的界面来访问的。它从 `Excel` 内部调用，但存在于其自己的平行宇宙中。这确保了无论你使用哪个版本的 `Excel`，它都具有一致的外观和体验。进入 `Power Query` 的入口点可能因 `Excel` 版本而异——但产品本身保持不变。只需记住，可用的数据源范围取决于你使用的 `Excel` 版本。一些“企业级”数据源仅在 `Excel` 的 `Pro`（专业版）和 `Enterprise`（企业版）订阅中可用。


# 如何使用本书

如果你愿意，可以从头到尾阅读本书，因为它被设计成一个循序渐进的教程，将帮助你学习`Power Query`。然而，由于`Power Query`由四个主要领域组成，本书相应地分为四组章节，分别侧重于该产品的各个关键领域。因此，如果你愿意，你可以专注于`Power Query`中的个别主题，而无需采用线性方式来阅读本书。

- 第`1`章至第`5`章向你展示如何连接到一系列不同的数据源，并使用`Power Query`将这些数据导入`Excel`。根据你需要使用的源数据，你可能只需查阅这些章节的部分内容，即可找到关于如何使用特定源数据类型的指南。
- 第`6`章至第`9`章解释了如何转换和清理数据，以便你可以将其用于分析。这些数据转换的范围从极其简单到可能非常复杂。实际上，它们可能像数据本身一样广阔。你可能永远不需要应用`Power Query`能够提供的所有广泛的数据修改和清理技术——但几乎所有它能做的事情都在这些章节中得到了详细解释。
- 第`10`章和第`11`章解释了如何驯服数据加载和转换的现实世界。在这里，你将学习如何组织和管理你的查询，以及如何添加参数以使它们更具交互性和弹性。
- 第`12`章向你介绍`M`——`Power Query`用于转换数据的语言。使用`M`，你可以将数据导入和转换例程推向仅使用`Power Query`界面根本无法实现的新高度。

最后一点，第 `6`–`12` 章中关于“纯” `Power Query` 的信息是独立于 `Excel` 的。因此，如果你在 `Power BI`、`SQL Server Integration Services` 或 `Power BI Service` 中学习 `Power Query`，你可以找到大量相关信息来协助你的数据转换项目。
