# 21. 结论

我写本书的目的是提供一些实用的代码，让您能快速上手。其中一些主题，比如预测模型，是许多厚重书籍以及成千上万数学、科学和商业相关论文的研究对象。我想展示的是，仅用几行代码就能实现*某些*功能，而无需花费数月或数年时间学习。几十年前，那些控制着旧式大型机的人被称为“高级祭司”——这不一定是一个褒义词。R 有潜力帮助全球各地的人们从数据中获取价值，因此应尽可能使其民主化。显然，如果您需要做更深入的分析，Apress 等出版社提供了许多优秀的书籍，可以帮助您获得所需的专业知识。但每个人在任何一个主题上都有“第一天”。我们不应让基本分析变得过于繁重而阻碍新的 R 语言使用者。成功是动力之源。

除了相对 R 语言较新的人之外，我在写作本书时还考虑到另一类人群：那些偶尔使用 R 并可能忘记具体细节的人。本书概述的内容是我对 R 常见编码问题的最佳回答。对于那些没写过书或尚未写书的人来说，这里有个小秘密：有时作者是为自己而写书，只是希望其他人也能从中受益。当我在工作中遇到需求时，我会将这本书放在手边作为参考。当然，我也可以使用 Google，但那样可能需要浏览大量无关材料。就像电视侦探剧中的 Friday 警官所说：“……只要事实，夫人。”
