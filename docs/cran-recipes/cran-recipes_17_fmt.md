# 13. 正则表达式小结

先苦后甜：这是学习正则表达式的典型结果。`R` 语言包含许多函数，这些函数复制了正则表达式针对特定操作的能力。然而，正则表达式模式匹配的范围超出了传统 `R` 逻辑的范畴。即使只知道几个正则表达式的示例，也能加快你的代码开发速度，并可能减少脚本的执行时间。

我的目的是通过一些相对简单的示例（这些示例在 `R` 中无需修改即可运行）来帮助你入门。正则表达式的流派众多，找到能在 `R` 中运行的代码考验着你的谷歌搜索技能。许多网站在展示示例时并未提及所使用的编程语言。

我的爱好之一是研究历史，所以我要用一个古罗马的类比。在帝国鼎盛时期，罗马军团即使寡不敌众，也常常征服其他军队。除了纪律和训练，他们对敌人还有一个优势——他们训练使用多种武器，而非仅仅一种，比如剑术。这种多才多艺常常为他们扭转战局。同样，掌握正则表达式将成为帮助你实现目标的第二个工具。此外，它也是区分顶尖与中级专业人士的“是/否”式凭证之一。

```R
# 一个简单的正则表达式匹配示例
if (condVar > someVal) {console.log("xxx")}
```
