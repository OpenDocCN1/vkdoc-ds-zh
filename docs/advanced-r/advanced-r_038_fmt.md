在`dplyr`中选取存储数据的部分，与`data.table`的方法论有所不同。请记住，`dplyr`通过函数调用工作。这些函数被设计为独立于底层数据结构。尽管如此，我们仍希望得到相同的最终结果。

按位置选择行是通过`slice()`函数完成的，它接受两个形式参数。第一个是数据对象，在我们的例子中是`diris`，第二个参数允许我们选择特定的行。我们首先只选择前五行：

```
slice(diris, 1:5)
```
