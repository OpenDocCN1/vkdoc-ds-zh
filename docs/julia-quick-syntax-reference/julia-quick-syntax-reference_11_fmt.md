# 第 3 章 控制流与函数

现在你已经了解了 Julia 中可用的主要类型和容器，是时候让它们发挥作用了。

## 3.1 代码块结构与变量作用域

所有典型的流程控制结构（`for`、`while`、`if/else` 和 `do`）都得到支持。其语法通常采用以下形式：

```
<关键字> <条件>
... 块内容...
end
```

例如：

```
for i in 1:5
    println(i)
end
```

注意，条件周围的括号不是必需的，并且块以关键字 `end` 结束。

### 变量作用域

请注意，在块内部，变量的可见性会发生变化，并且 Julia 在这方面比大多数其他语言更严格。

当你定义变量时（例如在 REPL、Atom 或 IJulia Notebook 中），你是在全局作用域中定义它们。

大多数块（`for`、`while`，但值得注意的是 `if` 不是）和函数都会定义新的局部作用域，这些作用域继承自周围的作用域。

全局变量仅被继承用于读取，而不是写入。以下代码片段将导致 `UndefVarError`：未定义的代码错误。

```
a = 4
while a > 2
    a -= 1
end
```

要赋值给全局变量，你需要显式使用 `global`：

```
a = 5
while a > 2
    global a
    println("a: $a")
    b = a
    while b > 2
        println("b: $b")
        b -= 1
    end
    a -= 1
end
```

注意，对 `b` 的赋值仍然是可行的，因为 `b` *不是*全局变量，而是在第一个 `while` 块中定义、然后在第二个块中继承的局部变量。

使用关键字 `local x`，你可以指定变量 `x` 必须被视为一个新的局部变量，与同名的全局变量无关。

滥用全局变量会使代码更难阅读，可能导致意外结果，并且常常是计算瓶颈的根源。请谨慎使用它们！

## 3.2 重复迭代：for 和 while 循环、列表推导、Map

`for` 和 `while` 结构非常灵活。首先，条件可以用多种方式表达：`for i = 1:2`、`for i in anArray`、`while i < 3`……

其次，可以在同一个循环中指定多个条件。考虑这个例子：

```
for i=1:2,j=2:5
    println("i: $i, j: $j")
end
```

在这种情况下，对范围 `1:2` 启动一个较高级别的循环，然后对于每个元素，对 `2:5` 执行一个嵌套循环。

支持 `break` 和 `continue`，并且它们按预期工作——`break` 立即中止循环序列，而 `continue` 立即进入下一次迭代。

Julia 支持其他用于重复迭代的结构，即列表推导和映射。

列表推导本质上是一种编写 `for` 循环的非常简洁的方式：

```
[myfunction(i) for i in [1,2,3]]
[x + 2y for x in [10,20,30], y in [1,2,3]]
```

例如，你可以使用列表推导从一个或多个数组填充字典：

```
[mydict[i]=value for (i, value) in enumerate(mylist)]
[students[name] = sex for (name,sex) in zip(names,sexes)]
```

你可以使用列表推导编写复杂的表达式，例如 `[println("i: $i - j: $j") for i in 1:5, j in 2:5 if i > j]`，但此时或许显式编写循环更好。

`map` 将一个函数应用到一个参数列表。填充字典的同一个例子也可以使用 `map` 编写（效率稍低）：`map((n,s) -> students[n] = s, names, sexes)`

当映射具有单个参数的函数时，该参数可以省略，如下所示：`a = map(f, [1,2,3])` 等价于 `a = map(x->f(x), [1,2,3])`

## 3.3 条件语句：if 块、三元运算符

条件语句可以使用典型的 `if/elseif/else` 结构编写：

```
i = 5
if i == 1
    println("i 是 1")
elseif i == 2
    println("i 是 2")
else
    println("既不是 1 也不是 2")
end
```

可以使用逻辑运算符考虑多个条件：与（`&&`）、或（`||`）和非（`!`）（不要与按位运算符 `&` 和 `|` 混淆）。

注意，当条件语句的结果能在表达式求值结束之前推断出来时，剩余部分将不会被求值（它们被“短路”了）。典型情况是 `&&` 运算符的第一个条件为假，或者 `||` 运算符的条件为真。在这种情况下，求值第二个条件是没用的。

正如列表推导是编写 `for` 循环的简洁方式一样，三元运算符是编写条件语句的简洁方式。

其语法如下：

```
a ? b : c
```

这意味着“如果 `a` 为真，则执行表达式 `b`；否则，执行表达式 `c`”。请确保 `?` 和 `:` 运算符周围有空格。与列表推导一样，重要的是不要滥用三元运算符来编写复杂的条件逻辑。

## 3.4 函数

Julia 的函数非常灵活。它们可以内联定义为 `f(x,y) = 2x+y`，或者使用 `function` 关键字引入自己的块：

```
function f(x)
    x+2
end
```

定义函数的第三种常见方式是创建一个匿名函数并将其赋值给一个命名空间（我们稍后会讨论这一点）。

函数被*定义*后，你可以调用它来执行。请注意，与大多数高级语言一样，在 Julia 中没有一个单独的*声明*函数的步骤。

函数甚至可以嵌套，即函数定义可以嵌入到另一个函数定义内部，或者可以是递归的，即函数定义内部存在对自身的调用。
