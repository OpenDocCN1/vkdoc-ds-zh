你可以使用 `==` 检查两个对象是否具有相同的值，并使用 `===` 检查两个对象是否完全相同（请记住：不可变对象按位检查，可变对象检查其内存地址。）：

- 给定 `a = [1, 2]; b = [1, 2]; a == b` 和 `a === a` 为真，但 `a === b` 为假。
- 给定 `a = (1, 2); b = (1, 2);` 则 `a == b`、`a === a` 和 `a === b` 均为真。

## 2.8 关于数据类型的各种说明

要将对象转换（“强制类型转换”）为不同类型，请使用 `convertedObj = convert(T,x)`。当转换不可能时，例如尝试将 `6.4 Float64` 转换为 `Int64` 值时，将会抛出错误（此例中为 `InexactError`）。

`const` 关键字应用于变量时（例如 `const x = 5`），表示该标识符不能用于绑定不同类型的对象。被引用的对象仍然可以发生改变，或者该标识符可以重新绑定到相同类型的另一个对象（但在后一种情况下会发出警告）。

只有全局变量可以声明为 `const`。

你可以使用点（`.`）运算符将函数“广播”到集合（而非标量）上工作。

例如，要将 `parse` 广播到数组上工作，你可以使用：`myNewList = parse.(Float64,["1.1","1.2"])`。

### 2.8.1 随机数

在 Julia 中很容易获得伪随机数：

- [0,1] 范围内的随机浮点数：`rand()`
- [a,b] 范围内的随机整数：`rand(a:b)`
- 精确到小数点后两位的 [a,b] 范围内的随机浮点数：`rand(a:0.01:b)`
- [a,b] 范围内的随机浮点数：`rand(Uniform(a,b))`（需要 `Distributions` 包）
- 使用特定分布（`Normal`、`Poisson`……）的 [a,b] 范围内的随机浮点数：`rand(DistributionName([distribution parameters]))`

你只需在 `rand()` 中指定所需的大小，即可获得随机数数组或矩阵。例如，`rand(2,3)` 或 `rand(Uniform(a,b),2,3)` 用于生成 2x3 的矩阵。

你可以使用 `import Random:seed!; seed!(1234)` 来“固定”伪随机数生成器的种子。这样做之后，你仍然在处理（伪）随机数，但每次运行 Julia 脚本时生成的序列将是相同的，即生成可重现的输出。如果你之后需要恢复到不可重现的随机性，可以使用不带参数的 `seed!()`。

### 2.8.2 Missing、Nothing 和 NaN

Julia 支持不同的“缺失”概念：

- `nothing`（类型 `Nothing`）：这是不返回任何内容的代码块和函数返回的值。它是单例类型 `Nothing` 的单个实例，更接近于 C 风格的 NULL（有时被称为“软件工程师的 null”）。大多数涉及 `nothing` 值的操作都会导致运行时错误。在某些上下文中，它被显示为 `#NULL`。
- `missing`（类型 `Missing`）：在统计意义上表示一个缺失值。应该有一个值，但你不知道它是什么（因此有时被称为“数据科学家的 null”）。大多数涉及 `missing` 值的操作会（静默地）传播。当容器被声明为 `Union{T,Missing}` 类型时，它们可以高效地处理 `missing` 值。`Missings.jl` 包（[`github.com/JuliaData/Missings.jl`](https://github.com/JuliaData/Missings.jl)）提供了处理缺失元素的额外方法。
- `NaN`（类型 `Float64`）：表示操作结果是非数字值时的情况（例如 `0/0`）。它与 `missing` 类似，会静默传播，而不会导致运行时错误。类似地，Julia 也提供 `Inf`（例如 `1/0`）和 `-Inf`（例如 `-1/0`）。
