# 递归函数

```julia
function fib(n)
    if n == 0 return 0
    elseif n == 1 return 1
    else
        return fib(n-1) + fib(n-2)
    end
end
```

在 Julia 社区中，函数调用遵循以下规则被认为是良好的编程实践：

- 函数调用应包含其逻辑所需的所有元素（即，除了常量全局变量外，不读取其他变量）。
- 函数不应更改程序中参数以外的任何其他部分（即，除了最终修改其参数外，不会产生任何“副作用”）。

遵循这些规则将帮助你编写出快速、可靠（每个函数的输出唯一地取决于其输入集合）且易于阅读和调试的代码。

### 3.4.1 参数

函数参数通常按位置指定（`位置参数`）。但是，如果在函数定义的参数列表中使用了分号（`;`），则该分号之后列出的参数必须按名称指定（`关键字参数`）。

函数调用必须遵守这种区别，按位置调用位置参数，按名称调用关键字参数。换句话说，不能按名称调用位置参数，也不能按位置调用关键字参数。

最后的参数（无论是位置参数还是关键字参数）都可以指定一个默认值。例如：

- 定义：`myfunction(a,b=1;c=2) = (a+b+c)`（定义包含两个位置参数和一个关键字参数）
- 函数调用：`myfunction(1,c=3)`（调用 `(1+1+3)`）请注意，调用中未提供 `b`，因此使用了默认值。

你可以选择通过使用类型注释参数来限制函数应接受的参数类型：

```julia
myfunction(a::Int64,b::Int64=1;c::Int64=2) = (a+b+c)
```

指定参数类型的原因与其说是为了获得速度提升。Julia 会尝试解析可能的参数类型和返回值，只有在极少数情况下，它才无法将返回类型唯一确定为输入类型的函数。在这些情况下（类型不稳定），指定参数类型可能有助于解决类型不稳定问题。

限制参数类型最重要的原因是为了尽早捕获错误，当函数被意外地使用其设计时未考虑的参数类型调用时。在这种情况下，如果函数被注释了允许的参数类型，Julia 将向用户返回一个有用的错误消息，而不是默默地尝试使用该参数。

然而，一种常见情况是，你希望函数处理给定参数的单个值（标量）或向量。你然后有两个选择：

- 你可以编写处理标量的函数，然后在调用时依赖点符号来广播该函数（稍后讨论）。
- 或者，你可能希望在函数定义中直接处理这个问题。在这种情况下，你可以使用联合类型将参数声明为标量类型 `T` 或向量 `T`。例如：`function f(par::Union{Float64, Vector{Float64}}) [...] end`。然后，你可以通过使用 `typeof` 检查参数类型来实现你想要的逻辑。

最后，Julia 中的函数也可以接受可变数量的参数。展开运算符（即省略号 `...`）可以在函数定义的参数声明中指定可变数量的参数，并可以在函数调用中“拼接”参数列表或数组：

```julia
values = [1,2,3]

function additionalAverage(init, args...)
    # 使用省略号的参数必须是最后一个
    s = 0
    for arg in args
        s += arg
    end
    return init + s/length(args)
end

a = additionalAverage(10,1,2,3) # 12.0
a = additionalAverage(10, values ...) # 12.0
```

### 3.4.2 返回值

使用 `return` 关键字提供返回值是可选的。默认情况下，函数返回最后计算的值。

通常，`return` 用于立即终止函数，例如，在出现某些条件时。请注意，返回值也可以是一个元组（一次性返回多个值）：

```julia
myfunction(a,b) = a*2,b+2

x,y = myfunction(1,2)
```

### 3.4.3 多重分派（即多态）

当类似的逻辑应应用于不同类型（即不同的类型）的对象时，你可以编写共享相同名称但具有不同类型或不同数量参数（以及不同实现）的函数。这极大地简化了应用程序的应用程序编程接口，因为只需要记住一个名称。

调用此类函数时，Julia 会根据调用中的参数选择正确的函数，默认选择更严格的版本。

这些不同的版本在 Julia 中被称为`方法`，如果函数是类型安全的，分派是在编译时实现的，速度非常快。

你可以通过使用 `methods(myfunction)` 列出给定函数的所有方法。

多重分派多态是面向对象运行时多态的一种泛化，其中相同的函数名称根据对象的类执行不同的任务。传统面向对象语言中的多态仅应用于单个元素，而在 Julia 中，它应用于所有函数参数（但面向对象语言在编译时确实具有多参数多态性）。

在处理第 4 章中的类型继承时，我将更深入地探讨多重分派。

### 3.4.4 模板（类型参数化）

可以指定函数操作的类型。你可以通过使用`模板`来实现这一点：

```julia
myfunction(x::T, y::T2, z::T2) where {T <: Number, T2} = x + y + z
```

此函数首先定义了两个类型，`T`（`Number` 的子集）和 `T2`，然后指定每个参数必须属于这两个类型中的哪一个。

你可以使用 `(1,2,3)` 或 `(1,2.5,3.5)` 作为参数来调用它，但不能使用 `(1,2,3.5)`，因为 `myfunction` 的定义要求第二个和第三个参数必须是相同的类型（无论是什么）。

### 3.4.5 函数作为对象

函数本身也是对象，可以赋值给新变量、返回或嵌套。请看这个例子：

```julia
f(x) = 2x # 内联定义一个函数 f

a = f(2) # 调用 f 并将返回值赋给 a。àìs 是一个值

a = f # 将 f 绑定到一个新的变量名。àìs 现在是一个函数

a(5) # 再次调用（相同的）函数
```

### 3.4.6 按引用传递/按值传递

Julia 函数使用一种约定进行调用——在其他语言中有时被称为`按共享传递`——它某种程度上介于传统的`按引用传递`（仅将指向原始变量的内存指针传递给函数）和`按值传递`（传递变量的副本，函数在此副本上操作）之间。

在 Julia 中，函数操作新的局部变量，这些变量仅在函数内部已知。将变量赋值给另一个对象不会影响原始变量。但是，如果与变量绑定的对象是可变的（例如，数组），则此对象的*修改*也将应用于原始变量：

```julia
function f(x,y)
    x = 10
    y[1] = 10
end

x = 1
y = [1,1]
f(x,y) # x 不会改变，但 y 现在将变为 [10,1]
```

（另请参阅第 2 章末尾的“内存和复制问题”部分。）按约定，会修改其参数的函数，其名称后跟一个 `!`。例如，`myfunction!(ref_par, other_pars)`。仍然按约定，第一个参数是将会被修改的那个。

### 3.4.7 匿名函数（即“Lambda”函数）

有时你不需要命名一个函数（例如，当函数是传递给高阶函数（如 `map` 函数）的参数之一时）。要定义匿名（无名）函数，你可以使用 `->` 语法，如下所示：

```julia
x -> x² + 2x - 1
```

这定义了一个无名函数，它接受一个参数 `x`，并产生 `x² + 2x - 1`。可以使用元组提供多个参数，如下所示：

```julia
(x,y,z) -> x + y + z
```

你仍然可以这样将匿名函数赋值给一个变量：

```julia
f = (x,y) -> x+y
```

不要将用于定义匿名函数的单箭头 `->` 与用于定义键值对（例如，在字典中）的双箭头 `=>` 混淆。

### 3.4.8 广播函数

你经常会有一个设计用于处理标量的函数，但你想将其重复应用于容器内的值，例如数组的元素。你可以不编写 `for` 循环，而是依赖 Julia 的原生功能，即`广播`函数到你希望的元素上。

例如，考虑以下函数：

```julia
f1(a::Int64,b::Int64) = a*b
```

它期望输入两个标量。例如：

```julia
f1(2,3)
```

但是，如果 `a` 和 `b` 是向量（例如 `a=[2,3]` 和 `b=[3,4]`）呢？你不能直接调用函数 `f1([2,3],[3,4])`。解决方案是使用 `broadcast()` 函数，该函数将原始函数作为其第一个参数，后跟原始函数的参数：

```julia
broadcast(f1,[2,3],[3,4])
```

输出是一个向量，其中包含原始函数首先应用于 `(a=2,b=3)`，然后应用于 `(a=3,b=4)` 的结果。

一个方便的广播快捷方式是使用点符号，即原始函数名后跟一个点：`f1.([2,3],[3,4])`。

有时原始函数本身接受一些参数作为向量，而你想将广播限制在标量参数上。在这种情况下，你可以使用`Ref()`函数来保护你不想被广播的参数：

```julia
f2(a::Int64,b::Int64,c::Array{Int64,1},d::Array{Int64,1}) = a*b+sum(c)-sum(d)

f2(1,2,[1,2,3],[0,0,1]) # 不带广播的正常调用
f2.([1,1,1],[2,2,2],Ref([1,2,3]),Ref([0,0,1])) # 仅广播前两个参数
```

#### 3.5 Do 块

我们通过分析 do 块来结束本章。Do 块允许开发人员定义作为参数传递给外部函数的“匿名”函数。

例如，你编写`f1(f2,x,y) = f2(x+1,x+2)+y`。要使用这个`f1`函数，你首先需要另一个函数来充当`f2`（内部函数）。

你可以将其定义为`f2(g,z) = g*z`，然后调用`f1`作为`f1(f2,2,8)`。

每当第一个参数是一个函数时，这都可以*事后*用 do 块来编写。因此，你可以使用 do 块获得相同的结果：

```julia
f1(2,8) do i,j
    i*j
end
```

这将`i`和`j`定义为可供 do 块使用的局部变量。它们的值在`f1`函数中确定（在这种情况下，`i=2+1`和`j=2+2`）。然后，块计算的结果作为充当`f1`第一个参数的函数的输出提供。同样，此值的用途由`f1`函数的定义指定（在这种情况下，值`8`被加到它上面，得到`20`，即返回值）。

Do 块的另一个典型用途是在输入/输出操作中，如第 5 章所述。

#### 3.6 退出 Julia

要退出正在运行的 Julia 会话，请按`Ctrl+D`（或在可能的情况下使用`Ctrl+C`抛出`InterruptException`，无需关闭进程即可重新获得对 Julia 提示符的控制）。

要以编程方式退出脚本，请使用`exit(exit_code)`，其中默认的零退出码按约定表示程序正常终止。

最后，有时你希望能够定义在 Julia 进程退出时运行的代码。这正是`atexit(f)`函数的作用。它允许你定义一个零参数函数`f()`，该函数将在退出时被调用。

例如，你可以使用它在调用给定函数时启动一个新的“干净 Julia 会话”。作为示例，在你的全局或本地的`startup.jl`文件中键入以下函数：

```julia
function workspace()
    atexit() do
        run(`$(Base.julia_cmd())`)
    end
    exit()
end
```

现在，每当调用`workspace()`函数时，当前的 Julia 进程将被关闭，并启动一个新进程（请注意，`workspace`是先前 Julia 版本中一个清理工作区函数的名称；它不再可用。此脚本复制了其功能，尽管代价是强制重启整个 Julia 进程。）。

### 第 4 章：自定义类型

第 2 章“数据类型与结构”讨论了内置类型，包括容器。在本章中，我们将研究如何创建用户定义的类型。

类型与结构

让我们在 Julia 语言的背景下澄清这两个术语。

用通俗的英语来说，一个对象的*类型*指的是描述该对象的一组特征。例如，一个 sheet 类型的对象可以用其尺寸、重量、大小或颜色来描述。

Julia 中的所有值都是属于给定类型的真实对象（它们是给定类型的各个“实例”）。

Julia 类型包括所谓的*原始类型*（由固定数量的比特组成，如所有数值类型，如`Int64`、`Float64`和`Char`）和*复合类型*或*结构*，其中对象的特征是使用多个字段和可变数量的比特来描述的。

*结构*和*原始类型*都可以由用户定义，并且是分层组织的。*结构*大致对应于其他语言中所谓的*类*。

在处理类型时，有两个运算符特别重要：

- `::`运算符用于约束对象属于给定类型。例如，`a::B`意味着“a 必须是 B 类型”。
- `<:`运算符具有类似含义，但稍微宽松一些，因为对象可以是给定类型的任何子类型。例如，`A<:B`意味着“A 必须是 B 的子类型”，即 B 是“父”类型，A 是它的“子”类型。

使用这些运算符的主要原因是为了确认程序按预期方式工作。在某些情况下，提供这些额外信息也可以提高性能。

#### 4.1 原始类型定义

用户定义的原始类型使用关键字`primitive type`及其名称和所需的比特数来定义：

```
primitive type [名称] [比特数] end
```

例如：

```julia
primitive type My10KBBuffer 81920 end
```

Julia 的一个（当前）限制是比特数必须是 8 的倍数且小于 8388608。

也可以选择指定父类型，如下所示：

```
primitive type [名称] <: [超类型] [比特数] end
```

请注意，具有相同比特数的两个用户定义类型的内部表示是完全相同的。唯一改变的是它们的名称，但这是一个重要的区别：当这些类型的对象作为参数传递时，函数的行为方式会改变，也就是说，在整个程序中使用命名类型来区分它们，而不是它们的实现。

#### 4.2 结构定义

要定义结构，请使用关键字`mutable struct`，为结构指定一个名称，指定字段，并使用`end`关键字结束定义：

```julia
mutable struct MyOwnType
    field1
    field2::String
    field3::Int64
end
```

请注意，虽然你可以选择将每个单独的字段定义为给定类型（例如，`field3::Int64`），但不能将字段定义为给定类型的子类型（例如，`field3<:Number`）。为此，你可以在结构定义中使用模板：

```julia
mutable struct MyOwnType{T<:Number}
    field1
    field2::String
    field3::T
end
```

使用模板，结构的定义会在首次构造一个其`field3`为`T`类型的对象时动态创建。

用于注释单个字段的类型可以是原始类型（如前面的示例），也可以是对另一个结构的引用（请参见后面的示例）。

还要注意，与 Julia 不同，与其他高级语言（例如 Python）不同，你不能在定义结构后添加或删除字段。如果你需要此功能，则必须使用字典，但请注意，你将牺牲这种灵活性来换取更差的性能。

相反，为了获得性能（但同样牺牲了灵活性），你可以在`struct`前省略`mutable`关键字。这样，一旦创建了该类型的对象，其字段就不能再更改（即，结构默认是不可变的）。

请注意，可变对象（如数组）在不可变结构中仍然是可变的。

#### 4.3 对象初始化与使用

定义自定义类型（原始类型或结构）后，你可以从该类型初始化任意数量的对象：

```julia
myObject = MyOwnType("something","something",10)
a = myObject.field3 # 10
myObject.field3 = 20 # 仅当 myObject 是可变结构时
```

请注意，你必须按照结构定义中指定的相同顺序使用值来初始化对象。你不能按名称初始化对象（为此，请考虑使用具名元组）：

```julia
MyOwnType(field3 = 10, field1 = "something", field2 = "something") # 错误！
```

要访问对象字段或更改其值，你可以像大多数其他语言一样，使用`object.field`语法。

函数与结构

请注意，处理对象的函数不是在类型定义中定义或声明的，即它们不与特定类型相关联。

这意味着，在 Julia 中，你不需要像调用对象方法那样使用`myobj.func(x,y)`，而是将对象作为参数传递，例如`func(myobj,x,y)`，无论它是作为第一个、第二个还是更后面的参数。

#### 4.4 抽象类型与继承

你可以使用关键字`abstract type`创建抽象类型。抽象类型不允许包含任何字段，也不能从中实例化对象。相反，带有字段的具体类型可以被定义为它们的子类型，并从它们实例化对象。一个允许抽象类实际持有字段的问题（请参见 https://github.com/JuliaLang/julia/issues/4935）目前是开放的，可能会在 Julia 的下一个主要版本中实现。

你可以创建整个抽象类型层次结构，尽管当前不支持多重继承（一个类型是多个类型的子类型）：

### 4.4.1 在 Julia 中实现面向对象范式

Julia 既支持继承也支持组合模型，尽管支持程度不同。

继承就是你刚才看到的，当一个类型的层次结构通过将一个类型声明为另一个类型的子类型来获得时。你也看到了在 Julia 中使用继承的局限性，即只能继承行为（而不是结构）。

那么，如何在 Julia 中实现面向对象模型呢？嗯，Julia 社区的偏好是使用组合而非继承。

组合是指你将给定类型的一个字段声明为另一个复合类型的对象。通过这个（被引用的）对象，你就可以访问另一个类型的字段。

考虑以下示例，你首先定义一个通用的 `Person` 结构，然后再定义两个更具体的 `Student` 和 `Employee` 结构：

```julia
struct Shoes
    shoesType::String
    colour::String
end

struct Person
    myname::String
    age::Int64
end

struct Student
    p::Person
    school::String
    shoes::Shoes
end

struct Employee
    p::Person
    monthlyIncomes::Float64
    company::String
    shoes::Shoes
end
```

你没有使用继承将 `Student` 和 `Employee` 声明为 `Person` 的子类型，而是使用组合为两者都分配了一个 `Person` 类型的字段 `p`。正是由于这个字段，你无需重复两者共有的字段。

类型必须先定义，然后才能用于引用对象。因此，`Shoes` 的定义必须放在 `Students` 和 `Employee` 定义之前。

然后，你可以创建专门类型的实例，要么先创建引用的对象，要么在专门类型的构造函数中内联创建：

```julia
gymShoes = Shoes("gym","white")
proShoes = Shoes("classical","brown")

Marc = Student(Person("Marc",15),"Divine School",gymShoes)
MrBrown = Employee(Person("Brown",45),3200.0,"ABC Corporation Inc.", proShoes)
```

最后，你可以使用多重分派为专门类型提供定制实现，并通过点（`.`）运算符的链式使用来访问引用的对象和/或通用字段：

```julia
function printMyActivity(self::Student)
    println("嗨！我是 $(self.p.myname)，我在 $(self.school) 学校学习，我穿 $(self.shoes.colour) 颜色的鞋子")
end

function printMyActivity(self::Employee)
    println("你好。我的名字是 $(self.p.myname)，我在 $(self.company) 公司工作，我穿 $(self.shoes.colour) 颜色的鞋子")
end

printMyActivity(Marc) # 嗨！我是 Marc，...
printMyActivity(MrBrown) # 你好。我的名字是 MrBrown，...
```

虽然明智地使用继承在实际中可以满足你可能遇到的许多建模设计情况，但 Julia 核心语言在表现力方面确实有所欠缺，因为你无法直接考虑和/或区分对象之间关系的不同概念，如特化（例如，`Person→Student`）、组合（例如，`Person→Arm`）和弱关系（例如，`Person→Shoes`）。

为了解决这个不足，已经发布了一些第三方包（本书未讨论）来提高 Julia 在这个领域的灵活性，例如用于模拟多重继承的 `SimpleTraits` 包，或用于自动将字段声明从父类型复制到子类型的 `OOPMacro.jl`。

### 4.5 与类型相关的一些有用函数

为了完成关于用户定义类型的讨论，你可能会发现以下与类型相关的函数很有用：

- `supertype(MyType)`：返回一个类型的父类型
- `subtypes(MyType)`：列出一个类型的所有子类型
- `fieldnames(MyType)`：查询一个结构的所有字段
- `isa(obj,MyType)`：检查 `obj` 是否是 `MyType` 类型
- `typeof(obj)`：返回 `obj` 的类型
- `eltype(obj)`：返回集合的内部元素类型，例如数组的内部元素

#### 5.1 读取（输入）

##### 5.1.1 从终端读取

- `aString = readline()`：读取用户输入到终端的任何内容，直到按下 `Enter`。

- `anInteger = parse(Int64, readline())`：读取用户在终端输入的数字。

让我们注意，你很少需要这个。Julia 是交互式的，你可以直接通过终端或正在使用的编辑器运行代码片段或更改变量。

尽管如此，你可以创建一个 Julia 脚本（如下例所示）并运行它（使用 `julia myScript.jl` 或在 Julia 提示符中使用 `include("myScript.jl")`）。这将模拟经典的“脚本”行为，用户运行脚本时无法完全控制它，只能输入脚本请求的用户输入：

```julia
println("欢迎来到 Julia 脚本\n\n")

function getUserInput(T=String,msg="")
    print("$msg ")
    if T == String
        return readline()
    else
        try
            return parse(T,readline())
        catch
            println("抱歉，我无法解释你的答案。请再试一次")
            getUserInput(T,msg)
        end
    end
end

sentence = getUserInput(String,"你想重复哪句话？");
n = getUserInput(Int64,"你想重复多少次？");
[println(sentence) for i in 1:n]
println("完成！")
```

请注意，在此代码片段中，函数使用运行时异常来确保用户的响应与你想要的类型兼容。你将在第 8 章中了解更多关于运行时异常的信息。

##### 5.1.2 从文件读取

Julia 中的文件读取（以及你将看到的写入）与其他语言相似。

你打开文件，指定模式（`r`，代表“reading”），将文件绑定到一个对象，对该对象进行操作，并在完成时 `close()` 它。

一个更好的选择是将文件操作封装在一个 do 块中，该块会在块结束时自动关闭文件。

- 一次性读取整个文件：

```julia
open("afile.txt", "r") do f # "r" 代表读取
    filecontent = read(f,String) # 注意它只能使用一次。如果第二次使用而不重新打开文件，read() 将返回一个空字符串
end
```
