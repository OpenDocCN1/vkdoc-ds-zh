# 1. 探索机器学习

本章介绍了最佳的机器学习方法，并详细说明了监督式机器学习与非监督式机器学习的主要区别。它还讨论了这两种方法的各种应用。

机器学习已经存在了很长时间；然而，直到最近才获得广泛认可。这是因为现代计算机系统的计算能力增强，以及开源平台和框架的易用性。机器学习涉及通过实施各种编程和统计技术来赋予计算机系统智能。它借鉴了统计学、计算语言学和神经科学等领域。它还应用了现代统计学和基础编程。它使开发人员能够开发和部署智能计算机系统，并创建实用且可靠的应用程序。

## 探索监督式方法

监督式学习涉及向机器学习算法提供大量数据集，算法通过该数据集学习所需的输出。主要的机器学习方法有线性方法、非线性方法和集成方法。以下部分将让您熟悉参数方法，也称为线性回归方法。参见表1-1。

线性回归方法期望数据遵循高斯分布。普通最小二乘法是标准的线性方法；它最小化误差项，并确定斜率和截距，以使数据拟合一条直线（其中因变量是连续的）。

此外，普通最小二乘法确定了特征之间关联的程度。它还假设线性关系、残差中无自相关且无多重共线性。在现实世界中，数据几乎从不来自正态分布；该方法难以解释变异性，导致模型欠拟合或过拟合。为了解决这个问题，我们在方程中引入一个惩罚项来改变模型的性能。

**表1-1** 参数方法类型

| 模型 | 描述 |
| --- | --- |
| 线性回归方法 | 当有一个因变量（连续特征）和一个自变量（连续或分类特征）时应用。主要的线性回归方法有`GLM`、`Ridge`、`Lasso`、`Elastic Net`等。 |
| 生存回归方法 | 应用于与时间事件相关的删失数据，其中因变量是分类的，自变量是连续的。 |
| 时间序列分析方法 | 应用于发现序列数据中的模式并预测未来实例。主要的时间序列模型包括`ARIMA`模型、`SARIMA`、`Additive`模型等。 |

### 探索非线性模型

非线性（分类）方法用于区分不同类别（也称为分类或标签）——见表1-2。当因变量特征中存在两个类别时，你将实施二分类方法。当存在两个以上类别时，你将实施多分类方法。分类函数数不胜数，包括 `sigmoid`、`双曲正切` 和 `核函数` 等。其应用取决于具体情境。后续章节将介绍其中部分函数。

**表1-2** 不同的非线性模型

| 模型 | 描述 |
| --- | --- |
| 二分类方法 | 适用于分类特征仅有两个可能结果的情况。常用的二分类器是逻辑回归模型。 |
| 多分类方法 | 适用于分类特征有两个以上可能结果的情况。主要的多分类器是线性判别分析模型（也可用于降维）。 |
| 生存分类 | 适用于使用分类特征计算事件发生概率的情况。 |

### 探索集成方法

集成方法使你能够揭示线性和非线性关系。主要的集成方法是随机森林树，它通常计算量很大。此外，其性能取决于多种因素，如树的深度、迭代次数、数据划分和提升方法。

## 探索无监督方法

与监督式机器学习相反，无监督学习不包含真实标签。你将模型暴露于所有样本数据，让其自行猜测数据的模式。最常见的无监督方法是与聚类相关的方法。

### 探索聚类方法

聚类方法便于将数据中的公共值聚合在一起；它们使你能够发现结构化和非结构化数据中的模式。表1-3重点介绍了几种可用于猜测数据模式的聚类方法。

**表1-3** 不同的聚类模型

| 技术 | 描述 |
| --- | --- |
| 质心聚类 | 用于确定数据的中心，并将数据点向中心拉拢。主要的质心聚类方法是 `k-means` 方法。 |
| 密度聚类 | 用于确定数据集中分布的区域。主要的密度聚类模型是 `DBSCAN` 方法。 |
| 分布聚类 | 基于某种分布识别数据点属于某个聚类的概率。主要的分布聚类方法是 `高斯混合` 方法。 |

## 探索深度学习

深度学习是机器学习的延伸，它利用人工神经网络来解决复杂问题。你可以使用深度学习来发现大数据中的模式。深度学习使用人工神经网络来发现复杂数据中的模式。这些网络采用类似于动物的方法，即从环境接收输入数据的神经元（节点）扫描输入，并将其传递给后续层中的神经元，最终得出某种输出（即理解数据中的复杂性）。根据具体情境，有几种人工神经网络可用于确定某种现象的行为模式。表1-5重点介绍了主要的神经网络。

**表1-5** 不同的神经网络

| 网络 | 描述 |
| --- | --- |
| 受限玻尔兹曼机 (RBM) | 最常见的神经网络，仅包含隐藏层和可见层。 |
| 多层感知器 (MLP) | 一种神经网络，通过增加输入层、隐藏层和输出层来扩展受限玻尔兹曼机。 |
| 循环神经网络 (RNN) | 用作序列建模器。 |
| 卷积神经网络 (CNN) | 用作降维器和分类器。 |

## 本章小结

本章介绍了机器学习的两种方式——监督式学习和无监督学习。首先解释了监督式机器学习，并讨论了三种监督式学习方法及其应用。然后介绍了无监督学习技术、降维和聚类分析。
