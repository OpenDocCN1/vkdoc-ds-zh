# 引言

《快速上手：Power BI 中的 DAX》是一本浓缩的自学资源，旨在帮助你在 Power BI Desktop 中学习 DAX。DAX（数据分析表达式）是 Microsoft Power BI 的公式语言，最初于 2009 年作为 Excel 加载项 Power Pivot（Power BI 的前身）的编程语言引入。随着 Power BI 作为首选数据分析平台被日益广泛采用，掌握 DAX 正迅速成为发现并分享数据重要见解的必要能力。本书专为非技术用户编写，是一本简明指南，聚焦于支撑该语言的核心概念，带你从零基础起步，直至能够使用 DAX 编写在数据报告中常常必需的具有挑战性的计算。

如果你需要使用 DAX，已有大量学习资源：书籍、视频，以及众多专家提供的各种观点和海量令人费解的 DAX 代码示例——你可以直接复制粘贴使用这些代码，而无需理解其工作原理。然而，即便有这些资源的帮助，关于 DAX 的抱怨依然不绝于耳：“DAX 太难了”！但这是一个误解，也是你学习 DAX 时将遇到的第一个障碍。尽管 DAX 的理解过程无疑常具挑战性，但将其贴上“困难”的标签，对于那些未曾努力理解其底层机制的人来说，或许更像是一种借口。

当你摆脱了“DAX 很难”的误解，并决定要理解 DAX 的工作原理时，目前你会面临两个障碍，而本书将逐一攻克。首先，许多资源是专门为 DAX 开发者或其他高技能技术人员编写的。然而，本书的目标读者是 Excel 用户或没有技术或编程背景的人。事实上，它面向的可能正是像你一样，只想在完成日常工作的同时，成为一名熟练的 DAX 用户的人。本书假定读者仅具备少量技术知识。复杂的概念均通过易于理解的示例来解释，确保每个人都能看懂，并且内容结构设计旨在逐步建立使用 DAX 的信心。你将会遇到的第二个障碍是，大多数关于 DAX 的书籍可被视为“参考手册”。例如，《DAX 权威指南》¹ 篇幅超过 700 页，详述了 DAX 的方方面面。你可能会觉得，将此类作品用作“自学”资源会令人望而生畏，因为信息量过大会很快让人不知所措。要快速上手 DAX，没有必要费力翻阅大量关于生僻 DAX 函数和技术细节的篇章。只有少数几个核心概念必须在掌握 DAX 之前得以充分理解，而本书正是聚焦于这些概念。另外，你可能也希望用一种更易消化、更省时间的方式来学习 DAX。正因如此，我认为有必要采用一种更简洁的方法来解释 DAX 语言。

为充分利用本书信息，若你已是 Power BI Desktop 的熟练用户将更具优势。这包括能够创建数据模型并使用 Power BI 的数据可视化功能生成报告。然而，在需要特定知识的领域，我会提供相应信息的链接供你自行探索。你会发现，在后续的每一章中，本书都会建立在之前获得的知识和技能之上；到最后一章时，你将掌握必要的 DAX 知识，能够编写复杂的计算。

在第 1 章至第 3 章，我们涵盖了你开始编写 DAX 表达式前所需的预备知识，例如理解数据模型的结构以及使用 DAX 语法。然后你将能够创建一些基本的计算列和度量值。你会发现，到此为止，DAX 绝对很简单！随后，在第 4 章，我们将探讨第一个主要的 DAX 概念——计值上下文。在这里，我们研究计算列和度量值在计算方式上的显著区别。接着，在第 5 章，我们将引导你进入第二个重要概念——理解迭代器，即对表的每一行执行计算，就像你在 Excel 中向下复制公式一样。

在第 6 章，你对 DAX 的理解将迈出一大步，你将遇到 DAX 中最重要的函数——`CALCULATE`。正是在这个节点，你将开始将 DAX 作为一种编程语言来使用，表达式的计算结果将在内存中完成。也正是在这里，DAX 在概念上开始与 Excel 分道扬镳，你将能够编写出比简单的求和与平均值更强大的计算。

# 在第 7 章中，我们探讨了用于生成内存中虚拟表的表表达式概念。随着你进入 DAX 更高级的领域，你会开始意识到大多数 DAX 表达式都涉及生成这些虚拟表。这些虚拟表通常是真实表的子集，用于通过编程方式筛选数据，为通过 DAX 度量值进行聚合做准备。此时，你可能会觉得 DAX 确实变得更具挑战性。这是因为你看不到虚拟表，只能想象它们的存在，而表达式内部的工作机制对我们来说大多是隐藏的。

一旦你完成了第 8 章中我们对`ALL`函数的详细学习（该函数与`CALCULATE`一起构成了大多数 DAX 表达式），你就准备好使用 DAX 来解决各种数据分析场景了。例如，在第 9 章中，你将学习如何跨时间段比较数据；在第 12 章中，你将学习如何使用参数表创建用户驱动的计算。在第 14 章中，你将发现如何跨数据类别进行动态比较，例如找出购买了产品“X”的客户是否也购买了产品“Y”。

第 15 章将带你进入所有 DAX 概念中最具挑战性的一个——上下文转换。你将学习如何在更高的粒度级别上执行聚合。一旦掌握了这个概念的用法，你能发现的数据洞察列表将大大增加。你将能够按销售额对客户或产品进行排名，将合计值分入数值范围，动态查找按价值计算的前后百分比，并计算多年、多季度和多月的平均总销售额。事实上，你编写的大多数 DAX 计算都会以某种方式用到上下文转换。

这看起来可能有点奇怪，直到你即将完成 DAX 的学习之旅时，我们才最终告诉你 DAX 真正的工作原理以及所有部分是如何组合在一起的。原因在于，只有当你读到第 18 章时，你才具备了理解最后一个 DAX 概念——表扩展——所需的技能。尽管这个概念在很大程度上是理论性的，但一旦你了解了当表达式被评估时数据模型在幕后如何运作，你在本书中积累的知识就会豁然开朗。最终，在第 18 章中，DAX 拼图的所有碎片都拼合在了一起，此时你已成为一名成熟的 DAX 专家。

最后，就我个人而言，我写了这本我希望在我最初学习 DAX 时就能读到的书，那还是在 Power Pivot 刚推出的年代。当时能帮助我的资料非常少，我从未忘记自己花费无数个小时来解读 DAX 代码，最终达到“是的，我能行！”的境界。我希望，在这本书的帮助下，你的学习之路能更轻松一些，并且随着 DAX 像 Excel 公式一样成为主流，这本书能成为一个有用的资源。

我们也不要忘记学习 DAX 的目标，它本身并非终点。学习 DAX 不是为了通过炫耀编写大量 DAX 代码的技能来给你的同事留下深刻印象。不，学习 DAX 的目标是作为一种达到目的的手段。它让你能够以那些直到现在还让你苦苦寻找洞察的方式来分析你的数据。

> *“目标是将数据转化为信息，再将信息转化为洞察。”*^(²)
