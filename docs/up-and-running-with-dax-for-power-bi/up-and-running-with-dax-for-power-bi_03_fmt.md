# 致谢

写作一本书常常是一种孤独的体验，但一本书只有在外界的帮助下才能结出硕果。我想感谢并致谢我身边的那些专业人士和家人，他们在协助我撰写本书的过程中发挥了重要作用。

首先，非常感谢我的技术审校 Jake Halsey，他提供了宝贵且鼓舞人心的评论，并对众多 DAX 示例和代码清单进行了彻底审阅。我还要感谢 Apress 的策划编辑 Joan Murray，她在收到全书原稿后，同意出版一本以非技术为重点的 DAX 书籍是有益的。我也很感谢我的协调编辑 Jill Balzano，她专业的工作方式使得与 Apress 的合作成为一种愉快的体验。

最后但同样重要的是，我衷心并永远感谢我的家人始终如一的支持和鼓励，没有他们，我很难坚持完成这本书。
