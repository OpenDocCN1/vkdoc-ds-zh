# 自助式分析

凭借易于学习的用户界面和强大的数据源连接器，`Tableau`颠覆了商业智能软件行业，并在老牌商业智能供应商艰难适应的同时，实现了十倍的增长。其他初创公司也纷纷定位自己，将自助服务模式引入其他领域，如`OLAP`和机器学习。

---

这不是另一本炒作大数据的书。拍字节的数据如果不能回答某个业务问题，就一文不值；数字经济产生的海量数据只是管理者必须面对的一个事实。无论你管理一家跨国公司还是驾驶卡车，你的业务产生的数据都比以往任何时候都多；你要么利用它，要么舍弃它，但无论如何，你必须做出明智的决策。

在一个被颠覆的商业分析市场中，管理者必须无情地将重点放在对洞察的需求上，然后构建满足这些需求的系统和流程。理解这些章节中描述的创新是实现这一目标的一步，但重点必须始终放在对洞察的需求以及提供洞察的价值链上。

创新并非一蹴而就地完整诞生于发明家的头脑中；它们是长期修修补补过程的最终结果。我们在本书中描述的许多最重要的创新已有超过 50 年的历史；它们如今的出现是出于各种原因，例如计算成本的长期下降。我们在本书的几个地方提供了历史视角，以便读者能够区分哪些是真正的新事物，哪些仅仅是重新包装和更名。

在本书的中间章节，我们概述了商业分析领域的一项关键创新。这些章节包含了关于现有软件产品和开源项目的详细信息。总的来说，我们的前提是这些行业领导者有充足的营销预算来建立其产品的知名度，因此我们不涵盖它们的产品。

我们以一本管理者手册作为本书的结尾：从颠覆性创新中获利的特定策略。其中一些策略可能看起来激进；如果这让你感到不安，请放下这本书——它不适合你。但如果你准备好拥抱颠覆性创新，并从中获利，那就请继续读下去。
