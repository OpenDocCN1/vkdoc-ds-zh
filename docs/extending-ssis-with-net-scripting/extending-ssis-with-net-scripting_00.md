



## 引言

Microsoft SQL Server 集成服务（SSIS）是数据集成、数据整合和数据转换领域的领先工具之一。ETL 开发人员、数据库管理员和数据分析师使用它在 ETL（提取、加载和转换）过程中提取、转换和加载数据，或执行维护任务。虽然有很多现成的任务、源、转换和目标组件可以满足大多数人的需求，但它们永远无法覆盖所有人的全部需求。

有时，你需要针对自己的情况使用非常具体的功能，而这些功能对大多数人来说并无用处；或者 ICT 领域的持续发展速度远快于你正在使用的 SSIS 版本；当然，有时你也会纳闷为什么微软没有包含 ZIP 任务、SFTP 任务或 XML 目标组件。这正是本书的写作目的。

# 本书读者对象

你已有创建`SSIS`包的经验，但遇到了现成任务和转换的一些局限性。你不是经验丰富的程序员，但也许你曾调整过`Excel`宏，或为你的网站添加过一些简单的`JavaScript`。至少，如果你能得到一些好的指导，你并不会害怕使用一些脚本。

或者，你可能拥有`.NET`开发背景，并且想要了解`SSIS`脚本如何与其余的`SSIS`组件集成以实现数据传输和整合；或者，你可能是一位有兴趣使用`SSIS`执行一些管理任务的`DBA`。

无论你使用`SSIS`脚本组件的背景和动机如何，你都需要对`SSIS`和脚本有一个恰当的基础和入门介绍。除了描述基础知识，本书还为所有常见问题提供了一整套现成的脚本示例。
