# 第一部分：对话式语音系统基础

欢迎进入语音系统的世界！

无论您是来自移动应用或在线界面领域的设计师、开发者、产品经理，还是仅仅好奇语音技术究竟为何物，您在某些领域的知识和经验可能多于其他领域。因此，我们首先打好基础，让您无论背景如何，都能充分利用本书的后续内容。

*   第 1 章介绍语音优先系统、核心概念，以及本书结构所反映的三个高级语音开发阶段。通过探讨当今语音技术及其用户的一些常见说法，我们为语音行业的现状和挑战提供了解释性背景。

*   在第 2 章中，您将了解人类和计算机如何“说话”和“聆听”，在对话交互中哪些对用户和技术来说是容易或困难的，以及原因。成功的语音优先开发关键在于协调人类能力与技术，使两个截然不同的对话参与者之间能够进行对话。

*   在第 3 章中，您将把基础知识付诸实践，搭建并运行您的编码环境，创建一个简单的语音应用，并可在后续章节中扩展。我们将立即通过几个具体示例，让您实践测试、分析和改进语音体验。

在本部分结束时，您将能够解释当今语音用户界面（VUI）系统设计和开发中的难易之处，以及为什么某些方面比其他方面更具挑战性。您将理解 VUI 设计最佳实践背后的原因。这些是您的基本工具，意味着您已准备好学习如何应用它们。
