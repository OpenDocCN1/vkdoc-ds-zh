# 第四部分：启动阶段：验证与调优

没有哪个语音优先解决方案一开始就是完美的。虽然有些人部署了系统后就不再投入额外精力，但如果您的目标是创建尽可能最好的语音系统，我们不推荐这种方法。语音系统绝不是一劳永逸的。

这最后一部分涵盖了语音系统成功的第三阶段：测试、分析和修复问题，并在生产发布前后快速且恰当地完成这些工作。您将学习收集和分析数据的技术，以及如何将您的发现映射到适当的解决方案。

您如何知道用户是否喜欢您的语音解决方案？第 16 章涵盖了专为语音定制的各种用户测试方法、支持这些测试所需的编码，以及您可以从此类测试中学到什么。您将学习语音系统 QA 测试的注意事项，以及测试识别率和可用性的方法。

第 17 章教您如何改进或调优您的语音解决方案。您将了解真实用户数据如何反映您 VUI 的性能、需要记录和跟踪什么、如何衡量准确性，以及最重要的是，如何解读数据以便知道需要修复什么。本章涵盖了性能调优的多个方面，包括覆盖范围、识别、对话和意图调优。

恭喜！您付出了努力并学到了很多。现在，您已准备好将任何优秀的语音系统打磨成卓越的系统。
