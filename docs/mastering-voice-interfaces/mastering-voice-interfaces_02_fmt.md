# 向语音系统问好

你可能有过这样的经历：使用某个应用时心想，*我本可以做得更好*。现在，你就有机会用一项前景广阔的新技术来创造点什么——一个用户能与之对话、并能用语音回应的应用。

你听说几乎每个人都在使用语音技术，所以你最好抓紧时间，否则就会被甩在后面。你的信息流里充斥着爆炸式增长的消息：家家户户都有数百万台语音设备，数千款应用已经上线。这一定是真的：电视广告里展示着那些将对话设备引入家庭的幸福用户的笑脸，由此带来了完美无瑕、整洁有序的家居生活，机器处理着日常生活的枯燥乏味。而且，得益于 API 和 SDK，整合这一切应该很快就能完成。有什么理由不爱呢？于是你有了一个想法：也许是用语音控制自己家里的一切，或者更简单些，比如一个本地餐厅查找器。你选择一个平台，也许是 Amazon Alexa、Google Assistant 或其他某个平台，然后看几个教程来学习这些工具。你构建了你的想法，部署了它，等待用户……但他们没有出现，或者给了你一个低评分。

哪里出了问题？以下只是人们不使用你的语音应用的几个可能原因：

- 它没有提供用户想要的功能。
- 它涵盖了正确的功能，但设计或实现使其使用起来困难或缓慢——如果用户有其他选择，他们为什么要费心使用这个解决方案？
- 功能是有的，但用户找不到。
- 它不能恰当或正确地响应用户所说的短语；应用不理解它的用户。
- 用户被应用的回应搞糊涂了；用户不理解这个应用。
- 用户不喜欢应用的说话方式：无论是语音还是措辞，或者两者都不喜欢。
- 用户被理解了，但他们没有得到所请求的内容或操作。
- 应用对用户做出了错误的假设，或者强行推行自己的意图。
- 语音应用未能与内容或相关的外部用户账户良好集成。
- 出于隐私原因，用户更倾向于对你的应用所做的事情进行静默交互。
- 应用在该响应时不响应，或者在不该响应时响应！

这些原因可分为三类：

- **未能理解用户**：他们如何说话和倾听，他们需要和想要什么
- **未能理解技术**：它是如何工作的，哪些容易做，哪些不容易做
- **未能理解解决方案需要同时为用户和技术服务**

要创建成功的语音解决方案，你需要解决所有这三个方面。我们的书正是帮助你做到这一点。本章首先定义语音技术领域，然后探究一些你将会听到的关于语音的说法及其背后的现实。在概述了大多数语音优先系统的技术、架构和组件之后，我们将讨论成功语音系统开发的各个阶段以及每个阶段需要注意的事项。理解语音优先开发的各个方面对每个人都有益，无论是设计师、开发者、产品负责人——甚至用户自己。每个人都想构建或使用能解决问题的东西。让我们行动起来吧！

### 语音优先、纯语音与一切对话式

首先，我们所说的纯语音、语音优先和语音前置是什么意思，为什么这些术语很重要？

我们用纯语音来表示其字面意思：语音是交互的**唯一**模式，无论是输入还是输出。用户与设备对话，设备通过语音或其他纯音频反馈来回应。没有屏幕，没有按钮，没有打字。可以有支持性的灯光来指示设备是否在监听，但就意义而言，这些是可选的。我们会将“传统”的 Amazon Echo 或 Google Home 视为纯语音设备，因为你无需查看设备上的灯光就能与之交互。大多数基于电话的呼叫中心企业系统也是纯语音系统，尽管许多系统允许使用按键音作为备用。

对我们来说，语音优先有两个相关的含义：语音是交互的主要模式，无论是输入还是输出。如果你的交互是多模态的，它应该是你设计和实现的第一种模态。这意味着你为纯语音进行设计和开发，同时计划现在或将来增加其他模态，例如屏幕或按钮。在后面的章节中，你会看到如果语音占据主导地位而不是后来才添加的附加功能，你的成功几率会增加的原因。语音用户界面（VUI，发音为 *voo-ees*，与 GUI 即图形界面押韵）需要不同的交互元素和不同级别的反馈。语音前置是类似的：语音是主要的交互方法，尽管其他模态也存在以支持输入和/或输出。多模态界面并非本书的主要焦点——在你学习的解决方案中，语音应该始终能够独立存在——但我们确实会强调模态如何影响你的设计和开发选择。请留意全书中的“多模态角落”部分。

语音应用，或称口语对话系统，在不同设备上有多种形式：手机、汽车、家用虚拟助手、客户服务等等。语音应用可以是通才，用维基百科片段来回答问题。它们也可以是专才，与特定设备绑定，比如改变单个房间温度的恒温器。它们可以像导师一样主动引导，也可以耐心等待你提出要求。有些可以访问你的日历、预约、播放你最喜欢的歌曲、查找 2001 年上映的电影，甚至从你的支票账户转账来支付信用卡账单。有些会假设只有一个用户，有些会识别说话者是谁或要求他们表明身份，还有一些会对每个提问者给出相同的答案。有些只使用语音；有些带有屏幕或物理按钮。有些固定在一个地方；有些随用户移动。你在本书中学到的大部分内容都适用于各种设备、主题和场景。它们都有一个共同点：口语是主要的交互模式。
