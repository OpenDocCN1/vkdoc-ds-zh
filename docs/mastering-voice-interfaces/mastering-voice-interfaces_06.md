# 第二部分：规划阶段：需求发现与高层设计定义

在本书的这一部分，我们将重点放在规划阶段，以及如何找到与构建任何语音系统相关问题的答案。这个阶段在大多数语音资源中并未被详细涵盖，但我们一次又一次地看到，它对语音系统开发的最终成功——以及痛苦程度——有着巨大的影响。你很快就会发现，你自己的语音系统的成功取决于找到 (1) 业务和产品需求、(2) 系统和技术依赖与限制，以及 (3) 理解用户行为、语言、需求和目标之间的正确平衡。在本部分的两个章节中，你将学习如何定义范围和功能，如何确定你的挑战以及解决这些挑战的可用选项。你还将学习如何以促进语音 UI 设计思维，同时促进跨职能团队沟通和开发工作的方式来记录你的发现。

-   第 4 章涵盖了以语音为中心的需求发现和定义。我们在其他地方没有看到过如此深入的介绍，但我们确实看到了当这个阶段被忽略时，最终语音产品会受到怎样的影响！无论你的角色是什么，如果你理解了关键点，你将会更加成功。你未来的 VUI 系统用户会感谢你的！

-   在第 5 章中，你将学习如何将发现结果转化为高层架构设计。语音优先开发只有与扎实的设计相协调才能成功。你将了解为什么流程图、示例对话和详细的对话管理规范仍然是对话式语音系统最广泛使用的工具和方法。

在本书这一部分的结尾，你将理解创建语音系统与设计开发其他界面和模式有何不同。你有了自己的计划；现在你已经准备好进行“真正的”工作：构建你的语音系统。
