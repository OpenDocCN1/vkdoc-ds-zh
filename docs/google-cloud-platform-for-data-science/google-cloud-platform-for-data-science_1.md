# 前言

商业格局正通过整合数据科学和机器学习而发生转变，云计算平台已成为处理和分析海量数据集不可或缺的工具。谷歌云平台（GCP）作为顶级的云计算平台脱颖而出，为数据科学和机器学习提供了广泛的服务。

本书是一本全面的指南，旨在教你仅使用 GCP 平台提供的免费层级服务来学习数据科学。无论你的职业背景是数据分析师、数据科学家、软件工程师还是学生，本书都提供了一种全面且循序渐进的方法来掌握 GCP 的数据科学服务。它提供了一份逐步指南，涵盖了从基础概念到高级主题的所有内容，使你能够掌握利用 GCP 进行数据科学的专业知识。

本书首先介绍了 GCP 及其数据科学服务，包括`BigQuery`、`Cloud AI Platform`、`Cloud Dataflow`、`Cloud Storage`等。你将学习如何设置 GCP 账户和项目，以及如何使用 Google Colaboratory 创建和运行 Jupyter 笔记本，包括机器学习模型。

接着，本书涵盖了大数据和机器学习，包括`BigQuery ML`、Google Cloud AI Platform 和`TensorFlow`。在此学习过程中，你将掌握利用`Vertex AI`训练和部署机器学习模型的技能，并利用 Google Cloud Dataproc 高效处理大规模数据集的能力。

然后，本书深入探讨了数据可视化和商业智能，涵盖了 Looker Studio 和 Google Colaboratory。你将熟练使用 Looker Studio 生成和分发数据可视化图表及报告，并学习构建交互式仪表板的知识。

本书随后介绍了数据处理和转换，包括 Google Cloud Dataflow 和 Google Cloud Dataprep。你将学习如何在 Cloud Dataflow 上运行数据处理管道，以及如何使用 Cloud Dataprep 进行数据准备。

本书还涵盖了数据分析和存储，包括 Google Cloud Storage、Google Cloud SQL 和 Google Cloud Pub/Sub。你将学习如何使用 Cloud Pub/Sub 进行实时数据流处理，以及如何设置和消费数据流。

最后，本书涵盖了高级主题，包括使用身份与访问管理（IAM）保护和管理 GCP 资源、使用 Google Cloud Source Repositories 进行版本控制、Dataplex 和 Cloud Data Fusion。

总的来说，本书提供了一份全面的指南，教你仅使用 GCP 平台提供的免费层级服务来学习数据科学。它涵盖了平台的基础知识以及适合希望将技能提升到更高水平的个人的高级主题。
