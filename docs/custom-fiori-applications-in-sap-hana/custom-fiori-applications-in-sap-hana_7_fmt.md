# 全书结语

在结束本书的写作时，我对贯穿练习中的各个主题感到非常欣慰。仿佛就在不久前，我还在撰写关于创建自定义`Fiori`应用并从白板设计开始的内容。之后，我迅速转向了可以为`Fiori`应用开发的各种平面图和应用类型。接着，本书介绍了使用SAP提供的工具（如`SAP Web IDE`、`SAP Web IDE 个人版`）以及外部IDE工具（如安装了SAP提供的一些扩展的`Visual Studio Code`编辑器）来开发、设置和扩展`Fiori`应用的各种工具。在介绍了工具和`Fiori`应用的开发（展示了使用`XML`视图、`JavaScript`控制器以及各种呈现和建模数据方式的`MVS`模式）之后，本书转而介绍了单元测试框架，我认为这是一个需要各公司越来越多地探索的领域。最后，我通过解释所需步骤、介绍软件版本管理，并将我们开发的自定义`Fiori`应用部署到各种平台来结束本书。希望你能够跟上思路，并从至少部分章节中学到一些技巧，无论你是在设计、集成第三方`JavaScript`库、添加软件版本管理，还是部署到不同平台方面有所收获。非常感谢你抽出时间跟随我的旅程，祝你在自定义`Fiori`开发中一切顺利。
