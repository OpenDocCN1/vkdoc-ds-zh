# 总结

双积分器是开发控制系统时一个非常有用的模型，因为它代表了许多系统的理想版本，例如附在质量块上的弹簧。在本章中，您建立了双积分器的数学模型，并在一个右侧函数中编写了动力学方程。您了解了数值积分，并编写了 `Runge-Kutta` 积分器，该积分器将用于本书后续的应用中。控制函数的配方结合了设计和实现，包含一个内置演示，并定义了一个在调用之间用于存储的数据结构。第一个演示脚本展示了如何初始化一个用于双积分器的控制器，进行仿真，并绘制结果。表 6-2 列出了本章中开发的代码。这几乎是您在 MATLAB 中进行任何数学或控制分析的基础！

**表 6-2. 章节代码清单**

| 文件 | 描述 |
| --- | --- |
| `RHSDoubleIntegrator` | 双积分器的动力学模型。 |
| `RungeKutta` | 四阶龙格-库塔积分器。 |
| `PDControl` | 比例-微分控制器。 |
