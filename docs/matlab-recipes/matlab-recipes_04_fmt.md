# 1.1 创建函数帮助

## 问题描述

你需要为函数编写文档，以便他人能够使用它们，也方便你日后回忆其工作原理。

## 解决方案

将文档放置在正确的位置后，MATLAB 提供了一种机制，让你能够通过 `help` 命令在命令行中访问函数或脚本的相关文档。

## 实现原理

你在函数文件顶部添加的注释（称为**头部注释**）会成为函数的帮助文本。在命令行中输入 `help MyFunction` 即可显示该帮助文本。虽然注释的风格和格式将在下一章讨论，但此处需要你关注其功能。

帮助注释可以放在函数声明行的上方或下方。如果在注释中包含“see also”字样，后跟其他函数的名称，MATLAB 会自动为这些函数提供帮助链接。所有注释内容会一直打印到遇到第一个空行为止。

以下是一个计算点积的函数的帮助示例。第一行应为函数的单句描述，供 `lookfor` 命令使用。如果在注释中以全大写形式插入函数名，MATLAB 在打印帮助时会自动将其转换为正确的大小写形式。你的注释可能如下所示：

```
function d = Dot( w, y )

%% DOT 两个数组的点积。

%% 形式

% d = Dot( w, y )

% d = Dot( w )

%

%% 描述

% 支持数组的点积。w 和 y 的列数可以是：

%

% * 两者均大于 1 且相等

% * 其中一个只有一列，另一个有任意列数

%

% 如果只有一个输入，则计算该输入与自身的点积。

%

%% 另请参阅

% Cross
```

当打印到命令行时，MATLAB 会移除百分号，仅显示文本内容，如下所示：

```
>> help Dot

Dot 两个数组的点积。

% 形式

d = Dot( w, y )

d = Dot( w )

% 描述

支持数组的点积。w 和 y 的列数可以是：

* 两者均大于 1 且相等
* 其中一个只有一列，另一个有任意列数

如果只有一个输入，则计算该输入与自身的点积。

% 另请参阅

Cross
```

你还可以链接到文件中子函数附带的额外帮助文档。这对于提供更详细的示例或算法描述非常有用。为此，你需要在帮助注释中嵌入一个 HTML 链接。例如：

```
% 更详细的帮助请参阅<a href="matlab: help foo>extended_help">扩展帮助</a>。

function extended_help

%EXTENDED_HELP 额外的技术细节和示例

%

% 描述算法的额外细节或提供示例。

error ('此函数仅为帮助文本而设的占位函数');
```

这种格式在命令窗口中的显示效果为：

更详细的信息请参阅扩展帮助。

MATLAB 还允许你为函数创建 HTML 帮助，使其显示在帮助浏览器中。这需要创建 XML 文件来提供目录层次结构。请参阅 MATLAB 帮助主题“显示自定义文档”以及下一章的相关方法。

你还可以运行帮助报告，以识别缺少帮助或缺少某些帮助部分（如版权声明）的函数。要了解如何在你的操作系统上启动此报告，请参阅 MathWorks 的帮助主题“检查哪些程序具有帮助”。
