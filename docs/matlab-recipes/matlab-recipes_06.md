# 第二部分
## 应用
在本书的这一部分，我们将探讨 MATLAB 在多项技术中用于动力学系统及控制系统设计的应用。在每个领域，我们都会推导系统的运动方程。系统由其状态方程、状态和参数定义。运动方程即系统各状态所对应的方程。状态变量是一组随时间演变的变量，它们完整地定义了系统的当前状态，并允许在无需任何过去信息的情况下预测未来状态。我们还需要独立于状态的参数，结合系统输入，来完整定义系统。状态向量始终用一个 n×1 的 MATLAB 数组表示。在我们给出的方程中，将使用点号表示导数，即状态方程的形式为：`x` 是状态，表示为一个 n 行 1 列的 MATLAB 数组的 n×1 向量。`u` 是输入矩阵，为 m×1 维。`y` 是测量量。`a` 将状态与状态导数关联起来，是一个 n×n 数组。`b` 是输入数组，为 n×m 维，其中输入 `u` 的数量为 m。`c` 将状态与测量量关联，`d` 将输入与测量量关联。我们不会深入探讨控制理论的细节。这本身就需要一整本教材，而如果你想深入探索控制系统设计，则可能需要许多本教材。我们将提供一种直观的方法，让你能够快速启动并运行控制系统，且无需编写过多代码！
