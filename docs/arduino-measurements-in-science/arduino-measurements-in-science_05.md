# 排版后内容

测量通常可分为两类：相对测量与绝对测量。绝对测量需要使用已知或已定义的标准对测量设备进行校准。相对测量则监测被测量参数的变化。如果实验能设计为相对测量而非绝对测量，将能获得更优的测量结果。

除物理参数测量章节外，本书还新增了数据采集与能源供应相关章节，以协助您使用远离实验室的实验设备或装置。

## 作者为《Arduino 科学测量》所作的前言

《Arduino 科学测量》介绍了实现基本技术的方法，这些技术旨在帮助人们进行实验性科学测量。我希望本书能协助学生——那些对机电技术或物理科学缺乏经验或背景有限的学生——设计并开展他们所需的实验，以推进其研究或学业。同时，我也希望本书对资金有限、难以基于实验科学创建和发展科学项目的群体有所助益。

迁徙或觅食的动物及昆虫利用日光、近红外光、偏振光、天体指示、水中的化学痕迹、地球磁场等辅助手段，在地球表面导航，以寻找食物或返回繁殖地。

诸如天文学、生物学、化学、地质学/地理学、数学、物理学直至动物学等字母顺序分类法，是人类的概念与分类方式，而动物世界的旅行者对此一无所知。动物王国对理化物参数的无类别运用，与当前科学研究之间存在着相似之处。

大量新的科学知识，正由接受某一学科教育的研究者通过运用另一学科的非传统实验技术所揭示。尽管本书出自一位分析化学家之手，但它汇编了适用于任何需要实验测量基本理化物参数的科学学科的基础入门技术。

我是一名与分析化学家共事过的人，曾接触过真空管、晶体管、集成电路、大型机、小型机、微型计算机和微控制器。计算技术从`BASIC`、`Fortran`、各种`C`语言变体，过渡到开源系统迭代，如`Python`、`Processing`（Arduino 微控制器*集成开发环境*（`IDE`）语言的基础），以及`Raspberry Pi`所使用的`Linux`操作系统。新的及修订版的开源语言、`IDE`和操作系统均可从互联网免费获取。

这本书在撰写之时或许就已近乎过时，但正如它所描述的科学与技术一样，它只是这个永恒变化主题的一个起点。对于研究人员和实践科学家而言，科学基础相对恒定且已充分理解，因此在判定某个概念或技术“过时”时必须极为谨慎。

`SCADA`概念及其发展远早于`PC`。如今仍在广泛使用的一些晶体管和`CMOS` `IC`以及`7400`系列集成电路，其历史可追溯到 20 世纪 70 年代。如今教授和使用的化学分析、医学及物理测量技术，其起源可追溯至中世纪。

`SCADA`是*监控与数据采集*的缩写。`SCADA`软件允许计算机通过从监测被控过程的传感器获取数据，来监督一个机电过程。将要讨论的许多测量技术可视为单一组件，它们不仅是`SCADA`系统的组成部分，也可能属于被称为物联网（`IoT`）的发展中技术的一部分。

`HMI`是*人机界面*的缩写。`HMI`可以是一种电子设备或结构，为计算机、实验装置和人类操作员之间提供接口。（图形用户界面（`GUI`）可充当`HMI`）。

`USB`是通用串行总线的缩写，这是一套成文的规范标准，机电硬件系统需符合该标准。`USB`是一个子系统，允许个人计算机与插入通用串行总线的设备进行通信。在本书撰写之时，`USB`已发展到第三代。

当个人计算机运行监控与数据采集软件，并通过通用串行总线系统连接人机界面时，无论是位于数英里外“现场”的实验装置或设备，还是紧挨着计算机/工作站或笔记本电脑“在台面上”的实验装置或设备，都可以进行实时监控和控制。

笔记本电脑、独立台式机、有线或无线网络工作站，加上互联网连接，如今为实验室或“现场”监测科学实验提供了前所未有的灵活性。

实验人员可用于实现`SCADA`系统的选项，本质上可根据达到全功能系统所需的开发工作量分为三类。

来自国家仪器公司和福克斯波罗等制造商的完整、成品化的可用软件系统，能够测量和控制几乎任何光电机械系统。市售的全功能基础纯软件系统，其成本预计在数千美元范围内。

我选择基于三种成本较低的方案来编写本书，以实现实验装置上的`SCADA`。

本书中的练习采用了一种中等成本的实施策略，使用了以下资源。这些资源对于进一步开发新应用的实验也应足够。

*   一台装有`SCADA`软件的`PC`。可用的系统很多。本书使用了 AzeoTech 公司的`DAQFactory Express`和基础版`DAQFactory`。`DAQFactory`基础版软件的成本约为`250 加元`。

对于能够适配软件并可能需要更高灵活性的用户，可获取免费版本的`SCADA`系统。AzeoTech 提供了一个名为`Express`的优秀的精简但功能完整的`DAQFactory`版本，它具备完整的绘图功能，但分页和脚本功能有限。

*   一个`USB` `HMI`。多家制造商提供多种设备，本书选用的是 LabJack 公司的`U12`型号（`U12`成本约为`120 美元`。后来增加了`U3`，成本约为`110 美元`）。

LabJack 设备附带以`DAQFactory`程序工作版本（名为`Express`）形式提供的软件。LabJack 软件因其图形显示能力而表现优异，对于科学研究中的许多应用来说已是绰绰有余。

`DAQFactory Express`限制为十行脚本代码、五个脚本序列和两个显示页面。本书中的某些项目练习可能需要`DAQFactory`商业版的强大功能。如需购买软件，读者应从最基本版本开始，并根据需要升级。


* 第三种方案是实施 SCADA 系统的最新且成本最低的方法，该系统由树莓派 (`RPi`)、其 Linux 操作系统、带有`Matplotlib`库的 Python 编程语言以及`Tkinter`图形用户界面组成。

Linux 操作系统、Python 及其模块均为开源项目，可免费从互联网下载。

树莓派项目推出了树莓派单板计算机 (`SBC`)，可从许多大型电子元器件供应商处（例如 Digi-Key 或 Newark Element 14，仅举两例）以 35 美元的价格购买。树莓派板需要一台支持 HDMI 的电视或电脑显示器、鼠标和键盘，才能构成一个功能完整的计算系统。Linux 操作系统软件、Python 编程语言及其模块均为开源软件，可从互联网免费下载。

除了几乎零成本的软件外，树莓派板除了其 USB 输入/输出接口外，还包含自己的通用输入/输出 (`GPIO`) 总线。它拥有自己的 HMI（人机界面），无需额外电路或费用即可与外部电子设备或实验装置连接。树莓派板配备了以太网接口，因此具备网络功能。树莓派基金会提供了大量在线免费使用的库，这些库可以将 `RPi` 与现实世界中的传感器、机器人、设备和仪器连接起来。

2008 年，一个名为 Arduino 的开源项目推出了一系列通过 USB 连接的微控制器板，使设计人员、艺术家、爱好者和非电子专业人士能够将光电机械设备连接到计算机。

一块基础的 Arduino Uno Rev 3 板可以从任何主要电子元器件供应商处以大约 20 美元的价格购买。为微控制器板编程的软件是另一个开源项目，是可以从互联网免费下载的自由软件。Arduino 板可与 Windows 或基于 Linux 的操作系统配合使用。它拥有在线论坛、大量教程以及广泛的示例程序和应用程序的全面支持。Arduino 几乎可以为任何计算系统充当智能接口。

使用 SCADA 类型实现的实验可以采用完整商业可用套件的形式，开箱即用，无需开发时间。也可以采用成本较低但需要一定编程量的系统，使用`DAQFactory`程序和商业 HMI 设备（例如`LabJack`系列接口）来实现。最后，在增加开发时间的情况下，还可以使用 Arduino，或一组低成本硬件和可从互联网免费下载的开源软件，来构成一个可运行的系统。

除了实施监控系统所需的软件和硬件外，可能还需要以下列表形式的附加辅助设备。

* 需要一套无焊面包板系统、合适的电源（例如电池或电子稳压电源），以及各种 IC 和被动电子元件。

* 需要万用表用于故障排除。对于更高级的工作，可能需要独立的示波器或用于 PC 的示波器程序。

我认为你对这项技术并非完全陌生，并且可以在参考资料、在线教程和元器件制造商数据手册的帮助下完成任何测量流程。如果需要额外帮助，可以在线找到带有练习题的学术课程大纲，以帮助你理解实现特定测量技术所需的基础知识。所有科学都是基于经验的，本书与现实中的科学工作并无不同。

你必须从测量项目的简单部分逐步深入到更复杂的方面，在任何多阶段测量过程中验证并确认每个中间步骤。

正如标题所述，本书涉及使用集成电路和物理计算系统来监测和测量物理化学参数。使用现成的廉价组件来监测和控制实验装置，这些装置可以在许多分类科学中以基本物理化学参数的形式测量数据——在某些情况下，其灵敏度、灵活性、准确性和精度令人惊叹。
