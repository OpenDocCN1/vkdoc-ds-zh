# 6. 模糊逻辑

图 6-2 中的隶属函数呈梯形，具有平行的水平边。但从概率论和统计学中，我们知道许多论域中的数据呈正态分布，并由形式为 `e^(-βx²)` 的高斯函数表示，其中 `β` 是一个正实数。例如，正态分布的概率密度函数由高斯函数 `1/(√(2πσ)) * e^(-(x-μ)²/(2σ²))` 给出，该函数属于后一种形式。因此，模糊隶属函数常采用高斯函数的形式，其图形与图 6-3 中的图形类似。

再举一个例子，一个与 1 近似相等的实数模糊集的隶属函数，可以用下面(6.15)中给出的高斯函数来建模。

```
μ_X = e^(-β(x-1)²)
```

(6.15)

必须注意，隶属函数可以有多种形状。图 6-2 和图 6-3 是其中的两种形状，可能也是更常见的两种。梯形隶属函数的值如下表 6-11 所示。

**表 6-11** 梯形隶属函数的值

| `μ[X]` 的值 | 当 `x` 的值为 |
| --- | --- |
| `1 - (a-x)/α` | `a - α ≤ x ≤ a` |
| `1` | `a ≤ x ≤ b` |
| `1 - (x-b)/β` | `b ≤ x ≤ b + β` |
| `0` | 所有其他值 |

利用隶属函数的概念，可以扩展命题逻辑和谓词演算来对模糊性进行建模。运算符的定义如表 6-12 所示，以纳入模糊性。在表中所给的示例中，假设 `T` 是真推文的集合，`F` 是假推文的集合。隶属函数 `μ[T]` 给出推文为真的可能性，`μ[F]` 表示推文为假的可能性。可以看出，它们的总和超过 1.0，这体现了模糊集的粒化与渐变。粒化指的是一类对象关联着一个范围，而不仅仅是单个值。渐变意味着不同类之间的转换是渐进的，并存在一些重叠。

**表 6-12** 逻辑运算符的模糊解释

| 运算符 | 含义 | 模糊解释 | 示例 (`μ[T] = 0.7`, `μ[F] = 0.4`) |
| --- | --- | --- | --- |
| `⋏` | 与（合取） | `min(μ[T], μ[F])` | 0.4 |
| `⋎` | 或（析取） | `max(μ[T], μ[F])` | 0.7 |
| `¬` | 非（否定） | `1 - μ_T` | 0.3 |

将`μ[T]`和`μ[F]`限制为只能取 1 或 0，并与布尔逻辑的解释进行交叉验证，可以证明表 6-12 中的解释是正确的。例如，当 `μ_T = 1` 且 `μ_F = 0` 时，合取结果为 0，因为 `min(μ_T, μ_F) = 0`，而析取结果为 1。表 6-8（在命题逻辑一节中给出）中的交换律、结合律、分配律、幂等律和德摩根定律，同样适用于模糊逻辑。布尔逻辑的推理机制也可以类似地扩展，以处理模糊逻辑中的不精确性。

模糊集的一个有用度量是其熵。它在下面的(6.16)中定义。

```
Entropy(T) = |T ∩ T^C| / |T ∪ T^C|
```

(6.16)

熵是类中无序或不精确性的一个指标。对于清晰集和布尔逻辑，可以很容易地看出熵为零，因为 `|T ∩ T^C| = 0`。

> **注意**：尽管经典布尔逻辑在时间上发明得更早，但它可以被视为模糊逻辑的一个特例。

## 小结

以适当的方式表示数据有助于通过推理来确定其真实性。在本章中，我们研究了如何使用经典布尔逻辑和模糊逻辑来建模现实世界并推理得出结论。我们使用了在第 5 章中使用的同一个推特示例，来演示模糊逻辑如何帮助处理推文真实性中的熵。本章提出的技术需要对大数据的表示方式进行变革。这个主题还有很大的空间可以进一步演进，以覆盖各种形式的大数据。在下一章中，我们将考察更多的方法，特别是来自信息检索领域的方法，以解决真实性问题。
