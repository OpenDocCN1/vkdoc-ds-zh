# 引言

大数据相关主题正迅速发展。从最初定义大数据的三个 V，到如今业界已识别出与大数据相关的 42 个 V。我们如何定义大数据以及能利用它做什么，这份列表只会随着时间的推移不断增长。真实性常被称为大数据的第四个 V。它作为大数据概念出现后的第一个 V，这一事实本身就表明了真实性主题对大数据演进的重要性。确实，数据质量是其应用的根本。我们可以构建许多先进工具来驾驭大数据，但如果数据质量不达标，这些应用将价值有限。真实性是数据的基石，实际上也是人类文明的基石。

尽管真实性主题触及大数据的根基，但相关研究尚未充分展开。一个主题真正开始发展，通常始于一本关于它的印刷书籍。研究论文和文章，尽管其过程严谨，但只能帮助吸引人们对某个主题的关注。然而，一个主题在工业规模上的研究，始于出现一本关于它的书。衷心希望本书能开启对大数据真实性这一主题的此类研究。

各章节涵盖的主题不仅对大数据真实性重要，对许多其他领域也同样重要。这些主题的引入方式使得任何对数学和技术感兴趣的人都能理解，无需像其他同类书籍那样需要深厚的背景知识。本书内容源自作者在过去几年中发表的各类讲座、主题演讲及其他特邀报告，因此已证明对现场听众而言既有趣又富有启发性。

本书对于希望快速了解最新技术的业界管理者和从业者尤其有用。这本书甚至在出版前就已对业界产生影响，正如技术审稿人在一封邮件中所承认的那样，他审阅的本书中解释的一项技术，结果证明比他们当时正在使用的技术更好，以至于来自本书的新技术成为该产品线所有产品的默认方案。

本书不仅可用于介绍大数据真实性，还可在一本书中同时介绍机器学习、形式化方法、统计学以及革命性技术——区块链。它可作为研究生和本科生课程的推荐阅读材料。希望每章末尾的练习题能激发批判性思维并点燃好奇心。研究人员也可以使用本书，评估书中提出的新颖技术对其自身研究的适用性。书中描述的一些用于真实性问题的技术，是基于作者本人的研究成果。

各章节可以按任意顺序阅读，尽管存在一些前后交叉引用。第 3 章关于大数据真实性方法的内容，为剩余部分提供了很好的概述，是时间紧张者的必读之选。区块链正被吹捧为终极真相机器，可以解决现实世界中的许多信任和真实性问题。最后一章简要介绍了区块链这一值得密切关注的发展趋势。衷心希望本书能长期推动对真实性主题的深入研究。祝阅读愉快！
