# 引言：从稀缺到丰裕

## 信息简史与宣传问题

自我们拥有信息以来，虚假信息便随之存在。自广告诞生以来，试图进行“心理特征画像”的尝试便从未停止。自印刷术发明以来，我们便一直担忧大众媒体的腐蚀性影响。但在过去十年中，出现了一些新情况。信息的丰裕程度是我们在一二十年前无法想象的，而推荐引擎——一种基于个人数据档案、通过算法筛选内容的全新科学——主导着现代媒体格局。在本引言中，我们将厘清误解，聚焦问题的核心——即信息丰裕、人类心理、用户数据画像与媒体推荐算法之间的交汇点。这正是宣传渗入现代社会的途径。

### 现状概览

你是否曾使用搜索引擎寻找过库存照片？也许你需要在博客文章中插入一个漂亮的标题图，为家庭节日信件找些风景素材，或是为办公室派对传单设计背景。搜索结果可能相当不错，尤其是在使用专业库存图片网站（并且懂得如何选择搜索词）时。

但你是否曾用普通搜索引擎搜索过某些通用类别的图片？不妨试试。搜索*医生*的图片，然后搜索*护士*。再搜索*教授*，接着搜索*教师*。你看到了什么？

很可能你会发现一些相当明显的刻板印象。头发花白的教授穿着粗花呢外套，在黑板前讲课。教师同样站在黑板前，对着热切的学生微笑。医生穿着白大褂，娴熟地使用听诊器或在患者病历上做记录。护士穿着蓝色刷手服，同样精通于病历和仪器。你懂的。

然而，如果你走进一所中小学、大学、医院或全科诊所，会发现现实与这些图像几乎毫无相似之处。多数中小学和大学早已抛弃粉笔，转而使用白板和电子投影仪。面向一排排学生进行讲座式教学的情况也越来越少，尤其是针对低龄学生。而且，顺便提一句，所有这些专业人士的着装往往比搜索结果图像中的对象更随意，当然也更多样化。

搜索引擎并没有呈现现实。它们提供的是我们*预期*会看到的结果。结合人工编程、用户交互数据以及两者间不断重复的反馈循环，这些搜索结果会逐渐变得与我们脑海中的一般化印象越来越相似。我们心中的刻板印象决定了我们点击什么，而这些点击行为则构成了搜索引擎算法所用的原始数据。反过来，这些算法会根据我们的集体点击行为，形成对预期用户行为的一般化模型，并基于这些数据向你推送最可能点击的结果。我们感知、归纳、搜索、点击；机器感知（点击行为）、归纳、返回结果。

事情并未就此结束。这些搜索结果在网络上和印刷品中被*广泛使用*（这难道不正是我们当初搜索的目的吗？）。这些图像成为我们世界观背景的一部分，并进一步强化了我们头脑中的一般化印象。由此形成了一个无尽的循环：人类感知 → 人类归纳 → 人类行为 → 机器感知 → 机器归纳 → 机器行为 → 人类感知 → 人类行为……而在每次反馈循环的迭代中，刻板印象会变得更加刻板。现实被遗失了。然而，由于这些刻板印象已成为我们媒体景观的一部分，在某种意义上，现实也被*塑造*了。

但你注意到这些图片结果中另一个奇怪的现象了吗？

那些医生中有多少是男性，多少是女性？护士的情况又如何？据《华尔街日报》报道，2012 年美国 32%的医生是女性，且这一比例正在上升。¹(¹) 你的搜索结果中是否显示了这一比例？根据美国国家教育统计中心的数据，美国 49%的终身教职大学教师和 57%的非终身教职大学教师是女性。²(²) 你搜索的*教授*结果与之相比如何？



你的搜索结果很可能更多地反映了刻板印象，而非现实。这在一定程度上要归咎于我们的大脑。大脑会对我们在世界中所感知到的事物进行概括，而这些概括使我们能够对世界做出预测，从而帮助我们更高效地与之互动。认知科学家还发现，当我们形成概括——即所谓的“图式”（`schema`）——时，我们往往会通过与其他图式进行对比来定义这些图式。换句话说，我们会强调它们之间的*差异*，常常使它们在头脑中变得比现实中*更加泾渭分明*。虽然这种在头脑中定义思想和类别的方法通常很有帮助，但有时它也会适得其反，因为它会强化我们环境中的*偏见*，包括我们接触到的（充满刻板印象的）媒体。而当人类概括、机器概括和媒体呈现的反馈循环上线时，这种偏见就会以接近光速的速度传播和再现。

这一切都是相互关联的——我们的媒体、记忆、身份和社会。我们与世界互动的方式，直接受到我们拥有的世界“心理地图”的影响——什么是真实的，什么不是，以及一切都应归属于哪里。虽然这张心理地图主要是根据我们的经验形成的（并得益于数十万年的人类进化），但它越来越多地受到我们所消费媒体的影响。

我说“越来越多”，并非因为我们的大脑发生了某种变化，而是因为我们的媒体格局在过去一个世纪——甚至过去十年——发生了翻天覆地的变化。我们已经从信息匮乏走向信息过剩，从媒体荒漠走向媒体无处不在。对于这个星球上的大多数人——尽管重要的是，并非所有人——而言，我们接触现有信息和媒体的渠道也已同样迅速地扩展。我们的生活经验正越来越多地通过媒体来传递。

### 注意力的局限

但有一件重要的事情*没有*改变：人类身体（包括大脑）的极限。诚然，过去一个世纪里，大多数社会的婴儿死亡率 ^(³) 和预期寿命 ^(⁴) 有所改善，并且由于科学和人文学科的进步，许多人的生活质量得到了提高。然而，人类的认知系统——大脑与身体、记忆与感官的相互作用——早在数万年前就已基本定型。^(⁵) 我们大脑所能容纳的信息量没有改变，有意识的*注意力*的极限也没有改变。

随着所有媒体都在争抢我们的注意力，这种注意力已成为我们最宝贵——或许也是我们最常忽视——的资源。

让我们暂时回到搜索引擎的世界。它们是可能被入侵的。我指的不是全面的安全漏洞（虽然这当然也可能），而是它们可能被动机强烈的用户操纵。就像用户点击的内容会（部分）决定搜索结果排名一样，用户搜索的词汇也会（部分）决定输入时自动补全弹出的词汇。（找点乐子，去谷歌搜索你的家乡国家或州，比如“Why is [Colorado] so”，看看谷歌认为你可能想怎样完成这个搜索。）如果输入搜索引擎的搜索词可以决定自动补全词汇，那么一群愿意投入时间的人就可以反复搜索同一件事，直到它主导自动补全结果，从而增加看到它、受其影响并点击它的人数。

这种事在 2016 年就真实发生了。所谓“另类右翼”运动（右翼极端分子，通常与宣扬白人至上、反犹太主义、极端大男子主义反女权主义等仇恨观点的团体有关）的成员成功操纵了谷歌的自动补全，使其推荐带有种族主义色彩的搜索词和亲另类右翼的信息。^(⁶) 当谷歌了解到这种操纵行为后，他们对系统进行了修改。但没有一个系统能完全抵御入侵。

就连人类的心灵也不例外。

### 认知入侵

任何部分或全部基于统计数据得出结论的系统，都可能通过操纵统计数据而被利用。人类大脑的运作方式正是如此——随着时间的推移，我们感知到的事物被聚合在一起，形成概括性的图式，这些图式会随着新信息而不断变化（当然，更根深蒂固的图式变化得更慢）。通过改变大脑的统计输入，“入侵者”就能影响我们大脑形成的图式。这种*认知入侵*不仅影响我们如何定义事物，还影响我们将什么与它们联系起来，以及我们对它们反应的积极或消极程度。正如操纵谷歌的另类右翼人士只是少数用户，却依然能够影响该平台一样，即便是小规模的认知入侵者，只要他们能够操纵我们所消费的、围绕特定议题的足够多的媒体内容，就能对我们“心理地图”（及其影响的行为）产生显著影响。

现在，在你开始想到“俄罗斯人！俄罗斯人！”之前，有必要指出，很多认知“入侵”是无意的。（我们稍后会在本书中讨论俄罗斯政府支持的影响力行动，但它们只是更大问题的一部分。）也就是说，我们日常使用的媒体平台的结构，影响着我们感知世界的方式。

例如，我们知道用户更倾向于参与能引发强烈情感的媒体内容，尤其是当这种情感是愤怒时。^(⁷) 我们还知道，人们正越来越多地通过社交媒体平台消费新闻，^(⁸) 而社交媒体平台通过一种算法来推送内容，该算法旨在最大化“参与度”（点击、点赞、收藏、分享、愤怒表情等），而最大化参与度的努力往往转化为最大化强烈情感，尤其是愤怒。因此，研究政治和数字媒体的人观察到围绕政治议题的两极化加剧——强烈的情感、减少的细微差别，以及意识形态立场向远离政治中心的方向聚集，这就不足为奇了。

我们注意力自然会被能引发强烈情感的事物所吸引，而这种现象因对我们注意力的*争夺*而加剧，因为数据量以及数据生产者的数量正以令人瞠目结舌的速度增长。2013 年，科学家估计全球 90%的数据仅是在此前两年内产生的。^(⁹) 到了 2015 年，仅`Facebook`的用户数就超过了 2008 年*整个互联网*的用户数。^(¹⁰) 再加上许多家庭电视频道的激增，以及其他数字屏幕的便携普及，我们整个社会都沉浸在视觉和听觉媒体中，而这一切是我们进化史上从未准备过的。随着每一则商业媒体都在争夺我们的注意力，它们都试图通过超越对手来做到这一点。其结果是一场认知操纵的数字军备竞赛，加剧了吸引眼球媒体已经造成的危险和极化效应。



这种极化现象并非仅仅源于情绪。人们倾向于接触那些能巩固自身既有观点的事物，科学家称之为*确认偏误*——如果我本就认同，那它必然有可取之处。这包括看似能证实其准确性的内容（毕竟，发现新信息证明自己一直正确，感觉真棒！），或是能印证持不同立场者之谬误的内容。人类进化出一种（重要的！）先天倾向：厌恶并回避那些让我们意外发现自身缺陷的情境。在远古时期捕食者与猎物频繁互动的时代，这种情境往往致命。但当涉及网络政治辩论时，这种进化而来的倾向却让我们回避那些能在智识、伦理和道德层面促进个体与社会成长的情境。由于回避细微差别并屈服于`确认偏误`，我们进一步偏离了中间立场——也远离了那些与我们意见相左的人。我们构建起个人的信息茧房，却始终相信自己的观点建立在*更广泛*的信息基础之上——这多亏了万维网的奇迹。在这种错觉之下，若不加以干预，社会将变得支离破碎，不同意识形态的人更难找到共同立场。

尽管我们生活在人类历史上信息最丰富、联系最紧密的时代，但我们的大脑*天然*处理信息过剩的方式，却意味着我们这代人可能是人类历史上最易受宣传影响的一代。但我强调的是*天然*。我们的基因禀赋，是祖先在抵御四面八方威胁时艰难赢得的，在许多方面是极其珍贵的馈赠。但在当今时代，大多数人面临的*并非*捕食者的日常威胁，而是那些企图利用媒体操纵我们的注意力，从而影响我们思想和行为的人。我们*天然*配置的工具，并不适合应对这些威胁。对于背后突袭的捕食者，或是在能量不足时面对丰盛食物，我们拥有出色的本能反应。但对于`数字虚假信息`，我们毫无本能。

然而，我们*确实*进化出了学习、分析、推理、沟通和以逻辑说服的能力。这些并非我们的*自动*本能。但如果我们恰当引导心智——在正确的时间以正确的方式掌控自己的注意力——我们就能抵御这种操纵，构建更美好的社会。但这需要付出努力。而在此之前，需要先理解问题所在。

这正是本书要探讨的内容。

### 我们前行的方向

首先，我们将揭示“宣传问题”。为何我们有意识的注意力如此有限？它究竟有多有限？这对我们在数字时代处理信息的方式又意味着什么？我们还将探究社交媒体及内容推荐系统（如 Pandora、Netflix 和 Amazon）的算法基础——它们如何在技术上运作，如何与我们认知系统的优势与局限相互作用，以及如何被“黑入”以影响我们的思想和行为。

接着，我们将研究几个案例，探讨基于社交媒体的行动如何显著影响了公众意识——甚至公众行动。从通过 Twitter 和 Vine 组织并扩散、推动“黑人的命也是命”运动显著发展的弗格森抗议，到在 Twitter 上针对女性游戏设计师和评论家进行有组织的骚扰（即玩家门事件），再到近年影响乌克兰、瑞典、美国、土耳其、巴西、菲律宾、缅甸、墨西哥和哥伦比亚等国选举和政治动荡的影响力行动（无论是国内还是国际）。

我们生活在一个前所未有的时代。我们拥有完成非凡事业所需的工具、信息和人际关系。但就像火的发现或核能的利用一样，我们新获得的数字能力也让我们容易遭受人为灾难的侵袭——这类灾难的形态我们才刚刚开始想象。这种力量可以用来行善、作恶，或仅仅被视为玩具。当我们过于频繁地将数字技术当作纯粹的玩物，我们就向那些可能利用它来毁灭我们的人敞开了大门。但通过少许教育、些许监管和大量的谨慎，我们可以将这数字技术重新变为希望的灯塔。

撰写本书的目的，正是要提供这种教育，培养这种谨慎，并且，是的，鼓励这种监管。因为如果我们携手合作，并且做对事情，我们*确实*能成就一些非凡之事。

那么，让我们开始吧。
