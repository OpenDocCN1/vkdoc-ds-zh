# 7.1 为什么要使用统计学？

数学包含多个分支，包括算术、代数和几何。与数学密切相关的两个学科——`统计学`和`概率论`——在研究、理解和分析数据时非常有用。

让我们先分析几个与数据相关的问题，回答这些问题可能需要也可能不需要统计学相关的概念。请看下面这组问题：
1. 你每月的开销是多少？
2. 数据科学家的薪水比 IT 程序员高吗？
3. 你的狗能跑多快？
4. 猎豹跑得比老虎快吗？
5. 班加罗尔在 2015 年 7 月下了多少雨？
6. 印度北部的降雨量比印度南部多吗？
7. 即将到来的周末下雨的概率是多少？
8. 周末航班准时起飞的的概率是多少？

这些问题中，有几个比较容易回答。我们可以依靠回忆或者深入查阅信息档案来找到答案。然而，问题 2、4 和 6 存在变异性；可能拥有更多数据点，并且需要应用统计学来回答。最后两个问题需要运用概率论的概念，利用一段时间内收集的大量数据点来预测可能性。

让我们考虑几个与业务相关的实际场景，并回答需要统计学知识的问题。
- 你的城市最近爆发了一种由病毒引起的流行病。你是一名研究医学的学者。你一直在研究一种可能对抗该病毒效果的药物。你已经从服用了你药物的患者那里收集了数据。根据你的研究、分析和评估，你需要确定你的药物是否可以被认定为能有效治愈病毒带来的影响。
- 你在某蒸馏水厂的包装部门担任质量控制员。你的部门每天包装 10,000 瓶蒸馏水。每瓶容量为 1 升。上周三，运往某度假村的货物因瓶子尺寸小于通常的 1 升而被拒收。你有责任查明是否还有更多这种较小尺寸的瓶子被运出。如果有，数量是多少，以及发往了哪些目的地。
- 你在一家在线零售商的营销团队工作。你被要求牵头开展数字营销活动，以适当地宣传产品、提供合适的优惠，并承诺每周增加 500 名新客户。你已经制定了一些活动方案，正在思考这些活动成功的概率。
- 你是一家摩托车修理店的服务主管。你看到许多客户抱怨服务质量。这让你很担心，你想知道在未来三个月内，有多少客户可能会转而选择你的竞争对手。

概率论可以通过提供“数字”来帮助你做出采取补救措施的业务决策。让我们看看在上述业务场景中可以采取哪些行动。
- 如果目前的药物对患者无效，药物研究员可能需要专注于备用方案。
- 质量控制员需要安排召回已发出的货物，并与瓶子供应商核对瓶子的尺寸。
- 服务主管可能需要立即与不满意的客户沟通，以防止客户流失。

统计与概率在分析业务数据和支持决策方面扮演着非常重要的角色。

## 7.2 什么是统计学？

对外行人来说，“统计学”意味着以定量形式表达的数值信息。这些信息可能与物体、过程、商业活动、科学现象或体育相关。

简单来说，统计学可以定义为收集大量事实（或现实世界的观察结果）并对其进行分析，目的是总结这些收集结果并得出结论的科学。概率论可以定义为对某事件发生的确信程度的度量或估计，其尺度从不可能到确定。它可以定义为有利结果与总可能性数量的比例。

我们在两个广泛的领域中研究统计学。
- 汇总或聚合，即描述性统计学；
- 概率统计，即推断性统计学。

## 7.3 描述性统计学

描述性统计学允许人们以有意义的方式展示、描述或呈现数据，从而可能从数据中发现模式。它只能用于描述正在研究的群体，不能推广到更大的群体。换句话说，它只是一种描述我们数据的方式。例如：
- 集中趋势度量，如均值、中位数和众数。
- 离散程度度量，如极差、四分位距、方差和标准差。

## 7.4 推断性统计学

推断性统计学帮助人们根据对样本的观察或分析，对总体做出预测或推断。但是，样本必须具有代表性。

推断性统计学可用于两个目的：通过评估某个陈述真假的概率来促进科学理解；以及通过评估一系列可能性中哪个备选方案最理想来帮助做出明智的决策。

需要注意的是，如果原始数据集质量较差，概率和统计计算就不会非常有用。因此，基于这种错误基础做出的决策将是有缺陷的。

统计学和概率论中有大量的可用工具，例如`t 检验`、`Z 检验`、`F 检验`、直方图、排名和百分位数计算、抽样、曲线拟合、相关性、协方差、回归、随机数生成、`ANOVA`等。
