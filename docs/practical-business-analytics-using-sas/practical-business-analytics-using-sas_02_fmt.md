# 关于作者

![A978-1-4842-0043-8_BookFrontmatter_Fig1_HTML.jpg](img/A978-1-4842-0043-8_BookFrontmatter_Fig1_HTML.jpg) **文卡特·雷迪·科纳萨尼**毕业于印度孟买理工学院（`IIT`），获应用统计学与信息学技术硕士学位。他在预测建模、大数据分析以及包括 SAS 和 R 在内的多种分析软件工具领域拥有八年以上经验。其主要专长包括信用风险模型构建、客户体验管理、社交媒体分析、机器学习、自然语言处理、文本挖掘和大数据分析。他曾为多家知名机构和国际客户承担多个享有盛誉的分析项目。其中一些重大项目包括：`GIS` 工具的分析插件、文本挖掘与社交媒体数据的推文情感分析、足球比赛预测模型构建、客户体验管理、消费信用卡和贷款的信用风险模型构建，以及使用 Tableau 实现消费信用风险指标的可视化。他在预测建模、社交媒体分析和数据分析方面拥有专长，并已将这些技能应用于为国际公司开展的项目中。

![A978-1-4842-0043-8_BookFrontmatter_Fig2_HTML.jpg](img/A978-1-4842-0043-8_BookFrontmatter_Fig2_HTML.jpg) **沙伊伦德拉·卡德雷**是来自印度班加罗尔的一名高级 `IT` 和管理顾问，也是 2011 年 Apress 出版的《走向企业：极客指南》一书的作者。该书涵盖了 `IT` 运营管理和 `IT` 的商业方面。他撰写了多篇关于技术、`IT` 投资组合管理以及项目和计划管理的研究论文和文章。

目前，他在惠普印度公司担任解决方案顾问。他在技术、项目管理、售前、企业销售和业务分析领域拥有 20 多年经验。他目前的兴趣包括业务分析和企业打印解决方案。

沙伊伦德拉拥有印度德里理工学院（`IIT`）的机械工程硕士学位。他与妻子米纳克希、女儿内哈和儿子维韦克居住在印度班加罗尔。可通过 `shailendrakadre@gmail.com` 与他联系。
