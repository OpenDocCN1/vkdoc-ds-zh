# 数据分析工具简介

本节将讨论当今行业中使用的一些更常见的商业分析工具。数据分析师只学习一种工具是不够的。他们需要根据情况或手头问题的需求来应用不同的工具。对工具优缺点的全面了解无疑会为数据分析职业生涯增添价值。

本节将讨论三个行业领先工具的功能，并提供进一步信息的资源：SAS、R 和 SPSS。

商业分析旨在对数据进行建模，以发现有用的信息或商业洞察，并支持决策制定。它需要对数据进行各种操作，例如审查、清洗、转换和建模、验证以及解释，以获取有用的商业洞察。有时数据集可能包含数百万条甚至更多的记录。处理并操作如此复杂的数据需要自动化分析工具。幸运的是，如今有许多这样优秀的工具可用。只需在谷歌上简单搜索“数据分析工具”，就能得到许多此类工具的列表。其中许多是开源的且免费使用。SAS、SPSS 和 R 是当今使用最广泛的软件包，至少在商业分析应用方面是如此。R 是开源类别中最流行、使用最广泛的统计分析包，而 SAS 和 SPSS 是市面上最广泛使用的两款商业数据分析包。

SAS 工具自 20 世纪 70 年代就已存在。基于此工具构建的遗留系统非常多，以至于企业界中任何级别从事商业分析的大多数公司都继续使用 SAS。R 于 1996 年推出。多年来，围绕 R 构建了许多新的功能和特性。它是当今最强大的开源数据分析工具之一。这使得它在研究和学术界广受欢迎。许多企业界公司也已开始使用 R。SPSS 也已存在超过 20 年。它在社会科学和许多其他社区拥有强大的用户基础。

#### 选择工具

最终选用哪种数据分析工具，取决于诸多考量因素。

-   业务应用本身、其复杂程度以及组织内可用的专业水平。
-   组织的长期业务、信息与分析战略。
-   现有的组织流程。
-   预算限制。
-   在计算硬件系统上已提出或已进行的投资，这反过来可能决定软件运行可用的处理能力和内存等因素。
-   整体组织结构以及分析工作的执行地点。
-   项目环境与治理结构。
-   公司在使用开源软件方面的接受程度、保修及其他法律考量。
-   待处理的数据量大小。
-   项目所需的图形和展示的精美程度。
-   将使用哪些分析技术以及使用的频率。
-   当前数据的组织方式以及团队在处理数据时的熟练程度。
-   是否已建立数据仓库，以及该仓库在多大程度上涵盖了分析可能需要的业务和客户信息。
-   遗留系统因素。是否已有其他类似工具在使用？如果是，计划切换需要投入多少时间和资源？
-   投资回报预期。

还可以在此清单中添加许多特定于组织或项目的考量因素。这些因素的重要程度排序可能因人、因项目、因组织而异。然而，最终决策并非易事。本章后续部分将列出`SAS`、`SPSS`和`R`的一些对比功能，这或许有助于您决策选择最适合您需求的工具。最后，不必局限于单一工具，也可以决定针对不同的业务分析需求使用多种工具。

在某些情况下，可能会得出结论：像 Microsoft Excel 这样简单的电子表格应用程序最方便、最有效，并且足以提供解决当前业务问题所需的洞见。

有时，单个分析项目可能需要使用多种工具。数据分析师应根据手头问题，灵活运用不同的软件工具。

#### SAS、SPSS 和 R 的主要组成部分

`SAS`和`SPSS`拥有数百个函数和过程，大致可分为五个部分。

-   数据管理和输入功能，用于在分析前读取、转换和组织数据。
-   数据分析过程，用于实际的统计分析。
-   SAS 的输出交付系统（ODS）和 SPSS 的输出管理系统（OMS），用于提取输出数据以供最终呈现，或作为其他过程的输入。
-   宏语言，可用于重复执行命令集和处理编程相关任务。
-   矩阵语言（`SAS` `IML`和`SPSS` `Matrix`），可用于添加新算法。

`R`将这五个领域整合为一体。大多数`R`过程使用`R`语言编写，而`SAS`和`SPSS`则不使用其原生语言编写过程。作为开源软件，R 的过程可供用户查看并根据自身优势进行编辑。

##### SAS

根据`SAS`官网介绍，`SAS`业务分析软件套件拥有超过 35 年的经验，在全球拥有超过 60,000 个客户站点。它在高级分析领域拥有全球最大的市场份额。几乎可以处理与高级分析、商业智能、数据管理和预测分析相关的所有事务。因此，整本书都致力于解释`SAS`在高级业务分析中的应用，也就不足为奇了。

`SAS`的开发最初始于北卡罗来纳州立大学，并于 1966 年至 1976 年间在那里开发完成。成立于 1976 年的`SAS`研究所在全球拥有该软件的所有权。自 1976 年以来，核心软件中不断添加新的模块和功能。社交媒体分析模块于 2010 年加入。

`SAS`软件整体庞大，拥有超过 200 个组件。其中一些有趣的组件包括：

-   `Base SAS`：基本过程和数据管理
-   `SAS/STAT`：统计分析
-   `SAS/GRAPH`：图形和展示
-   `SAS/ETS`：计量经济学和时间序列分析
-   `SAS/IML`：交互式矩阵语言
-   `SAS/INSIGHT`：数据挖掘
-   `Enterprise Miner`：数据挖掘

###### 使用 SAS 进行分析：基本要素

本节将重点介绍`Base SAS`过程。`Base SAS`有助于读取、提取、转换、管理几乎所有形式的数据，并对其进行统计分析。这些数据可以来自各种源，例如 Excel、平面文件、关系数据库和互联网。`SAS`提供点选式图形用户界面来执行数据的统计分析。此选项易于使用，可能对非技术用户有用，或作为快速分析的手段。`SAS`还提供其自己的编程语言，称为`SAS 编程语言`。此选项提供 GUI 所拥有的一切，此外还包括若干高级操作和分析。许多专业的`SAS`用户仅偏好使用编程选项，因为它让用户在数据操作、分析和呈现方面拥有几乎无限的控制权。

大多数`SAS`程序都包含一个`DATA`步骤和一个`PROC`步骤。`DATA`步骤用于检索和操作数据，而`PROC`步骤包含用于数据分析和报告的代码。大约有 300 个`PROC`过程。`SAS`还提供了一种宏语言，可用于执行常规编程任务，包括重复调用`SAS`过程。在早期系统中，`SAS`提供了`ODS`，通过使用它，`SAS`数据可以发布为许多常用的文件格式，例如 Excel、PDF 和 HTML。许多`SAS`过程具有历史悠久、用户群广泛和文档完善的优点。

###### SAS 提供的主要优势

`SAS`编程语言是一种高级过程式编程语言，提供了大量内置的统计和数学函数。它还提供了线性和非线性图形功能以及高级报告特性。在应用统计技术之前，可以使用`SAS`编程语言对数据进行操作和便捷处理。`SAS`提供的数据操作能力变得尤为重要，因为在大多数分析项目中，多达四分之三的时间都花在数据提取、转换和清洗上。这种能力在其他一些流行的数据分析包中并不存在，这些包可能需要在使用其他几个程序对数据进行操作或转换后，才能将其提交给实际的统计分析过程。一些统计技术，如方差分析（ANOVA）过程，在`SAS`环境中尤为强大。

清单 1-1 和清单 1-2 是`SAS`代码示例。它们只是为了让您大致了解`SAS`代码通常的样子。关于编写`SAS`代码的更详细论述将在本书后面介绍。

清单 1-1. 回归 SAS 代码

```
Proc reg data=sales;
Model bill_amount=income Average_spending family_members Age;
Run;
```

清单 1-2. 聚类分析代码

```
Proc fastclus data= sup_market radius=0 replace=full maxclusters = 5 ;
id cust_id;
Var visitsincome age spends;
run;
```



##### R 工具

如前文所述，`R`是一个集成的数据处理、管理、分析以及图形与报告生成工具。它可以在集成环境中完成以下所有任务：

- 数据管理功能，如提取、处理、操作、转换和存储
- 完整的函数式和面向对象的`R`编程语言
- 统计分析过程
- 图形和高级报告生成功能

`R`是由`R`开发核心团队和庞大的`R`社区（[`www.r-project.org`](http://www.r-project.org/)）维护的开源软件。它拥有大量支持包，使其在分析社区中功能丰富。核心`R`软件中大约附带了 25 个标准包和推荐包，更多包可从`CRAN`网站（[`http://CRAN.R-project.org`](http://cran.r-project.org/)）及其他来源获取。`CRAN`网站（[`http://cran.r-project.org/doc/manuals/R-intro.html#Top`](http://cran.r-project.org/doc/manuals/R-intro.html#Top)）提供了包括文档资源在内的优秀`R`入门指南。

`R`的可扩展性是它最大的优势之一。现有数千个包作为核心`R`软件的扩展。开发人员可以查看`R`程序背后的代码并加以修改，以编写自己的包。大多数流行编程语言（如`C++`、`Java`和`Python`）都可以连接到`R`环境。`SPSS`为主要使用`SPSS`环境进行数据分析的用户提供了与`R`的连接。`SAS`也提供了一些在两个包之间传输数据和图形的方法。表 1-2 列出了最广泛使用的`R`包（请参阅[`http://piccolboni.info/2012/05/essential-r-packages.html`](http://piccolboni.info/2012/05/essential-r-packages.html)）。

##### IBM SPSS Analytics 工具

`SPSS` 最初代表“社会科学统计软件包”。它是一个用于统计分析的软件包，最初由 `SPSS Inc.` 开发。2009 年被 IBM 收购，IBM 将其更名为 `SPSS Statistics`，最新版本为 `SPSS Statistics 22`。

许多 `SPSS` 用户认为，与 `R` 和 `SAS` 相比，它的命令菜单选项更强大，学习曲线也更短。

网站 [`http://fmwww.bc.edu/GStat/docs/StataVSPSS.html`](http://fmwww.bc.edu/GStat/docs/StataVSPSS.html) 对 `SPSS` 有如下评价：

> SPSS 植根于社会科学，其许多核心优势在于问卷和调查分析。

`SPSS` 已存在很长时间，因此拥有强大的用户基础。与其他软件一样，在做出购买决策时，必须进行成本效益分析。

用户可能会发现 `SAS` 和 `SPSS` 彼此相似，从一个切换到另一个可能相当容易。初次使用的用户可能会觉得 `R` 有些不同。

###### SPSS Statistics 22 的特性

`SPSS Statistics 22` 建立在随时随地进行数据驱动决策的理念之上。它有许多新特性，例如与移动设备的交互。它支持 Windows、Mac 和 Linux 桌面系统。对于移动设备，它支持 Apple、Windows 8 和 Android 设备。它支持自动线性建模（`ALM`）和热力图。它增强了蒙特卡洛模拟，有助于提高针对不确定输入的预测模型的准确性。就可扩展性和性能而言，`SPSS Statistics Server` 表现良好。自定义编程也比以前更容易。Python 插件可以作为主安装的一部分添加。

蒙特卡洛模拟是一种解决问题的技术，用于通过进行多次使用随机变量的试验或模拟来近似某些结果。

### 分析工具的选择

网站 [`http://stanfordphd.com/Statistical_Software.html`](http://stanfordphd.com/Statistical_Software.html) 对 `R`、`Minitab`、`SAS`、`STATA` 和 `SPSS` 进行了统计特性比较。`R` 看起来功能丰富，这得益于其支撑包，这些包由 `R` 核心开发团队和许多其他 `R` 爱好者编写。`SAS` 自 20 世纪 70 年代以来就已存在，并拥有庞大的用户基础。它具有强大的数据管理能力，使其成为大多数分析练习的一站式工具。用户无需使用其他程序来处理数据文件或进行最终演示。

`SPSS` 具有出色的菜单驱动功能，在大多数情况下不需要任何编程培训。`SAS` 的市场份额和广泛吸引力使其成为本书的主要主题。企业界的许多公司对 `SAS` 感到满意，主要是因为多年来围绕它建立的大量遗产、其工业级代码质量、良好的文档质量以及市场上可用的技能。

正如本章所讨论的，需要接受所有可用的应用程序都有其自身优缺点的事实。没有一种软件适用于所有情况。数据分析师必须学习多种软件产品，并根据情况需求加以使用，才能取得成功。
