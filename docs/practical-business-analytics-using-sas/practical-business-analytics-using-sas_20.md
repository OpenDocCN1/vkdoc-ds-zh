# 商业分析成功职业生涯所需的背景

在本节中，我们将讨论成为一名数据科学家需要具备哪些条件。主要要求是热爱数字。通常，研究生水平的数学背景会有所帮助。研究生水平的优秀统计学或定量技术课程也可能是一个好的开端。拥有统计学学位的候选人通常会发现商业分析是一个自然而然的职业选择。具备基础计算机编程、数据库和 `SQL` 的使用经验将奠定坚实的基础。你也可以从商业智能或报告类工作入手，逐步过渡到全面的分析工作。掌握电子表格软件包（如 Microsoft `Excel`）和基础数据库（如 Microsoft `Access`）的知识通常也很有帮助。学习一些高级统计学的正规课程也会有所裨益。随着大数据时代的到来，`Hadoop` 等框架也日益重要。

### 商业分析专业人员所需的技能

以下是在商业分析领域取得成功所需的技能。随着你在公司层级中的晋升，软技能的重要性将超过硬核技术技能。（更多信息请参见 [`www.villanovau.com/business-analyst-skills`](http://www.villanovau.com/business-analyst-skills)。）

#### 沟通技能

商业分析师需要与用户、高级管理层、技术人员和客户进行沟通，以了解项目需求、业务目标、要遵循的方法、测试以及其他与项目相关的活动。他们需要透彻理解业务以及需要解决的潜在问题。分析结果通常通过复杂的 Microsoft `PowerPoint` 演示文稿和其他报告工具呈现给高级管理层及其他项目利益相关者。要在这一职业中取得成功，必须具备高水平的语言表达和书面沟通能力。

#### 技术技能

数据分析师在日常工作中使用复杂的统计软件包、报告工具、演示和测试软件。通常，掌握单一工具或软件是不够的；根据问题的性质，可能需要组合使用多种软件。有时，在构建最终模型之前，会使用诸如 `C` 之类的纯编程语言来对数据执行复杂操作。项目中可能涉及多个数据库，分析师可能需要从这些数据库中提取和处理数据。可能会使用各种报告和演示工具来有效地呈现项目结果。因此，成功需要强大的技术能力和 IT 技能。

#### 分析技能

这项工作的核心是分析庞大而复杂的数据集、业务文档、调查、业务和运营需求。商业分析师需要对业务、待解决的问题、分析方法论以及演示需求有深入的理解。分析师可能还需要提出规范性措施来纠正业务问题。强大的分析能力对于在这份工作中取得成功至关重要。

#### 解决问题能力

基于本章内容，不难看出解决问题的能力对商业分析师来说有多么重要。在项目进行过程中，甚至在日常工作中，分析师几乎每天都会面临各种挑战。

#### 决策能力

商业分析师需要就复杂的业务事项从不同来源和利益相关者处获取输入，然后运用良好的判断力来决定正确的行动方案。分析师可能需要就业务问题向管理层、开发人员和客户提供建议，其中一些决策可能对业务产生长期影响，涉及数十亿美元的业务。因此，根据正确的输入和方法做出正确决策的能力是商业分析师的一项重要技能。

#### 管理技能

分析问题的解决通常以项目形式进行。分析师需要管理项目，并指导团队成员的日常活动。所有项目都必须在时间、成本和质量约束下进行管理。这需要高度的项目管理和管理技能。同时，也需要具备谈判和说服的技巧。
