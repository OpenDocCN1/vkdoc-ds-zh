### 天气预报

假设我们有一个预测下一小时天气的天气预报系统。

天气只有三种可能：晴天、多云或雨天。在这里，我们称这些可能性为*状态*。我们不会连续地预测天气，而是预测下一小时的天气。这使得我们的系统是*离散的*。

连续时间马尔可夫链超出了本书的讨论范围。它需要更严谨的分析。然而，离散时间马尔可夫链的基本思想是不变的。

天气会变化，所以晴天有概率变为多云。同样，多云有概率变为雨天，依此类推。我们可以定义表 2-1 中的转移概率。列表示当前天气状态，行表示下一小时的天气状态。

解读这个表格的方法是按列阅读。例如，如果当前天气是晴天，那么下一小时天气是多云的概率是 `1/3`。这由第一列的第二行（除了行名所在列）表示。

我们也可以用*转移概率*符号来表示这个概率。我们用 `si` 来表示第 `i` 小时的天气状态。那么之前的转移概率可以表示如下：

`P(s_cloudy | s_sunny)`

`P(cloudy | sunny)`

在表达式 `P(s1 = cloudy | s0 = sunny)` 中，我们使用了条件概率的符号。它简单意味着，在前一小时天气为晴天（这是一个*条件*）的情况下，下一小时天气为多云的概率是 `1/3`。

那么，这究竟意味着什么呢？我们如何使用表格或图形来预测天气？想法很简单；我们从一个当前天气（即一个状态）开始，然后根据转移概率转移到其他可能的状态。例如，如果当前状态是晴天，那么下一小时，我们有 `1/2` 的概率保持晴天，有 `1/3` 的概率变为多云，等等。到目前为止看起来很简单。那再下一小时的天气呢？我们必须结合所有可能的*轨迹*来进行预测。例如，晴天状态可以通过三种不同的轨迹达到：从晴天开始，从多云开始，以及从雨天开始。这给了我们如下的组合概率：`P(s_sunny) = (1/2)*(1/2) + (1/3)*(1/3) + (1/6)*(2/3) = 1/4 + 1/9 + 2/18 = 17/36`

手动继续计算仍然是*可能的*，但我们更愿意把这项工作留给计算机。

从形式上讲，我们刚刚介绍的系统必须满足两个重要属性才能成为马尔可夫链：

1.  第一个称为*马尔可夫性*或*无记忆性*属性。这意味着系统只会记住紧邻的过去状态，而不会记住更早的状态。例如，天气预报系统只会记住并使用当前天气来预测下一小时的天气，而不会使用前几小时的天气。

**第 2 章 马尔可夫链，一窥未来**

2.  第二个应被视为一种简化，如果你想匹配现实世界的场景，可以将其移除。即，我们的马尔可夫转移概率是固定的，不随时间索引 `i` 变化。在现实生活中，随着季节变化，我们的转移概率应该改变。

以下是用于自动化计算的代码片段。请注意，我已经使用矩阵符号来表示转移概率：

```python
sunny_to = {"sunny":1/2, "cloudy":1/3,"rainy":1/6}
cloudy_to = {"sunny":1/3, "cloudy":1/3,"rainy":1/3}
rainy_to = {"sunny":2/3, "cloudy":1/6,"rainy":1/6}
state = {"sunny":1, "cloudy":0,"rainy":0}
weathers = ["sunny","cloudy","rainy"]
for _ in range(10):
    next_state = {}
    for weather in weathers:
        next_state[weather] = (sunny_to[weather] * state["sunny"] +
                                cloudy_to[weather] * state["cloudy"] +
                                rainy_to[weather] * state["rainy"])
    state = next_state
    print(state)
```

### 马尔可夫链的本征态

稳定概率分布 `x = (0.486, 0.297, 0.216)` 有什么特别之处吗？

事实证明，它是转移矩阵的特征值为 `1` 的一个特征向量。换句话说，它代表了马尔可夫链的*本征态*。实际上，我们可以对任何一个方阵进行分解，以找出它的特征值和特征向量。你可以使用 `numpy.linalg.eig(tm)[0]` 来获取矩阵 `tm` 的特征值，并使用 `numpy.linalg.eig(tm)[1]` 来获取相应的特征向量。

注意，本征态在量子力学中有特殊含义。在这里，我只是借用这个词，因为它在这个上下文中是有意义的。它还有其他名称，如平稳分布、均衡分布、极限分布等。

首先，让我们看一下先前模拟中已经使用的转移矩阵。我们用 `x'` 和 `x` 分别表示新（下一小时）状态和旧（当前小时）状态。转移矩阵用 `T` 表示：

`x' = T @ x`

```
| 1/2  1/3  2/3 |   | 0.48648649 |   | 0.48648649 |
| 1/3  1/3  1/6 | @ | 0.2972973  | = | 0.2972973  |
| 1/6  1/3  1/6 |   | 0.21621622 |   | 0.21621622 |
```

请注意，计算忽略了一些由精度引起、可忽略的数值误差。

**第 2 章 马尔可夫链，一窥未来**

这个方程告诉我们，一旦我们的系统达到本征态，它将在后续的转移中保持不变。这意味着几个小时后，无论当前天气如何，晴天的概率将约为 50%。矩阵符号也启示我们，系统的演化也可以写成一系列矩阵的乘积。为简单起见，我复用了符号 `sn`。你已经见过 `si` 了，对吧？它们基本上是同一个东西。

```
sn = T @ s(n-1)
   = T² @ s(n-2)
   = T^n @ s0
```

```
        | 0.49  0.49 0.49 |
T^inf = | 0.30  0.30 0.30 |
        | 0.22  0.22 0.22 |
```

正如你所见，无论我们的初始状态 `s0` 是什么，只要其元素之和为 1，输出 `sn` 就是本征态。这是一个值得注意的事实。

你可能会问，是否所有的转移矩阵都具有这样良好的性质。答案是否定的。这里有一个例子：

```python
tm = np.array([[0, 0, 1],
               [1, 0, 0],
               [0, 1, 0]])
state = np.array([1,0,0])
for _ in range(10):
    state = tm@state
    print(state)
```

#### 一个有终点的随机游走

假设有一只爱吃水果的乌龟，它在一条管道里移动。管道长 7 英寸。左端有一根香蕉，右端有一个苹果。现在，乌龟从离左端 3 英寸的位置开始，这意味着它离香蕉比离苹果近 1 英寸。乌龟每分钟只能移动 1 英寸，并且它以相等的概率随机向左或向右移动。乌龟非常活跃，它*会*每分钟都移动，直到它到达其中一个水果。该设置可如图 2-4 所示。

***图 2-4.** 表示乌龟可能所处状态的示意图*

问题是，乌龟*最终*到达香蕉和苹果的概率分别是多少？

花些时间自己思考一下这个问题。以下是一些直觉和观察：

1.  直觉上，只要有足够的时间，乌龟会到达其中一个水果。我们的管道只有 7 英寸长，而乌龟一直在移动。
2.  乌龟到达香蕉的概率应该比到达苹果的概率高，但可能不会高很多。这个设置不是对称的。

让我们进行一组模拟运行，直接模拟这样的系统并评估这些概率：

```python
def tortoise_run(state = 3, left_prob = 0.5):
    steps = 0
    while state % 7 != 0:
        if np.random.random() < left_prob:
            state -= 1
        else:
            state += 1
        steps += 1
```

这个马尔可夫链与天气马尔可夫链的主要不同之处在于，它有两个所谓的*吸收态*。吸收态就是管道的左端和右端。一旦乌龟到达其中一个端点，它就停止移动。转移矩阵对角线上的第一个和最后一个元素是 `1`，表明它们是吸收态。

现在，让我们找出多步转移矩阵的*本征态*。思路是，我们将多个连续转移（例如 50 步）视为一个转移，并考虑其转移矩阵。你可以使用一行代码 `reduce(lambda x,y:x@y,[tortoise_tm for _ in range(50)])` 找到 `50` 步的转移矩阵。如果你将 `50` 改为一个更大的数，矩阵除精度误差外基本保持不变。

对称性很明显。乌龟离左端越近，到达香蕉的可能性就越大。最大概率是 `0.86`。这与我们的直觉一致，因为尽管香蕉只有 1 英寸远，但乌龟确实有机会到达苹果。我们将转移矩阵与初始状态 `numpy.array([0,0,0,1,0,0,0,0])` 相乘，以获得最终到达香蕉的概率。

十四行诗之间用空行分隔。以下代码将预处理每个句子（可能不完整），使其变为小写并去除标点符号：
