## Python 注释

在我们开始讨论 Python 数据类型之前，有必要了解 Python 中的注释行，因为我们会在代码中经常使用它们。根据注释的目的，有两种编写注释行的方法。

如果你想为自己编写关于代码中某一行简短说明，那么单行注释是最佳选择。这些单行注释只需在行首使用井号（`#`）字符即可创建，并会在行尾自动结束。执行代码时，Python 编译器会忽略井号符号之后直到行尾的所有内容。

多行注释用于向他人解释代码的特定方面，可以通过在注释的开头和结尾添加三个单引号（`'''`）来创建。Python 编译器不会忽略这些注释，如果脚本中除了注释没有其他内容，它们会出现在输出中。这两种注释在 IDLE Python shell 格式中的示例如下：

```
>>> # 这是一个注释
>>> "'这是一个注释'"
'这是一个注释'
```

### `list`

## 控制流语句

控制流语句允许根据表达式的值执行一条语句或一组语句。控制流语句可以分为三类：`顺序控制流语句`按程序中的顺序执行语句，`决策控制流语句`根据条件为 `True` 或 `False` 来执行或跳过一组语句，`循环控制流语句`允许重复执行一组语句直到满足终止条件。

### `if` 语句

决策控制流语句类别中的 `if` 控制语句以 `if` 关键字开头，后跟条件语句，并以冒号结尾。条件语句计算一个布尔表达式，只有当布尔表达式计算结果为 `True` 时，才会执行 `if` 语句中的语句体。`if` 块语句从缩进开始，第一个没有缩进的语句标志着块的结束。`if` 语句的语法如下，清单 2-12 展示了它的工作原理：

```
if <条件>:
    <语句>
```

```
x = 12
y=8
if x > y:
out = "x is greater than y"
print(out)
输出：x is greater than y
清单 2-12
if 语句操作
```

#### `if-else` 语句

`if` 语句后面可以跟一个可选的 `else` 语句。如果 `if` 语句中条件语句对应的布尔表达式为 `True`，则执行 `if` 块中的语句；如果布尔表达式为 `False`，则执行 `else` 块中的语句。换句话说，`if-else` 语句提供了双向决策过程。`if-else` 语句的语法如下：

```
if <条件>:
    <语句>
else:
    <语句>
```

清单 2-13 展示了 `if-else` 语句的示例代码。

```

y=9

out = "x is greater than y"
else:
out = "x is less than y"
print(out)
输出：
x is less than y
清单 2-13
if-else 语句操作
```

#### `if...elif...else` 语句

`if...elif...else` 语句可以提供多路决策过程。关键字 `elif` 是 `else-if` 的缩写形式。如果需要从多个可能的选择中选取一个，则可以将 `elif` 语句与 `if` 语句一起使用。`else` 语句将最后出现，作为默认操作。以下是 `if...elif...else` 语句的语法，清单 2-14 展示了示例代码：

```
if <条件 1>:
    <语句>
elif <条件 2>:
    <语句>
elif <条件 3>:
    <语句>
...
else:
    <默认语句>
```

```
x = 4
y=4
if x > y:
out = "x is greater than y"
elif x<y:

# for 循环

`for` 循环使用一个迭代变量运行，该变量在每次迭代时递增，直到变量到达循环所操作序列的末尾。在每次迭代中，取出序列中与迭代变量所指示位置相对应的项目，并执行循环中的语句。`for` 循环的语法如下：

```
for <variable> in <sequence>:
    <statements>

`range()` 函数在 `for` 循环中非常有用，因为它可以生成一个数字序列，可以使用 `for` 循环对其进行迭代。`range()` 函数的语法是 `range([start,] stop [,step])`，其中 `start` 表示序列的起始位置（如果未指定，则从零开始），`stop` 表示需要生成数字到的值（不包括该数字本身），`step` 表示生成的序列中每两个连续数字之间的差值。`start` 和 `step` 值是可选的。`range` 参数生成的值应始终为整数。清单 2-16 展示了一个用于逐个打印字符串中元素的 `for` 循环。

x = "Hello"

# o

## 异常处理

异常就是在执行过程中检测到的错误。当程序中发生异常时，执行会终止，从而中断程序的正常流程。通过异常处理，可以向用户提供有关错误的有意义信息，而不是系统生成的消息。异常可以是内置的或用户定义的。用户定义的异常是用户创建的自定义异常，可以使用 `try...except` 语句实现，如清单 2-18 所示。

```python
while True:
    try:
        n = int(input("Enter a number"))
        print("The number you entered is", n)
        break
    except ValueError:
        print("The number you entered is not the correct data type")
        print("Enter a different number")

# Output:
# Enter a number 5
# The number you have entered is 5
# Enter a number 3.6
# The number you entered is not the correct data type
# Enter a different number
```

**清单 2-18** 异常处理

在清单 2-18 中，当变量接收到不适当数据类型的值时，会发生 `ValueError` 异常。如果没有发生异常（即输入的数字是整数），则跳过 `except` 块，只执行 `try` 块。如果在输入不同数据类型的数字时发生异常，则跳过 `try` 块中的其余语句，执行 `except` 块，并将程序返回到 `try` 块。

## 函数

函数是 Python 编程中的基本构建块，当需要在程序中多次执行一组语句时可以使用函数。可以通过将这组语句分组并为其命名来创建函数，这样可以在程序的任何部分通过该名称调用这些语句，而无需重复整个代码块。因此，函数可以通过消除冗余代码来减小程序规模。函数可以是内置的或用户定义的。

Python 解释器有许多内置函数，我们已经见过其中一些，如 `print()`、`range()`、`len()` 等。另一方面，Python 允许用户定义自己的函数并根据需要使用它们。函数定义的语法如下：

```python
def function_name(parameter1, .... parameter n):
    statement(s)
```

函数名可以包含字母、数字或下划线，但不能以数字开头，也不应与关键字同名。让我们考虑一个简单的函数，它接收单个参数作为输入并计算其平方；请参见清单 2-19。

```python
def sq(a):
    b = a * a
    print(b)

sq(36)
# Output: 1296
```

import math as mt

def dec2bin(a):
    b = ''

    return b[::-1]  # 反转字符串 b
