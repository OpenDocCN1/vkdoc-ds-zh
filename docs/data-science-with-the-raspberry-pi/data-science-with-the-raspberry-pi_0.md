# 引言

在现代，数据可以被视为像石油或黄金一样珍贵的商品，因为借助科学方法，我们能从数据中获取大量有用信息，并据此做出明智决策，从而将其转化为财富。`数据科学`就是从数据中提取知识或有用信息的过程。

例如，IBM 预测，到 2020 年，数据科学领域对技能型人才的需求将增长 28%。许多行业在其业务的不同方面应用数据科学概念，例如检查是否达成目标、查找故障根源等。近年来，数据科学已被有效应用于政治领域，用于制定战略、识别弱势区域、预测民众情绪和期望等。此外，地方政府利用从城镇居民收集的数据，为城镇发展规划和政策制定提供依据。数据科学在农业领域也取得了成功应用，例如干旱评估、作物产量预测和遥感等。这表明，与数据科学概念相关的应用如今正跨领域涌现。

当前大多数书籍侧重于将数据科学技术应用于某些开放或标准数据集。而本书专门探讨在 `Raspberry Pi` 开发板上应用数据科学概念。`Raspberry Pi` 可以作为一台单板计算机运行，并且能够通过传感器与实时环境交互，而大多数本地服务器无法完成此任务。

本书首先对数据科学进行简要介绍，随后将专门用一章讲解 `Python` 概念，涵盖从软件安装到各种可用数据类型及模块的内容。接下来的两章将向读者介绍 `Raspberry Pi` 设备、其硬件描述以及如何设置设备以采集实时数据。再接下来的四章将结合 `Raspberry Pi` 硬件，讨论数据科学在实时应用中的不同操作。本书的倒数第二章将探讨使 `Raspberry Pi` 能够从数据中学习的概念。最后一章将包含几个案例研究，让读者了解这些概念可应用的领域范围。
