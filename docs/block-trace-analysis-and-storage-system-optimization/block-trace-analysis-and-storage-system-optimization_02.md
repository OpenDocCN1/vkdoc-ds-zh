# 致谢

本工作的主要部分源于我在西部数据、淡马锡实验室和数据存储研究所从事数据分析和存储系统研发 16 年的经验。我要感谢西部数据允许我发表一些与工作相关的内容。在本书的编写过程中，我得到了许多朋友和同事的支持和建议。在此仅提及几位：于杰博士、郭国晓博士、Robin O’Neill、Grant Mackey、王建毅博士、David Chan、Wai-Ee Wong、李毅博士、Samuel Torrez、冯世华、蒋丹、Terry Wu、Allen Samuels、Gregory Thelin、William Boyle、David Hamilton、John Clinton、Nils Larson、Karanvir Singh、Eric Lee 和 Sang Huynh。特别地，我的博士生兼同事牛俊鹏也帮助我撰写了第 1 章中关于混合磁盘的几个段落。

我还要感谢技术审稿人蔡云鹏和夏莉，他们提出了非常有帮助的意见。同时，深深感谢编辑 Susan McDermott、Rita Fernando、Laura Berendson、Amrita Stanley、Krishnan Sathyamurthy 和 Joseph Quatela 的辛勤工作。

最后但同样重要的是，我最感激我的妻子格蕾丝，她在我一生中给予我爱与鼓励；以及我的两个儿子亚历山大和亚瑟，他们提醒我工作之外还有生活。没有他们极大的耐心和热情的支持，我无法完成这本书。
