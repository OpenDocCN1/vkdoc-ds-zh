# 建模问题

评估系统设计通常有两种常规方法。一种是直接使用追踪到的工作负载来驱动模拟。另一种是根据追踪记录构建模型，并利用该模型进行分析或模拟。尽管基于数值追踪的方法很直接，但工作负载模型相比追踪记录可能具有一些优势，例如可通过受控修改进行调整、可重复性、平稳性、泛化能力、避免噪声、增强理解、增加特性、提高效率等。因此，通过数学模型来理解这些指标至关重要。在上一节中，我指出假设检验是基于统计模型的一些假设。表 2-8 和 2-9 列出了一些关于基础指标和高级指标建模问题的常识性细节。更多详情请参考 [35]。

**表 2-9** 高级指标的数学模型

| 指标 | 建模问题 |
| --- | --- |
| **局部性** | 常用分布：Zipf 分布（独立引用模型）。其他模型：LRU 栈模型、马尔可夫模型、分形模型 |
| **空间局部性** | 最简单的方法是通过统计引用流中的唯一子串数量。正式度量方式为工作集的大小。 |
| **时间局部性** | 最简单的度量是通过一个“针孔”观察引用流，或使用 LRU 栈的模拟。 |
| **读/写依赖性** | 模型：状态机、马尔可夫链、聚类 |
| **优先级相关指标** | 完全由操作系统/文件系统规则决定。可基于马尔可夫链构建模型，并考虑 |
| **突发性与自相似性** | 自协方差和协方差矩阵常用于描述自相似性。 |

**表 2-8** 基础指标的数学模型

| 指标 | 建模问题 |
| --- | --- |
| **吞吐量** | 常用分布：帕累托分布 |
| **排队时间** | 常用分布：指数分布、爱尔朗分布 |
| **服务时间** | 常用分布：指数分布、爱尔朗分布 |
| **响应时间** | 常用分布：指数分布、爱尔朗分布 |
| **磁盘寻道时间** | 可通过分段函数进行数据拟合来建模 |
| **读写比** | 无明显分布，取决于读/写依赖性 |
| **请求大小分布** | 常用分布：对数分布、截断正态分布、帕累托分布、指数分布、幂律分布、对数均匀分布 |
| **LBA 范围/随机性** | 参见空间局部性 |
| **到达间隔时间** | 常用分布：泊松分布、指数分布、对数正态分布 |

生成分析模型的一般步骤如下：

-   首先，确定公式：表征级别和工作负载基本组件。
-   其次，在工作负载执行期间收集待建模的参数。
-   第三，使用某种统计分布（例如，对数分布、截断正态分布、帕累托分布、指数分布、幂律分布、对数均匀分布）和随机模型（例如，马尔可夫模型）对测量数据进行统计分析，包括采样过程和静态/动态分析。

一个使用马尔可夫链的示例如下所述步骤。

1.  假设工作负载近似周期性地具有 *s* 个状态，将一个周期内每个数据存储单元的 IO 追踪建模为特定的马尔可夫链。否则，所有相应的马尔可夫链参数都应是时变的。

2.  给定一个历史工作负载追踪 *L*，表示为 *D × T* 矩阵：

```
X = [[x_{1,1}, x_{1,2}, ..., x_{1,T}],
     [x_{2,1}, x_{2,2}, ..., x_{2,T}],
     [..., ..., ..., ...],
     [x_{D,1}, x_{D,2}, ..., x_{D,T}]]
```

其中 *D* 是数据存储单元的总数，*T* 是时间间隔的总数。`x[d,t]` 是任意选定数据单元 `d` 在时间 `t` 的 IO 强度。`x[d,t] ∈ {1, 2, 3, ..., s}`。

3.  每个马尔可夫链可以用其 `s` 乘 `s` 的状态转移概率矩阵表示：

```
P = [[p_{1,1}, p_{1,2}, ..., p_{1,T}],
     [p_{2,1}, p_{2,2}, ..., p_{2,T}],
     [..., ..., ..., ...],
     [p_{s,1}, p_{s,2}, ..., p_{s,s}]]
```

其中 `p[i,j]` 是在当前 IO 强度状态为 `i` 的条件下，数据单元 IO 强度状态在下一个时间间隔变为 `j` 的概率，且 `i, j ∈ {1, 2, 3, ..., s}`。

4.  为了简化分层存储系统中的数据分配，您还需要根据数千个数据单元的动态 IO 强度将其分类为十几个数据簇，例如使用 K-means 算法，该算法利用状态转移概率矩阵以及每个数据单元在每个状态 `s` 的驻留时间。通过结合簇的初始状态 `S`，您可以获得整个周期内所有簇的预测 IO 强度，表示为以下 `N × T` 矩阵：

```
S = [[s_{1,1}, s_{1,2}, ..., s_{1,T}],
     [s_{2,1}, s_{2,2}, ..., s_{2,T}],
     [..., ..., ..., ...],
     [s_{N,1}, s_{N,2}, ..., s_{N,T}]]
```

其中 `s[l,t]` 是第 `l` 个数据簇在第 `t` 个时间间隔的 IO 强度。

请参考 [7, 8] 了解模拟方法与建模方法之间的区别。对于更复杂的情况，您可以使用所谓的多级过程模型。并且，在这些情况下，必须考虑相关性。
