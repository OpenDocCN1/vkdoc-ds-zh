# 11. 结论

就原样提供的 SQL Server Integration Services (SSIS) 而言，它已为企业数据集成做好了准备，但在企业 DevOps 和数据集成生命周期管理 (DILM) 方面尚不够成熟。使用本书中概述的最佳实践、工具和实用程序，您可以提供参与企业 DevOps 的数据集成解决方案。

DILM Suite 提供的免费、免费开源以及付费实用程序集，旨在支持使用 SSIS 进行数据集成的企业的企业级数据集成生命周期管理。
