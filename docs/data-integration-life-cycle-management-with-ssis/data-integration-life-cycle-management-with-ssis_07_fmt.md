# 7. SSIS 目录比较器

查看 SSIS 目录内容，包括 SSIS 目录项目、包、环境、环境变量、引用和引用映射，以及 SSIS 包和 SSIS 目录属性，这很有帮助。但如果你想查看一个 SSIS 目录实例与另一个实例之间的内容差异呢？或者，也许更有用的是，你如何才能“知道”企业 QA 和生产环境中的 SSIS 目录实例是匹配的？

## 作者 Andy Leonard 分享：为何构建 SSIS 目录比较器

我的团队使用 SSIS 为客户构建了一个相当复杂的数据集成解决方案。我们在两个 DevOps 层级（测试环境和 UAT（用户验收测试）环境）中测试了该解决方案。我们发现了一些问题并进行了修正。然后到了部署到生产环境的时候。在生产部署和初始生产测试期间，我和我的团队处于待命状态。

起初，一切均告失败。

我们找出了根本原因并修正了问题，但我们在业务方面丢了面子，而且理由充分。我们曾向他们保证“我们做得对”。我们确实做得对，但有一个例外。企业数据架构师提出了一个很好的问题，指出了差距：“我们如何“知道”生产环境和 UAT 环境的 SSIS 目录是相同的？”我当时回应道：“（沉思片刻……然后）我不知道。”

我构建了 `SSIS Catalog Compare`（SSIS 目录比较器），这样我——以及我的客户，还有你——就能够回答这个问题了。
