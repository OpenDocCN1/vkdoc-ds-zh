# 前言

文本分析和自然语言处理的力量正开始兑现其承诺，这要归功于机器学习领域的当代发展。

如果你读过 Dipanjan Sarkar 的《Python 文本分析：从数据中获取可行洞察的实用真实世界方法》一书，那么你可能已经对此有所体会。该书于 2016 年出版，已迅速成为自然语言处理领域的重要读物。然而，在技术领域，两年时间可能像是一辈子，所以欢迎来到更新后的《Python 文本分析》第二版！

虽然第一版原始材料的核心内容得以保留，但全书进行了许多更新和修改。值得注意的是，文本分类和情感分析章节已扩展，涵盖了传统机器学习和深度学习模型——随着神经网络在自然语言处理方法中日益核心化，这一点非常重要。此外，主题建模（一种用于抽象主题发现的技巧集合）也得到了进一步发展，增加了许多互补方法，并利用了额外的 Python 库。

书中还新增了关于特征工程的完整章节——这在自然语言处理和文本数据中扮演着尤为核心的角色——其中涵盖了传统方法和基于神经网络的方法。此外，尽管如今深度学习的讨论常常围绕自然语言处理展开，但明显感觉到这仅仅是开始；为此，又一个全新章节专门探讨了深度学习在自然语言处理领域的潜力。

为什么要选择《Python 文本分析》？本书不仅涵盖了各种前沿文本分析和自然语言处理任务背后的概念与直觉，还详尽地介绍了实用方法和 Python 代码来巩固这些概念，以便读者能够自己应用这些知识。既然 Sarkar 已经证明了自己在文本分析领域的知识和指导价值，那么审视这本全面扩展和更新的第二版，无疑是一个绝佳的主意。
