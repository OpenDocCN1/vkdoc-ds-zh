# 排版后的内容

所以我写了这本书，因为我想带领读者深入了解这些内容，帮助他们建立信心，让他们明白自己可以在这些模型中进行原型设计，而不必害怕。我希望他们看到，尽管这些模型看起来简单甚至有些愚蠢，但它们依然能出色地完成任务。我想拓宽讨论的范围。我觉得很多人谈论这些东西的方式太过神秘了。他们并不真的想告诉你他们在做什么，因为他们的工作保障建立在某种像萨满一样的角色之上。但这不应该是你工作保障的真正基础——它应该基于解决问题。如果你能恰当地解决问题，并且你能很好地解释自己，你就不会失去工作。你不必躲在没人了解这个模型背后的事实后面。

这就是这本书的目的。它适合那些乐于接受挑战、真正想了解这些模型如何工作的人。你可以和我一起操作电子表格。到最后，如果你坚持下来了，你就能真正掌握这些东西。你会知道如何有根据地讨论它们。所以我认为这对特定类型的读者来说非常有趣。这不是睡前读物。你不会在床上读它。它更像是让你坐在书桌前，身体前倾，跟着我一步步操作。所以我认为这是对市面上许多其他书籍的一个很酷的补充。

**Gutierrez：** 你为什么选择用 Excel 作为学习这些技术的工具？

**Foreman：** 已经有很多关于 R、Python 和类似编程语言的书了。不幸的是，企业领域有很多人既不用 R，也不用 Python。如果你看看会计、金融或政府部门，你会发现很多地方的分析记录系统就是该死的 Excel 电子表格和 VBA 宏。

这意味着那些使用前面提到的编程语言的书籍把这些人都抛在了后面。

你如何与他们展开关于这些技术的对话呢？你可以在他们熟悉和舒适的工具中工作，然后慢慢引导他们使用更现代的工具。在我书的最后一章，我确实介绍了 R，并说：“还记得我们花了 50 页书和 10 个 Excel 标签页构建的预测模型吗？事实证明，你可以在 R 中用三行代码调用它。”我带领读者体验这个过程，向他们展示你可以直接调用`forecast()`函数，它就能直接完成工作，这太神奇了。我能在第一页就做到这一点吗？绝对不能。你不能一开始就这样做。你必须先教导人们。

所以这就是这本书。我认为这回归了我的总体理念，即如果你要从事数据科学，你不能只是买来工具坐在那里。你必须知道你可以使用哪些工具。你必须深入了解这些技术，因为你已经像我这样的书一样学习过了。

然后，当问题出现时——哇，你的工具箱里就不会只有一把锤子了。你的工具箱里将包含所有工具。

很多数据科学家只做人工智能，而实际上有很多问题可以通过优化来解决，甚至还有一系列问题可以通过模拟来解决。你的工具箱里必须有所有这些工具。这样，当你了解所有这些后，你就能选择适当的工具以有意义的方式解决问题。

**古铁雷斯：** 从投资以数据为中心的公司中，您学到了哪些经验教训？

**埃伦伯格：** 有趣的是，最有价值的公司看起来很像平台，但它们并非一开始就是这样。它们起初往往看起来像是拥有非常具体垂直应用的初创公司。随着时间的推移，当在一个特定用例或垂直领域取得成功后，这些公司才会扩展到其他垂直领域。我认为，拥有一个非常清晰的早期用例至关重要，因为《工作中的数据科学家》第 135 页提到，当你支持这些拥有平台愿景的杰出技术专家时，很容易分心太多，“试图煮沸整个海洋”。

从一开始就构建一个通用平台往往不会成功，因为你没有解决特定客户群体已知的痛点，而这些客户已经表示愿意为此付费。所以我想最重要的教训是，要明确你将服务哪一组客户，尽管你最终可能构建出能帮助许多不同类型客户的东西。早期这种激光般的聚焦，对于展示技术实力和证明产品/市场契合度非常重要。

**古铁雷斯：** 当您审视由杰出技术专家组成的团队时，您是期望他们有一个完全成型的想法，还是更倾向于在投资前的接触中与他们共事、了解他们？



**埃伦伯格：** 几乎总是后者。这本身就是一件特殊的事情。我们是一家相当年轻的公司，正在通过与创始人建立的关系网络来打造声誉和积累经验。我们不像`红杉资本`那样历经数代而始终卓越，他们的创始人已经创办过第二、第三、第四甚至第五家公司了。

对我们而言，我们主要支持的是初次创业者，所以他们不仅没有所有答案，而且通常缺乏商业建设的经验。

我们寻找的是那些拥有令人信服的愿景、展现出编写和交付代码能力的优秀人才，并且我们愿意在未来的 8 到 10 年内与他们共事。鉴于我们与所投公司之间的高度紧密合作，确保双方合拍至关重要。

我们花费大量时间与这些更年轻、经验不足的团队在一起，帮助他们聚焦目标，成长为合格的创始人和建设者，并执行他们的愿景。

**古铁雷斯：** 与公司早期合作是什么样的？

**埃伦伯格：** 我们很早就与所投公司合作，确定在执行他们的计划时，关键绩效指标是什么以及应该是什么。关键绩效指标并非在第一天就能确定。当然，有一些通用指标是每个人都需要追踪的，但根据业务不同，你可能还需要收集其他数据元素，而这些元素的重要性只有在客户开始与产品互动时才会显现。因此，我们与公司合作，努力建立一种衡量文化。我们倾向于那些直觉上就接受数据收集和分析的创始人。我们与这些团队合作，根据他们的特定业务识别出需要追踪的正确数据，以及如何利用这些数据来改进产品和/或营销策略。

**古铁雷斯：** 在访谈中，你谈到投资那些将*被动数据*转化为*主动数据资产*的公司。你是如何找到这些公司的？

**埃伦伯格：** 识别机会有两种主要方法。一种是筛选我们大量的*进入式*交易流，这些交易流要么通过可信赖的关系以“*热*”的方式来到我们面前，要么通过不在我们网络中的人直接接触以“*冷*”的方式出现。另一种方法源于我们对某个特定市场机会或新兴领域的假设。在这种情况下，我们会主动寻找那些试图解决我们眼中市场空白问题的人，并且我们对寻找解决方案充满热情。

而帮助将被动数据转化为主动数据的问题则是在后期才出现的。

我们投资的是一个正在建立业务的团队。我们投资的是一个不是正在建立数据集的团队。数据集在许多情况下是与客户互动产生的副产品。一旦公司与客户互动，我们就可以考虑这些副产品，以及公司如何通过从数据中获取洞察来改进产品或客户体验。

**古铁雷斯：** 是什么人或什么事帮助塑造了你对数据领域的看法？

**埃伦伯格：** 除了阅读当前文献，我认为就是观察社会如何应对快速变化的条件和新技术的浪潮。随着我们投资组合的增长以及我们对所投公司有了更长的纵向经验，我们能够越来越多地了解到哪些是有效的，哪些是无效的，以及哪些是尚未解决的大问题。我们一直在收集数据，无论是来自我们自己公司的内部数据，还是我们在外部世界中观察到的东西。

**古铁雷斯：** 你最初关于以数据为中心的公司的看法是如何形成的？

**埃伦伯格：** 很大一部分是通过我在华尔街的经历潜移默化而来的。我职业生涯的最后五年都沉浸在高速数据和数据流的世界里。这让我明白，尽管 90 年代末和 21 世纪初存在的基础设施还不错，但相对于我所认为的数据速度和体量不可阻挡的增长而言，存在着巨大的差距。我明白需要出现新的技术来处理这个不断变化的世界。

另一个帮助我形成观点的经历是预测分析和语义智能如何被实际应用。同样，这些也是我们在 DB Advisors 的一些策略中涉足过的事情。所以，即使我离开了华尔街，我仍然觉得这两个领域非常吸引人。有趣的是，大多数传统的量化方法已经是众所周知的。文献资料就摆在那里，人人都可以看到，因此，要么需要在被解析以产生洞察的数据类型上进行创新，要么需要在解析现有数据以产生更好、更快洞察的技术上进行创新。

然后，当我看到广告技术领域正在发生的事情时，我凭直觉就明白，广告市场和金融市场的结构会随着时间的推移而趋于一致。至于何时会发生，我当时并不确定，但这正是指导我在早期进行广告技术投资（例如投资 Invite Media 和 TubeMogul 这样的公司）的理念。这些早期的洞察，以及它们后来被验证的方式，一直延续到了 IA Ventures。

**古铁雷斯：** 既然有了这些看法和洞察，你是否创办了一家公司来利用它们？

**埃伦伯格：** 我确实自己创办了一家公司。不幸的是，我们起步太早，犯了很多错误，最终失败了。在帮助建立这家公司的过程中，我继续做天使投资，所以收集了大量关于成功的创始人如何建立公司，以及这与我的第一手经验有何不同的数据。在我作为公司创始人失败后，我决定有一种方法可以让我继续成为建设者——那就是成为一名全职投资者。这就是促使我创办一家风险投资公司，并更好地利用我的核心能力的原因。到目前为止，一切进展得相当顺利，但风险投资和公司建设是一个非常长周期的事业。

**古铁雷斯：** 你如何引导初次创业者思考并找到他们的核心能力？

**埃伦伯格：** 当我们进行投资时，我们对创始人的核心能力已经有了一个概念。仅仅因为创始人的技能组合不完整，并不意味着他们不能成长和发展，特别是考虑到我们支持的大多数创始人都在 20 多岁和 30 多岁——这些是年轻人，有大量的时间成长和发展。然而，有些人就是不想改变。比如说，一个创始人非常专注于技术，他们只想写代码。所以他们既不想做 CTO，也不想做工程副总裁。他们真正想做的是首席架构师。我们尝试做的是支持那些人才济济的优秀小团队。然后，随着时间的推移，当公司执行他们的计划并相应配置人员时，他们和我们都会重新评估角色和职责。

有些技术型创始人绝对、肯定地想要成为 CEO，然而他们知道，与那些成功将公司做大的前辈相比，自己在知识和经验上存在差距。这些技术创始人中的许多人会积极寻求指导。他们思想开放，渴望拓展自己的技能组合。然而，有时候，一个创始人认为自己想当 CEO，但当他被要求负责招聘、财务和整体监督时，他们会意识到(a) 他们不擅长这些，并且 (b) 他们讨厌这些。
