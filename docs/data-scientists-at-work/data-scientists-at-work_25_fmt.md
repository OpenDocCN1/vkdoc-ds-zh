# 专访 MailChimp 的约翰·福尔曼

在某些组织中，如果有一个关键的分析项目需要不断优化、变得更好，那么雇佣那些不需要专注于与他人沟通的人可能是合理的。例如，在大型搜索公司中负责广告投放，你只需要雇佣那些在特定领域写过博士论文的人，不需要他们懂得如何沟通。你只需要他们做好本职工作，就能从他们改进人工智能模型中获得巨大的边际收益。

但在像 MailChimp 这样的组织中，收益是通过协作和解决新问题来实现的，因此你必须懂得如何沟通。所以，这是我真正看重的一个关键点。这不只是技术熟练度，还包括学习能力和与他人沟通的能力。

## 第 6 章 | 约翰·福尔曼，MailChimp

**古铁雷斯：** 你认为找到并雇佣合适的人选是容易还是困难？

**福尔曼：** 我觉得找到并雇佣合适的人选很难。这实际上是一件非常困难的事情，因为当我们审视现有的大学教育体系时，无论是本科还是研究生阶段，你都只专注于一个领域。你会专业化。但数据科学家有点像新时代的文艺复兴人士，因为数据科学本质上是跨学科的。

这就引出了那个著名的笑话：数据科学家是那种比程序员更懂统计学，又比统计学家更会编程的人。这个笑话想说明什么？它说的是数据科学家是对两方面都懂一点的人。但我认为他们懂的不仅仅是两方面。他们还必须懂得沟通。他们需要掌握的也不仅仅是基础统计学；还必须了解概率论、组合数学、微积分等。懂一些数据可视化也有好处。他们还需要知道如何处理数据、使用数据库，甚至可能还需要一点运筹学知识。他们需要了解的东西很多。因此，找到这样的人变得非常困难，因为他们必须涉猎多个学科，并且能够明智地讲述自己的经验。

这对任何求职者来说都是一个很高的要求。

雇佣一个人需要很长时间，这就是为什么我认为人们一直在谈论当前数据科学领域人才短缺的原因。

我认为这在某种程度上是事实。我认为一些新开设的学位课程会有所帮助。但即便如此，对于从这些课程毕业的学生，在 MailChimp，我们会考察他们如何清晰地向我们阐述，是如何运用该课程教授的多学科数据科学技能的。这一点就会淘汰掉很多人。我希望有更多课程能侧重于职场中数据科学家的沟通与协作能力。

**古铁雷斯：** 在构建数据科学产品时，你在 MailChimp 如何处理与用户数据相关的隐私和用户期望问题？

**福尔曼：** 首先，MailChimp 不通过任何与用户或读者利益相悖的方式来盈利。我们的收入来自基于许可名单的用户的月度订阅费。这意味着，我不需要以欺骗、操纵或任何方式从客户身上榨取更多钱财的方式来使用数据（比如广告投放）。当我使用数据时，是符合客户期望的，这非常棒。

显然，内部律师提供了巨大的帮助。但问题的关键并不在于法律，不是吗？关键在于用户的期望。因此，拥有如此活跃且与我们保持联系的用户群是很好的，因为比起任何法律，他们总能清晰地表明自己的偏好。我们的用户会说：“我认为这样做是可以接受的，那样做是不可以接受的。”这也是我们追求最大化用户满意度而非冷冰冰的

无情 KPI（关键绩效指标）的另一个重要原因。因此，我们不断倾听用户的意见，以理解如何恰当地使用数据来为我们的服务增值，并以一种让我们的用户和我们自己都感到舒适的方式。

**古铁雷斯：** 尽管市面上已经有那么多优秀的书籍，您能否详细说明为什么认为有必要写一本关于数据科学的书？

**福尔曼：** 这又回到了我热衷的一个话题，也许很多人并不在意，那就是：人们很容易痴迷于工具——你必须时刻警惕。让工具替你完成所有工作是非常容易的。但我认为，数据科学从业者了解这些工具在做什么是很重要的。你不必知道所有细节，但应该有一个总体概念。

这一点在研究生阶段就深深地烙在了我的脑海里。有一次课上，教授让我们手工构建一个优化模型。我们必须手写在纸上完成单纯形法的所有迭代运算。那真是糟糕透顶。任何时候你要手工对矩阵进行大量运算，都是一场噩梦。他让我们只做了一次，之后我们再也不需要手工做了。虽然过程很痛苦，但现在当我运行单纯形法时，我清楚地知道背后发生了什么，因为我曾用手工做过。

这对于直观地理解你所做的事情非常有帮助。

当你构建一个模型时，你会本能地知道自己在做什么，以及当你调用某个方法时，它会做什么。如果你没有做过一次，没有真正学习并内化它，那么我觉得你内心总会潜藏着某种隐秘的疑虑。而且你将无法完全证明或相信你所做的事情，因为你在某个时刻就像念了一句神奇的咒语：“调用这个人工智能模型。”你实际上并不了解它在做什么。你可能会对它期望过低，也可能期望过高，但就是无法完全理解它。

我认为很多人工智能模型其实非常“笨”。朴素贝叶斯是你见过的最笨的东西。所以，既然我知道它是如何构建的，并且实际上手工做过一次，我就大概知道它能达到什么效果，因为我了解它内部的工作原理。

因此，我写那本《数据智慧》的目的是，带领读者体验各种不同类型的建模。它引导人们从无监督人工智能一直到数据挖掘。它多次引导人们进行有监督人工智能建模。它还引导人们进行预测、异常值检测、优化和模拟。而他们进行建模的方式是在电子表格中手工完成每一个模型。

他们在电子表格中完成，因为这样无处可逃，也无法隐藏。你亲手完成每一步，就能看到它是如何工作的。我这样做有几个原因。一是向人们展示这不是什么黑魔法。数据科学和机器学习周围有很多非常酷的词汇，让它们听起来像《终结者 2》里那样，机器人要来毁灭地球。然而，当你看到像提升树模型这样的东西时，它虽然相对前沿，但并没有那么难。我认为一个有大学一年级数学基础的人就能构建那个模型，并理解关于它的一切。
