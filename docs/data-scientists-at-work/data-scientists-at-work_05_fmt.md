# *到 2018 年，美国将面临 19 万名熟练数据科学家的短缺，以及 150 万名能够从大数据洪流中获取可操作洞察的管理者和分析师的缺口。*
——麦肯锡报告

数据科学的兴起正日益受到关注，而`数据科学`这一术语本身充满争议——关于它的定义以及它是否真正算作一个领域——这已不是秘密。在《工作中的数据科学家》一书中，我采访了来自十六个不同行业的十六位数据科学家，以了解他们如何从理论上思考这一领域，以及非常实际的问题：他们正在解决哪些问题、数据如何提供帮助，以及取得成功需要具备哪些条件。

为了反映数据科学自身所处的动态变化，本书所调查的数据科学家样本在`数据科学`是否指代一个连贯学科、以及`数据科学家`是否指代一个明确定义的职业这两个术语的意义和实用性上，观点各异。本着充分透明的原则，我本人属于相信数据科学确实是一门新兴学术学科、并且数据科学家在组织中应拥有恰当角色的阵营。此外，我相信我为本书采访的每位对象都是真正的数据科学家——而在与他们所有人相处之后，我对数据科学的未来感到无比兴奋。

## 引言

尽管其中一些人对于该领域所吸引的关注热潮持谨慎态度，但这十六位数据科学家都坚信他们所做工作的力量以及所采用的方法。所有十六位受访者都处于理解并从数据中提取价值的前沿，跨越了多种公共和私人组织类型——从初创公司和成熟企业，到初级研究团体和人道主义非营利组织——以及多样化的行业领域：广告、电子商务、电子邮件营销、企业云计算、时尚、工业互联网、互联网电视与娱乐、音乐、非营利、神经生物学、报纸与媒体、专业与社交网络、零售、销售情报和风险投资。

我的采访方法采用开放式提问，以便每位受访者的个性和自发思维过程能够清晰而准确地展现出来。我的目标是深入了解他们如何成为数据科学家、他们热爱这个领域的哪些方面、他们的日常工作内容、他们如何构建职业生涯、如何发展技能、他们对想成为数据科学家的人有何建议，以及他们认为这个领域的未来会怎样。

尽管所有十六位受访者在数据科学方面都表现出色，但最让我印象深刻的是每个人对“人”这一商业侧面的重视——不仅体现在指导后来者方面，还体现在他们的数据产品和公司如何与客户及用户互动上。无论公司规模和阶段、资历、行业和角色如何多样，所有十六位受访者都分享了对数据使用方式的深切伦理关怀。

采访中弥漫着乐观情绪，谈论数据科学已取得的进步、它如何被使用，以及未来不仅涉及工具、技术和数据集，还关乎人们的生活如何通过数据科学得到改善。我所有的采访对象都相信，他们正忙于创造更美好的未来。

为了帮助这个庞大的集体事业招募未来的同事，他们回答了那些将数据科学视为潜在职业的人提出的紧迫问题——关于应使用哪些正确的工具和技术，以及要成为一名数据科学家，真正需要了解和理解什么。本书中的从业者分享了他们对数据科学含义的个人思考、如何理解它、如何加入该领域的建议，以及通过经验积累的智慧：数据科学家必须深刻理解什么才能在该领域取得成功。

数据正在以指数级速度生成，而那些能够理解数据并从中提取价值的人现在比以往任何时候都更需要。因此，请享受这本书，并从这些深思熟虑的从业者身上汲取关于数据和模型的来之不易的经验教训与乐趣，让它们成为你生活的一部分。
