# 访谈：数据科学与原型缩放测试

**Lenaghan:** 如果原型在缩放测试中表现良好，我们就进入生产阶段。我会说大约 60%的时间我们会让工程团队介入，而大约 40%的时间我们自己做。如果我们需要真正高性能且复杂、涉及大量配置的东西，那么我们总是会让工程团队参与进来。最终，会有一个将原型迁移到生产代码的流程。工程团队会把我们的联合成果推送给`dev ops`团队，并由此将其移入生产环境。然后我们进行监控，并希望再也不用去动它。

**Gutierrez:** 你们如何进行缩放测试？

**Lenaghan:** 我们逐步在两个维度上提升原型处理的数据规模。我们有地理空间维度，这个维度很大，但并非极其巨大。在这里，我们讨论的是数以亿计的实体，假设在美国境内。我们还有第二个维度，我们认为是动态方面。这是来自广告请求端的数据。这些数据量级约为每月数百亿个数据点。我们想了解原型在两个维度——空间维度和动态维度——上缩放的性能如何。通常，我们从地理空间方面开始，只对一个都市区域应用分析。出于各种原因，我们总是使用旧金山。我们也可以使用纽约市，但曼哈顿太过异常。

**Gutierrez:** 旧金山是空间维度测试的基础都市区吗？

**Lenaghan:** 完全正确。我们从设置以该大都市为起点的初始地理尺度开始，然后在动态方面，我们从一天的数据量开始。接着我们将数据量扩大到一周的数据量，再扩大到一个月的数据量。每一步我们都在测试原型的性能表现。根据项目或产品的不同，进一步的测试需要不同长度的历史数据。有趣的是，数据越多并不总是更好，这完全取决于产品。

**Gutierrez:** 测试取决于产品、数据历史以及你在建模的内容。如果是一个针对十二月份假日的原型，你肯定不会想使用仲夏的数据。

**Lenaghan:** 完全正确。

**Gutierrez:** 除了最明显的信息内容之外，数据集还有其他有趣的方面吗？

**Lenaghan:** 事实证明，数据中的许多偏差都源于这样一个事实：所有的动态数据都来自智能手机。这意味着你的数据完全偏向于拥有智能手机的人群。这是一个庞大的人群，因为目前美国大约有 1.1 亿部智能手机。虽然这代表了美国人口的一大部分，但这仍然是一个有偏差的样本。所以我们必须处理数据中的这种偏差。

**Gutierrez:** 还有其他需要考虑的重大偏差吗？

**Lenaghan:** 我们看到的移动历史记录也存在很大的偏差，因为这些手机并不会一直每隔 5 分钟就留下“面包屑”轨迹。只有当有人使用某个支持广告的应用程序时，它们才会被激活——所以这里也存在偏差，这意味着你最终会偏向于使用支持广告的应用程序的人。事实上，人们经常使用的不同支持广告的应用程序会产生偏差，比如短信应用、与朋友拼词（`Words with Friends`）或其他应用。免费短信应用往往朝一个方向偏移，而与朋友拼词这类应用——连我妈妈都在用——则往往朝另一个方向偏移。在解读我们的数据时，我们必须不断地对这些以及许多其他类型的偏差进行校正。

**Gutierrez:** 让我们更深入地探讨一下偏差。这些偏差是您和同事们自己发现的，还是业内已知的、基于人口、社会及/或心理特征的启发式标准（`heuristics`）？

**Lenaghan:** 这是我们在内部自己琢磨出来的。我们一直非常清楚的一点是，我们不想成为一个毫无特色的黑箱机器学习平台。因此，我们偏差校正工作的很大一部分是建立在社会人类学基础上的。我们会查看动态数据，并向办公室里有人类学或社会学背景的同事提问，以加深理解。我们真正想要理解的是：“我们该如何解读这些数据？它以这种方式产生偏差，为什么？”很多时候，数据本身无法回答这些问题。关键的一点是：永远不要低估领域特定知识的力量。

**Gutierrez:** 你认为在 PlaceIQ，最有帮助的领域特定知识是什么？

**Lenaghan:** PlaceIQ 这里的领域是“人”。人们在做什么？这些人是谁？我们可以基于直觉或人类学，将什么样的启发式方法（`heuristics`）叠加到我们的数据上，使其真实可信？这为我们带来了巨大的优势。我们有很多分析师，他们仅凭人类经验就能判断某事可能成立或不成立，从而绕开我们的一些算法工作。

**Gutierrez:** 你们始终牢记，海量数据的背后是真实的人。

**Lenaghan:** 正确——我们希望构建一个分析平台，而不是给客户提供黑箱式的答案。我们真的希望被用作、并被视作一个为分析师服务的增强智能（`augmented intelligence`）服务。这些人是开展市场营销活动的人，他们是从事消费者洞察业务的人。

**Gutierrez:** 这里有一个关于“数据尾气”的概念。在摄入和分析数据的过程中，你也在生成可能对其他人有用的数据。你们如何看待这些二级数据？你们考虑过将其商业化、回馈社区、或是两者结合吗？

**Lenaghan:** 这是一个非常好的问题。目前，我们并没有这样做。我们专注于消费者洞察，尤其是移动广告领域。话虽如此，我认为公司的长期愿景是平台本身。这是一个我们可以授权给其他人的平台。这是一个拥有潜在 API 的平台，可以将这些情境化信息回馈给社区。我认为这真的是公司的发展方向。这不是我们接下来一段时间要做的事情，而是在未来几年内要做的事情。

**Gutierrez:** 说到社区，你之前提到你们使用了`R`、`Python`和`Java`，这些都是由开源软件社区构建的工具。你们使用什么工具，在你的职业生涯中这些工具发生了怎样的变化？

**Gutierrez:** 是不是所有人都用`Python`来做原型？

**Lenaghan:** 在构建原型方面，我们大量使用`Python`和`scikit-learn`（`Python`的机器学习库）。团队里的其他人很多使用`R`，尤其是那些统计学背景出身的人，他们非常精通`R`。然后我们还有一些来自金融背景的人，所以他们仍然写很多`Java`。
