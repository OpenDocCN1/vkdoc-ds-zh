# 第二章

## Caitlin Smallwood，Netflix 公司

**Caitlin Smallwood** 是 Netflix 公司的科学与算法副总裁。Netflix 是一家提供按需互联网媒体服务的公司，流媒体播放电视节目和电影。Netflix 在超过 40 个国家拥有超过五千万订阅用户，并且正在迅速扩张，会员可以在任何时间、任何地点、几乎任何联网屏幕上随心所欲地观看节目，无需忍受商业广告或长期合约的束缚。Netflix 处于互联网电视的前沿，并通过开始开发和制作自己的节目进一步巩固了其领导地位。随着提供和消费的内容数量快速增长（目前每月流媒体播放的电视节目和电影时长超过 10 亿小时），有效个性化推荐和确保即时内容交付所需的预测引擎和数据基础设施也变得越来越复杂。

为了应对 Netflix 的这些挑战，Smallwood 运用她在实验、分析和推荐方面广泛的技术专长，这些专长源于她在互联网数据产品领域超过二十年的经验，包括曾任职于 Intuit、Yahoo! 和 Hyperion Solutions。她在 Netflix 还担任过其他多个职务，最近的是消费者科学与分析总监，并曾在普华永道和 SRA International 担任分析顾问。她拥有斯坦福大学运筹学硕士学位和威廉与玛丽学院数学学士学位。

Smallwood 的职业生涯贯穿了大数据、分析、实验和推荐从互联网诞生之初到我们今天生活的这个永远在线、数据丰富的世界的整个演变过程。她分享了对互联网时代之前分析的看法，当她第一次在 Yahoo! 遇到海量数据以及在 Netflix 遇到第一个数据集时的兴奋之情，以及她对在以数据为中心的组织中文化和团队重要性的见解。她的观点独特而卓越。Smallwood 的访谈充满了智慧、经验和领导力。

**Sebastian Gutierrez:** 在 Netflix 工作感觉如何？

**Caitlin Smallwood:** 从很多层面来说，这都是一段引人入胜且激动人心的经历。虽然我觉得自己很幸运能在许多很棒的地方工作过，但我在 Netflix 感到无比快乐。

从使命角度看，公司正在变革电视行业。互联网电视的黎明令人着迷，能参与其中是一件很棒的事。从人员角度看，我喜欢在像我们这样的文化中工作。我们在招聘网站上发布了一份名为`Netflix 文档：自由与责任`的公开文化文档，它定义了我们的核心价值观。伟大之处在于，这种文化和你从文档中读到的一模一样。确实如此。从你面试的那一刻起就能感受到。身处一个真正拥有如此多自由、并能与众多杰出人才共事的地方，这种感觉非常强烈。无论从个人还是职业角度，能享受到在这种文化下工作的益处，都是非常棒的。

从数据角度看，身处数据世界，在 Netflix 这样的公司工作简直无与伦比，因为从高管到基层，整个公司都非常重视数据。这种观点使得处理数据的任何方面都成为一种享受，无论是数据工程、分析，还是更硬核的数学建模。这很棒，因为你不需要为了诸如“我们能否捕获这类数据？”或“是否有人愿意投入精力来构建我们真正想用来做大事的数据结构？”之类的问题而争论不休。

说服人们这些项目很重要并不难。而且，大量的数据争论和公开分享，以及结果的公布，使这一切变得非常激动人心。

**Gutierrez:** 你的团队在组织中处于什么位置？

**Smallwood:** 我向产品部门汇报，我的经理是首席产品官 Neil Hunt。虽然我是产品部门的一员，但我的团队更像一个支持整个公司建模需求的中心化团队，无论是预测建模还是其他建模。产品部门的同事们都非常出色，每个人，无论级别高低，都在自己的领域非常强大。

在公司范围内，创新的水平一直激励着周围的每一个人。

例如，在产品部门，我们经常召开战略会议，Neil Hunt、所有副总裁以及各个级别的人员都会参加，会议议程非常精彩。在这些会议上，会有人提出关于产品的新想法，并附上数据、分析结果或 `A/B` 测试的结果来支持，然后所有人都会公开讨论这个想法，这是一种非常棒的学习方式，也能让更多的想法涌现出来。所以，这部分工作真的让人充满活力。

**Gutierrez:** 是谁推动了数据文化？你加入的时候它就已经存在了吗？

**Smallwood:** 我加入时数据文化就已经存在了，并且它还在不断增强。至于谁推动了它，我认为没有某个人或某个组织。这实际上是集体努力的结果。你会看到这种文化让每个参与其中的人都充满活力，所以它本身就会自我强化。话虽如此，我们的首席执行官 Reed Hastings 是拥有如此强大数据文化的重要原因。他相信因果关系而非相关性，并且非常强调在做决策时尽可能依赖数据，而不是仅凭判断。当然，良好的判断力很重要，但尝试用数据和分析来支撑决策一直是他的信念，而这种信念也正是从这里传播开来的。

**Gutierrez:** 公司内部对自身数据的开放程度如何？

**Smallwood:** 在内部，我们非常开放。事实上，如果有人不公开他们的数据，他们会被公开指责，因为隐瞒你知道的信息被认为不是一件好事。我们鼓励你思考公司在不同业务领域的战略，如果你知道某些信息，或者有一个见解或一组数据可以帮助其他组织，你被期望以一种对公司有用的方式分享它。当然，你也要确保不会用太多信息淹没他人，对吧？这其中需要判断力，也包括对分享多少的判断。

**Gutierrez:** 你今年在做什么工作？

**Smallwood:** 我的第一反应是，Netflix 的一年相当于别的公司的七年。由于流程精简，Netflix 是一个非常高效的公司。这意味着我们一年内能完成非常多的工作，所以我将简要列举过去一年我们一直在做的一些事情。我们在个性化算法、推荐系统以及相关算法上做了大量工作，这是一个持续优化的领域。我们一直在努力改进它，这是一项重大的投入。

我们也在研究搜索，这是 Netflix 产品中一个非常有趣的领域。我们一直试图让搜索体验对用户来说非常敏捷。例如，在搜索自动补全功能中，当你输入字母`A`时，我们希望根据你的历史记录和 Netflix 的总体使用情况，立即知道你在搜索哪部电影或电视剧。

在产品方面，我们已经发展出浓厚的实验文化，现在我们正试图将同样严谨的态度应用到业务的其他部分，比如我们的营销组织和其他部门。这很有趣，因为组织的其他部分在决策和探索想法方面有不同的思维方式和方法。这对我们来说是一个重要的领域。

我们一直重点关注的一个关键内部事务是，为用户创建小巧、灵活的界面，以便他们探索模型的输出，让这些数据不再难以访问。例如，我们的排名算法会如何向你展示 Netflix 中所有片名的排名？我们能否向你展示这个内部工具，来帮助你？这类工具有助于加快创新，因为这样 Netflix 的每个人都能访问模型输出，去研究和理解它们。这会反过来激发他们对自身工作的思考。因此，我们一直努力以更多人可以利用的方式，更多地暴露这些复杂模型的输出。

**Gutierrez:** 流程精简意味着什么？它是如何让你完成这些优秀产品的？

**Smallwood:** 这意味着我们真的没有那些让你为了完成工作而“跳火圈”的程序。我不需要获得批准才能开展工作，举个例子，我获取一个软件也不需要经过什么审批流程。我们只需要运用良好的判断力，不浪费公司的钱。诸如此类的每件小事都很重要。它无处不在。体现在采购、差旅，以及所有事情上。

这种流程精简也适用于项目。我们不会规划一个项目，然后正式地从需要为完成该项目做出贡献的不同团队那里获取资源。在战略会议上，如果一个主意很棒，大家就会清楚，然后会有人牵头这个计划，并去找需要参与的各个团队。我们彼此信任对方的判断，因此人们会找出如何以及何时完成工作的方法。这让一切变得非常敏捷。

**Gutierrez:** 是什么让 Netflix 运转得如此之快，以至于感觉一年浓缩了多年的工作？

**Smallwood:** 对我们来说，这种速度源于我们对业务的热爱，以及我们对改变电视观看体验、让体验更多地掌握在客户手中这件事的热情。帮助客户弄清楚他们想看什么、想看多久，并使之成为无缝、轻松的体验，是让我们非常兴奋的事情。我们对此欲罢不能。

我们招聘的是非常有自驱力的人。当整个公司都是充满热情、对自己所做的事感到兴奋的人时，你真的很难慢下来。这已刻入基因。当然，随着竞争对手进入市场，如果我们真的希望我们出色的业务持续繁荣，快速行动也是一个正当的商业需求。

**Gutierrez:** 你会如何向一位数据科学家描述你的工作？

**Smallwood:** 我会说我们是一个处理各种统计建模的团队。作为一个团队，我们主要关注并产出三样东西。我们使用该领域的人熟悉的所有技术来开发预测模型——`回归技术`、`聚类技术`、`矩阵分解`、`支持向量机`等，包括监督和无监督技术。

第二样是算法，我认为它们显然与模型密切相关，只是它们被嵌入到某种持续进行的过程中，比如我们的产品。然后第三样是实验以及其背后的所有科学方法论，我们利用这些方法，以及我们运行的每个实验附带的所有数据分析。

**Gutierrez:** 你会如何向非数据科学家描述你的工作？

**Smallwood:** 我会说，我们收集所有客户如何观看以及观看什么的数据。然后我们在数据中寻找模式，利用这些模式向他们推荐可能想看的内容，从而从根本上改善每个人的服务。因此，我们利用整个用户群体的信息，让我们的每一位客户都更满意。

**Gutierrez:** 你是如何获得目前在 Netflix 的职位的？

**Smallwood:** 我的第一份工作是在一家咨询公司做程序员。那时我甚至没有做什么复杂的算法工作。通过这份工作，我偶然遇到了一个优化问题，这让我对运筹学（OR）产生了兴趣。兴趣如此浓厚，以至于我回到研究生院学习运筹学。研究生毕业后，我去了一家专注于为不同行业和公司构建运筹学模型的小公司。这家公司后来被普华永道收购。那段时间很棒，但恰逢互联网热潮兴起，一切都变了，机会呈爆炸式增长。

我感觉自己很幸运，我的职业生涯恰好与互联网时代重叠。突然间，就像，嘿，有这么多以前没有的数据，有全新的机会来构建模型，有全新的问题需要解决。过去需要“建模”的东西不再需要模型了，因为有大量的数据。你只需要弄清楚某个特定维度值的中位数就可以了。这改变了整个机遇格局。

随着互联网热潮的发展，我对开发产品产生了浓厚的兴趣。这让我进入了创建分析产品（如个性化引擎或其他产品组件）的领域。这是我职业生涯从运筹学转向算法和数据领域的转折点。能够将数据与人以及人们可能采取的行动联系起来，带给我前所未有的兴奋感。对我来说，通过数据发现关于人的东西真是一件很酷的事情。就这样一步步地，我从事了越来越多的分析产品和组件的工作。
