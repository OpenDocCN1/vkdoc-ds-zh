# 另一个令人惊叹的案例，展示了真正审视数据能学到什么教训。

它发生在最近一次调查欺诈案件时。我的首席技术官走进来说：“各位，你们在过去两周内将我们所有广告活动的效果提升了一倍。有什么要跟我说的吗？”我们面面相觑，因为我们实际上什么都没做。唯一做过的事情就是从各个交易所添加了一些新数据。但一旦你知道预测人类行为有多难，业绩翻倍这个事实本身——就有点吓人了。最终发现，确实，业绩翻倍是因为存在实施欺诈的机器人。我们之所以能通过数据识破这一点，是因为这些机器人的行为非常机械刻板。

整件事最初只是一个业余项目，目的是搞清楚为什么业绩会翻倍——这在某种程度上是件好事。但我们足够怀疑，以至于没有轻信。结果发现，整个机器人网络都在欺骗我们。好吧，我很高兴我们讨论并搞清楚了这一点。从那以后，我们实施了一整套监控系统来防范这种情况。这类事情非常典型：我们开始调查一些事情，说：“嘿，发生了一些非常令人惊讶的事情”，而答案通常与你最初的推测完全不同。这就是学到的教训：始终要对旁枝末节保持开放心态。我认为这是一种很好的技能：不要仅仅缩小范围，只盯着你眼前的特定问题。保持开放思维，看看这里还在发生什么。你通常会在过程中发现更多事情。

**佩利希：** 我认为这确实是优秀数据科学家的标志——你必须对应该发生的事情有一定的直觉。你不需要成为医学专家才能意识到患者 ID 具有预测性是一个问题。只需要一些常识就能观察到这一点。我认为这种直觉是通过大量经验培养出来的。你未必能仅仅通过将计算机科学家或数学家训练成数据科学家。

我所观察到的是，有一类人能够接纳不确定性和噪声及其含义。还有另一类人则喜欢生活在一个确定性的非黑即白的世界里。从某种意义上说，他们相信当你对列表排序时，它就被排好了。一旦算法对列表排序，它总能正确排序，因为这就是它的设计目的。算法要么是正确的，要么是错误的，但你有非常明确的正确性度量标准。

一旦你转向数据层面，整个世界就出现了更多灰色地带。对我来说，观察我们与一些工程团队的互动真的很有趣。有些人能理解这一点，有些人最终也能想明白，而有些人则觉得只要完成了列表上的步骤就算完事了。最后一类人没有理解到，执行完这些步骤之后，你必须开始审视输出结果，检查这些输出是否合理。“合理”或“这不应该发生”并不在这些程序员的非正式检查清单里。

因此，数据科学家需要这种围绕数据的直觉部分。这就像怀疑精神和抱有预期一样，是性格的一部分。我和我的朋友安德烈亚斯·魏根德进行过一次长谈，他是第一个让我对数据感到兴奋的人。他的信念甚至更坚定。他认为：“你必须要有情绪反应。”我说：“你只要抱有预期就行了。你需要知道你会期望看到什么，然后你才能看出它是否偏离了预期。”他认为这很好，但他更强烈地认为必须要有情绪上的反应。

**古铁雷斯：** 这是一个人与生俱来的，还是可以教授和/或学习的？

**佩利希：** 在我自己和其他数据科学家身上，我始终观察到一种能力，那就是说：“你知道，有些地方看起来不对劲”，尽管可能需要一段时间才能将这种感觉转化为可以表达的内容，并正式论证其错误之处。这通常始于“嗯，我不太确定这个。”要培养这种能力，我认为需要良好的师徒传承。你需要有人向你展示这个过程。你需要与这个过程和解。我有幸拥有非常好的导师，从安德烈亚斯开始，然后是福斯特，他对这些事情有着非常相似的背景和态度。有趣的是，这个过程并不那么正式，但只要你见过几次这个过程，你就能开始掌握它的要领。

话虽如此，你不可能强迫每个人都接受。它需要经验和学徒经历，但这是必要条件，而非充分条件。除了经验和学徒经历，你仍然需要对正在发生的事情有直觉。

**古铁雷斯：** 你如何看待自己是否在解决正确的问题或对正确的事物建模？你甚至如何知道自己拥有了正确的数据？

**佩利希：** 这是数据科学领域出现的最普遍的问题之一。要回答这些问题，仅仅有技术技能是不够的。我可能知道如何解决一个问题，但是能否对别人向我提出的问题本身是否有意义提供反馈——这是一个非常棘手的问题。

我喜欢在`Dstillery`工作的原因之一，就是这里非常欣赏数据科学的作用以及我们如何提供帮助。从商业角度来看，我们几乎从一开始就参与了几乎所有的决策过程。我在`IBM`担任咨询工作时看到的是，如果一个对话中没有了解数据能做什么的人参与，你最终往往会解决错误的问题，或者根本解决不了问题。

我喜欢把它比作牵线搭桥。首先，有你试图解决的问题。其次，有你可能有、可能没有、或想要获取的数据。最后，有算法。作为一名数据科学家，我的主要挑战是用正确的算法，将正确的数据与你实际想要解决的问题连接起来。然而，在尝试匹配这三者的过程中，也可能意味着这个问题无法用我所知的任何算法来解决。也可能意味着我们的数据可能不对。最后，还有一个问题：我们正在解决的这个问题本身是否相关、是否定义明确、是否从一开始就是正确的问题？在问题、数据和算法之间进行这种迭代的最佳方式是，你需要有一个由业务人员和数据科学家共同组成的团队。数据和算法知识存在于数据科学家手中，但要真正将其与你想要解决的业务问题联系起来，如果你能把数据科学家请进会议室，让他们从一开始就参与讨论，那就太好了。

我想到一个例子。最近有人来问我：“我们看到的`cookie`平均年龄是多少？”这个问题表面上听起来有意义，但实际上并不是一个很有意义的问题。要回答这个问题，我可以给出在一小时到三个月之间的任何数字。不仅如此，每个时间段给出的答案都可以是合理的。之所以有这么大的差异，是因为如果有人在他们的电脑上禁用了第三方`cookie`，那么该`cookie`看起来就像只存活了零秒，所以我写下`cookie`，它再也没有回来过。

**Gutierrez：** 这是否部分解释了为什么让数据科学家从一开始就参与对话是有帮助的？

**Perlich：** 是的，因为——取决于目标和背景是什么——答案可能完全不同。问题在于，很多人认为自己足够了解数据，可以谈论平均值和其他统计指标，这让他们觉得自己能提出有意义的问题。但问题在于，在现实世界中，数据不像他们在课堂和书本上看到的数据那样。他们没有意识到，自己对分布和其他统计指标的实际运作方式知之甚少。如果他们知道，就会意识到单一数字的汇总几乎总是完全无用的。而这正是我需要进行的对话部分，因为在知道你想做什么之前，我不会给你一个数字。你可能正在解决正确的问题，只是不知道如何提出正确的问题。甚至不一定是问题本身错了，你可能只是无法在提交问题时以一种有意义的方式将其表述出来。

**Gutierrez：** 你如何看待非数据科学家向你以及向数据提问这个问题？

**Perlich：** 你不能期望每个人都成为数据科学家。我并不真的需要我的 CEO 或其他管理层人员理解长尾分布的细微之处。我认为，对于管理层来说，有其他更重要的核心能力需要培养和发展。最重要的是要摆脱你过去在很多设有统计学家的机构中看到的“孤岛”模式。在这些机构中，统计学家被安置在地下室或远离业务部门的地方。没人认识他们，他们被完全隔离。你只需向他们订购一份报告，他们就会把答案返回给你。然后你根据这些报告做出任何你想做的决定。我见过的与统计学家和数据科学家合作成功的唯一情况是，问题解决是以团队形式进行的，你实际上有足够的面谈时间来与最终执行的人进行对话。

在教育和数据素养方面有帮助的是，你不必在每次讨论时都花三天时间来统一术语。至少我们必须知道如何互相沟通。当你向我索要平均值时，在开始对话之前，有一个关于平均值含义的共同语言会带来巨大的不同。否则，如果我不能迅速切入要点或理解他们问的是什么，人们几分钟后就会走开。

这意味着业务方可能应该具备一些高层次的分析理解能力。他们不需要能亲自操作，但他们需要掌握足够的词汇来理解他们的技术人员或数据科学家在告诉他们什么。同样，强制技术人员或数据科学家实际与从业者交流也是非常好的。让他们真正了解业务方以及那个世界的通用语言，并非世界上最糟糕的事情。这是双向的。这并非要让每个人都变得多才多艺，更多的是就一种用于沟通的词汇达成一致并学习它。一旦你做到了这一点，就是向前迈出了一大步。

**Gutierrez：** 当你在招聘时，你是如何思考这个过程的，沟通方面在其中扮演了什么角色？

**Perlich：** 在内部，我们一直在进行一场有趣的对话，讨论数据科学家是史上最困难的工作之一，因此如何正确地招聘一位数据科学家。随着我们最近招聘了两个人，这场讨论一直在进行。面试分两个主要阶段。首先，我们给他们半小时的时间，就他们之前的工作做一个演示。这个演示可以是他们以前做过的一两件事。然后我们会讨论一些我们正在处理的问题，并征求他们的想法。在整个面试过程中，我们主要考察四个方面：直觉测试、批判性思维、沟通能力，以及他们如何推动理解数据的过程。

我首先看的是直觉测试。我需要你有那种感觉，即当数据中的某些东西感觉不对劲时能察觉到。这是如果你没有一定的感觉，我就无法教你的东西。我可以教你语言。我完全不需要的是领域知识。当我们第一次与 HR 人员讨论需要数据科学家时，他们问我们是否需要他们了解数字广告。

我们告诉他们：“不，完全不需要。我们一点也不在乎。”相反，我更喜欢那些在十个不同领域做过十件不同事情的人，因为他们很可能从每一个不同的地方和领域学到了一些关于数据的新东西。我宁愿要广度而不是深度。所以，忘掉领域知识吧。我假设他们足够聪明，可以在两周到三个月内学会他们需要了解的领域知识。

在直觉测试之后，我们会考察其余的标准。我认为沟通能力在任何一组要求中都没有被明确提及，但这是我们在与候选人交谈时能感知到的东西。在批判性思维方面，我们可能会向他们展示数据图，然后说：“这里面有什么让你觉得奇怪的地方吗？”我们想看看他们如何处理这些信息，并提出他们认为对于真正弄清事情根源至关重要的那些问题。

然后我们会继续说：“好的，这里有一个问题。”对我们来说，甚至比谈论问题更重要的是，他们能够并且自如地开始提出正确的问题。当我提出一个场景时，我希望他们问：“你这是什么意思？”他们需要知道什么时候自己真正理解了某件事，什么时候没有。所以，思想开放并且能够推动这个过程是非常重要的。毕竟，这就是他们作为数据科学家在这里要做的事情。

## 第 8 章 | 克劳迪娅·珀利奇, Dstillery

所以现在，一家有数据科学家的公司想招聘一位数据科学家。这位数据科学家给了公司他们负责的一个项目，然后公司就应该判断这个数据科学家的模型有多好？数据科学家自己都不知道。公司也不清楚这位数据科学家到底做了什么，或者本可以做什么。而且，除非是在同一个行业，公司甚至可能并不真正了解这些数据。因此，从一个半外部的角度，甚至是管理或招聘的角度来看待一个项目，去评判它本可能达到或应该达到的水平有多好，几乎是不可能的。而这直接关系到衡量数据科学家的技能水平，因为技能水平决定了能产出多好的项目。所以，质量控制既是项目本身的问题，也转化成了评估你正在招聘或洽谈对象的技能和方案的真正难题。如果你已经有一个团队，他们既能审视项目，又能对数据科学家进行直觉判断，那就会容易一些。

**古铁雷斯：** 您如何看待数据科学的现在和未来？

**珀利奇：** 就目前而言，我不太确定我们作为一个群体处于什么位置。这种不确定性部分源于数据科学和大数据的叙事很大程度上是由那些有切身利益的人塑造的，无论是供应商还是顾问。他们专注于告诉你所有可以用大数据做的酷炫事情。这产生了许多人难以满足的期望，这是消极的一面。

与此同时，我认为人们对数据带来的机遇有了更多的认识，这是非常好的事情。因为过去二十年里，我们一直在争论数据和它的未来。我很高兴终于有人愿意听了。我认为这完全是好事。有很多人一直在用数据做很酷的事情，但可能长期被忽视。现在他们开始获得一些关注。

在未来，我认为我们将拥有一个规模大得多的、技能娴熟的人才群体。

我还认为，关于数据的教育、语言、鉴赏能力以及发现机遇的能力也将得到提升。尤其是在管理层方面，我们将看到这种知识的增长。

未来人们也会更清晰地认识到，数据科学并非总是有用的。有很多领域你并不需要数据科学家，不要让任何人告诉你并非如此。归根结底，你能用数据做的事情是有限的。如今我看到很多人鼓吹的东西，只会让我翻个白眼说：“好吧，行——随便吧。”仅仅因为某件事可以用数据完成，并不代表它就有价值，哪怕它看起来很酷。归根结底，问题必须始终是：你是否能够并且愿意根据数据采取行动。如果不能，那你就是在浪费金钱和资源，搞“数据色情”。

我认为我们还需要五到十年的时间，才能更好地理解最佳实践和预期，知道什么时候事情真正有效且有用，什么时候并非如此。我不认为数据科学的实践方式会发生根本性的改变。随着炒作降温，我认为一些流传的更硬核的概念，比如优化，会得到更多的认可，而一些炒作性强的东西，当人们意识到它们最终无法产生真正影响时，热度会有所下降。

例如，每当有人向我索求可执行的洞察（`actionable insights`）时，我都会非常犹豫。这让我害怕。真的让我害怕，因为如果你不先告诉我你的行动是什么，你怎么能期望我告诉你可执行的洞察呢？除非你非常清晰地沟通，并且思考清楚你到底能做什么、愿意根据数据做什么，否则让我像没头苍蝇一样在数据里乱转，然后带回所谓的可执行洞察，这根本就是徒劳的任务。你给我的数据越多，情况就越糟，因为我会找到更多可能毫无意义的东西。我认为我们需要改变这个过程，而这又回到了沟通问题上。我认为这将会改善，但我不认为会有任何根本性的改变。

我不相信数据科学会被自动化。我不相信你的秘书能为你做数据科学，尽管它被宣传成那样——好像人人都能做数据科学。这不是真的，因为通常情况下，问题出在数据上，你必须先找到问题，如果你不了解数据，你就无法做到这一点。仅仅因为你可以在数据上运行算法，并不意味着你得到了有意义的结果。你确实需要审视数据。这种能力必须具备。必须有人在其中，在某个环节。你不能把一切都隐藏起来，抽象成数据层和酷炫的工具。那是行不通的。

**古铁雷斯：** 你认为数据科学应该重点关注哪些领域？

**珀利希：** 我认为数据科学在医学领域，特别是大众健康方面，有巨大的机会可以产生重大影响。要实现这种影响，我们必须回过头来，真正弄清如何处理隐私和数据共享问题，以便奠定良好的基础。我个人曾多次放弃医疗应用项目，因为我总是被 `HIPPA` 法规卡住。这令人沮丧，因为我感觉自己的手脚被束缚住了。知道如果不受限制，我本可以产生巨大影响，这非常令人沮丧。

在医疗领域，我认为至关重要的是，我们要更好地理解这些法规所带来的利弊权衡。我们需要让医学专家清楚地沟通哪些事情可以做，以及处理数据的人会是谁。与大多数事情一样，部分问题在于信息共享的缺乏。每个医生基本上都有自己读过的病例，并且了解自己过去二十年职业生涯中做过什么。

所以当医生遇到一个新病人时，他们是在利用自己的经验以及他们读过的病例——可能甚至包括来自医学期刊的一些内容。更好的做法是，能够以保护隐私的方式，将某个人的具体情况、病情、用药和症状结合起来，输入到一个系统中。然后我们可以让系统告诉医生：“这种情况我们见过大约 15 次。如果你采用治疗方案 X，这个病人会恢复得很差，所以这不太是你想要的。但是，如果你采用治疗方案 Y，这个病人会好转。”

因此，能够拥有关于医疗状况、症状、诊断、用药、治疗方案和结果的集体经验，将是极其有益的。

毕竟，数据本质上就是这样——将发生的集体经验汇集在一起。这很重要，因为临床试验存在两个问题：(a) 临床试验从来都不是在真实的生活环境中进行，人们会服用所有药物，因为受试者是经过严格筛选的；(b) 另一方面，我确实有一些担忧，而且这些担忧已经被多次提及，即某些临床试验的可靠性如何。我暂且就说到这里。

我认为，通过观察性数据，我们可以学到更多，了解哪些是有效的解决方案，哪些是无效的解决方案。在获得更多观察性数据的同时，我们还需要更好的数据监管形式。必须处理好数据监管和隐私影响。我认为这普遍适用于广告和隐私领域。不仅仅是在医疗应用和人们在 Facebook 上分享的、被用于各种目的的社交数据中。

我认为医疗应用是最能说明“这才是真正应该做的事情”的案例。我们需要开始能够不带煽动性地比较收益与成本。

当我听到像 Target 事件那样孤立的、耸人听闻的例子——父亲发现女儿怀孕了——我感到不安。父亲们每天都会通过各种方式知道他们宝贝女儿怀孕的消息。无论是女儿的朋友告诉他们，还是爱管闲事的邻居不小心说漏了嘴，或者其他什么方式——这些事情一直都在发生。那也是生活的一部分。我不一定想借此呼吁更精准的营销定位。

相反，我认为我们必须面对这样一个事实：隐私有时确实可能被侵犯。毕竟，这在现实生活中每天都在发生。

所以，我对那种利用这种情况来煽动巨大抗议的小报氛围感到不安。事实是，你无法让隐私密不透风。这不能成为目标。我们需要就利弊权衡进行一次真正有意义的对话。遗憾的是，我认为这在短期内不会发生，因为隐私倡导者常常站在一边，抱怨连连，却拿不出任何更好的方案；而另一边，普遍的态度更接近于：“天空才是极限，我们想怎么做就怎么做。”

所以，双方都没有走到中间来推进讨论。我正在寻找一个真诚的中间地带，但我没有看到。我不确定如何达到那里，但我很希望能就此进行更有建设性的辩论。一旦我们达到了，我认为数据科学在医疗领域就有巨大的机会可以产生重大影响。

**古铁雷斯：** 对于刚入门的人，他们应该努力深入理解什么？

**Perlich：** 我认为，学习数据科学归根结底就像学滑雪。你必须亲自去实践。你可以看很多视频，观摩别人怎么滑。但最终，你还是得踩上你的雪橇，从山坡上滑下去。途中你会摔倒几次，这没关系。这正是你需要的学习体验。实际上，我更喜欢问面试者那些不顺利的事情，而不是他们成功的地方，因为这能告诉我他们从过程中学到了什么。

## 乔纳森·莱纳汉

### PlaceIQ

`乔纳森·莱纳汉`是`PlaceIQ`的数据科学负责人。`PlaceIQ`是一家移动地理定位智能公司，为营销人员聚合和分析空间数据。2014 年初，移动互联网用户首次超过桌面互联网用户。预测显示，随着我们迈向未来，这一趋势只会加速。`PlaceIQ`正处于移动广告与位置智能交汇的前沿。这一动态交汇点的快速增长带来了隐私、数据基础设施、数据规模以及智能处理数据并将数据学习成果付诸应用的能力等方面的挑战。

在涉足数据科学之前，`莱纳汉`的职业生涯跨越了理论物理研究、编辑知名科学期刊，以及在华尔街从事算法量化权益交易的量化研究。在耶鲁大学获得物理学博士学位后，他在布鲁克海文国家实验室、尼尔斯·玻尔研究所和弗吉尼亚大学进行了强相互作用夸克-胶子等离子体统计特性的研究。他曾担任美国物理学会两本期刊——《物理评论 C》（核物理）和《物理评论 D》（粒子物理与宇宙学）的编辑。

`莱纳汉`是一个从物理科学经由量化金融转向数据科学的数据科学家的杰出典范。这段极其多样化的背景塑造了`莱纳汉`对数据科学风险维度的细致理解、他乐观的实用主义，以及他坚信有用的数据科学关键在于扎实的工程基础的信念。
