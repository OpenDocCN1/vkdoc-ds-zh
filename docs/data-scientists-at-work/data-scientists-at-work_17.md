# 杨立昆谈监督学习与无监督学习

于是我开始研究并成为判别式纯监督学习的坚定信徒。卷积网络正是这种思维的产物。实际上，此前已有类似架构被使用过。例如福岛的神经认知机，其结构与卷积网络相近——虽不尽相同但高度相似。当时的研究者主要尝试使用无监督学习。我认为这种特定方法存在不足，因此卷积网络本质上是对福岛神经认知机进行监督简化的版本。与此同时，我的朋友弗拉基米尔·瓦普尼克提出了一个理论观点：永远不应试图解决比必须解决的更复杂的问题。在此语境下，无监督学习在某种程度上比分类问题更复杂——它好比在高维空间中学习密度分布，这是你能想象到的最困难的任务。所以当时我在某些方面是反对无监督学习的。

然而那个时期，杰夫·辛顿却是无监督学习的坚定倡导者和信徒。有趣的是，我们在监督学习与无监督学习的观点上始终存在相位差。当时他竭力说服我研究无监督学习，而我则不断告诉他真正奏效的是监督学习。进入 21 世纪初，我的看法发生了彻底转变。我意识到要用极深网络解决深度学习问题，或许需要无监督学习进行预训练。杰夫提出了实现这一目标的思路，这极具启发性。

于是我开始对这项工作和无监督学习产生浓厚兴趣。我研究了一种名为`稀疏自编码器`的技术，该技术现在应用相对广泛，尽管尚未真正用于工业领域。我们通过这项技术完成了一系列有趣的研究，并在某些数据集上看到了非常显著的改进。无监督学习在生物学上更具合理性，因为显然大脑更多是通过无监督方式而非监督方式进行训练。这项工作因此与神经科学建立了更多联系。这也成了一种发表论文的途径——因为如果你再发表一篇关于监督式卷积网络的论文，人们会说："你在 1991 年就讨论过这个了，为什么不换个方向？"

而无监督学习在当时算是新领域，正是它引发了人们对深度学习的兴趣。

然而后来深度学习的实际应用却全部是纯监督式的。它们本质上都是基于卷积网络的反向传播。

有趣的是，杰夫在这方面的观点也发生了变化。我的意思是，他并非彻底改变看法——他仍然认为无监督学习是长远之道，我也这么认为，吴恩达和约书亚·本吉奥也坚信这点。但在实际应用方面，他确实改变了想法，开始像我一样研究纯监督式卷积网络。他将此应用于语音识别、图像识别，并为改变学界对深度学习整体理念的看法做出了贡献。

我们一直处于某种摇摆状态：杰夫认为无监督学习是长远方向，却不得不捏着鼻子让监督学习发挥作用，因为它确实有效。而对我而言，这些年来的观念转变更为明显。如今我更接近杰夫的立场——我仍然确信在自然语言和视频等领域，无监督学习终将扮演重要角色，但我们今天实际使用的方法全是反向传播。

**古铁雷斯：** 数据科学领域未来会是什么样？

**勒昆：** 关于数据科学的未来，我经常强调的一点是：被收集和存储的数据量正以指数级增长——要么随通信网络带宽增速，要么随硬盘容量增速。这取决于数据是流式传输还是静态存储，但总是二选一。而这是个相当高速的指数增长。目前当我们试图从这些数据中提取知识时，仍有人类参与其中。地球上人类脑力的总量也在以指数增长，但增速非常非常缓慢。与数据增长速度相比，这种增速微不足道。

这意味着不可避免的是——事实上这已经发生——到达某个临界点后，地球上根本没有足够的脑细胞来检视这些数据，更不用说分析和提取知识了。因此未来世界上大部分知识都将由机器提取并存储在机器中。实际上这可能已经成为现实，取决于你如何定义知识。

对我而言，知识是能够辅助决策的数据汇编。如今我们看到计算机正在自动做出大量决策，未来这种情况只会更加普遍。

所以展望数据科学的未来，这门科学与技术——以及围绕从数据中提取知识的工程方法——将成为未来社会依赖的重要支柱。某种程度上这已是现实：互联网已经依赖于此。但未来整个社会都将依赖它。这不是一时热潮，也不会消失。如果说数据科学是一时狂热，那就像 1962 年说计算机科学是一时狂热一样。看看我们现在身处何处。

因此我的想法是，这种现象将会催生——当然它已经催生了我们熟知的产业——对专业人才的需求。同时也催生了处理这一领域的学术学科需求。这是目前某些人尚未完全理解的地方。例如，统计学家会说："这不就是统计学。"机器学习专家会说："这不就是机器学习。"数据库专家会说："这不就是数据库，再加点机器学习和统计学的应用。"应用数学家会说："所有这些技术和方法都用到了应用数学。"

所有这些人都错了。这是上述所有学科融合而成的新学科：统计学+应用数学+计算技术+基础设施+应用领域——也就是这些方法能应用的领域，这需要专业知识。因此深度学习这类技术能让我们减少或最小化解决新问题所需的人类专业知识，让机器尽可能自主完成。当然目前这个阶段仍需人类参与。只要还有人类参与，数据可视化这类工具就能帮助人们完成工作。但最终，这些模型将能够自我构建。

我坚信数据科学应该成为一门新的学术学科。
