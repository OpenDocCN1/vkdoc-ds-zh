# 引言

本书适合任何希望了解 SAP BW/4HANA 平台知识的读者。通过本书，读者将学习 SAP BW/4HANA 的新功能与组件，并获得使用现代建模概念实施敏捷数据模型的实用经验。本书尤其推荐给曾使用过早期 SAP BW 版本、计划将系统升级至 SAP BW/4HANA 版本，或已开始探索 SAP BW/4HANA 并希望更深入了解其变化及新功能的 BI 开发人员、顾问和团队领导者。

本书包含以下章节：



**第 1 章：SAP BW/4HANA 建模对象**

本章对 SAP HANA 和 SAP BW/4HANA 领域进行技术性介绍。它将引导读者了解主要建模对象，突出新功能，并解释如何创建这些对象。



**第 2 章：建模概念**

本章介绍五种建模概念，强调其用法以及各自的优缺点。后续章节将运用这些建模概念来实现满足特定业务场景需求的解决方案。



**第 3 章：通过 BW/4HANA 发布 HANA 对象**

本章将解释如何通过 BW/4HANA 层公开 HANA 对象，而无需创建持久化采集层。此外，读者还将学习如何在 BW 查询和 HANA 计算视图之间传递输入参数。



**第 4 章：创建基于字段的数据模型**

本章介绍如何在 HANA 对象之上创建基于字段的数据模型。学习本章后，读者将了解如何在不使用 InfoObjects 的情况下实现星型模型。



**第 5 章：创建混合数据模型**

本章解释用于混合基于字段的方法与 SAP InfoObjects 的混合建模方法。通过这种方法，即使源对象中不包含额外信息，您也能为模型增强信息。



**第 6 章：将 SAP 和非 SAP 数据集成到单一数据模型中**

本章演示如何整合 SAP 和非 SAP 数据，以创建一个提供 360 度数据视图的单一集成数据模型。

为了全面理解现代建模概念的各个方面，我建议从第 1 章开始，并按顺序通读本书。
