# 引言

数据科学和机器学习可以在不同的效率和生产力水平下进行实践。本书特别聚焦于基于 Python 的工具和技术，旨在帮助数据科学家（无论是初学者还是经验丰富的专业人士）在典型数据科学任务的各个方面实现高度生产力。

本书专门面向那些希望超越标准数据科学和机器学习任务执行方式、并利用 Python 数据科学生态系统的全部潜能来达到更高生产力水平的读者。你将学会如何发现标准流程中的低效环节和瓶颈，以及如何跳出固有思维模式。自动化重复性数据科学任务将是阅读本书后你将形成的关键思维模式。在许多情况下，你还将学习如何借助 Python 生态系统中已存在但未在任何标准数据科学书籍中教授的高级软件工具，以高效方式扩展现有编码实践，来处理更大的数据集。

这不是一本教授诸如 `NumPy` 或 `Pandas` 等标准库的常规 Python 食谱。相反，它侧重于实用的技巧，例如如何衡量 ML 模型的内存占用和执行速度、将数据科学或深度学习任务模块化、为数据科学库或 Web 应用开发编写面向对象的代码等等。它还涵盖了那些能方便自动化并加速任何数据科学家日常工作的 Python 库。此外，本书还涉及那些能帮助数据科学家以远比遵循标准 Python 数据科学技术智慧更优的方式处理大型复杂数据集的工具和包。

如果你在阅读本书后，养成了在数据科学代码中探究和衡量低效环节的思维习惯，并学会了发现解决这些生产力问题的有效技巧的窍门，那么我认为这本书就是成功的。这对我将是莫大的回报。
