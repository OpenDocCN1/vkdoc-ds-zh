# 引言
欢迎阅读《**R 语言中的面向对象编程**》。我撰写本书是为了提供超越大多数 R 语言教科书典型入门水平的教学材料。本书旨在介绍 R 中的对象与类，以及如何在 R 中进行面向对象编程。

面向对象编程基于对象的概念，以及根据可以对对象执行的操作和对象之间如何通信来设计程序。这通常被视为具有状态的对象，对对象的操作会改变其状态。设想一个像银行账户这样的对象，其状态就是其中的金额，存入或取出金钱都会改变其状态。我们对对象执行的操作在文献中通常被称为“方法”，但在某些编程语言中，概念模型是对象之间互相通信和发送消息，你对一个对象执行的操作就是它如何响应所接收到的消息。

在 R 中，数据是不可变的，因此你不会编写改变对象状态的代码。相反，你将对象视为值来处理，当你需要新的“状态”时，对对象的操作会创建新的对象。R 中的对象和类更像是抽象数据结构。你有值以及与这些值相关联的可以执行的操作。这种抽象数据结构在不同的编程语言中有不同的实现方式。大多数面向对象语言使用类和类层次结构来实现它们，而许多函数式语言则使用某种定义哪些函数可以应用于对象的类型规范来定义它们。

类型决定了你可以对对象做什么。例如，你可以对数字进行加法运算，也可以连接字符串，但你无法真正对字符串进行加法运算或连接数字。在某些编程语言（即所谓的静态类型语言）中，你将类型与变量关联起来，这限制了变量可以引用的对象，并能在运行代码之前进行一些一致性检查。在这类语言中，你可以通过定义可以对哪些操作来指定新的类型，然后需要为引用这些类型的变量添加类型规范。其他编程语言（称为动态类型语言）则不将类型与变量关联，而是允许它们引用任何类型的对象。R 是动态类型的，因此你无需通过类型规范来指定抽象数据类型。你可以对对象执行的操作，完全取决于你可以对该对象调用哪些函数。你仍然可以将这些视为抽象数据结构的规范；然而，它们只是隐式定义的。

抽象数据结构可以通过不同的方式实现，这正是使其变得*抽象*的原因，而将实现与接口分离的方式是通过多态或泛型函数——一种建立在面向对象编程基础上的结构。泛型函数通过类机制实现，这也源于面向对象编程。一个类实现的函数决定了该类中对象的接口，并且通过构建类的层次结构，你可以在类之间共享通用函数的实现。

抽象数据结构在算法编程中常用于实现高效的代码，但这类编程通常并非 R 程序的目标。在 R 中，我们更感兴趣的是将数据拟合到模型等，这通常不需要算法化的数据结构。然而，拟合模型也是我所指的抽象数据结构的例子。模型有一个抽象的接口，允许我们绘制拟合模型、预测新数据的响应变量等等，我们可以使用相同的泛型函数进行此类操作。不同的模型实现这些泛型函数的自有版本，因此你可以编写通用的代码，使其能够应用于线性模型、决策树或神经网络等。

面向对象编程并非最初内置在 R 语言中，而是后来添加的，不幸的是，添加了不止一种面向对象系统。实际上，在 R 中有三种不同的方式来实现面向对象的结构，每种方式都有不同的优缺点，并且这三种系统不能很好地协同工作。我将在本书中涵盖所有三种系统（S3、S4 和 R6），但会重点介绍 S3 系统，它是所谓的“tidyverse”的基础，即诸如`tidyr`、`dplyr`、`ggplot2`等包，这些包构成了现今大多数数据分析流程的基础。

在开发你自己的软件时，我强烈建议你坚持使用一种面向对象系统，而不是混合使用。至于选择哪一种，则取决于个人喜好以及你的代码需要与哪些其他包协同工作。



我所阅读过的关于面向对象编程的大多数书籍，以及我上过的面向对象编程课程，都侧重于面向对象建模和软件设计。其重点在于如何利用面向对象技术来构建你对软件的思考方式，以及软件如何反映你试图在软件中建模的现实世界或概念领域的物理或概念层面。例如，如果你开发一个处理会计的软件，你会将账户建模为对象，并为其定义存款和取款等操作。你会尽可能地尝试将问题域中的概念直接映射到软件中。这是一种设计软件的强大方法，但软件中总有一些方面不易适应此类建模，尤其是在涉及算法编程和数据结构设计时。例如，搜索树和排序算法通常并不反映问题域中的任何具体事物。

然而，面向对象编程也是设计算法和数据结构时一个非常强大的工具。在我学习编程时，算法和数据结构是在与面向对象课程分开的课程中讲授的。将面向对象和算法编程结合起来，是我后来通过编写软件自学掌握的。我认为这是一种遗憾，因为这两者实际上非常契合。

在本书中，我将尝试既将面向对象作为一种软件设计的建模技术，也将其作为开发可重用算法软件的工具来介绍。多态性是面向对象编程的基石，它非常适合用于开发灵活的算法，以及将抽象数据类型的不同具体实现结合起来，从而将抽象算法适配到具体问题中。R 的一个主要用途是机器学习和数据科学，在这些领域，高效灵活的算法比建模问题域更重要，因此本书的大部分内容将聚焦于面向对象编程的这些方面。

要阅读本书，你需要了解 R 编程的基础知识：如何操作数据以及如何编写函数。我们不会涉及特别复杂的 R 编程，所以你不需要具备在 R 中进行函数式编程的基础知识，但如果你想学习相关方法，我建议阅读本系列的第一本书，该书专门介绍了这一点。不过，即使没读过那本书，你也应该能够理解本书内容。
