# 引言

欢迎阅读《R 语言面向对象编程》。我编写这本书是为了提供超越大多数 R 语言教科书典型入门水平的教学材料。本书旨在介绍 R 中的对象和类，以及如何在 R 中进行面向对象编程。面向对象编程基于对象的概念，并以对象可执行的操作以及对象之间如何通信来设计程序。

这通常被理解为具有状态的对象，对对象的操作会改变对象状态。以银行账户这类对象为例，其状态是账户余额，存入或取出资金会改变其状态。我们对对象执行的操作在文献中常被称为"方法"，但在某些编程语言中，其概念模型是对象之间相互通信并发送消息，而你对对象执行的操作就是它对接收到的消息的响应方式。

在 R 中，数据是不可变的，因此你不会编写改变对象状态的代码。相反，你将对象视为值来处理，当需要新的"状态"时，对对象的操作会创建新对象。R 中的对象和类更像是抽象数据结构。你拥有值以及可以对这些值执行的相关操作。这类抽象数据结构在不同编程语言中以不同方式实现。大多数面向对象语言使用类和类层次结构来实现它们，而许多函数式语言则通过某种类型规范来定义哪些函数可以应用于对象。

类型决定了你能对对象做什么。例如，你可以对数字进行加法运算，对字符串进行拼接操作，但你实际上不能对字符串做加法，也不能对数字做拼接。在某些编程语言（即所谓的静态类型语言）中，你将类型与变量关联，这限制了变量可以引用的对象，并在代码运行前实现某些一致性检查。在这类语言中，你可以通过定义可执行的操作来指定新类型，然后需要为引用这些类型的变量添加类型规范。其他编程语言（称为动态类型语言）则不将类型与变量关联，而是允许它们引用任何类型的对象。R 是动态类型的，因此你不会通过类型规范来指定抽象数据类型。你能对对象执行的操作仅由你可以对对象调用的函数决定。你仍然可以将这些视为抽象数据结构的规范；然而，它们只是隐式定义的。

抽象数据结构可以通过不同方式实现，这正是其抽象性的体现，而将实现与接口分离的方式是通过多态或泛型函数，这是一种基于面向对象编程的构造。泛型函数通过类机制实现，这也源自面向对象编程。类所实现的函数决定了该类中对象的接口，通过构建类的层次结构，你可以在类之间共享通用函数的实现。

抽象数据结构在算法编程中常用于实现高效的代码，但这种编程通常并非 R 程序的目标。在 R 中，我们更关注将数据拟合到模型等操作，这通常不需要算法数据结构。然而，拟合模型也是我在本书中所用术语意义上的抽象数据结构示例。模型具有抽象接口，允许我们绘制拟合模型、为新数据预测新的响应变量等，我们可以对这类操作使用相同的泛型函数。不同模型实现了各自版本的泛型函数，因此你可以编写通用代码，例如使其能在线性模型、决策树或神经网络上工作。

面向对象编程最初并未内置在 R 语言中，而是后来添加的，不幸的是，添加了不止一种面向对象系统。实际上，在 R 中有三种不同的方式来实现面向对象构造，各有优缺点，而且这三种系统无法很好地协同工作。我将在本书中涵盖所有三种系统（S3、S4 和 R6），但重点放在 S3 系统上，它是所谓的"tidyverse"（包括诸如`tidyr`、`dplyr`、`ggplot2`等包）的基础，这些包如今构成了大多数数据分析流水线的基础。

在开发自己的软件时，我强烈建议你坚持使用一种面向对象系统，而不是混合使用它们，但选择哪一种则取决于个人偏好以及你的代码打算与哪些其他包协同工作。
