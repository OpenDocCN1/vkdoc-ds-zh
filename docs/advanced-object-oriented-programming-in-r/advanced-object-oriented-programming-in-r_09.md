# 8. 结论

这本关于 R 语言面向对象编程的书籍到此结束。现在你已经了解了 R 中三种不同的面向对象编程系统，以及如何使用它们来定义类层次结构和多态函数。

R 中的面向对象编程，至少对于 S3 和 S4 系统而言，与大多数其他面向对象编程语言不同。大多数语言认为对象是可变的，并且大多数面向对象软件设计涉及将对象通过引用相互连接，使得它们的行为依赖于其他对象的不断变化的状态。`R6` 系统更接近这类语言设计。尽管如此，`S3` 和 `S4` 系统结合了两种强大的编程语言范式：函数式编程和面向对象编程。基于参数类型的动态函数分派与高级函数式编程的结合，使你能够构建灵活且可扩展的软件。

在同一个语言中存在三种截然不同的面向对象编程系统可能会令人困惑，我建议你在任何一个项目中只坚持使用其中一种。然而，了解这三种系统以及使用它们的优缺点，能让你为特定任务选择正确的工具。`S3` 系统是三者中最简单的，非常适合在短时间内快速搭建一个小型模型。`S4` 系统更正式的类定义使得构建更复杂的框架变得更容易，而 `R6` 系统的引用语义使得实现传统的可变数据结构比在 R 中其他方式更简单。

当然，熟悉这些系统需要练习，你不会仅仅通过阅读这本书就成为面向对象编程的专家。不过，你现在已经掌握了足够的知识，可以开始实践了。
