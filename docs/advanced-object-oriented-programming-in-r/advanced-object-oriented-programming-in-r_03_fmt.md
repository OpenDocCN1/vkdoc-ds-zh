## 我读过的多数关于面向对象编程的书籍和课程，都聚焦于面向对象建模与软件设计。其核心在于如何利用面向对象思想来构建你对软件的思考方式，以及软件如何反映你在其中试图建模的现实世界中的物理或概念方面。例如，如果你要实现一个处理会计的软件，你会将账户建模为具有存取款操作的对象。你会尽可能地将问题域中的概念直接映射到软件中。这是一种强大的软件设计方法，但软件中总有些方面难以直接融入此类建模，尤其是在算法编程和数据结构设计方面。例如，搜索树和排序算法通常并不反映问题域中的具体事物。

然而，面向对象编程也是设计算法和数据结构时一个非常强大的工具。我学习编程时，算法与数据结构课程与面向对象编程课程是分开讲授的。将面向对象编程与算法编程结合起来，是我通过编写软件自学的。我认为这很遗憾，因为两者实际上非常契合。

在本书中，我将尝试把面向对象技术既作为设计软件的建模方法，也作为开发可复用算法软件的工具。多态性——面向对象编程的基石——本身就很适合开发灵活的算法，并将抽象数据类型的不同具体实现结合起来，为具体问题定制抽象算法。`R` 语言的主要应用领域是机器学习和数据科学，在这些领域，高效且灵活的算法比问题域建模更重要，因此本书的很大一部分将聚焦于面向对象编程的这些方面。

要阅读本书，你需要掌握 `R` 编程的基础知识：如何操作数据以及如何编写函数。我们不会涉及特别复杂的 `R` 编程，所以你不必具备在 `R` 中进行函数式编程的基础知识，但如果你想学习这部分内容，我建议阅读本系列的第一本书，那本书正是关于此内容的。不过，即使你没有读过那本书，也应该能跟上本书的进度。
