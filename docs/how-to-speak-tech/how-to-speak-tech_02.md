# 致谢

> *投资知识收益最大。*
> 
> ——本·富兰克林

没有我从父母和祖父母那里学到的关于教育和社区价值的教训，这本书就不会存在。他们养育我时相信，好奇心和知识是通往充实生活的关键，并且我们必须尽其所能回馈他人，因为我们是环境的产物。这些价值观激发了我出版《如何讲述技术》并深入参与其背后使命的兴趣。这本书的动机是希望帮助扩大 STEM 教育的普及，确保“非技术”人员拥有他们所需的知识，以便在一个几乎需要对技术有基本理解的世界中发挥有效作用。它涉及重新培训那些被人工智能和自动化取代之人的努力、为下一代宣扬 STEM 教育的项目，以及为 STEM 领域争取公平和多元化代表性的组织。我们致力于做出改变，而创作《如何讲述技术》正是为了服务于这些努力。

我要向我的杰出贡献者们表示极大的感谢，他们加入了团队，不辞辛劳地分享他们的专业知识，因为他们也相信我们的使命。感谢阿希、奇纳尔、沃伊塔、科伊和杰伊——感谢你们为所贡献的章节付出的辛勤工作。它们是你们知识、技能和热情的展示。感谢你们让我从你们身上学习，我很兴奋看到你们的才华将带你们走向何方。阿什莉，感谢你主导了第一版的编辑工作。你对计算机科学教育的热情显而易见且令人鼓舞。阿希、奇纳尔和杰伊，也感谢你们提供的编辑支持，特别感谢阿希在最后关头给予了巨大帮助。我们整个团队还要特别感谢过去一年中帮助我们完善各章节的无数读者。

最后但同样重要的是，我感谢我的家人、朋友和导师多年来的指导。每个人无尽的支持和无条件的爱是这本书真正的参考文献。
