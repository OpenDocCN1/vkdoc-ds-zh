# 10. 吸引并了解你的用户

用户可以通过多种不同途径了解你的网站，每种途径都被称为一个渠道。其中之一可能是通过社交媒体。例如，新用户可能通过 Facebook 上的帖子或推文了解并加入`MyAppoly`。另一个渠道可能是通过推荐（口碑传播的行话）。还有一种渠道可能是通过电子邮件营销活动。正如你所见，有多种方式可以触达潜在客户，并说服他们值得花时间关注你的网站。本章将聚焦于搜索引擎的崛起，以及与之相关的两个重要渠道：自然搜索和付费搜索。自然搜索指的是通过标准搜索弹出来的结果。当你在网上搜索某样东西时，你会注意到在搜索引擎结果页面（`SERP`）顶部，有一些与你的搜索词相关的付费广告。付费搜索指的就是这些广告的存在。

企业会收集客户数据以了解其运营状况。例如，杂货店会根据客户是谁、他们购买哪些产品以及哪些通道往往最受欢迎等信息，来定价库存、备货和调整布局。为了获取部分此类信息，杂货店巧妙地推出了会员卡。顾客仅仅将这张卡视为获取折扣的工具，但实际上，顾客是在用自己的个人数据为商店赋能。

会员卡对杂货店有效，是因为进入店铺的顾客几乎很少空手而归。线上客户则不同。如果你只能在你`MyAppoly`的客户进行购买时收集他们的数据，你会丢失大量有价值的数据。就像杂货店一样，你想弄清楚你的客户是谁，他们想要什么，以及他们对你的产品有何看法。由于你无法像杂货店调查顾客那样对每个用户进行可行性调查，你需要为这些信息寻找替代来源。

本章将介绍如何利用搜索引擎来吸引用户，以及网站如何追踪这些用户的行为。我们还将简要讨论新的数据保护法规，这些法规旨在保护我们的个人信息，防止其在未经我们明确许可的情况下被利用。

## 搜索引擎优化

如今，我们认为搜索引擎是理所当然的，但在 1990 年之前，在互联网上进行搜索的能力是不存在的，当时一个名为`Archie`的搜索引擎允许用户按文件名进行搜索。从那时起，许多参与者开始致力于创建更好的搜索引擎。1994 年，`Yahoo!`创建了一个它能手动找到的所有网页的数据库，并为用户提供了一种搜索目录的方式。不幸的是，他们的方法效果有限，因为手动收集网页的过程非常缓慢。`AskJeeves`提出了一种提问的新方法，这并非真正的搜索，但实现了知识共享。这些早期的参与者各自为战。他们几乎不知道，他们最终会输给两位名叫拉里·佩奇和谢尔盖·布林的斯坦福大学研究生。1998 年，这两位学生研究出了一种扫描整个互联网的方法，存储每个页面的描述信息，以便根据用户的搜索查询来回忆并显示网站。数字`googol`（1 后面跟 100 个零）启发了他们搜索引擎的名字。`Google`诞生了，我们使用互联网的方式也随之发生了根本性的改变。

现代搜索引擎存储着所有网站及相关关键词的信息。当你搜索一个词或短语时，它们会将你的搜索词与每个网站关联的描述性关键词进行匹配。

现代搜索引擎实际是如何收集网站名称和关键词的呢？手动录入目录的日子已经一去不复返了！正如谚语所说，需要是发明之母。随着网页数量以前所未有的速度增长，手动记录它们的方式变得难以为继。聪明的`Google`工程师改进了他们的能力，使用被称为爬虫的机器人在互联网上“爬行”，这些爬虫会扫描一个网页并跟踪页面上包含的所有链接。如果他们跟踪每一个链接，他们几乎就能发现整个万维网。当它们扫描每个页面时，会记录出现的关键词、链接到该页面的数量，以及其他几个有助于描述页面并将其与同主题其他页面进行比较以赋予其排名的特征。这个排名决定了当有人在`Google`上搜索某个主题时，该页面显示的顺序，这非常重要，因为大多数用户不会查看搜索结果的前几页之后的内容；更高的排名会为你的网站带来更多流量。搜索一个主题并点击排名文章的过程就是自然搜索，而搜索引擎优化（`SEO`）指的是优化你在`Google`和其他搜索引擎上排名的过程，以增加通过自然搜索获取用户的可能性。

为了理解搜索引擎优化，你还必须学习搜索查询与实际数据库关键词匹配的工作原理。由于查询可能因大小写（例如 *Tennis* vs. *tennis*）、单复数（例如 *rackets* vs. *racket*）、拼写（*racket* vs. *racquet*）以及包含非必要词汇（例如 *the* 和 *a*）而有所不同，搜索引擎通常在将查询与数据库进行匹配之前，会先去除所有这些变体。在查询匹配完成并选出所有对应的网页结果后，`Google`必须在将这些结果呈现给搜索者之前对其进行排名。最好的结果似乎总是在最前面，从而最大限度地减少用户找到正确链接所花费的时间。在某些方面，这正是搜索引擎真正神奇之处所在。实际的互联网爬行和数据库创建是可以预测的，但收集到的信息以及如何使用这些信息来对结果进行排名和展示，才是搜索引擎之间的差异化因素。

谷歌的排名算法被称为`PageRank`，多年来已声名显赫。尽管具体算法并未公开，但我们对其所考量的因素有所了解，因此，你可以借鉴谷歌的排名方法来指导网页的构建。

该算法针对的一个要素是`关键词密度`。频繁提及某个关键词的页面，其相关性往往高于提及次数较少的页面。一个一百次提到“网球拍”的页面，比仅出现一次“网球拍”的页面更可能与网球相关。搜索引擎工程师很快意识到，网页开发者可能会为了获得更高排名而在页面中堆砌重复关键词。很聪明，对吧？谷歌和其他搜索引擎同样精明，它们会监控此类行为并将其标记为降级处理。

搜索引擎还会关注`关键词邻近度`和`关键词突出度`。它们需要确保网球和拍这两个词相邻出现，因为如果它们相邻，与搜索词“网球拍”相关的可能性就很高。`关键词突出度`也可以表明文章的相对重要性：网球拍是网页的标题，还是仅仅出现在图片的脚注中？这同样会影响排名，大多数人认为理应如此。最后但同样重要的一点是`链接流行度`。如果有大量其他网站链接到你的页面，那么你的页面很可能具有较高的重要性。特别是当重要网站（同样由链接流行度及其他因素决定）链接到你的页面时，更是如此。继续以上述例子为例，如果美国网球公开赛的网站链接到你关于网球拍的页面，这就是一个关键信息，谷歌会因此给予你加分。但不会给你加分的是，你自己页面上放置的指向其他知名网站的链接。换句话说，在你自己的页面上包含指向美国网球公开赛网站的链接，并不会影响你的排名。任何人在自己的网站上都可以添加链接，因此这并不特别。

基于这些知识，你可以通过 SEO 流程优化网页以获得更高排名。你可以直接控制出现在网页上的内容：清晰且描述性的标题；关键词的战略性使用（注意邻近度、密度和突出度）；以及你可以添加到`meta`标签（用于向谷歌爬虫提供数据）和 HTML 中图片标签的描述信息，这些都会影响你的排名。定期更新页面内容也可能被视为可信度的标志，就像为爬虫定义和描述页面布局、描述、各页面重要性等的站点地图一样。

你可能已经猜到，控制你的`链接流行度`要困难得多。除了强迫他人包含指向你网页的链接之外，除了建立你的可信度和知名度之外，你几乎别无他法。

你越了解搜索引擎排名算法的工作原理，就越擅长 SEO。

## 搜索引擎营销

通过在谷歌或必应上为你的公司做广告，你的网站将出现在互联网上流量最高的黄金地段。本节将讨论其背后的工作原理。

搜索引擎营销（SEM）的概念相当简单。让我们继续假设 MyAppoly 是一个网球网站。你知道搜索“网球拍”的用户很可能是在寻找新的网球装备。为了让你的广告在用户搜索“网球包”时显示出来，你必须“购买”关键词“网球包”。当用户搜索“网球包”一词时，你的广告就会在侧边弹出，如果用户点击你的链接，你将按照你购买该关键词时的费率被扣费。然而，这其中还有一层额外的复杂性。

许多人想购买相同的关键词。所有网球网站可能都想购买关键词“网球包”。谷歌如何知道在给定的广告位（同样位于结果页面顶部）展示哪些广告呢？这由一场基于两个因素的实时拍卖决定：`出价`和`质量`。当你创建广告系列和广告时，你需要指定你的出价金额。自然，你的出价越高，你的广告就越有可能在购买了相同关键词的竞争对手的广告中胜出。这合乎情理，因为谷歌希望最大化其收入，在其他条件相同的情况下，更高的出价总是优于较低出价。质量同样重要，因为只有在用户点击广告时，谷歌才能获得收入。让我们通过例子来说明。如果 MyAppoly 开始为长曲棍球头盔购买广告，认为任何想要购买装备的运动员也可能对网球装备感兴趣会怎样？MyAppoly 可能会赢得长曲棍球头盔的拍卖，但一旦用户点击 MyAppoly 的广告，他们就会发现 MyAppoly 是一个网球网站，与长曲棍球毫无关系。他们很可能会立刻点击返回按钮。谷歌可以追踪到这种行为，如果它发现你的广告并未向客户提供他们真正想要的内容，你的`质量得分`就会下降。因此，如果你想赢得拍卖，你需要有精准定位的广告（高质量）并出价一个可能高于竞争对手的价格。

这被称为基于效果的广告模式，这种模式很好，因为与传统广告方式不同，你只在用户点击你的广告时才付费。各方的利益是一致的：广告商仅在广告被点击时付费；谷歌通过展示用户可能点击的广告来赚钱；用户则只会看到相关的广告。将这种模式与黄页模式相比，后者中广告商无论有多少人看到广告都支付固定费用，而用户则不得不从数百个不相关的广告中筛选。这对于如今能够获取高度精准数据的时代来说是低效的。

# 分析

搜索广告之所以有效，是因为搜索查询提供了上下文。在错误的人群上浪费广告费已成为过去时的风险，因为你只购买描述你目标市场的关键词。此外，当用户点击广告时，你可以控制他们进入你网页的哪个位置。因此，与其将所有用户引导至 `MyAppoly` 的主页，为何不将点击“网球拍”广告的用户直接导向 `MyAppoly` 上列出的网球拍列表呢？

*分析*指的是生成描述用户如何使用你网站的指标的软件程序。分析的历史并非始于一套用户追踪指标，而是作为一个存储用户操作以辅助调试的错误日志。^(¹²) 早期的开发者创建了自动生成的网络文档来记录错误，因此得名*网络日志*。然而，随着时间的推移，业务和市场营销人员意识到网络日志数据除了调试之外还有价值。这些数据可以用来了解客户。

1995 年，斯蒂芬·特纳编写了一个名为 `Analog` 的程序，用于分析这些错综复杂的日志文件，提取其中对分析有用的部分。后来的程序 `Webtrends` 帮助人们将存储在这些日志中的数据可视化。收集和可视化关于网站使用的有意义数据的动机，源于希望基于用户及其习惯的信息做出决策。

Web 应用程序公司感兴趣收集的是哪些数据呢？有几种类型，但这里讨论的是*点击流数据*。当用户访问 `MyAppoly` 时，他们会留下一条由所有访问过的页面和点击过的内容组成的轨迹。这种用户活动的记录定义了术语*点击流数据*，收集它的四种主要方式是：网络日志、网络信标、JavaScript 标记和包嗅探。

## 网页日志

当用户访问一个网站时，浏览器会向托管该网站的服务器发送请求。服务器在发回网页之前，会更新其日志，记录诸如“用户 X 于中午 12:00 访问了页面”的信息。这就是所谓的*网页日志*。其中一个缺点是，任何服务器的请求都会被记录，甚至连搜索引擎的爬虫也不例外。如果你只想监控人类活动，这可能不是最佳方法。此外，难以识别**独立访客**，这会使营销分析变得复杂。你不想重复计算同一个人，否则数据就会出错。最后，你还记得*缓存*这个术语吗？浏览器向服务器发送请求并接收包含所有图片和其他资源的页面需要时间。因此，为了提高效率，浏览器会在本地保存网站的副本，以尽量减少与服务器的交互。当服务器未被使用时，网页日志不会被触发，因此所有在网页缓存版本上的活动都不会被记录。这是**服务器端数据收集**的一个例子（用于存储数据的软件位于服务器上）。

## 网络信标

如果你收到过一封电子邮件，其中的图片被暂时隐藏，直到你授权邮件客户端显示它们，那你可能对网络信标并不陌生。为什么呢？网络信标通常是 1x1 像素的透明图片，它们托管在与网页所在服务器不同的独立服务器上。回想一下，要加载一张图片，浏览器必须发出额外的服务器请求。当浏览器从第三方服务器请求这个网络信标时，它们的行为就会被记录下来。使用第三方服务器让你在想要收集的数据方面拥有更多灵活性（要么包含网络信标，要么不包含），并且允许你跨多个网页聚合数据——也就是说，你可以从多个网站发起对这个网络信标的请求，所有这些请求都必须到达同一个服务器去获取那个 1x1 像素的图片。因此，即使请求来自不同的来源，所有数据都存储在同一个服务器上。话虽如此，由于这种方法依赖于图片请求，任何屏蔽图片请求的工具都会阻止你收集有用的数据。垃圾邮件发送者利用这一点来验证你的电子邮件账户是否仍然活跃，因此一些邮件客户端会禁用图片，直到你验证了它们的真实性。一些服务也使用网络信标来实现*已读回执*功能。

## JavaScript 标签

JavaScript 标签改变了网络分析的本质。如果你还记得我们关于 JavaScript 的讨论，这种语言拥有**事件监听器**，它们会等待特定事件（例如点击按钮）发生后才执行相应的代码。就像 JavaScript 监听器可能等待用户点击按钮后才触发显示弹出窗口的代码一样，JavaScript 可以利用“页面加载完成”这个事件作为触发点来执行代码。如果你能让这段代码收集关于用户、时间以及网页描述的信息，你就可以把 JavaScript 当作一个分析工具来使用。而这正是已经发生的情况。只要你包含了当页面加载时就会触发的 JavaScript 代码行，就可以了。即使你的页面被缓存了，当用户查看它时，JavaScript 代码也会执行，因此在这一点上它胜过了网页日志。你还可以在 JavaScript 代码中添加特殊的**标签**，以便之后更容易地过滤数据。

这个过程比这个简单的解释要稍微复杂一些，因为**Cookie**可以发挥重要作用。当你访问一个网站时，它可能会在你的浏览器上放置一个名为 Cookie 的东西，用来存储关于你的信息、你点击了什么以及其他相关信息。下次你访问这个网站时，它会查找该网站的 Cookie，如果找到了，它就知道你以前来过这个网站，并可以利用存储的信息为你定制页面。如果 Cookie 存储了你正在浏览的鞋子的信息，那么下次你访问时，那些鞋子可能会出现在页面顶部。回到分析上：JavaScript 代码使用 Cookie 来记录活动。它会在你的浏览器上存储一个 Cookie，并且在代码的其他部分执行完毕后，信息随后被传递到服务器进行存储。这些服务器要么由公司自己拥有，要么由第三方分析提供商拥有。

以前，分析工作完全由公司内部的 IT 团队管理，而现在，已经出现了完全以帮助他人进行分析为唯一目的的完整公司。这些公司提供一些 JavaScript 代码供其他人放在他们的网站上，然后他们负责处理剩下的事情。他们提供的价值还体现在可视化工具的形式上，以帮助你理解数据。Google 通过 `Google Analytics` 免费提供分析服务，其工作原理是将数据存储在日志文件中。每隔几小时，Google 会处理这些日志文件，然后使用户能够在其 Analytics 网站上查看数据。

这种方法的好处很多，最主要的是**易用性**。只需粘贴分析公司提供的代码，你就可以拥有一个完整且正在运行的追踪和可视化系统。瞧！

话虽如此，一些用户开始禁用 JavaScript，因此使用这种方法可以预期会有少量的数据丢失。另外，请务必记住，如果你使用第三方分析提供商（即，你不是自己构建和收集所有这些信息），那么你敏感的 `MyAppoly` 数据将会落入他人之手。

## 数据包嗅探

*数据包嗅探*本质上是在网站访问者和托管网站的 `MyAppoly` 服务器之间创建一个**中间人**。用户请求 `MyAppoly` 首页后，该请求会经过一个由软件和硬件组成的混合体，称为*数据包嗅探器*，在这里用户的请求信息被记录下来，然后再路由到服务器。当服务器用网页响应时，文件在路由回用户之前会再次经过数据包嗅探器。就是这样。一次经过获取用户数据，另一次经过获取网页信息。

这种方法方便之处在于**无需在实际的源代码中输入额外的代码**，并且它可以轻松拦截发送到你服务器的所有请求，从而满足整个网站的需求。缺点在于实际的设置过程可能比较复杂，并且对网站缓存版本的请求不会被记录。你还必须小心使用数据包嗅探器，因为它们会拦截大量敏感信息，例如用户的密码和信用卡号。以尊重隐私的方式处理这些数据至关重要。

# 数据可视化

数据显示的特定方式会影响你能得出的见解。因此，许多参与者都在努力让这个过程变得更加容易。因此，分析的下一阶段似乎不再是侧重于聚合，而是侧重于**可视化和处理**。

*点击密度*（也称为*站点覆盖*）可以根据用户的点击内容，提供关于用户可能在想什么的见解。*热力图*的最终发展也实现了同样的目的。热力图是网页的彩色图像，用于根据鼠标移动指示用户正在查看的位置。深红色表示鼠标经常悬停的区域，而蓝色区域则是页面上鼠标很少到达的位置。

分析不仅应该寻求回答*是什么*（例如，多少浏览量、多少注册量等等），还应该回答*为什么*。关注点已经重新转向任务，**漏斗图**成为可视化任务完成情况的流行方式。通过这种方式，公司可以清楚地看到在每个阶段有多少人流失。

可视化类型的列表可以无限延伸，但主要观点是这些数据对公司非常有价值，他们正在寻找任何方法来理解它们。**呈现方式至关重要**。

# GDPR（通用数据保护条例）

在关于追踪技术的讨论中，`MyAppoly` 团队务必意识到隐私问题引发的严重关切。自 2016 年起，我们对现有数据隐私法规进行了重大修改，其中最引人注目的是《通用数据保护条例》（GDPR），它试图以比以往更全面、更强有力的方案来统一欧盟各国的数据保护法。该条例于 2018 年 5 月起强制执行，要求企业在收集数据前披露相关行为，包括数据用途、存储期限及分享计划。企业只有在获得用户明确同意后方可继续处理个人数据，且用户可随时撤销该同意。GDPR 的涵盖范围远比我们在此讨论的要广泛，但条例核心应成为团队在数据追踪、收集、存储及处理方面讨论的基石。
