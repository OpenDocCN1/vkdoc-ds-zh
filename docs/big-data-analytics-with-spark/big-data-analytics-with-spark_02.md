# 本书是一本简洁易懂的大数据和 Spark 教程
本书是一本简洁易懂的大数据和 Spark 教程。它将帮助你学习如何使用`Spark`完成各种大数据分析任务，涵盖了你高效使用`Spark`所需了解的全部内容。

购买本书的好处之一是能帮助你高效学习 Spark，为你节省大量时间。本书涵盖的主题在网上均可找到。有大量博客、演示文稿和 YouTube 视频介绍 Spark。事实上，关于 Spark 的资料可能多到令人眼花缭乱。你可能会花数月时间在网上不同地方零散地阅读关于 Spark 的内容。本书提供了一个更好的选择：内容组织得当，并以易于理解的格式呈现。

本书的内容和结构基于我偶尔在不同大数据相关会议上举办的 Spark 工作坊。参与者对内容和流程的积极反馈促使我撰写本书。

书籍与工作坊的一个区别在于后者具有互动性。但举办多次 Spark 工作坊后，我了解人们通常会提出哪些问题，并在书中进行了回应。不过，如果你在阅读本书时有疑问，欢迎通过`LinkedIn`或`Twitter`联系我。请随意提问，不存在愚蠢的问题。

本书并非涵盖 Spark 的每个细节，而是介绍高效使用 Spark 所需了解的重要主题。我的目标是帮助你打下坚实基础。一旦基础扎实，学习新技术的所有细微之处就变得容易了。此外，我想让本书尽可能简单。如果读完本书后你觉得 Spark 很简单，那我的目标就达到了。

本书不假设读者对任何主题有预先了解。它循序渐进地介绍关键概念，每个章节都建立在前一章的基础上。同样，每章都是下一章的阶梯。如果你暂时不需要某些 Spark 库，可以跳过介绍这些库的后续章节。但我鼓励你通读所有章节，即使内容与当前项目不相关，也可能为你带来新思路。

通过阅读本书，你将学到大量关于 Spark 及相关技术的知识。但为了最大化收益，请亲手输入书中的示例并试验代码样例。动手编写和执行代码会让事情变得更清晰。如果你在阅读时能实践和试验示例，那么读完本书时，你将成为一名扎实的 Spark 开发者。

我在开发 Spark 应用程序时发现的一个有用资源是 Spark 官方 API（应用程序编程接口）文档，网址为`http://spark.apache.org/docs/latest/api/scala`。初学者可能觉得难以理解，但一旦掌握了基本概念，你会发现它非常有用。

另一个有用资源是 Spark 邮件列表。Spark 社区活跃且乐于助人。不仅 Spark 开发者会回答问题，有经验的 Spark 用户也会自愿花时间帮助新用户。无论遇到什么问题，邮件列表中都可能有人解决过。

你也可以联系我。我很乐意收到你的消息。欢迎反馈、建议和提问。
