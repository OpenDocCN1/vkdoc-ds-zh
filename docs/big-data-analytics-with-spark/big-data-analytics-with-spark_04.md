# 致谢

许多人直接或间接地为本书做出了贡献。没有各方的支持、鼓励和帮助，我不可能写成这本书。借此机会，我想感谢这些人。

首先，我要感谢我美丽的妻子塔拉努姆，以及三个出色的孩子莎拉、索哈和索海尔。写书是一项艰巨的任务。全职工作同时写书意味着我无法花太多时间陪伴家人。工作时间忙于工作，晚上和周末则完全被书稿占据。我感谢家人给予我所有的支持和鼓励。偶尔索哈和索海尔会想出巧妙的办法让我陪他们玩，但大多数时候，他们让我在应该陪他们玩的时段里专心写书。

其次，我要感谢马泰·扎哈里亚、雷昕、迈克尔·阿姆布拉斯特、塔塔加塔·达斯、帕特里克·温德尔、约瑟夫·布拉德利、孟祥瑞、约瑟夫·冈萨雷斯、安库尔·达夫以及其他 Spark 开发者。他们不仅创造了一项了不起的技术，还持续快速地完善它。没有他们的发明，本书就不会存在。

当我最初提议在 Glassbeam 公司使用 Spark 解决当时困扰我们的一些问题时，Spark 还很新，几乎没人了解。我要感谢我们的工程副总裁阿肖克·阿加瓦尔和首席执行官普尼特·潘迪特允许我推进这个计划。如果没有将 Spark 嵌入产品并日常使用所获得的实践经验，我很难写出一本关于它的书。

接下来，我要感谢我的技术审校桑达尔·拉詹·拉曼和刘海平。他们不辞辛劳地检查内容的准确性，运行示例确保代码正确，并提供了有益的建议。

最后，我要感谢 Apress 出版社参与本书工作的团队成员，包括克里斯·尼尔森、吉尔·巴尔扎诺、金·伯顿-韦斯曼、塞莱斯廷·约翰·苏雷什、尼基尔·钦纳里、达尼什·库马尔等。吉尔·巴尔扎诺协调了所有与书相关的活动。作为编辑，克里斯·尼尔森对本书的贡献是无价的。我感谢他的建议和编辑。因为他的参与，本书才变得更好。我的文字编辑金·伯顿-韦斯曼通读了书中每一句话，确保其正确并修正了有问题的句子。与 Apress 团队合作非常愉快。

——穆罕默德·古勒

加州丹维尔
