# 1. Python 的哲学

## 1.1 引言

Python 之所以能在包括 `C`、`C++` 和 `Java` 在内的成熟且经过优化的语言中脱颖而出 [1]，原因非常简单。Python 融合了一种哲学理念：复杂的任务可以用简单的方式完成。我们往往认为，现实世界中的复杂问题需要复杂的路径才能产生复杂的解决方案。而 Python 的开发者们秉持的恰恰是相反的哲学。Python 的创建旨在为软件工程师提供一条极其快速且简单的学习曲线和开发流程。因此，它被认为是最通用的编程语言，因为用户几乎可以在任何研究领域工作，并且仍然能够找到对自己有用的代码片段。Python 利用了开源运动的力量，这帮助它积累了来自各行各业的大量用户。由于本质上是开源的，Python 允许人们编写小程序并轻松地相互分享。在 Python 中，一组用于执行各种任务的程序构成了一个模块（包）。截至撰写本文时，已有超过 117,181 [2] 个模块由世界各地更多的开发者提交。大量的模块和开发者使得 Python 在计算机科学社区中的使用量迅速增长，并最终占据了最受欢迎 [1] 编程语言的头把交椅。

Python 的哲学可以用一句话来概括：`Python` 是一种多用途、可移植、面向对象的高级编程语言，它提供了一个交互式环境，能够以极简的方式进行编码。

让我们来看看 `Python` 的各个特性。

### 1.1.1 高级编程

高级编程语言是一种与特定计算机的细节相分离的语言。低级语言是指用户直接将机器码输入处理器以获取结果的语言。高级语言提供了诸如库函数之类的设施来执行低级任务，并且还提供了以人类可读的形式定义代码的方法，然后这些代码会被翻译成机器语言以供处理器执行。

### 1.1.2 交互式环境

在很大程度上，Python 的哲学源自 `ABC` 语言。其语法结构主要源自 `C` 语言和 `UNIX` 的 Bourne shell 环境。这些环境为工作环境的解释性本质提供了灵感。解释性意味着 Python 为开发者提供了一个基于 `REPL` 的交互式环境。Python 编程语言的交互式 shell 通常被称为 `REPL`（读取-求值-打印-循环），因为它：

*   读取用户输入的内容，
*   求值它读取的内容，
*   打印出求值后的返回值，并且
*   循环回去，重复整个过程。

这种交互式工作环境对于调试尤其有用。它也有助于对问题进行原型设计，在此过程中可以实时可视化每一步的输出。用户一写完特定代码，就可以立即检查其结果。使用 `Python REPL` 的方式是编写代码、分析结果，并持续此过程直到计算出最终结果。除了允许快速简便地求值 `Python` 语句外，该语言还展示了以下特性：

*   可搜索的历史记录
    *   用户可以按键盘上的向上和向下键来浏览之前的命令，而无需重新编写。
*   制表符补全
    *   用户只需在输入命令的几个字母后按 Tab 键，它就会自动补全。
    *   因此，制表符补全消除了语法错误。
    *   如果按 Tab 键时有多个选项匹配，这些选项会显示在命令提示符下，以便用户选择他们想要的那个。
*   许多有用的快捷键绑定
    *   快捷键绑定取决于操作系统。
    *   快捷键绑定有助于快速操作，其中组合键等同于特定操作。
*   帮助和文档
    *   在 Python 中获取主题帮助和查找文档非常容易。
    *   用户可以将任何参数作为字符串（即用双引号括起来的字符）传递给内置函数 `help()`。

除了交互性之外，Python 还是一种解释型语言。其他语言需要将源代码转换为可执行文件，然后在机器上运行——换句话说，即 `AOT`（提前）编译——而 Python 则直接从源代码运行程序。Python 将源代码转换为一种称为字节码的中间形式，然后将字节码翻译成计算机的本机语言并运行它。这是一种 `OTF`（即时）编译类型，实现了可移植性，并使开发者能够以交互方式更轻松地编写和检查程序。

### 1.1.3 面向对象

大多数原始的编程语言本质上是过程式的。换句话说，定义一组过程来计算一个问题，信息流在这些过程中被控制以获得期望的输出。因此，一个程序仅仅被划分为相互交互的代码块，其中一个代码块定义了属于所研究计算问题的计算子任务。相反，面向对象编程（`OOP`）语言将数据视为一个对象，不同的方法作用于该对象以产生期望的结果。一切可计算的事物都被视为对象。其本质被定义为其属性。这些属性可以通过函数（称为方法）来探查。对象的抽象特性使得发明用户自己选择的对象成为可能，并将编程概念应用于各种应用程序。

### 1.1.5 极简设计

Python 的极简设计理念意味着它强调代码的可读性。它还提供了一种语法结构，使程序员能够用比 `C++` 和 `Java` 等语言更少的代码行来表达概念。此外，Python 提供了编写易于扩展的程序的方法。Python 具有动态类型系统，Python 解释器会根据对象的定义来推断其类型，从而避免了用户自行定义类型的需要。

该语言的核心哲学由 `Tim Peters` 在文档 *Python 之禅*（`PEP 20`）[3] 中进行了总结，其中包含以下格言：

- 优美胜于丑陋。
- 显式胜于隐式。
- 简单胜于复杂。
- 复杂胜于凌乱。
- 扁平胜于嵌套。
- 稀疏胜于密集。
- 可读性至关重要。
- 特殊情况也不足以特殊到打破规则。
- 尽管实用性胜过纯粹性。
- 错误永远不应静默传递。
- 除非明确需要静默。
- 面对歧义，拒绝猜测的诱惑。
- 应该有一种——最好只有一种——显而易见的方法来做这件事。
- 尽管这种方法一开始可能并不明显，除非你是荷兰人。
- 现在做胜于永不开始。
- 虽然永不开始通常比“立刻动手”更好。
- 如果实现难以解释，那可能是个坏主意。
- 如果实现易于解释，那可能是个好主意。
- 命名空间是个绝妙的主意——让我们更多地使用它们吧！

### 1.1.6 可移植性

由于 Python 属于开源社区，它已被移植（即经过适配）到众多平台上，使得在一个平台上编写的 `Python` 代码无需修改即可在其他平台上运行（系统相关功能除外）。`Python` 已发布适用于主流操作系统的版本，包括 `Linux`、`Windows`、`Macintosh`、`Solaris` 和 `Sony PlayStation`。

### 1.1.7 可扩展性

Python 的创造者并未在其核心程序中提供所有功能，而是将其设计为高度可扩展的。因此，用户可以根据自己的需求选择所需的功能。例如，如果用户需要处理微分方程，那么该用户可以使用一个微分方程模块，而不是让所有用户都拥有这个功能却从未使用。Python 也可以嵌入到需要可编程接口的现有应用程序中。

`Python` 程序可以嵌入到用 `Julia`、`C`、`C++` 等编程语言编写的其他程序中。此外，其他编程语言的代码也可以嵌入到 `Python` 中。这一特性使得大量用其他语言编写、且已针对速度和稳定性进行优化的遗留代码得以使用，从而避免了重复劳动，并极大地提高了组织的生产力。因此，Python 受到了工业界和学术界的热烈欢迎。

## 1.2 历史


### 1.1 Python 编程语言

Python 编程语言的发展可以追溯到 20 世纪 80 年代。荷兰 `CWI` 的 `Guido van Rossum` 于 1989 年 12 月开始实现它。那是一个计算设备日益强大和可靠的时代。`Van Rossum` 以 BBC 电视节目《Monty Python's Flying Circus》命名了该语言。`Python 1.0` 于 1994 年向公众发布，`Python 2.0` 于 2000 年发布，`Python 3.0` 于 2008 年发布。然而，`Python 3` 在设计上并未向后兼容 `Python 2`，这使得它对于已经使用 `Python 2` 进行开发的用户来说不太实用。因此，许多开发者至今仍在使用 `Python 2`。尽管如此，未来属于 `Python 3`，它是以更高效的方式开发的。因此，本书将讨论基于 `Python 3` 的代码。

### 1.2.1 Python 2 与 Python 3 对比

在这一点上，需要注意的是 `Python 3` 并不向后兼容。互联网上充斥着用 `Python 2` 编写的代码。学习如何将这些代码从 `Python 2` 转换为 `Python 3` 非常重要 [4, 5]。当你理解了它们的基本结构和基本用法后，就能明白它们之间差异的技术细节。

## 1.3 Python 与工程学

### 1.3.1 概述

工程问题既涉及小规模也涉及大规模的数值计算。因此，工程应用需要一种编程语言能够很好地适应这两种场景。很少有语言能具备这种特性，所以 `Python` 在这方面无疑是赢家。在较大的计算架构上运行大型计算任务时，内存管理、速度和可靠性是关键参数。`Python` 作为一种解释型语言，在这方面通常被认为速度较慢，但它能够使用通过互连包 `cython`、`jython` 和 `f2p` 编写的、用 `C`、`Java` 和 `Fortran` 编写的更快代码，从而允许在 `Python` 代码中以这些原生语言运行速度密集型任务。这一能力减轻了世界各地许多程序员对于是否必须用 `Python` 重写已优化代码的疑虑。

### 1.3.2 与硬件通信

另一个工程方面的关注点是编程语言与物理设备高效通信的能力。电子设备通过有线和蓝牙无线技术连接到互联网。使用合适的 `Python` 模块，用户可以连接到兼容设备以从中获取数据，然后在所需平台上进行可视化。多种微控制器允许 `Python` 轻松地在硬件上运行。`MicroPython` [6] 就是为此目的而专门设计的。`MicroPython` 是 `Python 3` 编程语言的一个精简高效的实现，它包含了 `Python` 标准库的一小部分，并针对在微控制器和受限环境中运行进行了优化。即使是像 `Raspberry Pi` 这样的微型计算机，也允许运行访问输入输出设备的 `Python` 程序。这使得工程问题的原型设计具有成本效益。

### 1.3.3 与其他工具对比

`MATLAB` 的用户认为 `Simulink` 是原型设计和模拟工程问题最简单的方法之一，因为他们无需编写代码。相反，用户只需在图形终端上将图形块表示的代码片段拼接在一起。（`Scilab` 也提供了一个名为 `Xcos` 的类似平台。）`Python` 仍然缺乏这种能力，有抱负的程序员可以将其视为一个挑战。大量的开发者社区正在热切期待这样的解决方案，但大多数工程师不会介意花一两天时间学习一门新的编程语言，这门语言可以提升他们的生产力，而这是现成工具无法提供的。

## 1.4 模块化编程

Python 编程的模块化特性将复杂任务分解为可无缝交互的小模块。模块使开发和调试都变得更加容易，只需简单导入即可使用各种函数。

Python 自带数千个模块用于执行各种任务。由于本书是科学计算的入门教材，因此仅讨论几个基本必要模块（如表 1-2 所示）的用法。

**表 1-2** 基本 Python 模块

| 包名 | 含义 | 用途 |
| --- | --- | --- |
| `numpy` | 数值 Python | 数值计算 |
| `scipy` | 科学 Python | 科学计算 |
| `sympy` | 符号 Python | 符号计算 |
| `matplotlib` | 数学绘图库 | 绘制图表 |

需要注意的是，虽然现代个人计算机拥有大容量内存，但像树莓派这样的微型计算机内存有限。因此，强烈建议明智地使用这些内存资源。由于所有模块都会占用内存，因此应按需安装。此外，应在程序中按需导入模块。Python 允许选择性导入特定函数以优化内存使用。编写避免浪费资源的程序被认为是一种良好的实践。

逐一介绍每个模块的用法超出了本书的范围。模块将根据当前主题的需要进行介绍。鼓励用户自行探索各种模块及其文档以了解用法。模块及其函数的一般用法将在本书后续部分讨论。

## 1.5 总结

Python 因其平缓的学习曲线和陡峭的开发曲线而受到全球广泛关注。近年来，它在编程语言流行度方面已跃居榜首。由于其开源模式拥有庞大的开发者基础，Python 为解决许多工程问题所需的各种任务提供了丰富的模块库。因此，掌握 Python 的工程师能够满足现代工业的需求，即要求快速高效地解决问题。
