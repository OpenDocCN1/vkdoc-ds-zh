# 前言

在伦敦郊区诺森伯兰公爵城堡阴影下举行的一场相当高端的首席数据官会议上，我沿着自助餐队伍移动。作为活动的主席，我尽职尽责地与每个人交谈，但此时此刻，我有点饿，还有点时差反应。当我反常地独自一人，舀起一块特别美味的鸡肉时，被餐盘对面传来的一声洪亮嗓音吓了一跳。

“我敢打赌你不喜欢最后那位发言人的话？”

出于我的角色，我需要保持外交辞令，不对任何演讲者进行严厉批评。“您说什么？”我回答道。

“我是说，我敢打赌你不喜欢最后那位发言人说的话：大多数`首席数据官`最终应该演变为`首席数据与分析官`！”

这个评论在会议期间触动了某根神经，而这位同样在舀鸡肉的仁兄对我的了解足以知道触动了哪根神经。

“*不*！”我喊道，“我*确实*不喜欢！”

“我确定你*确实*不喜欢，”他微笑道。

就这样，我与马丁·特雷德开始了即时的友谊。我们意识到——他比我先意识到——我们是多么志同道合，尤其是在数据的重要性方面。

我是斯科特·泰勒，人称“`数据低语者`”。我帮助数据平静下来。这就是我们在数据管理领域所做的一切：让数据平静下来。数据是桀骜不驯的，数据是庞大的，数据是非结构化的，它需要被安抚。

和马丁一样，我坚信适当数据管理的战略重要性。我们对管理数据所需的条件有着共同的理解。我们从骨子里理解数据——尤其是基础数据——如何帮助企业成长、改善和保护其业务。我还相信，像分析这样重要的事情，得到了过多的关注和曝光。它们是酷炫、花哨、性感的东西。因此，我成为了默默无闻、相对枯燥但至关重要的东西的倡导者。没有适当的数据基础，就没有分析洞见。

我们都一直在执行这一使命，向组织布道：他们需要关注自己的数据——不仅仅是彩色图表和报告，而是要把基础工作做好。在我看来，数据和数据管理是关于确定真相。分析和商业智能是关于推导意义。我想大多数数据专家已经知道这一点。他们支持它。他们理解它。他们相信它。事实上，我从未遇到过任何一位数据专家认为数据在被恰当用于分析时不会产生更多价值。马丁和我也理解这一点。思考数据和分析时，它们是协同工作的。它们确实需要彼此。这两件事是相关联的，但分开思考会有所帮助。正如马丁所说，“在每个企业中，都需要一个坚实的数据基础，来支撑人们打算用数据做的所有花哨事情。”

当今的宏观趋势就是关于这些“花哨事情”：关于云、数据科学、边缘分析以及其他酷炫事物。这些仍然需要一个坚实的数据基础。无论我们过去在哪里，无论我们现在身处何处，无论我们要走向何方，无论未来是什么，你始终都需要“一个坚实的数据基础来支撑所有花哨的事情。”

我为那些“不花哨”的事情，以及有时默默无闻的`数据`专业人士（如数据管理、数据治理、主数据管理、参考数据管理、主数据、元数据等领域的人）呐喊，他们每天都深知自己的工作具有基础性、是基石，并且能够使企业通过富有洞见的分析而蓬勃发展。

如果你想要一个健康的组织，贯穿你组织的生命线就是你的数据，你必须为此努力。这就像减肥和健身一样。你必须改变饮食。你必须锻炼。你必须理解并掌握基础。你必须付出艰苦的努力。没有捷径可走。

我希望你现在能看出我擅长“谈论数据”。我专注于“战略性的原因”，而不是“实践性的方法”。我假设，既然你在读这本书，你需要的不仅仅是在与 CEO 会面时在电梯里分享的一个好故事。你需要一位经验丰富的数据专业人士的实用建议——一位投入了时间、犯过错误、克服了挑战、庆祝过成功，并且理解`首席数据官`当前及未来角色的人。这就是为什么`首席数据官管理手册`会成为你宝贵的首选资源。马丁深入挖掘了他广博的专业知识以及其他专业人士分享的经验，帮助你理解几十年来高管层最重要的新增角色——`首席数据官`——的设计、执行乃至心理学。（注意，这里没有加“分析”二字。）

马丁提供的是你可以付诸行动的建议，而非学术理论。这是一本*手册*，而非教科书。它简单，但并不肤浅。它将帮助你发展技术知识之外所需的技能。希望这本手册能成为你作为现任（甚至是未来）`首席数据官`日常业务生活中的有益指南。

我曾见过马丁向一屋子的数据领导者演讲。他能用他无尽的热情煽动起人群。他能用他对数据价值和力量的坚定决心激励他们。有时他似乎准备要冲出讲台，卷起袖子，亲自深入你的数据之中。我希望有朝一日你能亲身体验到那种能量；在那之前，你手中握有一个极好的替代品。阅读这本书，你会得到足够多的收获。也许，有一天，你会有幸亲眼目睹他激励他人，甚至只是在自助餐队伍旁与他简单聊聊天。祝阅读愉快！

> 斯科特·泰勒
