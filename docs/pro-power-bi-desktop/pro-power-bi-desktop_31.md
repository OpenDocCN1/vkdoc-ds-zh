# 示例数据

如果你想跟随本书中的示例进行练习——我希望你会——你需要一些示例数据。本书中提到的所有文件均可下载，并能轻松安装到你的本地电脑上。本附录将说明如何获取示例文件、如何安装它们以及它们的用途。

## 下载示例数据

本书中使用的示例文件目前可在 Apress 网站上获取。你可以通过以下方式访问：

1.  在你的网络浏览器中，导航至以下网址：[`https://www.apress.com/gb/book/9781484257623`](https://www.apress.com/gb/book/9781484257623)。
2.  单击“下载源代码”按钮。这将跳转到本书源代码的 GitHub 页面。
3.  单击“克隆或下载” ➤ “下载 ZIP”，然后下载文件 `PowerBIDesktopSamples.zip`。

然后你需要从 zip 文件中解压文件和目录。具体操作方法取决于你使用的处理压缩文件的软件。如果你没有使用任何第三方软件，一种方法是：

1.  创建一个名为 `C:\PowerBIDesktopSamples` 的目录。
2.  在 Windows 资源管理器的导航窗格中，单击文件 `PowerBIDesktopSamples.zip`。
3.  选中其中包含的所有文件和文件夹。
4.  将它们复制到你在步骤 1 中创建的文件夹中。

## 图片

各章节中使用的图片可以在目录 `C:\PowerBIDesktopSamples\Images` 中找到。
