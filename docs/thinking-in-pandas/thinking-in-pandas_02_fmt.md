# 简介

使用`pandas` Python 库需要思维上的转变，这对初学者来说并不总是直观的。对于新手而言，`pandas`丰富的 API 通常令人不知所措，且在确定哪种解决方案最优时不够清晰。本书旨在通过解释其底层操作原理，帮助您培养正确使用`pandas`的直觉。我们将建立知识基础，涵盖诸如 Python 和 NumPy 数据结构、计算机体系结构以及 Python 与 C 语言之间的性能差异等信息。有了这个基础，我们将能够解释为什么某些`pandas`操作在特定情况下会有那样的性能表现。我们将学习何时使用某些操作，以及何时使用更高性能的替代方案。最后，我们将介绍可以并正在进行的改进，以使`pandas`更加高效。
