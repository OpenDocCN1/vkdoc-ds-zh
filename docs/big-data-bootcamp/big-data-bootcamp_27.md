# 数据科学家与数据管理员：大数据管理者

咨询公司麦肯锡估计，大数据在从医疗保健、制造业到公共部门的许多领域都可能产生巨大影响。仅在美国医疗保健领域，有效利用大数据每年就能减少约 8% 的医疗支出。

然而，我们正面临精通大数据技术、分析方法和可视化工具的人才短缺问题。据麦肯锡称，仅美国就面临 14 万到 19 万名数据分析师的短缺，以及 150 万“具备基于大数据分析进行理解和决策技能的管理者和分析师”的缺口。¹

数据科学家和数据分析师的角色并没有标准的定义。然而，数据科学家往往更精通处理数据所需的工具，而数据分析师则更关注期望的结果——需要解答的问题、业务目标、关键指标以及日常使用的最终仪表盘。由于大数据相对较新，这些角色常常界限模糊。

当涉及处理存储在传统数据库中的结构化数据时，没有比身边有一位经验丰富的数据库管理员更好的事情了。虽然构建基本的 SQL 查询很简单，但在处理大量表和行，以及处理存储在多个数据库中的数据时，查询可能会很快变得非常复杂。数据库管理员能够找出优化查询的方法，使其尽可能高效地运行。

与此同时，系统管理员通常负责管理数据存储库，有时也负责管理存储和处理大量数据所需的基础系统。随着组织继续从网站、应用程序、客户以及构成物联网的物理系统（如飞机发动机、汽车和其他所有设备）中捕获和存储更多数据，系统和数据库管理员的角色重要性将持续增长。从一开始就设计正确的系统，并选择在本地或云端存储数据的位置和方式，对于成功的长期大数据战略至关重要。这样的战略是构建专有大数据资产的基础，从而带来战略性的竞争优势。

所有这些角色对于从大数据中获得成功结果都至关重要。如果你不知道要问什么问题，世界上所有的数据都不会给出你需要的答案。一旦有了答案，就需要将它们转化为人们可以据此行动的形式。这意味着要将复杂的分析、决策树和原始统计数据转化为易于理解的仪表盘和可视化图表。

对于那些缺乏成为大数据专家所需深度技能的人来说，好消息是，现在无论是来自公司还是当地学院和大学，都有数十门大数据相关课程在线提供。像 IBM 和 Rackspace 这样的供应商也提供在线大数据课程，Rackspace 最近还推出了免费观看的 CloudU。²

我合作的一家财富 500 强公司运营着一所内部大学，作为其持续人力资本投资的一部分。他们最近新增了来自我的公司——大数据集团——提供的大数据、云和网络安全课程。在这些课程中，我们不仅涵盖这些领域的最新发展，还讨论参与者回到日常工作后可以探索的大数据机会。

考虑到麦肯锡报告引用的数字，我预计在未来几个月和几年里，会有更多公司为高管和员工投资大数据、分析和数据管理教育。对于那些希望涉足大数据、转换工作职能，或在做出重要商业决策时更好地利用数据的人来说，这是个好消息。
