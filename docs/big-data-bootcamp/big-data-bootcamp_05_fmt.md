# 数据如何让我们更聪明

## 个人健康监测与大数据的交汇

当涉及到个人生活时，仪器化可以让我们对另一个完全不同的复杂系统——人体——获得更深刻的见解。从历史上看，医生监测患者健康状况以及我们个人监测自身健康往往既昂贵又繁琐。但现在，三种趋势共同降低了收集和分析健康数据的成本。

这些关键趋势包括：可用于测量和监测的低成本移动设备的广泛普及、用于分析这些设备所生成数据的基于云的应用程序的出现，当然还有大数据本身——它与合适的分析软件和服务相结合，能够为我们提供巨大的洞察力。因此，大数据正在改变个人健康和医疗领域。

大数据也有潜力对我们生活的许多其他领域产生积极影响，从让我们学习得更快，到帮助我们在意的人际关系中维持更久。正如我们将要了解到的，大数据不仅让计算机更聪明——它也让人更聪明。

## 数据与大脑

科学家曾认为人脑的大小是固定的。但根据伦敦大学学院维康信托神经影像学中心埃莉诺·马奎尔教授的一项研究，大脑本质上是“可塑的”，并且可以随着时间而改变。该研究追踪了 79 名出租车司机的进展，其中只有 39 人最终通过了考试。虽然司机们列举了许多未通过的原因，如缺乏时间和金钱，但学习如此庞大的信息量所带来的困难无疑是关键因素之一。据伦敦市网站称，全市总共只有 25000 名持牌出租车司机，大约每条街对应一名司机。

在学习了城市街道多年之后，参与研究的司机在大脑一个被称为后海马区的区域显示出“灰质增加”。换句话说，司机们为了存储必要的数据而生长出了更多的细胞，从而使他们变得更聪明。

当然，这些记忆力的提升并非没有代价。根据马奎尔的另一项研究，海马体增大的司机更难吸收新路线，也更难形成新的关联来保留视觉信息。同样，在计算机中，某一方面的优势也会以其他方面为代价。存储大量数据可能意味着处理这些数据需要更长的时间。存储较少的数据可能会产生更快的结果，但这些结果的依据可能不足。

以计算机程序试图分析商店销售商品的历史销售数据，以便对未来可能发生的销售进行预测为例。如果该程序只能访问季度销售数据，它可能能够快速处理这些数据，但这些数据可能不够详细，无法提供任何真正的见解。商店经理可能知道某些产品在一年中的某些时候需求更高，但他们无法做出会影响每小时或每日销售额的定价或布局决策。

相反，如果该程序试图分析按分钟追踪的历史销售数据，它将拥有更精细的数据，从而产生更好的见解，但产生这些见解可能需要更多时间。例如，由于数据量巨大，该程序可能无法一次性处理所有数据。相反，它可能必须一次分析其中的一个数据块。

## 大数据让计算机更聪明、更高效

伦敦持牌出租车司机的神奇之处在于，他们能够将伦敦查令十字街六英里范围内的完整地图存储在记忆中，而无需查阅纸质地图或使用 GPS。如果司机不必时刻关注路况并手握方向盘，而且也不需要快速做出导航决策，那么查看地图对他们来说就不是问题。在一个节奏较慢的世界里，司机也许可以在旅程开始时规划好路线，然后在途中根据需要停下来进行调整。

问题是，在伦敦拥挤的街道上，没有哪个司机有奢侈的时间来进行这种缓慢的计算和重新计算。因此，司机必须将整个地图存储在记忆中。必须基于处理大量数据来提供结果的计算机系统也做同样的事情：它们将所有数据存储在一个存储系统中，有时全部存储在内存中，有时分布在许多不同的物理系统上。我们将在后续章节中详细讨论这种方法以及其他快速分析数据的方法。

幸运的是，如果你想拥有更大的大脑，记住伦敦城市地图并不是增加海马体大小的唯一方法。根据另一项研究，好消息是，锻炼也可以让你的大脑变大。随着年龄增长，我们的大脑会萎缩，导致记忆力受损。根据该研究的作者（他们对 120 名老年人进行了一项试验）的说法，锻炼训练使这些成年人的海马体体积增加了 2%，这与记忆功能的改善有关。换句话说，保持足够的血液流经大脑有助于防止我们变得更笨。所以，如果你想保持聪明，就去锻炼吧。

然而，与人类不同，计算机不能通过去健身房来增加其内存容量。当涉及到计算机和内存时，有三种选择：增加更多内存、将数据交换进出内存，或者压缩数据。大量数据是冗余的。想想你上次写一个句子或做一些大数乘法时的情景。计算机可以通过压缩重复的字符、单词甚至整个短语来节省大量空间，其方式与法庭书记员使用速记法而无需打出每个单词非常相似。

添加更多内存成本高昂，而且通常内存越快，成本越高。根据某来源，随机存取内存（`RAM`）比磁盘内存快 10 万倍，但其成本也高出约 100 倍。成本高昂的不仅仅是内存本身。更多内存还会带来其他成本。

一台典型的计算机只能容纳那么多内存芯片，而每个内存条可以容纳一定数量的芯片。电力和散热也是问题。更多的电子设备需要更多的电力，而更多的电力会产生更多的热量。热量需要散发或冷却，而这本身又需要更多的电力（并产生更多的热量）。所有这些因素加在一起，使得看似简单的增加更多内存的任务变得相当复杂。
