# 大数据打造更好的汽车

科技领域之外的情况又如何呢？福特的首席大数据官约翰·金德认为，这家汽车公司坐拥海量数据，这些数据可以“惠及消费者、公众以及福特自身”。由于 21 世纪初福特的金融危机以及 2006 年新 CEO 艾伦·穆拉利的到来，公司变得更加开放，愿意基于数据而非直觉来做决策。该公司正在考虑基于分析和模拟的新方法。

福特在其不同的职能部门都有分析团队，例如福特信贷部门的风险分析、市场部门的市场分析，以及研发部门的基础汽车研究。数据在公司的扭亏为盈中发挥了巨大作用，因为数据和分析不仅被用来解决单个部门内的战术问题，而且成为制定公司前进战略的关键资产。与此同时，穆拉利非常强调数据驱动的文化；据金德称，这种自上而下对衡量的关注对公司的数据使用及其扭亏为盈产生了巨大影响。

福特还在硅谷开设了一个实验室，以帮助公司获取技术创新。公司从大约四百万辆具备车载传感能力的车辆中获取数据。工程师可以分析有关人们如何使用汽车、驾驶环境以及车辆响应方式的数据。

所有这些数据都有潜力帮助公司改进汽车的操控性、燃油经济性和尾气排放。公司已经利用此类数据通过减少车内噪音来改进汽车设计，这种噪音曾干扰车载语音识别软件。这类数据还帮助福特工程师确定了用于接收语音命令的麦克风的最佳位置。

大数据还帮助汽车设计师打造更好的发动机。马自达使用`MathWorks`的工具开发了其创驰蓝天发动机技术系列。模型使马自达的工程师能够“更深入地了解发动机内部的情况”，并因此实现更好的燃油效率和发动机性能。这种模型使发动机设计师能够在制造昂贵的原型之前测试新的发动机部件和设计。

从历史上看，挑战在于为绝大多数车辆提供动力的内燃机极其难以建模。这是因为它们本质上是复杂的系统。它们涉及流体运动、热传递、点火、污染物的形成，以及在柴油机和燃油喷射发动机中的喷雾动力学。

设计师也在使用数据分析来做出如何改进赛车的决策，这些决策最终可能会影响到消费者购买的汽车。举一个例子，彭斯克赛车队一直在输掉比赛。为了找出原因，工程师为车队赛车配备了传感器，收集了包括轮胎温度和转向在内的 20 多个不同变量的数据。尽管工程师对这些数据进行了为期两年的分析，他们仍然无法弄清楚车手为什么会输掉比赛。

数据分析公司`Event Horizon`获取了相同的数据，但采用了一种不同的方法来理解它。他们没有查看原始数据，而是使用动画可视化来表示赛车的动态变化。通过使用这些可视化，他们很快发现，从车手转动方向盘到车辆实际转向之间存在一个延迟。这导致车手进行了大量细微的调整，所有这些调整累积起来造成了时间损失。仅仅拥有正确的数据是不够的——在设计以及大数据的其他方面，能够以正确的方式查看数据至关重要。
