## 关于作者

![9781484200414_unFM-01.jpg](img/9781484200414_unFM-01.jpg)

**大卫·范莱布**是《大数据版图》、《大数据趋势》和《大数据 TV》的制作人，这些内容均可在线访问：`www.BigDataLandscape.com`。范莱布先生的大数据趋势演示文稿曾被推荐为“Twitter 热门”，并在 SlideShare 上被观看超过 50,000 次。范莱布先生曾被《商业内幕》和 CNET 引用，其文章曾刊登于`Forbes.com`和《哈佛商业评论》中文版。他是大数据集团的董事总经理。



# 加入大数据集团之前

费因莱布先生曾是莫尔·达维多风险投资公司的普通合伙人。他共同创立了`Consera Software`（后被惠普收购）、`Likewise Software`（后被 EMC Isilon 收购）以及`Speechpad`（基于网络的音视频转录领域领导者）。他的职业生涯始于微软。费因莱布先生拥有康奈尔大学学士学位，以*最优等成绩*毕业，并持有斯坦福大学商学院工商管理硕士学位。他是《*为什么初创公司会失败*》（Apress，2011 年出版）的作者，同时也是一位热衷于小提琴演奏并两次完成铁人三项赛的选手。
