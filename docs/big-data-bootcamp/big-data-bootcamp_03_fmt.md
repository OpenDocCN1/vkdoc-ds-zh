# 前言

如果是三月或十二月，请当心。你可能正面临分手危机。数据可视化领域的两位专家——作者大卫·麦坎德利斯和李·拜伦，分析了 10,000 条 Facebook 状态更新，并将它们绘制成图表。他们得出了一些惊人的见解。分手率在春假前后达到高峰，然后在寒假前两周再次飙升。

而另一方面，如果是圣诞节，你的处境则很乐观。圣诞节当天的分手事件比一年中任何一天都少。如果你认为大数据是一个与你日常生活毫不相干的遥远话题，请三思。数据正在改变约会网站组织用户资料的方式，改变营销人员精准定位你并促使你购买产品的方式，甚至改变我们追踪健身目标以便减肥的方式。

我对大数据本身的迷恋始于我备战法国铁人三项赛期间。我开始记录我爬过的每一座山丘、跑过的每一英里，以及在旧金山水上公园冰冷刺骨的水中完成的每一次游泳。然后，我将所有这些信息上传到网络，以便查看、可视化和分析。当时我并未意识到，这正是一场迷人探索的开端，探索的对象正是如今被称为“大数据”的领域。

航空公司与银行多年来一直利用数据来确定收费标准以及贷款对象。信用卡公司利用数据来检测欺诈行为。但直到相对较近的时期，数据——也就是如今人们谈论的大数据——才真正成为我们日常生活的一部分。这是因为，尽管这些公司处理大量数据，但这些数据对我们来说基本上是隐形的。

接着，Facebook 和谷歌出现了，数据游戏从此被彻底改变。你、我以及这些服务的每一位其他用户都生成了一条反映我们行为的数据轨迹。每当我们搜索某个东西、“点赞”某人，或者仅仅是访问一个网页，我们都在为这条轨迹增添内容。当 Facebook 只有少量用户时，存储所有关于我们行为的数据不是什么大问题。但现有技术很快就无法满足数万亿次网络搜索和超过十亿用户的需求。

这些公司不得不构建新技术来存储和分析数据。其结果是引发了一场被称为“大数据”的创新爆炸。其他公司看到了 Facebook 和谷歌的做法，并希望以同样的方式利用数据来弄清我们想买什么，从而向我们推销更多他们的产品。企业家们希望利用这些数据来提供更好的医疗服务。市政当局则希望利用它来更好地了解城市居民，并确定提供哪些服务。

但一个巨大的问题依然存在。

大多数公司都有大量的数据。但大多数员工并非数据科学家。因此，围绕大数据的讨论仍然过于技术化，无法被广大受众所理解。

这里有一个机会，可以拿一个高度技术性的话题——一个相对偏向极客风格的话题——向所有人敞开大门，解释数据对我们日常生活的影响。这本书就是这一努力的结果。它讲述的是数据如何不仅改变我们的工作方式，还改变我们的生活、爱与学习方式。

如同任何重大工程一样，许多人提供了帮助和支持，我对此深表感激。我尤其要感谢 Yuchi Chou，没有他，这本书就不会存在；感谢 Apress 出版社的 Jeff Olson 牵头这个项目，并感谢他及其团队令人赞叹的编辑技巧；感谢 Cameron Myhrvold 一直以来给予的指导；感谢 Walmart.com 的 Houston Jayne 和 AT&T 的 Scott Morell 及其各自的团队提供的见解和支持；以及感谢 Jon Feiber、Mark Gorenberg 和 Joe 与 Nancy Schoendorf 给予的智慧和建议。
