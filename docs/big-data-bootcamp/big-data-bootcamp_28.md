# 首席数据官：大数据所有者

根据行业研究公司 Gartner 的数据，到 2015 年，25% 的大型全球组织将任命一名首席数据官。³ 大型组织中首席数据官的数量从 2012 年到 2014 年翻了一番。为什么首席数据官职位会兴起呢？

多年来，信息技术主要围绕硬件、软件以及管理为大型组织提供技术能力所需的资源、供应商和预算。公司的 IT 资源曾是竞争优势的来源。正确的 IT 投资可以使组织比其竞争对手更具协作性和灵活性。数据仅仅是更大 IT 战略的一个组成部分，通常甚至不会被视为独立于存储和计算资源之外的东西来考虑。

如今，数据本身正成为曾经 IT 所扮演的战略竞争优势来源，而存储硬件和计算资源则成为大数据这出戏中的配角。

在公司寻求从大数据中获得更多优势的同时，数据的正确使用和滥用也受到了更严格的审视。公司存储的信息量急剧增加，再加上黑客获取公司存储的个人数据的案件数量不断上升，使得数据被归入了自己的类别。

2013 年发生了两起非常引人注目的数据泄露事件。黑客从零售商 Target 窃取了超过 7000 万条个人数据记录，其中包括 Target 购物者的姓名、地址、电子邮件地址和电话号码信息。黑客还从软件制造商 Adobe 窃取了约 3800 万条用户账户记录。随后在 2014 年，黑客获取了 eBay 账户的访问权限，使约 1.45 亿个用户账户面临风险。



隐私问题的日益凸显也进一步提升了数据的重要性。客户现在分享的个人信息比以往多得多，从信用卡号到购买偏好，从个人照片到社交关系。因此，公司对客户的了解远胜于过去。如今，仅仅访问一个网站就会产生海量的数字信息痕迹：你花更多时间看了哪些产品？跳过了哪些产品？你在其他网站上查看过哪些可能与你购买决策相关的产品？所有这些数据都以数字面包屑的形式存在，记录了你在电脑、平板或手机上浏览网页时的路径。

对数据访问的需求——不仅是对数据本身，还包括用于分析、可视化和分享数据的正确工具——也在增长。曾经，只有精通`R`等统计工具的数据分析专家才能掌握的领域，如今，基于数据的可操作洞察已成为组织中所有成员的高需求。运营经理、一线经理、营销人员、销售人员以及客户服务人员都希望能更好地访问数据，以便更好地服务客户。

此外，相关数据既可能存储在公司的内部服务器上，也同样可能存储在云端。谁能将所有数据汇集起来，确保数据的使用符合隐私要求，并提供必要的工具、培训和数据访问权限，让人们能够理解这些数据？答案是首席数据官。

信息技术（IT）过去是，并将继续是一种竞争优势。数据如今作为另一种形式的竞争优势——一种需要独立构建和管理的战略资产——其重要性正在上升。因此，我预计未来会有更多组织将数据提升到高管层面。

### 你的大数据愿景

要实现你的大数据愿景，你需要合适的团队成员、技术和数据源。在组建团队之前，你可能想先尝试一些免费的在线大数据资源。`Google Public Data Explorer`让你能够与各种不同的公共数据源进行交互，地址是`www.google.com/publicdata/directory`。即使这些最终可能不是你想要使用的数据源，花几个小时甚至几分钟时间体验一下`Data Explorer`，也能让你很好地了解你可能想要构建的、用于帮助解释和说明大数据结果的可视化和仪表盘类型。

明确大数据的目标后，你就可以开始组建你的团队、技术资源和数据资源。

你的团队包括实际成员和虚拟成员。在推进大数据工作时，要吸纳来自不同职能领域的业务利益相关者。即使你的项目可能只聚焦于营销或网站设计，但在项目完成前，你很可能会需要来自 IT 部门的资源以及法务或合规部门的批准。

市面上有如此多的大数据技术，选择起来往往令人眼花缭乱。不要让技术驱动你的项目——你的业务需求应该驱动你对技术的选择。

最后，你可能无法立即访问到所有需要的数据。这时，预先设计和草拟出你最终想要交付的仪表盘，有助于确保项目按计划进行。即使无法填充每一个图表，使用模拟可视化图表也能帮助每个人清楚地了解哪些数据源对于实现你的大数据愿景最为重要。

在接下来的章节中，我们将详细探讨各种不同的技术、可视化工具和数据类型。从最终目标出发，并采用迭代的、测试驱动的方法，将有助于将你的大数据愿景变为现实。
