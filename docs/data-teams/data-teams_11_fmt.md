# 第二部分：组建你的数据团队

数据分析中的第一个管理任务是找到拥有合适技能的人，包括技术技能和组织技能。团队需要具备不同技能的多种人才——没有人能事事精通。本书的这一部分将解释你需要雇用什么样的人。

许多组织仍然坚持全能型人才的观念，即能包揽一切：机器学习、编程以及让所有系统在生产环境中运行。这种全能型人才确实存在，但凤毛麟角。你会花费大量时间寻找这些人，而且他们的薪水会很高。

包揽一切和*完美地*包揽一切之间也有很大的区别。有些全能型人才在紧急情况下可以应付，但常常在稳健性、可维护性或对业务需求的适用性上偷工减料。这些人很难看到自己技能和能力中的盲点。

有时，对单一人才的渴望纯粹源于预算需求：一个小组织可能决定只能负担一名训练有素的人员。管理者被迫选择他们认为相对于薪资能产生最大影响的那个人。结果通常是雇用一名期望能完成所有工作的数据科学家。

在其他情况下，不愿多样化配置员工源于希望避免协调多人或多个团队的困难。但依赖单个人才是通往问题和延误的路径，而数据团队管理中的棘手部分将不得不在以后处理。创建数据团队是一项艰巨的工作。避免组建团队的做法无法扩展。创建数据团队的解决方案就蕴含在本书的篇章之中。
