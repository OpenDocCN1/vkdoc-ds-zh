# 引言

当我职业生涯刚刚开始时，我所在的团队由五位女数据库管理员组成。在九个月内，其中一位与我同时入职的五人之一离开了这个行业。她年轻、单身，拥有计算机科学学位，主攻数据库技术，并且没有孩子。我很难理解，如果我这样一个离婚、带着三个孩子、还有一个年幼婴儿、且没有计算机科学学位的人都能坚持下去，她为什么却不能。

在接下来的六年里，我忙于自己的事业和抚养孩子，以至于没有注意到，我已经从全女性的数据库管理员团队变成了团队中唯一的女性。随着我职业生涯的不断推进，我原先认为女性是数据库管理员、男性从事网络和服务器管理的传统观念发生了变化，以至于男性从事信息技术、女性在这个行业中是少数派的文化常态，变成了我周围的现实。

直到一位同行遭遇的令人不安的情况迫使我审视真正的罪魁祸首，我才发现大多数关于歧视和骚扰的政策很少能够有效遏制影响多元化的性别偏见。我觉得有必要发声，但显然我需要开始研究以理解这一切。偏见是一种复杂的生物学机制，历史上作为启发式思维的一部分发展而来，并由经验和文化教养塑造而成。历史上，启发式特质被构建出来，是为了保护我们避免食用与已知有毒植物相似的植物，或避免类似之前使我们陷入危险的環境情境。我们通过经验和榜样学习，但为了做到这一点，人类会简化和分类周围环境，以减轻对安全问题深入探究的需求。举一个危险性较低的启发式思维例子：如果我递给你一个青柠，你会预期拿到一个小的、圆的、绿色的柑橘类水果。相反，如果我递给你一个红色的指橙，一种原产于澳大利亚、形似香蕉的青柠家族少数派，那么会有一定比例的人很难接受它是一个青柠的事实。它不符合他们对青柠外观的预期。这种偏见来源的保護機制虽然有着重要的目的，即用于识别环境危险，如有毒食物和物理威胁，但也会在这种无害的情况下出现，导致一定比例的个体拒绝不符合他们预期标准的青柠。我们都受启发式思维的影响，无论男女，尽管某些人格类型更依赖于他们的启发式倾向。他们不喜欢走出舒适区，不喜欢打破传统，也不喜欢接受改变。

本书的总体目标是：如果我们不知道有问题，又如何去解决它？由于我们对启发式思维的使用是一種保護措施，它可能是无意识的，并且由于偏见的一部分建立在文化和教养之上，启发式思维可以无缝地融入我们的社会。本书的第二个目标是分享见解、知识和支持，以帮助行业中的女性取得成功。

我自己的旅程让我意识到文化和偏见是多么难以解决，更不用说改变了。但变化可以带来巨大的成长和惠及每个人的益处。没有这种变化，科技行业的增长就会受阻；它无法充分发展和发挥其潜力。由缺乏多样性的科技行业生产的产品，其满足其所应代表的客户需求的能力将是有限的。
