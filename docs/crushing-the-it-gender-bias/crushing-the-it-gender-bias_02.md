# 致谢

我要感谢我出色的丈夫蒂姆·戈尔曼，感谢他巨大的支持和爱。拥有一位真正重视婚姻平等的伴侣，在这个世界上能产生令人难以置信的变化。蒂姆，你是我在这场我们称之为生活、爱与科技的旅程中的伴侣。我无法奢求有更好的人与我分享这段旅程。

我还要感谢微软，它证明了无论多样性和包容性面临多少挑战，它都证明了微小而真实的改变能带来不同。当我开始意识到改变需要从我身边的人做起，并且我无法改变世界时，微软选择了专注于他们能在公司内部改变的事情，而这已经显现出成效。

如今，我在微软工作已有一年，在行业里也已有 20 年经验。我正在一个拥有两名以上女性的团队中工作。这是 15 年多来的第一次。在一个五人的团队中，有三位是女性，其中两位担任深度技术岗位。微软是我经历过的唯一一家将多样性和包容性作为每天更高优先级事项并融入每个目标的公司。这不仅仅是为了在检查清单上打勾。这种改变科技行业现状并致力于带来改变的政策，甚至能为我这样身经百战的“女战士”带来和平与和谐。
