# 浮点型输入作为模块参数

若未连接至其他模块，可通过双击浮点类型输入锚点并使用控制器来设定其值。

浮点型锚点会分配一个默认控制器，通常（但不一定）是一个旋钮。若要查看可用控制器并选择合适的类型，请右键点击锚点，并从表 7-8 所列选项中选择一个。

**表 7-8.** 浮点数输入

| 控制器 | 图标 | 描述 |
|---|---|---|
| 旋钮 | | 旋钮控制器。使用鼠标调整数值时，在靠近中心处单击并拖动（按住鼠标按钮移动鼠标）上下移动进行粗调，左右移动进行微调。另外，按住 `Shift` 键可让数值以 `0.1` 的倍数吸附。要直接更改数值，请点击数字并使用键盘输入数值。按 `Ctrl+Del` 清除字段。完成后按 `Enter`/`Return` 确认。如需在画布上移动旋钮，请点击并拖动黑色区域。双击旋钮可将其关闭。 |
| 滑块 | | 滑块控制器。用于定义在浮点数值范围内操作的滑块。上方的旋钮定义浮点数值的最大值，下方的旋钮为最小值。每个旋钮的控制方式与单个旋钮控制器完全相同。可通过拖拽滑块手柄来调整滑块值。或者通过点击刻度上方数字并使用键盘输入数值（方式与单个旋钮控制器相同）来输入数值。如需在画布上移动滑块，请点击并拖动其中一个黑色区域。双击滑块任意位置可将其关闭。 |
| 直接输入 | | 使用键盘直接输入数值。点击数字并使用键盘输入新数值，然后按 `Enter` 或 `Return` 确认。先按 `Ctrl+Del` 清除字段。通过拖动黑色区域移动。双击可将其关闭。 |
