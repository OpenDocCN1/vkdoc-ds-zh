# 8. 结构化流

在本章中，我们将探讨 Apache Spark 的结构化流（Structured Streaming）特性。到目前为止，我们已经了解了 Apache Spark 为批处理数据提供的流畅 API。典型的基于 ETL 的数据流是面向批处理的，并且操作于静态数据。在这种情况下，静态数据已经被获取并可进行处理。虽然这是其中一面，但另一面则是流式数据。例如，Twitter 和 Facebook 等网站会持续接收来自其数十亿用户的数据。这些数据以极快的速度涌入这些网站。如果网站需要识别过去一小时内讨论最多的主题，它们就必须非常迅速地做出反应。它们没有时间先整合数据、存储，然后再对其应用 ETL 处理。相反，这些网站需要在数据进入系统时即时进行分析。这种处理方式被称为*流式计算*。这类计算在监控诊断、识别数据趋势等场景中非常有用，尤其是在物联网（IoT）领域，那里存在着源源不断的数据流，我们需要基于这些数据来预测设备故障等。Apache Spark 提供了流式 API，使你能够接收此类流式数据并对其进行分析。这是一个非常有趣的话题；让我们进入具体内容。
