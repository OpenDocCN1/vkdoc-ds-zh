如果我们想要对 `DataFrame` 中列的每个元素进行操作，就必须使用 `withColumn()` 函数。

`withColumn()` 函数定义在 `DataFrame` 对象上。此函数可以向现有 `DataFrame` 添加新列，或者用一个包含新数据的新列替换现有列。我们必须使用某种表达式来获取新列的数据。

### 工作原理

#### 步骤 4-1-1. 创建 `DataFrame`

第一步是最简单的。正如我们在前一章中所发现的，我们可以读取 CSV 文件并从中创建 `DataFrame`。

```python
In [1]: swimmerDf = spark.read.csv('swimmerData.csv',
header=True, inferSchema=True)

In [2]: swimmerDf.show(4)
+----+------+-----------+----------------+
|  id|性别|   职业|游泳时间(秒)|
+----+------+-----------+----------------+
| id1|  男| 程序员|           16.73|
| id2|  女|    经理|           15.56|
| id3|  男|    经理|           15.15|
| id4|  男|风险分析师|           15.27|
+----+------+-----------+----------------+
only showing top 4 rows
```

`swimmerDf` `DataFrame` 已创建。我们将 `inferSchema` 参数设置为 `True`。这意味着 PySpark SQL 将自行推断 `Schema`。因此，最好检查一下。让我们使用 `printSchema()` 函数将其打印出来。

```python
In [3]: swimmerDf.printSchema()
```

输出如下：

```
root
|-- id: string (nullable = true)
|-- Gender: string (nullable = true)
|-- Occupation: string (nullable = true)
|-- swimTimeInSecond: double (nullable = true)
```

#### 步骤 4-1-2. 计算每位游泳者的速度并添加为一列

如何计算游泳者的速度？速度定义为距离除以时间，我们可以使用 `withColumn()` 函数以表达式形式进行计算。我们必须计算每位游泳者的速度，并将结果添加为一个新列。以下代码行实现了此目的。

```python
In [4]: swimmerDf1 = swimmerDf.withColumn('swimmerSpeed', 20.0/swimmerDf.swimTimeInSecond)
```

我们知道 `withColumn()` 函数返回一个新的 `DataFrame`。新列将被添加到新创建的名为 `swimmerDf1` 的 `DataFrame` 中。我们可以使用 `show()` 函数来验证这一点。

```python
In [5]: swimmerDf1.show(4)
```

输出如下：

```
+---+------+-----------+----------------+------------------+
| id|性别| 职业|游泳时间(秒)| 游泳速度|
+---+------+-----------+----------------+------------------+
|id1|  男| 程序员|           16.73| 1.195457262402869|
|id2|  女|    经理|           15.56|1.2853470437017995|
|id3|  男|    经理|           15.15|1.3201320132013201|
|id4|  男|风险分析师|           15.27| 1.309757694826457|
+---+------+-----------+----------------+------------------+
only showing top 4 rows
```

在 `swimmerDf1` `DataFrame` 中，我们可以看到 `swimmerSpeed` 是最后一列。如果我们要对 `swimmerSpeed` 列中的值进行四舍五入，可以使用 `pyspark.sql.functions` 子模块中的 `round()` 函数。要使用它，我们必须先导入它。以下代码行从 `pyspark.sql.functions` 子模块中导入了 `round()` 函数。

```python
In [6]: from pyspark.sql.functions import round
```

#### 步骤 4-1-3. 对 `swimmerSpeed` 列的值进行四舍五入

`round()`函数可以与`withColumn()`函数配合使用。我们将使用`withColumn()`函数的`col`参数。`round()`函数的第一个参数是`swimmerSpeed`列，第二个参数是`scale`。`scale`参数定义了十进制数的格式，即小数点后需要保留的位数。我们将`scale`设置为 3。

```
In [7]: swimmerDf2 = swimmerDf1.withColumn('swimmerSpeed', round(swimmerDf1.swimmerSpeed, 3))
```

```
In [8]: swimmerDf2.show(5)
```
