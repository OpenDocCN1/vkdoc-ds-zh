## 致谢

我从未想过写一本书会如此耗费心力，尤其是一本涵盖如此广泛领域的书。最初计划是一年完成的项目，最终延长成了近两年的工程。在 2021 年的八个月里，我几乎每天都在写这本书，除此之外什么也没做。在无限期的 COVID-19 封锁期间，还有什么比这更好的事情可做呢？

本书涵盖了大学基础应用数学中的大量主题，并辅以大量示例代码和超过 300 幅图表进行说明。将这些素材整合在一起是一项巨大的工程。我要感谢我的团队在撰写本书过程中给予的鼎力支持。他们非常出色，没有他们，这本书就不可能完成：冯克豪、郭靖琦、刘世豪、陆阳、罗恒宇和倪雪莹博士。

虽然我们从未谋面，但我还是要感谢 Steve Anglin 邀请我撰写这本书——这是我长久以来想做、却一直缺乏足够动力去做的事情。感谢 Mark Wickham 仔细审阅我的书稿并提出了许多中肯的评论和建议。最后但同样重要的是，我必须感谢 Mark Powers 督促我提交书稿。他极大地推动我坐到电脑前开始打字，赶上一个又一个总是错过又总是迟到的截止日期。感谢各位的耐心！
