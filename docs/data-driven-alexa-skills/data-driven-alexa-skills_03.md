## 1. 语音用户界面

欢迎来到语音用户界面（VUI）的奇妙世界。你即将踏上一段精彩的探索之旅。你是 VUI 新手吗？是否掌握了一些 Python 基础知识？想学习如何为家庭和商业场景设计并构建创新、定制化、数据驱动的 Alexa 技能吗？是否已经发布了你的第一个掷骰子技能？作为经验丰富的 Alexa 技能开发者，你是否希望将 Alexa 与在线 API（应用程序编程接口）、丰富的数据源和强大的应用程序集成？如果答案是"是的"，那么本书将教你如何分析、构建、测试和部署数据驱动的 Alexa 技能。你将学会使用相关工具、技术和代码，快速提升技能水平——从构建一个简单的计算器技能开始，直到最终项目：创建一个利用 API 计算个人净资产的金融科技（FinTech）技能。

### 为什么选择语音用户界面？

语音用户界面（VUI）是允许你通过语音与智能设备交互的任何系统。智能设备包括你的电脑、汽车、手机、平板电脑、家居设备，甚至你的吸尘器。传统上，我们需要起床打开电灯开关，去厨房启动咖啡机，按下按钮给孩子们发短信提醒他们该起床上学了。而借助 VUI，你可以通过语音指令让智能音箱为你完成所有这些操作。

Alexa 是内置于每个 Amazon Echo 智能音箱及亚马逊合作伙伴众多设备中的语音技术。支持 Alexa 的智能设备让你不仅能控制智能音箱，还能通过语音操控更多设备。我们花了很长时间才达到这样的水平：拥有体积小巧、价格相对低廉且具备足够计算能力的设备，同时实现互联网的广泛普及，使智能音箱技术得以有效运作。下一节，我们将回顾历史，了解 VUI 的发展历程以及我们如何走到今天这一步。

在 Botmock 中设计好对话后，我们就可以将设计迁移到新的 Alexa 技能中。



**第 10 章：使用 APL 在屏幕上呈现内容**

对话设计完成后，下一步是为带屏幕的 Alexa 设备创建可视化界面。为此，我们需要使用 Alexa 演示语言（APL），这将在第 10 章中详细介绍。



**第 11 章：编写 Lambda 函数**

在创建并编写好 VUI 和 APL 后，我们可以编写后端代码。我们将使用一个完全自定义的 lambda 函数，构建意图处理器，进行日历绘制的数学计算，并创建数据集以绑定到 APL 模板。



**第 12 章：对 Alexa 技能进行单元测试**

代码编写完成后，应该进行一些测试。在第 12 章中，我们将探讨几种测试意图处理器和 Alexa 响应的方法，包括在 lambda 函数和 VS Code 中进行单元测试，以及测试 Alexa 的自然语言理解和自动语音识别功能。



**第 13 章：存储数据**

当技能按设计正常运作后，我们可以通过捕捉你生活中的事件将其提升到新水平。这需要通过账户关联来确保数据安全地存储在 DynamoDB NoSQL 数据库中。本章最后会提供一些后续步骤建议，以完善这个 90 年日历技能的其余部分。



**第三部分：在高级技能中使用 API**

现在你已经学会了如何创建 Alexa 技能，我们将开始使用应用程序编程接口（API）。这是通过互联网收集数据的常见方式。我们将特别使用两个 API 来构建一个个人净资产技能，该技能可以告诉你房屋和投资的价值。当然，这样的技能会接触到你的部分个人数据，但所有数据都将安全地存储在受保护的数据库中并加密保护。在任何情况下，你都可以选择使用测试账户进行开发，因此完全不需要涉及真实数据。



**第 14 章：个人净资产技能**

想象一下 Alexa 能够告诉你净资产的情况。通过使用账户关联和 DynamoDB，我们可以安全地存储你的个人数据。在本章中，我们将完善 VUI 并构建后端 lambda 函数。但一旦对话模型设计完成，如何获取你的资产价值呢？答案就在互联网上——通过使用 API。



**第 15 章：房地产 API**

通过使用名为 Rapid API 的网站，我们找到了几个可以为房屋估价的 API。其中 Realty Mole 的销售价格估算器尤为突出。在本章中，我们将弄清楚如何利用第 14 章中提供给 Alexa 的地址来获取你的房屋价格。



**第 16 章：股票市场 API**

从数百个股票价格 API 中选择一个后，我们将其集成到 lambda 函数中。本章将扩展第 12 章中的单元测试内容，测试多种不同场景以确保你的股票投资组合得到正确估值。本章最后会提供一些改进技能的建议。



**第 17 章：下一步是什么？**

在本书中，你接触了多种数据源，包括 DynamoDb 等数据库以及 Realty Mole Property API 等 API。此外，你还创建并测试了作为云端后端应用的 lambda 函数。这些 Lambda 后端可以从任何地方拉取数据，并通过 Alexa 技能界面呈现。下一步是什么？本书只是你数据驱动 Alexa 技能之旅的起点。我迫不及待想听听你将会构建什么。
