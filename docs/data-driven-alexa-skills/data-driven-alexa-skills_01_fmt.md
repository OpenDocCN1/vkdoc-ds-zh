## 引言

欢迎来到数据驱动的 Alexa 技能的奇妙世界。让我们一起踏上超越典型 Hello World 示例的旅程，为您的家庭或企业设计和构建创新的、定制的、数据驱动的 Alexa 技能，将 Alexa 与在线 API、丰富的数据源和强大的应用程序集成。如果您具备基本的 Python 技能，本书将向您展示如何构建数据驱动的 Alexa 技能。您将学习如何使用数据为您的 Alexa 技能赋予动态智能、深入的知识和记忆能力。

`数据驱动的 Alexa 技能` 采用循序渐进的方法进行技能开发。您将首先在 Alexa 技能构建器控制台中配置一项技能。然后，您将开发一项高级自定义技能，该技能使用最新的 Alexa 技能开发工具包功能，与 lambda 函数、亚马逊云服务（AWS）和互联网数据源集成。这些技能使您能够链接用户帐户、使用 NoSQL 数据库查询和存储数据，并通过 Web API 访问股票价格等。

从本书中学到的知识将帮助您将 Alexa 与软件即服务和平台即服务应用程序及环境（如 Salesforce、ServiceNow、Microsoft Azure 和 AWS）集成。

本书面向下一代 Alexa 技能开发者，他们希望利用数据让 Alexa 更智能、更相关、更有帮助。为了更接近环境计算的目标，Alexa 需要以多种方式访问和组合来自多个来源的数据。如果您想象有一天 Alexa 能够智能地管理您的电子邮件，能够协调您来自 Outlook、Google、Apple 和 Calendly 的日程，能够告诉您您的净资产，或者能够帮您在 ServiceNow 中记录一个工单，那么本书就是为您准备的。

## 第一部分：入门

在本书的第一部分，我们将向您介绍语音用户界面开发。然后，我们将使用蓝图构建一个例程和几个 Alexa 技能。接着，我们将设置一些您需要的帐户，以便您可以开发 Alexa 技能。现在您已准备好创建一项技能，首先创建 Alexa 对话式语音用户界面，然后在 Python 和 VS Code 中编码和测试后端。在第一部分的最后一章中，您将把您的新技能发布到 Alexa 技能商店！

### 第 1 章：语音用户界面

介绍语音用户界面开发的世界。第 1 章包括从语音开发早期到当今语音格局的简要历史。它还回答了以下问题：为什么是语音？为什么是 Alexa？为什么是现在？

### 第 2 章：例程和蓝图

为 Alexa 创建新技能的最简单方法是使用例程和蓝图。本章将引导您完成创建这些无代码技能的过程。

### 第 3 章：开发者帐户

您需要创建和配置许多帐户才能开发 Alexa 技能。本章将指导您创建这些帐户。

### 第 4 章：为自定义数据驱动技能创建 VUI

现在帐户已设置好，我们准备创建基础的 Alexa 技能。在第一部分的剩余部分，我们将创建一个身体质量指数技能。在本章中，我们配置语音用户界面，包括对话、用户表述、槽位值和 Alexa 的响应。

### 第 5 章：编写后端代码

创建了 VUI 后，我们准备编写一些代码。当然，您需要安装工具，包括 VS Code 和 Anaconda 等。第 5 章列出了您需要的工具以及在哪里可以找到它们。然后，它引导您为 Python 开发配置 Anaconda 环境。接下来，我们为 BMI Alexa 技能创建后端代码。我们通过测试代码来结束本章。

### 第 6 章：发布 Alexa 技能

在第 4 章中创建了 VUI 并在第 5 章中编写了后端代码后，您将准备好将您的新 Alexa 技能发布到 Alexa 技能商店。到第 6 章结束时，您将完成这一目标！
