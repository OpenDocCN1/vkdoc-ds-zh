# 5. 函数与循环

## 5.1 引言

当某个特定的数值任务需要在不同的数据点上“重复”执行时，数字计算机就成为了有用的工具，因为它们比人类能更快地完成这项工作。循环正是执行这些任务的。通过使用条件来检查开始和终止规则，你可以轻松地执行一个过程中的重复部分。不同的编程语言和环境对于定义循环有不同的规则。MATLAB 提供了一种更简单的方式来定义和运行循环。稍后将讨论这些内容。

在此定义“函数”这个术语很有用。一个大型程序可能需要在不同时间调用一组指令。因此，这组指令可以被定义为一个子程序，可以在需要时请求它执行计算。这样，一个复杂的任务就可以被分解成许多小的部分。这种编程架构被称为模块化编程。这是最流行的编程方式，因为它非常合乎逻辑，更利于可视化问题，并且易于调试。定义这些小指令集最流行的方法是将它们定义为函数。本章将详细讨论这两个概念。

## 5.2 循环

循环构成了算法的一个基本部分，因为它们执行的是计算机最擅长的任务：非常快速地执行重复性操作。循环有多种形式——`for` 循环在一系列变量值上重复执行某些任务，`while` 循环在执行特定任务之前检查一个逻辑条件，而 `if-then-else` 循环则检查一个条件并引导算法的流程。选择哪种循环取决于手头的问题。

以下各节列出了各种函数及其用法。批判性地判断它们的用法变得非常重要，因为算法中的循环部分消耗了大部分执行时间。

### 5.2.1 `while` 循环

`while` 循环定义一个逻辑条件，在条件满足之前，它会运行一个代码块。`while` 循环的语法如下：

```
1  while condition
2  BODY
3  endwhile
```

这里，关键字 `while` 启动了一个 `while` 循环的执行。`condition` 是一个逻辑条件，其答案可以是 `true`（真）（1）或 `false`（假）（0）。`BODY` 包含一组命令，这些命令在条件成立之前一直执行（见清单 5-1）。

```
1  x = 1.0;
2  while x<10
3     disp(sqrt(x));
4     x = x+1;
5  endwhile
清单 5-1
while1.m 程序
```

`while1.m` 程序首先将变量 `x` 初始化为值 `1.0`。然后它列出一个逻辑条件：

`x < 10`

在循环的第一步中，`x = 1`，由于 `1 < 10`，此条件满足。由于此条件满足，执行 `disp(sqrt(x))` 并显示 `x` 的平方根。然后执行第 4 行，`x = x + 1` 使 `x` 递增。`x` 的新递增值为 2，再次检查逻辑条件 `x < 10`，并执行第 3 行和第 4 行给出的循环体。这个过程一直持续到 `x = 10`，此时循环条件不再满足。此时，执行第 5 行，宣告 `while` 循环结束。执行 `while1.m` 的结果如下：

```
1  >> while1
2  1
3  1.4142
4  1.7321
5  2
6  2.2361
7  2.4495
8  2.6458
9  2.8284
10  3
```

### 5.2.2 `do-until` 循环

重要的是要注意，在某些情况下，对于 `while` 循环，循环体可能一次都不会被执行。这种情况发生在初始化之后，条件不满足时。为了处理这种情况，`do-until` 循环的语法如下：

```
1  do
2  BODY
3  until condition
```

该循环首先执行代码体，然后检查条件。这样，构成循环 `BODY` 的代码块至少会被执行一次。其用法可以通过清单 5-2 中的示例来理解。

```
1  %显示前十个正自然数的平方根
2  %前十个正自然数
3
4  x = 1.0;
5  do
6    disp(sqrt(x));
7    x = x+1;
8  until x == 10
清单 5-2
dountil1.m 程序
```

执行该代码的结果如下：

```
1  >> dountil1
2  1
3  1.4142
4  1.7321
5  2
6  2.2361
7  2.4495
8  2.6458
9  2.8284
10  3
11  >>
```

在第 4 行，`x` 被初始化为 `1.0`。然后编写循环体来显示 `x` 的平方根，并将其递增 1。这个过程一直持续到 `x = 10`，即直到 `x` 的值变为 `10`。

### 5.2.3 `for` 循环

`for` 循环用于对一组已知的值执行计算。`for` 循环的语法如下：

```
1  for variable = vector
2    BODY
3  end
```

关键字 `for` 声明循环开始，此时一个变量会取存储在向量中的值。然后执行代码体（此处用 `BODY` 表示）。关键字 `end` 声明 `for` 循环的结束。这在清单 5-3 的示例中进行了解释。

```
1  %计算前 10 个数的平方根的程序
2  %前 10 个数的平方根
3
4  for i = 1:10
5    ans = sqrt(i)
6  end

for1.m 程序
```

执行 `for1.m` 的结果如下：

```

3  ans = 1.4142
4  ans = 1.7321
5  ans = 2
6  ans = 2.2361
7  ans = 2.4495
8  ans = 2.8284

```

### 5.2.4 `if-elseif-else` 循环

当你需要在不同时间检查多个条件时，`if-elseif-else` 循环效果很好。此循环的语法如下：

```
1  if condition1
2  BODY1
3  elseif condition2
4  BODY2
5  else
6  BODY3
7  endif
```

在第 1 行，定义了一个条件。如果该条件满足，则执行第 2 行；否则，执行第 3 行。因此，`BODY1` 和 `BODY2` 是通过检查不同条件集而执行的代码块，而 `BODY3` 是在任何条件都不满足时执行的代码。见清单 5-4。

```
1  %检查一个数的程序
2  %数是奇数还是偶数
3
4  x = 33;
5
6  if(rem(x,2) == 0)
7    printf("x 是偶数\n");
8  elseif(rem(x,5) == 0)
9    printf("x 是奇数且可被 5 整除\n");
10  else
11    printf("x 是奇数\n");
12  endif
清单 5-4
ifelse1.m 程序
```

执行 `ifelse1.m` 的结果如下：

```
1  >> ifelse1
2  x 是奇数且可被 5 整除
```

在第 4 行，`x` 被初始化为 `33`。然后，在第 6 行，检查 `x / 2` 的余数。如果为零，则执行第 7 行。否则，执行第 8 行，并检查 `x / 5` 的余数。如果为零，则执行第 9 行。如果两个条件都不满足，则执行第 11 行。第 12 行结束 `if-else` 循环。

## 5.3 函数

函数是可以根据需要调用的代码。因此，它可以单独定义，要么在单独的文件中，要么在程序体内。MATLAB 提供了几种定义函数的方法，这些将在以下小节中讨论。



### 5.3.1 `function` 函数

`function` 的定义遵循以下语法：

```
1  function [返回值 1, 返回值 2, ...] = 函数名([参数 1, 参数 2,...])
2  函数体
3  endfunction
```

在这里，`function` 关键字将对象类型定义为函数。然后，定义一组该函数预期返回的变量。接下来是 `=` 运算符，然后是函数的名称。在这个例子中，它被命名为 `name`。`name` 对象接受一组参数，这些参数是函数所定义的对象。接着是函数的主体部分。最后一部分定义了函数的结束。例如，可以编写一个函数来计算 x² − y²，并将结果赋值给名为 `z` 的变量，如下所示：

```
1  function y = fn1(x,y)
2  y = xˆ2−yˆ2;
3  end
```

将其保存为当前工作目录下的 `fn1.m` 文件。现在转到 MATLAB 终端并输入以下内容：

```
1  >> fn1(5,1)
2  ans = 24
3  >> fn1(5,2)
4  ans = 21
5  >> fn1(5,3)
6  ans = 16
7  >> fn1(5,4)
8  ans = 9
9  >> fn1(5,5)
10  ans = 0
```

可以看到，名为 `fn1` 的函数正在对其定义的两个输入参数执行 x² − y² 的计算。

将程序定义为一组函数文件，然后在存储为脚本文件的主程序中调用它们，是一种良好的实践。这种模块化方法使得尝试不同的思路变得容易，同时也使代码的调试和测试更加简便。一个函数也可以返回两个以上的值。例如：

```
1  function[y1,y2,y3] = fn2(x,y)
2  y1 = xˆ2−yˆ2;
3  y2 = xˆ2+yˆ2;
4  y3 = y2−y1;
5  end
```

这将得到以下结果：

```
1  >> [a,b,c] = fn2(5,2)
2  a = 21
3  b = 29
4  c = 8
5  >> [a,b,c] = fn2(5,0)
6  a = 25
7  b = 25
8  c = 0
```

函数可以包含循环来管理程序中的重复任务。例如，可以使用下面给出的函数来计算一个数的阶乘：

```
1  function result = factorial(n)
2    if(n == 0)
3      result = 1;
4      return;
5    else
6      result = prod(1:n);
7    endif
8  endfunction
```

一个名为 `factorial` 的函数，它接受一个数字 `n` 作为参数，计算该数字与所有连续数字的乘积。当从 MATLAB 命令行调用时，该函数产生以下结果：

```
1  >> factorial(50)
2  ans = 3.0414e+064
3  >> factorial(1)
4  ans = 1
5  >> factorial(0)
6  ans = 1
7  >> factorial(100)
8  ans = 9.3326e+157
9  >> factorial(1000)
10  ans = NaN
11  >> factorial(−1)
12  error:factorial:N must all be non−negative integers
```

`help NaN` 和 `help prod` 提供了关于这些命令行为的有用见解。

### 5.3.2 `inline` 函数

函数也可以使用 `inline` 关键字进行内联定义，如下所示：

```
1  >> f = inline("xˆ2+y");
2  >> f(1,2)
3  ans = 3
4  >> f(10,10)
5  ans = 110
6  >> f(0,2)
7  ans = 2
8  >>
```

第 1 行定义了一个名为 `f` 的函数，包含两个变量 `x` 和 `y`，用于计算 f(x, y) = x² + y。当使用这两个变量的值调用时，该函数会输出计算出的值。

### 5.3.3 匿名函数

匿名函数是在程序中定义的未命名函数对象。它们的定义遵循简单的语法：

```
@(参数列表) 表达式
```

例如：

```
1  >> a = @(x) sin(x)*cos(x);
2  >> quad(a,0,1)
3  ans = 0.35404
4  >> quad(a,0,pi)
5  ans = 7.3031e−017
6  >> quad(a,−pi,pi)
7  ans = 0
8  >> quad(a,−pi,2*pi)
9  ans = −2.8435e−016
10  >> quad(a,−2*pi,2*pi)
11  ans = 0
```

`help quad` 告诉我们，函数 `quad` 用于计算一个函数在两个值之间的积分。因此，第 1 行定义了一个函数 sin(x)cos(x)，其积分结果如下所示。

## 5.4 总结

定义函数是模块化编程的关键。MATLAB 提供了一种优雅的方式来定义和使用函数，无论是内联形式还是单独的文件形式。当与在循环中编写函数的能力相结合时，复杂的问题只需几行代码即可实现。这需要在设计算法时具备艺术性的态度，其中函数和循环就像是画笔，帮助您为给定的数值问题设计出优雅的解决方案。
