# 15. 预测经济：一场新的工业革命

> *“我设想有那么一天，我们之于机器人，就如同狗之于人类，而我支持机器。”*
> 
> ——克劳德·香农

自从地球上出现生命以来，它就始终面对着模糊、不可预测和未知的事物。在历史的大部分时间里，自然界的未知可能比任何人造的未知都显得更为关键。天气好坏可能意味着一个季节是挨饿还是幸存下来。随着社会日益复杂，人造的未知变得比自然的未知更具威力。战争夺去了数百万人的生命。新发明带来了前所未有的繁荣岁月。新的文化和政治趋势每几十年就会出现一次，并改变着人类的生活和经商方式。

然而，无论最大的挑战是来自自然还是其他人，纵观历史，总有一个共同的主题：人类预测和掌控未来的渴望。从古希腊的德尔斐神谕，到诺查丹玛斯的预言，再到萨满和灵媒，人类一直试图预测未来。不确定性是焦虑的一个主要成因，这种焦虑如此强烈，正如你之前读到的，它已经根植于我们的大脑中。避免这种焦虑的渴望*如此*强烈，以至于人类很容易被任何声称拥有神秘力量的人所欺骗。也许，许多人预测未来的愿望是如此之大，以至于他们甚至欺骗了自己。

随着人类迈入 21 世纪，收集数据、发现模式和进行预测的能力正变得越来越好、越来越精确。预测未来的能力不再是科幻小说；它已成为现实。我们正在见证一场以数据科学为中心的重大革命。一些人预测，大数据将彻底颠覆我们生活的方方面面。另一些人则对将要实现的颠覆程度持更为谨慎的态度。但无论如何，人工智能和数据科学目前正被越来越多的行业所采用。

不确定性在许多行业中扮演着关键角色，甚至是一些行业（如保险业）的根本驱动力。因此，驱散不确定性迷雾的能力至关重要。要理解不确定性在经济活动中的作用方式，我们必须对行业可能面临其影响的不同方式进行分类。本章考察的三个类别如下：

1.  不确定性中介：核心业务是管理不确定性和风险的行业。

2.  信息不完整：因当前世界的真实状态而面临不确定性的行业。

3.  预测型行业：面临未来不确定性，因此必须预测未来世界状态的行业。

另一个对经济产生的重大影响是通过自动化实现的。虽然自动化与不确定性没有直接关系，但所应用的算法和技术是相似的。这里讨论的分类是基于经济学术语的。

第一类指的是所有预测在其中扮演关键角色的行业。例如，在农业和渔业中，预测天气的能力至关重要，因为恶劣天气可能对作物造成灾难性影响。但这关乎对自然现象的预测。其他行业则面临受人类影响事件的不确定性。例如，在金融领域，如果有人能构建出出色的股价预测算法，财富便会随之而来。在零售业，公司必须预测产品的未来需求以及新趋势。在警务工作中，当局若能预测新犯罪最可能发生的地点，将从中受益。而这仅仅是面临未来预测的不同行业中几个例子而已。

第二类指的是那些要么面临未知因果关系，要么需要基于不完整信息做出决策的行业。例如，在医学领域，预测药物对个体的影响往往很困难。医生必须对药物的副作用或潜在疗效做出有根据的猜测。Netflix 正试图预测你最可能喜欢哪些电影，而亚马逊则在预测你最可能购买哪些产品。军方必须基于关于敌人能力的不完整信息做出决策。法官必须基于法医鉴定结果做出判决。

最后，还有一些行业，不确定性本身就是被交易的产品。保险业是其中的典型代表。自诞生以来，它就一直为那些认为风险对其业务和生活不利的人提供风险保障。金融业也属于这一类。许多金融产品试图在最小化风险的同时确保利润。投资这些产品的人们是在为他们的资金寻找避风港，以抵御通货膨胀，而不是想通过预测股市来发财致富。
