# 从加密无政府主义到毒品交易：一项有趣技术的非传统起源

区块链的兴起背后有一个有趣的故事。`比特币`试图彻底改变我们进行货币交易的方式。然而，在很长一段时间里，使用它的地方并不多。它最受欢迎的使用场景之一是“丝绸之路”（并非古老的欧亚贸易路线）。丝绸之路是暗网上的一个毒品交易市场。暗网是一个无法被搜索引擎索引的网络；它需要特殊软件才能访问。

那么，一个非法市场如何在互联网上运作？一个人如何向毒贩付款而不被警方发现？答案是`比特币`。`比特币`具有伪匿名的特性。交易双方无需使用真实姓名。之所以说是`伪`匿名，是因为后来人们发现，在某些情况下仍然可以追溯到个人交易行为。然而，早期许多人认为它是完全匿名的。

`比特币`在很长一段时间里是丝绸之路使用的加密货币。丝绸之路在 2014 年被美国联邦调查局和欧洲刑警组织捣毁。讽刺的是，这反而进一步推动了`比特币`的普及。`比特币`也成为了那些想要藏匿资金或逃税的人的交易媒介。因此，`比特币`的知名度进一步提升，但却是出于错误的原因。不过，同样值得注意的是，许多早期参与`比特币`应用的人是加密理想主义者，他们真心相信中本聪的愿景。如今，随着许多个人和公司将其视为价值储存手段，`比特币`的受欢迎程度进一步增加。最好的例子就是来自`MicroStrategy`的迈克尔·塞勒，他将公司资金投资于`比特币`作为一项投资。

`以太坊`的出现证明了区块链除了货币兑换之外还有其他用途。虽然智能合约原本被认为是未来交易的方式，但真正的革命却来自于首次代币发行（ICO）。智能合约允许任何人在`以太坊`区块链上创建自己的加密货币。以这种方式创建的加密货币被称为代币。因此，代币经济和 ICO 应运而生。

ICO 背后的概念如下：一个企业使用代币作为其平台的货币。为了购买这种代币，你需要花费`以太坊`或`比特币`。ICO 就像首次公开募股（IPO），但它使用的是代币而非股票。代币向公众发行，然后这些代币要么以固定价格购买，要么通过某种拍卖机制购买。公众购买代币，要么是因为他们认为代币会升值，要么是因为他们想在平台上使用这些代币。

例如，`Filecoin`是一个去中心化版本的硬盘。你可以使用`Filecoin`在由其他用户组成的`Filecoin`网络中存储文件。你也可以通过允许其他用户使用你硬盘上的空闲空间来赚取`Filecoin`。代币催生了所谓的“代币经济”。代币经济允许通过任意激励措施（例如，使用你的硬盘空间）来获得奖励。一些例子，比如前面提到的`Filecoin`，只能存在于区块链之上。

但是，撇开代币经济不谈，公司为什么会想通过这种方式筹集资金呢？通过这种方式筹集资金比其他方式（例如，传统众筹）要容易得多。此外，区块链的全球性意味着世界上的任何人都可以非常轻松地在瞬间购买这些代币。加密货币让国际交易看起来很简单。最后，区块链项目日益增长的人气意味着人们愿意向任何与区块链相关的东西投入大量资金。

2018 年，ICO 筹集了超过 70 亿美元。^(¹⁶⁶) 这些项目大部分都失败了，这并不令人意外，因为有些公司甚至在产品都没造出来时就要求数百万美元。作为比较，在许多国家，种子轮融资通常不超过 100 万美元，即便如此，要求资金的公司也很有可能已经构建了产品原型。到了 2019 年，ICO 成了一个有毒的词汇，大多数投资者都避之不及。

然而，这两个故事在普及区块链技术方面都发挥了巨大作用。无论是在认知方面还是在监管方面，这个领域现在正日趋成熟。

ICO 已被其他更稳健且通常受到监管的筹资形式所取代。这些形式包括`Binance`等交易所上的发射台、首次交易所发行（IEO）^(¹⁶⁷)，以及`Uniswap`等去中心化交易所上的去中心化交易所发行（DEO）。^(¹⁶⁸)

过去几年也出现了一些积极和消极的进一步发展，它们帮助加密世界闯入了主流视野。

加密社区见证了一次所谓的“牛市”，所有加密货币的价格在 2022 年飙升至新高，随后崩盘。崩盘之后是一系列丑闻，例如`Terra/Luna`稳定币的完全崩盘、`Genesis`加密借贷平台的倒闭，以及曾经最大的交易所之一`FTX`的破产。

与此同时，世界也见证了新的发展，例如去中心化金融、NFT 和元宇宙。

各国政府正在讨论各种加密货币监管政策，并推出 CBDC（即央行数字货币），这是一种中心化的数字货币版本。

因此，尽管区块链起步坎坷，但它似乎将长期存在，并在未来几年在我们的生活中扮演更重要的角色。
