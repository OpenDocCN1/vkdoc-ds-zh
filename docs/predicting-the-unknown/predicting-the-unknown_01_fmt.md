# 序言

公元前 8000 年，一个部落中的男子因猎杀一只瞪羚而欣喜若狂。然而，这份快乐转瞬即逝，因为这点食物仅够勉强维持一个五口之家。他明天还能找到食物吗？一位高中毕业生刚刚收到普林斯顿大学的录取信。她怀着焦虑与兴奋交织的复杂心情，举起信准备拆开。整个国家都目不转睛地注视着选举结果的揭晓。哪个政党将在未来四年执掌国家？一对夫妇正赶往机场，准备开始他们计划已久的假期，却得知所有航班因疫情而取消。

专家们争论着人类在 21 世纪是否正面临环境灾难。争论愈演愈烈，关于其影响及后续可能的解决方案，各方观点不一，但没有人能确知未来会发生什么。

这些看似毫无关联的轶事，有什么共同点？

不确定性是贯穿存在的一条共同主线。近期的科技进步，不过是人类自诞生以来，为对抗这一宿敌所付出努力的具体体现。哲学家们探讨过关于真知本质与世界状态的疑问。数学家们则想出了衡量不确定性及其反面——信息——的方法。不确定性是生活的一部分，是许多人宁愿避而不及、却又无法回避的一部分。

世界正在改变，我们目睹的主要变化之一，便是信息、互联互通、测量、控制与预测的增强。在我们全天候互联的世界里，秘密已所剩无几。我们不再相信世界边缘有巨龙盘踞，城市外的森林里有怪物出没。相反，这些巨龙与怪物如今藏身于未来：在难以预料的金融危机中，在突如其来的疾病中，在可能让我们丢掉工作的意外交通堵塞中，或是在我们选择（无论是政治选择还是个人选择）所带来的、未曾预见的结果里。我们正在逐步征服未知的疆域，但有些壁垒似乎依然坚不可摧。
