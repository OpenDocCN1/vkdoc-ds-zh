# 有没有更高效的方式来表达你对《侏罗纪公园》的热爱？

这条消息由三个完全相同的句子组成。与其发送整条消息，你可以将其编码为类似下面的表达式：

*   “*3: 《侏罗纪公园》是有史以来最棒的电影！”

这是原始消息的压缩形式。你传达了完全相同的信息量，但使用了更紧凑、更短的表示形式，从而节省了比特。

那么，数据压缩与机器学习有何关联？David MacKay（1967–2016）在其著作《信息论、推理与学习算法》^(⁴⁰)中描述了两者之间的关系。压缩与可预测性相关。正如你将在第 8 章中看到的，学习的关键概念是从具体示例泛化到更广泛的概念。当我们这样做时，实质上是在尝试压缩信息，同时接受学习过程在此过程中也会犯一些错误。

当某事物易于预测时，它也易于压缩。例如，假设你正在尝试压缩一首歌曲，其中每第三个和弦是 C 小调。一种简单的压缩方式是使用一种代码，用简单的话来说可能像这样：

*   “C 小调位于位置 3、5、8，直到最终位置 30。”

如果你预测每个和弦都是 C 小调，你仍然有 1/3 的时间是正确的。这个简单的例子展示了两者之间的类比关系。

信息论也与进化有关。首先，我们所有的遗传信息都编码在我们的 DNA 中。其次，进化可以被看作是一场学习游戏。每个生物体都有一个称为“适应度”的量。适应度可以是任何有助于生存和繁衍的东西：从我们高智商，到鸟类飞行的能力，再到羚羊快速奔跑的能力。自然选择可以被视为一位老师。每一代幸存下来的新生命都会产下后代，这些后代携带着关于哪些适应措施有效的信息。

John Maynard Smith（1920–2004）认为，猿类和人类之间的差异是 40 万比特的信息。MacKay 则认为，考虑到基因组的大小，这是一个很小的差异，并提出了一个不同的模型。从信息论角度来看，进化也解释了为什么存在有性生殖，而不是大多数生物仅通过单性生殖进行繁殖。一个基因组大小为 G 的种群，其获取信息的速度比单性生殖种群快 $\sqrt{G}$ 倍，因此它能更快地进化并适应环境。因此，一个拥有 1000 个基因的简单生物体（人类基因组大约有 20000 个基因）通过有性生殖进化的速度是通过单性生殖的 100 倍。

信息论应用的另一个领域是密码学。网络安全是当今技术领域的热门方向，这有其充分的理由。我们的世界越依赖于互联网，我们传输的数据就越多，进行的交易也越多，这些信息落入不法之徒手中的风险就越大。我们已经讨论过密码学在第二次世界大战中的使用方式，以及艾伦·图灵——与香农及其他杰出科学家一起——的努力在其中所起的作用。

香农是第一个证明牢不可破的密码学是可能的人。他设计了一种称为“一次性密码本方案”或维纳姆密码的方案，以其发明者吉尔伯特·维纳姆（1890–1960）命名。香农证明了这种编码方案是无法破解的。我们至今尚未拥有牢不可破的加密方法，是因为这种方案实际上不可用。然而，量子密码学或许能在未来解决这个问题。

香农的多方面贡献是他个性的直接结果。香农一生涉足不同的科学领域和问题，同时他热爱非传统的爱好——至少对学术界而言是如此。人们经常看到他一边骑独轮车一边玩杂耍。有时他会骑着弹簧单高跷四处走动。他是一位国际象棋爱好者，研究国际象棋的复杂性，甚至创建了一个可以下棋的程序。他喜欢制造东西，在他创造的众多设备中，他建造了一个能走出迷宫的机器老鼠（人工智能最早的尝试之一）、一个能玩杂耍球的机器，以及一把吹奏时能喷火的号角。^(⁴¹) 他一生获得了超过 20 个荣誉博士学位和奖项，但他从未真正在意过它们。他把博士帽挂在一个他自己制作的、类似于旋转领带架的装置上。

不幸的是，香农在 20 世纪 90 年代患上了阿尔茨海默病。这是一个悲剧性的讽刺，因为这位创立了信息论的人，却被一种会损害大脑信息通道的疾病所折磨。他于 2001 年因该病去世，享年 84 岁。

然而，在他去世之前，这位伟人成功奠定了信息时代的基础。他是第一个直接向不确定性问题发起挑战、对其进行量化并将其数字化的人。

概率究竟如何应用于实践？统计学这门科学，构成了下一章的基础，一直是唯一一门明确处理不确定性研究的学科——当然，直到机器学习出现之前。虽然统计学可能唤起枯燥的校园回忆，但正如卡尔·皮尔逊所说，它是“科学的语法”。这是一门值得你花心思去掌握的语言。
