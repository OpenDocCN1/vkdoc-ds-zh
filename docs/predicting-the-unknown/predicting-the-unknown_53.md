# 不确定性下的全球经济

许多数据科学的乐观支持者相信，我们很快就能预测一切。从时尚新潮流到疾病，我们的预测能力越来越强。因此，有人可能会推断，不确定性终将减少到零。

然而，也有一些更为悲观的论调。纳西姆·尼古拉斯·塔勒布认为，我们根本无法预测重大的未来事件。这主要有两个原因。首先，我们建模事物能力依赖于过去已发生的事件。最大的洪水或灾难可能根本尚未发生。其次，我们当前世界中的很大一部分不确定性并非来自自然世界，而是来自社会世界。预测金融危机甚至比预测自然灾害更难。因此，试图做出预测是徒劳的。相反，我们必须尝试构建塔勒布所称的"`反脆弱系统`"。这些系统能从随机性和不确定性中获益。

例如，一个拥有多层管理结构和严格流程的大型企业是脆弱的。经济上的任何剧烈变化都可能迅速将这种组织化为乌有。另一方面，一家小型科技公司可能极具反脆弱性。一个单一的随机事件（例如，签下一个大客户）就能迅速使这家初创企业从小公司一跃成为新星。

对反脆弱性概念的完整讨论超出了本书的范围；然而，这个概念确实有其可取之处。尽管如此，两种观点都各有道理，而且，一如既往地，真相往往更为复杂。

对于许多现实世界的挑战，我们最终或许能够实现近乎完美的预测，尤其是与自然系统相关的任何事物。医学就是一个很好的例子。此外，具有有限规则的社会系统也能以高度准确性进行预测。交通拥堵就是一个很好的例子，因为基于智能体的建模可用于优化交通。

有些自然现象，如洪水和地震，可能很难——甚至不可能——在长期范围内进行预测。这些都是自然的复杂系统，与复杂的社会系统（例如，经济）非常相似，多种因素结合在一起，使得预测几乎不可能。然而，我们已经看到模拟在这些情况下如何成为一种宝贵的工具。

我个人的观点是，讨论我们未来是否能完美预测一切，这让我们回到了围绕不确定性的重大问题的根源。世界上的所有不确定性是随机性的，还是认知性的？我们是否能像维多利亚时代的科学家所相信的那样，只要能够测量就能预测一切，还是我们生活在一个混乱的世界中，我们预测不确定性的能力是有限的？

这些都是重要的哲学问题，但"做"通常比"想"更有力量。而当我们思考这些问题的同时，经济体和社会已经在效率和利润方面取得了进步。然而，这些进步是渐进的、递增的。我们听到一些声音警告，某种迫在眉睫的奇点即将到来，人工智能将夺走我们所有的工作，世界将陷入停滞。事实上，自动化*确实*会取代许多工作岗位，但我们并不面临全球性人工智能接管的风险。

我们的预测能力变得越来越好。有些人实际上能够做出很好的预测，尽管他们是少数。我们的大脑已经进化到可以应对不确定性，而我们如今都好好地活着这一事实表明，至少我们世界中的部分不确定性是可以被战胜的。

然而，随着我们的进步，新的不确定性也被引入我们的世界。我们不再需要担心食物从何而来，但我们必须担心中央银行设定的利率将如何影响我们的房贷，或者担心下一次选举的结果。我们非常擅长消除许多小事物中的不确定性，而这正是复杂互联社会的成果，在这种社会中，此类数据聚合成为可能。

然而，在这样做的过程中，我们也增加了社会其他方面的复杂性和不可预测性。在经济层面上，一个国家的危机可能拖垮全球金融体系。当我们征服了自然世界中可预测的不确定性时，人类便成为了不确定性的主要来源。控制社会系统中那些能够减少不确定性的部分，责任在我们自己。一个金融体系不一定是脆弱的。是设计者的失误使其变得脆弱。政府可能成为不确定性的巨大来源，但我们有能力利用技术使决策更加去中心化、组织得更好。在正确原则的指导下，任何社会系统中的不确定性都可以减少。然而，这已经超越了单纯技术进步的范围，进入了社会进步的领域，而社会进步总是更缓慢，且充满起伏。话又说回来，一点不确定性反而让我们的生活更有趣，所以我们可能永远也不想完全消除它。
