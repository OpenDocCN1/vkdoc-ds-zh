# 前言

## 作者致好奇的读者

《不确定性》带领我们踏上一段旅程，从古代哲学出发，经过文艺复兴时期的数学家，直至现代的机器学习实践者。它探讨了我们的心智与大脑如何处理不确定性，以及由人类引发的不确定性为何且如何可能无法被征服。本书也讨论了现代技术发展，如机器学习和区块链，并阐释它们如何影响经济和我们的世界。

我在此论证，将人类历史与当前科技进步联系起来的那条共同主线，正是不确定性。

在第一章，我们将探索不确定性的简史——未知事物如何塑造了文明，它可能侵入我们生活的多种方式，以及不确定性的不同种类和伪装。

在接下来的章节，我们将探讨一个最重要的哲学问题。归纳推理是我们构建关于世界理论的过程；它是科学思维的基础。从方法论上讲，它是我们对抗不确定性这一战役中最重要的武器之一。但它在两千多年来一直困扰着思想家们：它为何有效，又如何运作？我们将讨论不同时代的哲学家是如何处理这个问题的，以及这与我们当前用来对抗不确定性的一些工具有何关联。

在第三至第五章中，我们将审视概率论。我们将了解这一理论是如何形成的，并探讨一些概率的替代理论。

在第六章，我们将探讨信息论，以及克劳德·香农的工作——他是量化不确定性的第一人。

在第七章，我们将深入探讨第一个明确处理不确定性主题的学科：统计学。在我们进入计算机时代并取得近期发展之前，统计学这门学科一直垄断着关于不确定性的讨论。我们将审视统计学家们使用的一些核心工具，以及这个领域的一些英雄人物——和争议人物，如罗纳德·费希尔、卡尔·皮尔逊和埃贡·皮尔逊。

第八章将探讨我们目前用以描述、控制和抵御不确定性最前沿的技术：机器学习。在过去二三十年里，机器学习已成为处理预测相关问题的事实标准方法。我们将了解机器学习的基本类型，讨论其历史中的一些片段、它与统计学的区别，以及一些关于它为何如此有效的理论。

在第九章，我们将跨越可能是不确定性研究的下一个前沿：因果关系，以及统计学和机器学习在理解因果关系方面的不足之处。我们将探讨构建真正人工智能的关键可能在于因果关系——是如何实现的，以及为何如此。

在第十章，我们将探索可以说是不确定性领域中最激动人心——当然也最具争议和风险——的领域之一：预测。预测未来一直是人类想象力的源泉。从古代的神谕到现代的民调专家，我们对未来之事的着迷，甚至可能是人类与动物之间最具决定性的区别。

在第十一章和第十二章，我们将思考预测的局限性。自然是否设置了某种上限，阻碍我们做出准确预测并揭开不确定性的面纱？几个世纪以来，出现了许多不同的理论。
