# 我无法信任你，但可以信任区块链

> *“传统货币的根本问题在于其运作所必需的信任。我们必须信任央行不会让货币贬值，但法定货币的历史充满了背信弃义。我们必须信任银行能保管我们的资金并以电子方式转账，但它们却以极少的准备金为基础，在信贷泡沫的浪潮中不断放贷。我们必须信任它们保护我们的隐私，信任它们不会让身份窃贼掏空我们的账户。”*
>
> ——中本聪，比特币创始人

区块链为许多人认为真实存在的问题提供了一个有趣的解决方案。交易中充斥着信任问题。因此，任何促进信任的技术都应有利于经济发展。然而，首次代币发行（ICO）和“丝绸之路”网站表明，区块链所承诺的部分应用案例并非全然有益。区块链本应解决信任问题，但许多 ICO 要么是骗局，要么是糟糕的投资，以至于有专门的网页来记录这一主题。^(¹⁶⁹)

那么，当我们首先需要信任区块链时，它又如何能解决信任问题呢？公链试图解决一个早已通过全球货币体系解决的问题。区块链背后的愿景之一是“去中心化本身即有益”，但这并非总是如此。如果一样东西没坏，你并不总需要去修理它。很多时候，新技术——包括区块链——都被过度炒作。但它的确有许多诱人的应用场景。

## 支持代币经济的论点

在众多领域中都有支持代币经济的论点。例如，开源浏览器 Brave 创建了一种名为“基本注意力代币”（`Basic Attention Token`）的代币。这种代币通过奖励观看广告的用户，以及奖励发布承载广告内容（例如视频和博客文章）的创作者，完全去除了中介（如谷歌广告）。`IPFS`（星际文件系统，`Interplanetary File System`）是一个用于数据共享的代币化区块链。用户保有对自己数据的所有权，可以直接相互共享，而无需通过中央服务器。安全代币是另一个应用场景。安全代币是一种充当金融证券的加密代币。安全代币将区块链的所有优势引入传统证券世界。例如，股票或土地所有权证可以以安全代币的形式发行。这样做的好处是，与需要通过中介进行交易的传统证券相比，安全代币可以更快地、全天候地进行交易。

另一个有趣的代币经济典型例子是 `Steemit`。^(¹⁷⁰) `Steemit` 是一个基于区块链的社交媒体网站，拥有非常有趣的代币经济。它有三种代币：`Steem`、`Steem Dollars` 和 `Steem Power`。该平台通过以 `Steem Dollars` 形式的奖励激励内容创作者，这些奖励随后可以兑换成 `Steem` 以便换成美元，或兑换成 `Steem Power`。后者代表了平台的所有权，`Steem Power` 持有者根据其持股比例获得代币。`Steemit` 展示了区块链初创公司如何以民主的方式运作。随着区块链的不断发展，有见识的读者可以找到更多类似的例子。

## 分布式账本在企业环境中的应用

其次，分布式账本在企业环境中也有许多应用。分布式账本技术 `Corda`（并非基于区块链）已被多家公司采用，作为简化运营流程的方式。^(¹⁷¹) 一个由多家银行组成的联盟使用 `Corda` 创建了一个贸易金融应用程序，^(¹⁷²) 因为它能提供比现有基础设施更优的架构。

## 区块链在供应链中的应用

在供应链中使用区块链可以减少信息不确定性并提高效率。马士基公司发现，一次冷藏货物的运输^(¹⁷³) 就涉及 30 个不同的个人和组织以及 200 次独立的交互。这个过程非常复杂，成本高昂，且容易出错和发生欺诈。而区块链可以用来解决这个问题。使用区块链使得供应链中的任何一方都能轻松地检查商品的原产地。结合物联网和区块链，可以自动跟踪货物的位置，无需人工操作。

大公司已经在这方面进行投资。IBM 通过其 `TradeLens` 平台^(¹⁷⁴) 使用区块链作为供应链管理的解决方案。沃尔玛宣布打算使用 `IBM Food Trust` 平台通过区块链来追溯食品。^(¹⁷⁵)

## 区块链在保险业的应用

区块链在保险业也有多种用途。`Etherisc`^(¹⁷⁶) 构建了一个航班延误保险项目。当符合条件的触发事件发生时，投保乘客会自动收到赔偿，这使得整个流程更加高效。他们目前还在研究农作物保险。安永推出了 `Insurwave`，^(¹⁷⁷) 这是一个基于区块链的海运保险平台。`Insurwave` 平台提供关于船舶位置、状态和安全状况的实时信息。当船舶进入高风险区域（例如战区或风暴区）时，程序会检测到并更新其承保和定价计算。

## 区块链在医疗记录管理中的应用

麻省理工学院开发了一个名为 `MedRec` 的区块链平台，用于存储和处理医疗记录。^(¹⁷⁸) 患者可以将他们的记录保存在区块链上，然后他们可以选择授权医疗服务提供者进行访问。这种缺乏中心化中介的架构使系统更加安全和高效，因为患者可以直接访问其记录，并完全控制这些记录的使用方式。

## 区块链在政府行政管理中的应用

区块链在政府行政管理中也有应用。例如，身份证和出生证明的发放可以通过区块链进行。税务记录也可以保存在区块链系统中，然后通过智能合约自动进行审计。泰国政府已经部署了这样一个系统，用于防止涉税欺诈。^(¹⁷⁹) `World Identity Record`^(¹⁸⁰) 是一个基于区块链的系统，为那些没有身份证明或丢失身份证明的人提供身份。人口贩卖受害者、现代奴隶制受害者以及逃离战区的移民等只是其中一些例子。摩尔多瓦共和国是使用该系统打击人口贩卖的国家之一。^(¹⁸¹)

## 区块链对金融领域的颠覆及其他应用

区块链公司也在试图颠覆金融领域，例如汇款、资金转账以及资产代币化。去中心化金融（常被称为 DeFi）已成为一股流行趋势，许多团体正在致力于开发区块链解决方案，以替代当前金融体系的某些方面。金融业的未来难以预测，但几乎可以肯定的是，它将包括一些区块链应用。

最后，还有其他一些应用，例如元宇宙和同质化代币（也称为 NFT）。这一叙事的影响力如此之大，以至于 Facebook 决定更名为 Meta，为可能成为下一个计算大趋势做准备。NFT 在 2021 年创造了一个巨大的市场，主要集中在艺术品领域。NFT 允许数字资产（图像是最佳例证）所有权的交换，从而实现了数字商品的拍卖和获取。过去，数字商品（例如数码照片）价值非常低，因为它们可以被无限复制，而 NFT 将这些类型的物品变成了稀有收藏品。

反对区块链的主要论点之一在于，其许多使用场景也可以通过中心化数据库来解决。诚然，在很多情况下并不需要区块链。就像科技领域屡见不鲜的情况一样，它被过度炒作，并被吹捧为万能药。大公司也助长了这一趋势，它们总是热衷于向客户推广新技术。支持与反对区块链的论点都带有技术性，但至少就目前而言，区块链似乎正在许多行业占据一席之地。

如果非要总结分布式账本的核心优势，我会这样说：分布式账本增强了信任。增强信任带来的好处可能意味着更高的效率、更大的利润率，以及中间商的消除。区块链面临着技术挑战，如果要让区块链得到大规模采用，我们就必须克服这些挑战。

区块链有潜力在正在兴起的新预测经济中发挥巨大作用，这正是下一章的主题。
