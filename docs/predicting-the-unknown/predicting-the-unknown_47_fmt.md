# 信任互联网

比特币试图解决的问题是创建一种去中心化、"无需信任"的货币。比特币是去中心化的，因为它不需要中央机构来运作。它是无需信任的，因为货币的交换不依赖于各方的信念或声誉。该系统之所以能够运行，是因为其背后有一套算法在驱动，而该算法并不依赖于中心化权威机构。

维塔利克·布特林是一位俄裔加拿大程序员。2013 年，^(¹⁶³)他在 GitHub 上发布了一份白皮书，阐述了作为比特币核心支柱的`区块链`技术如何用于创建`智能合约`。以太坊于 2015 年上线，是区块链发展过程中除比特币之外最重要的单一项目。

布特林的洞察在于：虽然比特币试图解决的问题是货币的去中心化与无需信任交换，但区块链真正要解决的问题是信任。`智能合约`是两方之间在去中心化的以太坊网络上经过验证和核查的协议。一份`智能合约`可以包含任何类型的协定与条件。

例如，可以在供应商与买方之间创建一份`智能合约`，要求货物一到达，买方就向供应商付款。也可以在被保险人与保险公司之间使用`智能合约`，一旦汽车受损，被保险人立即获得赔偿。

这些显然可以通过传统技术手段实现。然而，与以太坊的不同之处在于，`智能合约`的验证是以去中心化、无需信任且透明的方式进行的。`区块链`承诺了以下优势：

1.  去中心化：没有任何单一权威有能力影响该系统。
2.  透明性：所有交易都公开可供任何人查看和审计。
3.  不可篡改性：一旦交易被记录到区块链上，就无法更改。

`区块链`承诺了一个去中心化且无需信任的世界，在这里交易无需中介即可进行。但这究竟是如何运作的呢？

## 区块链是如何运作的

在技术领域，事物往往朝着更高层次的抽象发展。比特币作为一种创新，聚焦于货币领域并利用了`区块链`技术。我们发现，`区块链`是一种更为通用的技术，可以用于任何类型的协议，而不仅仅是涉及货币的协议。一个更广泛的概念，也囊括了`区块链`，就是`分布式账本`。

传统上，所有交易都记录在一个账本中。账本自官僚体系诞生之初就已存在。`分布式账本`是一个由系统中所有参与方共同维护的账本。因此，任何发生的交易都会被所有参与方记录，并且从第一笔交易到最后一笔交易，存在一个所有参与方都认同的共同历史记录。

这为什么重要？比特币最初试图解决的问题是如何在数字货币中防止双重支付。假设有一群人同意使用一种由计算机文件代表的数字货币。是什么阻止了某个参与方无限次复制文件，从而成为百万富翁？嗯，显然没有什么能阻止。有人可以轻易复制文件，花掉一笔货币，但同时仍然持有这笔货币。这就是所谓的双重支付问题。如果阿马拉给鲍勃一个代币，但她之后仍然可以使用这个代币（例如，因为她复制了文件）去购买其他商品或服务，那么阿马拉就是在双重支付。法定货币通过两种方式避免双重支付：

1.  实物交换媒介（纸币和硬币）无法复制，且当局故意使伪造变得困难。
2.  货币的数字化表示受到可信权威机构（即银行）的保护。

比特币通过以下方式解决了这个问题。一个账本记录了从第一组交易（称为创世块）到最后一组交易的所有交易。交易被组织成区块，每个区块包含发送方、接收方以及前一个区块的哈希值信息。当阿马拉向鲍勃发送一个比特币时，系统中的一组节点（称为矿工）会从创世块开始检查账本，以确保阿马拉确实拥有所需的货币数量。

然而，矿工们并非易事。为了检查账本，他们必须解决一个困难的`密码学谜题`。解开这个`密码学谜题`需要消耗大量电力，这带来了显著的经济成本。第一个找到解决方案的矿工将获得比特币奖励。一旦找到解决方案，它会被广播到网络中的其余部分，被其他节点采纳，然后整个周期重新开始。

我提到过一个区块包含一个哈希值。`密码学哈希函数`是一种将任意数字或字母映射到固定长度字符序列的函数。例如，如果你将数字 `0` 输入 `SHA-256`（比特币使用的哈希函数），结果将是：

```
07b01b0f4672f2bc58ef11132df4bc74a4e0dc9f2e07ee5d9a0428d3836bc6cb
```

在比特币中，每个区块不仅包含自上一个区块以来发生的所有交易信息，还包含前一个区块的哈希值。解决`密码学谜题`意味着你必须考虑前一个区块的哈希值，而该哈希值又依赖于更前一个区块，如此层层依赖，一直追溯到第一个交易区块。

这种对先前区块的依赖性意味着，如果有人想篡改系统，他们必须消耗巨量电力来改变过去。据报道，2018 年，全球比特币挖矿所消耗的电力超过了捷克共和国的总用电量。^(¹⁶⁴)攻击比特币在经济上并不合算；遵守系统规则显然更有意义。如果有人想在比特币区块链上进行双重支付，他们需要控制网络中至少 51%的计算能力。一笔交易发生的时间越久远，更改起来就越困难。因此，共识是通过激励机制来强制达成的。

刚才描述的协议被称为`工作量证明`。这个系统完美吗？嗯，并不。首先，加密货币曾遭受过 51%攻击。2018 年，针对较小型的加密货币的 51%攻击造成了约 2000 万美元的损失。^(¹⁶⁵)小型加密货币的节点网络规模较小，因此更容易面临这种危险。其次，`工作量证明`消耗的电力对环境造成了巨大影响。区块链达成协议的方式被称为`共识协议`。除了`工作量证明`之外，还有其他`共识协议`有望解决其面临的一些问题。例如，`权益证明`被推崇为一种更环保的替代方案，此外还有`消逝时间证明`和`委托权益证明`等其他协议。

是否存在不是区块链的`分布式账本`？是的，存在。一些例子包括 Corda、IOTA 和 HashGraph。非区块链的`分布式账本`不要求存储从过去到现在的所有交易记录。

此外，也存在非公开的区块链。虽然 2018 年公众对加密货币着迷，但作为企业解决方案被推广的私有区块链开始受到欢迎。超级账本 Fabric 就是这样一个区块链项目。这种私有（或称为许可型）区块链仅对预先批准的成员开放。企业可以利用这些区块链来获得区块链技术的好处，例如透明性和不可篡改性，而无需使用加密货币。
