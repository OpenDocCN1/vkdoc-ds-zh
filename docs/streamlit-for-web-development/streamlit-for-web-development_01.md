# 前言

那是一个寻常的夜晚，就在我即将入睡时，手机震动了一下。作为千禧一代，我忍不住拿起手机查看，结果发现又是一封烦人的邮件广告，推荐一个叫“Streamlit”的东西。通常我会直接忽略，但不知为何，Streamlit 那简洁的 Logo 吸引了我的目光。如今回想起来，我很庆幸点开了那则广告。自那以后，我的编程生涯便与一个我一直期盼有人能创造的框架紧密相连——那就是强大的 Streamlit。

在职业生涯早期，我注意到包括我在内的许多 Python 开发高手，虽然精于后端和服务器端编程，却在面对前端用户界面和客户端软件时感到力不从心。尽管 `Flask` 和 `Django` 努力试图解决这一问题，但它们都需要开发者具备大量的 `HTML`、`CSS` 和 `HTTP` 知识，使用起来门槛颇高。我常常转向 `Tkinter` 和 `PyQt` 来开发本地桌面应用，但却无法将任何应用部署到云端。我们真正需要的，是一个纯 Python 编写的 Web 框架，它拥有直观的 `API`，能够让我们轻松创建和部署 Web 应用，同时将主要精力集中在后端开发上。本质上，就像 `ReactJS` 那样，但专为 Python 设计。而当我点开那则广告时，我找到了我梦寐以求的东西。那真是一个“尤里卡”时刻！

这件事发生在 2020 年夏天，而 Streamlit 在 2019 年秋季才刚对外发布。在不到一年的时间里，开发团队就已经打造出了一个完全符合我需求的框架和 `API`。自那以后，Streamlit 越来越受欢迎，而对我来说，它的出现恰逢其时。我当时刚加入伊维尔德罗拉公司，负责开发一个基于 Python 的 Web 应用。在遇到 Streamlit 之前，我甚至会对将应用部署到 Web 上的想法犹豫不决，但现在，我却成了 Web 应用的倡导者，自豪地展示着 Streamlit 的强大功能。没过多久，我就成为了所在开发团队中的先行者。

和所有伟大的发现一样，我觉得独享其成是不对的。我决定向全世界分享 Streamlit 的潜力，而这本书就是这一决心的成果。它专为那些像我一样，在创建和部署 Web 应用时曾经挣扎过的开发者而写。这本书提供了 Streamlit 的全面指南，从简单的用例到构建复杂的、基于云的应用。

在读完本书后，读者不仅将理解如何使用 Streamlit，还将学会如何将他们的 Web 应用与强大的服务器端基础设施（如 `MongoDB`、`PostgreSQL`、Linux、Windows Server 以及 Streamlit 的部署平台）进行集成。本书的目标是赋能读者，让他们的想法能够落地于 Web 之上，甚至可能借此开启自己的事业。

— 穆罕默德·霍拉萨尼
