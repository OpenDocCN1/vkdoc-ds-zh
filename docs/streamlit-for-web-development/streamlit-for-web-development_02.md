# 缩略语

`aaS` — 即服务

`API` — 应用程序编程接口

`BLOB` — 二进制大对象

`CLI` — 命令行界面

`CPU` — 中央处理器

`CRUD` — 创建、读取、更新和删除

`CSP` — 云服务提供商

`CSRF` — 跨站请求伪造

`CSS` — 层叠样式表

`DI` — 依赖注入，一种编码模式

`DG` — 增量生成器，Streamlit 中的核心模块

`DOM` — 文档对象模型

`DTW` — 动态时间规整

`GPU` — 图形处理器

`HTML` — 超文本标记语言

`IDE` — 集成开发环境

`ISP` — 互联网服务提供商

`JSON` — JavaScript 对象表示法

`JWT` — JSON Web 令牌

`LLM` — 大型语言模型

`MLaaS` — 机器学习即服务

`MVC` — 模型-视图-控制器

`NAT` — 网络地址转换

`ORM` — 对象关系映射

`OS` — 操作系统

`PID` — 进程标识符

`PV` — 光伏

`RAG` — 检索增强生成

`RCE` — 远程代码执行

`RDP` — 远程桌面协议

`REST` — 表述性状态转移

`SaaS` — 软件即服务

`SCADA` — 监控与数据采集

`SQL` — 结构化查询语言

`SQLI` — SQL 注入

`SSH` — 安全外壳协议

`TPU` — 张量处理器

`UI` — 用户界面

`URI` — 统一资源标识符

`URL` — 统一资源定位符

`UX` — 用户体验

`VPN` — 虚拟专用网络

`WSL` — 适用于 Linux 的 Windows 子系统

`XSS` — 跨站脚本攻击
