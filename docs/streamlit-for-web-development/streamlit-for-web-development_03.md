# 目标读者

本书假定你至少对以下主题有基本了解：

- 面向对象编程
- 数据结构与算法
- `Python` 及其以下绑定库：
    - `Pandas`
    - `Numpy`
    - `Plotly`
- `SQL`（包括关系型与非关系型数据库）
- `Git` 版本控制框架
- 云计算

要充分吸收本书的内容，具备一定的编程经验至关重要。如果你对上述领域尚不熟悉，建议先选修入门课程再深入阅读。话虽如此，你并不需要成为专家才能从中获益。即便你已经能够使用更高级的框架构建应用，你仍可能会惊叹于 `Streamlit` 所能节省的巨量时间与精力。它让你在数小时内就能创建出一个强大的网页应用，而使用 `Flask` 或 `Django` 等框架则可能需要数周时间。

然而，如果你追求高度定制和精细的前端用户界面，那么现阶段 `Streamlit` 可能并非最佳选择。虽然它在不断改进，但目前 `Django` 等框架可能提供更大的灵活性。但如前所述，`Django` 需要更高级的编程技能才能开发网页应用。

通过阅读本书，你将能够构建并部署可扩展的云网页应用，并具备处理后端和前端需求的能力。你将能够将应用与 `PostgreSQL` 和 `MongoDB` 等数据库集成，并使用 `Microsoft Server`、`Linux` 容器以及 `Streamlit` 自有云平台等云服务进行部署。

虽然本书会详细阐述所需概念，但仍需你具备一定的自学和研究能力。教程中可能存在疏漏，或者你阅读时某些工具可能已经过时。你需要运用自己的直觉和判断力来填补这些空白。本书还将侧重于 `Streamlit` 及其他工具的实际应用，而非解释其源代码的内部工作原理。每个教程都会介绍一个具体的用例或应用，并附带相应的代码。本书提供的所有代码均为开源，遵循 `MIT 许可证` 发布。我们鼓励你根据自身技术需求，改编并应用这里分享的方法论。
