在商业智能工具库中，另外两个日益重要的工具是 `Power Query` 和 `Power Map`。你通常需要先对原始数据进行某种形式的转换，然后才能将其加载到数据模型中。你可能需要筛选、聚合或清理原始数据。我将向你展示 `Power Query` 如何让你在将数据纳入数据模型之前，轻松地转换和精炼数据。在分析数据时，你可能还需要将基于位置的可视化信息整合到地图中。`Power Map` 使用微软的必应地图引擎，轻松地将数据整合到交互式地图上。我将向你展示如何使用 `Power Map` 为你的数据创建有趣的可视化效果。
