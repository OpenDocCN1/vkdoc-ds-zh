**梅丽莎·德姆萨克**是一位数据专家，拥有丰富的企业数据职业生涯，曾领导数据团队并担任业务与技术组织之间的联络人。她具备跨多个垂直行业的经验，包括制药、房地产、金融、消费品、信贷/营销服务及保险机构。她的兴趣涵盖利用数据驱动业务目标、数据策略、领导数据分析团队、数据洞察及数据可视化。她理想的工作日包括分析原始数据，并与业务合作伙伴及 IT 专业人员协作提供能够影响业务价值的数据洞察。您可通过 LinkedIn (`https://www.linkedin.com/in/sqldiva`) 和 Twitter (`@SQLDiva`) 联系梅丽莎。

**珍·安德伍德**在数据仓库、商业智能及预测分析领域拥有近 20 年经验。她提供咨询、开发与审查技术方案，并进行行业分析。在创立 Impact Analytix 之前，她曾是微软全球商业智能技术产品经理，负责涵盖 Microsoft SQL Server、Excel 及 SharePoint 的产品线。她还曾担任企业数据平台专家、Tableau 技术布道师以及四大系统集成公司的商业智能顾问。在其职业生涯的大部分时间里，她一直在研究、设计和实现跨多种开源、专有及企业级供应商（包括 Microsoft、Oracle、IBM 和 SAP）的分析解决方案。

作为行业分析师、演讲者、作者、博主和培训师，珍在全球技术社区中非常活跃。近期，她获得了博尔德商业智能智库（BBBT）会员资格、2013 年 Tableau 大师奖、PASS 全球 Excel BI 分会领导职务以及邓白氏 MVP 荣誉。她为 *SQL Server Pro*、BeyeNETWORK 及其他行业媒体渠道撰写文章。

珍拥有威斯康星大学密尔沃基分校的工商管理学士学位，以及加州大学圣地亚哥分校的计算机科学（数据挖掘方向）研究生证书。
