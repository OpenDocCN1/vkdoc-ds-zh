# 引言

自助式商业智能（BI）正风靡一时。你听过相关宣传，看过销售演示，并且准备亲自尝试。然后呢？如果你和我一样，可能已经浏览过一些网站的例子，尝试了一下，并学到了一些东西。但你仍然想知道这些工具如何组合在一起，以及如何创建完整的解决方案，对吧？如果是这样，那么本书就是为你准备的。它将带你一步步地使用微软自助式 BI 解决方案核心的各种工具来执行数据分析流程。

微软自助式 BI 解决方案的核心是 Power Pivot。我将向你展示如何使用 Power Pivot 创建强大、可扩展的数据模型；这些模型将作为你数据分析的基础。由于 Power Pivot 是创建自助式 BI 解决方案的核心工具，本书将对其进行详尽介绍。接下来是 Power View。我将展示如何使用 Power View 轻松构建交互式可视化对象，让你能够探索数据以发现趋势并获得洞见。此外，我还会说明 Power Pivot 如何让你创建能充分利用 Power View 功能的数据模型。
