# 前言

本书的编写目标之一，是使其严格适用于本科生的单一数学课程，通常被称为“核心课程”。从这个意义上说，它适合纳入统计方法课程（通常在前面加上“基础”或“入门”修饰词）。此外，根据读者在最后几章中学习的深入程度，本书也适用于社会科学（例如心理学或社会学）的高年级本科课程。

然而，除了这些目标之外，本书旨在让学习者通过亲手使用`R`编程语言，切实体验统计思维。虽然不会忽视理论，但技术和理论将首先通过模型、可视化和直观的方法进行引导。真正的目标是分享一种语言，用以用易于理解的术语传达复杂的数字事实。这种实际应用——有时被称为经验和量化技能——旨在让学生能够批判性地思考并探索日益复杂的数据集，成功描述和总结大量信息，并准确分析、建模，将结果传达给技术受众和非专业受众。

为实现这一目标，本书包含两个不同的部分。第一部分旨在高效地引导读者逐步安装并理解`R`编程语言计算机环境的基本要素。我们将尽力避免“技术术语”，使用日常语言，尽可能快地帮助读者通过初始阶段，并尽可能明智地过渡到实际统计学习。第二部分是关于入门统计的方法论。总体、样本、描述性统计、概率、分布、相关、回归、置信区间、假设检验和方差分析（ANOVA）将逐一讨论。本书不回避技术性的数学理论，但所有统计思想都会先以概念方式进行介绍。从可视化到手把手的实践活动，旨在建立坚实的、现实世界中的、上下文的直觉，使理论更易于理解。作者的目标是帮助学习者“过上统计生活”——并完全避免写出一本用于通过一门课程然后很快被遗忘的书。

最后，虽然我们说本书适用于本科课程，但它无疑会提高学习者使用一种非常流行的编程语言的能力，并为使用`R`进行研究、数据科学、机器学习、动态报告和定制可视化奠定基础。因此，它也适合希望过渡到`R`的实践数据分析师，希望同时获得强大技能并重温统计知识的研究生，以及任何喜欢学习数据和统计知识的人。
