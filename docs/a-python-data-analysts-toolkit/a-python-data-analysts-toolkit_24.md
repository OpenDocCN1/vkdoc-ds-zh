### **问题 6**

1. **陈述假设：**

设该饮品的平均卡路里值为`μ`

原假设：`H[0]: μ=100`

备择假设：`H[1] : μ != 100`

这是一个双尾检验。

2. **选择合适的假设检验：**

我们根据以下特征选择单样本`t 检验`：

*   样本数量：一个样本
*   样本量：小（n=13）
*   检验内容：平均卡路里值
*   总体特征：总体服从正态分布，且总体标准差未知

3. **设定显著性水平：** `α=0.05`

4. **计算检验统计量和 p 值：**

代码：

```
import numpy as np
import scipy.stats as stats
values=np.array([78,110,105,72,88,107,85,92,82,92,91,82,103])
stats.ttest_1samp(values,100)
```

输出：

```
Ttest_1sampResult(statistic=-2.6371941582527527, pvalue=0.02168579243588164)
```

5. **比较：** 由于计算出的 p 值 < `α`，我们拒绝原假设。

6. **推断：** 可以得出结论，在 5%的水平上，样本的卡路里值与总体的卡路里值存在显著差异。

### **问题 7**

1. **陈述假设：**

设`μ[d]`为总体在减肥计划前后体重的平均差异

原假设：`H[0]:μ[d] < 3`

备择假设：`μ[d] ≥ 3`

由于备择假设中包含大于或等于号，因此是单尾检验。

2. **选择合适的假设检验：**

*   样本数量：两个样本（对相同受试者取两个不同的样本）
*   样本量：小（20）
*   检验内容：检验体重减轻的平均差异
*   总体特征：总体分布为正态，但总体方差未知。

基于上述特征，并且由于样本彼此相关（考虑到我们比较的是同一批客户的体重），我们进行配对双样本`t 检验`。

3. **设定显著性水平：** `α=0.05`

4. **计算 p 值：**

p 值可以使用`stats.ttest_rel`函数计算，如下列代码所示。

代码：

```
import scipy.stats as stats
before_weights=[56,95,78,67,59,81,60,56,70,78,84,71,90,101,54,60]
after_weights=[52,91,77,65,54,78,54,55,65,76,82,66,88,94,53,55]
stats.ttest_rel(before_weights,after_weights)
```

输出：

```
Ttest_relResult(statistic=7.120275558034701, pvalue=3.504936069662947e-06)
```

5. **结论/解释**

由于计算出的 p 值 < `α` (0.05)，我们拒绝原假设。
可以得出结论，减肥计划前后的两组数据之间存在显著差异。
