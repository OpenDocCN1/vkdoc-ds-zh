# 2. 入门

`SAS Studio` 使您能够导入和导出原始数据文件、操作和转换数据、组合 SAS 数据集、使用 SAS 过程生成摘要报告、识别和纠正数据，以及调试语法和编程逻辑错误。此外，它还让您能够更轻松地完成可视化（包括地图），步骤比 `R` 或 `Python` 等其他编程语言更简单。不过，它也有一个编程编辑器，以便在需要时自定义和编写您自己的代码。

## 如何安装 SAS Studio？

安装包括四个步骤。您可以通过以下网址逐步操作：[`www.sas.com/en_us/software/university-edition/download-software.html`](https://www.sas.com/en_us/software/university-edition/download-software.html)。

由于安装步骤可能会发生变化，最好查阅此网址以获得最新的在线指南。

## 什么是 SAS 和 SAS Studio？

`SAS` 代表统计分析系统（Statistical Analysis System），`SAS Studio` 是其界面。`SAS Studio` 拥有一个强大的集成开发环境（IDE），其中既包含任务的图形用户界面（GUI），也包含代码编辑器。如果您使用采用“点击”方式的 GUI，`SAS Studio` 会自动为您生成相应的代码。或者，您也可以使用代码编辑器编写自己的代码。

在本书中，我们将介绍两种方法：使用 GUI 和编写代码。对于使用 GUI 的示例，我们将解释生成的代码。对于某些高级示例或仅能通过代码完成的用户自定义示例，我将逐行解释所需的代码，以及相关的过程和选项。

值得一提的是，`SAS Studio` 还有两种模式：`SAS Programmer`（SAS 程序员）和 `Visual Programmer`（可视化程序员）。`Visual Programmer` 模式使用拖放方法。您可以从右上角顶栏的下拉菜单中更改模式。然而，本书重点介绍的是 `SAS Programmer` 模式。
