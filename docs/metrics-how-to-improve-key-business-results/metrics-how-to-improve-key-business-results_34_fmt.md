# 调查工具

以下三款调查工具各有优点。依次来说，第一款能提供一些有用的分析，关于什么对客户重要以及你提供这些服务的表现如何。第二款是第三方服务（并非真正意义上的工具），让调查工作变得简单。最后一款是我的最爱，因为它允许你创建所需的内容，自定义调查以满足你的要求（而且成本很有吸引力）。

## TechQual+

`TechQual+`（`www.techqual.org`）是调查工具的一个好例子；它是由我的朋友、佐治亚大学首席信息官蒂莫西·切斯特创建的。`TechQual+` 中大部分问题都是预设的，这造成了一些限制；但这也是它的优势所在。由于问题是标准化的，你可以将自己的结果与选择使用该工具的其他人进行比较。还有其他第三方调查机构（例如 HDI），但 `TechQual+` 的一大优势是它是免费的。

## HDI

`HDI` 客户满意度指数是一项调查服务。`HDI` 为你做所有事情：他们调查你的客户，汇总你的结果，并以多种格式向你提供报告。他们还提供与其他人的比较（例如，按行业或所有其他客户）。`HDI` 只是一个例子；还有其他第三方调查服务提供这种服务。我建议你货比三家*并*寻找那些已经在*你的*行业拥有大量客户基础的服务。客户满意度调查是一个有趣的利基市场。

## SurveyMonkey

我承认——我喜欢 `SurveyMonkey`；部分原因是它是免费的（如果你用得不多；不过，如果你想更大规模地使用，其费用也非常合理），但主要是因为它的简单性。使用 `SurveyMonkey`，你创建调查问卷；然后向你的客户提供一个指向该调查的链接。`SurveyMonkey` 还提供简单的分析工具，但我通常将结果下载到 `Excel` 中并自行分析。
