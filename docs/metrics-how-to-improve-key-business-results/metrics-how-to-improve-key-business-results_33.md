# 可视化工具

可视化工具主要（即便不是唯一）旨在以仪表盘、计分卡或其他可视化的形式，让你能够访问数据。根据我的定义，这些工具可以用于展示指标。

## Theoris Vision Software 软件

`Theoris Vision Software` 提供了一款仪表盘和报告解决方案，包含图表、图形、计分卡、地图和即席报告。所有功能都从仪表盘驱动。我喜欢它的一点是，我可以相当轻松地创建自己的视觉内容和报告内容。据我所见，这款应用真正的强大之处在于它能够映射到各种数据源和文件，而不是像传统方法那样将所有数据汇总到电子表格或数据库中。

`Vision` 本身并非指标设计工具，但它是一个用于将你的度量进行可视化的强大工具。它还允许其他人（利益相关者）自行访问你的指标。我尤其喜欢在数据中设置层级结构的功能，这反过来让查看者能够进一步深入挖掘数据。这一功能得到了进一步扩展，允许在不同信息层级创建即席报告。这可能是一件坏事——取决于你受众的成熟度——但大多数情况下，这相当出色。总的来说，这确实是一款展示指标并开启关键对话的令人印象深刻的工具。目前，`Vision` 主要专注于健康行业，但随着 `Vision` 扩展到其他行业，竞争对手最好当心了。这是一款非常好的工具，我已将其列入我的愿望清单。

## iDashboards

`iDashboards` 正如其名所料：一款用于创建和展示仪表盘——或关键流程指标（我称之为度量）汇编——的出色工具。使用 `iDashboards`，你可以利用你的度量，为特定问题创建指标视图。

就这个目的而言，我喜欢 `Vision` 和 `iDashboards` 这两款工具。对我来说，问题就变成了成本和易用性。如果你正考虑获取一款以这种方式展示数据的工具，我建议你花时间试用一下这两款产品。这款工具也在我的愿望清单上——无论收到哪一款作为圣诞惊喜，我都会很开心。

## Tableau

`Tableau` 并非插件，但它能与 `Excel` 良好配合。你可以轻松地从 `Excel` 或其他常用工具将数据导入 `Tableau`。`Tableau` 的强大之处在于能够快速、轻松地尝试数据的不同图形表示（可视化）。我认识一些喜欢它并在进行任何彻底分析之前就使用它的人。我还没发现它适合我，但我确实看到了它的潜在价值（我有一份副本，但还没能充分利用起来）。
