# IT 解决方案/商业智能工具

许多“IT 解决方案”公司现在在其服务包中包含了仪表盘和计分卡。这清楚地表明了指标的需求以及软件在帮助交付指标方面的力量。IT 解决方案包可能将指标工具作为服务套件的附加组件——从关键产品（流程控制、管理、架构设计等）中提取数据副产品。

我发现这些工具与独立工具之间的主要区别在于范围。如果你不需要（或负担不起）大规模解决方案集，你可以从专门为指标设计的工具中获得很多价值。如果你正考虑购买（或已经拥有）大规模 IT 解决方案，你可能想研究其提供指标辅助的能力。

## ASE 10

一个以数据为中心、使用计分卡、仪表盘和度量来改进组织的工具集例子是来自`ActiveStrategy`(`activestrategy.com`)的`ASE 10`。它有点复杂，但提供基于公司规模定价。`ASE 10`很大程度上依赖于预定义的方法论，但似乎有足够的灵活性来处理你设计的指标。我没有使用过这个工具，但它是由一位我信任其判断的同事推荐的。

对于大多数较大规模的工具来说，问题在于它们可能功能过多。忽略成本不谈，这些工具提供的功能超过了大多数人的需求——尤其是如果你刚刚开始你的指标之旅。
