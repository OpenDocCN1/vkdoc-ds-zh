# 12. 流程控制

流程控制语句用于重复执行一系列任务若干次，或根据逻辑对象来引导执行流程。对于那些在 FORTRAN 和 BASIC 时代开始编程的人来说，使用循环非常得心应手。在 R 中，如果可能，更好的选择是使用数组和索引选择，而不是循环。使用索引比循环快得多。

话虽如此，控制语句包括 `if`、`if/else`、`while`、`for` 和 `repeat`。它们有时是必需的，并且通常很有用。在本章中，我们给出了流程控制语句的语法。我们在第 13 章中给出了流程控制使用的示例。

## 花括号“{}”和分号“;”

花括号用于括起代码段。花括号可以与 `if`、`else`、`while`、`for` 和 `repeat` 流程控制语句一起使用，以界定控制语句要操作的代码段，无论是在函数内部还是在 R 控制台中。

花括号也可以在没有伴随流程控制语句的情况下直接用于 R 控制台。从左花括号开始，可以逐行输入代码语句。这些语句在输入右花括号之前不会执行。

分号用于在一行中包含多个语句。一个语句要等到它前面的语句执行完毕后才会被求值。如果第一个语句是一个流程控制语句，后面跟着一个单一的代码语句，那么控制流程必须完成，第二个语句才会执行。然而，如果两个（或多个）语句被包含在流程控制语句后面的一对左、右花括号内，那么花括号内的所有语句将根据该流程控制语句一起执行。

## `if` 和 `if/else` 控制语句

`if` 控制语句接受一个逻辑对象，如果该对象为真，则执行相应的代码。如果该对象不为真，则可以选择性地执行由 `else` 语句提供的另一段代码。

该逻辑对象必须是可以强制转换为逻辑类型的对象。如果逻辑对象的长度大于 1，则仅使用该对象的第一个元素。

`if` 语句可以采用以下形式：

```
if ('逻辑对象') '单一代码语句'
if ('逻辑对象') '单一代码语句';'单一代码语句'
if ('逻辑对象') {'多个用分号分隔的代码语句'}
if ('逻辑对象') {
'多行代码语句'
}
```

这四种形式并未穷举所有可能的形式。在第二种形式中，即使逻辑对象为假，第二个语句也会执行，因为这两个语句没有被括在花括号中。

如果逻辑对象为假，则可以选择使用 `else` 语句让 R 执行不同的代码。对于 `if` 和 `else` 这两个控制语句，下面给出了两种形式的示例：

```
if ('逻辑对象') '单一代码语句' else '单一代码语句'
if ('逻辑对象') {
'多行代码语句'
}
else {
'多行代码语句'
}
```

同样，这两种形式并未穷举所有可能。如果没有 `else` 控制语句且逻辑对象为假，则与 `if` 语句关联的代码语句将被跳过。

## `while` 控制语句

`while` 控制语句在一个逻辑条件为真时执行一个代码块。同样，该逻辑对象必须是可以强制转换为逻辑类型的对象。如果逻辑对象的长度大于 1，则仅使用该对象的第一个元素。

该控制语句可以采用以下形式：

```
while ('逻辑对象') '单一代码语句'
while ('逻辑对象') '单一代码语句'; '单一代码语句'
while ('逻辑对象') {'多个用分号分隔的代码语句'}
while ('逻辑对象') {
'多行代码语句'
}
```

同样，所示形式并未穷举所有可能的形式。请注意，对于第二种形式，第二个语句要等到 `while` 循环结束后才会执行，因为这两个语句没有被括在花括号中。

# `for` 控制语句

`for` 控制语句指示 R 按设定次数循环执行一段代码。根据循环条件，有多种方式可以实现循环。

循环条件可以非常灵活。最简单的形式是：

```
for (i in 1:n)
```

其中，`i` 是一个从 `1` 索引到 `n` 的对象，`n` 是一个整数。

通常，`for` 循环的流程控制语句语法如下：

```
for ('索引变量' in '向量对象')
```

其中，`索引变量` 是一个在每次循环迭代中其值都会改变的变量，而`向量对象`包含了该`索引变量`所取的值。向量对象可以是任何能强制转换为向量的对象，包括 `list` 和 `expression` 模式的对象。

对象`索引变量`将依次取`向量对象`中的值。通常，索引变量会在 `for` 循环执行的代码语句中使用。

注意，如果向量对象是在 `for` 语句内部使用函数 `seq()` 创建的，并且使用了 `seq()` 的参数 `along.with`（可以缩写为 `along`），那么 `seq()` 给出的是 `along.with` 中元素的索引，而不是对象本身的值。

`for` 循环的几种形式如下：

```
for ('循环条件') '单条代码语句'
for ('循环条件') '单条代码语句'; '单条代码语句'
for ('循环条件') {'用分号分隔的多条代码语句'}
for ('循环条件') {
'多行代码语句'
}
```

再次强调，这四种形式并未穷尽所有可能的形式。在第二种形式中，分号后的代码要等到 `for` 循环结束后才会执行，因为这两条语句没有放在花括号内。

根据 CRAN 关于流程控制的帮助页面，索引变量的值可以在 `for` 引用的代码语句中被改变，但在下一次循环开始时，它会恢复为变量的下一个索引值。循环结束时，`索引变量`的值是循环中该索引变量的最终值。

## `repeat` 控制语句

`repeat` 流程控制语句会重复执行一段代码，直到达到一个停止点。这个停止点必须编程写入该段代码中。与 `while` 不同，`repeat` 的控制语句中不包含逻辑对象；与 `for` 不同，其控制语句中也不包含循环索引。以下是 `repeat` 的两种形式：

```
repeat {'一些用分号分隔的代码语句'}

repeat {
'多行代码语句'
}
```

同样，这两种形式并未穷尽所有可能。使用 `repeat` 时可能产生无限循环，因此请谨慎使用。

## 语句 `break` 和 `next`

语句 `break` 和 `next` 用于由某个流程控制器控制的代码段内的流程控制。

`break` 语句告诉 R 离开 `for`、`while` 或 `repeat` 循环，或者离开 `if` 区块，然后跳转到该循环或区块之后的第一条语句。

`next` 语句告诉 R 停止执行 `for`、`while` 或 `repeat` 循环中的代码语句，并从循环的开头重新开始——如果存在索引变量，则使用该变量的下一个值。

## 嵌套

任何流程控制语句都可以嵌套在其他流程控制代码段中。为了清晰以及防止微妙的错误，在将一个流程控制段嵌套到另一个流程控制段时，应在所有层级使用花括号。

此处介绍的关于流程控制的大部分信息都来自 CRAN 上关于流程控制的帮助页面，可以通过在 R 提示符下输入 `?"if"` 或使用 R Studio 中的“帮助”选项卡找到该页面。
