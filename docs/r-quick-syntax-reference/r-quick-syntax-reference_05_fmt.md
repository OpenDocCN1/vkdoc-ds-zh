# R 语言的三大组成部分：对象、运算符和赋值

R 语言主要由三部分组成：对象、运算符和赋值。

- **对象**包含信息，可以是数据、函数或函数结果等。对象总是有名称的。用户创建一些对象，这些对象在创建时会自动保存。其他对象是常量、函数以及 R 语言包中包含的数据集。
- **运算符**用于操作对象、数字、字符串和/或逻辑变量。例如，在 R 提示符下输入 `a = 2*b` 会将 `b` 乘以 2，并将结果赋值给 `a`。对象 `a` 和 `b` 是数值对象，`*` 是乘法运算符。等号将 `2*b` 这个值赋值给 `a`。运算符是一种函数。
- **赋值**是将一个表达式赋给一个对象。**表达式**可以由对象、数字、逻辑变量、字符串、列表、其他表达式和/或函数组成，并通过运算符进行操作。

表达式可以在 R 提示符下直接求值，而不是求值后赋值给对象。（赋值和运算发生的其他位置是在函数内部和流程控制内部。）

## R 提示符

R 的所有功能都源于 R 提示符。R 本质上就是运行函数和执行计算。函数和计算可以在 R 提示符下运行，可以赋值给对象，也可以不赋值。函数和计算也可以作为其他函数的一部分运行，但一切始于 R 提示符。

一开始使用 R 提示符可能令人望而生畏。R 启动时会显示一些文字，然后是一个孤零零的大于号（`>`），这就是 R 提示符。启动时显示的文字给出了 R 的版本号以及其他一些关于程序的信息，包括该程序不提供任何担保。

R 会记住输入到程序中的每一行内容，直到达到设定的行数。R 的一个非常方便的功能是，可以使用键盘上的向上和向下箭头浏览这些行。你只需输入一次表达式。修改表达式也很容易，无需重新输入整个表达式。

要关闭 R，请在 R 提示符下输入 `q()`，或者对于 Windows 和 macOS 系统，直接关闭窗口。关闭 R 时，会提供保存工作空间的选项。在 Linux 中，如果未使用 `q()` 就关闭了终端窗口，当前工作空间将会丢失。

工作空间包含程序关闭时 R 中存在的任何对象以及当前历史记录。如果未保存工作空间就关闭 R，则将恢复到该 R 会话开始时的工作空间。

## 计算示例

R 最简单的用法就是当作计算器。下面的计算是在 R 提示符下完成的。该计算没有赋值，因此结果会显示在屏幕上。

```
> (1 + 3 + 7)/5
[1] 2.2
>
```

第一行给出了要计算的表达式，第二行给出了结果。第二行中的 `[1]` 是一个标签，告诉用户该结果是表达式返回的第一个值。许多表达式会返回多个值。在第三行，R 提示符再次出现，R 已准备好执行下一个任务。

## RStudio 的四个窗口

首次打开程序时，RStudio 会显示三个子窗口。主 RStudio 窗口的左侧是一个较小的单窗口。右侧是两个垂直对齐的较小窗口。在顶部，三个窗口的上方，有两个菜单提供了使用 RStudio 的多种选项。这两个菜单都延伸至主窗口的整个宽度。

在 Windows 和 Linux 中，上方菜单是 RStudio 主窗口的菜单，而在 macOS 中，顶部菜单位于 macOS 主菜单栏中。在 macOS 中，如果 RStudio 全屏显示，您需要将鼠标悬停到页面顶部才能看到上方菜单。RStudio 的一个优点是，当您输入时，它会提供对象名称的自动补全功能。但是，RStudio 的加载速度可能较慢。

上方菜单包含 `File`、`Edit`、`Code`、`View`、`Plots`、`Session`、`Build`、`Debug`、`Profile`、`Tools` 和 `Help` 按钮。每个按钮都会打开一个下拉菜单。这些下拉菜单不言自明。

下方菜单包含以下图标（从左到右）：新建项目（R 脚本、R Notebook、R Markdown 文档、Shiny Web App、文本文件、C++文件、R Sweave 文档、R HTML 文档、R 演示文稿或 R 文档文件）、新建项目、打开计算机上的文件、保存“源代码”窗口的内容（参见关于第四个窗口的章节）、保存所有“源代码”窗口选项卡下的内容、打印活动子窗口的内容、在工作目录中搜索并打开文件（它会从左到右搜索字母，在 macOS 上似乎不起作用）、调整子窗口的外观和位置，以及添加插件。

### 第一个子窗口

左侧的子窗口打开后显示标准的 R 控制台，位于一个标记为 `console` 的选项卡下。命令以与在 R 中相同的方式在 R 提示符下输入。在控制台选项卡的右侧是一个标记为 `terminal` 的选项卡，它提供了访问计算机终端的途径。

### 第二个子窗口

右侧上方的窗口包含 `Environment`、`History` 和 `Connections` 选项卡。在 `Environment` 选项卡下，RStudio 列出了工作空间中的对象，分为 `Data`、`Values` 和 `Functions`。`Data` 包含数据框和矩阵对象（将在后面定义）。`Values` 包含不是数据框、矩阵或用户自定义函数的对象。`Functions` 包含用户自定义函数。窗口中会给出对象的各种属性，例如对象的类型和对象的维数。

在 `History` 选项卡下，显示的是已在控制台输入的代码行。只保留设定的行数。代码可以被高亮显示并移至控制台。还提供了一个搜索功能来搜索历史记录。

在 `Connections` 选项卡下是一个连接列表。最初，列表为空。连接是指向文件、URL、管道、套接字或其他 R 外部数据类型的链接。连接用于交互式地读取外部数据，并用于数据挖掘。点击 `Connections` 选项卡下的 `new connections` 按钮，会列出 RStudio 认为可用的所有可能的连接。（也可以从 R 提示符打开连接。）

### 第三子窗口

右下窗口包含 `文件`、`图形`、`包`、`帮助` 和 `查看器` 选项卡。在 `文件` 选项卡下，会列出计算机工作目录中的文件和文件夹。此处提供添加文件夹、删除文件、重命名文件、复制或移动文件，以及前往或设置工作目录等选项。

在 `图形` 选项卡下，会显示所有已创建的图形。您可以使用左右箭头图标在图形间切换。图形可以导出为图像或 PDF 文件。

`包` 选项卡会列出已安装的包。点击 `安装` 链接会打开一个搜索框，用于查找要安装的包。在搜索框中输入字符，会列出所有以这些字符开头的包，方便您找到要安装的包。点击 `更新` 链接会列出所有可更新的已安装包，并提供更新选项。在包列表中勾选某个包左侧的复选框，会在控制台窗口中加载该库，取消勾选则会分离该库。

`帮助` 选项卡提供了一个指向帮助页面的链接。在窗口菜单栏右侧的搜索框中输入字符，会列出所有以这些字符开头的可用函数。搜索区分大小写。只有那些已加载其库的函数才可用。在帮助页面下方有一行用于在页面内搜索的搜索框。

`查看器` 选项卡用于查看本地 Web 上的内容。R Studio 网站上提供了关于使用查看器的有用信息。

### 第四子窗口

第四个窗口是“源代码”窗口。源代码窗口包含源代码或数据集，打开时位于主窗口的左上侧。当在环境窗口中点击某个数据对象或函数时，源代码窗口会打开。该数据对象或函数会显示在源代码窗口中供检查，但不可编辑。如果您打开一个外部文件进行编辑和/或运行，或者打开一个用于编写新代码的空白页，源代码窗口也会打开。

如果工作目录中存在源文件（通常带有 R 扩展名），则该文件可以加载到源代码窗口中。带有 R 扩展名的文件称为脚本，加载后可编辑和运行。没有 R 扩展名的文本文件不可运行，但可以编辑和保存。此外，新代码可以输入到从下方主菜单打开的空白窗口中。

源代码窗口中可以打开多个页面，但一次只能显示一个。窗口中每个打开的页面上方都有一个选项卡，其中包含源文件的名称或标签 `未命名*n*`，其中 `*n*` 是一个数字，表示该选项卡下第几个未命名的对象。点击选项卡可显示相应的源文件，点击选项卡右侧的小 `x` 可将其关闭。

子窗口上方的菜单是窗口中对象选项卡的一部分。如果该对象是一个脚本，则菜单提供以下选项（从左到右）：用于返回上一个选项卡或前进到下一个选项卡的箭头、一个用于在独立窗口中打开窗口的图标、一个用于将当前对象另存为 R 脚本的图标、一个用于在保存时运行脚本的复选框、一个用于使用专用编辑工具的图标、一个用于运行高亮文本的图标、一个用于重新运行文本的图标，以及一个用于运行窗口中全部内容的图标。

如果该对象是一个文本文件，则选项卡菜单包含（从左到右）以下内容：用于在选项卡间移动的箭头、一个用于在新窗口中打开文本的图标、一个用于将文档保存到工作目录的图标、一个拼写检查器图标，以及一个查找和替换图标。

如果该对象是一个数据集，则菜单包含（从左到右）：用于在选项卡间移动的箭头、一个用于在新独立窗口中打开窗口的图标、一个用于按值范围筛选列的筛选选项，以及最右侧的一个用于搜索数据的搜索框。

如果该对象是一个函数，则菜单包含（从左到右）以下内容：用于在选项卡间移动的箭头、一个用于在独立窗口中打开窗口的图标、一个用于打印函数的图标、一个搜索功能、一个用于代码工具的图标或一个用于打开高亮文本的帮助函数的图标，以及菜单右侧的用于运行全部或部分选中函数的运行和重新运行图标。
