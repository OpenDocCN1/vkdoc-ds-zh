# 在 R 和 R Studio 中列出与移除对象

要查看工作空间中存在的对象，使用 R Studio 比使用 R 更简便——请查看右上角窗口中的“环境”(Environment)选项卡。R 提供了`ls()`函数来列出工作空间中的对象。

在前面示例的 R 提示符下输入`ls()`会得到

```
> ls()
[1] "abc" "bcd" "cde"
>
```

即之前创建的三个对象。

尽管函数将在第三部分详细讨论，但这里值得注意函数的一个有趣特性：它们可以包含用户输入的参数。`ls()`的两个可选参数是`pattern`和`all.names`。

第一个参数输入格式为`pattern = "a string"`，其中`"a string"`是对象名称的任意部分。例如，在前面的工作空间中，搜索名称中包含`bc`的对象会得到`abc`和`bcd`，即

```
> ls( pattern="bc" )
[1] "abc" "bcd"
```

参数`pattern`可以简写为`pat`，例如`ls(pat="bc")`。函数参数可简写是 R 的一个特性。R 中的所有参数都可以缩减到最短的唯一形式，但在手册中通常会给出完整形式。

第二个参数是`all.names`，它可以等于`TRUE`或`FALSE`。如果设置为`TRUE`，`all.names`参数会指示 R 列出工作空间中的所有文件，包括那些以句点开头的文件。`FALSE`是默认值，无需输入。对于前面的示例工作空间，将`all.names`设为`TRUE`会得到

```
> ls( all.n=T )
[1] ".commander.done" ".First"   ".Random.seed"   ".Traceback"
[5] "abc"             "bcd"      "cde"
.
```

`[1]`指向`.commander.done`，因为`.commander.done`是向量的第一个元素；`[5]`指向`abc`，因为`abc`是向量的第五个元素。（在 R 中，如果向量的元素没有命名，列出元素时的惯例是在每一行显示该行第一个元素的索引。）

函数`rm()`可用于从工作空间中移除对象。对于`rm()`，要删除的对象名之间用逗号分隔。例如

```
rm( a, b, c )
```

将移除对象`a`、`b`和`c`。要移除所有对象，可用

```
rm( list=ls() )
```

若要移除 S4 类，可使用`removeClass()`。

在 R Studio 中，可以在列出环境对象的网格选项下移除对象。在“环境”选项卡下菜单的右侧有一个写着“列表”(List)的图标。点击该图标，选择“网格”(Grid)而非“列表”。在出现的网格中，勾选要移除的对象左侧的复选框。然后，点击菜单中间的扫帚图标。系统会询问你是否真的想要删除选中的对象。

有关`ls()`或`rm()`的更多信息，在 R 提示符下输入`?ls`或`?rm`，或者在 R Studio 中使用右下角窗口的“帮助”(Help)选项卡。

## 运算符

运算符对对象进行操作。运算符可以是逻辑运算符、算术运算符、矩阵运算符、关系运算符、下标运算符，或者具有特殊含义。以下描述各类运算符。

对于运算符，`逐元素`是指对对象的每个元素（或两个对象的配对元素）分别执行操作。如果两个对象维度不同，运算符通常会针对较大对象循环使用较小对象。循环会遍历每个维度。例如，对于矩阵，第一维度是行，第二维度是列，因此循环是从第一列开始逐行向下进行。

字母`NA`用于表示某个元素数据缺失。大多数运算符都有处理缺失数据的规则，如果数据缺失，可能会返回`NA`。

CRAN 提供了一个关于运算优先级的帮助页面。在 R 提示符下输入`??"Operator Syntax and Precedence"`查看该页面，或使用 R Studio 中的“帮助”选项卡。

## 逻辑运算符和函数

逻辑运算符和函数返回值`TRUE`、`FALSE`或`NA`，其中`NA`表示缺失值。逻辑运算符包括`非`运算符、两个`或`运算符和两个`与`运算符。函数`xor()`、`isTRUE()`、`isFALSE()`、`any()`和`all()`（这些是作用于逻辑对象的函数）也返回逻辑值。对于逻辑运算符，如果两个对象维度不同，较大对象的元素个数必须是较小对象元素个数的整数倍，才能进行循环。逻辑运算符和五个逻辑函数列于表 3-1 中。

表 3-1

逻辑运算符和函数

| 运算符 | 操作 | 描述 |

| --- | --- | --- |

| `!` | 非 | 取反运算符——例如，`!a` |

| `|` | 或 | 逐元素`或`运算符——例如，`a|b` |

| `||` | 或（首元素） | `或`运算符，仅评估对象中的第一个元素——例如，`a||b` |

| `&` | 与 | 逐元素`与`运算符——例如，`a&b` |

| `&&` | 与（首元素） | `与`运算符，仅评估对象中的第一个元素——例如，`a&&b` |

| `xor()` | 异或 | `异或`函数——例如，`xor(a,b)` |

| `isTRUE()` | 逻辑测试 | 如果参数只包含一个值且该值为真，则返回`TRUE`，否则返回`FALSE`——例如，`isTRUE(a)` |

| `isFALSE()` | 逻辑测试 | 如果参数只包含一个值且该值为假，则返回`TRUE`，否则返回`FALSE`——例如，`isFALSE(a)` |

| `any()` | 逻辑测试 | 如果逻辑对象中存在`TRUE`，则返回`TRUE`——例如，`any(a)` |

| `all()` | 逻辑测试 | 如果逻辑对象中只包含`TRUE`，则返回`TRUE`——例如，`all(a)` |

逻辑运算符作用于逻辑型、数值型或原始型对象。当数值型对象被强制转换为逻辑型时，所有非零值被设置为`TRUE`，零值被设置为`FALSE`。对于原始向量，运算符按位应用。

取反运算符将逻辑对象中的`TRUE`变为`FALSE`，`FALSE`变为`TRUE`。`NA`保持不变。

运算符`|`逐元素比较两个对象，对于每一对元素，如果存在`TRUE`则返回`TRUE`，如果不存在`TRUE`或`NA`则返回`FALSE`，如果存在任何`NA`则返回`NA`。运算符`||`比较第一个对象的第一个元素和第二个对象的第一个元素，如果两个元素都是`TRUE`则返回`TRUE`，如果两个都是`FALSE`则返回`FALSE`，如果任一元素是`NA`则返回`NA`。

运算符`&`逐元素比较两个对象，对于每一对元素，如果两个元素都是`TRUE`则返回`TRUE`，如果存在`FALSE`则返回`FALSE`，如果两个元素都是`NA`则返回`NA`。运算符`&&`比较第一个对象的第一个元素和第二个对象的第一个元素，如果第一个元素都是`TRUE`则返回`TRUE`，如果存在`FALSE`则返回`FALSE`，如果两个元素都是`NA`则返回`NA`。

`xor()`函数逐元素比较对象，如果配对元素不同则返回`TRUE`，如果配对元素相同则返回`FALSE`，除非存在`NA`。如果存在`NA`，则测试返回`NA`。

对于一个逻辑向量或可强制转换为逻辑型的向量，函数`any()`会在存在任何`TRUE`时返回`TRUE`，如果不存在`TRUE`或`NA`则返回`FALSE`，如果不存在`TRUE`但存在`NA`则返回`NA`。

对于一个逻辑向量或可强制转换为逻辑型的向量，函数`all()`会在所有元素都是`TRUE`时返回`TRUE`，否则在存在`FALSE`时返回`FALSE`，在不存在`FALSE`但存在`NA`时返回`NA`。

函数`isTRUE()`和`isFALSE()`仅对单元素对象或表达式求值。如果存在多个元素，函数将报错。函数`isTRUE()`在值为`TRUE`时返回`TRUE`，否则返回`FALSE`。函数`isFALSE()`在值为`FALSE`时返回`TRUE`，否则返回`FALSE`。

有关逻辑运算符以及函数`isTRUE()`和`isFALSE()`的更多信息，可以在 R 提示符下输入`??"logical operators"`或使用 R Studio 的“帮助”选项卡来访问 CRAN 关于逻辑运算符的帮助页面。函数`any()`和`all()`的帮助页面可以在 R 提示符下输入`?any`或`?all`，或使用 R Studio 的“帮助”选项卡来访问。

### 算术运算符

算术运算符可以操作数值型操作数，或可强制转换为数值型的操作数。例如，对于逻辑对象，`TRUE`会被强制转换为`1`，`FALSE`会被强制转换为`0`。对于某些类型的对象，特定运算符具有不同的含义，但本章不涉及这些类型的对象。

算术表达式按元素逐一求值。如果表达式中各对象的元素数量不一致，则元素较少的对象会循环使用其元素，直至与元素较多的对象匹配。元素较多的对象其元素数量不必是元素较少对象元素数量的整数倍。表达式按照优先级规则从左到右求值。

算术运算符包括：标准乘号 `*` 表示乘法，`/` 表示除法，`+` 表示加法，`-` 表示减法。乘方符号是 `^`。运算符 `%%` 表示第一个参数对第二个参数取模。运算符 `%/%` 执行整数除法。表达式可以使用括号进行分组，例如 `(a+b)/c`。表 3-2 列出了算术运算符。

**表 3-2：算术运算符**

| 运算符 | 运算     | 示例   |
| :----- | :------- | :----- |
| `*`    | 乘法     | `a*b`  |
| `/`    | 除法     | `a/b`  |
| `+`    | 加法     | `a+b`  |
| `-`    | 减法     | `a-b`  |
| `^`    | 乘方     | `a^b`  |
| `%%`   | 取模     | `a%%b` |
| `%/%`  | 整数除法 | `a%/%b`|

更多信息，可以在 R 提示符下输入 `??"arithmetic operators"` 或使用 R Studio 的“帮助”选项卡来访问 CRAN 关于算术运算符的帮助页面。（在撰写本文时，上述方法可能无法访问此帮助页面，但可以在 R 提示符下输入 `?"+"` 或在 R Studio 的“帮助”选项卡搜索框中输入 `+` 来调出该页面。）

### 矩阵运算符和函数

R 提供了用于操作矩阵的运算符和函数。一些矩阵运算符和函数见表 3-3。

**表 3-3：矩阵运算符和函数**

| 运算符 / 函数                  | 运算                           | 示例                                                         |
| :----------------------------- | :----------------------------- | :----------------------------------------------------------- |
| `%*%`                          | 矩阵乘法                       | `a%*%b`                                                      |
| `%o%` 或 `outer()`             | 两个向量、矩阵或数组的外积     | `a%*%b`，`outer(a,b)`                                        |
| `%x%` 或 `kronecker()`         | 矩阵（或数组）的克罗内克积     | `a%x%b`，`kronecker(a,b)`                                    |
| `t()`                          | 矩阵的转置                     | `t(a)`                                                       |
| `crossprod()` 或 `tcrossprod()`| 一个矩阵或两个矩阵的叉积       | `crossprod(a)` 或 `crossprod(a,b)` 或 `tcrossprod(a)` 或 `tcrossprod(a,b)` |
| `diag()`                       | 矩阵的对角线或生成对角矩阵     | `diag(a)`（`a` 是矩阵）或 `diag(a)`（`a` 是向量）             |
| `solve()`                      | 矩阵的逆或求解方程 `Xa=b`       | `solve(a)`，`solve(X,b)`                                     |
| `det()`                        | 方阵的行列式                   | `det(a)`                                                     |

矩阵乘法运算符是 `%*%`。如果两个矩阵不可乘，R 将返回错误。

对于两个数组（数组包括向量和矩阵），`%o%` 或 `outer()` 给出数组的外积。

对于两个数组，`%x%` 或 `kronecker()` 给出数组的克罗内克积。

使用函数 `t()` 来转置矩阵，例如 `t(a)`。

要计算一个矩阵与另一个矩阵（或原矩阵自身）的叉积，请使用函数 `crossprod()` 或 `tcrossprod()`。如果 `a` 和 `b` 是可乘矩阵，则：

```
crossprod(a) = t(a)%*%a,
tcrossprod(a) = a%*%t(a),
crossprod(a,b) = t(a)%*%b,
tcrossprod(a,b) = a%*%t(b).
```

要求一个非奇异方阵的逆矩阵，请使用函数 `solve()`，例如 `solve(a)`。函数 `solve()` 也可以用于求解线性方程

```
Xa=b，
```

其中 `X` 是一个非奇异方阵，`b` 的行数与 `X` 相同。语法是 `solve(X,b)`。

要求方阵的行列式，请使用 `det(X)`，其中 `X` 是一个方阵。

要创建对角矩阵或获取矩阵的对角线，请使用函数 `diag()`。如果 `a` 是一个向量，`diag(a)` 将返回一个对角矩阵，其对角线等于 `a`。例如：

```
> a = 1:2
> a
[1] 1 2
> diag(a)
     [,1] [,2]
[1,]    1    0
[2,]    0    2
```

如果 `a` 是一个矩阵，`diag(a)` 将返回矩阵的对角线元素，即使矩阵不是方阵。例如：

```
> a = matrix(1:6,2,3)
> a
     [,1] [,2] [,3]
[1,]    1    3    5
[2,]    2    4    6
> diag(a)
[1] 1 4
```

更多信息，可以在 R 提示符下输入 `??"matrix multiplication"` 来访问 CRAN 关于矩阵乘法的帮助页面。对于这六个函数，在 R 提示符下输入 `?函数名`（其中 `函数名` 是函数的名称）可以调出该函数的帮助页面。您也可以使用 R Studio 的“帮助”选项卡。在 R 提示符下输入 `?"%"` 或在 R Studio 的“帮助”选项卡中输入 `%` 来查看 `%` 运算符。

### 关系运算符

关系运算符用于逻辑测试。六个关系运算符是：`==`（等于），`!=`（不等于），`<`（小于），`<=`（小于或等于），`>`（大于），`>=`（大于或等于）。逻辑运算符列表见表 3-4。

**表 3-4：逻辑运算符**

| 运算符 | 运算         | 示例   |
| :----- | :----------- | :----- |
| `==`   | 等于         | `a==9` |
| `!=`   | 不等于       | `a!=9` |
| `>`    | 大于         | `a>9`  |
| `>=`   | 大于或等于   | `a>=9` |
| `<`    | 小于         | `a<9`  |
| `<=`   | 小于或等于   | `a<=9` |

请注意，“等于”的关系运算符是 `==`，而不是 `=`。一个常见的错误是在逻辑表达式中将 `=` 误用作 `==`。R 对于使用 `=` 会返回错误。

与算术运算符一样，逻辑表达式可以使用括号进行分组。例如，

```
( ( a>0 & b>0 ) & ( a<5 & b<5 ) )
```

是一个逻辑表达式，可以为其赋值一个名称。

CRAN 关于关系运算符的帮助页面可以在 R 提示符下输入`??"relational operators"`，或在 R Studio 的“帮助”选项卡搜索框中输入`==`来访问。

# 下标运算符

R 中的许多对象包含多个元素。下标用于访问对象的特定元素。向量、矩阵、数组、列表和槽都可以使用下标。在 S3 中，使用单方括号（`[]`）、双方括号（`[[]]`）和美元符号（`$`）。对于 S4 对象，使用`@`符号进行下标操作。这些符号在此处不用于其他用途。

## 向量

对于向量，除了列表向量外，通常使用单方括号是合适的。也可以使用双方括号，但一次只能访问向量的一个元素。在单方括号内，可以包含一个逻辑表达式或一组索引。例如：

```
a[ 3:7 ] 或  a[ a>3 ]
```

第一个表达式的结果是`a`的第三到第七个元素。第二个表达式的结果是`a`中大于三的那些元素。

如果索引带有负号，则这些索引将被排除。例如：

```
a[ -2:-6 ]
```

将返回对象`a`移除第二到第六个元素后的结果。

一个对象可以在一个方括号内进行子集选择，并在另一个方括号内再次进行子集选择。例如：

```
a[ 1:10 ][ b>3 ]
```

其中`a`的长度大于或等于十，且`b`的长度为十。该表达式会返回`a`的前十个元素中，对应`b`的元素大于三的那些元素。子集选择可以继续使用更多方括号。每一组方括号都将作用于前一次子集选择的结果。

### 矩阵

对于矩阵，两种方括号也都适用。使用单方括号时，行的选择指令和列的选择指令之间用逗号分隔。或者，如果不使用逗号，矩阵将被视为向量处理，按第一列开始逐行向下检索。与向量的子集选择类似，对于单方括号，可以使用索引或逻辑表达式对矩阵进行子集选择。要引用矩阵的所有行，只需将括号内逗号的左侧留空。要引用矩阵的所有列，只需将括号内逗号的右侧留空。

双方括号只返回一个值。如果通过逗号分隔的行和列索引进行子集选择，则返回该单元格中的值。如果只在双方括号内输入一个索引值，R 会将矩阵视为向量（按行向下检索），并返回该向量中索引对应的元素。

矩阵下标操作的一个示例如下：

```
a[ a[,1]>3 , 1:4 ]
```

其中`a`是一个至少包含四列的矩阵。该表达式将返回前四列中，第一列元素大于三的那些行。注意，`a[,1]`由一列组成，包含所有行。

矩阵也可以使用一个两列的矩阵进行子集选择。这个两列矩阵将包含行索引和列索引，并根据每行中的索引选出矩阵中的单个单元格。例如，如果`b`是一个矩阵，第一行为`[1 2]`，第二行为`[2 3]`，那么`a[b]`将返回两个元素`a[1,2]`和`a[2,3]`。

### 数组

数组类似于矩阵，但可以有超过两个维度。请注意，矩阵是一个二维数组，而向量是一维数组。对超过二维的数组进行下标操作，与矩阵的下标操作类似，区别在于单方括号内会有更多的逗号。示例如下：

```
a[ 1:3,,2:7 ]
```

其中`a`是一个三维数组，第一维至少有三个层级，第三维至少有七个层级。子集选择的结果将是第二维中所有元素，这些元素在第一维的索引为一、二或三，并且在第三维的索引介于二到七之间（含端点）。

与矩阵类似，数组也可以使用一个矩阵进行子集选择，该矩阵的列数需与数组的维度数相同，其行则由数组中单个单元格的索引组成。不带逗号的单方括号和双方括号的操作方式与向量和矩阵相同。

### 列表

列表是 R 对象的集合（也是一种向量）。这些对象可以是任何类型，并且在同一个列表中不必是相同类型。这些对象在列表中有索引。要查看列表中的对象，可以使用单方括号。例如：

```
blist[ 1:5 ]
```

将返回`blist`中的前五个对象，并且结果本身也是一个列表。

要访问列表中的一个对象，则需要使用双方括号或美元符号。例如：

```
blist[[ 2 ]]
```

将返回列表`blist`中的第二个对象，而：

```
blist$b1
```

将返回`blist`中名为`b1`的对象。列表中的对象一次只能访问一个。

如果创建的列表中的对象没有关联名称，则在创建列表时会为这些对象赋予名称。名称可以随时更改。

数据框是一种特殊的列表。数据框中列表内的每个对象都具有相同数量的元素，并定义为`data.frame`。列表中的每个对象都属于一种原子模式（将在第 4 章中描述），不过不同的对象不必属于同一种模式。数据框可以像矩阵或列表一样进行子集选择。如果像矩阵一样进行子集选择，结果对象将是一个列表。如果像列表一样进行子集选择，则结果对象将是原始型、复数型、数值型、逻辑型或字符型，具体取决于列表对象是原始型、逻辑型、数值型、复数型还是字符型。`data.frame`中的单个单元格可以使用双方括号中的索引来访问。例如：

```
adframe[[ 1,2 ]]
```

将返回数据框`adframe`中第一行第二列的元素。

许多函数以列表形式返回输出。通常使用美元符号下标来访问输出，尽管也可以使用方括号索引。例如，对于线性模型函数`lm()`，输入：

```
lm( y~x )$resid
```

或：

```
lm( y~x )[[2]]
```

将返回`y`对`x`进行简单线性回归后的残差，以下两组语句也会得到相同结果：

```
a=lm( y~x )
a$resid
```

或：

```
a=lm( y~x )
a[[2]]
```

### 其他类型

其他类型的对象也可以进行子集选择，例如因子和槽。因子对象是向量，可以像向量一样进行子集选择。槽是 S4 对象，使用`@`进行子集选择。除非在方法声明中（这将在函数章节中描述），否则不应进行槽的子集选择。关于两者子集选择的更多信息，可以在 R 提示符下输入`??"Extract or Replace"`，或使用 R Studio 的帮助标签进行查找。
