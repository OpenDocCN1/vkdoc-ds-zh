# 16. 包 `base`、`stats` 和 `graphics`

在本章中，我们快速浏览一下 `base`、`stats` 和 `graphics` 这三个包——它们是 R 中默认加载的三个包。`base` 包包含三角函数和其他数学函数、许多 `as.` 和 `is.` 类函数、算术运算符、流程控制语句、某些 apply 函数以及 R 中许多其他基本函数。

`stats` 包包含许多基本统计函数，例如查找中位数、标准差和方差的函数。它还包括与常见概率分布相关的函数以及更多其他统计函数。`graphics` 包包含基本绘图函数及其辅助函数。

其他默认加载的包包括：`datasets`（包含数据集）、`utils`（包含实用函数）、`grDevices`（包含绘图所需的信息，如字体和颜色）以及 `methods`（包含用于处理 S4（形式化）方法和类的函数和信息）。

要查看某个包中的函数列表（带有指向函数帮助页面的可点击链接），请在 R 提示符下输入 `help(package="package.name")` 或 `library(help=package.name)`，其中 `package.name` 是包的名称。

本章信息的来源是 CRAN 帮助页面。

### 三角函数与双曲函数

R 中可用的三角函数和双曲函数包括：余弦 (`cos()`)、考虑 π 的余弦 (`cospi()`)、正弦 (`sin()`)、考虑 π 的正弦 (`sinpi()`)、正切 (`tan()`)、考虑 π 的正切 (`tanpi()`)、反余弦 (`acos()`)、反正弦 (`asin()`)、两种版本的反正切 (`atan()` 和 `atan2()`)、双曲余弦 (`cosh()`)、双曲正弦 (`sinh()`)、双曲正切 (`tanh()`)、反双曲余弦 (`acosh()`)、反双曲正弦 (`asinh()`)，以及反双曲正切 (`atanh()`)。

除 `cospi()`、`sinpi()` 和 `tanpi()` 外，角度以弧度形式输入函数（弧度 = π / 180 × 角度）。对于 `cospi()`、`sinpi()` 和 `tanpi()`，角度以圆的双倍分数形式输入（每 180° 为一个单位；即 1 等于 180°）。对于反函数，角度以弧度形式返回（角度 = 180 / π × 弧度）。参数必须为原子模式，并且是逻辑型、数值型或复数型——但 `cospi()`、`sinpi()` 和 `tanpi()` 除外，它们不能接受复数参数。逻辑值会被强制转换为数值。

对于反余弦和反正弦，其值必须在 `-1` 到 `1`（含）之间。对于其他值，结果为 `NaN`。对于反正切，`atan()` 接受一个参数，返回的结果在 `–π/2` 到 `π/2` 之间。

函数 `atan2()` 接受两个参数。该函数返回两个参数比值的反正切值，其中第一个参数为分子，第二个参数为分母。该函数接受任何数值（实数或复数）作为分子和分母。两个参数的长度可以不同，并且会循环使用。

函数 `atan2()` 返回 `-π` 到 `π` 之间的结果。角度的象限取决于分子和分母的符号，即：(+,+) 第一象限；(+,–) 第二象限；(–,–) 第三象限；(–,+) 第四象限。（根据定义，对于任意数 x，x 的正切等于 x 的正弦除以 x 的余弦。）分母为零时，根据分子的符号返回 `π/2` 或 `–π/2`。

双曲函数也可以接受任何数值（实数或复数）。对于反双曲函数，`acosh()` 的参数必须在 `1` 到 `∞`（含）之间，`atanh()` 的参数必须在 `–1` 到 `1`（含）之间。

参数可以是向量、矩阵、数据框或数组。对于包含多个元素的参数，操作会按元素逐一执行。对于接受两个参数的 `atan2()`，参数会循环使用。这些函数会返回与参数维度相同的对象。

### Beta 函数与 Gamma 函数相关函数

与 Beta 函数和 Gamma 函数相关的函数有：`beta()`、`lbeta()`、`gamma()`、`lgamma()`、`psigamma()`、`bigamma()`、`trigamma()`、`choose()`、`lchoose()`、`factorial()` 和 `lfactorial()`。在 R 中，这些函数属于**特殊**函数。这些函数的参数必须是原子模式且为逻辑型（会被强制转换为数值型）或数值型。函数返回的结果与参数形式相同（维度相同）。参数会循环使用。

`beta()` 和 `lbeta()` 函数接受参数 `a` 和 `b`，两者都必须是非负数，并分别返回 Beta 函数的值或 Beta 函数值的自然对数。负数会返回 `NaN`，并伴有警告。

# R 语言中的数学函数

## Gamma 函数及其相关函数

`gamma()`、`lgamma()`、`psigamma()`、`digamma()` 和 `trigamma()` 函数接受参数 `x`，其中 `psigamma()` 还接受参数 `deriv`。参数 `x` 可以是任意数值，但零或负整数除外，对于这些值会返回 `NaN`，并伴有警告。函数 `gamma()` 和 `lgamma()` 分别返回 Gamma 函数的值和 Gamma 函数绝对值的自然对数。函数 `psigamma()` 返回 Gamma 函数自然对数的 `deriv` 阶导数。参数 `deriv` 必须是一个大于或等于零的整数，否则会返回 `NaN`，并伴有警告。默认情况下，`deriv` 等于零。函数 `digamma()` 返回 Gamma 函数自然对数的一阶导数值，而 `trigamma()` 返回二阶导数值。

## 二项式系数函数

函数 `choose()` 和 `lchoose()` 分别返回二项式系数和二项式系数绝对值的自然对数。这两个函数都接受参数 `n`（可以是任意实数）和 `k`（可以是任意实数，但会被四舍五入为整数）。`k` 四舍五入后为负数时返回 `0`。函数 `choose()` 就是我们熟悉的“`n` 选 `k`”，适用于 `n` 为正整数且 `k` 为小于或等于 `n` 的非负整数的情况。

## 阶乘函数

函数 `factorial()` 和 `lfactorial()` 分别返回阶乘值和阶乘值绝对值的自然对数。这两个函数接受一个参数 `x`。`x` 的值可以是任意实数（数值型或逻辑型，后者会被强制转换为数值型）。阶乘值定义为：

```
factorial(x) = gamma(x+1)
```

适用于任意 `x` 值；当 `x` 为正整数时，其值等于 `x!`（即 `(x)(x-1)(x-2)...(2)(1)`）。当 `x` 等于零时，`factorial(x)` 等于一。负整数会返回 `NaN`，并伴有警告。

## 其他数学函数

其他一些数学函数包括：

- `abs()`：计算对象中各元素的绝对值
- `sqrt()`：计算对象中各元素的平方根
- `ceiling()`：将对象中的元素向上取整为整数
- `floor()`：将对象中的元素向下取整为整数
- `trunc()`：截断对象中元素的小数部分
- `cummax()`：计算原子对象的累积最大值
- `cummin()`：计算原子对象的累积最小值
- `cumprod()`：计算原子对象的累积乘积
- `cumsum()`：计算原子对象的累积和
- `exp()`：计算以 e 为底的指数，指数为对象元素的值
- `log()`、`log10()` 和 `log2()`：分别计算对象元素以指定底数（默认为自然对数）、以 10 为底和以 2 为底的对数
- `max()`：返回对象中元素的最大值，可以是字符型
- `min()`：返回对象中元素的最小值，可以是字符型
- `pmax()`：用于多个向量或矩阵（会循环使用）——返回多个对象之间逐行的最大值
- `pmin()`：用于多个向量或矩阵（会循环使用）——返回多个对象之间逐行的最小值
- `sum()`：计算对象中元素的和
- `prod()`：计算对象中元素的乘积
- `mean()`：计算对象中元素的平均值
- `range()`：计算对象中元素的范围（最小值和最大值）
- `rank()`：计算对象中元素的秩（排名）
- `sign()`：返回对象中元素的符号——正数返回 1，负数返回 –1，零返回 0
- `order()`：返回对对象元素排序后的索引；当有多个对象时，首先依据第一个对象排序，若存在相同值，则依据第二个对象，以此类推；用于对向量、矩阵、数据框和数组进行重新排序；`x[order(x)]` 等于 `sort(x)`
- `sort()`：对对象中的元素进行排序
- `zapsmall()`：将非常小的数值设置为零

这些函数可以用于合法模式的原子向量、矩阵、数组和数据框。这些函数返回的结果是各种类型的对象，具体取决于函数本身。

## 复数

以下函数用于复数：

- `Re()`，复数的实部
- `Img()`，复数的虚部
- `Arg()`，原点到复数的连线与 x 轴之间的弧度角
- `Mod()`，复数的模；等于原点到复数连线的长度
- `Conj()`，复数的共轭

这些函数接受逻辑型、数值型和复数对象作为参数。逻辑型参数会被强制转换为数值型。结果与参数具有相同的维度。

您可以通过在 R 提示符下输入 `?Re` 或使用 R Studio 中的“帮助”选项卡来了解更多关于复数函数的信息。
