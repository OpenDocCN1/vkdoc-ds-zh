# 2. R 提示符与 R Studio 窗口

本章涵盖 R 提示符与 R Studio 窗口。首先描述 R 的三个组成部分：对象、运算符和赋值。接着讨论如何使用 R 提示符，并给出一个在 R 提示符下进行计算的示例。随后，描述四个 R Studio 窗口。

在 Windows 和 macOS 中，R 运行在图形用户界面（GUI）中：Windows 中的`RGUI`和 macOS 中的`R.app GUI`。`RGUI`和`R.app GUI`都会打开一个 R 控制台，并以此在 R 控制台中的 R 提示符下运行。Linux 中也有 GUI，但本书仅介绍在终端窗口的 R 提示符下运行 R。对于这三种操作系统，R Studio 中的 R 也有涉及。
