# 杂项

`R` 中使用了两种主要的对象系统——`S3` 和 `S4`。`Slots` 是 `S4` 的一部分。本书以及 [PDF 文件](http://www.r-project.org/conferences/useR-2004/Keynotes/Leisch.pdf) 中都讨论了 `S3` 和 `S4`。

可以对对象的子集进行赋值。例如，令 `a` 为一个矩阵，用户想要将 `a` 中大于 100 的值更改为 100。那么，语句

```
a[ a>100 ] = 100
```

将执行替换并保持矩阵的其余部分不变。

在 R Studio 中，帮助页面易于访问且拥有独立的窗口。在 R 中，`?` 和 `??` 运算符用于打开帮助页面。对于已知的函数名，`?name`（或 `help(name)`）将返回该函数的帮助页面，其中 `name` 是函数名。要搜索与某些技术或方法相关的函数，可使用 `??` 运算符。输入 `??“关键词”`（或 `help.search(“关键词”)`），其中 `关键词` 由关于该技术或方法的关键词组成，可能会列出与该主题相关的包中的函数列表。有时，搜索结果可能为空。可以尝试使用不同的关键词再次搜索。

在 `R` 中，冒号有四种用法。这里我们只关心使用单冒号定义序列，以及使用双冒号通过包名和函数名来引用函数。

如果 `a` 和 `b` 是两个数字，表达式 `a:b` 将生成从 `a` 向下取整到整数到 `b` 向下取整到整数之间的整数序列。注意，数字 `a` 可以大于数字 `b`。

`R` 自带的函数都是某个包的一部分。如果一个包未被加载，仅使用函数名进行搜索将不会返回任何结果。函数的全名是 `包名::函数名`，其中 `包名` 是包的名称，`函数名` 是函数的名称。

关于冒号的更多信息，请在 R 提示符下输入 `?":"`，或在 R Studio 的“帮助”选项卡下输入 `:`。

运算符 `~` 在模型公式中用于分隔模型的左侧和右侧。更多信息，请在 R 提示符下输入 `?"~"`，或在 R Studio 的“帮助”选项卡下输入 `~`。

符号 `#` 用于注释。编写函数时，代码行中 `#` 右侧的所有内容都会被忽略。

运算符 `%in%` 对于运算符左侧对象中那些也存在于右侧对象中的值返回 `TRUE`，对于不存在的值返回 `FALSE`。结果的长度与第一个对象的长度相同。如果第一个对象具有多个维度，它将被转换为向量以获取结果。

通过输入 `??"提取或替换"` 或使用 R Studio 的“帮助”选项卡，可以找到关于子集操作的 CRAN 帮助页面。
