# 函数 `c()`

函数 `c()` 用于将多个对象合并成一个对象。在调用 `c()` 时，待合并的对象之间用逗号分隔。这些对象可以是 `NULL`、`raw`、`logical`、`integer`、`double`、字符串（必须加引号）、命名对象（必须是原子对象、列表或表达式）、列表以及表达式。对象也可以是返回上述任何类别的函数调用。

如果调用中的所有对象都是原子对象，函数 `c()` 会将这些对象合并成一个由构成这些对象的元素组成的向量。结果向量的类别是其各元素中层级最高的类别，其中类别的层级按 `NULL`、`raw`、`logical`、`integer`、`double`、`complex`、`character` 的顺序递增。

以下是层级关系的示例：

```
> rw = as.raw(c(36, 37, 38, 39))
> rw
[1] 24 25 26 27
> c(rw, rw)
[1] 24 25 26 27 24 25 26 27
> c(rw, TRUE)
[1] TRUE TRUE TRUE TRUE TRUE
> c(rw, 40)
[1] 36 37 38 39 40
> c(rw, 40.5)
[1] 36.0 37.0 38.0 39.0 40.5
> c(rw, 1+1i)
[1] 36+0i 37+0i 38+0i 39+0i  1+1i
> c(rw, "six")
[1] "24"  "25"  "26"  "27"  "six"
```

从 `raw` 类型的转换是自动进行的，但转换为 `character` 类型时除外，此时会保留 `raw` 的值。

函数 `c()` 有一个可选的命名参数，即逻辑参数 `recursive`。`recursive` 的默认值为 `FALSE`。如果将 `recursive` 设为 `TRUE`，并且待合并的对象集合中包含列表但不包含表达式，那么该列表会被拆解到最底层的单个元素层级，并返回一个原子元素向量。该对象会采用其内部层级最高的类别的类别。如果 `recursive` 为 `FALSE`，则结果对象会变成一个列表。

在类别的层级关系中，`list` 位于原子类别之上，但低于 `expression`。如果在调用 `c()` 时包含了表达式，那么结果的类别就是 `expression`。

以下是针对列表和表达式类别对象的示例：

```
> a.list
[[1]]
cl1 cl2
[1,]   1   3
[2,]   2   4
[[2]]
[1] "abc" "cde"
> c(a.list, 1:2)
[[1]]
cl1 cl2
[1,]   1   3
[2,]   2   4
[[2]]
[1] "abc" "cde"
[[3]]
[1] 1
[[4]]
[1] 2
> c(a.list, 1:2, recursive=T)
[1] "1"   "2"   "3"   "4"   "abc" "cde" "1"   "2"
> a.expr = expression(y ~ x, `1`)
> c(a.list, a.expr)
expression(1:4, c("abc", "cde"), y ~ x, `1`)
```

在第一次调用 `c()` 时，返回的是一个类别为 `list` 的对象。在第二次调用中，返回的是一个类别为 `character` 的对象。在第三次调用中，返回的是一个类别为 `expression` 的对象。

可以通过在列举元素时将元素名称设定为某个名称，来为 `c()` 创建的对象中的元素赋值名称，例如：

```
> c(a=1,b=2,3)
a b
1 2 3
```

这里，前两个元素被分别赋予了名称 `a` 和 `b`，而第三个元素没有赋予名称。

关于 `c()` 的更多信息，可以在 R 提示符下输入 `?c`，或使用 R Studio 中的“帮助”选项卡来查阅。
