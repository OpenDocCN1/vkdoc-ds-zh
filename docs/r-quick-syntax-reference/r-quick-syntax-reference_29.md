# 函数 `read.table()` 和 `read.csv()`

`read.table()` 和 `read.csv()` 这两个函数本质上是相同的，仅在于参数 `sep` 和 `header` 的默认值不同。与函数 `scan()` 一样，参数 `sep` 用于指定文件中数据值的分隔符，可以是任何单字节值。参数 `header` 取逻辑值，用于告知函数是否从第一行读取表头。

这两个函数从文件或连接（以矩阵形式呈现）中导入数据，或从参数 `text` 的值中导入数据。这些函数会根据数据创建一个数据框。如果数据来自文件，则在调用时，文件的位置需首先用引号括起来输入。文件位置可以是相对于工作空间的路径，也可以是绝对路径（包括 URL）。若要浏览文件，请在引号名称处输入 `file.choose()`，例如 `read.table(file.choose())`。以下是一个使用引号名称的示例：

```
> read.table( "test2.txt" )
V1 V2 V3 V4
1 one  3  5  7
2 two  4  6  8
```

请注意，各列的模式不必相同。此处，文件 `test2.txt` 既包含字符数据也包含数值数据，并且与 R 工作空间位于同一文件夹中。

如果文件中的行长度不全相等，默认情况下函数会返回错误。参数 `fill` 是一个逻辑参数，用于告知 R 填充那些元素数量少于其他行的行。例如：

```
> read.table( "test4.txt", fill=T )
V1 V2 V3 V4
1 one  3  5  7
2 two  4  6 NA
```

此处，`test4.txt` 第二行缺少最后一个元素。R 会使用 `NA` 填充该元素。

如果使用参数 `text` 输入一个表格，则行的结束由 `\n` 表示。例如：

```
> read.table( text="1 2 3 4 \n 2 3 4 5" )
V1 V2 V3 V4
1  1  2  3  4
2  2  3  4  5
```

对于 `read.table()`，`sep` 的默认值是空白字符，`header` 的默认值是 `FALSE`。对于 `read.csv()`，`sep` 的默认值是逗号，`header` 的默认值是 `TRUE`。（还有一个相关的函数 `read.csv2()`，用于欧洲地区，其小数点样式参数 `dec` 设置为 `,`，`sep` 设置为 `;`。）

由于这两个函数会根据数据创建数据框，因此各元素的模式仅需在列方向上保持一致。如果某列包含字符数据，默认情况下该列会被转换为因子。通过将参数 `as.is` 设置为 `TRUE`，则会将其转换为字符。例如：

```
> read.table( "test3.txt", sep="," )
V1    V2 V3 V4
1 one     1  3  4
2   1  four  3  2
> class( read.table( "test3.txt", sep="," )[,1] )
[1] "factor"
> class( read.table( "test3.txt", sep="," )[,3]  )
[1] "integer"
> read.table("test3.txt", sep=",", as.is=T)
V1    V2 V3 V4
1 one     1  3  4
2   1  four  3  2
> class( read.table( "test.txt3", sep=",", as.is=T )[,1] )
[1] "character"
> class( read.table( "test.txt3", sep=",", as.is=T )[,3] )
[1] "integer"
```

你可以看到不设置 `as.is` 与将其设置为 `TRUE` 之间的区别。文件 `test3.txt` 与工作空间位于同一文件夹中，呈矩阵形式，同时包含字符和整数数据。

这两个函数只能读取某些类型的原子数据：逻辑型、整数型、双精度型、复数型和字符型。根据这两个函数的 R 帮助页面，R 会先将数据作为字符型数据读入，然后从字符型转换为 `logical`、整数型、`numeric`、`complex` 或 `factor` 中的一种。

如上所述，如果 `as.is` 设置为 `TRUE`，包含字符数据的列不会转换为因子，而是保留为字符型。参数 `as.is` 也可以作为一个逻辑向量输入，为每一列指定一个值。也可以输入一个更短的向量，其值会在各列之间循环使用。

参数 `colClasses` 可以手动设置每一列的类，并且可以替代 `as.is` 来保持某一列为字符模式。列类可能的值有 `NA`、`NULL`、`logical`、`integer`、`numeric`、`complex`、`raw`、`character`、`factor`、`Date` 或 POSIXct。这些值需要加引号（`NA` 和 `NULL` 除外），并以向量的形式输入。这些值会循环使用。

如果值为 `NA`，则进行正常的转换。否则，如果可能，列元素会被强制转换为该列指定的类。例如：

```
> read.table( "test2.txt", colClasses=c( "character", "factor", NA, NA ) )
V1 V2 V3 V4
1 one  3  5  7
2 two  4  6  8
> class( read.table( "test2.txt", colClasses=c( "character", "factor", NA, NA ) )[,1] )
[1] "character"
> class( read.table( "test2.txt", colClasses=c( "character", "factor", NA, NA ) )[,2] )
[1] "factor"
> class( read.table( "test2.txt", colClasses=c( "character", "factor", NA, NA ) )[,3] )
[1] "integer"
```

参数 `row.names` 和 `col.names` 用于为 data.frame 的行和列指定名称。对于 `row.names`，参数可以是一个长度等于 data.frame 行数的字符向量；也可以是一个整数，指定 data.frame 中的哪一列用作行名；或者是一个包含要用作行名称的列名的字符值。行名不会循环使用。

对于 `col.names`，参数是一个用于列名的字符向量。该向量长度必须与列数相同。如果未指定 `col.names` 且 `header` 为 `FALSE`，则列将被命名为 V1、V2、...、Vn，其中 `n` 是最后一列的编号。

如果 `header` 为 `TRUE` 并且第一列没有名称，而其余列都有名称，则 R 会将第一列设置为行名。

以下是一些示例：

对于矩阵

即文件 `test5.txt`，示例如下：

```
> read.table( "test5.txt", header=T )
c1 c2 c3
one  3  5  7
two  4  6  8
```

请注意，`header` 为 `TRUE`，并且第一列少了一行。

对于由 `test5.txt` 的后两行组成的矩阵（称为 `test6.txt`），示例如下：

```
> read.table( "test6.txt", col.names=c( "c1", "c2", "c3", "c4" ), row.names=2 )
c1 c3 c4
```

函数 `read.table()` 和 `read.csv()` 还有几个其他参数。关于这些函数的完整描述，可以在 R 提示符下输入 `?read.table` 或通过 R Studio 的“帮助”选项卡找到。



### 函数 `load()`、`attach()` 和 `data()`

`load()` 函数用于加载由 `save()` 函数外部保存的对象。使用 `save()` 保存对象时，默认以二进制格式保存。因此，相较于 `dput()` 和 `dget()` 函数，这两个函数更常用于保存和加载对象。

`load()` 的参数包括 `file`、`envir` 和 `verbose`。参数 `file` 指定要读取的文件名或连接。文件名必须用引号括起来，或是一个字符对象。参数 `envir` 指定加载对象的目标环境，默认值为 `parent.env()`。参数 `verbose` 默认值为 `FALSE`。若 `verbose` 为 `FALSE`，加载过程中命令行不会输出任何信息；若为 `TRUE`，则会列出所加载对象的名称。加载的对象会以保存时的名称被加载到工作空间中。例如：

```
> load( "a.fun.ex" )
> load( "a.fun.ex", verbose=T )
Loading objects:
a.fun
atl.strm
```

此处，“a.fun”和“atl.strm”是保存在外部文件“a.fun.ex”中的对象。

`attach()` 函数可用于访问使用 `save()` 保存的数据文件。该数据文件实际上并未被加载，而是被置入搜索流中。`attach()` 的参数包括 `what`、`pos`、`name`、`backtick` 和 `warn.conflicts`。参数 `what` 应赋值为包含外部文件名的字符串或字符对象。数据文件在搜索流中的位置由参数 `pos` 设定，默认值为“2L”，即上次使用位置之后的位置。参数 `name` 为附加的数据文件指定一个名称。参数 `backtick` 未被使用。参数 `warn.conflicts` 是逻辑值，用于告知 R 是否在搜索流中较低位置存在同名对象时向用户发出警告，默认值为 `TRUE`。例如：

```
> a.fun
Error: object 'a.fun' not found
> attach( "a.fun.ex", name="one" )
The following object is masked _by_ .GlobalEnv:
atl.strm
> a.fun
function() {
# an example
print(1:5)
}
> ls( pat="a.fun" )
character(0)
> detach( one )
> a.fun
Error: object 'a.fun' not found
```

此处，`a.fun` 并非工作空间中的对象，但在附加了“a.fun.ex”后，`a.fun` 便可在工作空间中访问。在解除“a.fun.ex”的附加后，`a.fun` 便不再可访问。

`data()` 函数用于加载保存在工作目录的“data”子目录或已安装包中的对象。`data()` 的参数包括 `...`、`list`、`package`、`lib.loc`、`verbose` 和 `envir`。第一个参数是包含数据集的名称（针对包内数据集）或不含扩展名的数据文件名的字符串——扩展名可以是 .R、.r、.RData、.rda、.tab、.txt、.TXT、.csv 或 .CSV。第二个参数 `list` 包含与第一个参数相同类型的信息，但以字符向量列表的形式呈现。参数 `package` 允许你指定在哪一个包中查找数据。默认情况下，会搜索所有已加载的包和工作目录下的“data”子目录。参数 `lib.loc` 指定了包含 R 库（要搜索的库）的库位置。默认情况下，会搜索 R 已知的库。参数 `verbose` 会提供通常不显示的调用信息。参数 `envir` 指定存放数据的环境，默认值为 `.GlobalEnv`。

数据集“airmiles”位于“datasets”库中，该库在打开 R 或 R Studio 时默认加载。下面是一个使用数据集“airmiles”的示例：

```
> library( datasets )
> airmiles
Time Series:
Start = 1937
End = 1960
Frequency = 1
[1]   412   480   683  1052  1385  1418  1634  2178  3362
[10]  5948  6109  5981  6753  8003 10566 12528 14760 16769
[19] 19819 22362 25340 25343 29269 30514
> ls( pattern="air" )
character(0)
> detach( "package:datasets", unload=TRUE )
> data( "airmiles", package="datasets" )
> ls( pattern="air" )
[1] "airmiles"
```

当“datasets”被加载时，数据集“airmiles”可用，但它并不在工作空间中；而解除“datasets”的附加后，“airmiles”便不再可用。调用 `data()` 会将“airmiles”加载到工作空间中，即使“datasets”并未被加载。

第二个示例展示了如何从文件系统加载数据：

```
> save( "atl.strm", "atl.strm.plot.fun", file="~/data/AS.RData" )
> rm( atl.strm, atl.strm.plot.fun )
> ls( pat="atl" )
character(0)
> data( "AS" )
> ls( pat="atl" )
[1] "atl.strm"          "atl.strm.plot.fun"
```

首先，将对象“atl.strm”和“atl.strm.plot.fun”保存到文件“AS.RData”。然后，从工作空间中移除这些对象。最后，使用 `data()` 将这些对象重新加载回工作空间。本示例中使用的文件名语法是 OS X 系统的语法，你应当使用与你的操作系统相匹配的语法。

更多信息可以通过在 R 提示符下输入 `?load`（关于 `load()`）、`?attach`（关于 `attach()`）或 `?data`（关于 `data()`），或者使用 R Studio 中的“帮助”选项卡来获取。

### 函数 `readRDS()`

`readRDS()` 函数用于读取单个使用 `saveRDS()` 保存的对象。使用 `saveRDS()` 保存的文件是二进制格式。`readRDS()` 函数有两个参数：`file` 和 `refhook`。参数 `file` 指定保存对象的文件名或连接，必须是一个字符串或字符对象。引用 `readRDS()` 的 R 帮助页面，参数 `refhook` 包含“一个用于处理引用对象的钩子函数”，默认值为 `NULL`。

示例如下：

```
> saveRDS( atl.strm.plot.fun, "ASPF" )
> rm( atl.strm.plot.fun )
> ls( pat="fun" )
character(0)
> atl.strm.plot.fun = readRDS( "ASPF" )
> ls( pat="fun" )
[1] "atl.strm.plot.fun"
```

首先，使用 `saveRDS()` 将对象“atl.strm.plot.fun”保存到文件“ASPF”。然后，从工作空间中移除该对象。最后，使用 `readRDS()` 将文件重新加载回工作空间。

更多信息可以通过在 R 提示符下输入 `?readRDS`，或者使用 R Studio 中的“帮助”选项卡来获取。

### 使用 R Studio 读取数据

要将数据集加载到 R Studio 中，请转到右上角窗口的 `“环境”` 选项卡。选择 `“导入数据集”`。您将看到六个可选方案：使用基础包中的函数从文本导入、使用 `readr` 包中的函数从文本导入、从 Excel 数据集导入、从 SPSS 数据集导入、从 SAS 数据集导入以及从 Stata 数据集导入。

如果数据位于列格式的文本文件中（例如 `.csv`、`.txt` 或 `.dat` 文件），则 `“从文本（基础）”` 是合适的选项。选择此选项后，您将进入计算机上的文件目录。选择包含要加载数据的文件。此时会打开一个表单，左侧显示用于读取数据的选择项，右侧显示一个 `“输入文件”` 窗口和一个 `“数据框”` 窗口。`“输入文件”` 显示 R Studio 在默认左侧选项下看到的输入文件，而 `“数据框”` 窗口则显示在给定默认值下将创建的数据框。

左侧的第一个选项是为工作区中的数据框指定的名称。默认名称基于文件名。文件名中的空格会被下划线替换。名称可以更改。第二个选项是文件中文本的编码方式。通常，默认值 `“自动”` 即可读取文件。第三个选项是 `“标题”`，默认值为 `“否”`。如果数据文件中有标题，请将 `“标题”` 更改为 `“是”`。

第四个选项是 `“行名”`，提供了 `“自动”`、`“使用第一列”` 或 `“使用数字”` 这些选项。默认值为 `“自动”`。第五个选项是 `“分隔符”`。根据数据文件中使用的分隔符类型，分隔符可以是 `“逗号”`、`“空白”`、`“分号”` 或 `“制表符”`。第六个选项是数据中小数点的形式。选项为 `“句点”` 和 `“逗号”`。第七个选项是 `“引号”`，用于指定数据文件中使用的引号类型。选项为 `“双引号 (")”`、`“单引号 (')”` 和 `“无”`。

第八个选项是用于指示文件中某行为注释的符号。选项包括：`“#”`、`“!”`、`“%”`、`“@”`、`“/”` 和 `“~”`。第九个选项是用于缺失数据的值。可以输入任何文本。默认值为 `“NA”`。最后一个选项是 `“字符串作为因子”`。如果字符串应作为字符型字符串而非因子读取，请取消选中该复选框。

当 `“数据框”` 窗口中的数据达到所需形式时，选择该窗口右下方的 `“导入”` 按钮。R Studio 将导入数据集。

使用 `“从文本（readr）”` 导入选项，您可以通过文件或 `“URL”` 进行读取。在 `“文件/URL”` 框中输入文件或 URL 地址。输入地址后，将 `“导入选项”` 更改为适合数据的选项。这些选项与 `“从文本（基础）”` 的选项类似，但更灵活一些。`“名称”` 选项在数据更新前默认为 `“dataset”`，更新后会变为地址中数据集的名称。`“跳过”` 告知 R Studio 要跳过多少行。如果没有标题行，请取消选中 `“第一行作为名称”`（第一行是指任何跳过行之后的那一行）。

取消选中 `“修剪空格”` 以保留数据文件中的空白。取消选中 `“打开数据查看器”` 以在加载后不在源窗口中打开数据集。`“分隔符”` 选项包括用户指定的单字节分隔符。`“引号”` 给出引号存在时的引号方法。`“区域设置”` 提供数据所在地域（国家或语言）中各种格式的默认值。`“转义符”` 给出数据的转义字符（如果存在）。用于指示注释的可能值包括 `“默认”`、`“#”`、`“%”`、`“//”`、`“'”`、`“!”`、`“;”`、`“—”`、`“*”`、`“||”`、`“'”`、`“*”`、`“\”` 和 `“*>”`。`“NA”` 选项包括 `“默认”`、`“NA”`、`“null”`、`“0”` 和 `“空”`。

选择好导入选项后，点击 `“文件/URL”` 框右侧的 `“更新”` 按钮。数据将使用 `“代码预览”` 窗口中的代码（该代码可更改）加载到 `“数据框”` 窗口中。`“名称”` 将更改为文件名。此时，可以更改要在 R Studio 中分配给数据集的名称。如有必要，可根据 `“数据框”` 窗口中的数据指示，对导入选项或代码进行更改。数据预览会随着更改而更新。准备就绪后，选择 `“导入文本数据”` 窗口右下角的 `“导入”` 按钮。数据集将加载。或者选择 `“取消”` 退出该窗口，不加载数据。

`“从 Excel”`、`“从 SPSS”`、`“从 SAS”` 和 `“从 Stata”` 这些选项与 `“从文本（readr）”` 类似，此处不再赘述。

### R 数据集

R 中的许多包都附带数据集。其中一些数据集位于 `datasets` 包中，该包是 R 默认安装的包之一。要访问 `datasets` 包中的数据集，请在 R 提示符下输入 `library(datasets)`，或者在 R Studio 的 `“包”` 选项卡下选中 `datasets` 左侧的复选框。要查看 `datasets` 中的数据集，请在 R 提示符下输入 `library(help=datasets)`，或者选择 `“包”` 选项卡下的 `datasets`。一旦加载该库，即可访问 `datasets` 中的数据集。

您也可以使用 `attach()` 函数来访问某个库中的数据集，而无需加载该库。需要同时提供包名和数据集名，两者之间用双冒号分隔且不加引号，例如 `attach(datasets::attitude)`。使用完附加的数据集后，应将其分离，例如 `detach(datasets::attitude)`。

对于任何库，一旦加载了该库，其中的数据集就可以像工作区中的任何其他对象一样被访问。数据集可以是原子对象、`data.frame` 或列表。如果数据集不是数据框或列表，`attach()` 函数会报错，但只要库已加载，仅通过使用对象名称即可访问该对象。但是，在 R Studio 中，这些数据集不会出现在 `“环境”` 选项卡下，因此它们不在工作区中。如前述，使用 `data()` 函数可将数据加载到工作区。

`attach()` 函数会将数据附加到工作区中的某个特定位置。R 会按工作区中的位置顺序搜索对象。位置一是工作区本身。第一次调用 `attach()` 会附加到位置二，第二次调用附加到位置三，以此类推。也可以在调用中指定位置。R 会从位置一开始，使用找到的第一个具有该名称的对象。

## 概率分布与函数 `sample()`

R 拥有丰富的随机数生成器。对于概率分布，随机数生成器是与该概率分布相关的四个函数之一。这里将介绍全部四个函数。与概率分布相关的函数具有相同的基本形式。

在 R 提示符下输入 `?distribution` 可以查看 `stats` 包中的分布（以及生成器）。其他包中的许多分布可以在 [`https://cran.r-project.org/web/views/Distributions.html`](https://cran.r-project.org/web/views/Distributions.html) 找到。



### 概率分布

对于 `stats` 包中的概率分布，每个分布都关联了四个函数：`ddist()`、`pdist()`、`qdist()` 和 `rdist()`，其中 `dist` 表示具体的分布。例如，对于正态分布，`dist` 等于 `norm`。并非所有分布都具备全部四个函数。

第一个函数是密度函数。函数 `ddist()` 返回在指定的数值向量各点上概率密度函数的高度。第二个函数是累积概率函数。默认情况下，函数 `pdist()` 返回概率密度函数在指定数值向量左侧的区域面积。

第三个函数是分位数函数。默认情况下，函数 `qdist()` 返回实数轴上的值，使得这些值左侧的区域面积等于指定概率向量中的各个值。第四个函数是随机数生成器。函数 `rdist()` 生成来自该分布的伪随机变量。对于所有这些函数，向量可以是长度为 1 的向量。

这四个函数都包含用于指定给定分布标准参数的参数，其中许多参数都有默认值。例如，对于正态分布，参数是 `mean` 和 `sd`，默认值分别为 `0` 和 `1`。`mean` 和 `sd` 变量都可以作为向量输入，并会循环使用。这些向量必须为数值型或逻辑型。逻辑型向量会被强制转换为数值型。`stats` 包中的分布及其参数如表 9-1 所示。

**表 9-1** `Stats` 包中的概率分布

| R 中的分布名称 | 分布的参数 |
| --- | --- |
| `beta` | `shape1=1`, `shape2=2`, `npc=0` |
| `binom` | `size`, `prob` |
| `birthday` | `classes=365`, `coincident=2` |
| `cauchy` | `location=0`, `scale=1` |
| `chisq` | `df`, `npc=0` |
| `exp` | `rate=1` |
| `f` | `df1`, `df2`, `npc` |
| `gamma` | `shape`, `rate=1`, `scale=1/rate` |
| `geom` | `prob` |
| `hyper` | `m`, `n`, `k` |
| `lnorm` | `meanlog=0`, `sdlog=1` |
| `multinom` | `size`, `prob` |
| `nbinom` | `size`, `prob`, `mu` |
| `norm` | `mean=0`, `sd=1` |
| `pois` | `lambda` |
| `signrank` | `n` |
| `t` | `df`, `ncp` |
| `tukey` | `nmeans`, `df`, `nranges=1` |
| `unif` | `min=0`, `max=1` |
| `weibull` | `shape`, `scale=1` |
| `wilcox` | `m`, `n` |

前缀为 `d`、`p`、`q` 和 `r`。`multinom` 函数只有 `d` 和 `r`。`tukey` 函数只有 `p` 和 `q`。`birthday` 函数只有 `p` 和 `q`，并且没有 `log.p` 参数。以上信息来自 CRAN 关于分布的帮助页面。

对于这四个函数，第一个参数都是必需的，并且没有默认值。对于密度函数，第一个参数 `x` 是一个实数向量，或者可强制转换为实数的值。对于累积概率函数，第一个参数 `q` 也是一个实数向量，或者可强制转换为实数的值。对于分位数函数，第一个参数 `p` 是一个概率向量，或者可强制转换为介于 0 和 1 之间（包含 0 和 1）的值。对于随机数生成器，第一个参数 `n`（对于超几何分布、符号秩分布和 wilcox 分布为 `nn`）是一个正整数，或者可强制转换为整数的值，它告诉 R 要生成多少个随机数。

通常，对于密度函数，如果第一个参数的值被视为目标值的对数，则逻辑参数 `log` 应设置为 `TRUE`。对于概率函数和分位数函数，如果用于概率的值是以概率对数的形式输入或输出，则逻辑参数 `log.p` 应设置为 true。

通常，对于累积概率函数和分位数函数，可以使用逻辑参数 `lower.tail` 来设置是使用分布的下尾还是上尾。默认使用下尾。下尾是分布函数中不大于第一个参数值的区域的面积，上尾是分布函数中大于第一个参数值的区域的面积。

此外，通常情况下，参数可以作为向量输入，并会循环使用。如果输入了非法的参数值，函数将报错。

要获取有关某个给定概率分布的更多信息，可以在 R 提示符下输入 `?ddist`，其中 `dist` 是表 9-1 中的分布名称，但 `tukey` 和 `birthday` 分布除外，对于它们应使用 `?pdist`。或者使用 R Studio 中的 “帮助” 选项卡。

### `sample()` 函数

有时需要的是随机样本而非随机数。`sample()` 函数可以从原子对象、列表对象或任何其他定义了长度的模式对象中抽取随机样本。

`sample()` 函数接受四个参数。第一个参数 `x` 是要抽样的对象。如果 `x` 是一个大于 1 的单个正实数，`sample()` 将从 1 到该实数向下取整得到的整数序列中抽样。如果 `x` 是一个可强制转换为向量的对象或单个正数，并且没有提供其他参数，则 `sample()` 返回该对象或从 1 到该数向下取整得到的整数序列的一个排列。

第二个参数 `size` 是要抽样的项目数量。`size` 参数可以是一个非负整数，或者可以向下取整为非负整数的实数。

第三个参数是逻辑参数 `replace`，它告诉 `sample()` 是否进行有放回抽样。默认值为 `FALSE`，即进行无放回抽样。如果 `size` 大于 `x` 的长度且 `replace` 为 `FALSE`，则 `sample()` 将报错。

第四个参数是 `prob`，它提供了用于抽样的权重列表。`prob` 参数必须与 `x` 的长度相同，其元素必须可强制转换为非负数值元素，并且强制转换后的元素中至少有一半是非零的。`prob` 强制转换后的元素之和不必为 1。

例如：

```
> sample(10)
[1]  8 10  6  4  7  5  3  9  1  2
> sample(10, 5)
[1] 3 1 6 8 9
> sample(c("a1", "a2", "a3"), 6, replace=T)
[1] "a1" "a1" "a1" "a3" "a3" "a1"
> sample(11:21, prob=1:11)
[1] 18 20 14 21 19 17 12 16 15 13 11
```

要获取关于 `sample()` 的更多信息，可以在 R 提示符下输入 `?sample`，或者使用 R Studio 中的 “帮助” 选项卡。

## 手动输入数据与生成带模式的数据

可以使用 `c()` 函数手动输入数据，其中的 `c` 代表 *collect*（收集）。有时需要具有特定模式的数据，例如，为矩阵或数组操作设置索引，或作为函数的输入。R 中有许多函数可以生成模式化的结果，这非常有用。有时向量、矩阵或数组的维度需要索引化的名称。`paste()` 函数可用于创建索引化的名称。
