# 12. 流程控制

流程控制语句用于重复执行一系列任务若干次，或根据逻辑对象来引导执行流程。对于那些在 FORTRAN 和 BASIC 时代开始编程的人来说，使用循环非常得心应手。在 R 中，如果可能，更好的选择是使用数组和索引选择，而不是循环。使用索引比循环快得多。

话虽如此，控制语句包括 `if`、`if/else`、`while`、`for` 和 `repeat`。它们有时是必需的，并且通常很有用。在本章中，我们给出了流程控制语句的语法。我们在第 13 章中给出了流程控制使用的示例。

## 花括号“{}”和分号“;”

花括号用于括起代码段。花括号可以与 `if`、`else`、`while`、`for` 和 `repeat` 流程控制语句一起使用，以界定控制语句要操作的代码段，无论是在函数内部还是在 R 控制台中。

花括号也可以在没有伴随流程控制语句的情况下直接用于 R 控制台。从左花括号开始，可以逐行输入代码语句。这些语句在输入右花括号之前不会执行。

分号用于在一行中包含多个语句。一个语句要等到它前面的语句执行完毕后才会被求值。如果第一个语句是一个流程控制语句，后面跟着一个单一的代码语句，那么控制流程必须完成，第二个语句才会执行。然而，如果两个（或多个）语句被包含在流程控制语句后面的一对左、右花括号内，那么花括号内的所有语句将根据该流程控制语句一起执行。

## `if` 和 `if/else` 控制语句

`if` 控制语句接受一个逻辑对象，如果该对象为真，则执行相应的代码。如果该对象不为真，则可以选择性地执行由 `else` 语句提供的另一段代码。

该逻辑对象必须是可以强制转换为逻辑类型的对象。如果逻辑对象的长度大于 1，则仅使用该对象的第一个元素。

`if` 语句可以采用以下形式：

```
if ('逻辑对象') '单一代码语句'
if ('逻辑对象') '单一代码语句';'单一代码语句'
if ('逻辑对象') {'多个用分号分隔的代码语句'}
if ('逻辑对象') {
'多行代码语句'
}
```

这四种形式并未穷举所有可能的形式。在第二种形式中，即使逻辑对象为假，第二个语句也会执行，因为这两个语句没有被括在花括号中。

如果逻辑对象为假，则可以选择使用 `else` 语句让 R 执行不同的代码。对于 `if` 和 `else` 这两个控制语句，下面给出了两种形式的示例：

```
if ('逻辑对象') '单一代码语句' else '单一代码语句'
if ('逻辑对象') {
'多行代码语句'
}
else {
'多行代码语句'
}
```

同样，这两种形式并未穷举所有可能。如果没有 `else` 控制语句且逻辑对象为假，则与 `if` 语句关联的代码语句将被跳过。

## `while` 控制语句

`while` 控制语句在一个逻辑条件为真时执行一个代码块。同样，该逻辑对象必须是可以强制转换为逻辑类型的对象。如果逻辑对象的长度大于 1，则仅使用该对象的第一个元素。

该控制语句可以采用以下形式：

```
while ('逻辑对象') '单一代码语句'
while ('逻辑对象') '单一代码语句'; '单一代码语句'
while ('逻辑对象') {'多个用分号分隔的代码语句'}
while ('逻辑对象') {
'多行代码语句'
}
```

同样，所示形式并未穷举所有可能的形式。请注意，对于第二种形式，第二个语句要等到 `while` 循环结束后才会执行，因为这两个语句没有被括在花括号中。
