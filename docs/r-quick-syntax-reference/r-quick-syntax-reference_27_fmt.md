# 9. 导入与创建数据

当您向 R 或 R Studio 加载数据时，有多种选择。对于外部文件，有几个函数可以从特定类型的文件中读取数据到 R 中。对于不在文件中但可通过连接访问的数据，有许多函数可以连接到这些连接。

在 R Studio 中，许多数据集可以通过`Import Dataset`选项卡读取——该选项卡位于右上角窗口的`Environment`选项卡下。其他类型的文件可以加载到 R Studio 的`Source`（左上角）窗口中，如第 2 章所述。

R 自带了许多内置数据集，可以直接加载。

有时，用户需要创建数据。R 拥有大量的随机数生成器用于数据创建。数据也可以使用`c()`或其它各种函数手动输入，以创建具有特定模式的数据。

在底层，R 使用连接函数进行读取。本章涵盖的高级函数使用了这些底层函数。有关底层函数的更多信息，请在 R 提示符下输入`?connections`，或使用 R Studio 中的`Help`选项卡。

本章第一部分介绍将数据读入 R 和 R Studio 以及加载 R 数据集。第二部分介绍概率分布，包括随机数生成器和`sample()`函数。第三部分介绍手动数据输入和创建具有模式的数据。
