# 15. 一些常用函数

本章介绍 R 中的一些常用函数。第一节讨论函数 `options()`，它用于设置 R 的默认选项。第二节描述函数 `round()`、`signif()` 和 `noquote()`，它们用于格式化对象。第三节涵盖函数 `cat()`，它用于将结果打印到控制台、文件或连接。第四节讨论用于显示对象的函数 `format()`、`print()`、`plot()` 和 `summary()`。第四节中的函数对不同类别的对象有不同的操作方式，因此它们是通用函数。在第五节中，我们介绍函数 `anova()`、`coef()`、`effects()`、`residuals()`、`fitted()`、`vcov()`、`confint()` 和 `predict()`，这些函数专门作用于模型，并且也是通用函数。

## 函数 `options()`

目前在我的 OS X 系统上，函数 `options()` 中有 84 个选项。这些选项在使用它们的包被加载时一同加载。要查看选项及其设置值的列表，请在 R 提示符下输入 `options()`。所有已加载包的选项都包含在该列表中。

要查看特定选项的值，请在 R 提示符下输入 `options("opt1", "opt2", ... ,"opt_n")`，其中 `opt1` 到 `opt_n` 是选项的名称。要访问某个选项的值，请使用 `getOption("opt")`，其中 `opt` 是选项的名称。

要设置选项值，请在 R 提示符下输入 `options(opt1=value1, opt2=value2, opt3=value3, ... , opt_n=value_n)`，其中 `opt1` 到 `opt_n` 是选项，`value1` 到 `value_n` 是分配给这些选项的值。请注意，在设置和访问选项时，选项以字符串形式（带引号）输入，而在设置值时，选项以对象形式（不带引号）输入。

有关选项及其所属包的说明，请在 R 提示符下输入 `?options`，或使用 R Studio 中的帮助选项卡。

在 R 会话期间更改选项时，更改仅在该会话中有效。要更改 R 运行时加载的选项默认值，请尝试在与 `.RData` 和 `.Rhistory` 相同的文件夹中创建文件 `.Rprofile`。如果该文件尚不存在，此方法有效。如果文件已存在，编辑该文件即可。文件 `.Rprofile` 必须是纯文本文件，且没有扩展名。该文件告诉 R 在启动时要运行哪些函数。

在文件中添加行来运行 `options()` 可以设置默认选项。例如，`.Rprofile` 的内容可能如下：

```
options( defaultPackages=c( getOption( "defaultPackages" ), "MASS" ),
contrasts=c( "contr.sum", "contr.poly" ) )
```

这里，包 `MASS` 被添加到启动时加载的包中，无序因子的对比方式从默认的 `contr.treatment` 更改为 `contr.sum`。有关启动过程的更多信息，请在 R 提示符下输入 `?Startup`，或使用 R Studio 中的帮助选项卡。

一些选项包括：

* `continue` — 字符串 — 表示当 R 代码使用多行时 R 在控制台打印的内容 — 默认值为 `+`。
* `contrasts` — 字符串 — 在线性模型中用于因子数据的对比类型 — 无序对比的默认值为 `contr.treatment`，有序对比的默认值为 `contr.poly` — 其他可能的值有 `contr.sum` 和 `contr.helmert` — 有关对比的详细信息，请在 R 提示符下输入 `?contrasts`，或使用 R Studio 中的帮助选项卡。
* `defaultPackages` — 字符串 — R 运行时默认加载的包 — 默认值为 `datasets`、`utils`、`grDevices`、`graphics`、`stats` 和 `methods`（`base` 始终被加载）。
* `digits` — 整数 — 建议返回数字的位数 — R 不一定使用建议的位数 — 默认值为 `7`。
* `editor` — 字符串 — 指定函数 `edit()` 调用的编辑器 — 默认值因操作系统而异 — 更多信息请参见 `edit()` 的帮助页面。
* `expressions` — 整数 — 嵌套的最大深度 — 值可以在 25 到 500,000 之间 — 默认值为 `5000`。
* `na.action` — 指定函数的字符串 — 设置缺失值的处理选项 — 默认值为 `na.omit` — 其他值有 `na.fail`、`na.pass` 和 `na.exclude` — 更多信息请参见 `na.omit()`、`na.fail()`、`na.pass()` 和 `na.exclude()` 的帮助页面。
* `scipen` — 整数 — 一个选项，使 R 倾向于使用科学记数法（负整数）或固定记数法（正整数） — 更多信息请参见 `options()` 帮助页面 — 默认值为 `0`。
* `show.coef.Pvalues` — 逻辑值 — 一个选项，告诉 R 是否在线性模型的 `summary()` 输出中显示 p 值 — 默认值为 `TRUE`。
* `show.signif.stars` — 逻辑值 — 一个选项，告诉 R 是否在线性模型的 `summary()` 输出中显示星号以指示显著性水平 — 默认值为 `TRUE`。
* `stringsAsFactor` — 逻辑值 — 告诉 `data.frame()` 和 `read.table()` 是否将字符字符串转换为因子 — 默认值为 `TRUE` — 是，转换字符串。
* `OutDec` — 单个字符串 — 设置小数点使用的字符 — 默认值为 `.`。
* `prompt` — 字符串 — 用作 R 提示符的字符 — 默认值为 `>`。
* `ts.eps` — 数值 — 比较多个时间序列中时间段的容差水平 — 默认值为 `1.0e-5`。

## 函数 `round()`、`signif()` 和 `noquote()`

函数 `round()`、`signif()` 和 `noquote()` 使输出更易于阅读。

### 函数 `round()`

函数 `round()` 将模式为 `numeric` 或 `complex` 的对象元素四舍五入到小数点后指定的位数。该函数接受两个参数：要四舍五入的对象 `x`，和位数 `digits`。`digits` 为负数时，四舍五入到小数点左侧的位数。例如：

```
> set.seed( 69235 )
> round( c( 1.2344, 5.67, 1234.567 ), 3 )
[1]    1.234    5.670 1234.567
> round( rnorm( 3 ) + 63, -1 )
[1] 60 60 60
> round( 1.34+3.0i, 1 )
[1] 1.3+3i
```

请注意，所有返回的值（如果存在小数点）都具有相同的小数位数，但复数的实部和虚部分别处理。`digits` 的默认值为零。如果 `x` 的最后一位数字等于 5，关于 `round()` 的四舍五入规则请参见其帮助页面。可以在 R 提示符下输入 `?round` 或使用 R 中的帮助选项卡找到该帮助页面。

### 函数 `signif()`

函数 `signif()` 将数值或复数对象的元素舍入到指定的有效数字位数。该函数接受两个参数：对象 `x` 和有效数字位数 `digit`。例如：

```
> set.seed( 69235 )
> signif( c( 1.2344, 5.67, 1234.567 ), 3 )
[1]    1.23    5.67 1230.00
> signif( rnorm( 3 ) + 63, -1 )
[1] 60 60 60
> signif( 1.34+3.0i, 1 )
[1] 1+3i
```

请注意，与 `round()` 类似，所有返回的数字都显示到相同的小数位数，但有效数字被限制为由 `digit` 给定的整数。如果为 `digit` 提供的值小于一，则有效数字位数设为一。`digit` 的默认值为六。有关 `signif()` 的更多信息，请在 R 提示符下输入 `?signif`，或使用 R Studio 中的帮助选项卡。

### `noquote()` 函数

`noquote()` 函数返回的输出中，对象内任何字符串的引号都会被移除。该函数接受一个参数 `obj`，可以是任何类型的对象。例如：

```
> noquote( c( " a", "bc", "d" ) )
[1]  a bc d
```

关于 `noquote()` 的更多信息，可以在 R 提示符下输入 `?noquote` 来获取。也可以通过 R Studio 的“帮助”选项卡来查找信息。

## `cat()` 函数

`cat()` 函数可用于将函数中的数据输出到控制台、文件或连接。函数名 `cat` 代表`连接`（concatenate）。要连接的对象必须是 `atomic` 模式，并用逗号分隔。这些对象会被强制转换为向量。除了要连接的对象外，该函数还有五个参数。

这五个参数分别是 `file`、`sep`、`fill`、`labels` 和 `append`。参数 `file` 告诉 `cat()` 将输出发送到哪里。该参数是一个字符串，可以是一个文件地址、一个连接，或者“”——如果控制台是标准输出 `stdout()`，则代表控制台，否则代表 `stdout()` 的值。默认值是“”。参数 `sep` 是一个字符串。`sep` 的值用于分隔输出中打印的对象。默认值是“ ”。

参数 `fill` 可以是一个逻辑变量或一个正数。如果是 `FALSE`，则使用 `\n` 或引号字符串内的换行符来设置换行。如果是 `TRUE`，则使用选项 `width` 的值来设置输出的宽度（宽度在 `options()` 中设置，表示一行中的字符数——包括空格——默认等于 30）。如果 `fill` 是一个正数，则使用该数字来设置宽度。默认值是 `FALSE`。

参数 `labels` 是一个字符串向量，用于标记输出行，并且仅在 `fill` 为 `TRUE` 或数值时使用。默认值是 `NULL`。参数 `append` 在 `file` 是外部文件时使用。如果为 `TRUE`，则输出会追加到文件中。否则，文件会被覆盖。默认值是 `FALSE`。

示例：

```
> set.seed( 69235 )
> x=1:4
> y= runif( 4 )
> a.lm=lm( y~x )
> a.sm=summary( a.lm )
> cat( "\n 截距是 ",  round( coef( a.lm )[1], 3 ), ". 斜率是 ",
round( coef( a.lm )[2], 3 ), ".  F 统计量是 ", round( a.sm$f[1], 4 ), " 自由度为 ",
a.sm$f[2], " 和 ", a.sm$f[3], "。 p 值是 ",
round( 1-pf( a.sm$f[1], a.sm$f[2], a.sm$f[3] ), 4 ), ".\n", sep="" )
截距是 -0.301. 斜率是 0.257.  F 统计量是 4.5039 自由度为 1 和 2。 p 值是 0.167
> cat( round( coef( a.lm )[1], 3 ), round( coef( a.lm )[2], 3 ), round( a.sm$f[1], 4 ),
a.sm$f[2], a.sm$f[3], round( 1-pf( a.sm$f[1], a.sm$f[2], a.sm$f[3]), 3 ),
fill=17, labels = c( "截距      ", "斜率      ",  "F          ",  "自由度 1 & 2  ",
"p 值      " ) )
截距       -0.301
斜率       0.257
F           4.5039
自由度 1 & 2   1 2
p 值        0.168
```

关于 `cat()` 的更多信息，可以在 R 提示符下输入 `?cat` 或使用 R Studio 的“帮助”选项卡来获取。

## 格式化与绘图函数

### `format()`、`print()`、`plot()` 和 `summary()` 函数概览

`format()`、`print()`、`plot()` 和 `summary()` 函数的行为取决于它们所操作的对象的类。它们是泛型函数，并且为其定义了方法（它们的行为方式）。在 S3 中，方法是已经创建好的。在 S4 中，方法由用户根据其定义的类来创建。本节介绍这四个函数的 S3 方法。

对于给定函数，若要查看具有该函数特殊方法的对象类，请在 R 提示符下输入 `methods('function')`，其中 `function` 是函数名。在 R Studio 中，在“帮助”选项卡下的搜索框中输入函数名，会打开一个下拉菜单，菜单中显示函数名后跟一个句点，然后是函数对应的类名，例如：`plot.acf`。菜单按字母顺序排列。如果菜单长度超过可用空间，在句点后输入一个字母会列出以该字母开头的类。

如果对象的类具有特殊函数，即使未包含类扩展名，R 也会自动对该对象使用该特殊方法。例如，如果 `a.ts` 是一个时间序列，则 `plot(a.ts)` 和 `plot.ts(a.ts)` 会给出相同的结果。如果对象类没有特殊函数，则使用默认方法（如果存在默认方法的话）。有关默认方法的信息，请在 R 提示符下输入 `?function.default`，其中 `function` 是函数名；例如，`?plot.default`。或者使用 R Studio 的“帮助”选项卡。

### `format()` 函数

在我使用的 OS X 系统上，`format()` 函数有 73 种方法（包括默认方法）。该函数返回原子对象的字符版本，并且对于许多列表对象，返回列表的简化字符版本。该函数接受多个参数，这些参数可以结构化输出，以获得视觉上美观的结果。参数因方法而异。例如：

```
> a.date = as.Date( 1:4, "2014-3-9" )
> a.date
[1] "2014-03-10" "2014-03-11" "2014-03-12" "2014-03-13"
> format(a.date, "%m/%d/%Y")
[1] "03/10/2014" "03/11/2014" "03/12/2014" "03/13/2014"
> a.list = list( c( "a", "b", "c" ), matrix( 1:4, 2, 2 ) )
> dimnames( a.list[[2]] ) = list( c( "r1", "r2" ), c( "c1", "c2" ) )
> a.list
[[1]]
[1] "a" "b" "c"
[[2]]
c1 c2
r1  1  3
r2  2  4
> format( a.list )
[1] "a, b, c"    "1, 2, 3, 4"
```

有关 `format()` 的更多信息，请在 R 提示符下输入 `?format` 或 `?format.'ext'`，其中 `ext` 是类的扩展名。可以通过在 R 提示符下输入 `methods(format)` 或按照上述说明在 R Studio 中查找扩展名。

### `print()` 函数

`print()` 函数用于打印对象。在我使用的 OS X 系统上，该函数有 209 种方法（包括默认方法）。根据要打印对象的类，这些函数可以接受多种参数。许多类都可用的一些有用参数包括：`quote`，一个逻辑参数，告诉 `print()` 是否打印引号；`print.gap`，一个整数参数，告诉 `print()` 在矩阵、数组和数据框的列之间放置多少个空格；以及 `right`，一个逻辑参数，告诉 `print()` 是右对齐还是左对齐字符串。例如：

```
> a.mat = matrix( paste( "m", 1:8, sep="" ), 2, 4 )
> print( a.mat )
[,1] [,2] [,3] [,4]
[1,] "m1" "m3" "m5" "m7"
[2,] "m2" "m4" "m6" "m8"
> print( a.mat, quote=F, right=T, print.gap=3 )
[,1]   [,2]   [,3]   [,4]
[1,]     m1     m3     m5     m7
[2,]     m2     m4     m6     m8
```

要查找有关 `print()` 和各种打印方法的更多信息，请在 R 提示符下输入 `?print` 或 `?print.'ext'`，其中 `ext` 是对象类的扩展名，或者使用 R Studio 的“帮助”选项卡。

### `plot()` 函数

`plot()` 函数是用于绘图的函数之一。在我使用的 OS X 系统上，该函数有 30 种方法（包括默认方法）。在 R 中绘图可以从简单的描述性绘图到非常复杂的绘图。这个主题值得专门用一本书来介绍；因此，此处不再赘述。关于 `plot()` 的信息，可以通过在 R 提示符下输入 `?plot` 或 `?plot.'ext'` 来获取，其中 `ext` 是待绘图对象类的扩展名，或者使用 R Studio 的“帮助”选项卡。

## 一些模型函数：`anova()`、`coef()`、`effects()`、`residuals()`、`fitted()`、`vcov()`、`confint()` 和 `predict()`

虽然 `print()`、`plot()` 和 `summary()` 对于像 `lm` 和 `glm` 这样的模型类有特殊的方法，但这些函数也涵盖了许多其他类。函数 `anova()`、`coef()`、`effects()`、`residuals()`、`fitted()`、`vcov()`、`confint()` 和 `predict()` 是泛型函数，专为模型编写。

在本节的示例中，我们使用以下线性模型：

```
> set.seed( 69235 )
> x=1:5
> y = rnorm( 5 )
> a.lm = lm( y~x )
```

函数 `anova()` 在我的 OS X 系统上有 7 个方法，并返回模型的方差分析表。例如：

```

x          1 0.00198 0.00198  0.0052 0.9469
Residuals  3 1.13477 0.37826
```

函数 `coef()` 在我的 OS X 系统上有 6 个方法（包括 `default` 方法），并返回模型的系数。例如：

```

(Intercept)           x
```
