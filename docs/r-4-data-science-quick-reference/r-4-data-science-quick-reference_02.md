# 1. 引言

R 是一种专注于统计分析的函数式编程语言。它内置支持将模型规格作为一等对象进行操作，并拥有大量用于处理概率分布和模型拟合的函数集合，这些函数既包含内置的，也通过扩展包提供。

该语言有着悠久的历史。它创建于 1992 年，并基于更古老的语言 S（始于 1976 年）。多年来，语言中引入了许多特性和不一致之处。例如，至少有三种部分不兼容的方式来实现面向对象编程，其中一种基于的命名约定与某些内置函数冲突。驾驭 R 语言的众多特性可能颇具挑战性，但一套统称为“Tidyverse”的扩展包缓解了这一问题。

虽然许多数据科学应用涉及更复杂的数据结构，如图和树，但大多数日常工作分析涉及的是矩形数据。也就是说，分析的数据可以结构化为由行和列组成的表格，其中行通常对应观测值，列对应解释变量和观测结果。通常的数据集大小也可以加载到内存中，并在单个台式机或笔记本电脑上进行分析。在此我假定情况如此。如果不是这样，那么你需要不同的、超出本书范围的大数据技术。

Tidyverse 是 R 语言的一系列扩展：这些包主要旨在分析适合计算机内存的表格数据。部分包的功能超出了这一范围，但由于数据科学主要涉及表格数据的操作，因此本书重点关注这一点。

Tidyverse 包提供一致的命名约定、一致的编程接口，更重要的是，提供一种一致的符号来表示数据分析如何由不同的数据操作和模型拟合步骤组成。

这些包不仅提供了用于操作数据的函数集合，还为分析的各个方面提供了微小的领域特定语言。几乎所有这类微小语言都基于由`magrittr`包引入的相同整体“管道”语法。该包引入了一种语法，用于将一个函数调用的输出发送到另一个函数调用。它为此提供了各种运算符，但最常用的是`%>%`，它为你编写函数调用提供了一种替代语法：

```
x %>% f() %>% g()
```

等价于

```
g(f(x))
```

该语法被认为非常有用，以至于在 R 4.1 版本中将一个类似的运算符`|>`引入了主 R 语言，因此现在你也会看到如下语法：

```
x |> f() |> g()
```

在方便的时候，我会在代码示例中使用内置的管道运算符`|>`，但我会将`magrittr`语法留到第 6 章之后，届时我将描述`magrittr`包。

这两个运算符并不相同，我将在第 6 章中强调一些差异。它们在几个方面有所不同，但你可以在使用 Tidyverse 包时使用其中任何一个，并且这些包通常设计为假设你以这种方式使用它们。

一个显著的例外是绘图库`ggplot2`。它比 Tidyverse 中的其他扩展略旧，因此具有不同的语法。主要区别在于用于组合不同操作的运算符。数据管道符号使用`%>%`或`|>`运算符，而`ggplot2`使用`+`来组合绘图指令。如果你像我一样，那么你经常会出于习惯尝试使用`%>%`组合`ggplot2`指令——但一旦从 R 收到错误，你就会意识到自己的错误并可以快速修正。

本书是一本现代数据科学在 R 中语法的参考指南，这意味着它是一本使用 Tidyverse 包的指南，也是一本面向希望使用 R 的 Tidyverse 包而不是基础 R 编程的程序员的指南。我将假设你熟悉基础 R 及其中的函数，或者至少能够阅读这些函数的文档，例如，当你想知道函数`read.table()`的行为时，你可以在 R 控制台中输入`?read.table`。当 Tidyverse 函数中的类似功能与基础 R 函数不同时，我会在文中提及基础 R 函数。这可以提醒你，如果你熟悉基础 R 函数并且可能有代码使用它们，并且你想将这些代码移植到 Tidyverse 代码中。如果你不熟悉基础 R，并希望获得核心 R 语言的参考资料，你可能希望阅读 Margot Tollefson 所著的 *R Quick Syntax Reference* 一书。

本指南并未详尽解释每个 Tidyverse 包。Tidyverse 包的开发进展迅速，本书在印刷后不久可能就不会包含完整的指南。然而，这些扩展及其提供的领域特定语言的结构是稳定的，通过其中部分功能的示例，你应该能够毫无困难地阅读每个包的文档，并找到本书未涵盖但你需要的功能。

要开始使用 Tidyverse，请安装并加载它：

```
install.packages("tidyverse")
library(tidyverse)
```

Tidyverse 由许多包组成，你可以独立安装和加载它们，但通过`tidyverse`包一次性加载是最简单的方法。因此，除非你有充分的理由（例如，你需要一个未自动加载的包），否则在开始分析时只需加载`tidyverse`。在本书中，我描述了三个不是从`tidyverse`加载但通常被认为属于 Tidyverse 的包。^(¹)
