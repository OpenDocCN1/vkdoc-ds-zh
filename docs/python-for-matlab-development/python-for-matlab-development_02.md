## 致谢

Rachel Rybarczyk 关于 MATLAB 和 Python 的评论激励我踏上了撰写本书的旅程。

Alain Sei 在意识到未来工作之艰巨后，虽辞去合著者一职，但依然作为我的首位读者留了下来。在 R2 楼的每周例会上，Alain 总是提出发人深省的观点，让我保持视角的新鲜感。

Rocco Samuele 帮助提升了文本的文学质量。虽然我没有 Rocco 在文字方面的功力，但他的编辑建议让我的写作更加清晰明了。

当 Curtis Webb 四年前第一次向我介绍`Numba`时，我对他声称无需 C/C++/Fortran 编译器就能让 Python 函数运行速度快 10 倍、甚至 30 倍的说法嗤之以鼻。不可能！然而，就像一种神奇的外星科技，`Numba`确实做到了。这是有史以来最好的提示，谢谢，Curtis！

Parker Hudnut 对本书的整体结构提出了宝贵的“大局观”建议。谢谢！下次我们在 H 楼见面时，啤酒我请。
