# 致谢

开发一个全功能的数值分析系统非常复杂。撰写一本深入探讨其架构的书籍则是一项更具挑战性的任务。这不仅需要技能、热情和毅力，还需要来自家庭、同事和社区的强大支持。多年来，我们得到了许多个人和组织的帮助，几乎无法详尽列出。尽管如此，我们特别要强调，Owl 是建立在大量先前工作的基础之上开发的。没有这些项目多年的持续努力以及这些人的智力贡献，我们不可能创建这个系统并交付这本书。

我们衷心感谢所有为 Owl 项目做出贡献的人。Marcello Seri 和 Ta-Chu Kao 开发了`owl-ode`，这是一个基于 Owl 的常微分方程求解器库。Pierre Vandenhove 在剑桥 OCaml 实验室实习期间，负责计算图模块的内存优化工作。Tudor Tiplea 参与了 Owl 基础库的开发，使其能够在浏览器等多种后端上运行。Ben Catterall 关于 PSP 的论文工作为 Actor 系统提供了理论基础。

我们谨向 OCaml 软件基金会^(¹)和 Ahrefs^(²)表示最诚挚的感谢和赞赏，感谢他们全额赞助这本开放获取书籍，以及他们对 Owl 项目的长期支持。
