# 构建函数

你也可以通过拼接各个组成部分来构建新的函数。用于此目的的函数是 `as.function`。它接受一个 `alist` 作为输入，并将其中的最后一个元素解释为新函数的主体，其余元素解释为形式参数。

```
f <- as.function(alist(x =, y = 2, x + y))
f
## function (x, y = 2)
## x + y
f(2)
## [1] 4
```

不要试图在这里使用 `list`；它不会按你的预期工作。

```
f <- as.function(list(x = 2, y = 2, x + y))
```

如果你给 `as.function` 一个列表，它会将其解释为一个表达式，然后这个表达式会成为新函数的主体。在这里，如果你有全局定义的 `x` 和 `y` 以便能够计算 `x + y`，那么你会得到一个主体为 `c(2, 2, x+y)` 的函数，其中 `x+y` 引用的是全局变量 `x` 和 `y` 的和的值，而不是它们的表达式。

新函数的环境默认是调用 `as.function` 时的环境。因此，要创建一个闭包，你只需在另一个函数内部调用 `as.function` 即可。

```
nested <- function(z) {
function(x, y = z) x + y
}
```

这里你在 `nested` 内部调用了 `as.function`，因此在此创建的这些函数的环境将会知道 `nested` 的参数 `z`，并能够在 `y` 的默认值中使用它。

不要尝试这样写：

```
nested <- function(y) {
as.function(alist(x =, y = y, x + y))
}
```

请记住，作为默认参数的表达式会在你定义的函数主体内部进行惰性求值。这里，你指定 `y` 应该求值为 `y`，这是一个循环依赖。这与 `as.function` 无关。你在下面的定义中也会遇到同样的问题：

```
nested <- function(y) {
function(x, y = y) x + y
}
```

如果你想要类似的功能，即创建一个具有给定默认值 `y` 的函数，并且你绝对希望所创建的函数将该参数命名为 `y`，那么你需要在嵌套作用域中对表达式求值，并使用不同的名称来引用它，以避免嵌套函数的参数遮蔽它。

```
nested <- function(y) {
z <- y
function(x, y = z) x + y
}
nested(2)(2)
## [1] 4
```

如果你不希望新函数的环境是当前环境，你可以为 `as.function` 指定一个环境，以明确其定义域。在下面的例子中，你有两个用于构建闭包的函数。第一个创建的函数可以看到包围它的 `z`，而另一个则使用了全局环境，因此根本不是闭包，所以参数 `z` 不可见。相反，全局的 `z` 是可见的。

```
nested <- function(z) {
as.function(alist(x =, y = z, x + y))
}
nested2 <- function(z) {
as.function(alist(x =, y = z, x + y),
envir = globalenv())
}
```

如果你对用这两个函数创建的函数进行求值，`nested` 创建的那个会将 `x` 与你在调用 `nested` 时提供的 `z` 值相加，而 `nested2` 创建的那个则会忽略其输入，并在全局作用域中寻找 `z`。

```
z <- -1
nested(3)(1)
## [1] 4
nested2(3)(1)
## [1] 0
```
