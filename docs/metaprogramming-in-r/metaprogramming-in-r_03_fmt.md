# 修改函数

你不仅能检查函数，还能做更多操作。用于检查的三个函数也各有赋值版本，你可以利用它们修改函数的三个组成部分。回到`f`的简单定义：

```
f <- function(x) x
f
## function(x) x
```

你可以尝试通过为`x`设置默认值来修改其形式参数：

```
formals(f) <- list(x = 3)
f
## function (x = 3)
## x
```

此时，由于`x`有了默认值，你可以在其形式参数的环境中计算函数体：

```
eval(body(f), formals(f))
## [1] 3
```

不过，我要再次强调，调用函数并不是简单地在形式参数上下文中计算函数体。当函数被调用时，你在其定义之外修改形式参数并不影响实际执行。形式参数仍会在函数定义时的环境中被计算。

如果你定义一个闭包，就能看到这一点：

```
nested <- function() {
y <- 5
function(x) x
}
f <- nested()
```

由于`f`是在`nested`的计算环境中定义的，因此`environment(f)`就是那个环境。当你调用它时，它就能看见`nested`中的局部变量`y`。它并没有引用这个变量，但你可以通过修改其形式参数来改变这一点：

```
formals(f) 
```

这里，你必须使用`quote`函数来让`y`成为一个名称。如果不这样做，你会遇到错误，或者得到对全局环境中`y`的引用。在函数定义中，默认参数会被自动引用（quote）以转化为表达式，但当你修改`formals`时，你需要显式地执行这一操作。

如果你现在调用不带参数的`f`，`x`将采用`formals(f)`指定的默认值。也就是说，它会引用`y`。由于这是一个默认参数，它会被转化为一个promise，并在`f`的计算环境中求值。那里没有名为`y`的局部变量，因此R会在`environment(f)`中查找`y`，并在`nested`环境中找到它：

```
f()
## [1] 5
```

仅仅因为你在全局环境中修改了`formals(f)`，并不会改变R计算默认参数promise的环境。即使有一个全局变量`y`，`f`形式参数中的`y`仍然引用`nested`中的那个：

```
y <- 2
f()
## [1] 5
```

当然，如果你在调用`f`时显式提供参数`y`，情况就不同了。此时它会变成一个应在调用环境中计算的promise，因此在这种情况下，你得到的是对全局变量`y`的引用：

```
f(x = y)
## [1] 2
```

你也可以修改`f`的函数体。例如，不让函数体引用`x`，而是让它返回常量6：

```
body(f) 
```

现在，当我们调用它时，无论`x`是什么，它都会计算那个常量6：

```
f()
## [1] 6
f(x = 12)
## [1] 6
```

你还可以尝试让`f`的函数体更复杂，使其成为一个实际的表达式：

```
body(f) <- 2 * y
f()
## [1] 4
```

然而，这里你并没有得到完全想要的结果。你并不希望在调用函数之前就计算函数体，但当你像这样赋值时，在赋值之前你就已经计算了它。惰性求值（lazy evaluation）也有其限度。由于`y`是2，你实际上是将`f`的函数体设置成了4。之后再改变`y`也不会改变这一点：

```
y <- 3
f()
## [1] 4
```

要得到一个未经计算的函数体，你必须再次使用`quote`：

```
body(f) 
```

但现在，你又回到了函数调用的语义，这意味着函数体是在一个父环境为`nested`内部环境的计算环境中求值的，因此`y`引用的是局部变量，而非全局变量：

```
f()
## [1] 10
y <- 2
f()
## [1] 10
```

如果你想让`f`使用全局变量`y`，可以修改`environment(f)`：

```
environment(f) <- globalenv()
f()
## [1] 4
y <- 3
f()
## [1] 6
```

不过，如果这样做，它就不再知晓`nested`内部的环境了。如果你想挑选函数在哪些环境中查找变量，需要大量的环境操作（environment hacking）；如果你的确有此需求，那么最好重写函数，通过其他方式访问变量。

如果你想将函数的形式参数设置为缺失值（即让它们成为没有默认值的参数），那么你需要使用`list`来创建参数。

如果你像这样定义一个函数`f`，它接受一个参数`x`，并将其与一个全局参数`y`相加：

```
f <- function(x) x + y
```

如果你希望`y`也是一个参数，但不给它默认值，你可以尝试这样：

```
formals(f) <- list(x =, y =)
```

但这行不通，因为`list`不接受空值。相反，你可以使用`alist`。这个函数创建了一个“成对列表”（pair-list），这是R内部用于表示形式参数的数据结构。这种数据结构仅用于此目的，但如果你要着手修改函数的参数，它就是你应该使用的工具：

```
formals(f) <- alist(x =, y =)
```

使用`alist`时，表达式也会被自动引用。在前面的例子中，当你希望参数`x`默认值为`y`时，需要使用`quote(y)`来让`y`作为一个promise在`environment(f)`中计算，而不是在调用作用域中计算。使用`alist`时，你不需要引用`y`：

```
nested 
f()
## [1] 5
```
