# 1. 函数的剖析

你在 R 中所做的一切都涉及定义函数或调用函数。如果不求值某个函数，你无法执行任何操作。即使是将值赋给变量或对向量或列表进行下标操作，也涉及求值函数。但函数不仅仅是关于如何执行不同操作的配方；它们本身也是数据对象，并且有探查和修改它们的方法。

## 操作函数

如果你定义一个像下面这样的简单函数，就可以检查它的组成部分：

```r
f <- function(x) x
```

一个函数包含三个部分：形式参数 (formal parameters)、函数体 (body) 以及它被定义的环境 (environment)。函数 `formals`、`body` 和 `environment` 可以获取这些部分：

```r
formals(f)
## $x
body(f)
## x
environment(f)
## <environment: R_GlobalEnv>
```

### 形式参数 (Formals)

形式参数以列表形式给出，其中元素名称是参数名，值是默认参数。

```r
g <- function(x, y = 1, z = 2) {
    parameters <- formals(g)
    for (param in names(parameters)) {
        cat(param, "=>", parameters[[param]], "\n")
    }
}
g()
## x => 
## y => 1
## z => 2
```

严格来说，它是一个所谓的“配对列表 (pairlist)”，但这是一个实现细节，对你如何处理它没有影响。你可以把它当作一个 `list` 来处理。

```r
g <- function(x, y = 1, z = 2) {
    parameters <- formals(g)
    for (param in names(parameters)) {
        cat(param, "=>", '"', parameters[[param]], '"', "\n", sep = "")
    }
}
g()
## x => ""
## y => "1"
## z => "2"
```

对于此列表中那些没有默认值的变量，该列表将其值表示为空名称。这是一个特殊的符号，你不能给它赋值，因此它不会与真实值混淆。你不能使用 `missing` 函数来检查 `formals` 函数中的缺失值（该函数仅在函数调用内部有用，并且无论如何，缺失参数与没有默认值的参数之间是有区别的），但你始终可以检查该值是否为空符号。

```r
g <- function(x, y = 1, z = 2) {
    parameters <- formals(g)
    for (param in names(parameters)) {
        cat(param, "=>", '"', parameters[[param]], '"',
        " (", class(parameters[[param]]), ")\n", sep = "")
    }
}
g()
## x => "" (name)
## y => "1" (numeric)
## z => "2" (numeric)
```

原始函数 (Primitive functions) (那些调用运行时系统的函数，例如 `+`) 没有形式参数。只有那些在 R 中定义的函数才有。

```r
formals(`+`)
## NULL
```

### 函数体 (Function Bodies)

函数体是一个表达式。对于 `f`，它是一个简单的表达式。

```r
body(f)
## x
```

但即使是多语句的函数体也是表达式。它们只是求值为序列中最后一个表达式的结果。

```r
g <- function(x) {
y <- 2*x
z <- x**2
x + y + z
}
body(g)
## {
##     y <- 2 * x
##     z <- x**2
##     x + y + z
## }
```

当调用一个函数时，R 会为其设置一个环境来求值这个表达式；这个环境被称为该函数调用的求值环境。求值环境首先会被填充函数形式参数的值，这些值要么在函数调用中提供，要么作为默认参数给出，然后函数体在这个环境中执行。赋值操作将修改这个局部环境，除非你使用 `<<-` 运算符，而函数的结果是函数体中被求值的最后一个表达式。这要么是序列中的最后一个表达式，要么是显式传递给 `return` 函数的表达式。

当你只是将函数体作为一个表达式时，你无法获得这种函数调用语义，但你仍然可以尝试求值该表达式。

```r
eval(body(f))
## Error in eval(expr, envir, enclos): object 'x' not found
```

它失败了，因为你在任何地方都没有定义变量 `x`。如果你有一个全局变量 `x`，求值就会使用那个变量，而不会使用任何函数参数，因为这个表达式不知道它是函数的一部分。如果我们调用该函数，表达式当然会知道函数上下文，但当我们像这样简单地求值函数体时则不会。不过，你可以像这样为 `x` 提供一个值：

```r
eval(body(f), list(x = 2))
## [1] 2
```

`eval` 函数用于求值一个表达式，并使用第二个参数来查找参数。你可以给它一个环境，然后表达式将在该环境中被求值，或者你可以使用一个列表。第 3 章介绍了如何处理表达式以及如何求值它们；现在你只需要知道，如果表达式中的变量可以在你调用 `eval` 的作用域中找到，或者提供给 `eval` 的第二个参数中，你就可以使用 `eval` 来求值一个表达式。

你还可以将 `x` 设置为一个默认参数，并在求值表达式时使用它。

```r
f <- function(x = 2) x
formals(f)
## $x
## [1] 2
eval(body(f), formals(f))
## [1] 2
```

如果默认参数相互引用，事情会变得稍微复杂一些。这与求值环境的设置方式有关，而与表达式如何求值关系不大，但请考虑以下示例，其中一个默认参数引用另一个：

```r
f <- function(x = y, y = 5) x + y
```

两个参数都有默认值，因此你可以在不提供任何参数的情况下调用 `f`。

```r
f()
## [1] 10
```

但是，如果仅仅基于形式参数而不提供值，你是无法求值的。

```r
eval(body(f), formals(f))
## Error in x + y: non-numeric argument to binary operator
```

在 `formals(f)` 中，`x` 指向符号 `y`，而 `y` 指向数值 5。但 `y` 并没有在表达式中使用，如果你只是查找 `x`，你只会得到符号 `y`，并且你不会进一步求值以找出 `y` 是什么。因此，你会得到一个错误。

形式参数在调用函数时不会以这种方式求值。它们会被转换成所谓的“承诺 (promises)”，即带有相关作用域的未求值表达式。形式语言定义是这样描述的：

- 当调用一个函数时，每个形式参数会在调用的局部环境中被分配一个承诺，其表达式插槽包含实际参数（如果存在），环境插槽包含调用者的环境。如果在调用中没有为某个形式参数提供实际参数，并且存在默认表达式，则该表达式类似地被分配到形式参数的表达式插槽中，但环境被设置为局部环境。

这意味着在求值环境中，R 首先将所有变量赋给这些“承诺”。承诺是值的占位符，但以你尚未求值的表达式形式表示。然而，一旦你访问它们，它们就会被求值（并且 R 会记住该值）。对于默认参数，承诺会在求值环境中被求值；对于在函数调用中传递给函数的参数，承诺会在调用作用域中被求值。

由于所有承诺都是未求值的表达式，你不必担心变量赋值的顺序。只要在求值承诺时这些变量存在，就不会有问题；只要表达式之间没有循环依赖，你就可以在需要时找出所有值。

不要制造循环依赖。不要做类似这样的事情：

```r
g <- function(x = 2*y, y = x/2) x + y
```

你可以尝试为 `f` 建立一个类似的设置，将其形式参数构建为一个包含承诺的环境。你可以使用 `delayedAssign` 函数像这样将值赋给承诺：

```r
fenv <- new.env()
parameters <- formals(f)
for (param in names(parameters)) {
    delayedAssign(param, parameters[[param]], fenv, fenv)
}
eval(body(f), fenv)
## [1] 10
```

这里你将表达式 `y` 赋给变量 `x`，将值 5 赋给变量 `y`。像数值向量这样的原始值不会作为未求值表达式来处理。它们可以被这样处理，但没有必要。因此，在求值 `f` 的函数体之前，环境中有 `y` 指向 5，`x` 指向表达式 `y`，后者被包装成一个承诺，表示当你需要知道 `y` 的值时，该表达式应在 `fenv` 中被求值。

### 函数环境

函数的环境是其最简单的组成部分。它只是函数被定义时所处的环境。这个环境用于捕获外部作用域，也是 R 语言能够实现闭包的原因。当函数创建时，其计算环境会与函数环境相关联，这样，在局部环境（由局部变量和形式参数组成）中找不到的变量，就会到外部作用域中去查找。
