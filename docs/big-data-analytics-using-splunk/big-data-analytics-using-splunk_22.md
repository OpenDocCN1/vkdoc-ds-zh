# 关于作者

![image](img/9781430257615_unFM-01.jpg)

**彼得·扎德罗兹尼** 是软件行业的资深人士。他是 Opallios 公司的创始人兼首席技术官，该公司专注于利用大数据和云技术的力量，同时通过外包产品开发为客户创造价值。彼得还在圣何塞州立大学讲授大数据相关主题。他曾在全球多个国家的初创公司和财富 500 强企业中担任各种高管和技术职务。其职业生涯亮点包括在欧洲启动 WebLogic 的业务以及在墨西哥启动 Sun Microsystems 的业务。他是一位成就卓著的作家，撰写了多本关于 Java 企业版和性能工程的成功著作，并且是流行开源项目 The Grinder 的原始贡献者。

![image](img/9781430257615_unFM-02.jpg)

**拉古·科达利** 是 Solix Technologies 的产品管理与战略副总裁，负责产品愿景、管理、战略、用户设计和交互。他的工作包括下一代数据优化平台、行业领先的数据发现平台、企业数据管理即服务、以及使用大数据平台和云进行应用开发。在加入 Solix 之前，他在甲骨文公司工作了 12 年，担任高级管理职位，负责 Oracle Fusion Middleware 产品的产品管理与战略。此外，拉古还是甲骨文的 SOA 布道者，领导着下一代 Java EE 计划。拉古撰写了关于 Java 计算的主要技术参考书《Beginning EJB 3 Application Development: From Novice to Professional》（Apress，2006 年），并发表了大量关于企业技术的文章。他还是《Oracle Information Integration, Migration and Consolidation》（PACKT Publishing，2011 年）的合著者之一。
