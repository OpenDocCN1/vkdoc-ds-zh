# 逐字文本

有时，你希望文本完全不应用任何格式；希望按原样逐字显示。当你有此需求时，你可以用制表符（或四个空格）对其进行缩进。你可以这样编写：

```
这将以逐字显示
绝对原样显示
```

结果将如下所示：

```
这将以逐字显示
绝对原样显示
```

有时，你也希望在段落内内联添加逐字文本。要实现这一点，只需将逐字文本放在反引号内即可。因此你可以编写 `` `'this'` `` 来实现 `this`。

## 链接

Markdown 最初是为了让编写网页内容更容易而创建的。因此，它内置了插入超文本链接的语法。这些链接既适用于网页链接，也适用于文本内部的交叉引用。

你有两种方式指定链接：你可以在插入链接的位置放置目标 URL，或者创建一个标签并将其映射到 URL，这样在插入链接时就可以引用该标签。要在插入链接的位置放置 URL，你需要将要作为链接的文本放在方括号内，并立即在后面用圆括号括上链接的目标 URL。你可以这样编写文本：

```
这是一个指向[我的博客](http://www.mailund.dk)的链接。
```

这在大多数情况下没问题，但如果你在一个段落中有很多链接，那么链接注释就会开始干扰文本的可读性。相反，你可以给目标链接一个更短的名称，并将目标定义放在文本后面。要做到这一点，你需要将圆括号替换为方括号，如下所示：

```
这是一个指向[我的博客][blog]的链接。
```

然后，在后面的文本中，你这样定义链接指向的目标：

```
[blog]: http://www.mailund.dk
```

你使用相同的语法来制作文档内部的超文本链接。创建指向某个章节的链接最简单的方法是省略目标，而是将章节名称放在方括号内。指向本章的链接可以这样编写：

```
这是一个指向[编写 Markdown]章节的链接。
```

当然，如果你希望链接包含不同于章节名称的文本，或者你有几个同名的章节，这种方法就行不通了。你可以通过给章节标题添加显式标签来解决这个问题。这些标签需要放在章节标题后面的花括号内。你可以这样为标题分配标签：

```
## 我的标题 {#header}
```

这里需要井号，并且在链接到该章节时也需要井号。井号在 HTML 中用于引用网页的各个部分，Markdown 正是从那里继承的语法。为了链接到我们这样标记的章节，我们可以这样编写链接：

```
这是一个指向该章节的链接。
```

链接仅对超文本文档有用，在标准 Markdown 中，你无法创建对图表或任何非章节元素的交叉引用。在 Pandoc 中，你可以通过扩展来实现，但我们会在第 7 章中介绍。

## 图片

要在文档中插入图片，你需使用与插入链接类似的语法。区别在于你需要在链接前加一个感叹号 `!`。

```
![图片标题](img/图片-URL)
```

通常，你会将图片作为本地文件，并使用图片文件的路径，可以是相对于构建文档位置的路径，也可以是绝对路径。

```
![图片标题](img/我的图片)
```
