# 前言

在我从事 SEO 行业的 17 年间，我们所能获取的数据发生了巨大变化。虽然我们失去了分析级别的关键词数据以及雅虎站点浏览器，但我们在大数据、专有指标，甚至来自谷歌搜索控制台的官方数据方面获得了大量机遇。

你不需要会编程也能成为一名高效的 SEO 专家。但有一种特定的方法和思维方式，能从处理各种形式的数据中获益。如果你偏好这种工作方式，你很快就会遇到电子表格和文本编辑器的极限。这时，你最好转向更强大的工具，来帮助你扩展能力范围，完成那些没有计算机辅助甚至无法完成的任务，并加速流程的每一步。

编程语言有很多种，学习它们的方式也多种多样。有些人会告诉你只有一种正确的方法。我不是那种人，但多年来我个人首选一直是 Python。我最初喜欢它是因为它相对简单且易于上手，并且很快就沉迷于能够通过一行代码导入他人编写的强大功能的魔力之中。随着我对这门语言更深入的了解，并开始领悟“Pythonic”的做事方式，我逐渐欣赏起这门语言的简洁与清晰。我不是专家，当然也不是专业的软件工程师，但我希望这能让我成为本书所阐述方法的强力倡导者——因为我正是其目标受众。

在大学期间，我学习了神经网络等诸多课程。当时，它们在运筹学中还是相当抽象的概念。在 90 年代末的那个时候，还没有现成的计算能力和庞大的数据集来实现隐藏在这些节点、边和统计关系中的机器学习能力。我一直对可能性着迷，借助神奇的导入语句和非常成熟的框架，我甚至能够用 Python 构建并训练自己的神经网络。作为一个统计极客，我喜欢其底层全是统计学的本质，同时，我也欣赏计算机能够完成人类无法做到的事情之美。

大学毕业后几年，我与联合创始人邓肯·莫里斯共同创立了 SEO 机构 Distilled，我们鼓励 SEO 顾问们利用手头的数据和工具。这带来了有趣的创新——既有分散式的，即个别顾问编写脚本和笔记本以帮助他们扩展工作、提高速度或效率；也有集中式的，即我们的研发团队。

那个研发团队后来构建了后来成为 SearchPilot 的平台，并开启了我职业生涯的最新阶段，在这个阶段，我们大力倡导在 SEO 中基于数据做出决策。我们正在构建企业级 SEO A/B 测试平台，以帮助全球最大的网站证明其站内 SEO 举措的价值。所有这些都使用了与后续章节中概述的类似技术，来决定如何实施测试、如何从各种 API 获取数据，以及如何用神经网络分析结果。

我相信，随着谷歌在其排名算法中越来越多地应用自己的机器学习技术，SEO 从根本上变得更加困难，因为系统变得更难预测，并且在不同网站、关键词和主题之间的差异更大。正是出于这个原因，我将如此多的时间、精力以及我职业生涯的下一个阶段投入到数据驱动 SEO 的领域。我希望这本书能够引导全新一代的 SEO 从业者走上类似的道路。

我是在十多年前于伦敦第一次见到安德烈亚斯的。这些年来，我见证了他所构建的一些成果，我相信他将是引导你穿越数据处理的复杂迷宫、在 SEO 世界中为你带来利益的绝佳向导。祝你编码愉快！

威尔·克里奇洛，SearchPilot 首席执行官
2022 年 9 月

# 我为何撰写此书

自 2003 年我（偶然）进入 SEO 领域以来，SEO 的实践发生了巨大变化。尽管许多重点仍放在获取反向链接上（无论是互惠链接、单向链接还是来自私密网络的链接，这些在游戏领域仍在使用），但其他要素已变得更为人熟知。这些要素包括：转型成为公认的品牌、制作对用户有价值的高质量内容、提供愉悦的用户体验、根据搜索意图制作和组织内容，以及（对于现在和未来而言）优化搜索旅程。

如今，许多要素已广为人知，但随着移动设备、社交媒体、语音搜索的兴起以及搜索引擎日益复杂，这些要素也变得更加复杂。现在比以往任何时候都更应注重细节。来自越来越多的第三方数据源和工具的数据比以往任何时候都多。仅靠电子表格是行不通的。你需要一把更锋利的刀，而数据科学（结合你的 SEO 知识）就是你最好的朋友。我为你创作了这本书，旨在让你的 SEO 工作以数据为驱动，从而发挥其最大潜力。

为什么是 2023 年的现在？因为新冠疫情的发生，让我有时间思考如何为世界，特别是 SEO 这个小众领域增加价值。更富远见的是，Twitter 和 LinkedIn 上有很多关于 SEO 从业者以及 Python 在 SEO 中应用的讨论。因此，我们觉得时机已到，因为 SEO 行业有需求，而我们也有知识可以分享。

我衷心祝愿你在作为数据驱动型 SEO 专家的新征程中一切顺利！

# 本书面向的读者

我们撰写本书旨在帮助您作为 SEO 专家在职业生涯中取得进步。无论您是为品牌、广告公司、咨询公司还是其他机构（请写信给我们介绍您自己！）工作，本书都将帮助您从一个不同的角度，甚至可能以一种全新的方式看待 SEO。我们为您设定的目标如下：

-   **以数据科学思维解决 SEO 挑战**：您将开始思考结果指标、数据源、用于向模型输入数据的数据结构，以及帮助您解决问题或至少消除围绕 SEO 挑战的一些错误信息所需的模型。所有这些都将使您更接近提出出色的 SEO 建议和拆分测试思路。

-   **对搜索引擎更深入的洞察**：您还将对谷歌等搜索引擎有更深刻的理解，并对它们可能如何对网站进行排名有更情境化的认识。毕竟，搜索引擎是计算机算法，而不是人，因此构建您自己的算法和模型来解决 SEO 挑战，将使您洞察搜索引擎可能如何奖励或不奖励网站及其内容的某些特征。

-   **可上手的代码**：自然学习的最佳方式就是动手实践。虽然有许多 SEO 课程，但最投入的 SEO 学生会建立自己的网站并测试 SEO 思路和实践。如果您想让您的 SEO 由数据驱动，那么 SEO 的数据科学也不例外。因此，我们将为您提供 Python 入门脚本，让您亲自尝试对页面和内容进行聚类、分析排名因素。大部分内容都会有代码，但并非全部，因为并非所有内容都已编写好代码（目前）。这些代码旨在帮助您入门，并且总可以进一步改进。

-   **熟悉 Python**：Python 是工业界数据科学的中流砥柱，尽管 R 语言仍被广泛使用。Python 是免费的（开源），并且在 SEO 社区、数据科学家和学术界都非常受欢迎。事实上，R 和 Python 在语法和结构上非常相似。Python 易于使用、阅读和学习。需要明确的是，我们绝不暗示或主张一种语言优于另一种，这完全取决于用户的偏好和便利性。

## 超出本书范围

虽然本书承诺并实现了让您的 SEO 由数据驱动，但有一些内容更适合由其他书籍来涵盖，例如：

-   **如何成为 SEO 专家**：本书不会涵盖如何成为 SEO 专家，尽管您肯定会学到很多关于如何成为更优秀的 SEO 专家的知识。一些基础知识超出了本书的范围。

例如，我们不会深入探讨搜索引擎如何工作、什么是内容管理系统、它如何工作，以及如何阅读和编写 HTML 和 CSS。我们也不会揭示搜索引擎可能用于对网站进行排名的所有排名因素，或如何执行网站重新上线或网站迁移。

本书假设您对 SEO 的工作原理以及 SEO 是什么有基本的了解。我们将提供对 SEO 诸多方面的数据驱动视角，即从数据科学的角度重新定义 SEO 挑战，以便您拥有一个有用的起点。

-   **如何成为数据科学家**：本书当然会介绍解决 SEO 挑战的数据科学技术。但它不会教您成为数据科学家，也不会教您如何使用 Python 编程语言进行编程。

要成为数据科学专业人士，除了编程之外，还需要具备数学知识（线性代数、概率论和统计学）。真正的数据科学家不仅了解数学的理论基础和软件工程以获取和转换数据，他们还知道如何以及何时部署特定模型、每种模型的优缺点（例如随机森林与 AdaBoost），以及如何从头开始重建每个模型。虽然我们不会教您如何成为一名完全成熟的数据科学家，但您将理解模型背后的直觉，以及数据科学家将如何处理 SEO 挑战。

当然，没有唯一的答案；然而，我们提供的答案基于经验，并且在我们撰写时我们认为是最佳答案。因此，您肯定会成为一名数据驱动的 SEO 专家，如果您不辞辛劳地正确学习数据科学，那么您就离成为一名 SEO 科学家不远了。

-   从数据角度看的 SEO 挑战

-   数据结构
