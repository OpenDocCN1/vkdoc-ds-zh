# 会议

由于 `Covid-19` 疫情，大多数线下会议已转为诸如网络研讨会之类的线上活动。无论形式如何，它们都提供了绝佳的机会，不仅可以学习，还可以与他人建立联系。强大的人脉网络可以帮助你接触以前无法触及的受众。不确定在哪里可以找到会议？

参加线上活动时，不要忘记社交。尽管线上活动中的社交方式与线下活动有所不同，但它仍然很重要。正如那句老话所说：“重要的不是你知道什么，而是你认识谁。”你的社交方法必须有创意。例如，大多数线上活动平台都为参与者提供聊天功能。你可以利用聊天功能介绍自己，并提供你的网站或 `LinkedIn` 个人资料的链接，以便与他人建立联系。对于允许创建个人资料的线上会议，不要错过这个机会：不仅要撰写包含你专业领域的信息性简介，还要附上社交媒体账号和在线课程网站的链接。永远不要错过宣传自己、你的网站和在线课程的机会。你可能不会有第二次机会。一些寻找线上会议的资源包括：

-   [`www.linkedin.com`](http://www.linkedin.com)

-   [`www.meetup.com`](http://www.meetup.com)
