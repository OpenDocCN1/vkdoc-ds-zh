# 引言

欢迎来到图表的世界。如果你正手捧这本书，无疑是对数据可视化感兴趣，或许希望开发出充满交互式图表的网页。又或者，你的目标是加深对`D3`库的了解。无论你的目标是什么，我希望这本书能助你实现它。

除了各种类型的图表，本书还涵盖了一系列主题：`DOM`元素与选择、`HTML5`与画布、`jQuery UI`小部件与控件、基于可缩放矢量图形（`SVG`）技术的图形操作，以及数学概念（比例尺与定义域、曲线拟合与趋势线、聚类分析等等）。

我用大量示例丰富了这些广泛的主题，每个示例都紧密聚焦于一个特定主题，并按照有序的步骤说明呈现给你。

一旦你掌握了流程并备好合适的工具，图表开发就会变得简单。因此，在呈现这些材料时，我加入了有用的、可复用的代码片段以及对底层概念的解释。读完本书后，你将能够自信地创建任何类型的数据可视化，无论是传统的还是新颖的。
