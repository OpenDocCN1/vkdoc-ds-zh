# 图表技术概述

当我们需要以图形方式表示数据或定性结构，以展示某种关系——进行比较或突出趋势时，我们会使用图表。图表是一种图形结构，由符号组成，例如折线图中的线条、柱状图中的柱形或饼图中的扇区。图表是有效的工具，可以帮助我们辨别和理解大量数据背后的关系。对人类而言，阅读图表等图形表示比阅读原始数字数据更容易。如今，在众多专业领域以及日常生活的许多其他方面，使用图表已成为普遍做法。因此，根据数据的结构和需要突出的现象，图表呈现出多种形式。例如，如果你的数据被分成不同的组，并且想要表示每组占总数的百分比，你通常会将这些数据组显示在饼图或柱状图中。相反，如果你想展示某个变量随时间变化的趋势，折线图通常是最佳选择。

在本书中，你将学习如何使用基于 JavaScript 的各种技术，根据你的需求创建、绘制和调整图表。然而，在开始使用 JavaScript 开发图表之前，理解本书各章节将涵盖的基本概念非常重要。在本章中，我将简要概述这些概念。

首先，我将向你展示如何识别构成图表的最常见元素。了解这些元素将很有帮助，因为你将在专为实现图表而创建的 JavaScript 库中，以组件、变量和对象的形式找到它们。

接下来，我将列出最常见的图表类型。你对图表及其特性了解得越多，就越容易为你的数据选择正确的表示方式。做出正确的选择至关重要，这样才能突出你想要表示的关系，而仅仅阅读数据是不够的。只有当你熟悉了最常见的图表类型后，你才能选择出最适合你目的的图表。

一旦你熟悉了这些概念，就需要学习如何通过网络实现它们，以及当前有哪些技术可以帮助你实现这一目标。因此，在本章的第二部分，我将讨论这些技术方面的问题，逐一介绍本书示例开发中所涉及的技术。

最后，鉴于我们所有的工作都将集中在 JavaScript 代码的开发上，我认为提供对某些数据类型的简要描述会有所帮助。不熟悉 JavaScript 的读者可以从这个关于数据在代码中呈现形式的快速参考中受益。不过，我强烈建议读者更深入地研究本章讨论的概念和技术。

## 图表中的元素

你很快就会看到，图表可以呈现多种形式。在图表中，数据通过特定于图表类型的符号来呈现图形结构；然而，所有图表都有一些共同特征。

通常，每个图表都有一个标题，位于顶部，提供对数据的简短描述。较少情况下，会使用副标题或脚注来提供额外的描述（主要是与数据相关的信息，如参考文献、地点、日期和注释）。

图表通常有坐标轴——两条垂直的线，允许用户参考每个数据点 `P(x, y)` 的坐标值（`x`，`y`），如图 1-1 所示。水平线通常代表 `x` 轴，垂直线代表 `y` 轴。

## 最常见的图表类型

本节简要概述了最常见的图表类型。本书后续章节将对每种图表进行更详细的介绍。

![A978-1-4842-0865-6_1_Fig10_HTML.jpg](img/A978-1-4842-0865-6_1_Fig10_HTML.jpg)

图 1-10. 蜡烛图

- `蜡烛图`：一种专门用于描述价格随时间变化趋势的图表。每个数据点由四个数值组成，通常称为开盘价-最高价-最低价-收盘价（`OHLC`），其形状类似蜡烛（见图 1-10）。

![A978-1-4842-0865-6_1_Fig9_HTML.jpg](img/A978-1-4842-0865-6_1_Fig9_HTML.jpg)

- `气泡图`：一种二维散点图，其中第三个变量通过数据点的大小来表示（见图 1-9）。
- `雷达图`：一种图表，其中一系列数据分布在多个轴上，这些轴从图表中心的原点径向延伸。这种图表通常呈现蜘蛛网的形状（见图 1-9）。

![A978-1-4842-0865-6_1_Fig8_HTML.jpg](img/A978-1-4842-0865-6_1_Fig8_HTML.jpg)

图 1-8. 折线图和饼图

- `折线图`：由一条线连接的一系列有序数据点。图表中报告了数据点 `P(x, y)`，表示 `x` 和 `y` 两个轴的刻度（见图 1-8）。
- `饼图`：一个被分割成若干扇区（切片）的圆形（饼）。每个切片代表一组数据，其大小与百分比值成比例（见图 1-8）。

![A978-1-4842-0865-6_1_Fig7_HTML.jpg](img/A978-1-4842-0865-6_1_Fig7_HTML.jpg)

图 1-7. 直方图和柱状图

- `直方图`：建立在 `x` 轴上的相邻矩形，被分割成离散的区间（组距），其面积与该组距的观测频率成比例（见图 1-7）。
- `柱状图`：形状与直方图相似，但本质不同，这是一种由矩形条组成的图表，其长度与所代表的值成比例。每个条形代表一组数据（见图 1-7）。

> **注意**：开盘价-最高价-最低价-收盘价（`OHLC`）是四个数值，通常用于说明金融工具价格随时间的变化。

## 如何在 Web 上实现图表

现在我已经描述了最常见的图表类型及其组成元素，下一步是快速了解一下当前可用于实现图表的技术。

如今，Web 技术日新月异：每天都有新的解决方案被提出，解决那些不久前还相当复杂的问题。这些创新使您能够仅通过编写几行 JavaScript 代码，就能实现具有引人注目的图形的高度交互式图表。整个过程可以快速轻松地完成，因为大部分工作都由高度专业化的图表表示 JavaScript 库为您完成。这些库现在在网络中随处可见。

在本书中，您将使用 `D3` 库，这是目前使用最广泛的库，它能为图表实现过程中可能出现的几乎所有问题提供通用解决方案。

但是，在深入学习这个库之前（这将在后续章节中进行），您必须先了解构成 JavaScript 图表开发基础的所有技术，因为这些技术将伴随您阅读本书的其余部分。

### HTML5

最近，关于 HTML5 的讨论很多，它实际上正在彻底改变 Web 应用程序的开发方式。在它出现之前，如果您想引入交互式图形内容，使用 Adobe Flash 之类的应用程序几乎是必经之路。但是，使用 Flash 或类似应用程序在 Web 上开发图表或其他图形表示存在一个明显的限制：依赖最终用户机器上安装的插件。此外，这类应用程序在智能手机上不受支持。得益于 HTML5，开发人员现在无需依赖 Flash 即可创建高级图形和动画。

在阅读本书的过程中，您将看到 HTML5 如何催生了许多其他技术，有些是新的，有些是旧的但焕发了新生，例如 JavaScript。事实上，作为一种语言，JavaScript 正在经历重生，这得益于正是为了利用 HTML5 引入的创新而开发的新库。HTML5 有许多新的语法特性，包括 `<canvas>` 元素和标量矢量图形（SVG）内容的集成。借助这些元素，无需使用 Flash 即可非常轻松地在 Web 上集成多媒体和图形内容。

在 Flash 的位置上，您将使用 `D3` 库。目前，这是可用于实现数据图形可视化等任务的最广泛、最完整的库。然而，Web 技术世界在不断演进；在互联网上，您总能找到具有与 `D3` 库类似特性的新库。

### 使用 SVG 和 CANVAS 绘制图表

在 HTML5 引入的新技术可以实现的众多图形应用中，我将重点介绍通过图表进行数据表示和可视化。使用 JavaScript 作为编程语言，我们现在可以利用嵌入在新浏览器中的强大渲染引擎。作为该语言新能力的基础，我将提及 HTML5 canvas 和 SVG。与在服务器上绘制静态图像然后下载到浏览器中不同，SVG 和 canvas 允许您开发完全交互式的图表，从而通过内置的动画、过渡和工具提示来丰富您的图形表示。这是因为 SVG 和 canvas 内容是在浏览器中绘制的，因此构成图表的图形元素可以在不刷新页面的情况下进行转换。此功能对于可视化实时数据至关重要，这些数据要求图表随着数据变化而持续更新。以这种方式操作将确保真正的客户端图表绘制。事实上，通过利用这些技术，图表实际上是在客户端绘制的，只需要从服务器传递数据即可。这一方面带来了相当多的优势，其中最重要的是无需从服务器下载大型图形文件。

#### Canvas 与 SVG 对比

HTML5 的 Canvas 和 SVG 都是允许你在浏览器中创建丰富图形的 Web 技术，但它们有着本质上的不同。在本文中，你将主要看到 D3 如何利用 SVG 技术。其他与 D3 类似的库（例如 `jqPlot` 和 `Highcharts`）则利用 HTML5 的 `<canvas>` 元素来绘制图表。相比之下，D3 并不使用 Canvas；它依赖 SVG 技术进行图形表示。

SVG 是一种基于 XML 的矢量图形格式。SVG 内容可以是静态的、动态的、交互式的或动画的，这使得它非常灵活。你还可以使用层叠样式表（CSS）来设置 SVG 元素的样式，并通过 SVG 文档对象模型（DOM）提供的应用程序编程接口（API）方法为其添加动态行为。因此，选择这种格式，你所能获得的远不止简单的矢量图形和动画：你可以开发高度交互的 Web 应用程序，包括脚本、高级动画、事件、滤镜，以及几乎任何你能想象到的功能。

HTML5 Canvas 规范是一个多功能的 JavaScript API，允许你编写程序化的绘图操作。Canvas 本身允许你定义一个画布上下文对象，在 HTML 页面中显示为 `<canvas>` 元素。然后，你可以使用 Web 图形库（WebGL）通过二维或三维绘图上下文在该元素内部进行绘制。

与 SVG 相比，Canvas 的优势在于其高性能的绘图能力以及更快的图形和图像编辑速度。当需要在像素级别工作时，Canvas 是更优的选择。然而，使用 Canvas 时，没有可供操作的 DOM 节点可能是一个劣势，尤其是在你没有使用 JavaScript 框架的情况下。另一个缺点是文本渲染能力较弱。

与 Canvas 相比，SVG 的优势在于其分辨率无关性、良好的动画支持，以及能够使用声明式语法对元素进行动画处理。但最重要的是，你可以通过 JavaScript 中的 SVG DOM API 完全控制每个元素。然而，当复杂度增加时，渲染速度慢可能成为一个问题，但浏览器供应商正在努力使浏览器变得更快（参见表 1-1 和 1-2）。

### DOM

在使用作用于 HTML 页面结构元素层面的库时，我们不可避免地要谈到 DOM。我将经常提及这个概念，因为它是每个网页的基础结构。万维网联盟（W3C）认为有必要（也确实如此）为结构化文档的表示创建一个官方标准，以便为所有编程语言和平台制定指导方针。HTML 文档以及 XML 文档的树形结构完全遵循该标准制定的指导方针。以下是一个 HTML 文档的示例：

```html
<HTML>
<HEAD>
<TITLE>一个标题</TITLE>
</HEAD>
<BODY>
你好
<BR>
</BODY>
</HTML>
```

该文档的 DOM 树可以如图 1-11 所示进行表示。

![A978-1-4842-0865-6_1_Fig11_HTML.jpg](img/A978-1-4842-0865-6_1_Fig11_HTML.jpg)

图 1-11. DOM 树形结构示例

但是，DOM 标准并不仅限于制定文档中 DOM 应如何构建的指导方针；该标准还定义了许多旨在作用于构成文档的元素的功能。因此，任何与文档相关的操作（创建、插入、删除）都应遵循 DOM 标准。结果就是，无论你使用哪种编程语言或工作在哪个平台上，你总能找到该标准所表达的相同功能。通常，术语 DOM 也适用于管理网页所有元素的 API。

所有这些都很重要，因为任何选择阅读本书的人都有兴趣开发图表，这些图表不仅使用 DOM，而且本身也是 DOM 的一部分，并且其每个方面都可以在 JavaScript 中进行检查和操作。在本书中，你将学习如何充分利用 `D3` 库。借助这个 JavaScript 库，你可以访问每个图表元素，例如更改对象的颜色和位置。

#### 运行和调试 JavaScript

如果我们想在客户端-服务器框架中定义`JavaScript`，它是一种完全客户端的编程语言。它不需要编译，并且除了`HTML`文档之外，代码片段还可以出现在许多其他特定于其他语言的文件类型中，例如`.JSP`或`.PHP`。

这些代码片段未经任何处理就原封不动地通过应用服务器。只有浏览器负责运行`JavaScript`代码。因此，`JavaScript`代码仅在网页下载时或之后响应事件时运行。如果`JavaScript`代码规模较大或将来可能有用，则可以将其定义在外部`.JS`文件中；在这里，你将找到本书中提到的所有`JavaScript`库和框架。然而，无论其形式如何，`JavaScript`都直接在浏览器中运行。

因此，即使你不使用真正的`IDE`来开发和调试`JavaScript`代码，你也可以简单地将代码插入到一个空的`HTML`文件中，然后直接在浏览器（`Chrome`、`Internet Explorer`和`Firefox`是最常见的）中加载该文件。为了将其与页面上的其他文本区分开来，你必须将代码放在`<script></script>`标签内：

```
<script type="text/javascript">

// JavaScript 代码

</script>
```

如果`JavaScript`代码位于外部文件中，则需要将其包含在`HTML`页面中，编写如下：

```
<script type="text/javascript" src="library.js"></script>
```

因此，只要执行`JavaScript`的目的不是为了安装某些东西，你就拥有了所需的一切。谁的操作系统上没有网页浏览器呢？

#### JavaScript 中的数据类型

如前所述，本书既不会解释编写优秀`JavaScript`代码的规则和语法，也不会过多地停留在编程细节上。尽管如此，我们将要开发的代码是围绕图表展开的，或者更确切地说，是围绕数据处理以及如何显示它们展开的。让我们从最简单的情况开始。所有数据结构的最小构建块是变量（当它包含单个值时）。在处理数据类型方面，`JavaScript`与其他编程语言非常不同。当你想要将值存储到`JavaScript`变量中时，你无需指定值的类型（`int`、`string`、`float`、`boolean`等）；你只需使用`var`关键字来定义它。

在`Java`或`C`中，包含整数值的变量与包含文本的变量的声明方式不同：

```
int value = 3;
String text = "这是一个字符串值";
```

在`JavaScript`中，存储值的类型无关紧要。一切都用`var`声明，因此相同的声明是：

```
var value = 3;
var text = "这是一个字符串值";
```

因此，在`JavaScript`中，我们可以将变量视为用于存储任何类型值的容器。

为简单起见，这里将变量视为单个值的容器，从而代表了最简单的数据结构。然而，实际上，变量也可能包含更复杂的数据类型：数组和对象。

**注意**

在`JavaScript`中使用变量实际上稍微复杂一些。你也可以在不使用`var`关键字声明的情况下使用变量。`var`关键字将在当前作用域内声明该变量。如果缺少`var`，`JavaScript`将搜索在更高作用域级别声明的同名变量。如果`JavaScript`没有找到这个变量，则会声明一个新的变量；否则，`JavaScript`将使用找到的变量中的值。因此，变量的不正确使用有时会导致难以检测的错误。

### 数组

数组是由逗号分隔、并用方括号`[ ]`括起来的一系列值：

```
var array = [ 1, 6, 3, 8, 2, 4 ];
```

数组是 JavaScript 中最简单、最广泛使用的数据结构，因此你应该非常熟悉它们。通过在数组名后的方括号中指定其索引（在数组中的位置），可以访问数组中的任何值。在 JavaScript 中，索引从 0 开始：

```
array[3]  //返回 8
```

数组可以包含任何类型的数据，而不仅仅是整数：

```
var fruits = [ "banana", "apple", "peach" ];
```

有许多函数可以帮助我们处理这种对象。由于其有用性，我将在本书中频繁使用此对象，因此有必要快速了解一下。

可以通过以下方式知道数组中值的数量：

```
fruits.length  //返回 3
```

或者，如果你知道值，可以通过以下方式获取对应的索引：

```
fruits.indexOf("apple") //返回 1
```

此外，还有一组函数允许我们在数组中添加和删除项目。`push()`和`pop()`函数用于添加和删除数组的最后一个元素，而`shift()`和`unshift()`函数用于添加和删除数组的第一个元素：

```
fruits.push("strawberry");

// 现在数组是 ["banana", "apple", "peach", "strawberry"];

fruits.pop();   //返回 "strawberry"

// 现在数组是 ["banana", "apple", "peach"];

fruits.unshift("orange", "pear");

// 现在数组是 ["orange", "pear", "banana", "apple", "peach"];

fruits.shift(); //返回 "orange"

// 现在数组是 ["pear", "banana", "apple", "peach"];
```

有时，需要遍历数组中的每个值以对其执行某些操作。在其他编程语言中广泛使用的一种方法是使用`for()`函数。例如，要计算数组中值的总和，你可以这样写：

```
var sum = 0;

for (var i = 0; i < array.length; i++) {

sum += array[i];

}
```

但是，在 JavaScript 中更常见的是使用`forEach()`函数，其中`d`按顺序依次取数组中的值：

```
var sum = 0;

array.forEach(function(d) {

sum += d;

});
```

### 对象

数组对于简单的值列表很有用，但如果你想要结构化数据，则需要定义一个对象。对象是一种自定义数据结构，其属性和值由你定义。你可以通过将属性括在两个花括号`{ }`中来定义对象；每个属性由一个名称后跟冒号（`:`）和赋值的值定义，逗号分隔每个属性/值对：

```
var animal = {

species: "lion",

class: "mammalia",

order: "carnivora",

extinct: false,

number: 123456

};
```

在 JavaScript 代码中，点表示法通过指定属性名称来引用每个值：

```
animal.species      //返回 "lion"
```

现在你已经了解了对象和数组，可以看到如何将它们组合起来，以在 JavaScript 中获得更复杂的数据结构。你可以创建对象数组、数组对象，甚至是对象中的对象。方括号用于表示数组，花括号用于表示对象。例如，让我们这样定义一个对象数组：

```
var animals = [

{

species: "lion",

class: "mammalia",

order: "carnivora",

extinct: false,

number: 123456

},

{

species: "gorilla",

class: "mammalia",

order: "primates",

extinct: false,

number: 555234

},

{

species: "octopus",

class: "cephalopoda",

order: "octopoda",

extinct: false,

number: 333421

}

];
```

要获取这些数据结构的值，你需要同时使用带索引的方括号和属性名称：

```
animals[0].extinct //返回 false

animals[2].species //返回 "octopus"
```

### JSON

JSON 是一种将数据组织为 JavaScript 对象的特定语法。这种格式通常用于基于浏览器的代码中，尤其是在 JavaScript 中。JSON 是 XML 组织数据的有效替代方案。两者都与编程语言无关，但 JSON 比 XML（一种完整的标记语言）更快，更容易用 JavaScript 解析。此外，`D3`与 JSON 配合得很好。其结构完全遵循我们在 JavaScript 中定义的对象和数组的规则：

```
var company = {

"name": "Elusive Dinamics",

"location": "France",

"sites": 2,

"employees": 234,

"updated": true

};
```
