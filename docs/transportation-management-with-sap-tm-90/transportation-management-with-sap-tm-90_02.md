# 运输行业概览：第三方物流视角

本章将讨论以下内容：

- 第三方物流提供商（3PL）行业的演变过程
- 3PL 提供的服务
- 3PL 客户在技术与服务方面的期望
- 未来发展方向

几十年前，货主（制造商/托运人）使用自有的内部车队将产品运送给批发商和零售商是普遍做法。然而，由于车辆无法调配，产品常常无法按时送达客户手中，这导致了机会和收入的损失，更不用说客户的不满。当制造商/托运人开始向国际市场销售商品时，这个问题变得更加严重。在此期间，许多企业雇佣了拥有一两辆卡车/挂车的本地道路承运商来补充其车队运力。他们发现，这种外包方式既经济高效又灵活，还能让他们免于资本投入和维护老化资产的麻烦。很快，使用租用或签约车辆成为内陆运输的普遍接受方式。此外，货主开始与这类承运商签订长期合同，以避免在服务和运输成本方面出现不确定性。拥有一两辆车的承运商扩大了车队规模，并引入不同类型的车辆，以获取这些能带来稳定业务量的长期合同。

随着国际贸易的繁荣，产品开始跨越国界。制造商/托运人招募了具有进出口、国际海运和空运货代经验的专业人士来管理其产品的运输。为了完成清关、联系和预订承运商、提供文件以及处理国际运输的各种法律问题，需要组建一支数十到数百人的团队，具体人数取决于业务规模、货物地点及性质。然而，在其他大洲建立运输网络仍然是一个重大挑战。某些贸易航线上业务量的不可预测增长以及进口国的法律，都增加了运输业务的复杂性。

全球化迫使制造商/托运人和零售商生产既具成本效益又高质量的产品。许多知名老牌品牌正面临新品牌的挑战，因为新品牌的运营成本相对较低，能提供更低的价格。所有导致供应链支出增加的成本因素都受到了分析。延伸的供应链、减少的库存、缩短的产品生命周期、以及增加的运费和操作费，是导致供应链运营成本上升的几个因素。物流外包正是在这个时期出现的新理念。制造商/托运人开始专注于其核心业务，同时将物流功能转移给外包的第三方物流（3PL）。

随着 3PL 承接这些新客户，更高的运费和操作费用促使 3PL 涉足组织运输活动，例如：

- 将小批量货物与其他制造商/托运人的货物合并，以增加货量，从而从空运和海运承运商处获得更优惠的费率
- 清关
- 与内陆承运商进行费率谈判
- 处理部分文件工作
- 安排货物的临时仓储

最初，制造商/托运人谨慎地将相对有限的服务项目分配给 3PL，例如运输需求和仓库管理，但随后开始委托 3PL 处理更多事务。通过这种方式，3PL 在提供核心及相关服务方面积累了经验和专长，从而赢得了客户的信任。

当时选择不使用 3PL 的制造商/托运人基于以下原因：

- 物流运营需要核心竞争力，因此不能外包；而且，满足服务水平被视为一种风险。
- 外包不被视为能节约成本。
- 其组织内的物流专家不想失去自己的重要性和控制权。
- 难以将组织的互联网技术（`IT`）系统与 3PL 的系统集成。
- 担心货物安全。
- 与 3PL 的关系存在障碍。
- 3PL 的地理覆盖范围不足。
- 过去有过糟糕的经历。

在初始阶段，3PL 最多提供两种服务类型，例如制造商/托运人可能只能获得卡车运输、仅清关、或仅仓储加与承运商费率谈判等服务。地理覆盖范围也有限。3PL 大多是本地、私有的小型公司。然而，制造/托运行业的需求以及不断增长的全球贸易很快催生了更长、更复杂的供应链及其相关的物流流程。为满足这一需求，3PL 开始与不同国家、拥有专业化和专长的其他物流公司合作。这些安排为 3PL 赢得了发展自身的时间。然而，文化、发展水平和技术方面的差异是这种合作关系的主要障碍。3PL 行业领导者开始逐步淘汰这些业务关系，在部分国家开设自己的办事处。此外，日益全球化的制造商/托运人希望为其外包物流业务拥有单一的联络点。大型的全球制造商/托运人通常寻求规模庞大、财务稳定、能提供全方位服务和更广地理覆盖的 3PL。因此，地理和业务组合的扩张一直是 3PL 的优先事项。大型 3PL 开始探索在自身未涉足的地区收购合作伙伴的机会。1996 年至 2006 年间见证了重大的并购活动。

经历了一系列初期磨合后，母公司 3PL 与被收购的 3PL 开始作为一家公司协同运作。如何在组织内实现流程标准化，在很长一段时间内仍是一个重大挑战。业务流程映射、分析和自动化帮助朝着标准化取得了一些进展。培训则进一步推动了组织标准化。将本地需求和运作方式融入到全球标准流程中是一项艰巨的任务。如今，大多数领先的 3PL 都拥有其流程的相关文档。然而，技术整合仍然是一个主要的难题。3PL 使用不同的应用程序，其中大部分是自主研发的。这些应用程序不仅存在可扩展性和集成问题，功能上也很薄弱。3PL 正在努力优化其技术格局，以缩小客户在 `IT` 期望方面的差距——这是每个物流论坛都在讨论的话题。一些 3PL 正以全局视角审视其技术格局，但在大多数情况下，这仍然是项目导向的、战术性的。制造商/托运人希望 3PL 能够提供全面且易于集成的解决方案；为此，3PL 需要更清晰地了解制造商/托运人的供应链。制造商/托运人与 3PL 之间保持协作方式，仍是提高制造商/托运人对 3PL 的 `IT` 能力及双方关系满意度的唯一途径。如今，大多数制造商/托运人认为其 3PL 应具备以下以执行为导向的赋能工具：

- 网络建模与优化
- 订单管理
- 用于预订、跟踪和支付的协作门户
- 协作工具（`SharePoint`、`Lotus Notes`、视频会议等）
- 电子数据交换（订单、预先发货通知、发票）
- 运输管理：计划、寻源与执行
- 堆场管理
- 仓库管理
- 事件管理与追踪追溯
- 供应链事件管理
- 条码技术
- 射频识别技术（`RFID`）
- 全球贸易管理工具
- 高级分析与数据挖掘工具

大型第三方物流公司正在扩展其服务组合与覆盖范围。全球有超过十几家年营业额超过五十亿美元的企业。第三方物流行业的收入持续增长，原因是越来越多的制造商/货主选择外包而非自营。此外，制造商/货主也在考虑减少与其合作的第三方物流公司的数量。

第三方物流公司在许多国家都是主要的雇主。第三方物流公司已提升至合作伙伴地位，这实质上意味着它们已超越客户的期望。这些第三方物流公司能够洞察制造商/货主的供应链，这有助于它们更有效地预测和规划资源/运营，并为客户提供成本优势与优质服务。此外，第三方物流公司在网络规划和精简供应链运营中扮演着重要角色。制造商/货主对第三方物流公司分享的最新信息感到满意，并认为这些公司足够敏捷和灵活。制造商/货主大多认为这些合作关系是成功的，并且每年都能获得递增的收益。

通过在不同地点、众多行业中的长期实践，并深入了解供应链的复杂性，第三方物流公司预见到其服务将产生巨大需求。第三方物流公司学习、采纳并构建了各项服务能力，帮助制造商/货主降低物流成本，使其能够抢占市场先机并提升服务质量。第三方物流公司的优势在于其致力于超越客户期望并保持积极进取的态度。

如今，第三方物流公司在以下领域拥有成熟的服务能力：

- 海运和空运货代
- 运输执行
- 运费账单支付
- 与承运商谈判
- 运输途中的货物合并
- 信用证
- 货物保险
- 集拼
- 拆箱、分拨
- 无船承运人业务
- 追踪追溯
- 跨境服务
- 增值服务
- 以及更多！

一些领先的第三方物流公司已进一步升级为领先物流服务提供商（`4PL`）。这些公司代表制造商/货主协调活动，并监控其他物流公司的绩效与合同。`4PL` 还向制造商/货主提供技术知识，有时还会接手他们的业务流程。`4PL` 被视为帮助大型制造商/货主提升供应链效率的合作伙伴。越来越多的《财富》100 强企业正在使用 `4PL`。

此外，东南亚日益增长的繁荣正推动消费市场蓬勃发展。着眼于这些机遇，来自世界其他地区的全球领先第三方物流公司已在此区域加强了业务布局。

尽管第三方物流行业正努力扩展其服务组合、增加收入并进军不同地区，但它也面临着在日益激烈的竞争中求生存的巨大压力。该行业面临的挑战包括：

- 苛刻的客户
- 不断变化的法规与合规标准
- 缺乏熟练/有经验的劳动力资源
- `IT` 成熟度与客户需求/期望之间的差距

让我们来看一下该行业现有的技术格局。在许多情况下，这是由以下一个或多个因素造成的：

- 不完善的 `IT` 战略、系统导入及（对被收购组织的）系统保留
- 分散的开发职责
- 技术不足：提供类似功能的多重应用程序、陈旧的技术平台、点对点集成、功能覆盖范围差
- 高昂的维护成本、缺乏支持
- 系统不可用、不可扩展的交易捕捉系统
- 合并后的实体继续沿用各自遗留的系统
- 投资回报率低

## 总结

在本章中，我们阐述了第三方物流公司的演变历程及其面临的问题与挑战。第三方物流公司需要专注于合理化其应用系统架构，特别是那些处理关键功能领域的应用，例如订单管理、运输计划与执行、定价与成本核算、仓储、财务及计费。这些应用必须进行整体审视，因为第三方物流公司没有时间逐一处理。在缺乏集成、技术上扎实、功能丰富、架构设计良好且用户友好（最好基于单一平台）的应用来解决这些关键功能的每一天，都意味着该公司正在竞争中落后于人。一个涵盖这些业务功能的运输管理系统（`TMS`）仍然是第三方物流公司的首要任务。
