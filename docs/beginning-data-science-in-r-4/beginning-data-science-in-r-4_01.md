# 引言

欢迎阅读《R 语言 4 数据科学入门》。本书是根据我几年前教授的两门课程——“数据科学：可视化与分析”和“数据科学：软件开发与测试”的讲义编写而成。本书结构贴合这两门课程：每门课程包含七周授课，随后是项目实践。因此，本书前半部分包含八章核心内容，前七章聚焦数据分析，第八章为数据分析项目示例。数据分析章节之后是七章关于开发可复用数据科学软件的章节，接着是一个将软件开发章节联系起来的第二个项目。读完本书，您将对数据科学的全貌有清晰认识——它既涵盖分析领域，也涉及新方法开发与可复用软件产品的构建。

## 什么是数据科学？

这是一个难题。我不知道是否容易找到完全确定数据科学定义的人，但我很确定，要找到两个没有三种不同看法的人都很难。数据科学无疑是一个流行热词，如今每个人都想雇佣数据科学家，因此掌握数据科学技能对简历很有帮助。但它究竟是什么呢？

既然无法给出公认的定义，我就只给出我自己的理解：数据科学是从数据中学习的科学。

这个定义非常宽泛——几乎宽泛到失去实用性。我明白这一点。但话说回来，我认为数据科学是一个极其广泛的领域。对此我并不介意。当然，你可能会说任何科学都关乎从数据中提取信息，你可能是对的。然而，我认为科学不仅仅是把原始数据转化为有用信息。科学关注的是回答关于世界的具体问题，而数据科学关注的是如何高效且有效地处理数据。其核心并非该向数据提出哪些问题，而是无论问题是什么，我们如何回答它们。从这一点来看，数据科学更像计算机科学和数学，而非自然科学。它并非研究自然世界，而是关于高效地计算数据并从数据中学习模式。

数据科学还包括实验设计。拥有合适的数据，我们就能解答自己感兴趣的问题。如果实验设计不佳或收集数据的选择不当，这可能会变得困难。研究设计可能是数据科学最关键的部分，但并非本书的主题。本书聚焦于数据收集后的分析。

计算机科学主要研究计算（其名称已暗示），但范畴更广。它还涉及数据的表示和处理。“计算机科学”这个名称强调计算，而“数据科学”则强调数据。当然，这两个领域存在重叠。当你编写排序算法时，你是关注计算还是数据？这甚至是一个有意义的问题吗？

计算机科学与数据科学之间存在大量重叠，自然，你所需的技能集也相互重叠。要高效处理数据，你需要相应的工具，因此计算机编程技能必不可少，对算法和数据结构的了解通常也同样重要。然而，对于数据科学而言，焦点始终是数据。数据分析项目关注的是数据如何从原始形态经过各种处理，最终以某种有用的方式被归纳总结。尽管差异可能很微妙，但关注的不是程序在分析过程中执行了什么操作，而是数据如何流动和转换。它还关注我们为何进行某些数据转换，这些变化服务于什么目的，以及它们如何帮助我们获取关于数据的知识。这既关乎决定如何处理数据，也关乎如何高效地处理它。

统计学当然也与数据科学密切相关。两者联系如此紧密，以至于许多人认为数据科学只是统计学的一个花哨说法，看起来更现代、更性感。我不能说自己强烈反对这一点——数据科学听起来确实比统计学更酷——但正如数据科学与计算机科学略有不同，数据科学与统计学也略有不同。只是可能不像与计算机科学差异那么大。

进行统计的重要部分是为你数据建立数学模型，并将模型拟合到数据中，以此了解数据。这也是我们在数据科学中所做的。只要焦点在数据上，我很乐意将统计学称为数据科学。但如果焦点转移到模型和数学上，那我们就偏离数据科学，进入了其他领域——就像焦点从数据转移到计算上，我们就从数据科学偏离到了计算机科学。

数据科学还与机器学习和人工智能相关——同样，存在巨大重叠。这或许并不奇怪，因为机器学习本身既扎根于计算机科学，也扎根于统计学；如果它专注于数据分析，那么它也属于数据科学的范畴。老实说，我从未搞清楚过，一个数学模型何时从普通的老式统计模型变成了机器学习。

对于本书，我们将沿用我给出的定义，并且只要专注于数据分析，我们就称之为数据科学。



## 阅读本书的先决条件

本书前八章的重点是数据分析而非编程。对于这八章，我并未假设你熟悉软件设计、算法、数据结构等细节。我同样不期望你具备`R`编程语言的使用经验。但我假设你有一些编程、数学建模和统计学方面的经验。

如果你熟悉脚本语言或面向对象语言，有时用`R`编程会相当棘手。`R`是一门函数式语言，不允许修改数据。虽然它确实有面向对象编程的系统，但其处理这种编程范式的方式与你可能见过的`Java`或`Python`等语言大相径庭。

对于本书的数据分析部分（即前八章），我们仅会用`R`执行非常简单的编程任务，因此上述情况不应构成问题。我们需要编写简单的脚本来处理和汇总数据，因此你应该熟悉如何编写函数调用、`if`语句、循环等基本表达式——你需要对这些内容运用自如。当我们在书中需要用到这些结构时，我会逐一介绍，让你了解它们在`R`中如何编写，但我不会花大量时间解释它们。我主要期望你能通过示例自行掌握。

同样，我并不期望你已经知道如何在`R`中拟合数据和比较模型。但我假设你对统计学有足够的了解，能熟悉参数估计、模型拟合、解释变量与响应变量、模型比较等基本术语。如果尚不熟悉，我希望你至少能在需要时理解我们讨论的内容。

我不指望你精通统计和编程，但这也不是“傻瓜式数据科学”，因此我期望你能在无需我详尽解释所有细节的情况下理解示例。

在第七章之后，有一个简短的描述，介绍了我的一位学生在我首次授课时完成的数据分析项目。它展示了此类项目可能的样子，但我建议你不要等到读完前七章才开始自己进行此类分析。为了从阅读本书中获得最大收益，你应该持续应用所学知识。我建议，在你开始阅读时，就找一个你感兴趣的数据集，然后将每章所学内容应用到该数据上。

在本书接下来的八章中，重点在于编程。要阅读这部分内容，你应该熟悉面向对象编程——我会解释我们在`R`中如何处理它，以及它与`Python`、`Java`或`C++`等语言的区别。即便如此，我仍期望你熟悉类层次结构、继承和多态方法等术语。我不期望你已经熟悉函数式编程（但如果你熟悉，并且尚未精通`R`编程，那么这些章节中仍有大量内容值得学习）。最后一章是另一个项目描述。

## 本书规划

在本书中，我们将涵盖基本的数据操作：

-   筛选和选择相关数据
-   将数据转换为易于分析的形态
-   汇总数据
-   以信息丰富的方式可视化数据，用于探索数据和呈现结果
-   模型构建

这些都是数据科学中进行分析的关键方面。之后，我们将涵盖如何开发可重用且能与现有包良好配合、易于扩展的`R`代码，并了解如何构建新的`R`包，以便其他人能够在他们的项目中使用。这些是你开发自己的方法并与世界分享所需的基本技能。

`R`是当下最流行的（且开源的）数据分析编程语言之一。当然，流行并不代表质量。但是，正因为`R`如此流行，它拥有丰富的扩展生态系统（在`R`中称为“包”），几乎涵盖了你可能感兴趣的各类分析。开发统计方法的人通常会将其实现为`R`包，因此你可以很轻松地在`R`中获取最先进的技术。这种流行也意味着，如果你遇到问题，有一个庞大的社区可以求助。你遇到的大多数问题都可以通过几分钟的谷歌或 Stack Overflow 搜索解决，因为你不太可能是第一个遇到某个特定问题的人。还有很多在线教程可以帮助你更深入地学习`R`及其专用包。如果你想了解更多，也可以购买许多相关书籍。

## 数据分析与可视化

我在前八章中涵盖的数据分析与可视化主题如下：

1.  **R 语言入门**：本章学习如何处理数据以及编写数据管道。
2.  **可重现分析**：本章将了解如何将文档和分析整合到单个文档中，以及如何使用此类文档进行可重现的研究。
3.  **数据操作**：本章学习如何导入数据、整理数据、转换数据以及从数据中计算摘要。
4.  **数据可视化**：本章学习如何绘制图形，以探索数据特征、展示数据特征和分析结果。
5.  **处理大型数据集**：本章将探讨如何处理观测数量过多导致常规方法过慢的数据。
6.  **监督学习**：本章学习如何在使用已知类别或回归值的数据集上训练模型。
7.  **无监督学习**：本章学习如何在数据中搜索我们尚未意识到的模式。
8.  **项目一：饮酒分析**：紧随这些章节之后的是第一个项目，即对葡萄酒的物理化学特征进行分析，我们将在此项目中应用各种技术。

## 软件开发

接下来的九章涵盖软件和包开发：

1.  **深入 R 语言编程**：本章将探索`R`编程语言的更高级特性。
2.  **向量与列表操作**：本章将探讨两种基本数据结构：向量和列表。
3.  **函数式编程**：本章将探索`R`编程语言的一个高级特性——函数式编程。
4.  **面向对象编程**：本章将学习`R`如何处理面向对象，以及我们如何利用它编写更通用的代码。
5.  **构建 R 包**：本章将学习`R`包的必需组件，以及如何编写自己的包。
6.  **测试与包检查**：本章将学习测试`R`代码以及检查`R`包一致性的技术。
7.  **版本控制**：本章将学习如何在版本控制下管理代码，以及如何使用 GitHub 进行协作。
8.  **性能剖析与优化**：本章将学习如何识别因低效方案导致运行缓慢的代码热点，以及缓解这一问题的技术。
9.  **项目二：贝叶斯线性回归**：在最后一章，我们将进入第二个项目，构建一个用于贝叶斯线性回归的包。



## 获取 R 和 RStudio

你需要在计算机上安装 R，才能完成本书中的练习。我建议你安装一个集成环境，因为当你将图表、文档、代码等全部放在同一个程序中时，可以更方便地管理项目。

我使用的是 RStudio（[`www.rstudio.com/products/RStudio`](http://www.rstudio.com/products/RStudio)），并向你强烈推荐。你可以免费获取它——只需点击链接即可——在后续章节中，当我需要引用你使用的软件环境时，我会假设你已经安装了它。不过，本书中并不会涉及太多 RStudio 特有的内容，而且大多数用于处理 R 的工具都具有大致相同的功能，因此，如果你想使用其他工具，按照本书的说明进行操作应该也不会有太大困难。

## 项目

不分析数据就无法学会如何分析数据，同样，不开发软件就无法理解如何开发软件。照着书中的示例输入代码，与自己动手编写代码完全是两码事。即使是完成书中的练习（这也是你确实应该做的），也不同于处理你自己的项目。毕竟，练习只涉及你刚接触问题的那些微小的、孤立的方面。在现实世界中，你面临的每一项任务之前，并不会有一整章的铺垫材料。你需要自己弄清楚需要做什么，以及如何去做。如果你只做这本书里的练习，你将错过分析数据中最关键的一课：

*   如何探索数据并建立对其的直觉
*   如何进行必要的侦探工作，以从数据中提取出一些理解
*   如何处理任何数据集中都会出现的噪声和怪异现象

而对于开发一个包，你需要深思熟虑如何设计和实现其功能，使各种函数和数据结构能够很好地协同工作。

在本章中，我将带领你完成一个数据分析项目，向你展示它可能是什么样子。要学习如何独自分析数据，你同样需要亲自实践——而且你需要使用一个我尚未为你探索过的数据集。你可能手头有之前处理过的数据集，或者有出自你感兴趣事物的数据集，又或者你可以在公共数据存储库中找到一些有趣的数据，例如以下几个：

*   RDataMining.com：[`www.rdatamining.com/resources/data`](http://www.rdatamining.com/resources/data)
*   UCI 机器学习库：[`http://archive.ics.uci.edu/ml/`](http://archive.ics.uci.edu/ml/)
*   KDNuggets：[`www.kdnuggets.com/datasets/index.html`](http://www.kdnuggets.com/datasets/index.html)
*   Reddit R 数据集：[`www.reddit.com/r/datasets`](http://www.reddit.com/r/datasets)
*   GitHub 精彩公共数据集：[`https://github.com/caesar0301/awesome-public-datasets`](https://github.com/caesar0301/awesome-public-datasets)

我建议你找一个数据集，并在每节课后，运用你学到的技能来探索这个数据集。选择结构为表格形式的数据，其中行为观测值，列为变量，因为这是本书中将要考虑的数据形式。在完成前八章的学习后，你将分析完这些数据。你可以撰写一份关于你的分析的报告，其他人可以评估该报告以理解你的分析过程，甚至可能修改它：你正在实践可重复的科学。

关于编程主题，我将描述另一个项目，说明制作 R 包所涉及的设计和实现问题。在那里，你应该能够通过实现我所用项目的你自己的版本学到东西，但当然，如果完全不依赖我的帮助独立完成一个项目，你将面临更大的挑战。无论如何，为了充分受益于本书，你真的应该在阅读编程章节的同时制作你自己的包。
