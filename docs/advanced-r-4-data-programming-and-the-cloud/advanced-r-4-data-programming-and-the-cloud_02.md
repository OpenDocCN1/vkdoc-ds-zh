## 1.3 对象类型

首先，我们需要一些元素来构建我们的语言，在`R`中，这些元素被称为对象。我们从五种非常常见的对象类型开始。

### 逻辑型
逻辑型对象只取两个值：`TRUE` 或 `FALSE`。计算机是二进制机器，数据常常可以在一个“全有或全无”的世界中进行记录和建模。这些逻辑值可能很有用，其中 `TRUE` 的值为 1，`FALSE` 的值为 0。

提醒一下，`#`（例如井号或话题标签）是代码注释的指示符。`#` 后面的单词不会被`R`处理，旨在帮助读者理解：

```
TRUE  ## 逻辑型
## [1] TRUE

FALSE ## 逻辑型
## [1] FALSE
```

### 数值型
正如你可能从大学代数老师快速嘟囔的评论中记得的那样，数字有许多种。包括零和负值的整数被称为*整型*。在集合表示法中，也就是 ... , -2, -1, 0, 1, 2, ... ，这些数字对于人数计算或其他索引非常有用。在`R`中，整型有一个大写字母 `L` 后缀。如果需要小数，则需要使用双精度浮点型对象。这些数字适用于比率数据类型。复数也具有有用的性质，并且你可以完全按预期理解它们，在虚数部分加上 `i` 后缀。`R`在使用所有这些数字时非常友好，你只需输入所需的数字（记得在需要时加上 `L` 或 `i` 后缀）：

```
42L    ## 整型
## [1] 42

1.5    ## 双精度浮点型
## [1] 1.5

2+3i   ## 复数
## [1] 2+3i
```

### 字符型
定类数据可以通过字符类存储，并用引号指定：

```
"a"    ## 字符型
## [1] "a"
```

### 缺失值
数值数据可能包含缺失值。这些缺失值的类型与该数据集中其余数据的类型一致（我们稍后讨论数据存储）。尽管如此，了解如何手动编写逻辑型、整型、双精度浮点型、复数或字符型的缺失值仍会有帮助：

```
NA              ## 逻辑型
## [1] NA

NA_integer_     ## 整型
## [1] NA

NA_real_        ## 双精度浮点型/数值型
## [1] NA

NA_character_   ## 字符型
## [1] NA

NA_complex_     ## 复数型
## [1] NA
```

### 因子型
`因子型`是一种特殊的对象，在通用编程中不太常用，但在统计学中使用频率相当高。因子变量指示该变量应被视为离散值。因子以整数形式存储，并附带标签来指示原始值：

```
factor(1:3)
## [1] 1 2 3
## 水平: 1 2 3

factor(c("alice", "bob", "charlie"))
## [1] alice bob charlie
## 水平: alice bob charlie

factor(letters[1:3])
## [1] a b c
## 水平: a b c
```

### 向量
我们现在转向数据结构，它可以存储我们已讨论过（当然还有更多）类型的对象。*向量*是一种相对简单的数据存储对象。创建向量的一种简单方法是使用连接函数 `c()`：

```
## 向量

```

请注意矩阵填充数字 1 至 6 的方式，是按列逐次填充的：

在此阶段，有必要稍微提一下数据结构间的“战争”。

从历史上看，许多研究人员使用的主要数据结构是数据框，用于组织行/列或`表格`类型的数据。随着数据在列宽和行数上的增长，R 语言的基础结构已无法满足所有人的需求。`data.table`包/库源于与一些大型数据库相同的 SQL 数据控制思维，如今已能适应多核处理器和高效的内存操作，并在底层使用了比 R 更高效的语言。对于大型数据集以及有 SQL 或其他编程语言背景的人来说，数据表非常高效且直观。并非所有初学 R 的人都有编程背景（这其实是一件好事）。另一种竞争性的数据结构——`tibble`，是所谓`tidyverse`（整洁宇宙的合成词）的一部分。Tibble 在本质上也是数据框，但进行了改进。在作者看来，虽然速度尚不及数据表，但 tibble 拥有对新手更友好的风格或语言语法。它们受到 R 社区很大一部分人的喜爱，是现代 R 的重要组成部分。在实践中，数据表仍然更快，并且通常能用更少的代码行完成作者认为最常见的任务。这两种较新的结构各有优势，在 R 的宇宙中都有其位置（实际上，第 7 章和第 8 章专注于数据表，而第 9 章则重点介绍了 tibble）。尽管如此，本书将主要使用数据表。

## 1.4 基本运算符和函数

仅有对象不足以构成一门语言；名词虽好，但也需要动作。运算符和函数就是编程世界中的动词。我们从赋值开始，赋值有两种方式。就像书面语言一样，更优雅的措辞比简单的表述更有帮助。因此，虽然 `=` 和 `<-` 都是赋值运算符且功能相同，但由于 `=` 在函数内用于设置参数，我们建议出于清晰起见，在一般赋值中使用 `<-`。尽管如此，我们仍会演示这两种赋值技巧。赋值允许为对象赋予有意义的名称；这可以显著提高代码的可读性（对未来的你以及其他用户都是如此）。

除了为变量赋值，你还可以使用函数来检查具体细节。R 中的函数采用通用格式：函数名后跟括号，括号内输入参数，然后 R 提供输出。示例如下：

`x <- 5`

`y = 3`

`x`

```
## [1] 5
```

`y`

```
## [1] 3
```

`is.integer(x)`

```
## [1] FALSE
```

`is.double(y)`

```
## [1] TRUE
```

`is.vector(x)`

```
## [1] TRUE
```

能够读出并说出这些代码行会有所帮助（而这正是我们偏爱 `<-` 的核心原因，它读作“被赋值为”）。上面这段代码可以理解为“变量 `x` 被赋值为整数值 5”。相比之下，尽管 `y` 这行代码在底层执行了完全相同的操作，但说“`y` 等于 3”可能不太清楚到底是在讨论 `y` 的固有属性还是在执行赋值操作。

一旦对象被赋值，你可以使用方括号访问特定的对象元素。大多数计算机语言的索引从 0 或 1 开始。R 的索引从 1 开始。另外，请注意你可以毫无困难且无需警告地更改旧的赋值；因此明智的做法是谨慎地使用名称并仔细编写代码注释：

`x <- c("a", "b", "c")`

`x[1]`

```
## [1] "a"
```

`is.vector(x)`

```
## [1] TRUE
```

`is.vector(x[1])`

```
## [1] TRUE
```

`is.character(x[1])`

```
## [1] TRUE
```

“谨慎使用名称”是什么意思？我们之前把向量命名为 `x`，这不是一个很有趣的名字。很难记住 `x` 包含了字母表的前三个字母。相反，我们可以选择一个更好的变量名，将难以记忆的 `x` 替换为 `passingLetterGrades`。更好的是，当说出这个变量名时它是有意义的，并且以后也很容易改进，比如如果我们想添加有时代表通过的字母等级 D 或代表及格/不及格的通过等级 S：

`passingLetterGrades <- c("A", "B", "C")`

`passingLetterGrades[2]`

# 1 “B”

因此，以下代码实际上是一个包含元素`a`的向量。再次强调，使用数据类型检查函数有助于学习如何解释各种代码片段：

```
  c("a"),

## [[1]]
## [1] "a"
```

```

## [1] TRUE
```

```
is.list(y[1])
## [1] TRUE
```

```
is.character(y[1])
## [1] FALSE
```

```
## 使用双括号返回该列表元素内部的对象，
```

实际上，你可以将方括号链接起来使用，因此可以访问列表的第二个元素（一个包含数字1–3的向量），然后在该向量内部访问第三个元素：

```
## 可以链接方括号
y[[2]][3] ## 列表的第二个元素，向量的第三个元素
## [1] 3
```

方括号几乎总是有效，具体取决于对象的类型，但可能还有其他访问组件的方式。具有名称的数据框和列表可以使用`$`运算符。请注意在以下代码中方括号或美元符号最终是如何等效的：

```
x3 <- data.frame(
  A = 1:3,
  B = 4:6)
y2 <- list(
  C = c("a"),
  D = c(1, 2, 3))
```

```
x3$A
## [1] 1 2 3
```

```
y2$C
## [1] "a"
```

```
## 这些等效于
x3[["A"]]
## [1] 1 2 3
```

```
y2[["C"]]
## [1] "a"
```

```
## [1] TRUE
```

```

## [1] TRUE
```

```

## [1] FALSE
```

```

## [1] FALSE
```

```

## [1] 1
```

```

```

```
rownames(x3) <- c("first", "second", "third")
x3["second", "B"]
## [1] 5
```

数据表使用略有不同的方法。虽然我们将在后面的两章中专门讨论数据表的使用，但现在我们先提几个要点。选择行的方式几乎完全相同，但选择列时不需要引号。此外，您可以使用`.()`运算符按名称选择多个列而无需引号。如果需要使用引号，可以通过使用`with = FALSE`选项来访问数据表，如下所示：

```
x4 <- data.table(
  A = 1:3,
  B = 4:6)
```

```
x4[1, ]
##    A B
## 1: 1 4
```

```
x4[, A] # 在 data.table 中，列名不需要引号
## [1] 1 2 3
```

```
x4[1, A]
## [1] 1
```

```
x4[1:2, .(A, B)]
##    A B
## 1: 1 4
## 2: 2 5
```

```
x4[1, "A", with = FALSE]
##    A
```
