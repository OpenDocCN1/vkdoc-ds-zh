**关于作者**

**马特·威利** 在维多利亚学院负责机构效能、研究与评估工作，推动战略与部门规划、数据驱动决策以及州/地区/联邦问责制。作为一位拥有终身教职的数学副教授，他曾在数学教育（加利福尼亚州）和学生参与（德克萨斯州）方面获奖。马特在加州大学和德克萨斯 A&M 大学系统获得了计算机科学、商学和纯数学学位。

在学术界之外，他合著了关于流行的 `R` 编程语言的书籍，并在一家统计咨询公司担任了近十年的管理合伙人。他拥有 `R`、`SQL`、`C++`、`Ruby`、`Fortran` 和 `JavaScript` 的编程经验。

作为程序员、出版作者、数学家和变革型领导者，马特始终将对写作的热情与逻辑问题解决和数据科学的乐趣融为一体。从董事会到教室，他喜欢寻找动态方式与跨学科、多元化的团队合作，使复杂的想法和项目变得易于理解和解决。您可以在 Twitter 上通过 @matt math 或在 [`mattwiley.org/`](http://mattwiley.org/) 找到马特。

**约书亚·F·威利** 是莫纳什大学特纳大脑与心理健康研究所及心理科学学院的讲师。他在加州大学洛杉矶分校获得博士学位，并在初级护理与预防领域完成了博士后培训。他的研究使用高级定量方法，理解社会心理因素、睡眠及其他健康行为与心理和身体健康之间的动态关系。他独自或合作开发了多个 `R` 包，包括：用于执行贝叶斯尺度-位置结构方程模型的 `varian` 包；连接 `R` 与商业 `Mplus` 软件的流行包 `MplusAutomation`；用于更快逻辑运算的 `extraoperators`；用于诊断、效应量及多层/混合效应模型结果简易显示 的 `multilevelTools`；以及用于探索数据或加速 `JWileymisc` 中分析的各种函数。您可以在 Twitter 上通过 @WileyResearch 或在 [`joshuawiley.com/`](http://joshuawiley.com/) 找到约书亚。
