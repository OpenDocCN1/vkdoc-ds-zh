向量可能只接受单个索引，但更复杂的结构需要更多索引。对于你之前遇到的矩阵，第一个索引是行，第二个是列位置。请注意，在构建并赋值矩阵后，有多种方法可以访问元素的各种组合。这种仅访问部分元素的过程有时被称为`子集化`：

```
x2 <- matrix(c(1, 2, 3, 4, 5, 6), nrow = 3, ncol = 2)
```

`x2` `打印` 以查看 `完整` 矩阵

```
x2[1, ] ## 第 1 行的所有元素

```

访问和子集化列表可能稍微复杂一些，但对于后续技术而言，学习和掌握它却更为重要。单个方括号中的单个索引会返回该位置处的整个元素（回顾一下：对于列表，每个元素可能是一个向量或只是一个单独的对象）。使用双括号会返回该列表元素内部的对象——仅此而已。

因此，以下代码实际上是一个包含元素`a`的向量。再次强调，使用数据类型检查函数有助于学习如何解释各种代码片段：

```
## 对于列表，使用单个方括号
## 返回一个包含一个元素的列表
y <- list(
  c("a"),
  c(1:3))
y[1]
## [[1]]
## [1] "a"
```

```
is.vector(y[1])
## [1] TRUE
```

```
is.list(y[1])
## [1] TRUE
```

```
is.character(y[1])
## [1] FALSE
```

将其与以下代码进行对比，后者只是元素`a`：

```
## 使用双括号返回该列表元素内部的对象，
## 仅此而已
y[[1]]
## [1] "a"
```

```
is.vector(y[[1]])
## [1] TRUE
```

```
is.list(y[[1]])
## [1] FALSE
```

```
is.character(y[[1]])
## [1] TRUE
```

实际上，你可以将方括号链接起来使用，因此可以访问列表的第二个元素（一个包含数字1–3的向量），然后在该向量内部访问第三个元素：

```
## 可以链接方括号
y[[2]][3] ## 列表的第二个元素，向量的第三个元素
## [1] 3
```

方括号几乎总是有效，具体取决于对象的类型，但可能还有其他访问组件的方式。具有名称的数据框和列表可以使用`$`运算符。请注意在以下代码中方括号或美元符号最终是如何等效的：

```
x3 <- data.frame(
  A = 1:3,
  B = 4:6)
y2 <- list(
  C = c("a"),
  D = c(1, 2, 3))
```

```
x3$A
## [1] 1 2 3
```

```
y2$C
## [1] "a"
```

```
## 这些等效于
x3[["A"]]
## [1] 1 2 3
```

```
y2[["C"]]
## [1] "a"
```

请注意，虽然数据框和列表都是列表，但它们都不是矩阵：

```
is.list(x3)
## [1] TRUE
```

```
is.list(y2)
## [1] TRUE
```

```
is.matrix(x3)
## [1] FALSE
```

```
is.matrix(y2)
## [1] FALSE
```

此外，尽管不是矩阵，但由于其特殊的性质（即所有元素长度相等），数据框和数据表可以类似矩阵那样进行索引：

```
x3[1, 1]
## [1] 1
```

```
x3[1, ]
##   A B
## 1 1 4
```

```
x3[, 1]
## [1] 1 2 3
```

任何具有名称的对象都可以使用名称而不是位置编号来进行索引，前提是这些名称已被设置：

```
x3[1, "A"]
## [1] 1
```

```
x3[, "A"]
## [1] 1 2 3
```

对于数据框，这同样适用于列名和行名，并且这些名称可以在构建矩阵后建立：

```
rownames(x3) <- c("first", "second", "third")
x3["second", "B"]
## [1] 5
```

数据表使用略有不同的方法。虽然我们将在后面的两章中专门讨论数据表的使用，但现在我们先提几个要点。选择行的方式几乎完全相同，但选择列时不需要引号。此外，您可以使用`.()`运算符按名称选择多个列而无需引号。如果需要使用引号，可以通过使用`with = FALSE`选项来访问数据表，如下所示：

```
x4 <- data.table(
  A = 1:3,
  B = 4:6)
```

```
x4[1, ]
##    A B
## 1: 1 4
```

```
x4[, A] # 在 data.table 中，列名不需要引号
## [1] 1 2 3
```

```
x4[1, A]
## [1] 1
```

```
x4[1:2, .(A, B)]
##    A B
## 1: 1 4
## 2: 2 5
```

```
x4[1, "A", with = FALSE]
##    A
## 1: 1
```

请记住，我们说过R中的一切都是对象或函数。这就是两个基本构件。所以，从技术上讲，方括号运算符也是函数。尽管它们通常不像带有明显圆括号`()`的函数那样使用，但也可以这样使用。大多数函数都有名称，但方括号是一个特殊情况，需要使用常规函数格式中的单引号，如下例所示：

```
'['(x, 1)
## [1] "a"
```

```
'['(x3, "second", "A")
## [1] 2
```

```
'[['(y, 2)
## [1] 1 2 3
```

当然，在实际应用中，几乎从不这样使用。之所以需要提及这一点，是为了让你理解可以为任何函数自定义其含义（我们有一章专门讲解如何编写自己的函数）。实际上，从概念上讲，这就是data table能够实现对列名不加引号的原因——当`is.data.table()`返回`TRUE`时，它改变了方括号函数的工作方式。

尽管我们一直在使用`is.datatype()`函数来更好地说明一个对象是什么，但你可以做更多事情。具体来说，你可以使用`is.na()`函数检查一个值是否缺少元素：

```
NA == NA ## 不起作用
## [1] NA
```

```
is.na(NA) ## 起作用
## [1] TRUE
```

当然，前面的代码片段通常有一个向量或矩阵元素参数，其填充状态有待商榷。我们目前要介绍的最后一个探索性函数是`inherits()`函数。当没有`is.class()`函数存在时（这可能在开发了超出目前所见核心类之外的特定类时发生），它会很有帮助：

```
inherits(x3, "data.frame")
## [1] TRUE
```

```
inherits(x2, "matrix")
## [1] TRUE
```

你也可以将较低类型强制转换为较高类型。这种强制转换可能很有帮助，但也可能产生意想不到的后果。如果你有一个更高级的数据对象被强制转换为较低级的类型，可能会特别有风险（请密切注意尝试将整数强制转换的示例）：

```
as.integer(3.8)
## [1] 3
```

```
as.character(3)
## [1] "3"
```

```
as.numeric(3)
## [1] 3
```

```
as.complex(3)
## [1] 3+0i
```

```
as.factor(3)
## [1] 3
## 层级: 3
```

```
as.matrix(3)
##      [,1]
## [1,]    3
```

```
as.data.frame(3)
##   3
## 1 3
```

```
as.list(3)
## [[1]]
## [1] 3
```

```
as.logical("a") ## NA 无警告
## [1] NA
```

```
as.logical(3) ## TRUE，无警告
## [1] TRUE
```

```
as.numeric("a") ## NA 带警告
## 警告信息: 由强制转换引入的 NA 值
## [1] NA
```

强制转换可能很有帮助。尽管如此，必须谨慎使用。在你继续阅读本节后续部分之前，如果这些内容中有任何是新知识，请务必尝试使用与前例不同的输入进行实验！实验绝无坏处，它可能是学习的有力方式。
