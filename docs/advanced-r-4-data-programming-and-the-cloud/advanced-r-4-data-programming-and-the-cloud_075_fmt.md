# 第 12 章：面向 Windows 用户的云 Ubuntu

## 12.9 总结

现在你已经拥有了一个安装了`RStudio Server`（可能非常方便）的云实例。具体来说，你能够以无需本地超级用户权限的方式在本地机器之间上传和下载文件。如果你通过解除对更多 IP 地址的限制来开放权限访问，这便是一种从智能手机使用 R 的方法。此外，我们在`Ubuntu`服务器上安装了几个软件包和应用程序。

在接下来的章节中，我们将利用这些功能来实现一些引人入胜的分析。更重要的是，由于这些功能部署在云端，任何人都可以访问这些数据和结果。因此，分享结果从未如此简单。

表 12-1 列出了有用的`Ubuntu`命令。

**表 12-1.** 本章描述的关键功能及其作用摘要

| 命令 | 作用 |
|---------|--------------|
| `clear` | 清空控制台，类似于 R 中的 `Ctrl+l`。 |
| `ls` | 列出当前目录中的文件，可通过 `-hl` 参数修改显示格式（详情见 `man ls`）。 |
| `pwd` | 显示当前工作目录。 |
| `mkdir` | 创建目录。 |
| `cd` | 切换目录。 |
| `touch fileName` | 创建一个具有指定名称的文件。 |
| `chmod` | 更改/修改文件的读、写、执行权限。 |
| `whoami` | 标识当前用户。 |
| `sudo` | 以超级用户身份执行。 |
| `sudo apt-get update` | 更新软件包列表。 |
| `sudo apt-get upgrade` | 升级已安装的文件。 |
| `sudo apt-get dist-upgrade` | 安装当前文件发行版的升级版本。 |
| `sudo reboot` | 重启你的云实例；重启后需要等待一段时间才能重新连接。 |
| `lsb_release -a` | 显示当前`Ubuntu`版本。 |
| `nano` | 一个文本编辑器。 |
| `R CMD BATCH fileName.R` | 从命令行运行一个`.R`文件，而无需打开 R。 |
| `screen -A -d -m R CMD BATCH fileName.R` | 在一个新的 screen 窗口中运行一个`.R`文件，无需在 R 中打开，并且你可以退出终端，文件仍将在云端继续运行直至完成。 |
| `screen -ls` | 列出当前的 screen；如果有一个进程正在运行，它会显示一个或多个套接字。 |
| `wget` | 网络获取——下载一个文件到当前目录。 |
