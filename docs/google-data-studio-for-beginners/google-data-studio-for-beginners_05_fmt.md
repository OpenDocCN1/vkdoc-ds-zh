# 3. 指标和维度

有用的数据可视化

> *当你意识到所查看的每条数据都在驱动行动时，你便明白自己身处网络洞察的世界……*
>
> ——阿维纳什·考希克，谷歌数字营销布道师^(¹)

在上一章中，我们需要使用维度和指标来制作报告。让我们继续努力理解这些是什么。

几乎所有与数据相关的事情都可以归结为指标和维度。

## 指标

Data Studio 帮助中心词汇表对指标的定义极其复杂：

> *对一组数值应用的特定聚合。指标是来自底层数据集的聚合，或是隐式或显式应用聚合函数（如 `COUNT()`、`SUM()` 或 `AVG()`）的结果。指标本身没有定义好的值集合，因此你不能像对*[维度](https://support.google.com/datastudio/answer/6303401)*那样按它进行分组。*^(²)

让我们试着简化这个定义。指标是一种将数值分配给事物规模的方法。一个指标可以精炼地概括为：

> *你拥有某种特定事物的数量。*

想想第一章中的赫尔曼。作为一家现代蛋糕店的老板，他关心的是统计某一天卖出了多少蛋糕，或者他们用完了多少原料。

其他指标的示例包括：

* 温度计上的温度
* 游戏节目中获得的分数
* 医学研究中的人数
* 网站用户数，即在给定数据时期内访问你网站的人数
* 线上销售产品产生的销售收入
* 一天内向用户展示的错误数量
* 某个地区的平均降雨量

### 聚合指标

指标也可以复杂得多。我们可能关心数字随时间如何变化，或者不同时间段之间如何比较。

蛋糕店老板可以简单地衡量卖出的蛋糕数量，但他也可能想查明某一天卖出了多少蛋糕。

1. 与特定时期相比，销售额是增长还是下降，它们是缓慢增长还是快速下降
2. 销售额与上周、上个月相比如何

当你分析一个“集合”的指标时，这被称为聚合它们或将其汇总。聚合本身会成为新的指标。聚合使我们能够比较、分析和追踪数据趋势，从而发现洞见。

请注意，一个指标既可以是原始数值，也可以是聚合结果。聚合可以成为一个新的指标，即使在它的公式中使用了其他指标，它本身也成为了一个指标。

我们稍后会更详细地讨论聚合，但 Data Studio 词汇表对指标的定义提到了三种：

* `Count()` 或计数指标 – 例如，某一天卖出了多少蛋糕。
* `Sum()` 或求和指标 – 这可以是通过现金和信用卡销售蛋糕，在蛋糕店获得的所有收入的总和。
* `Avg()` 或平均值指标 – 这可以是每周在 bakery 工作的平均员工数（面包师、收银员等）。

## 维度

遗憾的是，在理解数据时，一个指标或聚合并不能让你看到全貌。你需要更多信息才能判断你所拥有的数据是否有用。

通过指标，我们能够真正理解数量方面，但我们如何理解质量的价值呢？这就是维度发挥作用的地方。

Data Studio 词汇表将维度定义为：

> *一组你可以据此对数据进行分组的值。维度是信息的类别。这些类别中包含的值通常是该数据的名称、描述或其他特征。*^(³)

这是一个相当简单的解释，但我认为我们可以做得更好，让它更容易理解：

> *维度是你所计数的对象的名称、描述或其他特征。*

想象一下采集食物的穴居人。仅仅知道他们在一天内采集了 100 颗浆果并不能区分生死。而知道他们采集了 50 颗美味的浆果和 50 颗有毒的浆果，这才是生死攸关的区别。这个至关重要的额外“维度”立刻使信息变得更有价值和有用。它将在未来帮助他们改变选择采集浆果的灌木丛，并为他们的未来提供一个“更健康”的前景。

与穴居人不同，对于大多数现代人来说，他们的数据不会在字面意义上决定生死，而是决定他们的事业在努力中能否成功。我们都希望在工作生活中获胜，因此确保拥有正确的维度来区分优劣将是我们工作的重要组成部分。

回顾我们在上一节中提到的指标示例，让我们为其中一些添加维度。了解维度会改变你从一个指标中接收到的信息。维度在以下列表中已加粗：

* 一场体育比赛中 **各队** 获得的进球或得分
* 医学研究中的人数，以及了解他们的 **年龄、身高或健康水平**
* 按 **来源国家、使用的设备类型，或是否购买** 划分的网站用户
* 线上销售产品的销售收入，按 **按国家划分的销售额或按类别划分的销售额** 细分
* 一天内向用户展示的错误数量，按 **错误类型以及错误对客户影响的严重程度** 细分

如果你在寻找数据的维度时遇到困难，只需向自己描述它。如果你听到诸如“按……细分”或“每……”之类的神奇短语，你就会知道这些元素正在划分数据，并且在大多数情况下，能让你更好地了解维度如何影响你所计数指标。

让我们想想赫尔曼的蛋糕店。就我们的蛋糕而言，我们可以想到哪些信息有助于进一步了解哪些产品卖得好？

我们知道我们在卖蛋糕，但还有其他维度可以从数据中细分出来，为我们提供更多背景信息。仅仅知道我们卖出了 100 个蛋糕，并不能真正帮助我们的团队了解他们未来应该生产哪些类型的蛋糕。

你通常可以通过查看你销售的产品，或询问企业或其客户，了解他们认为影响产品销量的“决定性因素”是什么，从而找出你所售蛋糕的最重要特征。仅仅问面包师产品之间有什么不同就是一个很好的开始。

* 蛋糕的尺寸是多少？是茶点蛋糕、杯子蛋糕，还是多层婚礼蛋糕？
* 蛋糕的味道是什么？巧克力味、香草味、胡萝卜味还是香蕉味？
* 蛋糕的装饰主题是什么？是只在顶部覆有糖霜的普通蛋糕，还是为一对即将结婚的新人精心装饰的蛋糕？

从烘焙店的例子可以看出，有很多决定因素与我们正在进行的销售相关。了解某些口味更受欢迎是一项至关重要的知识，因为这意味着烘焙师可以重点展示这些最受欢迎的口味。

最后要记住的一点是：大多数现代企业分析的都是“多维”数据——这意味着数据并非仅仅依赖于单一维度来解释。以我们的蛋糕为例，烘焙店会销售众多口味的纸杯蛋糕，但针对每一种口味，我们可能又有多种不同味道的奶油糖霜。我们还可能有多种不同的主题，而这些主题的销售情况又会根据星期几或季节的不同而有所差异。例如，无糖蛋糕可能会在某些特定人群中销量很好。

这就是优秀的数据开发者或数据可视化工程师的用武之地。维度为指标提供了背景信息，并帮助理解数据。你有能力在数据集上“尝试”一组维度，看看它是否能为最终用户提供更多洞察。你也可以查看数据是否与你试图实现的业务目标有很强的关联性。

## 本章小结

在本章中，我们讨论了指标本身或聚合后的指标如何变得有价值，尤其是在结合维度考虑其背景信息时。
