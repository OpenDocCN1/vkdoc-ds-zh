# 记住：你是一位数据开发者

当人们听到“开发者”这个词时，他们对这个角色的含义会有一些先入为主的看法。最常见的印象是，开发者是天才能以计算机般的方式在脑中处理海量算法来生成代码。这是一种误解。开发者只是普通人，他们投入时间学习编程语言，并理解所用技术的工具、技巧、细微差别和特性以产出成果。任何专业工作，无论是砌砖工、水管工还是开发者，都需要你学习行业工具来建造人们所需的东西。按我的定义，开发者就是从无到有创造事物的人。房地产开发商买下一块土地，建造房屋供人居住。Web 开发者则从零开始构建应用或网站。

在大多数传统、行动缓慢的组织中，负责为企业创建仪表板的人员，其职位通常包含“分析师”或“数据经理”等字眼。如果你在这样的组织工作，我希望你能跳出“分析师”的框架，开始将自己视为一名“开发者”，并在构建数据可视化报告时采用开发者的思维方式。

在一些更具前瞻性的组织中，专门从事仪表板构建或数据管道创建的人员的职位通常被称为 BI（商业智能）开发者或数据工程师。

通过迈出这精神上的第一步，称自己为开发者，你将把以下三个事实牢记于心：

1.  作为构建企业依赖其进行进度跟踪和决策的数据可视化系统的人，你和那些确保电商网站正常运行的人同样有价值。
2.  你的工作可以对企业的成功产生至关重要的影响。
3.  掌握数据开发技能的同时，也肩负着责任，要确保你开发的内容质量高、准确无误，并且适合其预期用途。

在我为企业构建数据报告的过程中，得益于使用了通常被视为开发流程的方法。这不是因为我试图把事情搞得更复杂，而是为了专注于交付可靠且可维护的数据可视化成果。数据开发者的角色可能是现代企业中最具影响力的角色之一，因此我们有必要做好工作，把事情弄对。恭喜你，欢迎进入开发者的世界！
