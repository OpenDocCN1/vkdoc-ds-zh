# 开启你的 Data Studio 之旅

构建你的第一份 Data Studio 报告

> *问题催人奋进。问题让我们看见生活的美好。永远不要停止提问。*
>
> ——彼得·考德隆，《你好，世界》(自出版，2019 年)

如今被视为“数据专家”或“数据大师”的大多数人，或许看起来像“巫师”，但他们也曾是初学者。某天，某件事促使他们决定开始尝试使用数据可视化工具。也许是一个周末或一个晚上，他们没有瘫在电视机前，而是选择打开笔记本电脑，开始摆弄一款数据工具。对他们来说，这个过程起初相当令人沮丧，因为坦率地讲，文档通常不怎么好，示例也往往更难以理解。在我的个人旅程中，我发现即使是为了完成一些我认为非常基础的任务，我也可能花上数小时去理解各种概念和想法。我最终找到了自己的路，但过程充满了压力和痛苦的学习经历。

好消息是，我们将一起踏上这段旅程。在本章中，我将引导你迈出使用 `Data Studio` 的第一步，并与你并肩作战，直到你准备好独当一面。

所以，拉把椅子坐下，确保手边有一杯好喝的饮料，我们就要开始尝试在 `Data Studio` 中构建你的第一份数据报告了。

## 开启你的数据之旅

我总是说，不是你找到了数据，而是数据找到了你。我曾与来自各行各业的无数人合作过，他们对数据的理解和兴趣处于不同阶段。通过我在各种会议和聚会上进行的演讲，我有幸遇到了许多正处于对数据产生兴趣初期阶段的人。最令我惊叹的是，他们来自如此多样的背景。他们唯一的共同点是，都曾面临一个让自己陷入困境的挑战或十字路口。他们知道自己理解中缺少了某一块，并正在寻找数据的“超级英雄”来拯救他们。

我当然希望数据是一颗神奇的子弹，可以简单启动就能解决问题；然而，在现实中，找到数据仅仅是旅程的开始。对一些人来说，他们在数据之路上走了一段后，可能会发现自己已经足够了，于是转向其他感兴趣的事情。而对另一些人来说，他们将被推向每周都在涌现的、大量精彩的新数据工作专业领域。

数据科学家、数据工程师、人工智能工程师——这些几年前还相当罕见的新角色，现在在大多数组织中都变得越来越普遍。可以说，如今即使要成为一名相当称职的数字营销经理，也需要具备以前只有数据分析师才需要的数据素养水平。

无论你选择哪条路（或者不选），我学到一个突出的事实是：每个人都能从数据可视化技能中获益。它可以帮助你：

- 用数据讲故事

- 带领你的受众与你一同踏上旅程

- 帮助你的受众理解你的数据并从中提炼洞察

就我个人而言，我发现我的大脑就是无法处理成堆的数字或文字。我使用数据可视化作为探索和理解数字的方法。这就像查看一张海滩图片与感受指间沙粒、聆听海浪拍岸之间的区别。

数据可视化让数据变得鲜活，并将其转化为真实的东西。

## 企业对数据的态度

在我的职业生涯中，一个分水岭般的发现是：企业在使用数据方面，与人们非常相似。数据的使用方式因人们的生活和经历而存在巨大差异。有些人高度依赖数据生活，无论是分析预算、规划未来，还是优化账单、通勤，甚至是在哪里购买日用品。另一些人则随遇而安，依靠自己的个性和直觉来获取生活中想要的东西。

当你开始将数据应用于企业时，首先需要了解这家企业对数据的态度。在公司的文化中，数据要么是业务的核心驱动力，要么是上级强加给别人的烦恼，其唯一使命就是阻止别人做自己想做的事。

我认为企业是极其复杂且重要的实体，不能依赖数据来做决策是行不通的。一个好的品牌或产品只能带你走这么远，之后你就需要开始理解市场和商业目标才能成功。当我遇到那些嘲笑数据的人时，我总是强调一点：数据从来不是企业的首要任务，直到它成为*首要*任务（当事情进展不顺时，这种情况会以难以置信的速度和突然性发生）。

在大学时，我忍受着无数枯燥乏味的统计学课程，并痛恨它们从不实用，总是停留在理论层面。如果我当时知道这些知识的应用前景，我可能仍然不会喜欢它们，因为它们对我来说不够真实。我非常希望当时能有真实世界的例子来教我数据这门手艺的方方面面。作为一个通过实践来学习的人，这是我能理解任何事物的最有效方式，而这也正是我试图通过这本书做到的。

那么，让我们一起继续深入 `Data Studio` 的旅程吧。我深情地回忆着自己的旅程，并希望我能为你缩短一些痛苦的过程，分享一些我在熟练掌握数据的道路上，迈出各种步伐（以及误入歧途）时所积累的积极经验。
