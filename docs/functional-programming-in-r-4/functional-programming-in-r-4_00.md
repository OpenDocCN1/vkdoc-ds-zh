
# 关于作者

**托马斯·迈隆德**（Thomas Mailund）是丹麦量子计算公司 Kvantify 的高级软件架构师。他拥有数学和计算机科学背景，目前致力于开发适用于量子计算的计算问题的算法。他曾在奥胡斯大学生物信息学研究中心从事遗传学与进化研究，特别是比较基因组学、物种形成以及新兴物种间的基因流动。他曾通过 Apress 出版社出版了 *《基于 R 语言的数据科学入门》* 等著作。

# 关于技术审校

**梅根·J·希尔尼**（Megan J. Hirni）目前正在密苏里大学哥伦比亚分校攻读博士学位，研究方向为应用统计学。除了对`R`语言编码的热爱，梅根还热衷于结识新朋友并学习多领域交叉的新课题。
