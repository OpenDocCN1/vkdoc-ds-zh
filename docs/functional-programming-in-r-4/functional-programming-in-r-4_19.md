闭包在函数式编程中经常使用，因为它们提供了一种将数据与函数打包在一起的方式，使我们能够将领域信息与通用代码分离。之前，我们使用三个闭包调用了 `sapply()`（它代表简化版的 apply）。`sapply()` 函数对序列中的每个元素调用其参数函数。它不关心函数具体做什么，但该函数必须能接受一个参数调用。通过使用闭包，我们将一个执行加法的函数适配为已经绑定了其中一个加法参数的函数。通过这样做，我们将加法适配到了 `sapply()` 提供的接口。

我们也不需要特意编写返回闭包的函数。每当你定义一个函数，你就赋予它访问定义时作用域内所有变量的权限。所以如果你编写这样的代码：

```r
# 将 x 中所有元素增加 inc
inc_all <- function(x, inc) {
  sapply(x, \(a) a + inc)
}

inc_all(1:5, 3)
## [1] 4 5 6 7 8
```

你仍然创建了一个函数（本例中我们没有命名，它是函数 `\(a) a + inc`），该函数知道增量是多少，因此 `sapply()` 可以使用它，而无需将增量作为额外参数。

当然，一个向量表达式：

```r

当你使用 `<-` 时，如果局部变量不存在，就会创建一个新的局部变量。即使变量名在环境链更深层被发现，也没有影响。赋值始终是针对局部环境。

要赋值给环境链中更深层的变量，你需要使用运算符 `<<-`。这个运算符会像 R 语言确定表达式求值方式一样，沿环境链向上搜索，并在找到该变量的环境中进行更新（如果环境链中找不到该变量，则将其添加到全局环境中）。

我们来看一下将示例中的赋值运算符更改后会发生什么：

```
Make_counter <- function() {
  x <- 0
  count <- function() {
    x <<- x + 1
    x
  }
}

counter <- make_counter()
counter()
## [1] 1
counter()
## [1] 2
counter()
## [1] 3
```

这次，当我们进行赋值时，发现外层环境中存在一个 `x`，即我们在调用 `make_counter` 时初始化的那个 `x`。因此，该赋值针对的是那个环境，而不是局部环境。每次调用 `counter` 时，我们都会创建一个新的函数实例环境，但所有实例都链接到同一个外层环境，因此每次调用该函数时，我们都会更新同一个环境。

我们可以结合使用这个计数器函数和 `<<-` 运算符，来创建 `depth_first_numbers` 函数的一个更简单版本，这样就不需要在递归调用中传递数据了。我们可以在最外层作用域中创建一个表格和一个计数器函数，然后直接使用该计数器并通过 `<<-` 对表格进行赋值：

```
depth_first_numbers <- function(tree) {
  table <- c()
  counter <- make_counter()
  traverse_tree <- function(node) {
    if (is.null(node$left) && is.null(node$right)) {
      dfn <- counter()
      node$range <- c(dfn, dfn)
      table[node$name] <<- dfn
      node
    } else {
      left <- traverse_tree(node$left)
      right <- traverse_tree(node$right)
      new_node <- make_node(node$name, left, right)
      new_node$range <- c(left$range[1], right$range[2])
      new_node
    }
  }
  new_tree <- traverse_tree(tree)
  list(tree = new_tree, table = table)
}

result <- depth_first_numbers(tree)
print_tree(result$tree)
## [1] "((A,B) ,D)"
result$table
## A B D
## 1 2 3
```

**词法作用域与动态作用域**

这种根据函数定义时所处环境来查找变量值的规则，被称为词法作用域，是最常见的作用域标准。之所以这样称呼，是因为原则上你可以通过代码判断表达式中的变量是在哪里定义的。首先，你检查变量是否在当前局部环境中设置，可以是局部变量或函数参数。如果没有，你会查看外围代码，检查该变量是否在该环境中。外围代码可以是全局环境，也可以是另一个函数。如果它是一个函数且变量未定义，你会沿着函数定义处的代码继续向外查找。如果变量到值的映射取决于函数被调用的位置而非定义的位置（即所谓的动态作用域），那么仅通过阅读函数定义处的代码，你无法确定变量名所引用的到底是哪个变量。

R 语言支持两种作用域，其中词法作用域是默认的（标准求值模式）。尽管如此，通过修改环境链，你可以访问调用函数的作用域（在非标准求值模式下）。在某些情况下，非标准求值可以为你的代码提供更简洁的接口，但在大多数项目中，你应该坚持使用标准的词法作用域，因为它是最容易处理的。

需要动态作用域和非标准求值的一个常见场景是，当你需要对表达式求值，而表达式中的数据部分存在于变量中，部分存在于数据框中时。在这里，如果你能像使用标准变量一样使用数据框变量，就能获得更简洁的接口。因此，我将给出一个如何实现这一点的例子。

我们将编写一个函数，它接受一个表达式和一个数据框作为输入，并在一个环境中对该表达式求值，该环境会优先在数据框中查找变量。如果找不到，它会在调用者（而非函数）的环境中查找。

该函数看起来像这样：

```
df_eval <- function(expr, df = list()) {
  x <- substitute(expr)  # 剥离 expr 的环境；现在只是引号内的表达式
  env <- list2env(df, parent = parent.frame())
  eval(x, env)
}
```

我们使用 `substitute()` 函数来剥离 `expr` 的环境。它将 `expr` 转换为原始表达式，就像我们可以用 `quote()` 创建的那样。我将其存储在变量 `x` 中，是为了稍后说明一个要点；通常情况下，我可能仍会称它为 `expr`。

无论如何，接下来我们根据数据框创建一个新环境。数据框也是列表，因此 `list2env()` 会创建一个环境，其中数据框中的每个变量都存储为环境变量。新环境的父环境是 `parent.frame()`，即调用者的环境。这样设置会将数据框放在前面，因此我们在查找父框架之前，会先使用数据框中的变量。如果在数据框中找不到某个变量，我们就会在调用者的环境中查找。最后，我们在新环境中对 `x` 进行求值。

让我们设置一些数据来进行实验：

```
x <- 1:3
y <- "foo"
df <- data.frame(y = 2:4, z = 3:5)
```

我们在调用者的环境中有一个 `x` 和一个 `y`，在数据框中有 `y` 和 `z`。我们希望函数选择这个 `x`（而不是 `df_eval` 内部的 `x`），并且如果我们调用 `df_eval` 并传入 `df` 作为数据框，我们不应该选择变量 `y`，而应该选择数据框中的 `y`。

# 第 5 章：高阶函数

*高阶函数*这个术语指的是那些以函数作为参数或返回函数的函数。我们在前一章中用来创建闭包的函数就是高阶函数。

在 R 中，高阶函数经常被用来替代循环控制结构，我们将在下一章中详细介绍如何做到这一点。在转向使用函数操作函数的更有趣的内容之前，我先在这里给出一个简单的例子。

我们在上一章中看到的 `sapply` 函数，允许你对列表或向量中的所有元素调用一个函数。你应该主要在 R 的交互式使用中用这个函数，因为它有点不安全。它会根据你给出的输入和函数的行为来猜测你想要的输出类型，这里有更安全的替代方案，`vapply` 和 `lapply`，它们的输出类型分别是预定义的类型或始终是列表。

无论如何，如果你想对向量中的所有元素求值一个函数，你可以编写如下代码：

```r
sapply(1:4, sqrt)
## [1] 1.000000 1.414214 1.732051 2.000000
```

这会对向量 `1:4` 中的所有元素求值 `sqrt` 并给出结果。它是向量化表达式的一种类比，如果你的表达式可以向量化，向量化版本可能总是更优的。向量表达式更易读，并且如果涉及调用内置函数，通常会快得多：

```r
sqrt(1:4)
```

但是，当你想要调用的函数没有被向量化时，你可以使用 `sapply` 对序列中的所有元素求值该函数。事实上，我们在第一章中看到的 `Vectorize` 函数就是使用 `sapply` 的表亲 `lapply` 实现的。

我们可以像这样实现自己的版本：

```r
myapply <- function(x, f) {
  result <- x
  for (i in seq_along(x))
    result[i] <- f(x[i])
  result
}

myapply(1:4, sqrt)
## [1] 1.000000 1.414214 1.732051 2.000000
```

这里，我通过复制 `x` 创建了一个长度正确的结果向量。对这个向量的赋值可能会创建副本。第一次赋值肯定会，因为我们正在修改一个向量，R 通过制作副本来避免这种情况。后续的赋值可能会再次进行此操作，以转换结果的类型。尽管如此，其工作原理仍然相当简单明了，并且如果输入和输出具有相同类型，它将以线性时间运行（取决于对 `f` 的函数调用次数，而 `f` 本身可以具有任意时间复杂度）。

使用像 `sapply` 或 `myapply` 这样的函数，或者它们的任何同类，让我们可以用一个函数调用来替换循环，而在循环中，可能会发生各种我们不希望发生的对局部变量的赋值。我们只需要将循环体包装在另一个我们可以传递给 apply 函数的函数中。

如果我们需要将某些信息传递给函数，闭包与 apply 函数结合使用会特别有用。例如，让我们考虑一个需要对向量中的元素进行缩放的情况。我们在第一章中编写了这样一个函数：

```r
rescale <- function(x) {
  m <- mean(x)
  s <- sd(x)
  (x - m) / s
}

rescale(1:4)
## [1] -1.1618950 -0.3872983  0.3872983  1.1618950
```

这个函数是用向量表达式编写的，这是正确的做法，但让我们看看可以用 apply 函数做什么。显然，我们仍然需要计算 `m` 和 `s`，然后需要一个计算 `(x - m) / s` 的函数：

```r
rescale <- function(x) {
  m <- mean(x)
  s <- sd(x)
  f <- function(y) (y - m) / s
  myapply(x, f)
}

rescale(1:4)
## [1] -1.1618950 -0.3872983  0.3872983  1.1618950
```

其实没有必要给函数命名然后再传递它；我们也可以这样写：

```r
rescale <- function(x) {
  m <- mean(x)
  s <- sd(x)
  myapply(x, \(y) (y - m) / s)
}

rescale(1:4)
## [1] -1.1618950 -0.3872983  0.3872983  1.1618950
```

我们传递给 `myapply` 的函数 `\(y) ...` 知道它被创建时的环境，因此它知道 `m` 和 `s`，并且可以在从 `myapply` 调用时使用这些变量。

## 柯里化

我们经常会遇到这样一种情况：有一个两个参数的函数，你想要绑定其中一个参数，并返回一个以第二个参数为参数的函数。例如，如果我们想使用函数

```r
f <- function(x, y) x + y
```

我们可能想要使用 `myapply` 将其应用于一个序列，给每个元素加上 2。再次强调，这个例子只是为了向你展示一种通用技术，当你可以用向量表达式解决问题时，永远不应该做这些事情。尽管如此，让我们暂时假装我们没有向量表达式。那么我们需要为其中一个参数（比如 `y`）创建一个函数，然后在调用时求值 `f(2, y)`。

显然，我们可以这样写：

```r
g <- function(y) f(2, y)
myapply(1:4, g)
## [1] 3 4 5 6
```

或者更简洁地写成：

```r
myapply(1:4, \(y) f(2, y))
## [1] 3 4 5 6
```

如果我们只需要给序列中的所有元素加 2，这就足够了。如果我们想要一个更通用的解决方案，我们需要一个函数来创建我们需要的函数，一个记住 `x` 并且可以用 `y` 调用的闭包。编写这样的函数稍微复杂一点；我们只需要一个返回如下函数的函数：

```r
h <- function(x) \(y) f(x, y)
myapply(1:4, h(2))
## [1] 3 4 5 6
```

函数 `f` 和 `h` 最终做的是同一件事，唯一的区别在于我们如何向它们提供参数。函数 `f` 需要同时提供两个参数，而函数 `h` 一次只接受一个参数：

```r
f(2, 2)
## [1] 4

h(2)(2)
## [1] 4
```

像 `h` 这样的函数，它不是通过单个函数调用接收一系列参数，而是通过一系列函数调用，每个调用接受一个参数并返回一个新函数，这被称为*柯里化*函数。我们将 `f` 转换为 `h` 的过程称为对 `f` 进行*柯里化*。这些名称源自逻辑学家哈斯凯尔·柯里，函数式编程语言 Haskell 的名字也来源于他。

我们手动完成了从 `f` 到 `h` 的转换，但我们可以编写一个转换函数的函数：一个接受函数作为输入并返回另一个函数的函数。因此，我们可以编写一个通用的柯里化函数的函数——另一个高阶函数。一个用于柯里化两个参数的函数的函数可以这样编写：

```r
curry2 <- function(f) \(x) \(y) f(x, y)
```

参数 `f` 是我们想要柯里化的函数，返回值是函数

```r
\(x) \(y) f(x, y)
```

它需要先使用参数 `x` 调用，然后使用参数 `y` 调用，之后它将返回值 `f(x, y)`。这里的变量名无关紧要，它们只是名称，不必与 `f` 实际使用的变量名有任何关系。

使用这个函数，我们可以自动从 `f` 创建 `h`：

```r
h <- curry2(f)

f(2, 3)
## [1] 5

h(2)(3)
## [1] 5
```

由于 `+` 在 R 中只是一个函数，我们也可以直接使用*它*，而无需先编写函数 `f`：

```r
h <- curry2(`+`)
h(2)(3)
## [1] 5
```

因此，可以用如下代码实现给序列中所有元素加 2 的操作：

```r
myapply(1:4, curry2(`+`)(2))
```
