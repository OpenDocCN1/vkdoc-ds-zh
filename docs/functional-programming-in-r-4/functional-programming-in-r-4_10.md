## 函数没有名称

在讨论函数定义时，我想强调的最后一点是：函数本身并没有名称。变量才有名称，变量可以指向函数，但这是两个不同的概念。

在许多语言，比如 Java、Python 或 C++ 中，当你定义一个函数时，同时也会给它一个名称。即便在允许的情况下，你也需要借助特殊的语法才能定义一个没有名称的函数。

但在 R 语言中并非如此。在 R 里，函数没有名称，当你定义它们时，并没有赋予它们名字。之前我们使用过的所有函数，都是通过在定义处将它们赋值给变量来命名的。但我们并非必须这样做。实际上，是 `function(...) ...` 这个语法定义了函数。无论我们是否将其赋值给变量，都是在定义一个函数。

### 第 2 章 R 语言中的函数

我们可以像这样定义一个函数并立即调用它：`(function(x) x²)(2)`

## [1] 4

当然，我们通常不会这样做。在任何需要定义匿名函数并立即调用的场景下，我们大可直接使用函数体。对于想要复用的函数，我们*必须*给它一个名称，以便能够再次调用它。

然而，定义函数的语法并不强制我们给函数命名。当你开始编写高阶函数（即接受其他函数作为输入或返回函数的函数）时，这种特性会非常便利。

这类高阶函数是函数式编程的重要组成部分，我们在本书后面会经常遇到它们。

## 向量化函数

R 语言中的表达式是向量化的。当你编写一个表达式时，它会隐式地作用于值的向量，而不是单个值。即使是只涉及数字的简单表达式，本质上也是向量运算，只不过这些向量的长度为 1。

对于更长的向量，表达式会按元素逐个进行计算。因此，如果你有向量 `x` 和 `y`，只需写成 `x - y` 就可以实现第二个向量元素减去第一个向量元素的操作：

```
x <- 1:5
y <- 6:10
x - y
```

## [1] -5 -5 -5 -5 -5

如果向量的长度不同，较短的向量会根据需要被重复多次。这就是为什么你可以将一个数与一个向量相乘，例如：

```
2 * x
```

## [1] 2 4 6 8 10

这里，`2` 是长度为 1 的向量，`x` 是长度为 5 的向量，`2` 被重复了五次。如果较长向量的长度不是较短向量长度的整数倍，你会收到一个警告，通常应尽量避免这种情况。不过语义是一样的：R 会尽可能多次地重复较短的向量，直到与较长向量长度匹配。

```
x <- 1:6
y <- 1:3
x - y
```

## [1] 0 0 0 3 3 3

根据函数的编写方式，它也可以用在向量化表达式中。只要函数调用的结果是一个向量，R 就乐意将其用于向量表达式。但这与函数对向量按元素进行操作并非完全相同。这样的函数我们可以称之为*向量化*函数。

大多数数学函数，如 `sqrt`、`log`、`cos` 和 `sin`，都是向量化的，你可以在表达式中使用它们：

```
log(1:3) - sqrt(1:3)
```

## [1] -1.0000000 -0.7210664 -0.6334385

如果你自己编写的函数的主体仅包含向量化表达式，那么该函数也会是向量化的：

```
f <- function(a, b) log(a) - sqrt(b)
f(1:3, 1:3)
```

## [1] -1.0000000 -0.7210664 -0.6334385

我们在本书中编写的第一个函数 `square` 也是一个向量化函数。函数 `scale` 同样如此，尽管它内部使用的 `mean` 和 `sd` 函数并非向量化函数；它们接收向量输入，但返回的是整个向量的汇总统计量，而不是对向量分量进行操作。

使用了控制结构的函数通常不会是向量化的。

我们可以编写一个比较函数，如果第一个参数小于第二个参数则返回 -1，如果第二个参数大于第一个参数则返回 1，否则返回 0，如下所示：

```
compare <- function(x, y) {
  if (x < y) {
    -1
  } else if (y < x) {
    1
  } else {
    0
  }
}
```

这个函数对于单个值工作良好，但不适用于向量。问题在于 `if` 表达式只会查看逻辑向量 `x < y` 的第一个元素。（没错，`x < y` 是一个向量，因为 `<` 是一个向量化函数。）

为了处理 if 表达式，我们可以使用 `ifelse` 函数来绕过这个问题。这是一个向量化函数，其行为类似于 if-else 表达式：

```
compare <- function(x, y) {
  ifelse(x < y, -1, ifelse(y < x, 1, 0))
}
compare(1:6, 1:3)
```

## [1] 0 0 0 1 1 1

情况并非总是简单到可以用 `ifelse` 替换 if 语句。大多数情况下可以，但当不能时，我们可以改用 `Vectorize` 函数。这个函数接受一个可操作单个值的函数，并将其转换为能按元素处理向量的函数。

举个例子，我们可以使用之前的 `compare` 函数并对其进行向量化：

```
compare <- function(x, y) {
  if (x < y) {
    -1
  } else if (y < x) {
    1
  } else {
    0
  }
}
compare <- Vectorize(compare)
compare(1:6, 1:3)
```

## [1] 0 0 0 1 1 1

默认情况下，`Vectorize` 会对函数的所有参数进行向量化。例如，假设我们想要一个缩放函数，它不按同一个向量的均值和标准差来缩放该向量中的所有变量，而是使用另一个向量的均值和标准差：

```
Scale_with <- function(x, y) {
  (x - mean(y)) / sd(y)
}
```

这个函数在其第一个参数上已经是向量化的了，因为它仅由一个向量化表达式组成，但如果对其使用 `Vectorize`，反而会破坏它：

```
scale_with(1:6, 1:3)
```

## [1] -1 0 1 2 3 4

```
scale_with <- Vectorize(scale_with)
scale_with(1:6, 1:3)
```

## [1] NA NA NA NA NA NA

用 `Vectorize` 创建的函数对 `x` 和 `y` 都是向量化的，这意味着它会按分量对它们进行操作。在缩放时，该函数只看到 `y` 的一个分量，而不是整个向量。结果会得到一个缺失值向量 NA，因为单个值的标准差是未定义的。

我们可以通过显式告诉 `Vectorize` 哪些参数需要向量化来解决这个问题——在本例中，只有参数 `x`：

```
Scale_with <- function(x, y) {
  (x - mean(y)) / sd(y)
}
scale_with <- Vectorize(scale_with, vectorize.args = "x")
scale_with(1:6, 1:3)
```

## [1] -1 0 1 2 3 4

举个例子，我们可以考虑一个树形数据结构，以及一个用于计算命名节点深度的函数——节点深度定义为到根节点的距离。为简单起见，我们只考虑二叉树。

我们可以使用列表来实现树：

```
Make_node <- function(name, left = NULL, right = NULL) list(name = name, left = left, right = right)
```

要计算节点深度，我们可以递归地遍历树：

```
node_depth <- function(tree, name, depth = 0) {
  if (is.null(tree)) return(NA)
  if (tree$name == name) return(depth)
  left <- node_depth(tree$left, name, depth + 1)
  if (!is.na(left)) return(left)
  right <- node_depth(tree$right, name, depth + 1)
  return(right)
}
```

这并非一个特别复杂的函数，但它比 `scale_with` 函数更难向量化。就其本身而言，它对单个名称运行良好：

**中缀运算符**

R 中的中缀运算符也是函数。你可以用其他函数覆盖它们（但你真的不应该这样做，因为可能会搞乱大量代码），你也可以创建自己的中缀运算符。

用户定义的中缀运算符是具有特殊名称的函数。名称以`%`开头和结尾的函数会被 R 视为中缀运算符。创建用作中缀运算符的函数没有特殊语法，只是它应该接受两个参数。不过，变量赋值有特殊语法，包括名称以`%`开头和结尾的变量。

`` `+`(2, 2) ``

R 解析器识别控制结构关键字和各种运算符，例如算术运算符，因此它们拥有特殊语法。但它们实际上都只是函数。甚至括号也是函数`(`的特殊语法，下标运算符也是如此，分别是`` `[` ``和`` `[[` ``。如果你引用它们，你就得到了一个变量名，可以像使用其他任何函数名一样使用它。

## 第 2 章 R 语言中的函数

在 R 语言中，当你给一个变量赋值时，你实际上是在调用赋值函数 ``<-``。当你给向量或列表中的某个元素赋值时，你使用的是 ``[<-`` 函数。但其实还有一整类这样的函数，它们可以让你在不实际修改对象的情况下，做出修改对象的样子。这些函数被称为替换函数，其名称以 ``<-`` 结尾。一个例子是 ``names<-`` 函数。如果你有一个向量 `x`，你可以使用如下语法为其元素命名：

```r
x <- 1:4
x
## [1] 1 2 3 4

names(x) <- letters[1:4]
x
## a b c d
## 1 2 3 4

names(x)
## [1] "a" "b" "c" "d"
```

这里涉及两个不同的函数。最后一个表达式，它返回了 `x` 的名称，这是 `names` 函数。而我们用来将名称*赋值*给 `x` 的函数是 ``names<-`` 函数。

任何你定义的、名称以 ``<-`` 结尾的函数都会成为一个替换函数。其语法是，它会求值赋值运算符右侧的内容，并将结果赋值给它作为参数接收的那个变量。

因此，这个语法

```r
names(x) <- letters[1:4]
```

会被翻译成

```r
x <- `names<-`(x, letters[1:4])
```

## 第 2 章 R 语言中的函数

在这个求值过程中，没有任何值被破坏，只是变量被设置为了新的值。

我们可以使用这种语法编写自定义的替换函数。只有两个要求。函数名必须以 ``<-`` 结尾——因此我们在赋值时需要给名称加上引号——并且，用于赋值运算符右侧的那个值的参数，必须命名为 `value`。最后一个要求的存在，是为了使替换函数可以接受两个以上的参数。

``attr<-`` 函数就是一个例子。属性是可以与对象关联的键值对映射。你可以使用 `attributes` 函数获取与对象关联的所有属性，并使用 ``attributes<-`` 函数设置所有属性，但你可以使用 ``attr<-`` 来分配单个属性。它接受三个参数：要修改的对象 `attr(x, which) <- value`、一个 `which` 参数（即要设置的属性名称）、以及一个 `value` 参数（即赋值运算符右侧的值）。`which` 参数会与要修改的对象一起传递给左侧的函数：

```r
x <- 1:4
attributes(x)
## NULL

attributes(x) <- list(foo = "bar")
attributes(x)
## $foo
## [1] "bar"

attr(x, "baz") <- "qux"
attributes(x)
## $foo
## [1] "bar"
##
## $baz
## [1] "qux"
```

```r
`right<-` <- function(node, value) {
    node$right = value
    node
}
```

## 第 2 章 R 语言中的函数

为了查看结果，我们可以编写一个用于打印树的函数。为了保持函数简单，我假设要么两个子节点都是 `NULL`，要么两个都是树。要扩展它以处理不满足此条件的树很简单，只是会让函数稍长一些：

```r
print_tree <- function(tree) {
    build_string <- function(node) {
        if (is.null(node$left) && is.null(node$right)) {
            node$name
        } else {
            left <- build_string(node$left)
            right <- build_string(node$right)
            paste0("(", left, ",", right, ")")
        }
    }
    build_string(tree)
}

print_tree(tree)
## [1] "((A,B),D)"
```

这个函数以所谓的 Newick 格式显示树，并且不会显示内部节点的名称，但你可以看到树的结构。
