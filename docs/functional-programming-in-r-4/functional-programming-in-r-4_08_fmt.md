# 第 1 章：引言

欢迎阅读 *《R 4 中的函数式编程》*。我撰写这本书的初衷，是希望提供超越大多数 R 教材典型入门水平（即将函数视为封装可重用指令的简单构造，在需要执行这些指令时进行调用）的教学材料。在诸如 R 这样的语言中，函数远不止于此。它们本身就是对象，你可以像处理其他对象一样将其视为数据、创建、操作并传递。学会这一点将使你成为一名更高效的 R 语言编程者。

R 语言是一种多范式语言，融合了过程式编程、面向对象编程和函数式编程的元素。过程式编程侧重于希望计算机执行的指令——如相加这些数字、将结果存入变量、循环遍历列表等。面向对象编程则侧重于你操作的数据类型、可对其执行的操作，以及操作后数据如何变化。如果你对 R 语言的这些方面感兴趣，我撰写了另一本由 Apress 出版的著作 *《R 中的高级面向对象编程》*，或许正合你意。

函数式编程是第三种编程风格，其重点在于转换。函数将数据从输入转换为输出，通过组合这些转换，你可以从简单函数构建出涉及数据处理的复杂管道。在函数式编程中，函数本身被视为数据，就像其他数据一样，你可以编写将函数作为输入并生成（其他）函数作为输出的转换。因此，你可以编写简单函数，然后（通过其他函数）对它们进行修改，并以多种方式组合，从而构建完整的程序。

R 编程语言支持过程式编程、面向对象编程和函数式编程，但它主要是一种函数式语言。不过，它并非“纯”函数式语言。纯函数式语言不允许你通过更改参数值来修改程序状态，也不允许函数产生副作用（因此需要各种技巧来处理程序输入和输出）。R 语言在一定程度上接近“纯”函数式语言。通常，数据是不可变的，因此函数内部对数据的修改通常不会改变函数外部数据的状态。但 R 确实允许副作用，例如打印数据或绘制图形，当然也允许变量改变值。

*纯*函数没有副作用，因此使用相同输入调用的函数始终返回相同输出。纯函数因此更易于调试和推理，因为它们可以独立地进行分析，不依赖于其被调用的上下文。R 语言并不保证你编写的函数是纯函数，但你可以仅使用纯函数来编写大部分程序。通过保持代码的纯函数性，你将编写出更健壮、且更易于在需要时修改的代码。你应该将不纯的函数集中到程序的一小部分中。这些函数通常是那些需要采样随机数据或产生输出（文本或图形）的函数。如果你知道不纯函数所在的位置，你就知道在修改代码时何时需要格外小心。
