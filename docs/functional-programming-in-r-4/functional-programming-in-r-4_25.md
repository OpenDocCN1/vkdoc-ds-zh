使用 `%>%` 时，你可以通过函数名来组合函数，例如 `mean %>% sqrt`；但使用 `|>` 时，你必须组合函数调用，例如 `mean() |> sqrt()`。

`%>%` 运算符也支持后一种语法。

默认情况下，管道中上一步的输出会作为第一个参数传递给下一步的函数。若要编写适合此模式的自定义函数，你只需让通过管道传输的数据成为函数的第一个参数即可。

由于管道现在在 R 中频繁使用，大多数函数都遵循这一模式，并且在 `dplyr` 和 `tidyr` 等流行包中也是如此。`purrr` 包也设计为与 `magrittr` 管道良好配合。它的所有函数都将要操作的数据作为第一个参数，因此使用 `%>%` 或 `|>` 将多个转换串联起来非常直接。

并非所有函数都遵循此模式，主要是较旧的函数不遵循，但你可以使用变量 `.` 来引用在管道中传递的数据，当你需要将其放在非第一个参数的位置时：`data.frame(x = 1:4, y = 2:5) %>% plot(y ~ x, data = .)`。

不过，这仅受 `%>%` 运算符支持，`|>` 则不支持。

如果输入是数据框，你可以像使用任何其他数据框一样，通过列名来访问其列。参数依然是 `.`，你只需使用该参数来引用数据：`data.frame(x = 1:4, y = 2:5) %>% plot(.$x, .$y)`。

`. ` 参数可以在管道中的函数调用中多次使用，并且可以与管道中的函数调用一起使用，例如：

```
rnorm(4) %>% data.frame(x = ., y = cos(.))
```

## x y
## 1 -0.4606873 0.89574717
## 2 -0.2682750 0.96422956
## 3 -0.5016734 0.87677906
## 4 -1.6209375 -0.05012016

有一点需要注意：如果 `.` *仅*出现在函数调用内部，那么它*也会*作为第一个参数传递给函数。这意味着类似下例的代码将创建一个包含三个变量的数据框，第一个变量是一个名为 `.` 的列：

```
rnorm(4) %>% data.frame(x = sin(.), y = cos(.))
```

## . x y
## 1 0.78527169 0.70701735 0.7071962
## 2 -0.01757641 -0.01757551 0.9998455
## 3 -0.24785011 -0.24532033 0.9694421
## 4 -0.37395301 -0.36529810 0.9308906

虽然 `%>%` 运算符主要用于编写此类数据处理管道，但它也可以用于通过组合其他函数来定义新函数，此时函数按从左到右的顺序编写。编写此类函数就像编写数据处理管道一样，但让管道的第一步是 `.`，因此这是一个数据管道：

```
mean_sqrt <- 1:4 %>% mean %>% sqrt
mean_sqrt
## [1] 1.581139
```

而这是一个函数：

```
mean_sqrt <- . %>% mean %>% sqrt
mean_sqrt(1:4)
## [1] 1.581139
```

并且你可以在管道中使用这个函数：

```
1:4 %>% mean_sqrt
## [1] 1.581139
```

`|>` 运算符不支持这种编写函数的方式；你可以用它来组合函数调用，但它只是调用函数的语法糖，不能用于定义函数。在定义函数方面，`%>%` 运算符更加灵活。

你只能使用这种方法定义接受单个参数作为输入的函数。如果你需要多个参数，则需要显式定义你的函数。整个管道模式的工作原理是假设在函数调用之间传递的是单条数据。尽管如此，这并不妨碍你拥有复杂的数据（例如数据框），并以此方式模拟拥有多个参数。

例如，以我们之前编写的均方根误差函数为例：`rmse <- (\(x, y) (x - y)**2) %>% mean %>% sqrt`

这个函数接受两个参数，因此我们不能使用 `.` 来创建它。我们可以改为让它接受一个参数，例如一个数据框，并从中获取两个值：

```
rmse <- . %>% { (.$x - .$y)**2 } %>% mean %>% sqrt
data.frame(x = 1:4, y = 2:5) %>% rmse
## [1] 1
```

这里，我们还使用了 `magrittr` 的另一个特性，一种更简洁的编写匿名函数的语法。通过将表达式 `{(.$x - .$y)**2}` 写在花括号中，我们创建了一个函数，在其中可以将参数引用为 `.`。

当数据需要稍微调整以匹配上一个函数的输出和下一个函数的预期输入时，能够通过将表达式放在花括号中来编写匿名函数是非常方便的。

匿名函数还可以防止 `.` 参数在仅用于函数调用时被隐式地作为第一个参数传递给函数。如果表达式被包裹在花括号中，那么函数调用就不会以任何方式被修改，因此 `.` 不会作为第一个参数被隐式添加：

```
rnorm(4) %>% { data.frame(x = sin(.), y = cos(.)) }
```
