# 引言

## 量子计算革命

我撰写本书，旨在成为在云端编程量子计算机的终极指南。IBM 已将旗下的量子装置（即 `IBM Quantum`）向研究领域乃至所有对这一令人振奋的新计算领域感兴趣的普通个人开放。

量子计算正日益普及，现在正是学习编程这些机器的好时机。未来几年内，首批商用量子计算机有望问世，它们承诺相比经典计算机将带来显著的计算速度提升。在密码学领域，这一优势尤为突出：量子整数分解算法的性能远超最佳经典方案数个数量级，以至于该算法的实际应用足以使当前的非对称加密变得彻底无效。

总而言之，本书是一段理解的旅程。你可能会发现各章节中解释的某些概念难以掌握；但请记住，你并非孤身一人。伟大的物理学家理查德·费曼曾说过：“*如果有人告诉你他懂量子力学，那只能说明他不懂量子力学。*” 即便是这门奇特理论的巨擘们，也曾在理解其全部含义的挣扎中求索。

我尽力通过真实的算法、电路、代码和图形结果来探索量子计算。本书收录的一些算法违背常识，与其说它们是物理系统的计算描述，不如说更像巫术魔法。这正是我决定挑战这个主题的主要原因。尽管量子力学那令人费解的原理十分奇特，但我始终为之着迷。因此，当 IBM 推出其独一无二的云端量子计算平台并向大众开放时，我迫不及待地抓住了学习和创作本书的机会。

归根结底，这是我对该主题的理解，希望您在阅读时能像我写作时一样享受其中。我的建议是：学习编程量子计算机；它们很快将遍布数据中心，执行从搜索、模拟到医学和人工智能的各种任务。以下是本书内容概览。

# 第 1 章：量子场：现实的基石

一切始于 20 世纪 30 年代，源于马克斯·普朗克不情愿的天才构想。他提出了对光谱能量分布的全新诠释。他不情愿地假设光子的能量并非如经典物理学家所相信的那样由连续函数描述，而是由他称为`量子`的微小能量块构成，由此拉开了本世纪最伟大科学革命——`量子力学`——的序幕。本章是主菜前的开胃菜，探讨了物理学两大巨擘——阿尔伯特·爱因斯坦与尼尔斯·玻尔——之间的交锋。量子力学在 20 世纪 30 年代是一项革命性理论，大多数科学界人士不愿接受它，包括本世纪的巨人阿尔伯特·爱因斯坦。刚获得诺贝尔奖的爱因斯坦从未接受过量子力学的概率性本质，这导致他与量子力学最坚定的捍卫者尼尔斯·玻尔之间产生了裂痕。两位伟人争论了数十年，却始终未能弥合分歧。最终，量子力学经受住了 70 年的理论和实验挑战，每次都以胜利者姿态屹立不倒。阅读本章，您将在两位非凡人物的传奇故事背景下，探索相关的理论、实验与结果。

## 第 2 章：理查德·费曼：物理学半神，量子计算机之父

20 世纪 80 年代，伟大的物理学家理查德·费曼提出了量子计算机的概念——即一种能够利用量子力学原理来更快解决问题的计算机。构建这种机器的竞赛由此展开。本章以一般性术语探讨了量子计算机的基本架构：`量子比特`——量子计算的基本模块。它们看似不起眼，却拥有近乎神奇的特性：`叠加态`——信不信由你，一个量子比特可以同时处于 0 和 1 两种状态。在我们生活的宏观世界，这难以理解。然而，在原子尺度上，一切皆有可能。这一事实已通过实验验证超过 70 年。因此，叠加态使量子计算机能够用相对较少的量子比特执行大量计算，从而超越经典计算机。另一个令人费解的概念是`量子纠缠`：纠缠的量子比特在观测时，其状态传递速度能超越光速，跨越时间与空间！请好好琢磨这一点。总之，本章探讨了量子计算机的所有物理组件：量子门、各种类型的量子比特（如超导回路、离子阱、拓扑辫子等）。此外，还介绍了当前所有主要科技公司在相关领域的努力，以及量子退火等其他类型的量子计算。

## 第 3 章：看哪，量子比特革命

在本章中，我们将探讨该领域先驱 IT 公司设计的量子比特基本架构。你还将了解到，尽管量子比特大多仍处于实验阶段且难以构建，但这并不意味着不能凭借一些光学工具和巧思来建造一个。即使有些粗糙简陋，我们仍可以用折射晶体、光子发射器以及简单的预算来构建一个量子门。本章还将探讨超导回路作为构建量子比特的事实标准方法，以及其他流行的设计方案及其相互之间的关系。

# 第四章：走进 IBM Quantum：独一无二的云端量子计算平台

在本章中，你将初次体验 IBM Q Experience。这是首个面向大众提供真实或模拟量子设备的云端量子计算平台。传统上，真实的量子设备仅用于研究目的。但如今已今非昔比，多亏了 IBM 团队数十年的积累，他们慷慨地决定将其开放给公众使用。

你将学习如何使用可视化编辑器创建量子电路，或利用出色的 Python SDK 为程序员编写电路。然后在真实设备上执行电路，探索结果，并迈向量子程序员新职业的第一步。IBM 可能创建了首个云端量子计算平台，但竞争对手紧随其后。预计不久其他 IT 巨头也将推出新的云平台。现在是学习的最佳时机。

# 第五章：数学基础：是时候重温线性代数了

矩阵、复数和张量积是量子计算的三位一体。量子力学的奇异特性完全由矩阵描述。正是矩阵和复数的丰富诠释，造就了相较于传统标量数学更广阔的图景优势。量子力学听起来和看起来都很奇特，但归根结底只是花辣的线性代数。

# 第六章：Qiskit：用于 Python 量子编程的出色 SDK

`Qiskit` 代表 Quantum Information Software Kit（量子信息软件套件）。它是一个 Python SDK，可用于在云端或本地模拟器中编写量子程序。在本章中，你将学习如何在个人电脑上设置该 Python SDK。接着，你将了解如何用线性代数描述量子门，从而更深入地理解幕后的运作原理。这是你第一个量子程序的开胃菜，一个非常简单的示例，旨在让你熟悉 Python SDK 的语法。最后，你将在真实的量子设备上运行它。当然，量子程序也可以在可视化编辑器中创建。深入了解量子门——量子程序的基本构建模块。本章将涵盖所有这些内容，甚至更多。

# 第七章：启动引擎：从量子随机数到隐形传态与超密编码

本章将带你踏上一段探索量子系统三种非凡信息处理能力的旅程。量子随机数生成探讨了量子力学作为真正随机性来源的本质。你将学习如何通过非常简单的逻辑门和 Python SDK 实现这一点。接下来，本章将探讨两种相关的信息处理协议：超密编码和量子隐形传态。它们拥有炫酷的名称和近乎魔法的特性。发现它们的秘密，为可视化编辑器编写电路，用 Python 远程执行，最后解释并验证其结果。

# 第八章：博弈论：有了量子力学，胜算总在你这边

本章有点奇特：探索了两个游戏谜题，展示了量子算法相对于经典算法的非凡威力——假币谜题和梅尔明-佩雷斯魔方。在假币谜题中，量子算法用于在有限次使用天平寻找假币时，实现相对于经典解法的四次加速。梅尔明-佩雷斯魔方则是一个量子伪心灵感应的例子，即玩家几乎能读懂彼此心思，实现只有在游戏过程中通信才能达成的结果。

# 第九章：量子优势：Deutsch-Jozsa、Bernstein-Vazirani 和 Simon 算法

本章研究三种实际用途不大但很重要的算法，因为它们是首批证明量子计算机能比经典计算机显著更快解决问题的方法：`Deutsch-Jozsa`、`Bernstein-Vazirani` 和 `Simon` 算法。它们通过使用 `Hadamard` 门将输入置于叠加态，利用大规模并行性实现了显著的性能提升。同时，它们也阐释了关键概念，如对输入执行某种变换的预言机或黑盒，以及相位反冲——一种用于改变输入相位使其相互抵消的强大技术。

# 第十章：高级算法：`Grover` 和 `Shor` 的无序搜索与整数分解

本章展示了两款激发人们对实用量子计算可能性的热情的算法：`Grover` 搜索，一种无序量子搜索算法，平均能在 `\(\sqrt{N}\)` 步内找到输入。这远优于经典最佳解法的 `\(N/2\)` 步。看似差距不大，但面对超大型数据库时，该算法可在数据中心大显身手。预计未来所有网络搜索都将由 `Grover` 算法执行。`Shor` 整数分解：专家称这种臭名昭著的量子分解可能使当前的非对称密码学陷入瘫痪。这是量子计算威力的最佳例证，相比经典最佳解法实现了指数级加速。

# 第十一章：现实世界中的量子：前沿化学与蛋白质折叠

量子已在化学和医学领域积极发挥作用。本章展示两项惊人的真实实验，以说明其威力：基态在分子化学中至关重要，大多数元素使用晶格建模，其中顶点代表相互作用的原子。在本章中，你将学习如何通过使用晶格来最小化分子的能量哈密顿量，以达到其基态。其次，蛋白质是驱动所有生命的基本构建模块。可靠预测蛋白质结构极其复杂，并可能改变我们对自然的理解。在此实验中，你将了解蛋白质的氨基酸、肽、链、命名法等；最棒的是，你将学习如何用量子计算机预测其结构。
