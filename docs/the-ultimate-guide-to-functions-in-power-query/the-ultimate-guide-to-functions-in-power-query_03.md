## 关于作者

**奥米德·莫塔梅迪塞德**（Omid Motamedisedeh）是一名自由数据与商业智能分析师，拥有工业工程博士学位。他目前正在昆士兰科技大学攻读第二个博士学位。奥米德是多篇行业期刊论文（*《电力系统研究》*、*《建筑工程学报》*、*《能源》*、*《神经计算与应用》*等）的作者，还著有七本波斯语书籍，包括《通过数据验证管理 Excel 数据录入》、《利用 Excel 数据透视表进行数据分析》、《Power Query：Excel 的魔法》、《Excel 2016 中最实用的 222 个函数》、《Excel 2019 中有用的 Excel 函数》、《Excel 2021 函数参考手册》以及《从绘制图表到在 Excel 2016 中创建仪表盘》。
