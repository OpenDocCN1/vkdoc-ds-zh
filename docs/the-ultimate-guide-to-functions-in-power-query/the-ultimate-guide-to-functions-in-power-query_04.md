## 关于技术审校

**博·里多邦**（Bo Rydobon，又称 Excel 巫师）是一位来自泰国的 Microsoft Excel 专家和 YouTube 博主，以其高超的 Excel 技巧和速度闻名。他也是 Excel 巫师 YouTube 频道的创建者，在频道中分享使用高级动态数组的技巧和诀窍。他活跃于 `Excelforum.com` 论坛，并在数年内跻身声誉排名前五。

他参加 Excel BI LinkedIn Excel 挑战赛时令人印象深刻的响应引起了广泛关注。2022 年，博·里多邦赢得了由金融建模世界杯举办的 Excel 电竞速通赛。

博·里多邦是全球 Excel 用户的灵感源泉。他证明了无论背景或经验如何，任何人都能学习 Excel 并成为专家。
