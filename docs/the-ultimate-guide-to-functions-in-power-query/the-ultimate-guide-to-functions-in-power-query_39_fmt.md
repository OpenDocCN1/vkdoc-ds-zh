## 其他函数

除上述函数外，Power Query 中还有其他用于修改列表的函数。

### `List.Single`

该函数接收一个列表形式的输入。如果列表中只有一个值，则将该值作为输出显示。否则，该函数的结果将是一个错误。该函数的定义如下：

`List.Single(list as list) as any`

因此，公式 `List.Single({1})` 的结果是数字 `1`，而公式 `List.Single({1..4})` 的结果是一个错误。同样，公式 `List.Single({ })` 的结果是 `null`。

### `List.SingleOrDefault`

此函数类似于 `List.Single` 函数，但在本函数中，可以指定一个值作为输出显示，以替代错误。

该函数在 Power Query 中的定义如下：

```
List.SingleOrDefault(
   list as list,
   optional default as any
) as any
```

此函数接收两个输入。

1.  第一个输入定义了参考列表。

2.  此函数的第二个输入是可选的，如果函数的结果是错误，则在此输入中输入的值将替代错误显示。

因此，公式 `List.SingleOrDefault({1})` 的结果等于数字 `1`，公式 `List.SingleOrDefault({1..4})` 的结果是一个错误，但公式 `List.SingleOrDefault({1..4}, -1)` 的结果等于 `-1`。

### `List.Repeat`

使用 `List.Repeat`，可以按照指定的次数重复列表中的值，如下所示：

```
List.Repeat(
   list as list,
   count as number
) as list
```

此函数接收两个输入。

1.  第一个输入表示参考列表。

2.  列表中的值重复的次数由此输入决定。

根据函数说明，此函数在不同条件下的结果如表 6-33 所示。

**表 6-33.** `List.Repeat` 示例

| 公式 | 结果 |
| :--- | :--- |
| `=List.Repeat({1,2},2)` | `{1,2,1,2}` |
| `=List.Repeat({1..3},2)` | `{1,2,3,1,2,3}` |
| `=List.Repeat({1,2},3)` | `{1,2,1,2,1,2}` |

### `List.Split`

通过使用具有以下语法的此函数，可以将一个大列表转换为多个较小的列表：

```
List.Split(
   list as list,
   pageSize as number
) as list
```

此函数接收两个输入。

1.  第一个输入定义了参考列表。

2.  第二个输入决定了子集列表的长度。例如，在此输入中输入 `2`，参考列表将被分割成多个长度为 `2` 的列表。

根据函数说明，此函数的结果通过表 6-34 中的几个示例提供。

**表 6-34.** `List.Split` 示例

| 公式 | 结果 |
| :--- | :--- |
| `=List.Split({1..5},2)` | `{{1,2},{3,4},{5}}` |
| `=List.Split({1..5},3)` | `{{1,2,3},{4,5}}` |
| `=List.Split({1..5},4)` | `{{1,2,3,4},{5}}` |

# 第 7 章 - 记录

在数据操作的交响乐中，零散的信息片段常常和谐地奏出更完整的旋律。记录就是这样一种多功能且动态的数据结构，它允许我们封装并理解实体各属性之间的相互作用。本章深入探讨 Power Query 中的记录函数世界，通过利用结构化关系的力量，揭示将原始数据转化为有意义见解的艺术。

本章的旅程从记录的基础探索开始：它们的结构、属性以及容纳混合数据类型的能力。有了这种理解，你将深入记录的创建领域，学习如何手动以及通过计算表达式来构建这些动态容器。

## 定义记录

记录是一组值，每个值都有一个特定的标题，并且每个标题只能输入一个值。为简单起见，可以将记录视为表中的一行。要定义记录，需要首先提及标题（类似于表中的列标题），然后在 `[ ]` 之间显示一个等号及其值，如下所示以及图 7-1 中所示：

`=[A=123,B=81,C="XYZ"]`

**图 7-1.** 在 Power Query 中定义记录

在记录中，一个字段的值可以基于其他字段计算。因此，使用记录，可以通过定义变量在多步中执行高级计算。请考虑以下示例以及图 7-2：

`= [A=5,B=A+3,C=A+B]`

**图 7-2.** 定义记录

记录的每个字段可以是一个值、一个列表、另一个记录或一个表。在以下公式和图 7-3 中，字段 `A` 等于一个数字，字段 `B` 和 `D` 是列表，字段 `C` 本身等于另一个记录：

`= [A=5,B={1..3},C=[A=1,B=3],D={2}]`

**图 7-3.** 包含另一个记录的记录

如前所述，记录可以看作是表中的一行，因此通过包含表名以及 `{ }` 内所需的行号，结果是一个记录，其字段标题与表中的列标题相同，字段值等于所选行的值。例如，考虑表 7-1 中所示的 `TableA`。

**表 7-1.** `TableA`

| 产品 | 价格 | 材料 |
| :--- | :--- | :--- |
| W11 | 100 | 金属 |
| s06 | 150 | 木材 |
| r08 | 125 | 玻璃 |

`TableA{0}` 的值等于以下记录：

`[Product="W11", Price=100, Material="Metal"]`

`TableA{2}` 的值等于以下记录：

`[Product="R08", Price=125, Material="Glass"]`

由于记录的性质，在 Power Query 中不能使用运算符执行数学运算（加法、乘法、除法和减法），但可以使用 `&` 运算符合并两个记录。
