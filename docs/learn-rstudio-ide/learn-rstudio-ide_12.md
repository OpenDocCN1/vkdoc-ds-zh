## 对象

在R语言中，一切都是对象。一个对象可以是一个数字列表、一个函数、一个图形或一个分析结果。存在不同类型的对象，例如列表、数据框和字符。

你可以使用赋值运算符`<-`创建对象。左边是你选择的一个名称，接着是赋值运算符`<-`，然后是定义对象的代码。你可以像这样创建一个数值对象：

```
a <- 9
```

第一部分`a`是我们为对象选择的名称，后面跟着赋值运算符`<-`，然后是一个值`9`。现在，我们在代码中通过直接使用字母`a`来引用这个对象。例如，如果我们想知道如何将`a`的值翻倍，我们可以这样做：

```
a * 2
```

这将在控制台打印出`18`。在R语言中，对象可以是不同的类型。上面的对象`a`是`numeric`类型。这些类型在R语言中被称为“类”。你可以使用`class`函数来查找对象的类。

```
class(a)
```

这将在你的控制台返回值`numeric`。你可以像这样使用赋值运算符来改变对象的类：

```
class(a) <- "custom_numeric"
```

通常，你不会改变已经存在的对象（如数值或字符）的类。然而，如果你正在创建自己的自定义类，并希望将你的对象与环境中的其他对象区分开来，你可能会这样做。

### 基本类类型

在编写代码时，我们可以定义和使用多种类型的对象，但其中有几种是R编程的基础，因此下面将专门介绍它们。

#### 字符和数值

我们在第一节中介绍了数值对象，字符对象的工作方式类似。真正的区别在于，字符对象存储的是字符而非数字。字符对象需要用单引号或双引号括起来，像这样：

```
b <- "nine"
```

当我们在代码中引用`b`时，我们将得到字符串“nine”。与我们之前看到的数值对象不同，我们不能将`b`乘以2。如果我们尝试这样做，会得到错误“二元运算符的非数值参数”。

虽然我们不能对字符对象进行数学运算，但我们可以使用`stringr`库来操作这些对象。例如，如果我们想将两个字符对象合并在一起，我们可以像这样使用`stringr`库中的`str_glue`函数：

```
library(stringr)
str_glue(b, " times 2")
```

这将返回字符串“nine times 2”。`library`关键字用于让我们访问一个函数库。上面的第一行代码意味着我们需要访问`stringr`库。

#### 向量

向量是同一类型对象的列表。你可能有一个字符、数值或其他类型对象的列表。你使用从1开始的数值来跟踪列表中的对象。要创建一个向量，你需要使用名为`c`的函数，该函数接受一个逗号分隔的值列表来创建该列表。下面是你如何创建一个包含字母表中前五个字母的向量：

```
alpha <- c("A", "B", "C", "D", "E")
```

你可以通过输入名称`alpha`将整个列表打印到控制台，或者通过使用对象名称后跟方括号以及对应向量中感兴趣元素的索引来引用单个元素。

例如，`alpha[1]`将打印出“A”，而`alpha[5]`将打印出“E”。

当你对向量应用像乘法这样的运算或函数时，该运算将应用于向量中的每个对象。结果将是一个新的向量。例如，如果我们有一个包含数字20、30、40、50和60的向量，然后将该向量乘以4，我们最终将得到一个新的向量80、120、160、200和240。

```
n <- c(20,30,40,50,60)
n
[1] 20 30 40 50 60
n * 4
[1]  80 120 160 200 240
```

### 矩阵

矩阵是一个具有两个维度（本质上是行和列）的向量。与向量类似，矩阵中的每个对象必须是相同类型。你可以通过像这样设置向量的`dim`（维度）属性来创建一个矩阵：

```
m <- c(1,2,3,4,5,6,7,8,9)
dim(m) <- c(3,3)
m
```

当你检查`m`时，你会看到这个矩阵：

```
     [,1] [,2] [,3]
[1,]    1    4    7
[2,]    2    5    8
[3,]    3    6    9
```

要引用矩阵中的单个单元格，你需要提供行和列的索引。例如，要查看第2行第1列的内容，你可以这样操作：`m[2,1]`将得到值2。

### 列表

我们之前讨论的向量被称为原子向量，因为它们必须包含所有相同类型的元素。而包含混合类型对象的向量则被称为列表。当你想要管理相关对象的集合时，列表非常方便。

要创建一个新列表，你可以像这样使用`list`函数：

```
l <- list()
l$name <- "Cards"
l$cards <- c("10","Jack","Queen","King","Ace")
l$bets <- c(1,5,10)
```

第一行创建了一个空列表，然后使用`$`来创建名称并分配对象。第一个是一个描述列表的字符对象，第二个是一个字符向量，最后一个是一个数值向量。之后要访问这些值，你必须使用列表名称后跟美元符号`$`和对象名称。例如，要查看卡牌列表，你可以输入`l$cards`，要获取列表中的第二张牌，则输入`l$cards[2]`。

### 因子

因子是一种只能包含特定值的向量类型。例如，你可能有一个用来表示性别的值列表，每个值必须是“male”、“female”或“unknown”。当我们对对象类别进行分析时，这种结构非常方便。

你可以使用`factor`函数并提供值列表来创建一个因子。

```
sex <- factor(c("male","female","unknown","male"))
sex
```

这段代码会输出以下信息：

```
[1] male    female  unknown male
Levels: female male unknown
```

我们得到了一个类似向量中的值列表，但还附带了额外的“水平”信息。

### 数据框

数据框是一种特殊的列表，其各个组件的长度必须相等。实际上，这提供了一种类似电子表格的二维数据结构，由行和列组成。你可以像使用列表一样，通过`$`运算符来操作数据框的组件，或者像使用矩阵一样，通过行和列索引来操作。

你可以使用`data.frame`函数创建一个数据框：

```
df <- data.frame(numbers = c(1,2,3),
letters = c("A","B","C"))
df$more <- c("1st","2nd","3rd")
```

在用`data.frame`函数创建数据框时，你可以提供长度相等的向量。一旦你有了一个数据框，就可以像上面那样使用`$`运算符创建额外的列。

通常，你会从一个函数的输出中得到一个为你创建好的数据框。数据框是R语言中一个基础对象，而数据框的“tibble”变体类型在“必备R包”一章中有非常详细的介绍。

## 流程控制

到目前为止，我们主要是在创建对象、设置属性并检查结果。R编程还包含使用条件分支和循环来重复执行代码的方法。

### If-Then 语句

if-then语句指示我们的程序根据某些对象的状态采取不同的操作。下面是一个if-then语句的例子：

```
state <- "startup"
if(state == "startup") {
print("We are about to start the program")
state = "running program"
} else {
print("Program running")
}
```

我们有一个名为`state`的对象，其值为“startup”。下一行代码会评估`state`对象，如果该对象等于“startup”，那么`if`语句后面花括号内的代码将被执行。程序会打印一条状态信息，并且`state`对象的值会发生改变。

如果`state`对象的值不是“startup”，那么`else`关键字后面的代码将被执行。在这里，程序会简单地打印出“Program running”这条消息。

在上面的例子中，我们使用了`==`运算符来测试两个值是否相等。你还可以测试不相等（`!=`）、大于（`>`）、小于（`<`）、大于等于（`>=`）和小于等于（`<=`）。

你还可以在一行代码中使用if-else，这在代码简洁时效果很好。例如，如果我们只是想测试`state`对象是否处于启动模式，我们可以简单地这样做：

```
ifelse(state == "startup", TRUE, FALSE)
```

如果`state`是“startup”，我们将得到布尔值`TRUE`。否则，我们得到布尔值`FALSE`。布尔值是一种特殊的对象类型，其值只能为真或假，常用于测试此类条件。

### 循环

循环为我们提供了一种重复执行相同代码的方法。在R中，我们可以使用两种类型的循环：`for`循环和`while`循环。我们还可以使用提供类似循环行为的`apply`函数族。让我们看看循环是如何工作的。

#### For 循环

For 循环会执行指定的次数。例如，如果你想循环执行代码五次，你可以这样做：

```r
for (i in 1:5){
print(i)
}
```

这将打印出数字1到5。这段代码由`for`关键字和括号中的对象`i`组成，对象`i`用于记录我们在循环中的位置。`1:5`是R中表示1到5所有数字的简写。这个循环将运行5次，花括号之间的代码每次运行都会产生以下输出：

```
[1] 1
[1] 2
[1] 3
[1] 4
[1] 5
```

#### While 循环

While 循环也会重复执行代码。但是，这些循环不会执行固定的次数，而是会一直运行直到满足某个条件。下面是我们如何使用`while`循环从1数到5的方法：

```r
i <- 0
while (i <= 5) {
print(i)
i <- i + 1
}
```

`while`循环检查`i`对象的状态，并在条件`i <= 5`为假之前，一直将值打印到控制台。每次循环迭代，`i`的值都会增加1。

#### Apply 函数

`apply`函数族也提供循环模式，但形式更为紧凑。你会在各种R包以及基础R中看到这类函数的使用。一般模式是，你通过传递一个对象（如向量、数据框或列表）来使用`apply`函数，然后`apply`函数会遍历该对象中的每个元素。你将要对每个元素执行的代码提供给`apply`函数，然后该函数会返回一个新的对象。

要复现我们目前使用循环所做的工作，我们可以这样做：

```r
sapply(1:5, function(x){print(x)})
```

这要简洁得多，我们实际上只需要向量`1:5`和要执行的代码。请注意，这段代码是一个“匿名函数”，接下来会更详细地讨论函数。基本上，我们定义了一个带有一个参数`x`的函数，`x`是向量中当前值的占位符，并且花括号之间是我们将对向量中每个元素执行的代码。

我们在这里使用了`sapply`函数，此版本的`apply`函数会返回一个简化后的对象（在此例中是一个向量）。在上述情况下，我们只是取回了同一个向量。然而，我们本可以做一些类似这样的事情：

```r
sapply(1:5, function(x){
x * 2
})
```

我们把匿名函数拆分开来是为了让代码更清晰一些。这段代码会生成一个新的向量，并在控制台打印出以下内容：

```
[1]  2  4  6  8 10
```

这个`apply`函数是一个通用的包装函数，它会返回最简单的对象。我们还有`lapply`，它用于列表和数据框，工作方式相同，但返回列表对象。

### 函数

函数是一种对象，其中包含一段代码块，该代码块可通过你提供的输入来执行。这些对象是遵循“一次编写代码”最佳实践的好方法。通常，任何你觉得可以在整个项目中重复使用的代码块，都可以封装成一个函数以备后用。以下是创建函数对象的方法：

```r
my_fun <- function(x, y) {
r = x * 2 + y
r
}
```

花括号`{`和`}`之间的代码构成了函数的主体。在这些花括号内部，你可以创建新对象，并引用那些在函数中声明为参数的对象。参数是在`function`关键字后的括号内，以逗号分隔的列表形式声明的。函数也可以使用在函数外部声明的对象，只要这些对象在函数之前已被声明即可。

包含参数列表和代码块的函数被赋值给`my_fun`对象。我们可以通过在控制台中输入对象名来检查该函数，从而获得函数代码的打印输出。

要使用该函数，我们必须输入函数名，后跟以逗号分隔的参数列表，示例如下：

```r
my_fun(3, 189)
```

这会返回数值对象`195`。在函数内部，每一行代码都会被执行，并且最后一行代码的结果会被返回给调用者。`my_fun`中的最后一行代码是计算结果。

未赋值给对象名的函数称为匿名函数，通常用作诸如`lapply`或`sapply`等函数的参数。这些函数的运行方式相同，但不像标准函数那样需要重复使用。

### 导入 JSON 数据

JSON（JavaScript Object Notation）是一种数据格式，与csv或其他二维数据格式相比，一些程序员可能不太熟悉。JSON数据格式的设计目标是能够以文本格式轻松发送，同时保持结构化格式。

以下是一个JSON数据示例：

```json
[{"year":2015,"race":"All Races","sex":"Both Sexes","death":733.1},{"year":2014,"race":"All Races","sex":"Both Sexes","life":78.9,"death":724.6},{"year":2013,"race":"All Races","sex":"Both Sexes","life":78.8,"death":731.9},{"year":2012,"race":"All Races","sex":"Both Sexes","life":78.8,"death":732.8},{"year":2011,"race":"All Races","sex":"Both Sexes","life":78.7,"death":741.3},{"year":2010,"race":"All Races","sex":"Both Sexes","life":78.7,"death":747}]
```

这是我们在本书中使用的预期寿命数据的一部分。你可能能大致理解这些数据，但它远非一种友好的格式。

要处理此类数据，你可以使用`jsonlite`包。使用以下代码安装这个包：

```r
install.packages("jsonlite")
```

现在，假设我们将上面的JSON数据存储在一个名为`life_json`的对象中，我们可以通过下面这行简单的代码将数据转换为整洁的格式，以便使用：

```r
library(tidyverse)
library(jsonlite)
life <- fromJSON(life_json)
```

我们在上面包含了库引用。你可以通过在命令行中输入对象名`life`来检查结果，从而得到这个数据框：

```
  year        race        sex death life
1 2015 All Races Both Sexes 733.1   NA
2 2014 All Races Both Sexes 724.6 78.9
3 2013 All Races Both Sexes 731.9 78.8
4 2012 All Races Both Sexes 732.8 78.8
5 2011 All Races Both Sexes 741.3 78.7
6 2010 All Races Both Sexes 747.0 78.7
```

`jsonlite`包中的`fromJSON`函数自动将文件转换为数据框。此函数会自动返回它能提取的最顶层的对象。由于我们的数据恰好适合放入一个数据框，所以我们就得到了数据框。然而，如果底层数据框不符合这种结构，你可能最终会得到一个反映JSON文件结构的列表对象。
