## 目标

对于那些不熟悉编程或网络深层工作原理的人来说，网络爬虫常常看起来像是一门黑色艺术：编写一个程序，让它自行出发探索互联网并收集数据的能力，被视为一种神奇、令人兴奋、甚至可能令人恐惧的力量。确实，很少有编程任务能像网络爬虫一样，同时吸引经验丰富的程序员和编程新手。当程序首次成功运行并在网络上抓取数据时，总能带来一种兴奋感，感觉像是绕过了“常规方式”，破解了某种密码。或许正因如此，网络爬虫如今也频频登上新闻头条。

在本书中，我们旨在提供一份简洁且现代的网络爬虫指南，使用 Python 作为编程语言。我们知道市面上有许多其他的书籍和在线教程，但我们认为仍有空间再添一册。具体来说，我们想提供一份“短小精悍”的指南，避免陷入典型的“X 小时学会”陷阱——为了速度而忽略重要细节或最佳实践。此外，您会注意到本书名为“面向数据科学的实用网络爬虫”。我们本身就是数据科学家，并且经常发现网络爬虫是数据收集武器库中的强大工具。许多数据科学项目都是从获取合适的数据集这一第一步开始的。在某些情况下（可以说是“理想情况”），数据集由业务伙伴、公司的数据仓库或学术导师直接提供，或者可以从外部数据提供商处购买或获得结构化格式的数据；但许多真正有趣的项目，都是从像人类一样的信息源泉——网络上，收集信息宝藏开始的。因此，我们力求提供如下内容：

-   简明扼要，同时足够详尽。
-   面向数据科学家：我们将向您展示网络爬虫如何“融入”数据科学工作流程的多个环节。
-   采用代码优先的方法，让您快速上手，避免过多冗长的文字说明。
-   遵循现代理念，仅使用公认的最佳实践和公开可用的开源 Python 库。
-   超越简单基础，展示如何处理当今的网络环境，包括 JavaScript、Cookie 和常见的反爬技术。
-   包含关于网络爬虫的深入管理和法律讨论。
-   提供大量用于进一步阅读和学习的参考资料。
-   包含多个更大型、完全可运行的示例。

## 目标读者

我们在撰写本书时，主要面向具有数据科学背景的读者。因此，您可能已经熟悉 Python 或其他编程语言或分析工具包（如 R、SAS、SPSS 或其他）。如果您已在用 Python，您会感到得心应手。如果没有，我们会在本章稍后提供一个快速的 Python 入门指南，以帮您掌握基础知识，并提供其他教程的参考。即使您还没有在日常数据科学工作中使用 Python（许多人会认为您应该用），我们也想向您展示，Python 是一种特别强大的用于从网络抓取数据的语言。我们还假设您对网络的工作原理有一些基本了解。也就是说，您熟悉网络浏览器的操作并知道什么是 URL；我们会在后续内容中深入解释细节。

总而言之，我们撰写本书的目标读者群体如下：

-   已在使用 Python 且希望学习如何使用该语言进行网络爬取的数据科学从业者。
-   使用其他编程语言或工具包，但希望采用 Python 执行其工作流程中网络爬取部分的数据科学从业者。
-   网络爬虫课程的讲师和教师。
-   正在从事网络爬虫项目或希望提升 Python 技能的学生。
-   拥有需要从网络获取数据的创意的“公民数据科学家”。
-   希望全面了解网络爬虫是什么、它如何为其团队带来益处、以及需要考虑哪些管理和法律方面的数据科学或商业智能经理。
