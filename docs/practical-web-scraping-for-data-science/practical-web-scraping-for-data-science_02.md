# 结构

本书的章节可分为三个部分：

-   第一部分：网络抓取基础（第 1 章至第 3 章）：在这些章节中，我们将向你介绍网络抓取，以及它对数据科学家为何有用，并讨论网络的关键组成部分——HTTP、HTML 和 CSS。我们将向你展示如何使用 Python 的 `requests` 和 `Beautiful Soup` 库编写基本的抓取器。
-   第二部分：高级网络抓取（第 4 章至第 6 章）：在这里，我们将更深入地探讨 HTTP，并向你展示如何处理表单、登录界面和 Cookie。我们还将解释如何处理大量使用 JavaScript 的网站，并展示如何从简单的网络抓取器进阶到高级网络爬虫。
-   第三部分：管理考量与最佳实践（第 7 章至第 9 章）：在这个结尾部分，我们将讨论在数据科学背景下网络抓取的管理和法律问题，并且“打开大门”，探索其他工具和有趣的库。我们还会列出关于网络抓取最佳实践和技巧的总体概述。最后一章包含一些较大的网络抓取示例，以展示之前涵盖的所有概念如何结合，并重点介绍一些以数据科学为导向的、使用网络抓取数据的趣味用例。

本书的设置非常易于阅读和实践。因此，建议新手从头到尾通读本书。尽管如此，本书的结构也便于你在以后想复习知识或查阅某个特定概念时，轻松地参考书中的任何部分。
