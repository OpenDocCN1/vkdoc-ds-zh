# 7. 数值计算形式体系

## 7.1 引言

数值计算使我们能够求解物理问题，前提是我们可以将其构建成恰当的格式。这一过程需要某些考量。首要且最重要的是理解近似解。例如，如果我们对连续函数进行数字化，由于以有限频率采样，将会引入一定误差。因此，要得到非常精确的结果，就需要非常高的采样率。在需要处理大数据集的情况下，这将成为计算上密集且耗时的任务。用户需要理解，与解析解相比，数值解充其量只是一种近似。寻找其物理意义和重要性的责任在于用户。舍弃那些在现实世界场景中没有意义的解，是一门科学家或工程师多年磨练出的技能。此外，计算设备与其操作者一样聪明。在此领域中，GIGO（垃圾进，垃圾出）法则被严格遵循。

在本章中，我们将讨论使用数值计算解决物理问题所涉及的一些重要步骤。用恰当的术语定义问题仅是第一步。选择合适的模型，然后使用正确的方法（求解器）来解决问题，是区分经验丰富的科学家/工程师与新手的关键。

## 7.2 物理问题

我们物理世界中的一切都受物理定律支配。感谢那些在艰苦条件下辛勤工作，为我们周围发生的现象提出精妙解决方案的科学家，我们才获得了物理定律的数学理论。为了检验这些物理定律的数学形式体系，我们使用计算技术。解析计算涉及符号的运用。而数值计算则涉及使用遵循二进制逻辑的计算机。这两种方法都有其局限性。尽管解析解非常精确，但它们难以推导，尤其是在缺乏预定义框架的情况下。另一方面，数值解始终是真实值的近似。无论如何，如果计算结果与真实实验的结果一致，那么这两个结果就相互印证。只要我们有一个经过充分检验的数学形式体系，数值模拟就能完全消除进行实验的必要。例如，当今的核大国已不再“真正地”测试核弹。在真实核爆炸中获得的数据使科学家能够相当精确地对这些物理系统进行建模，从而消除了真实测试的需要。

除了模拟真实实验这类应用之外，对物理问题进行建模也是一项很好的教育实践。在建模过程中，动手练习使学生能够深入探索某个主题，并赋予被研究主题恰当的意义。求解数值问题以及对结果进行可视化，能使学习成果持久，并激发对数学理论缺陷的研究，最终带来新的发现。

## 7.3 定义模型

建模意味着为物理系统写出方程。顾名思义，方程是关于将两边等起来的关系式。方程使用 `=` 符号书写，其中左侧的项等于右侧的项。方程两边的项可以是数字或表达式。例如：
$$ 3x+4y+9z=10 $$

这是一个方程，左侧（LHS）有一个项 `3x + 4y + 9z`，右侧（RHS）有一个项 `10`。请注意，尽管左侧是一个代数表达式，右侧却是一个数字。

表达式是使用函数编写的，而函数只是两个域之间的关系。函数 `f(x) = y` 使用代数规则表达了 `y` 和 `x` 之间的关系。数学拥有一个丰富的函数库，我们可以用来构建表达式。我们选择的函数取决于具体问题。有些函数能比其他函数更好地描述某些情形。例如，振荡行为可以用 `sin(x)` 和 `cos(x)` 等三角函数进行合理描述。沿直线运动的物体可以用 `y = mx + c` 这样的线性方程很好地描述，其中 `x` 是当前位置，`m` 是 `x` 相对于 `y` 的恒定变化率，`c` 是偏移位置。沿曲线运动的物体则可以用各种非线性函数（其中因变量（如先前例子中的`x`）的幂次不为 1）来描述。

在现实生活中，我们可能遇到多种情形混合的情况。例如，一个物体可以同时振荡和沿曲线运动。在这种情况下，我们使用混合函数来编写表达式，或者寻找能够解释该物体行为的新函数。通过求解描述行为的方程并将其与对物体的观察结果进行匹配，来验证这些函数选择。如果它们完全匹配，我们就得到完美解。在大多数情况下，可能难以获得精确解。在这些情况下，我们得到的是“近似”解。如果在获得近似解过程中涉及的误差在容许范围内，那么这些模型是可以接受的。

如前所述，通过使用涉及因变量的函数来编写数学表达式，可以对物理情况进行解析求解。最简单的问题涉及因变量之间的简单函数以及单个方程。也可能存在需要多个方程才能解释某种物理行为的情况。在求解多个方程的情况下，矩阵理论就派上了用场。

假设方程 `7.1` 和 `7.2` 定义了一个系统的物理行为：
```
$$ -x+3y=4 $$
```
(7.1)

```
$$ 2x-4y=-3 $$
```
(7.2)

那么，这个由两个方程组成的方程组可以用一个矩阵方程来表示，如下所示：
```
$$ \left[\begin{array}{cc}-1& 3\\ {}2& -4\end{array}\right]+\left[\begin{array}{c}x\\ {}y\end{array}\right]=\left[\begin{array}{c}4\\ {}3\end{array}\right] $$
```

现在，利用矩阵代数，可以找出满足这些方程的变量 `x` 和 `y` 的值。这些值被称为这些方程的根。这些根是二维空间中的点（因为我们有两个因变量），系统在该物理问题中将达到稳定状态。通过这种方式，我们可以预测系统的行为，而无需实际进行实验。
