# 通过文件读写处理数据

## 引言

利用第 4 章中的信息，您现在可以将物理问题用数值计算的形式表述出来，并在数字计算机上求解。这个过程需要满足以下要求：

- 数据应为数字形式（一个数字文件）。
- 计算机程序应能够读取该文件并无错误地创建数组。
  - 在这种情况下，错误纠正将是一个附加功能。
  - 如果发生错误，应具备检查这些错误并向用户发出警告的机制。
- 数据应根据数据类型存储为数组，并能在需要时以适当的格式显示。
- 对数据进行的数组操作会占用内存，这体现在磁盘上数据的读写方面。系统应为此提供支持。用户应能在需要时检查内存状态。
- 后处理任务包括以各种格式可视化数据：作为打印机的打印输出，作为终端或打印机/绘图仪上的图形，等等。
- 如果能够为某个包含输入参数、处理数据以及输出文件或图形的特定实验生成报告，那么用户的这项任务就变得更容易了。

Scilab 针对这些需求中的每一项都具备一些功能。在本章中，我们将讨论与处理各种格式数据输入和输出文件相关的一些功能。

## 文件操作

文件操作是解决计算问题的重要组成部分。需要重点注意的是，文件系统依赖于操作系统。由于 Unix/Linux 一直是科学和工程领域流行的操作系统，因此 Scilab 支持用于文件管理的 Unix/Linux 命令。当 Scilab 安装在 Windows 上时，您可以使用与 Linux 相同的命令来处理文件，因为您始终在 Scilab 微环境中工作。以下各节中的代码已在 Windows 8、MacOSX 10.12 和 Ubuntu 16.04 系统上测试过。

### 用户

计算系统由不同的用户通过操作系统访问。每个用户定义一个工作区，然后在该工作区内工作，以避免损坏其他用户的文件。登录后，用户的工作区即对该用户激活。Scilab 不提供针对该软件的登录功能，但当用户登录其操作系统时，他们的 Scilab 工作区也会被激活。（公用计算机不提供此功能。）工作区由各种文件和文件夹组成。文件存储数据，而文件夹/目录只是存储指向其他文件链接的特殊文件。因此，一个文件夹中可以存储多个文件。

您可以对文件对象执行许多操作。读取文件涉及将文件中的数据输入到所需位置。当该位置是计算机显示器并且您拥有文本可视化工具时，您可以以字符或符号的形式看到数据。当该位置是一个程序以接受文件中的数据时，数据被程序读取并输入到所需函数中。如果根据输入和输出端的要求需要格式转换，那么数据会有多种格式。某些文件（在本例中是 Scilab 的 `.sci` 和 `.sce` 文件）需要被执行（即运行程序）。

对于上述所有目的，文件在操作之前被打开，并且必须在操作之后关闭。文件的状态（是打开还是关闭）由一个标志（通常是一个整数）来指示。

有些文件对于操作系统定义系统的行为至关重要。因此，不应更改这些文件。通过对用户授予权限，可以防止不必要的更改。“读取”和“写入”文件受到权限的限制。“管理员”（常被称为 `admin`）也称为“超级用户”，拥有编辑任何文件/文件夹的所有特权和权限。您需要了解特定计算机系统上定义的用户类型，然后相应地发出命令。如果您没有访问某些文件夹的权限，而输入数据存放在这些文件/文件夹内，那么除非您请求 `admin` 更改权限参数，否则您总会遇到错误。

在公用计算机上，通常不授予 `admin` 权限。这限制了 `读取`、`写入` 和 `执行` 操作。当用户使用个人计算机时，他们通常将自己声明为超级用户，因此其账户拥有所有必需的权限。在多人共享的计算机上，`admin` 有选择地分配 `读取`、`写入` 和 `执行` 的权限。用户必须为所需操作寻求适当的权限。



### 5.2.2 文件路径

目录/文件夹可以包含子目录/子文件夹和文件。如果管理员不限制此过程，这种行为可以达到任意层级。`pwd` 命令代表打印当前工作目录。在 Scilab 终端中，输入 `pwd` 会显示当前工作目录的路径，如下例所示：

```
1  −−>pwd
2  ans =
3  /Users/
```

在用户目录下，`/Users` 目录包含一个以用户名（用户安装操作系统时给定的`<userName>`）命名的子目录。这是分配给 Scilab 会话的主要工作区。除非用户更改目录，否则用户在此工作区中执行所有任务。当在终端中输入 `pwd` 时，一个名为 `ans` 的变量会存储数据（文件路径）。如前所述，`ans` 存储 Scilab REPL 中的最后一个输出。可以分配一个变量（名称由用户选择）将文件名存储为字符串。

通过在终端中写入文件路径来访问文件/文件夹。让我们做一个小练习来理解这个过程。要创建一个新目录，请使用 `mkdir 'name'`，如下所示：

```
1  −>mkdir scilab // 创建一个名为 'scilab' 的新目录
2   ans =
3  1.
4  −−>cd scilab /// 将当前目录更改为目录名 'scilab'
5  ans =
6  /Users/sandeepnagar/scilab
7  −−>mkdir test // 创建一个名为 'test' 的目录
8  ans =
9  1.
10  −−>cd test // 将当前目录更改为目录名 'test'
11  ans =
12  /Users/sandeepnagar/scilab/test
13  −−>ls // 列出当前目录（即 'test'）的内容
14  ans =
15  []
16  −−>mkdir new // 在此处创建一个名为 'new' 的目录
17  ans =
18  1.
19  −−>ls // 列出当前目录（即 'test'）的内容
20  ans =
21  new
22  −−>rmdir new // 删除名为 'new' 的目录
23  ans =
24  1.
25  −−>ls // 列出当前目录（即 'test'）的内容
26  ans =
27  []
28  −−>isdir('/Users/sandeepnagar/scilab/test') // 检查目录 'test' 是否存在
29  ans =
30  T
```

在第 1 行，`mkdir scilab` 创建了一个名为 `'scilab'` 的目录。要查看当前目录的内容，我们可以使用命令 `ls`，它代表列表（list）。要更改目录，我们可以使用命令 `cd "file path"`。我们将在本书的其余练习中使用此目录。

我们可以在名为 `scilab` 的目录中创建一个名为 `test` 的目录。我们可以使用 `ls` 命令查看其内容列表。当目录为空时，显示 `ans=[]`。如果我们现在通过执行 `mkdir new` 命令在子目录 `test` 内创建一个名为 `new` 的新目录，然后检查内容列表，结果显示为 `ans= new`。要删除目录，我们可以使用 `rmdir` 命令。因此，通过执行 `rmdir new`，我们可以看到用户已删除名为 `new` 的目录。

命令 `isdir` 检查输入参数（路径）是否指向一个目录。当在输入路径处找到一个目录时，输出为布尔变量 `T` (真)；否则，输出为 `F` (假)。

### 5.2.3 创建文件并保存

`save` 和 `load` 命令使我们能够向内存写入数据和从内存读取数据：

```
1  −−>a = rand(3,3)
2  a =
3  0.2113249    0.3303271    0.8497452
4  0.7560439    0.6653811    0.6857310
5  0.0002211    0.6283918    0.8782165
6  −−>save('rand_matrix.dat','a')
7  −−>ls
8  ans =
9  ! rand_matrix.dat   !
10  −−>load('rand_matrix.dat','a')
11  −−>a =
12  0.2113249    0.3303271    0.8497452
13  0.7560439    0.6653811    0.6857310
14  0.0002211    0.6283918    0.8782165
```

在第 1 行，首先创建了一个名为 `a` 的变量，该变量存储一个随机的 3×3 矩阵。在第 2 行，这个数据被存储为一个名为 `rand_matrix.dat` 的 `.dat` 文件（数据文件），它将变量名作为参数传递。需要时，可以使用 `load` 命令将此文件加载到工作区中。请注意，数据并不一定非得是数字。

数据可以是数字计算机能够处理的任何东西，包括图片、视频、字符串和字符等等。

通过保存时传递变量名，可以将多个变量存储在同一个文件中：


`help("save")` 和 `help("load")` 提供了关于如何使用这些命令的非常有用的说明。

`load()` 函数遵循与 `save()` 函数相同的逻辑。数据可以从特定格式的文件中解压缩并加载为数组。这样填充的数组可用于计算，如果需要，可以使用 `save()` 函数再次生成结果文件。复杂的计算需要多次重复这个过程。因此，这些函数已经优化，可以在短时间内定位和加载所需数据。

#### 5.2.3.1 打开和关闭文件

要读取和写入数据文件，必须打开它们并将其定义为可读和/或可写。命令 `mopen()` 用于创建一个不存在的文件或打开一个现有文件。例如，以下代码展示了如何在 `write` (写入) 模式下创建一个名为 `test.sce` 的文件。一个名为 `file_handle` 的变量用于存储该事件。查看文件夹的内容列表，您可以看到确实创建了一个此名称的文件。与 `mopen()` 命令类似，`mclose()` 命令用于关闭文件：

```
1  −−>f ile_handle = mopen('test.sce','w') // 以 'write'（写入）模式创建文件
2  f ile_handle =
3  1.
4  −−>ls
5  ans =
6  test.sce
7  −−>mclose(f ile_handle) // 关闭文件，返回整数 0 表示文件成功关闭
8  ans =
9  0.
```

`mode` (模式) 参数控制文件的访问类型，其值可以在表 5-1 中找到。

**表 5-1** 不同的文件模式

| `r` | 以读取模式打开 (默认)。文件必须存在；否则，操作失败。 |
| :--- | :--- |
| `w` | 以写入模式打开。如果文件存在，其内容将被销毁。 |
| `a` | 以追加模式打开。如果文件不存在，则创建它。 |
| `r+` | 以读写模式打开。文件必须存在；否则，操作失败。 |
| `w+` | 以读写模式打开。如果文件存在，其内容将被销毁。 |
| `a+` | 以读写和追加模式打开。如果文件不存在，则创建它。 |

此外，表 5-2 中的字符可用于指定文件类型。

**表 5-2** 不同的文件类型

| `t` | 文本文件 |
| :--- | :--- |
| `b` | 二进制文件 (默认) |

默认的访问模式是 `'rb'` (读取二进制文件)。

## 5.3 总结

在本章中，我们阐述了多种函数，这些函数实现了读写权限，以及在文件中存取数据的功能。这些函数构成了数值计算练习的重要组成部分。数据可以通过软件包或硬件（仪器）以文件形式生成。Scilab 并不关心数据的来源。它根据数据的类型和文件类型来处理数据。用户需要根据实际情况，自行判断使用哪个合适的函数来操作文件。文件操作提供了裁剪数据的能力，以便仅将数据中有用的部分作为数组输入。进一步的裁剪可以通过切片操作来完成。掌握了文件处理的技巧，你就能自信地处理复杂的数值计算。
