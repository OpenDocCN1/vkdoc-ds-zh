# 6. 函数与循环

## 6.1 引言

当某个特定的数值计算任务需要在不同的数据点上“重复”执行时，数字计算机就成为了一个有用的工具，因为它们能以比人类更快的速度执行这种操作。循环正是执行此任务的。通过使用条件来检查开始和终止规则，用户可以按需执行过程中的重复部分。不同的编程语言和环境对定义循环有不同的规则。Scilab 提供了一种简单的方式来定义和运行循环。除了循环，函数也构成了现代编程架构的重要部分。一个大型程序可能需要在不同时间调用一组指令。因此，可以将这组指令定义为一个子程序，以便在需要时请求其执行计算。通过这种方式，一个复杂的任务可以被分解成许多小部分。这种编程架构被称为模块化编程。它是最流行的编程方式，因为它逻辑清晰、善于可视化问题，并且易于调试。定义这些小型指令集最流行的方法是将它们定义为函数。函数和循环共同将一个数值计算问题分解为一系列更简单的问题，从而可以根据需要随时调用。在本章中，我们将详细讨论这两个概念。

## 6.2 循环

循环构成了算法的重要组成部分，因为它们执行计算机最擅长的任务：以非常快速的方式执行重复性操作。循环有多种形式，例如 `for` 循环，它遍历一系列变量值并重复执行某些任务；`while` 循环，它在执行某任务之前检查一个逻辑条件；以及 `if-then-else` 循环，它检查一个条件并引导算法的流程。你选择的循环类型取决于手头的问题。

后续章节中描述了各种函数及其用法。批判性地判断其用法至关重要，因为循环部分会消耗大部分执行时间。

### 6.2.1 `while`

`while` 循环定义一个逻辑条件，并在该条件满足之前，持续运行一段代码块。`while` 循环的语法如下：

```
1  while 条件
2  循环体
3  endwhile
```

这里，关键字 `while` 启动 `while` 循环的执行。`条件` 是一个逻辑条件，其答案可以是 '`true`'（1）或 '`false`'（0）。`循环体` 包含一串命令，这些命令在条件保持为 `true` 期间被执行，如清单 6-1 所示。

```
1  i = 1
2  while i<20
3      disp(i);
4      i = i*2;
5   end
清单 6-1
while.sce
```

结果如下所示：

```
1  -->exec('/Users/sandeepnagar/.../while.sce', -1)
2  1.
3  2.
4  4.
5  8.
6  16
```

代码 `while.sce` 首先将变量 `i` 初始化为数值 1。然后检查条件 `i < 20`。这在第一步 `i = 1` 时为真。因此，它进入循环并执行命令 `disp(i)`。（数值 1 被打印在终端上。）接着执行下一行（`i = i * 2`），使得 `i` 的新值变为 2。在循环结束时，控制权再次交给条件语句（`i < 20`）。只要此条件为 `true`，循环就会运行，因此会打印出 1、2、4、8、16。当 `i = 16` 并执行语句 `i = i * 2` 后，`i` 的新值变为 32。此时条件不再满足，循环终止。

### 6.2.2 无限循环

有些循环可以无限运行，因此被称为无限循环。尝试通过将 `i` 初始化为 `0` 而不是 `i = 1` 来测试代码 `while.sce`。在这种情况下，循环内 `i` 的值将始终为 0，并且条件 `i < 20` 将始终为 `true`。因此，如果不中断，代码将永远运行下去。在 ASCII 键盘上，可以通过 `Ctrl+C` 组合键来中断无限循环。

避免无限循环的责任在于用户。Scilab 只会机械地执行语句，而不会显示警告或错误消息。从技术上讲，无限循环并不是编程错误，因为它们在语法上是正确的。实际上，如果你需要生成无限的数据流，或者需要无限地执行一个 Scilab 程序，那么可以使用无限循环。例如，假设一个 Scilab 程序报告远程风力涡轮机的状态。此代码需要无限运行，除非被中断。再比如，假设某个应用程序需要源源不断的随机数流。在这种情况下，可以编写一个 Scilab 代码来生成无限的随机数序列。



### 6.2.3 `for`

`for`循环用于对已知值列表执行计算。`for`循环的语法如下：

```
1  for 变量 = 向量
2    循环体
3  end
```

关键字 `for` 声明循环的开始，其中变量会依次取向量中存储的值。随后执行循环体代码（由 `循环体` 表示）。关键字 `end` 声明 `for` 循环的结束。这在清单 6-2 中进行了说明。

```
1  for i = 1:10
2      square_root = sqrt(i);
3      disp(square_root)
4  end

6  disp("程序结束")
清单 6-2
for.sce
```

执行 `for1.m` 会得到以下结果：

```
1  −−−>exec('/Users/sandeepnag.../for.sce', −1)
2  1.
3  1.4142136
4  1.7320508
5  2.
6  2.236068
7  2.4494897
8  2.6457513
9  2.8284271
10  3.
11  3.1622777
12  程序结束
```

`for` 语句会创建一个从 1 到 10 的数值向量，并将其存储在名为 `i` 的变量中。该向量的每个成员都会被送入循环体。一个名为 `square_root` 的变量存储数组中当前值的平方根，然后通过命令 `disp(square_root)` 在 Scilab 终端上打印该值。当这两个命令执行完毕后，会选取向量的下一个成员，并重复相同的过程。这一直持续到向量的最后一个成员被存储在名为 `i`（`i = 10`）的变量中。

### 6.2.4 `if-elseif-else`

在需要在不同时间点检查多个条件的情况下，`if-elseif-else` 循环效果很好。此循环的语法如下：

```
1  if 条件 1
2  代码块 1
3  elseif 条件 2
4  代码块 2
5  else
6  代码块 3
7  endif
```

在第 1 行，定义了一个条件。如果满足此条件，则执行第 2 行，否则执行第 3 行。因此，`代码块 1` 和 `代码块 2` 是通过检查不同条件集来执行的代码块，而当没有任何条件被执行时，会执行 `代码块 3` 的代码集。（参见清单 6-3）。

```
1  i = rand(1,1);
2  if i>0.5 then
3  disp(i);
4  disp("真");
5  else
6  disp(i);
7  disp("假");
8  end
清单 6-3
ifelse.sce
```

运行代码会得到以下结果：


## 6.3 函数

函数是一组可在需要时被调用的代码。因此，它可以单独定义在自己的文件中，也可以定义在程序主体内部。脚本文件在本质上是类似的。脚本文件存储了要执行的一系列命令。函数和脚本似乎性质相似，但与 MATLAB 和 Octave 不同，Scilab 为它们各自提供了独立的文件类型。这是基于它们与 Scilab 核心程序行为的不同性质决定的。

脚本文件（扩展名为 `.sce`）是可执行文件，而函数文件（扩展名为 `.sci`）存储一组指令。函数文件的行为就像一个黑盒，输入数据并得到输出。另一方面，脚本文件会根据输入值改变其行为。脚本文件访问的输入数据都取自 Scilab 工作空间。脚本文件的输出数据会被放入 Scilab 工作空间。而输入数据、局部变量的语义，仅在函数内部可见。

函数的定义遵循以下语法：

```
1  function [o1,o2,...] = 函数名 (i1,i2,...)
2  语句 _1
3  语句 _2
4  ...
5  语句 _n
6  endfunction
```

这里，关键字 `function` 将对象类型定义为函数。然后定义了一组该函数预期要返回的变量（`o1,o2,...` 表示输出 1、输出 2……）。接下来是 `=` 运算符和函数名。在上述例子中，是 `函数名`。函数接收输入（`i1,i2,...` 表示输入 1、输入 2……），并根据其主体中定义的计算产生输出。接着是函数的主体部分，其中列出了用于执行函数目的的指令。最后一条语句 `endfunction` 表示函数的结束。

例如，我们可以编写一个函数来计算 `x² − y²`，并将其赋值给变量 `z`，如清单 6-5 所示。

```
1  function y = fn1(a,b)
2  y = aˆ2−bˆ2;
3  endfunction
清单 6-5
fn1.sci
```

注意，这段代码的扩展名是 `.sci`。必须先将此文件加载到 Scilab 工作空间中。我们需要先将文件的完整路径提供给内置函数 `exec()`，然后通过提供函数名及输入参数来使用该函数：

```
1  −−−>exec('/Users/sandeepnagar/.../fn1.sci', −1)
2  −−−>fn1(2,3)
3  ans =
4  −5.
```

好的实践是将程序定义为一组函数文件，并在作为脚本文件存储的主程序中调用它们。这种模块化方法便于对思路进行实验，也使得代码更易于调试和测试。函数也可以返回两个以上的值，如清单 6-6 所示。

```
1  function[y1,y2,y3] = fn2(x,y)
2  y1 = x − y;
3  y2 = x + y;
4  y3 = y − x;
5  endfunction
清单 6-6
fn2.sci
```

这将产生以下结果：

```
1  −−−>exec('/Users/sandeepnagar/.../fn2.sci', −1)
2  −−−>[a,b,c] = fn2(2,3)
3  c =
4  1.
5  b =
6  5.
7  a =
8  −1.
```

函数可以包含循环来规范程序内的重复性任务。例如，可以使用清单 6-7 中给出的函数来计算一个数的阶乘。

```
1  function result = factorial1(n)
2    if(n == 0)
3       result = 1;
4       return;
5    else
6      result = prod(1:n);
7    end
8  endfunction
清单 6-7
factorial1.sci
```

一个名为 `factorial1` 的函数，接受数字 `n` 作为参数，计算该数字与其所有连续数字的乘积。当从 Scilab 命令行调用时，该函数会产生以下结果：

```
1  −−−>exec('/Users/sandeepnagar/.../factorial1.sci', −1)
2  −−−>factorial1(10)
3  ans =
4  3628800.
5  −−−>factorial1(10e5)
6  ans =
7  Inf
```

### 6.3.1 内联函数

内联函数是一种简短的函数，无需使用前面讨论的函数框架即可定义。仅当函数体很简短时，它才比较有用：

```
1  −−−>deff('[x] = mult(y,z)','x=y∗z')
2  −−−>mult(2,3)
3  ans =
4  6
```

内置函数 `deff()` 用于定义另一个内置函数。`deff` 的第一个参数定义了输出变量（本例中为 `x`）、函数名（`mult`）以及输入变量（`y` 和 `z`）。第二个参数定义了函数体（`x=y*z`）。这种函数像普通命令一样在 `.sce` 文件中定义，因此不需要单独的加载操作。定义后，可以通过函数名及输入参数来调用函数。



## 6.4 总结

定义函数是模块化编程的关键。`Scilab` 提供了一种优雅的方式来定义和使用函数，既支持内联函数，也支持独立的函数文件。当结合在循环内编写函数的能力时，复杂问题可以用寥寥数行代码实现。在设计算法时需要一种艺术性的态度，其中函数和循环如同画笔，用以构思出针对特定数值问题的优雅解决方案。
