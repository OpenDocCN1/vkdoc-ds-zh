# 内存溢出错误

随着 Cassandra 处理的海量数据，有时节点可能会因为“内存溢出”错误而崩溃。如果你遇到这种情况，请首先检查行缓存和 memtable 的大小，并确认它们的值是否设置得过大。这里的“过大”仅意味着它们无法很好地适应可用内存。如果这些值远低于可用内存限制，那么我们应该检查堆转储以及服务器和应用程序日志，以获取有关错误的更多信息。从 Cassandra 1.2.9 开始，许多后台进程已从堆内处理迁移到堆外处理，以避免垃圾回收活动。因此，你可能会遇到堆外或堆内内存不足的情况。有关堆外和堆内的更多讨论，请参考第 8 章中的“CPU 和内存利用率”以及“堆外 vs. 堆内”部分。此外，如果应用程序正在读取类似整行或大列的数据，你也可以检查客户端代码。
